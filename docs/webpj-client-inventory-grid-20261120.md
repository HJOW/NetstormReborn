# Client 생산 격자 소유자 (WB04-E1019)

실제 Client Gump 노드·가상 부착·입력·Form 통지를 기존 InventoryGump와 같은 Session의 Pool·내용물 검색기에 연결했다. 좌표 변환은 공통 원본 ScreenToLocal을 사용하고 자식 항목 공장·기본 메뉴 처리는 실제 제공자를 요구한다. 객체 0 부착은 원본 생산 Bind처럼 효과 없이 반환한다.

Tutorial1의 실제 생산 다리 내용물을 고정 격자 항목으로 만들어 같은 SID·마스크와 커서 영역 판정·삭제를 검사했다. 원본 격자 170행과 점멸 110행 등을 포함한 Node 13건이 통과했다. 항목 아이콘 및 클릭, 배경·예산, 완성된 생산 패널의 앱 설치와 부모 소멸 후 재부착 검증은 남았다.
