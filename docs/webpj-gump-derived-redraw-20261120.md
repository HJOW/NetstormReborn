# 파생 Gump 재그리기 분배

WB04-E1037은 같은 Client Gump 수명에서 파생 노드의 재그리기 가상 처리기를 등록하고, 트리·프레임 재그리기가 이를 호출하도록 연결한다. 파생 처리기는 기본 장치를 재귀 없이 직접 호출할 수 있으며 삭제와 미등록 반납 때 처리기 등록도 제거된다. 장식 메뉴의 확장 테두리 재그리기를 연결하기 위한 선행 단계다.

실제 트리 부착과 프레임 재그리기의 가상 분배·기본 호출·삭제를 검사했고 관련 Node 검사 43건이 통과했다. 최초 검사 명령에 존재하지 않는 `gump-frame.test.mjs`가 포함돼 Node 26이 그 경로를 무시했으므로, 실제 파일 `gump-events-input-frame.test.mjs`를 확인해 다시 실행했다. 장식 출력과 메뉴 조립은 남았다. E1035 고정 Node 26 전체 회귀는 실행 중이다.
