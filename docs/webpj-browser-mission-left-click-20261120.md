# 웹 미션 좌클릭 선택 (WB04-E991)

브라우저 좌클릭을 원본 버튼·보조 키·논리 좌표로 변환하고, 준비된 미션에서 실제 Client Gump 입력을 먼저 전달한 뒤 미처리 사건을 같은 World의 CampaignUserInput에 전달한다. 안내창이 열린 동안에는 기존 Tell 입력만 사용한다. 원본 입력 큐 전체 소비자가 아직 없으므로 현재 좌클릭은 임시로 브라우저 사건에서 직접 전달한다. 오른쪽 버튼·키보드·미니맵·HUD와 큐의 다른 명령은 별도 연결이 필요하다.

실제 Tutorial1 Session에서 사제 그림 좌표의 좌클릭이 같은 사제를 선택하는지 확인했다. Chromium에서는 Campaign에서 시작해 여러 안내 페이지를 실제 버튼으로 넘기고 게임 시계가 재개된 뒤 사제를 실제 마우스로 선택했다. 관련 Node 검사 23건과 Chromium 1건이 통과했다. 처음 Gump 검사 파일명을 잘못 지정한 실행은 Node 26이 조용히 건너뛰어 실제 `gump-events-input-frame.test.mjs`를 포함해 다시 검사했다. 브라우저 첫 시도에서는 안내가 단일 OK가 아니라 MORE/BACK 페이지임을 확인하고 실제 전진 버튼을 따라가도록 고쳤다.

E982 고정 Node 22 전체 6,556건은 통과했고 같은 고정 상태의 Node 26 전체 검사가 진행 중이다. 전체 입력·조작과 Tutorial 완료가 구현됐다는 뜻은 아니다.
