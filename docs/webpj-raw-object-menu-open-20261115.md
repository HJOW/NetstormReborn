# 공통 객체 메뉴 Open 이식 (WB04-E543)

G(UI 프레임워크·메뉴)의 "객체 우클릭 메뉴" 중 `client/RawObjectMenuOpen`(원문 10.78 공통 가상 `+ac` 004adb30, 객체 중심 위치 계산 00425f90, Factory `+ac` 004754b0, 포인터 열기 004d9df0)을
`webpj/www/core/raw-object-menu-open.js`로 옮겼다. 기준선 `225553df`와 현재 cpppj 소스가 같음을 확인했다.

## 옮긴 범위

- `open(object, event)`(004adb30): 슬롯 extra bit1이면 0 → TYPE `flags2 0x400000`(Dais)이면 같은 좌표의 제단을 조회해 제단이 유효할 때 그 가상 `+ac`에 같은 사건 참조를 위임 →
  Fancy 생성·제목/정보·파생 `+a8` 작성 → **작성 뒤의 현재 TYPE**이 `flags2 0x30100`이면 위치 계산, 아니면 사건 좌표에 부착 → 1. 사건 좌표는 메뉴 작성 뒤 같은 참조에서 읽어 콜백의 변경을 보존한다.
- `position(object)`(00425f90): 현재 객체 좌표(float)의 투영 → 첫 종속 Form이 있으면 그 kind의 사정거리를 `_ftol`(signed64 하위 DWORD, 불확정값은 0)로 줄여 2로 제한하고 여백 `(거리+1)<<4`·메뉴 폭(역시 `_ftol`)·현재 화면 폭(폭 조회 뒤 읽음)으로
  DWORD 감김·signed 비교를 그대로 따라 x를 오른쪽/왼쪽 중에서 고른 뒤 부착한다. 음수와 INT_MIN의 절댓값도 DWORD로 유지한다.
- `openFactory(object, event)`(004754b0): 건설 중 거부 → 생성·제목·파생 작성 → 위치 보정/선택/제단 위임 없이 같은 사건 좌표(x,y) 부착.
- `openPointerObjectMenu(open, sound)`(004d9df0): 가상 `+ac`가 비영일 때만 `opengump.wav`를 한 번 재생하고 반환값을 보존한다.
- 풀은 10.78이며 TYPE 188개만 받는다(CD 4aebf0/4e35f0 대응은 웹 범위 밖). 실행 경로에서 도달한 경계만 요구하고 누락은 `/미연결/` 오류이다.

## 시험

`webpj/tests/raw-object-menu-open.test.mjs` 4건:

1. 원본 관측 `object-menu-open-x86.tsv` **788입력**: Open/Position 두 부모, 입력 15 DWORD(모드·extra·TYPE flags·제단·위임 반환·변경 경계·사건 좌표·투영·내용물·사정거리·메뉴/화면 폭)에서 반환값·효과 순서와 전체 인자,
   콜백 뒤 현재 슬롯/사건/화면 폭 필드. **첫 실행에서 788입력 전부 일치**했다.
2. 계약: 조기 거부는 GUI 연결을 요구하지 않고 누락된 경계는 그 위치에서 거부(선행 효과는 남음), 풀 범위·TYPE 수 거부.
3. 계약: 사정거리 상한 2, 내용물 kind는 WORD 전체(TYPE 수 초과 거부), Factory는 사건 좌표를 x,y 순서로 부착(원본 fixture가 닿지 않는 경계라 변형 확인 뒤 보강).
4. 포인터 열기: 비영일 때만 한 번 재생·원래 반환값 보존·장치 누락 거부.

**변형 확인:** extra 거부·제단 위임 플래그/범위·위치 플래그·부착 좌표·Factory 거부·사정거리 상한·여백 시프트·오른쪽/왼쪽 보정·선택 비교·화면 폭 조회·`_ftol` 범위/비유한·kind 폭·투영 오프셋·소리 조건/파일명 등 22가지 중 20가지가 시험에서 잡혔다.
남은 2개는 동등 변형이다: ① 오른쪽 값이 이미 앞에서 0 이상으로 보정되어 두 번째 `right < 0` 절댓값 분기에는 도달할 수 없고(원본 컴파일러의 중복 분기), ② 입력이 단정도 float라 2^56 이상은 하위 32비트가 모두 0이어서 `_ftol` 범위를 2^62로 줄여도 결과가 같다.

`webpj/tests/fixtures/manifest.json`에 `object-menu-open`(788입력, 원본 10.78) 항목을 추가했다.
