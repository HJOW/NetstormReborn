# WB04-E908: 앱 공통 Gump 루트

cpppj `RawButtonControls`가 공유하는 Gump 생성·수명·수집·사건·입력 전역에 웹 Client 수명을 부여했다. 원본 기본 생성자로 등록 루트를 만든 뒤 현재 논리 크기를 적용한다. 입력은 같은 루트와 dialog·focus 표를 조회하고, 기본 루트의 미처리 사건은 원본처럼 0을 반환한다. 설정된 overlay 사건은 10.78 값이다. Client의 실제 checking DWORD를 수명 진단이 조회하며, 종료 시 Gump의 지연 삭제·정리 부모를 실행한다.

앱은 자산과 색표 준비 뒤 이 루트를 생성하고 화면비 변경 때 같은 루트 크기를 바꾸며 종료 후 새로 만든다. 현재 루트에 HUD·메뉴·진행 창의 파생 노드나 브라우저 입력을 연결하지 않았고, 실제 로그인 `uiMode`도 아직 이 루트에 연결하지 않았다. 전체 RawButtonControls·RawMenuControls 구현은 남아 있다.

기본 루트 등록·serial·크기·비처리 사건·동일 주소와 지연 삭제, 누락된 진단 및 잘못된 크기를 검사했다. 원본 Gump 생성·수명·사건·입력과 앱 적재 연관 Node 검사 60건, Chromium 실제 생성·화면비 변경·종료·재시작 1건이 통과했다.
