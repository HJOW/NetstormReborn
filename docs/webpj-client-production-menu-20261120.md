# 실제 생산 정보 메뉴 조립

WB04-E1044는 같은 미션 Session과 원본 자산을 사용하는 생산 정보 작성기와 장식 메뉴를 연결했다. 메뉴 제목·본문은 실제 스타일 글자·그림·스크롤 소유자를 공유하고 내용물은 같은 Session의 Form에 연결한다. 메뉴 인스턴스 수와 팝업 닫기, 전체 반납을 제공하며 미등록 노드도 정리한다.

Tutorial1 실제 Session의 생산 항목에서 정보 메뉴를 만들고 Form 소유자, 제목, 항목, 공통 입력에 의한 Help 명령과 삭제·재생성·반납을 확인했다. 검사 장치는 Help 글자를 명시 공급한다. 최초 통합 검사에서는 앱에 아직 초기화되지 않은 helpWord가 null이어서 실패했으며, 검사의 입력을 명시해 재실행했다. 실제 앱의 설정 기반 helpWord 초기화와 메뉴 설치·명령 처리 및 브라우저 검증은 후속이다. 최초 대응표 검사는 새 모듈 등록 전 실행되어 2건 실패했고 등록 후 다시 검사했다.

최종 Node 26 실제 미션·대응표 관련 검사 11건은 모두 통과했다.
