# 1.166 정기 전체 회귀

1.165까지의 Release 빌드를 사용해 Assets 383/383, Core 4,121/4,121, Client 2,970개가 통과했고 실패는 없다. Client 음향 하드웨어 1건은 TRX의 `UnitTestResult`에서 `NotExecuted`이며 통과에 포함하지 않는다. 합계는 7,474통과다. TRX 집계의 Client total은 2,971이다.

결과는 `extracted/dotnet-1166-regression/`에 있다. 검사 진행 중 다음 단위의 소스를 작성했으나 별도 출력 경로를 사용했으며 이 회귀의 실행 바이너리는 1.165까지다. 생산 정보 메뉴 연결, M1 및 실제 플레이 완료를 뜻하지 않는다.
