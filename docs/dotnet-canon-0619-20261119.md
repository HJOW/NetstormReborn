# 0.619 지역 칠하기·소유자 세션 Generate 연결 (R4-2 잔여)

- 일시: 2026-11-19, HJOW-Athlon
- 범위: R4-2 지역 잔여의 세션 연결. `HostSession.BuildRegionOwnershipDevices`·`RegisterRegionTemple`·`RegionPaint` 노출과 `ClientHostGame` Generate 결선, L1 3건과 L2 3경로 재측정이 중심이다.
- 목표: 0.618에서 닫은 본체·L1 전수 재생을 실제 세션에 이어 요새 신전 배치가 투표·도장을 일으키게 하고, 소유자·프레임 이동분을 L2에서 확인한다.

## 원인

- 0.618까지 `RawRegionPaint`·`RawRegionOwnership` 본체와 fixture 전수 재생(8건)은 닫혔으나 세션과는 끊어져 있었다. DN 지면은 도장 전 프레임·소유자 0이 그대로 남았다.
- cpp 근거는 `RawCampaignSession.cpp` 1266~1267행의 ownership 조립과 `RawCampaignOwnership.cpp` 49~53행의 paint·ownership·terrain 결선, 2694행의 vortex `regionOwnership` 호출과 `RawAssetPostPop.cpp` 287행의 신전 목록 등록이다.
- DN 공장 파생(R6)과 신전 전용 후처리·공장 정기 트리거·아웃포스트 목록은 전제이며, 이번 단위는 요새 적재 중 신전 배치 경로만 잇는다.

## 수정

- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`
  - 세션 소유 필드 추가: `_regionPaintState`·`_regionOwnershipState`·`_regionAdditional`·`_regionTemples`·`_regionThemes`·`_regionTerrain`·`_regionTerrainState`·`_regionPaint`·`_regionOwnership`. 같은 인스턴스를 도장·투표가 빌리며 수명은 세션이 진다.
  - `BuildRegionOwnershipDevices(types, themeMode)` 추가. 지형 해시·TYPE 동일성과 `WorldFrames` 크기를 확인하고, 테마 표·빈 프레임 표·getter 지형·도장·투표를 같은 풀·해시·프레임에 연결한다. `MakePaintOwnershipHooks`→`MakeTerrainRegionOwnershipHooks` 순서로 소유자 훅을 잇는다. paint 훅의 `RegionAt`은 getter 지형의 `(x, y) => terrain.RegionAt((int)x, (int)y)`로 연결한다(누락 시 Patch1078 생성자 거부로 L1 실패 확인·교정).
  - `RegionOwnership`·`RegionPaint`·`RegionTemples` 노출과 `RegisterRegionTemple(sid, x, y)` 추가. 슬롯 14~21바이트에 float32 좌표를 쓰고 신전 목록에 등록한 뒤 `ownership.Update(x, y)`로 투표·도장한다.
  - 요새 Pop 분배에 신전 후크 추가. `_regionOwnership`·`_regionTemples` 연결 뒤 `Flags2 & Vortex` 타입이면 `RegisterRegionTemple`을 먼저 호출하고 일반 지형 분배는 기존 경로를 유지한다.
- `dotnetpj/src/Netstorm.Client.Host/ClientHostGame.cs`
  - `BuildFarmPlacementDevices` 뒤에 `BuildRegionOwnershipDevices(types.Types, theammode 읽기)`를 연결했다. 없으면 1(켜짐)을 쓴다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionRegionOwnershipTests.cs`: 신규 L1 3건. `BuildsPaintAndOwnership`(장치 연결·풀 동일·빈 신전 목록·중복 거부), `RequiresDevices`(미연결 명시 예외), `RejectsMismatchedStorage`(지형 Pop과 다른 TYPE 거부).
- PORT_MAP 변경 없음: 기존 `RawRegionPaint`·`RawRegionOwnership` 4행이 같은 파일을 가리키며, 새 메서드는 같은 단위 내 세션 결선이다. 전체 트리거(공장·소용돌이·아웃포스트) 연결 뒤 상태를 다시 판정한다.
