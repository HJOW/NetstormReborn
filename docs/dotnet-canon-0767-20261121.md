# 0.767 ChatWindow 장기 공유 상태와 실제 편집기

ClientChatWindowGlobals에 같은 Window root/등록/후보 목록, 공유 StyleTextBuffer 상태, 파일/수신 마스크/뉴스 시각/키128BYTE, 무시 목록, 동맹 요청, inputLineOff, 자동완성 BSS와 안정된 호스트 문자열을 연결했다. 기존 Current API는 Window.Current의 같은 UIntBox를 반환한다. 공유 로그128줄은 실제 조각/글꼴 저장소가 대여할 때 생성하며 다른 owner의 이중 대여를 거부한다. 창 교체로 이 장기 상태를 초기화하지 않는다.

ClientChatWindowRuntime은 같은100행과 BSS로 Console 자동완성을 실행한다. HostTextEntry가 이미 생성한 처리기를 유지한 채 대상/완성 장치를 설치하도록 했고 실제 Host LoadContent에서 현재 Handle/현재 언어표와 같은 Root의 Identity/완성을 연결했다. 일반 TextEntry를 다른 객체로 교체하지 않는다. 전체 ChatWindow 생성/부착/메뉴, Enter 제출과 일반 전송/수신 설치는 아직 후속이다.

공유 로그 callback은 파일0/무효 관문, valid callback 뒤 현재 파일 재조회, 첫NUL 앞 BYTE 작성 순서를 유지한다. Host에는 명시 뉴스 적재/저장 API를 추가했고 시작 옵션의 같은 inputLineOff 요청도 읽는다. 실제 뉴스 수신 호출자와 프레임말 토글 소비자는 후속이다.
