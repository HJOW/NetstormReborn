# WB04-E715: 내부 로그인 큐의 서버 수신 경계

실제 Tutorial 1 Fort와 같은 Session Player·참여 객체·내부 두 전송 끝을 사용해 Begin, 상태 9, 27h 송신과 Pump를 연결했다. 서버는 같은 pending 연결을 Player 1로 옮기고 해당 Player의 참여 플래그와 Fort manager를 사용하며 응답 프레임을 큐에 넣는다. 월드 설치 callback을 연결하지 않은 검사에서는 실제 `loadWorld` 선택 위치의 미연결 오류까지 실행하고 그 앞의 실제 부분 효과를 확인한다.

처음에는 이미 생성된 같은 이름의 Fort manager를 재사용하는 원본 자연 경로에서 제목 갱신을 기대했으나, 그 경로는 파일을 다시 읽거나 제목을 갱신하지 않음을 확인해 검사 기대값을 바로잡았다. 집중 검사 70건이 통과했다. 이 검사는 서버 처리의 앞부분과 설치 경계만 검증하며 서버 후반, 클라이언트 응답 소비, 실제 월드 설치와 전체 왕복 성공을 주장하지 않는다.

다음은 외곽 `RawCampaignSession`이 Login의 실제 `loadWorld`를 자신의 `load()`와 명령 수신 등록에 연결하고, 같은 소유자 수명에서 서버 후반과 클라이언트 수신을 진행하는 것이다. 외부 전송 등록 반납·Native 분기와 기준선 뒤 32커밋 판정도 남는다. 새 검사에서 공중 유닛 전용 생성·행동, 사제 포획·희생·승리와 실제 게임·브라우저 창 실행은 수행하지 않았다.
