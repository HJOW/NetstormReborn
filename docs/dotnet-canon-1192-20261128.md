# 1.192 WP-5 실제 보호 자산의 캐논 사정선

2026-11-28, HJOW-Athlon. R4 병행 항목 WP-5의 `cannon-asset-ray48`을 실제 제품 적재 경로에 연결했다. 보호 원본의 TYPE/SHP → `MissionFortLoad`/`ShapeDatabase` → 제품 `TerrainDisplayShapes` → `RawGunTarget.CannonRay` 경로를 사용하며 기대값은 기존 원본 기계어 관측48행이다. 지상·보드 끝·8방향의 네 float32 경계를 비트 그대로 대조한다.

최초 검사는 실패했다. 첫 사정선의 기대 비트는 `1122500621,1119092749,1122644787,1121858355`, 실제는 `1122762765,1119617037,1122775859,1122382643`이었다. `TerrainDisplayShapes.Build`가 원본 SHP 추가 헤더의 signed WORD `+0x20/+0x22`인 포구 좌표를 채우지 않던 원인이다. `ShapeDatabase.SquidHeader`가 같은36바이트 헤더를 공급하고 제품 어댑터가 두 좌표를 채우도록 수정했다. 기존 그림 기준점과 포구 좌표는 구별한다.

수정 후 원본48행 전수 일치와 같은 실제 SHP 어댑터의 제단/공장 관련 검사를 포함해 **7/7 통과·실패0**이다. 최초 실패는 `extracted/dotnet-wp5-results/wp5-first.trx`, 수정 후는 `wp5-focus.trx`이며 별도 Release 빌드는 `extracted/dotnet-wp5-artifacts/`다. 공통 fixture 목록에는 해당 SHA/48행 한 항목만 추가했다. `cpp_sync.py` 종료0이다.

같은 검사 출력의 목록 파일을 현재 소스의 정확한 사본으로 갱신한 뒤 재빌드 없이 자료 목록4건+실제 사정선1건을 실행해 **5/5 통과**했다(`wp5-manifest.trx`). 전체 제품/검사 재빌드 결과로 확대하지 않는다.

보호 `_shapes.shp` SHA-256은 `c878353c8054208deef832e34c514b30fe670e175505b129333a5728ba70f68e`, fixture는 `7e74bd7c76044f719a02fb20a98b1cab3512a8fd87b82f31cbac24629edd67a9`이며 전후 불변이다. 실제 게임 실행이나 특정 적 공격·자연 전투 검증은 수행하지 않았다. 다른 SHP 필드와 전체 전투/프레임 결선은 해당 후속 항목으로 유지한다.
