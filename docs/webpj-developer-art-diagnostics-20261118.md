# WB04-E749 개발자 그림 프레임 진단

`31h`의 `dumpArtData`/`dad`를 현재 Session의 TYPE·그림 표와 동일 월드의 프레임 상세/단정 진단 및 수준 29 추적 장치에 연결했다. 최초 프레임 수로 반복 횟수를 정하고 각 반복에서 현재 TYPE와 그림을 읽으며, 진단 복귀 후 같은 그림의 헤더를 출력한다. 실물 범위를 벗어난 타입·프레임이나 도달한 진단 장치의 부재는 명시 오류다.

근거는 기준선 `225553df`의 `RawCampaignSession.cpp` 5120~5128행과 [cpppj 단위 문서](exe/cpp-developer-type-diagnostics-20261107.md)다. 기준선 이후 해당 C++ 파일의 변경은 없으며 새 원본 fixture나 실제 게임 실행은 없다.

독립 검사에서 음수 타입·입력 누락·프레임 상한 고정·출력 뒤 현재 경계 변경·상세 진단과 단정 순서·단정 복귀 뒤 헤더·물리 범위를 확인했다. Tutorial 1의 실제 `31h` 분배기에서 TYPE 154의 현재 그림 헤더와 모든 프레임 출력을 확인했으며 관련 집중 검사는 42건 통과했다. 대응표 검사 오류는 0건이다.

Node v26.13.0 전체 회귀 6,242건이 통과했고 실패·취소·건너뜀은 0건이다. E746의 v22 검사 뒤 네 번째 v26 전체 회귀다.

나머지 개발자 명령·Carrier 등록·로그인 서버 후반과 응답 왕복·Native 분기·앱 미션 연결은 미완료다.
