# WB04-E763 실제 로그인과 사제 이동 연속 검증

기준선 `225553df`의 `CampaignSession_LocalLoginActualHandshakeAndWorldLoad`에 대응해 기존 로그인 통합 검사를 확장했다. 이전 E751의 로그인·옵션 검증과 E755의 사제 이동 검증은 각각 실제 Session을 사용했지만 서로 다른 검사였다. 이번에는 동일한 TheWarBegins Session에서 Zone·로그인·상태 8/9/10/13/14·12개 수신 패킷·22개 옵션과 파생 값을 확인한 뒤 같은 전송에 사제의 40h 이동을 요청하고 실제 Kernel을 진행해 `(90,108)` 자연 도착을 확인했다.

로그인 전 비연결 상태·Player 플래그와 로그인 뒤 현재 Subscriber·Player를 확인했다. 사제의 요청 전 경로 부재, Pump 뒤 실제 경로 생성, SP 보존과 삭제/장부 깊이 0, 중복 로그인 거부도 확인했다. 첫 전체 회귀가 통과한 뒤 Subscriber·초기 플래그 단언을 보강해 집중 검사와 전체 회귀를 최종 코드로 다시 실행했다. 집중 검사 1건이 통과했다. 이 단위는 검사와 인수인계만 변경하며 게임 창·포획·희생·특정 적 공격·승리·세 공중 유닛 전용 행동은 실행하지 않았다.

다른 운반 유닛·실제 선택 UI, 워크샾 자연 완공·생산, 미션 프레임과 브라우저 앱 수명은 여전히 남는다. 기준 `225553df` 이후 `CampaignSessionTests.cpp`의 변경은 해당 검사 밖이다.

Node v26.13.0 전체 회귀 6,260건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 오류는 0건이며 E761의 Node v22 전체 검사 뒤 첫 번째 v26 전체 회귀다.
