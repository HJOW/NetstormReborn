# Fort 현재 이름의 원본 관측 전체 대조 (WB04-E892, 2026-11-19)

기준선 `225553df`의 `RawFortCurrentName`과 현행 소스·cpppj 검사 본체의 변경 이력이 없음을 확인했다. 보호된 10.78 x86 fixture 876행을 입력으로 실행하는 웹 검사 장치를 작성했다. manager 없는 기존 60행뿐 아니라 manager setter, 경로와 이름의 255/256바이트 경계, 자기 참조, 소유자·현재 이름·설정의 콜백 중 교체, 진단과 외부 효과 중단을 포함한다. 각 행의 완료 또는 중단, 12개 전역, 헤더·두 manager·두 이름·입력·설정·scratch 전체 바이트 및 콜백 순서를 직접 비교하고 156건의 중단과 중복 없는 876행을 확인한다. 실제 파일 삭제는 하지 않는다.

관측에 사용한 경로 비교는 원본 C 로케일에 맞춰 ASCII 대문자만 접는다. 원본 fixture는 변경하지 않았으며 fixture 목록에 새 소비자를 등록했다. 실제 Client Snapshot/Notify와 앱 미션 수명은 이 단위에서 연결하지 않았으므로 상위 4D-3a는 계속 미완료다.

Node v26.13.0과 v22.23.3의 집중·연관 검사 각 4건이 통과했다. fixture 831항목의 해시 불일치·누락은 0건이다. 전체 회귀는 정해진 주기상 다음 단위에서 Node v26으로 실행한다.
