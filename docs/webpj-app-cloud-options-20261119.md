# WB04-E906: 앱 설정과 구름 전역

cpppj `ClientMain.cpp`의 설정 해석과 설정 변경 콜백은 같은 Client의 `ClientKencloudGlobals::ReadOptions`를 호출한다. 웹 앱은 GameData가 준비되면 구름 옵션을 읽고, Config 쓰기·사용자 설정 변경·재시작 설정 동기화 뒤에도 같은 장기 구름 전역을 갱신한다. 설정이나 Client가 아직 없으면 건너뛰고 실제 자산 적재 시 반영한다. 읽기는 기존 `readOptions`의 찾은 값만 변경하는 계약과 DWORD 변환을 사용한다.

현재 웹은 원본과 달리 월드 장기 저장소를 만든 뒤 최초 구름 옵션을 읽는다. 구름 생성·표시·전투 팔레트 전환과 전체 설정 해석 순서는 이 단위의 범위가 아니다. 기존 GameData의 콜백 예외 처리와 silent 쓰기 규칙은 그대로이다.

실제 setup·TAFF로 최초 옵션과 이후 일반 설정 및 진행 값 쓰기를 검사하고, 부호 있는 값의 DWORD 변환과 난수·구름 할당 불변을 확인했다. 구름 전역·진행 저장·언어 및 오류 처리 연관 Node 검사 53건과 Chromium 실제 설정 쓰기 1건이 통과했다.
