# WB04-E795 캠페인 World 선택·강조·운반 입력

`GameWorldInput.inc`의 생성자·BindUserInput과 선택 초기화/해제·강조를 캠페인 World에 부분 연결했다. 실제 Session의 운반 입력과 선택 처리기는 같은 Client 선택 전역을 빌린다. 강조의 화면 좌표는 현재 카메라 snapshot과 원본 `RawCursorPosition.screenToWorld`로 역투영하고, 같은 운반체 처리기에 전달한다. 미니맵 이동은 현재 선택에 대한 실제 명령 뒤 강조를 해제한다. 객체 메뉴와 마우스 커서 갱신, 브라우저 UI·프레임 연결은 남는다.

TheWarBegins 실제 로컬 로그인에서 사제 선택이 강조 모드 5와 실제 현재 카메라의 운반 커서 평가로 이어지고, 미니맵 이동 요청이 선택·강조를 해제하며 내부 40h 이동 패킷을 보내는 것을 확인했다. 카메라 픽셀 적용은 명시된 독립 검사 장치이며 브라우저 Renderer가 아니다. 포획·희생·승패와 세 비행 유닛 전용 행동은 실행하지 않았다. 실제 미션 플레이와 전체 입력 조립은 아직 미완료다.

검증: Node v26.13.0 및 v22.23.3 전체 각각 6,294건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 두 버전은 순차 실행했으며 이후 v26 전체 검사 0/8회다.

후속 E796에서 객체 메뉴와 이동 커서 갱신을 연결하여 GameWorldInput 이식을 마쳤다([단위 문서](webpj-campaign-game-world-menu-cursor-20261118.md)). 브라우저 앱 연결은 계속 남는다.
