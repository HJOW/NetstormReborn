# dotnetpj 1.062 — R5-1 제품 카메라 프레임 적용

2026-11-26, HJOW-Athlon. R5 월드 화면 묶음의 첫 조각이다. 매 프레임 실제 지도 영역으로
카메라 목표·현재값을 적용하도록 제품 루프에 이었다. 뒤집기는 매 프레임 출력에 맡기며
월드 그리기는 R5 본편에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Game/ClientHostGame.Camera.cs`: 신규. `BindMissionCameraDevices`가
  세션 카메라 장치를 실제 화면 이동·dirty·다시 그리기에 연결하고, `ApplyMissionCameraFrame`이
  실제 지도 영역 전역으로 Present→Commit을 적용한다. 근거: cpppj `UberGumpCamera.cpp`의
  `CommitCameraNow`·`ApplyCameraFrame` 결선이다. 전체 viewport 대체 없이 실제 지도 영역을
  쓰며 바뀐 view에서만 다시 합성한다. 1.062에서 추가했다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 미션 시작에 카메라 장치를 설치하고 매
  프레임 미션 프레임 뒤에 카메라 프레임을 적용한다. 영상 갱신 잠금 중에는 건너뛴다. 1.062에서
  수정했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostCameraFrameTests.cs`: 신규 3건. 지도 영역
  전역의 Present→Commit 순서·노출 띠·픽셀·다시 그리기, 미설정 거부, 정지 프레임의 변경
  없음을 대조한다. 1.062에서 추가됐다.
