# 웹 미션 커서 자산 (WB04-E1007)

원본 실행 파일에서 기존에 추출한 커서 18종을 웹 메뉴 자산 묶음에 포함하고 원본 번호와 파일의 대응을 연결했다. 미션 커서 장치가 선택한 배치·이동 등의 번호가 더 이상 기본 화살표로 대체되지 않는다. 원본 파일은 변경하지 않았다.

18종의 실제 파일과 핫스폿·매니페스트를 원본 목록과 비교한 커서 및 자산 Node 검사 17건, 자산 복사본 검사, Chromium의 실제 Q 다리 취득 중 배치 커서와 미리보기 표시 검사가 통과했다. 브라우저는 화면 반전 커서 픽셀을 완전히 표현할 수 없지만 현재 포함된 18종의 반전 픽셀은 모두 0이다.
