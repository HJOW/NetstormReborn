# dotnetpj 1.095 — 세션 자원 삭제의 실제 가상 분배

2026-11-27, HJOW-Athlon. `HostSession.DestroyResourceObject`의 미연결 예외를 제거하고, cpppj의 `world.Destroy`에 대응하는 이미 설치된 같은 세션의 전체 가상 삭제 분배에 반환값을 보존해 연결했다. 설치 전과 미지원 가상표는 기존 분배의 명시 실패를 그대로 유지한다.

- 실제 같은 세션의 Process Form을 일반 월드 삭제와 자원 삭제로 각각 처리하고 가상 소멸·SID 반납, 설치 전 거부 및 미지원 가상표 거부를 확인했다. 관련 Client 검사 8/8 통과, 검사와 게임 Core/Client/Game DLL 해시 일치.
- Game Release 빌드 성공, `cpp_sync.py` 종료 0. 대표 세 미션 CPP/DN 각각 종료 0, DN 90프레임 덤프는 0998과 바이트 일치, 원본 1,392파일은 세 감사에서 불변이다. 기존 CPP-DN 상태 차이로 비교 도구 종료 1. 결과 `extracted/dotnet-l2-1095-resource-delete/`.

세션 삭제 분배에 GumpForm을 실제 등록하고 통지·중첩 삭제를 검증하는 작업은 남았다. 실제 생산 Form 생성·부착과 인벤토리 내용물·유지·입력, 전체 UberRoot 및 L4a 일치는 미완료다. 이번 검사는 전투 중 자원 삭제나 플레이 결과를 재현하지 않았다.
