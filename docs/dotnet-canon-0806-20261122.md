2026-11-22 · HJOW-Athlon · 제품11.01 · .NET10 Release. 전체 목표와 M1은 미완료다.

## 구현

`RawDeveloperCommandPacket`과 `DeveloperCommandRegistration`에31h의 실제 송수신을 이식했다. 송신만 len=-1을74b에서 진단하며 복귀 뒤 현재 DWORD+8의 하위WORD를 기록한다. 수신은 sender와 선언DWORD를 읽지 않고 +8의 첫NUL 전 실제 물리 구간을 빌린다. version1/정책0/가변길이ffff와 같은 단일 분배기를 사용한다.

`HostSession.DeveloperCommand.cs`는 Source `RawCampaignSession.cpp`5042~5156의 전체 분기를 실행한다. 같은 MissionSettings·QuickBuild/Vortex·Player·Subscriber·공장·Owner·공간·HP·TYPE/SHP·graph·게임시각·다리 스캔·CRT를 사용한다. 실제 외부 화면/설정/기록/가상 피해와 삭제는 선택된 위치에서만 요구한다. 첫 토큰255BYTE·ASCII 소문자, 나쁜 입력의 두 구두점, 기본값, 실제 빈rtt와 존재하지 않는dt/css 별칭, PATCH의 같은 setally/clrally 동작도 보존한다. 도움말32문자열 전체를 Source에 대조했다.

누락된 `RawBoardTarget`의 Side/Nearest와 장기 scatter 행3·combat 사건02000065를 추가했다. Subscriber ref 쓰기는 같은 장기 DWORD에 즉시 공개하며 기존 변경/등록/Template 실제 stream writer와 Notify를 연결한다. 같은 고정44dba0 entry가 전체 실행기를 직접 호출한다. 현재 고정 본문은 **17/26**, 나머지는35/38/39/3a/3b/3c/73/74/86의9개다.

## 검증과 한계

- Windows UCRT의 실제 scanf/printf를 제품 파서와 독립적으로 호출한 **434입력**을 별도 관리 fixture로 저장했다. 원본 PE 관측으로 집계하지 않는다. signed64 포화 뒤 정수 하위DWORD, float32 전체 비트, 16진 최근접 짝수 반올림·서브노멀·불완전 지수·NaN 부호/ind/snan, float 승격 뒤6자리 출력이 전수 일치한다. printf 열을 추가할 때 기존434변환 열이 불변임도 확인했다.
- 신규 Core9·Client27건을 포함해 최종 **Core 집중30건·Client 집중115건 통과**, 실패0. 제품 빌드 오류0·제품 경고0이며 기존 테스트 경고는 유지했다.
- 실제 단일 Net 기록→깊이→수신 순서, 고정F, 장기 설정/수명, Source32도움말/외부 서비스, 현재 로그 뒤 Player·TYPE·그림·다리 시각 재조회, Subscriber 실제 stream/ID/Notify, 방향별 동맹, 실제 Owner/HP/공간, 고갈된 간헐천 생성과10열 scatter/같은CRT를 확인했다.
- Dude의 전용 PostPop, 사제 보호막 음향과 낙하 위치 음향은 기존 미연결이다. 신규 검사는 이 실제 경계와 앞선 생성/좌표/owner/목록/부분 효과를 보존한다. 명시 음향 할당 실패 입력으로 그 뒤 낙하 경계도 구별했으며, gp의 마지막 전체 피해까지 실행됐다고 주장하지 않는다. 실제 ad는 같은 전체 가상 피해 서비스의 인자를 검증했고 HP setter로 대체하지 않았다.
- 초회 검사에는 기록 깊이 순서와 Template 미션/메모리 상태, 사제의 적재깊이별 Owner 계약, Dude 후처리, 보호막/낙하 음향 경계 및 검사에서 확장한 frame 코드와 실제 그림 수의 차이를 잘못 기대한 실패가 있었다. Source를 대조해 장면을 교정하고 미연결은 별도 실패 경계 검사로 보존했다. 기존 fixture와 제품 결과를 맞추려고 기대값을 갱신하지 않았다. 초기 로그/TRX를 유지한다.
- 같은 최종 빌드의 대표3시작은 모두 종료0이고 전체 덤프/지표가0.804와 같다. 검사 Client DLL과 실행본이 같으며 실행6파일·원본1,392파일의 전후 해시가 같고 원본 전체 해시는0.804와도 같다. 금지된 포획/희생·특정적공격·승리 GUI 재현은 수행하지 않았다.
