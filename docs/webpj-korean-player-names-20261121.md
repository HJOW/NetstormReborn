# 한국어 Player 이름이 깨지던 Players 메뉴 수정 (WB04-E1166)

LEFT_JOBS 한국어 항목의 "실제 화면 확인"을 한국어 미션을 직접 플레이하며 점검하다가 발견했다. 번역 누락 문자열 수집과 화면 확인으로 한국어 게임 메뉴·객체 메뉴·F9 목록을 훑었다.

## 점검 방법과 결과

- 한국어 The War Begins!(언어 2)를 시작해 번역표(`resources.translate`)를 감싸 번역되지 않은 영문을 수집하면서 게임 메뉴 막대(Game·View·Options·Players·About)의 모든 상위 메뉴와 하위 메뉴를 펼치고, 모든 객체 종류를 우클릭하고, F6 지식 창을 열었다. **번역 누락 문자열은 없었다**(메뉴 항목 라벨이 모두 한국어: `미션 목표 보기 - F8`·`전체 화면 가장자리 스크롤`·`조각 반시계 방향 회전 - C`·`난이도 ▸ 쉬움/보통/어려움` 등).
- 화면을 보니 **Players 메뉴 행이 깨져** 있었다(`당신`·`간수` 대신 모양이 어긋난 글자). 영어 모드는 `You >`·`The Jailer >` 로 정상이다.

## 원인과 수정

- Player 이름은 Player 기록(+0x0c, 최대 32바이트)에 **표시 부호화 바이트**로 저장된다. 한국어·일본어 확장 문자는 선두 `0x1f` 와 25진 숫자 세 개의 4바이트 시퀀스이다(`assets/display-text.js`, 예: 한국어 `간수` = `1f 01 01 05 1f 0c 02 07`).
- 게임 메뉴 막대의 Players 행(`ui/raw-game-menus.js` `players()`)은 이 바이트를 `String.fromCharCode` 로 그대로 문자열로 만들어 메뉴 라벨로 썼다. 영어 이름(ASCII)은 우연히 같아 문제가 없었고 한국어 이름은 제어 문자가 섞인 라벨이 되어 깨졌다. F9 플레이어 목록도 같은 함수를 쓴다.
- 수정: 선택 훅 `decodeName(bytes)` 를 더했다(`ui/raw-game-menus.js`·`ui/client-game-menu-bar.js` 의 두 조립 위치). 앱(`netstorm.js`)은 `displayTextCodec.decode` 를 넘긴다. 훅이 없으면 기존 동작이다.
- 확인: Players 메뉴는 `당신 >`·`간수 >`, F9 목록은 `플레이어 목록 / 당신 > / 간수 >`, 적 사제 우클릭 메뉴는 `사제 레벨 1 / 적: 간수 / 속성: 없음 / 분류: 사제 / 정보 / 플레이어 >` 로 나온다.

## 시험

- `e2e/korean-players-menu.spec.js`: 한국어 The War Begins! 의 Players 하위 메뉴 행에 제어 문자가 없고 AI 이름 `간수` 행이 있다. 앱에서 `decodeName` 을 빼면 `행 글자` 단계에서 실패한다. 관련 Node 시험(게임 메뉴·메뉴 막대 5건)도 통과한다.

## 남은 것

- 번역 누락 수집은 메뉴·객체 우클릭·지식 창 범위이다. 생산 창 도움말·미니맵 도움말·채팅 채널 이름(LEFT_JOBS 한국어 항목에 이미 적힌 "번역 호출이 없는 고정 영어")은 이 방법으로는 잡히지 않는다(번역 호출 자체가 없다).
