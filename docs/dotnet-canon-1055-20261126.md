# dotnetpj 1.055 — SL-3b 에너지 세션 조립

2026-11-26, HJOW-Athlon. SL-3의 두 번째 조각이다. 배치 에너지 본체의 세션 조립을 이었다.
공급 목록·동맹·반경은 실제 세션 값을 빌리며 요구 문자열 원천은 호출자가 공급한다. 배치·AI
호출자 결선은 R6에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Host/HostSession.Energy.cs`: 신규. `BuildEnergyDevices`가
  같은 세션 풀·공급 목록·동맹·월드 경계·치트 값으로 에너지 본체를 조립한다. 근거: cpppj
  `RawCampaignSession.cpp` 1322행의 energySupply 조립이다. 선택 30칸은 세션이 소유하고
  userCheat은 조립 시 같은 게임 값을 복사한다. 요구 문자열 원천(TYPE+a0 보호 AST)은 R6
  배치·AI 호출자에서 잇는다. 1.055에서 추가했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostEnergySessionTests.cs`: 신규 3건. 조립의
  동일 세션 결속·중복 거부·초기값, 주입 요구 문자열의 수집·평가·소비·정렬 실행, 우회 시
  수집 생략을 대조한다. 1.055에서 추가됐다.
