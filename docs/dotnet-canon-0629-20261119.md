- 일시: 2026-11-19, HJOW-Athlon
- 범위: 세션 정기 분배 결선(`PlayerProcesses` 처리기 사슬에 공장 분기 설치)과 프레임 틱(`ProcessTime` 전진+`Kernel.RunFrame()`을 매 프레임 실행) 연결, `guardmyback` L2 재수집. 사제 포획·희생·승리 재현은 사용자 확인 범위라 건드리지 않는다.
- 목표: 0.627에서 특정한 DN 공장 프레임 전건 0·정기 미발화 격차를 실제 실행에서 닫는다. cpp 오라클은 `RawSurfaceStorage::FactoryRegular`(27~36행: 레벨/첫프레임·개수·난수·지정·진행·큰효과·피해분배)와 세션 분배다.

## 이식 (증거)

- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`: `BuildFactoryPostPopDevices` 끝에 `_beforeFactoryRegular` 포착과 `RegularHandlerWithFactory` 설치. 공장 가상표면 `RunFactoryRegularSession`으로 분배하고 나머지는 이전 처리기(없으면 payload)로 넘긴다. 사제 월드는 이 사슬을 이전 처리기로 감싸므로 두 순서가 합성된다.
- `RunFactoryRegularSession`: `Level`=슬롯 상태 상위 3비트, `FirstFrame`/`FrameCount`=`WorldFrames` 현재 글자 구간(0~15 범위 검사, cpp `CurrentFactoryRun` 대응), `Random`=세션 `Game`(0범위는 선행 `Next(1)` 후 명시 예외), `Frame`=`_terrainFrames.Set`, `Advance`=`RawFrameAdvance.Advance`, `Begin`/`Finish`/`Flare`=R6 명시 예외, `Damageable`=이전 사슬 폴백이다.
- `dotnetpj/src/Netstorm.Client/Host/HostSession.PlayerWorld.cs`: `AdvanceMissionFrame(double)` 추가(`ProcessTime` 전진 후 `Kernel.RunFrame()` 1회). 메뉴에는 미션 세션이 없어 닿지 않는다.
- `dotnetpj/src/Netstorm.Client.Host/ClientHostGame.cs`: `Update`에서 미션 세션이 있을 때 매 프레임 틱 호출(고정 모드는 `FixedFrameMs/1000`, 아니면 `ElapsedGameTime`).

- `factory.PostPop(1)`을 공간 미등록 슬롯에 직접 부르면 `AdjustFrame→Set→Pop→Activate→PostPopVirtual→Dispatch→factory.PostPop`으로 재진입하고, `RawSquidPopParent` 198행의 첫Pop 정규화가 bit0을 세워 예약을 한 번 더 붙인다(커널 4건 관측).
