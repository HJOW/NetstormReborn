# WB04-E939: Client TextEntry 실제 글꼴 측정

`RawTextEntryControls` 기준선 `225553df`의 실제 GumpText·현재 TextEntry 문맥을 편집기 측정 경계에 연결했다. 호출자가 `FontSet`을 공급하면 원본 비트맵 캐시의 폭을 사용한다. 네 바이트 확장 문자는 표시 부호화를 해독해 유니코드 글꼴로 측정하고, 혼합 문자열의 1252 구간은 원본 글꼴로 측정해 선택 앞·뒤 폭이 일치하게 합산한다. 그림자 여백은 전체 측정에 한 번만 적용한다. 기존 명시 측정 장치도 계속 사용할 수 있다.

배포된 원본 Arial 비트맵 캐시를 실제로 읽어 측정하고, 시험용 유니코드 래스터라이저로 혼합 문자·부분 바이트 길이·그림자를 검사했다. 실제 TextEntry의 Slider 페이지 계산도 원본 글꼴 폭과 대조했다. 원본 10.78 편집 관측 2,292행 포함 연관 Node 검사 72건과 Node v22.23.3 전체 회귀 6,511건이 통과했다(실패·취소·건너뜀 0).

실제 앱 FontSet 전달, 갈무리11 래스터라이저와 픽셀 출력 및 실제 OS IME는 아직 통합 검증하지 않았다.
