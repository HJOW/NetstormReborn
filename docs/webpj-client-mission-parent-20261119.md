# WB04-E840 Client 미션 State7 부모

기준선 `225553df`의 `RunCampaignMissionStarting`을 실제 Client의 LocalState, 게임 전역, 표면 저장소와 시계에 연결했다. 상태 7의 몸체가 끝난 뒤 즉시 상태 8이 예약된 경우 원본 순서대로 상태 블록을 옮기고 내부 연결을 호출한다. 몸체와 연결이 각각 실패할 때도 이미 반영된 상태와 아직 옮기지 않은 상태를 따로 확인했다.

실제 미션 요청과 장기 Client 전역을 이용해 상태 7 몸체에서 `CampaignGameWorld`를 만들고, 상태 8 부모의 연결을 통해 실제 Session 내부 로그인과 준비 완료까지 진행했다. 상태 전환 전후의 독립된 상태 블록과 요청 소비, 팔레트·진행 안내·모드 관측 및 종료 시 저장소 반납을 확인했다. 첫 통합 검사에서는 Zone 사용자 번호와 연결 요청 번호가 달라 로그인이 거부됐으며, 두 번호를 실제 요청에 맞춘 뒤 통과했다.

이 검사의 화면 및 음향 장치 효과는 관측용 연결이다. 브라우저 앱의 실제 Client 소유·진행 창·HUD 수명, 다른 상태 전이 및 스커미시 준비는 아직 남았다. 원본 게임 창은 실행하지 않았다.

검증: 부모 집중 검사 2건, 실제 GameWorld 로그인 통합 1건, Node v26.13.0 전체 6,341건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E835의 Node v22 전체 검사 뒤 v26 회귀 5/8회다.
