# 1.201 음악 채널 제어와 읽기

`SoundMusic.cpp/.h`의 채널 저장소96BYTE·Active·SetVolume·Close·Stop·Rewind·Read·Start를 이식했다. +14/+3a 패딩과 다른 필드를 보존하고 OS 핸들과 CLR 재귀 잠금을 원시 배열 밖에 둔다. 같은 채널은 실제 파일/버퍼 장치를 값 복사해 빌리며 nested Stop/Release/Close와 실패 뒤 부분 출력·닫힌 토큰·선행 위치 쓰기를 원문 순서로 남긴다. 되감기 실패를 무시하고 다음 읽기로 진행하는 원문 분기도 보존했다.

원문 `musiccontrol-x86.tsv` **5,292행(10.78 1,780·CD1,756·10.37 1,756)**의 전체96BYTE·출력128BYTE·Adler·파일 위치·열림·볼륨 전역5개·잠금/장치 사건 순서를 전수 대조했다. 실제 채널 메서드를 묶은 읽기/정지 순서, SceneMusic과 같은+18 double 배치, IO 예외 뒤 실제 잠금 반납을 포함해 새 검사 **6/6 통과**다. 기존 음소거5·선택13·효과음10·목록4와 합친 관련 **38/38 통과**이며 `extracted/dotnet-1200-tests/focus.trx`에서 확인할 수 있다.
