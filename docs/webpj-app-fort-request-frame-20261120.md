# WB04-E968 앱 프레임의 최초 미션 Fort 요청

메인 메뉴에서 현재 Guide의 Fort 요청이 대기하고 기존 World가 없으면 앱 프레임이 효과음 준비를 시작한다. 준비 중에는 요청을 보존하며 완료 후 다음 프레임에서 Poll 전 동일 요청만 꺼내 현재 논리 화면 크기의 State7·State8 로컬 접속으로 넘긴다. 오디오 미지원은 비활성 재생기로 계속하고, 현재 요청의 음향 적재 실패는 원래 오류를 콘솔과 오류 화면에 남긴다. 취소·Guide 교체·앱 세대 변경 뒤의 오래된 실패는 화면에 적용하지 않는다.

검증: 실제 Tutorial1 Guide의 BridgeTheGap 요청을 앱 프레임에서 음향 적재 대기 → State7 → 로컬 로그인 준비 완료까지 처리했다. 실패·취소·동시 준비·기존 World 대기 보존, 기존 Poll/패킷 순서와 원본 효과음 프레임을 포함한 Node 13건 통과. 실제 로그인 검사에서는 작은 원본 효과음 목록과 관찰용 Web Audio를 사용했다. 전체 218개 해독은 E964 근거다.

범위: 기존 World가 있을 때는 아직 새 Fort 요청을 소비하지 않고 기존 Poll·패킷 처리만 진행한다. World 정리·교체는 후속 작업이다. 메뉴의 `MissionBegin`/`StartDemo`에서 Guide를 시작하는 분기, Guide 단계 3의 실제 World Start, 로그인 완료 후 HUD/월드 표시와 입력·게임 프레임은 아직 연결하지 않았다. 따라서 브라우저의 완전한 미션 플레이는 미완성이다.
