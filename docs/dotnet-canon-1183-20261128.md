# 1.183 실제 SP 표시 재부착

원본 `0043dad0`과 `00464020`의 SP 표시 갱신을 이식했다. 공통 등록표 1~999에서 요청 serial과 일치하는 첫 생존 노드를 찾고, 실제 Push 뒤 현재 좌표로 가상 Attach한 다음 정상 복귀에서만 기존 깊이를 복원한다. 대상이 없으면 가상 장치를 요구하지 않으며 실패 전의 실제 효과를 유지한다. 제품의 장기 Reward 장치에서 무조건 예외를 내던 SP 표시 콜백을 같은 현재 메뉴·생산 전역·실제 트리의 이 본체로 연결했다.

독립 원본 `budget-refresh-x86.tsv`의 **120행** 전체 노드/등록표/호출 및 48개 중단을 대조했고, 실제 생산 패널 예산 창의 부모·깊이·좌표를 확인했다. 관련 상태 정리와 패널 포함 집중 검사 **18/18 통과**, Release 빌드 오류0, `cpp_sync.py` 종료0이다. 원본 비교 자료는 테스트 출력에 별도로 복사한다.

제품의 `thewarbegins`·`tutorial1`·`surrounded` 진입/대기는 모두 종료0이며 90프레임 DN 덤프가 1.175와 같다. 1-1의 30·40·45·50·60·70프레임 화면은 1.177과 픽셀 단위로 같고, 원본 1,392파일은 전후 불변이다. 자료는 `extracted/dotnet-sp-refresh-1183/`에 있다. 이 경로는 완전한 State 정리 전환과 실제 게임 자금 변동 입력의 종단 검증을 대신하지 않는다.
