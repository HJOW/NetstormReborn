# WB04-E832 Session 생산 유지 연결

기준선 `225553df`의 `RawCampaignSession::MakeProductionMaintenance`와 `ProductionFinder`를 같은 Session의 실제 풀·내용물 검색기·Player 기록·기술 부모·Deck·SP·난수·시계·설정·생성/삭제에 연결했다. 생산 패널 전역·패널·벽시각·표시 갱신 장치는 호출자가 제공한다. JS에서 Session을 반납한 뒤 늦게 호출하는 콜백은 명시적으로 거부한다.

E830의 1-1 내부 Login·Start·워크샾 건설·연구 뒤 실제 기술 부모의 다리 수를 읽고 생산 슬롯 한 칸을 허용했다. 같은 Session의 내용물 생성이 지정된 조각을 추가하고, 실제 SP 2,200 및 생산과 다리 표시 갱신 순서를 관찰했다. 가득 찬 슬롯의 중복 공급을 막고, challenge 모드에서는 갱신을 멈추며 복귀 후 바뀐 SP 2,100을 다시 읽는지 확인했다. 미적재와 Session 반납 관문도 별도로 검사했다. 첫 기대값은 다리 갱신만 예상했으나 원본 비용 판정에 따른 생산 표시 갱신도 먼저 발생해 실제 순서 `[1, 2]`로 바로잡았다.

이 검사는 명시적으로 생산 유지 본체를 호출한다. 실제 HUD의 주기적 호출·브라우저 화면·사용자 입력과 유닛 생산의 전체 수명은 아직 연결하거나 검증하지 않았다. 원본 게임 창은 실행하지 않았다.

검증: 집중 통합 2건과 Node v26.13.0 전체 6,326건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E827의 Node v22 전체 검사 뒤 v26 회귀 5/8회다.
