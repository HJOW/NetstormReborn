# 0.741 실제 Template와 Player State의 Session 공유

Session의 독립 180바이트 헤더를 없애고 실제 CampaignTemplateStorage의 동일 배열을 빌리도록 바꿨다. 제품 호스트는 0.739의 장기 ClientStateResources.Templates를 넘긴다. 독립 조합만 Session 수명의 실제 저장소를 만든다. 새 Session을 구성하거나 반납해도 외부의 현재 manager와 State를 암묵적으로 초기화하지 않는다. State 컨텍스트와 월드 로더의 +8 DWORD 쓰기도 이제 같은 헤더를 사용한다.

개발용 일반 미션은 최초 MissionFortSourceImage의 바이트·실제 파일 이름을 보존하여 manager1에 InstallFile한다. 요새를 두 번째로 읽지 않는다. Territory와 현재 Template의 조회도 이 저장소에 연결했다. Native 로그인 전체의 지연 파일 선택/수신 설치는 아직 후속이며, 이번 개발용 진입으로 완료 처리하지 않는다. 서버 목록 읽기는 원문의 SP 초기화 정상 복귀 뒤로 옮겨 잘못된 파일로 실패할 때의 선행 효과도 맞췄다.

기존 Player 정기는 State 대신 헤더의 첫 바이트에 4를 OR하고 있었다. 같은 manager의 실제 State getter/GetMemory·Notify를 사용하도록 교체했다. GetMemory는 기존 원문 getter의 동일 Memory를 반환하고 기존 Get API는 그 Span을 돌려준다. 실제 Runtime은 반환 메모리 쓰기부터 현재 Notify까지 pin한다. 반납된 Session의 이전 getter는 거부한다. Notify의 isMine 자연 반환과 선택된 실제 저장의 실패를 유지하며 정상 복귀 뒤에만 기존 변경 관측 기록을 남긴다. 실제 DataManager 저장 부모는 아직 제품에 연결되지 않아 그 분기가 선택되면 명시 오류다.

빈 State는 현재 호스트의 미초기화 할당 바이트를 받아 정의된 필드만 초기화하고 실제 섹션을 만든다. 짧은 State는 같은 저장소의 확장 부모를 사용한다. 기존 Player 기록의 Marshal 할당 입력 본체를 ClientAllocationBytes로 공유하고 Edit 목록에도 연결했다. 고정 검사는 알려진 바이트 공급자를 사용하며 미정 부분을 임의 0으로 바꾸지 않는다.

신규 6건 포함 집중 81건이 통과했다. 실제 State/manager 헤더 분리, 순차 Session의 같은 저장소 보존, 빈 State의 알려진 미정 바이트와 공급 실패 prefix, 짧은 State의 실제 확장, non-mine Notify의 미연결 저장 실패·정상 복귀를 검증했다. 기존 Template 저장소/파일/섹션, Player 기록, 미션 요새와 State 자원 검사도 포함했다. 기존 Player 사건2 검사는 실제 manager/State를 구성하고 헤더 불변을 단언하도록 고쳤다. 근거는 extracted/dotnet-0741/client-initial.log·client-initial.trx다. 이는 어댑터 단위 검사이며 독립 PE L1 수를 늘린 것으로 세지 않는다.

대표 thewarbegins/tutorial1/surrounded 시작은 모두 종료0,0.740 전체 덤프 바이트와 기존 지표가 같다. 원본 1392파일 SHA가 불변이며 포획/희생·특정 적 공격·승리를 재현하지 않았다. 근거는 extracted/dotnet-0741/capture.py·capture.log·capture-summary.json·capture-originals-audit.json·audit.py·final-audit.json이다.

PORT_MAP에는 확인한 RawCampaignSession.cpp/.h, CurrentAllocationBytes.h, MissionFortSource.h의 해당 연결 4행만 추가한다. 기존 fixture367개는 변경하지 않았다. RawPlayerTemplateState.cpp의 기존 L1 기준 이후 변경도 player-state-cpp-delta.diff로 검토했다. Get 본체는 같으며 Changed는 비Session 소비자를 위해 독립 Notify 함수로 추출된 차이다. 현재 클래스의 Changed 분기 의미는 같고 그 비Session 부모 이식은 후속이다. 파일 전체를 새 L1 기준으로 올리지 않았다.
