# WB04-E869 cpppj Tutorial1 덤프·화면 기준 자료

기준선 `225553df`의 cpppj 실행 파일을 HJOW-Athlon에서 `--mission Tutorial1`, 영어 1024×768, 고정 25ms, 새 사용자 데이터로 실행했다. 30·60프레임의 `Play Mission` 선택적 클릭 뒤 90프레임의 Session 덤프와 논리 화면, 130프레임의 덤프와 보고서를 `webpj/tests/fixtures/cpppj/candidate-225553df/tutorial1/`에 보관했다. 90·130프레임 모두 `world 1`, Kernel 6개이며 보고서는 Tutorial1 시작과 실제 월드를 가리킨다. 90프레임 화면에는 Tutorial 안내 창이 열린 상태다.

같은 조건으로 두 번 실행해 각 프레임의 덤프 행을 비교했다. 두 프레임 모두 `sp` 한 행만 달랐고 나머지는 일치했다. 원본처럼 초기화되지 않은 소유자 0의 SP 메모리가 달라질 수 있으므로 이 칸은 결정론 비교에서 따로 다룬다. 보관 자료는 두 번째 실행분이며 메타는 실행 파일·시나리오·덤프·화면·보고서의 해시를 기록한다.

시나리오에 `mission`을 설정하면 cpppj `--mission`으로 전달하며 이 설정을 수집 입력 해시에 포함한다. 자료·해시 집중 검사와 Node v26.13.0 전체 회귀 6,409건은 실패·취소·건너뜀 없이 통과했다. 이 자료는 cpppj 관측이다. 웹 미션 진입·같은 시각의 웹 Session 덤프·픽셀과 L2 대조는 아직 수행하지 않았다.
