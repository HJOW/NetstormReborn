# 생산 항목 장식의 출력 클립

WB04-E1029는 생산 항목 장식의 배경 장치에 현재 Gump 픽셀 표면과 클립을 함께 전달한다. 재진입과 예외 후에는 이전 표면과 클립을 복구한다. 기존에는 표면만 전달해 실제 ClientGumpBackground.texture에 필요한 클립이 빠져 있었다.

실제 Tutorial1의 생산 항목과 fortGump 자산을 사용해 장식을 켰을 때 픽셀이 출력되는 것을 확인했다. 생산 항목·자산·앱 관련 Node 검사 14건이 통과했다. 생산 패널의 화면 설치와 사용자 입력 검증은 남았다. E1026 고정 Node 26 전체 회귀는 실행 중이다.
