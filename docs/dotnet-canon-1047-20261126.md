2026-11-26, HJOW-Athlon. R4-6 표시·입력 묶음의 DI-4를 네 조각으로 나눈 첫 조각이다. 실제

- `dotnetpj/src/Netstorm.Client/Display/RawCameraCommit.cs`: 신규. Commit 본체의 상태·전역·
  갈고리와 `CommitCameraTarget`을 이식했다. 근거: cpppj `RawCameraCommit.cpp`의
  `CommitCameraTarget`(497960)이다. zoom 분기의 view·snapshot 칸 크기·float 비트 적용, 일반
  이동 분기의 화면 이동·시차 노출 띠·두 setter·dirty 이동/합침·노출 띠 추가·마우스 갱신,
  정지 분기의 조기 반환, IDIV 두 오류의 선택 위치 거부를 보존한다. dirty는 값 복사 없이 같은
  목록을 직접 갱신한다. 1.047에서 추가했다.
- `dotnetpj/tests/Netstorm.Client.Tests/CameraCommitTests.cs`: 신규 4건. 배율 분기의 양쪽
  칸 크기·float 비트·전체 다시 그리기, 이동 분기의 화면 이동·dirty 이동/합침·무시 항목

  다시 그리기 미변경, 시차 분모 0의 IDIV 오류 거부를 대조한다. 1.047에서 추가됐다.
