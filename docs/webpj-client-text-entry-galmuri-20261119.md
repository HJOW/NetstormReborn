# WB04-E941: Chromium 실제 갈무리11 편집 출력 검증

Chromium에서 배포된 갈무리11 보통·굵은 woff2를 FontFace로 등록하고 실제 Canvas 래스터라이저와 원본 Arial 비트맵 글꼴을 사용했다. 앱의 실제 Client Gump 루트에 TextEntry·두 Slider를 임시 생성하고 `A한글B` 확정 사건을 원본 입력 큐에 넣어 공통 입력으로 수동 전달한 뒤, 원본 바이트 인코딩 복호화와 Gump 8비트 표면의 글리프·배경·자식 반납을 확인했다. Chromium 검사 1건과 Node v26.13.0 전체 회귀 6,512건이 통과했다(실패·취소·건너뜀 0).

검사에서 큐 소비를 직접 호출하므로 실제 앱 프레임의 미션 입력 연결을 입증하지 않는다. 실제 OS 입력기 조합이나 미션 화면 표시는 검증하지 않았다.
