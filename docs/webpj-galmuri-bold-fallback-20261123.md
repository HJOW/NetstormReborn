# 굵은 갈무리11에 없는 글자의 일반 글리프 대체 (WB04-E1244)

E1241의 cpppj 1322 판정(`BitmapFont.cpp` ③)이 남긴 "굵은 글꼴에 없는 문자를 같은 갈무리11 일반 파일에서 찾는" 규칙을 웹 한국어 글자 출력에 반영했다. 큰 슬롯(제목) 크기·굵기 규칙은 사용자 결정 대기([다음 작업 1 ⑤](../LEFT_JOBS.webpj.md#next))라 건드리지 않았다.

## 원본 흐름

cpppj 1322의 `BitmapFont::ExtendedGlyph`는 굵은 글꼴 파일(`Galmuri11-Bold`)에서 글리프를 못 찾으면 같은 폴더의 일반 파일(`Galmuri11`)에서 찾고(`EmbeddedBitmapFont::Load(.../kKoreanFontRegularFile)`), 그래도 없으면 `nullptr`을 돌려 GDI의 다른 글꼴로 대체하지 않는다. 합성 굵기도 적용하지 않는다.

## 실측: 굵은 파일이 갖지 않는 글자

`fonts/Galmuri11Bitmap-Regular/Bold-2.40.4.ttf`의 `cmap`(형식 4·12)을 직접 읽어 비교했다. 일반 20,965자·굵은 12,695자로 **일반에는 있고 굵은 파일에는 없는 글자가 8,271자**다(굵은 쪽에만 있는 글자는 1자). 범위: 라틴 확장(U+0100~02AF·1E00~1EFF), 그리스(U+0384~03CF)·키릴(U+0400~04F9), 일반 구두점·수학·도형 기호, 가나(U+3041~30FE)·한글 호환 자모 U+3165~318E, 한자 대부분(U+4E00~) 등이다. 한글 음절 11,172자와 기본 라틴·라틴-1(U+0020~00FF 191자)·호환 자모 U+3131~3164 52자는 굵은 파일에도 모두 있고, 없는 쪽은 호환 자모 U+3165~318E 42자(기존 인계의 "옛 호환 자모 42자")·한자 U+4E00~9FFF 6,477자 전부·나머지 약 1,750자다.

## 웹 변경

- 이전: Canvas 글꼴 문자열이 `bold 11px "Galmuri11"` 하나라 굵은 face에 없는 글자는 브라우저가 시스템 글꼴로 대체하고 굵게 합성했다(실측: 같은 글자의 굵게·일반 글리프가 서로 달랐다 — 가나 일반 15,030 대 굵게 10,062 등).
- 이후: `platform/glyph-rasterizer.js`가 일반 파일을 보조 이름 `Galmuri11Regular`(weight `'100 900'`, 모든 굵기 범위라 합성 굵기가 없다)로 한 번 더 등록하고 굵은 글자만 `"Galmuri11", "Galmuri11Regular"` 목록으로 그린다. 보통 글자는 이전과 같은 `"Galmuri11"` 하나다. 정리(`dispose`)는 세 face를 모두 문서에서 뺀다.

## 시험

- `tests/korean.test.mjs`(래스터라이저 시험 갱신): 등록 face가 `[Galmuri11 400, Galmuri11 700, Galmuri11Regular '100 900']`(각 데이터 바이트·적재 확인)이고 굵게·기울임 글꼴 문자열이 `italic 700 13px "Galmuri11", "Galmuri11Regular"`, 보통은 `400 13px "Galmuri11"`임을 고정한다.
- `e2e/galmuri-bold-fallback.spec.js`(실제 Chromium·실제 WOFF2): 등록 이름 `['Galmuri11/400','Galmuri11/700','Galmuri11Regular/100 900']`, 굵은 파일에 없는 가나(あ)·그리스(α)·키릴(Ж)·호환 자모(U+3165)를 굵게 요청하면 일반 글리프와 모양·전진 폭·좌표가 완전히 같고(시스템 글꼴·합성 굵기 아님), 굵은 파일에 있는 한글(한)·라틴(A)은 일반과 다른 실제 굵은 글리프임을 확인한다. 구현을 되돌린 상태의 같은 비교는 네 글자 모두 달랐다(탐침 값: 가나 일반 15,030/굵게 10,062, 그리스 7,792/7,394, 키릴 11,937/13,385, 자모 8,278/6,467).

## 남은 일

- 큰 슬롯(제목) 글꼴 크기 규칙(정수 배율)·굵기 고정은 의도적 선택이라 사용자 결정이 필요하다(다음 작업 1 ⑤).
- 이 대체는 갈무리11 글꼴 경로(한국어)에만 적용된다. 일본어는 별도 글꼴(Noto Sans JP)을 쓰며 13차에서 다룬다.
- 시각 대조(원본 화면 대비 픽셀 비교)는 하지 않았다. 일반·굵은 글리프 동일성만 확인했다.
