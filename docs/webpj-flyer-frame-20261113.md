## 1. 규칙

- **구성:** `new RawFlyerFrame(pool, types, details, soundFrames, globals, hooks)` — 풀은 PATCH, TYPE 표(`{ footX, footY }`)·보충 표(`{ range, sound }`)는 188칸이며 **만들 때 사본**을 보관한다. `soundFrames`(길이 188)는 호출자와 공유하는 타입별 마지막 소리 재생 프레임 장부이다. 전역 열 개(`server`·`boss`·`checking`·`now`·`frame`·`sunType`·`windType`·`rainType`·`sunAviaryProcess`·`soundProcess`)는 현재 값을 읽는 함수이고, 훅 36개는 원문의 큰 하위 함수와 가상 호출이다. 선택하지 않은 경계는 요구하지 않고 선택된 누락은 앞선 쓰기를 남긴 채 거부한다.
- **`initialize(fields, rain)` (0045bf00/0045b800):** 맨 오 워면 수명 타이머 104 = now + 60. 이어서 공격(80)·착륙(88) 0, 초기화 표식(84) 1, 최초 20초 타이머(72) = now + 20(타이머 64 와 구별).
- **`frame(fields)` (0045d630):** 맨 오 워 표(0x509f60)이면 초기화 전 `initialize(true)`, **boss 일 때만** 부모 정지(+40 의 0x20)이거나 수명이 지났으면 부모 삭제 0x200000 후 반환(server 가 아니어도 boss 이면 삭제). 그다음 `baseFrame`.
- **`baseFrame(fields)` (0045c9d0):** 초기화(전용 훨리기그 표는 `sunInitialize`) → 부모 dead/free면 반환 → (진단) 강건성 0x42c·홈 0x431·부모 0x434 → 부모 +40 의 비트 1 반환·비트 0x20 이면 boss 삭제 → 경과 시간 `now − 마지막 갱신`이 양수일 때: 위치 검사 0x447, **서버의 귀환 기한**(훨리기그 타입 확인 0x44b·표적 의존 해제·홈 검사 실패 시 종료 반환·표적을 홈으로·귀환 명령 3), 표적이 없거나 비트 1 이면 부모 위치 유지, 아니면 표적 중심(발자국 절반 차)에 오프셋 벡터·포위 벡터를 **각각 float 로 저장**하며 더하고 1..255 로 자른 뒤 이동 비율 `min(1, 속도 / max(거리, 0.0001f) × float(경과))`로 두 축을 각각 float 로 이동한다. 거리 ≥ 반경이면 시각 갱신·(공격 중이면 통지 1·공격 해제·맨 오 워는 소리 제거), 사거리 안의 다른 표적이면 공격 시작(통지 1, 1)·공격 중엔 `hit`(더스트 데빌 제외), 홈이면 거리 < 1 일 때 서버가 **착륙/재출격**(`returnHome`). 이어서 프레임(맨 오 워 `rainFrame`, 그 밖 `otherFrame`)을 정하고 위치가 유효하며 좌표나 프레임이 바뀌었으면 Unpop → 프레임 쓰기 → Pop(0x40) → 정수 칸이 바뀌면 `movedCell`. 마지막으로 dirty |= 0x40·마지막 갱신 = now, **서버만** 표적 유지(종속 진단 0x4f3·발사 가능·가까운 비행체 수 < 표적당 자리 또는 홈이면 사거리 안일 때 유지, 아니면 `clearTarget`) 또는 5초마다 표적 찾기.
- **`returnHome`(내부):** 홈의 부모 WORD 가 이 비행체의 부모가 아니면 `finish` 후 전체 Frame 반환(false). 아니면 훨리베이스를 조회해, 착륙 전이면 착륙 1·훨리베이스 상태 9·dirty |= 4·갱신 후 홈 Unpop → 직접 프레임 27 → Repop 하고 계속, 훨리베이스 상태가 9 면 그대로 계속, 아니면 표적 해제(의존 해제·dirty |= 4·표적 0)·귀환 기한 = 지연 + now·갱신·명령 2·착륙 0.
- **`rainFrame(fields)` (0045bf50):** 0.1초(배정도 0.10000000149011612) 애니메이션 타이머, 프레임 6·표적·공격 중이면 발사 뒤 타입별 마지막 재생 프레임이 현재 프레임과 다를 때만 소리를 요청하고 장부를 갱신한다. 다음 프레임 = `(프레임 + 1) % runCount`(부호 있는 나머지, 0 나눗셈과 INT_MIN / −1 은 거부, JS 의 −0 은 0 으로 정규화).
- **`clearTarget` / `notify` / `baseNotify` / `parentDying` / `checkForms`:** 표적 해제(boss 가 아니면 진단 0x2ac)·통지(전용 훨리기그 표는 `sunNotify` 로 먼저 분배, 공통은 메시지 2·서버만 표적 해제, 표적 불일치 0x2ba)·홈 통지(더스트 데빌과 0/ffff/범위 밖 홈은 생략, 살아 있는 홈만 가상 34(0, 0))·종속 검사(004ad730 은 `checkRawObjectForms`).
