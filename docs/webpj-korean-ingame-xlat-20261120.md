# 한국어 게임 안 메뉴·상태 안내 번역 (WB04-E1118)

미션 화면의 ESC 메뉴 막대, Game·View·Options 항목, Players 목록 제목, 오른쪽 위 상태 안내, 미션 시작 진행 창이 한국어 모드에서도 영어로 남아 있었다. 코드는 이 문구를 모두 `translate(원문)` 으로 번역표에 묻는데, `webpj/translations/xlat.korean` 에 원문이 없어 영어 그대로 돌아왔다. 이 단위는 번역표에 200개 항목을 더하고, 코드가 실제로 요청하는 원문이 모두 번역되는지 확인하는 시험을 추가했다.

## 번역 항목

| 영역 | 원문 → 한국어 |
| --- | --- |
| 막대 라벨 | Game → 게임, View → 보기, Players → 플레이어, About → 정보, Cheat → 치트 (Options → 옵션은 기존) |
| Game 메뉴 | Review Mission Objectives → 미션 목표 보기, Restart Mission → 미션 다시 시작, Leave Mission → 미션 나가기, Restart Demo → 데모 다시 시작, Exit Demo → 데모 나가기 |
| View 메뉴 | 채팅 숨기기/보이기(F3), 존 새로 고침(F9), 건물 숨기기(F2), 섬 테마 숨기기/보이기(Shift F3), 내 신전 보기(F4), 내 사제 보기(F5), NetStorm 지식 보기(F6), 섬 소유 표시 숨기기(F7), 플레이어 목록 보기(F9) — 단축키 표기 `~iF4~.` 는 그대로 둔다 |
| Options 남은 항목 | Cursor Snap To Grid → 커서를 격자에 맞추기, Counterclockwise Piece Rotation → 조각 반시계 방향 회전 |
| Players 목록 | `Player List\n` → `플레이어 목록\n` (끝 줄바꿈이 원문에 포함) |
| 상태 안내 | 게임 일시 정지!·게임 시간·게임 시작!·게임 완료!·서버 응답 없음·자원 주입 수신·접속/끊김/응답 없음·스톰 파워 수신·무승부 선언 요청·동맹 체결/해제 |
| 진행 창 | Initializing. → 초기화 중., Starting Mission... → 미션 시작 중..., Cancel → 취소 |

- 색 코드(`~E~b`·`~r`·`~w` 등)가 들어가는 안내는 원본처럼 플레이어 색(`b r w g m y l o`)마다 원문이 따로라 색별로 모두 넣었다. 응답 지연 안내는 네 번째 색이 `u` 이다. 두 이름 안내(동맹 체결/해제)는 앞 이름 색 8개 × 뒤 이름 색 8개 = 64개 조합씩 둔다.
- 서식 글자(`~E~w`, `~i…~.`)와 자리표시자(`%s`, `%d`, `%02d`)는 번역문에도 그대로 둔다. 이름 뒤 조사를 피하려고 `%s 접속`, `%s, %s 동맹 체결`, `님이 보낸 스톰 파워: %d` 처럼 조사에 의존하지 않는 표현을 썼다.
- **번역하지 않은 것:** `Type`(도움말 주제 이름 `bridgeType` 을 만드는 접미사라 번역하면 주제를 찾지 못한다), `LAN Server`(멀티플레이어, 웹 범위 밖), 서버 접속 진행 문구(멀티플레이어). 시험이 `Type` 이 번역표에 없음을 고정한다.
- 번역 문구는 개발자 검수 대상이다. 건물·유닛 이름은 AGENTS.md 용어 규칙을 따른다(`스톰 파워`는 기존 항목과 같다).

## 시험

- `tests/korean-ingame.test.mjs`(Node 5건): 실제 소스 모듈 `RawGameMenus`(Game·View·Options·Players, 미션·데모·도전·전투 상황)·`RawGameMenuBar`·`MessageGump`(안내 종류 14개 × 플레이어 8 × 8 조합)·`missionLoginProgressText` 에 번역 기록용 장치를 넣어 코드가 요청하는 원문을 모으고, 번역표에 없는 원문이 남지 않았는지 확인한다. 번역 결과로 표시 문자열을 만들어 `게임 일시 정지`·`게임 시간 … 1:02:05`·SP 수신 숫자가 채워지고 자리표시자가 남지 않았는지도 본다. 번역 항목 3개를 지우는 변형으로 시험 4건이 실패함을 확인했다.
- `e2e/korean-ingame.spec.js`(Chromium, 한국어 첫 캠페인 미션 시작 → ESC 막대 → Game·View 펼침 → Shift-F9): 막대 라벨 `게임·보기·옵션·플레이어·정보`, Game 하위 `미션 다시 시작·미션 나가기`, View 하위 `건물 숨기기·플레이어 목록 보기`, 정지 안내 `게임 일시 정지!` 가 갈무리11 글꼴로 그려짐을 화면으로 확인했다(오류 0).
- `e2e/korean-font.spec.js` 의 낡은 기대값(Options 첫 항목이 `소리 켜기`)을 E1095 이후 구조에 맞게 `언어` 첫 항목·`소리 켜기` 포함으로 고쳤다(이 단위 이전부터 실패하던 시험 결함이다).

## 남은 일

- 생산 창의 `Storm Power Available`·`Production Window`, 미니맵 도움말 `Sky Overview`, 채팅 채널 이름(`BATTLE`·`EVERYONE` 등) 같은 문구는 웹 코드가 아직 번역을 거치지 않는 고정 영어이거나 해당 UI 가 아직 연결되지 않았다. 그 UI 를 연결할 때 번역 호출과 함께 번역표에 넣는다. (객체 메뉴의 Upgrade·Salvage 문구는 기존 번역표 항목으로 이미 번역된다.)
- 번역 문구의 어색함은 사용자 검수 범위이다.
