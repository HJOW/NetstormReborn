# dotnetpj 0.805 — Host 부착 예외 소유권과 독립 공장 진단

2026-11-22 · HJOW-Athlon · 제품11.01 · .NET10 Release. 전체 목표와 M1은 미완료다.

## 구현

`RawSquidProcessHost.Attach`의 예외 처리를 C++ `SquidProcess.cpp`의 실제 unique_ptr 인계에 맞췄다. 등록 전 실패와 비활성 부모의 자연 반환은 Host가 한 번 소멸시킨다. Kernel.Add에 인계한 뒤에는 Kernel이 소유하며, 이후 Form 생성·전송·가상 부착 예외에서도 같은 객체와 앞선 부분 효과를 보존한다. Kernel 자체 진단이 이미 소멸시킨 인자를 Host가 다시 소멸시키지 않는다.

인계 표식은 TYPE 회전 뒤 실제 Add 바로 앞에서만 기록한다. 조회에서 제외되는 실제 slot0도 Kernel이 소유하므로 Kernel.Find로 소유권을 추측하지 않는다. 기존 객체의 Reattach는 새 소유권을 만들지 않는다. 할당·부모 체인·PID·Form·전송의 앞선 부분 효과를 되돌리지 않았다.

실제 공장 대여가 없는 독립 조합의 CreateOrTakeForm/AttachForm은 같은 Pool과 TYPE, 현재 Host assertion을 갖춘 독립 공장을 사용한다. 기존에는 선택된 원문 진단 대신 공장 진단 장치 미연결 예외가 발생했다. 장기 저장소에서 빌린 실제 공장의 수명과 진단은 그대로 유지한다.

## 검증

- 신규 Source 계약 검사 10건을 추가했다. 생성자 실패, 마지막 가상 통지 실패, Kernel 진단 실패의 정확히 한 번 소멸, 부모 free/dead, 등록 전 진단, 기존 객체 재부착, 실제 slot0, 서버 전송 실패, 독립 공장 진단을 실제 Host/Kernel/Pool/Form으로 구별한다.
- 제품 수정 전 소유권 관련 신규 9건 중 5건이 실패했고, 나중에 추가한 공장 진단 1건도 수정 전 실패했다. 제품이 고칠 차이를 먼저 재현한 로그/TRX를 보존했다.
- 기존 `AttachFailureKeepsEarlierRegistration`의 이름과 등록·할당 부분 효과 단언을 유지했다. 즉시 Dispose 기대를 Source의 Kernel 소유 보존으로 교정하고 같은 객체 및 외곽 drain 뒤 소멸을 추가했다. 원본 fixture/기대값을 바꾸지 않았다.
- 최종 Core 관련 **101건**, Client 실제 Host/미션/프로세스/경로/대여/수신 관련 **97건 통과**, 실패0이다. 제품 빌드 오류0이며 기존 테스트 경고는 유지했다.
- 검사한 Client 제품 DLL과 실행 폴더의 DLL이 일치했다. 같은 최종 빌드의 대표3시작(thewarbegins/tutorial1/surrounded)은 모두 종료0이고 전체 덤프 바이트와 지표가 마지막 전체0.804와 같다. 실행6파일과 원본1,392파일의 전후 해시가 같고 원본 전체 해시는0.804와도 같다.
- cpp_sync 읽기 전용 감사 종료0. 등록417자료와 PORT_MAP의 머리말/전체 행이0.803과 같다. PORT_MAP 물리1506줄·자료1501행(port1013/L1 481/session7)이다. 기존 대응 파일의 선택된 메서드만 보완했으며 파일 전체의 기준 커밋을 올리지 않았다.

신규 검사 초회에는 protected PID 접근과 검사 장면의 ProcessForm 번호가 잘못되어 컴파일/장면 실패가 있었다. 파생 검사 프로세스의 조회와 실제 기본 ProcessForm2로 교정했고 초기 로그를 남겼다. 이후 수정 전 제품의 위 6개 차이를 별도로 재현했다.

다음0.806은31h 패킷의 실제 문자열 파싱과 전체 개발자 명령 실행 본문이다. 나머지 고정 본문은31/35/38/39/3a/3b/3c/73/74/86의10개이며 전체 Native26F 설치/Bind와 Root의 실제 장치 공급도 남았다. 월드 표시·입력·플레이는 아직 연결되지 않았다. M1은 마지막 전체0.804의 **0/34**다. 다음 정기 전체는0.808이다.

CD Host/HP/Start·정지/도착과10.37 애니메이션의 기존 미검증 범위는 유지한다. 포획/희생·특정 적 공격·승리 GUI 재현은 수행하지 않았다.
