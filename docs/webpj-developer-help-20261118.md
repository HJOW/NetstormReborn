# WB04-E748 개발자 도움말 출력

`31h`의 `help`와 `?`를 현재 Session의 수준 29 추적 장치에 연결했다. 원문 32행을 각각 같은 순서로 출력하며, 추적 장치가 중간에 실패하면 앞선 호출을 유지하고 오류를 전파한다. 뒤에 오는 인자는 원문처럼 무시한다.

근거는 `225553df`의 `RawCampaignSession.cpp` 5045~5048행이며 해당 파일은 기준선 이후 변경되지 않았다. 두 구현의 32행을 순서대로 연결한 ASCII의 SHA-256은 모두 `2c314fc5e8db9776383fd7471681b456b1429ab256b7c740b7a0264fa8db13ec`다. 새 원본 fixture는 추가하지 않았다.

독립 검사에서 출력 행 수·수준·주요 문자열·별칭·오류 전파를 확인했다. Tutorial 1 Session의 실제 `31h` 분배기와 월드 추적 장치를 통과하는 검사도 포함해 집중 검사 39건이 통과했다. 대응표에 앞 단위 E747에서 누락한 기록과 이번 단위 기록을 함께 추가했으며 대응표 검사 오류는 0건이다.

Node v26.13.0 전체 회귀 6,239건이 통과했고 실패·취소·건너뜀은 0건이다. E746의 v22 검사 뒤 세 번째 v26 전체 회귀다.

나머지 개발자 명령·Carrier 등록·로그인 서버 후반과 응답 왕복, Native 분기 및 앱 미션 연결은 남아 있다.
