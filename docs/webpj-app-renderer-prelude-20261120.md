# 웹 미션 Renderer 프레임 준비 (WB04-E982)

앱의 현재 Tutorial1 World와 Client가 소유하는 Screen, Renderer, 카메라, 구름, Gump 및 프레임 전역을 원본 Renderer 표시 전 준비에 연결했다. 화면 모드 전환과 세계 전체 갱신은 같은 구름 사각형 큐를 사용하며, 세계 갱신 시 실제 Renderer 변경 표를 비우고 전체 화면을 추가한다. 원본처럼 이 준비 단계에서는 세계 갱신 요청을 지우지 않는다.

구름 override는 실제 Gump 수집 머리에서 읽고, 필요할 때 구름 갱신·행 검사와 시차 배경 갱신을 같은 장치에 전달한다. 시차 배경 합성의 분모는 Client 카메라의 실제 `current` 값을 매번 읽도록 수정했다. 웹의 현재 DIB 모드는 별도 DirectDraw 시차 표면을 지원하지 않으므로 해당 장치를 요구하는 경로는 기존처럼 명시적으로 거부한다.

실제 Tutorial1 로그인과 화면 크기 변경 이후 모드 및 강제 갱신, 구름 큐 4칸과 Renderer 변경 표를 확인했다. 분모 변경에 따른 두 시차 좌표 및 원본 앞단 관측 720행, 구름 관측 695행을 포함한 연관 Node 검사 28건이 통과했다. E974 고정 Node 26 전체 6,554건이 실패·건너뜀 없이 통과했고 E978 고정 Node 26 전체 검사가 실행 중이다. E982 고정 Node 22 전체 검사는 그 뒤 순차 실행한다.

이 단계는 준비 메서드를 실제 앱 소유 장치에 연결하고 독립 호출로 검증했다. 자동 프레임의 호출, Draw 뒤 구름 정리·Present·갱신 요청 해제, HUD·입력 및 미션 화면 전환은 아직 연결되지 않았다.
