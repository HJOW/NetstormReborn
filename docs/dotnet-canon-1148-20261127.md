# dotnetpj 1.148 — 설정 화면 모드와 구름

2026-11-27, HJOW-Athlon. 실제 1-1 화면의 갈색 단색 배경을 추적했다. 원본 `setup.cfg`의 `windowScreenFlags=10`, `workingFullScreenFlags=11`은 구름 비트를 포함하지만 C# 호스트의 창/전체화면 전환은 설정을 읽지 않고 DIB와 모드 비트만 지정했다. 각 전환에서 현재 설정의 해당 모드 비트를 선택하고 호환 DIB 모드로 정규화하도록 교정했다. 값이 없거나 불법이면 원본 기본값을 쓰며 명시된 구름 끄기 값 0은 유지한다.

- 창 10·전체화면 11·구름 끄기 0·애니메이션 비트와 기존 Screen/구름·옵션·실제 사제 검사 **32/32 통과**, Release 빌드 오류 0·기존 경고다.
- 캠페인1-1에서 1.147과 같은 1024×768·고정25ms·120프레임과 미니맵 드래그를 수행했다. 종료 0이고 구름이 출력된다. CPP 1.121과 전체 화면 차이는 75·81·89·95·105프레임에서 **32836·53107·31994·32133·31935픽셀**이다(1.147의 563577·566946·677115·677256·677024에서 감소). 미니맵 80×75는 모두 기존 **1픽셀** 차이다. 결과는 `extracted/dotnet-cloud-1148-first/`에 있다. 75프레임 비교는 기존 100프레임 L4a 관측과 별도다.
- 같은 격리 사용자 루트에서 전체화면 1-1을 두 번 연속 실행해 둘 다 정상 종료했고 75프레임 논리 BMP는 동일했다. 창 모드에 `windowScreenFlags=0`을 지정한 실행도 종료 0이며 이전 구름 없는 화면과 픽셀 일치했다. 세 실행 전후 원본 1,392파일 불변이다(`extracted/dotnet-cloud-1148-modes/`). 운영체제 출력의 모든 해상도나 장기 게임 플레이를 검증한 것은 아니다.
- 아직 남은 화면 픽셀·HUD 생산 내용물·입력과 게임 규칙, 미니맵 1픽셀·전환 수명, 메타/다리 추가 그림과 상태 효과 타이머는 미완료다. 전체 회귀는 1.140이며 이번 단위에서 재실행하지 않았다.
