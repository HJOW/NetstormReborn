# 0.614 농지 Generate 실결선 (파이프라인·단일·군집)

- 일시: 2026-11-18, HJOW-Athlon
- 범위: R4-2 농지 잔여의 Generate 현장 실결선. `HostSession.BuildFarmPlacementDevices`·`PlaceFarm` 추가와 `ClientHostGame` Generate 연결, L1 3건과 L2 3경로 재측정이 중심이다.
- 목표: 0.613의 월드훅 결선기를 실제 군집 배치로 잇고, `thewarbegins` cpp 농지 152셀과 타입·소유자·프레임을 대조한다.

## 원인

- 0.613까지 `MakeFarmWorldHooks`는 있었으나 `ClientHostGame` 449행의 `GenerateOriginal(..., (_, _, _) => { })` 자리는 비어 있었다.
- 0.608의 MayPlace-true 실험은 21/152셀 일치로 기각됐으며, 0.609~0.611에서 실제 파이프라인 본체와 전체 MayPlace 3건 전수 일치를 닫았다.
- 다음은 TYPE 핫스폿, 지역·추가·내용물·상태 수명, 패턴 전역·섬 표면 출처를 세션과 맞추고 실제 배치로 잇는 일이었다.

## 수정

- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`
  - `_terrainPopShapes` 보관 추가. `BuildTerrainPopDevices`가 셰이프 목록을 보관해 파이프라인 자료가 같은 인스턴스를 빌린다.
  - 농지 배치 소유 필드 추가: `_farmPipelineState`·`_farmAdditional`·`_farmContained`·`_farmRegions`·`_farmFrames`·`_farmHotspots`·`_farmPipelineData`·`_farmPipeline`·`_farmSingle`·`_farmCluster`.
  - `BuildFarmPlacementDevices(types, definitions, shapes)` 추가.
    - 지형 Pop·해시·점유지·TYPE·셰이프·바인딩·HP·WorldFrames 동일성과 판본 크기를 확인하고, 다르면 명시 거부한다.
    - 프레임은 70+적재 순서의 `FrameTable`+기본 프레임, 핫스폿은 TYPE 기준점, 패턴 8개는 로딩 순서에서 70+번호로 구한다(107·82·94·157·131·129·140·142).
    - 적재 스코프 기본값: `Permission.GraphReady=1`·`UseAlliances=1`, `Anchor.GraphReady=1`·`FenceType=90`·`WindArcherType=140`, `Placement.LocalPlayer=1`. 동맹·충돌 실제 값과 섬 제한·존재·첫 지역·정기 처리는 R4-6·R6에서 잇는다.
    - `RawCanonPlacementPipeline`→`MakeFarmWorldHooks`→`RawFortRandomPlacement`→`MakeFarmClusterPlacementHook`→`RawFarmCluster` 순서로 같은 풀·해시·점유지·장부에 연결한다.
    - 근거: cpppj `RawCampaignSession.cpp` 1826~1858행과 `RawNormalTerrainWorldBinding.cpp` 36~40행이다.
  - `FarmPipeline` 노출과 `PlaceFarm(area, region, quantity)` 추가. 근거: cpppj `RawNormalTerrainWorldBinding.cpp` 190행의 `farms_->Place` 호출이다.
- `dotnetpj/src/Netstorm.Client.Host/ClientHostGame.cs`
  - `BuildTerrainBinding` 뒤에 `BuildFarmPlacementDevices(types.Types, worldDefinitions, popShapes)`를 연결했다.
  - `Generate` 갈고리의 빈 place를 `(area, farmRegion, quantity) => session.PlaceFarm(area, farmRegion, quantity)`로 교체했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionFarmPlacementTests.cs`: 신규 L1 3건.
  - `BuildsPipelineSingleAndCluster`: 같은 장치에서 파이프라인·단일·군집이 연결되고 `MayPlace`·`PlaceFarm(..., 0)`이 명시 예외 없이 실행되며 중복 연결을 거부한다.
  - `RequiresDevices`: 장치 없으면 `PlaceFarm` 포함 명시 예외로 멈춘다.
  - `RejectsMismatchedStorage`: 지형 Pop 장치와 다른 인스턴스는 거부한다.
