# F3 채팅 전환과 정지 커서 건설 판정 보완 — WB04-E1486

2026-11-28 사용자 제보에 따라 webpj의 채팅 입력 중 F3 닫기와 마우스 정지 중 건설 가능 여부 갱신을 수정했다. cpppj의 같은 위치 갱신 누락도 함께 수정하며 dotnetpj와 그 인계는 다른 세션의 작업으로 유지한다.

## 원인과 변경

- `netstorm.js`의 미션 입력 프레임이 채팅 입력줄 활성 상태에서 F3까지 편집기로 전달한 뒤 소비했다. F3를 ESC와 같이 일반 입력 분배기로 통과시켜 기존 표시 명령 `0x02000088`을 실행한다. 작성 중인 문자열은 보존한다. F3로 다시 열면 원본처럼 로그 창이 보이고 Enter로 입력줄을 다시 표시한다.
- `RawCursorPosition.update`는 원본처럼 월드 좌표가 바뀔 때만 에너지와 공간 판정을 호출한다. 실제 게임의 `RawCampaignCursor.update`에서 위치가 그대로라면 기존 `gumpsChanged`의 이전 표시 범위 무효화 → 현재 에너지/공간/Gump 판정 → 새 표시 범위 무효화를 실행한다. 잠금 상태이거나 잡은 조각이 없으면 해당 메서드가 즉시 반환한다.
- 미리보기 SID 목록·조각·방향·좌표를 재생성하지 않으며 비용 차감·난수 소비·건설 송신을 추가하지 않는다. 원본 관측 687행을 대조하는 위치 몸체는 바꾸지 않았다.
- cpppj도 같은 조립 계층에서 같은 수정을 한다. [CP1382 기록](exe/cpp-stationary-placement-1382-20261128.md)을 따른다.
