# Client Slider 실제 출력

WB04-E1042는 선택적으로 실제 출력 장치를 받은 Client Slider의 빈 부모 Draw, 돌 배경, 화살표와 손잡이를 같은 Gump 픽셀·클립·FontSet에 연결했다. 손잡이 내부의 테두리 배경도 원본 배경 처리기를 사용한다. 기존 출력 장치를 주지 않은 독립 생성 경로는 유지한다.

Tutorial1 실제 fortGump 자산으로 다중 줄 Gump의 Slider를 켜고 두 화살표·돌 배경·손잡이가 각각 픽셀을 남기며 반납되는 것을 확인했다. 최초 검사는 손잡이 기본 배경 타입을 0으로 둬 실제 자산 조회에서 실패했고, 원본 초기화처럼 fortGump 타입을 공급한 뒤 다시 통과했다. 관련 Node 검사 16건이 통과했다. 스크롤바의 브라우저 조작과 메뉴 조립은 남았다. E1039 고정 Node 26 전체 회귀는 실행 중이다.
