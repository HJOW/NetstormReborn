# Session Login 상태 블록과 전송 앞단 (WB04-E707)

`RawCampaignSessionLogin.inc`의 `RawLocalMissionState` 생성에 현재 Client의 다섯 144BYTE 블록과 Player·권한·미션 모드·시각·기한·제목·Zone 전역을 연결했다. 초기화나 전환 시 별도 상태 사본을 만들지 않는다. StateHooks 앞단에서 현재 내부 전송의 접속·상태·닫기·번호 이전과 공유 시계, UI 모드, Fort 조회 경계를 연결했다.

실제 Session owner에서 상태 14의 공통 확정, 아직 서버가 열리지 않은 상태 8 접속의 선행 기한/실패, 상태 9의 만료 시 출처와 다음 상태만 쓰는 조기 반환을 확인했다. 원본 fixture와 기존 내부 전송 검사까지 집중 52건이 통과했다. 열린 실제 로그인 왕복을 가짜 성공으로 대체하지 않았다.

Fort 파일 선택·읽기, 로그인 이미지 송신, 타이머와 State7 공통 부모를 비롯한 나머지 StateHooks·Begin/Pump·서버/클라이언트 수신기·외곽 Session 연결은 미완료다. 일반 주소와 저장 재접속 주소는 해당 후속 경로가 준비될 때까지 명시 오류로 둔다. 32개 기준선 이후 커밋의 전체 판정도 남는다. 게임 창·플레이·공중 3종 전용 행동은 실행하지 않았다.
