# WB04-E1474 모드 추가 기능의 이식 분류 누락 보완

첫 Node26 전체는6,982건 중6,980통과·2실패·취소/건너뜀0·583.588초/종료1이다. 두 실패는 기존 port-map의 형식/완전성 검사가 새모듈5개에 CPP 대응 또는 웹 전용 사유가 없음을 지적한 것이다. 3,568입력의 원시 해시는 모두 불변이다. 이 전체를 성공 기준선으로 올리지 않고 Node22 전체는 시작하지 않았다.

`tools/port-map.mjs`의 기존 WEB_ONLY 목록에 공개API·실제Client호스트·입력경계·패키지·보관 모듈을 각각 사유와 함께 등록했다. 이들은 원본10.78/CPP기준선에 없는 사용자 추가 모딩 기능이다. 원본 이식1,007단위의 port/session 완료량에 가산하지 않으며 CPP 대응표/오라클/기존 검사 단언을 바꾸지 않았다. 게임 소스와3,517,946바이트 운영 번들도 그대로다.

기존 대응표 집중7/7과 변경 도구 ESLint를 통과했다. 별도 테스트나 분류 예외 우회는 추가하지 않았다. [실패 원문 SHA/종료·고정 확인](webpj-e1474-evidence/provenance.json).

이번 분류 보완을 한 단위로 기록한다. 마지막 성공 전체는 E1469이며 현재v26=5/4·v22=9/8로 두 전체 재실행이 필요하다. E1475 Node26 → E1476 Node22를 새 고정 입력으로 순차 실행하고 실제 통과/원시 해시를 확인한다. 실패한 E1474 원문과 수정 후 재실행 원문을 별도로 보존한다.
