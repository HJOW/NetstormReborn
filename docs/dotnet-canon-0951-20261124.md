# dotnetpj 0.951 — 1a/1b 배틀 시작 수신 본체·설치 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 1a/1b 배틀 시작의 송신 관찰기와 구역/상대 수신 본체, 고정 F 설치를 같은 분배기에 연결했다. 0.949의 0x66 수신·0.950의 검색 도우미와 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientStateBattleStart.ObserveZone`은 40a1e0 전체를 이식한다. 수신 방향은 버퍼를 읽지 않으며 진단 복귀 뒤 현재 BYTE를 다시 읽어 선언 WORD를 `개수*71+15`로 쓴다. 0.951에서 추가됐다.
- `ClientStateBattleStart.ReceiveZone`은 4b4df0 전체를 이식한다. 검사·phase 관문→next zlocal 3행·7·포트→복제→예약 증가→요청 시 기록→10/11 정리 순서를 보존한다. 0.951에서 추가됐다.
- `ClientStateBattleStart.ReceivePeer`는 4b8b20 전체를 이식한다. 서버/예약 조기 반환→검사·phase 관문→요청 시 기록→현재 블록 주소 복사→포트·7→직접 Run 순서를 보존한다. 0.951에서 추가됐다.
- `ClientStateBattleStart.Install`은 1a의 원문 packet 관찰기·버전·가변 길이·고정 F와 1b의 원문 빈 관찰기·버전·고정 길이·고정 F를 설치한다. 1a는 복제 위치에서 실제 Source를 선택하고 같은 UI 부모에 거짓으로 분배하며, 1b는 Run 위치까지 Source 선택을 지연하고 같은 UI 부모에 참으로 분배한다. 0.951에서 추가됐다.
- `ClientGameplayGlobals.GameServerPort`는 005318e8의 현재 DWORD 장기 owner다. 최초 6799이며 상태/일반 로그인/메타 listener 결선에서 같은 주소를 빌린다. 0.951에서 추가됐다.
