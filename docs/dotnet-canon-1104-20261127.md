# dotnetpj 1.104 — 공유 세션의 ContentForm 삭제 분배

2026-11-27, HJOW-Athlon. 1.103의 실제 장기 ContentLifetime을 제품 Native 공유 Surface 세션의 전체 삭제 분배기에 등록했다. 독립 및 Native가 아닌 공유 조합은 장기 Native ContentForm을 요구하지 않는다. 기존 GumpForm과 같은 실제 공통 삭제기·깊이를 공유하며 독립 조합의 기존 분배는 변경하지 않는다.

- 실제 파일 자산과 제품 순서의 공유 Surface/세션에서 GumpForm에 이어 ContentForm을 만들고 세션 자원 삭제 분배로 각각 반납했다. ContentForm 삭제 시 같은 커서 주소와 취소 장치를 확인했고 Pre/Post 깊이는 0으로 돌아왔다. 관련 Client 10/10 통과, 검사와 제품 Core/Client/Game DLL 해시 일치. 미부착 Form 삭제이며 너겟 수입·부모 중첩 통지 검사는 아니다.
- Game Release 빌드 성공, `cpp_sync.py` 종료 0. 대표 세 미션 CPP/DN 각각 종료 0, DN 90프레임 덤프는 0998과 바이트 일치, 원본 1,392파일은 세 감사에서 불변이다. 기존 CPP-DN 상태 차이로 비교 도구 종료 1. 결과 `extracted/dotnet-l2-1104-content-dispatch-final/`.

장기 종속 해제기의 Native 내용물 부모 통지와 실제 Gump 부모 삭제 중 UI 중첩 통지/삭제를 연결·검증해야 한다. 세션 커서 본체와 생산 Form 생성·부착, 인벤토리 내용물/유지/입력, 전체 UberRoot/L4a 일치도 미완료다. 다음 단위는 정기 전체 회귀다.
