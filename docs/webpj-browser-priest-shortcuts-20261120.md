# 미션 사제 선택·보기 단축키 (WB04-E999)

미션의 P/R 문자와 F5 가상 키를 같은 입력 큐에 예약하고 기존 선택 키 본체를 통해 현재 사제를 선택하거나 원본 `ViewYourPriest` 명령을 예약한다. 명령은 같은 Tutorial·Gump 관문과 GameMenuActions를 지나 현재 Session의 사제 또는 대체 참여 대상에 카메라를 맞춘다. Ctrl/Alt/Meta 문자는 임시 P/R 경로가 가로채지 않는다.

실제 Chromium에서 사제 이동 뒤 P로 다시 선택하고 R을 눌러 사제 보기 명령이 소비되는지 확인했다. 가장자리로 카메라를 옮긴 뒤 F5로 사제 위치로 돌아가고, 다시 이동 후 F4로 홈 복귀와 Tutorial A→B도 확인했다. 관련 Node 검사 29건과 Chromium 1건이 통과했다. 이 단계는 P/R/F4/F5 및 좌클릭만 연결하며 일반 키보드·HUD·다른 미션은 남았다.

E990 고정 Node 22 전체 6,557건이 실패·건너뜀 없이 통과했고 같은 상태의 Node 26 전체 검사가 진행 중이다.
