# 한국어 건물·유닛 명칭 규칙

2026-10-13 AGENTS.md의 사용자 추가 항목을 반영한다. cpppj와 dotnetpj의 문서·한국어 표시에서 같은 규칙을 사용한다.

## 표기 원칙

- **Priest → 사제, Temple → 신전, Bridge → 다리, Thrower → 발사기, Geyser → 간헐천, Altar → 제단, Residence → 거주 구역, Empty → 고갈된**은 뜻을 번역해도 된다(AGENTS.md. Altar·Residence·Empty는 2026-10-16 변경으로 추가). "번역해도 된다"이지 필수가 아니지만, 공유 표는 번역한 형태를 쓴다: Storm Geyser → 스톰 간헐천, Empty Storm Geyser → 고갈된 스톰 간헐천. High Priest도 사제로 표시한다.
- 발음 표기가 모호한 이름은 다음으로 정한다(2026-10-16 AGENTS.md): **Whirlibase → 훨리베이스, Whirligig → 훨리기그.** 이전 표기(휘리베이스·휘리기그·알타·레지던스·가이저·엠프티)는 쓰지 않는다.
- 위 규칙은 사용자에게 보이는 문구, 공유 표, 문서, 코드 주석에 모두 적용한다. cpppj의 해시 고정 파일도 2026-10-16 후속 작업에서 교정했으며, 과거 증거 사본과 보고서에 내장된 당시 원문·diff는 그대로 보존한다(아래 "적용 현황" 참고).
- 다른 건물·유닛 이름은 영어 발음의 한글 표기를 사용한다. **Workshop → 워크샾, Generator → 제네레이터**는 사용자가 지정한 표기다.
- 원소가 이름에 포함되면 Sun/ Wind/ Rain/ Thunder를 각각 썬/윈드/레인/썬더로 쓴다. 예: 레인 제네레이터, 썬 워크샾, 썬 캐논, 썬 디스크 발사기.
- Generator를 전기 생산 시설을 뜻하는 이름으로 바꾸지 않는다. 판타지 세계관의 의미를 유지한다.
- 타입 식별자, 원본 영어 description, 설정/미션 키, 파일 이름, 코드 심벌은 원본 값을 사용한다. 기술 분류·공격 방식·애니메이션 설명은 고유 이름과 구분한다.

## dotnetpj 연결

`Netstorm.Assets.GameUnitNames`가 공유 JSON을 내장 리소스로 읽는다. 빌드·배포·작업 폴더와 관계없이 같은 표를 사용하며 원본 자료 파일에 쓰지 않는다. `ForType`는 실제 타입의 description/이름을 읽고, `Format`은 이미 설정 치환을 마친 명칭을 표시한다.

한국어 모드의 생산 등록/현재 생산 메뉴·건설 목록·우클릭 제목/운반 사제·지식 카드/상세 제목·도움말 info 제목·개발 지도 이름에 연결했다. group을 기준으로 서로 다른 유닛을 하나의 짧은 분류명으로 바꾸던 표시를 실제 유닛 이름으로 교체했다.

영어와 다른 기존 언어는 원래 이름을 사용한다. 아직 공유 표에 없는 이름은 입력 원문을 표시한다. 도움말/미션 본문의 전체 번역과 메뉴의 모든 일반 문구 번역은 별도 작업이다. cpppj의 실제 한국어 표시 연결은 기존 로드맵의 한국어 단계에서 이 표를 참고한다.

## 문서 정리와 작업 기록

README·공통 규칙·자산/언어 문서·게임 규칙/녹화/분석 문서·두 인수인계의 관련 명칭을 갱신했다. 실제 링크 대상, 인라인 식별자와 명령/원본 자료 블록은 보존했다. 과거 실행/검증 횟수와 구현 완료 범위도 그대로 유지한다.

현재 규칙에 따라 한국어 명칭을 교정한 것이며 과거 녹화·검증을 다시 수행한 기록은 아니다. dotnetpj Release 게임 프로젝트와 Assets/Core 의존 프로젝트의 빌드는 **경고 0·오류 0**이다. 이번 단계의 새 테스트 추가/실행·GUI/게임 실행은 수행하지 않았다. 긴 한국어 이름의 실제 줄바꿈/폭·영어 UI 회귀 확인은 남아 있다.

이전 9-1 A 세션 시계 연결의 동작 대조와 24Hz/8틱 상한·타이머 이식은 기존 인수인계를 따른다. 원본 x86 **53,471개**, 단위 **990개 통과**는 앞 단계 기록이며 이번 명칭 변경의 검증 수가 아니다.

작업 PC는 **HJOW-Athlon**이고 공통 마지막 디컴파일 PC는 **HJOW-Athlon, 2026-10-13**이다. 이번 명칭 작업에서는 새 디컴파일·보호 원본 수정·AGENTS.md 편집·커밋/푸시를 수행하지 않았다.

### cpppj 후속 명칭 교정 (2026-10-16, `VM-W11-Codex`)

앞선 `DESKTOP-HJOW` 점검에서는 로컬 검증 자료가 없어 해시 고정 파일을 보류했다. 이후 사용자가 cpppj 명칭 작업을 요청하여 마지막 전체 디컴파일 PC와 일치하는 `VM-W11-Codex`에서 처리했다. 앞선 점검에서 빠진 `알터 → 제단`과 공유 표의 `바리케이드`도 함께 맞췄다. cpppj의 실제 한국어 UI 연결은 기존 로드맵의 3차 목표에 남는다.

소스·검사의 주석과 한국어 오류 문구, 분석 도구의 설명·주석 경계 문자열, 현재 JSON 설명, 분석 문서와 인수인계 이력을 교정했다. 내부 타입명을 한글로 적었던 실제 자산 설명도 대응표의 표시 이름(썬 디스크 발사기·썬 바리케이드·썬 워크샾 등)에 맞췄다. 원본 영어 심벌·타입 번호·설정 키·영어 문자열과 fixture의 입력·출력 행은 유지한다. 보고서의 `files`/`sha256` 연결은 **교정 직전 파일과 일치하던 SHA만** 새 값으로 바꾼다. 이미 어긋났던 SHA, 과거 `cpppj/hist` 사본, 내장 원문·diff는 당시 증거로 남긴다.

[명칭 교정 후속 기록](../cpppj/korean-name-migration.json)은 기준 커밋·전후 바이트 SHA·당시 유효했던 연결을 기록한다. `python tools/analyze_cpp_korean_names.py --verify`는 기준 Git 객체에서 이전 작업 바이트를 복원하여 지정 명칭·조사 치환만 수행했는지, JSON의 수치·관찰값·역사 원문이 그대로인지, fixture의 주석 밖 바이트가 동일한지 전수 검사한다. 새 원본 관찰·디컴파일·게임 실행은 0이다. 검증 결과와 기존 실패 범위는 [cpppj 명칭 교정 작업 기록](exe/cpp-korean-name-migration-20261016.md)에 구분해 기록한다.
