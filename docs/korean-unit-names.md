# 한국어 건물·유닛 명칭 규칙

2026-10-13 AGENTS.md의 사용자 추가 항목을 반영한다. cpppj와 dotnetpj의 문서·한국어 표시에서 같은 규칙을 사용한다.

## 표기 원칙

- **Priest → 사제, Temple → 신전, Bridge → 다리, Thrower → 발사기, Geyser → 간헐천, Altar → 제단, Residence → 거주 구역**은 뜻을 번역할 수 있다(Altar·Residence는 2026-10-16 AGENTS.md 변경으로 추가). "번역해도 된다"이지 필수가 아니며, 공유 표는 Geyser를 아직 발음 표기인 **가이저**(Storm Geyser → 스톰 가이저)로 두고 있다. 그 밖의 표기는 이 표기를 사용하며 High Priest도 사제로 표시한다.
- 발음 표기가 모호한 이름은 다음으로 정한다(2026-10-16 AGENTS.md): **Whirlibase → 훨리베이스, Whirligig → 훨리기그.** 이전 표기(휘리베이스·휘리기그·알타·레지던스)는 쓰지 않는다. 코드 주석과 과거 분석 기록 문서에 남은 이전 표기는 그 대상을 고칠 때 함께 바꾼다.
- 다른 건물·유닛 이름은 영어 발음의 한글 표기를 사용한다. **Workshop → 워크샾, Generator → 제네레이터**는 사용자가 지정한 표기다.
- 원소가 이름에 포함되면 Sun/ Wind/ Rain/ Thunder를 각각 썬/윈드/레인/썬더로 쓴다. 예: 레인 제네레이터, 썬 워크샾, 썬 캐논, 썬 디스크 발사기.
- Generator를 전기 생산 시설을 뜻하는 이름으로 바꾸지 않는다. 판타지 세계관의 의미를 유지한다.
- 타입 식별자, 원본 영어 description, 설정/미션 키, 파일 이름, 코드 심벌은 원본 값을 사용한다. 기술 분류·공격 방식·애니메이션 설명은 고유 이름과 구분한다.

## dotnetpj 연결

`Netstorm.Assets.GameUnitNames`가 공유 JSON을 내장 리소스로 읽는다. 빌드·배포·작업 폴더와 관계없이 같은 표를 사용하며 원본 자료 파일에 쓰지 않는다. `ForType`는 실제 타입의 description/이름을 읽고, `Format`은 이미 설정 치환을 마친 명칭을 표시한다.

한국어 모드의 생산 등록/현재 생산 메뉴·건설 목록·우클릭 제목/운반 사제·지식 카드/상세 제목·도움말 info 제목·개발 지도 이름에 연결했다. group을 기준으로 서로 다른 유닛을 하나의 짧은 분류명으로 바꾸던 표시를 실제 유닛 이름으로 교체했다.

영어와 다른 기존 언어는 원래 이름을 사용한다. 아직 공유 표에 없는 이름은 입력 원문을 표시한다. 도움말/미션 본문의 전체 번역과 메뉴의 모든 일반 문구 번역은 별도 작업이다. cpppj의 실제 한국어 표시 연결은 기존 로드맵의 한국어 단계에서 이 표를 참고한다.
