# WB04-E847 일반 전투 복귀 State6

기준선 `225553df`의 `NativeBattleReturnState`를 이식했다. 정리 전 결과·출처를 지역 값으로 보관하고, 결과에 따른 승리·패배·기본 배경과 음악, 출처 배경 재조회, 이전 전투 통지, 공통 준비와 외부 Fort 설치를 원본 순서로 실행한다. 후반의 결과 안내는 보관한 결과를 signed DWORD로 해석하고 안내 정상 복귀 뒤 현재 결과를 초기화한다.

집중 검사에서 결과 0의 배경 첫 BYTE만 지우는 동작, 승리·패배, 출처 배경 유무와 callback 뒤 현재 전투 모드, 정리 실패의 부분 상태, 후반 안내를 확인했다. 첫 출처 배경 검사에서는 이전 `defeat`의 NUL이 덮어쓰기 뒤에도 남는 원본 부분 쓰기를 기대값에서 놓쳐 정정했다. 기준선 뒤 해당 C++ 소스 변경은 없다.

Fort 설치와 멀티플레이 옵션은 원본 효과 순서를 보존하기 위한 외부 호출 경계다. 웹의 Edit·멀티플레이 기능을 구현하거나 공식 서버에 접속하지 않는다. 스커미시 결과 화면에 필요한 배경·음악의 실제 앱 연결은 아직 남았다. 원본 게임 창은 실행하지 않았다.

검증: 복귀 상태 집중 검사 5건, Node v26.13.0 전체 6,361건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E843의 Node v22 전체 검사 뒤 v26 회귀 4/8회다.
