# 미션 생산 UI 실제 장치 조립

WB04-E1033은 생산 패널을 현재 Session의 기술·커서·자본·재고와 실제 Client 글꼴·팔레트·소유자 색표·음향·시계에 조립하는 공장을 추가했다. 수량 글자, 배경, 비용 부족 점멸과 실패 안내는 앞서 이식한 실제 구성 요소를 함께 사용한다. 화면 갱신과 메뉴·도움말 경계는 현재 앱 장치를 호출자가 공급한다.

Tutorial1의 실제 Client와 Session에서 패널 생성, 색표를 사용한 아이콘 픽셀 출력, 슬롯 단축키의 실제 커서 취득·취소를 확인했다. 관련 Node·대응표 검사 11건이 통과했다. 최초 검사에서 색표 필드 이름을 잘못 지정해 실패한 뒤 실제 `_clientColorSort` 필드로 수정했다. 패널 공장은 아직 앱 프레임에 자동 설치하지 않았다. 미연결 생산 정보 메뉴, 생산 유지의 재부착 콜백, idle과 화면 크기 변경 및 Chromium 검증이 남았다.

E1030 고정 Node 26 전체 회귀는 6,564건 통과, 실패·취소·건너뜀 0이다. 같은 고정 상태의 Node 22 전체 회귀는 실행 중이다.
