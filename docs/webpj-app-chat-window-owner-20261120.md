# WB04-E969 앱 채팅 창 전역 소유

앱 Client가 Chat 창·로그·자동완성·무시 목록·문자열 표의 장기 전역 `ClientChatWindowGlobals`를 생성하고 모든 미션 Session에 같은 객체를 대여한다. 이전에는 각 Session이 별도 객체를 생성했으므로, 이후 명령 Gump의 현재 창 토큰과 Session 채팅/동맹 수신이 같은 Client 상태를 볼 수 없었다. 앱 반납 시 해당 소유 참조도 반납한다.

검증: 앱 공통 서비스의 동일 객체와 현재 창 토큰·무시 목록 변경, Session 소유자의 실제 입력 참조 대여, 실제 Tutorial1 로그인, 원본 채팅 창 전역과 중계 검사를 포함해 Node 26건 통과했다. 채팅 창의 생성·표시와 명령 Gump 알림은 아직 연결되지 않았다. E966 고정 Node 26 전체 6,547건 통과·실패와 건너뜀 0, 같은 고정 상태의 Node 22 전체 회귀 실행 중이다.
