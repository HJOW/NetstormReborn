# dotnetpj 0.931 — RU-3 NSInfo 입력 후크 분배 결선 검증

2026-11-24, HJOW-Athlon. RU-3 스물한 번째 묶음이다. NSInfo 이벤트/입력 후크가 소유한 파생 토큰을 실제 `Handle` 장치에 전달하고 반납 뒤 기본 처리에 넘어가는 분배 결선을 검증했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 검증 내용

- `HostNsInfoWindows.Bind`는 이벤트/입력 후크에서 소유한(`_roots`·`_players`·`_battles`) 토큰을 `Handle` 장치에 전달하고, 소유하지 않은 토큰은 이전 기본 후크에 넘긴다. 반납 뒤에는 이전 소유 토큰도 소유 판정에서 제외되어 기본 처리에 넘어간다.
- 버튼 후크(`BindButtonGump`)는 특수 버튼 소유 판정과 무관하게 이 분배와 함께 동작하며, 특수 버튼 그림 분배(0.930)와 충돌하지 않는다.

## 검증

- Release 테스트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 3건(이벤트→루트 장치·입력→플레이어 장치·반납 뒤 기본 전달)은 통과/실패 0이다. `HostNsInfoWindowsTests` 45건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0931-*/`의 각 실행 로그와 요약이다.
