# 생산 항목 정보 작성 연결

WB04-E1036은 원본 InventoryAboutMenu와 RawObjectMenuInfo를 현재 Session의 TYPE·실제 class 정의·Player·동맹·자본·비용·번역 및 외부 메뉴 작성기에 결합했다. 비용과 회수 판단은 같은 Session의 현재 전역을 사용한다. 정보 제목·본문·Help와 회수 항목은 원본 작성 순서로 전달한다.

Tutorial1의 실제 생산 항목으로 제목, 비용, Help 명령 및 소리 요청을 검사하고 원본 생산 정보 3,888행과 객체 정보 1,434행을 함께 대조했다. 관련 Node·대응표 검사 17건이 통과했다. 테스트의 메뉴 작성기는 호출을 수집하며 실제 화면 메뉴는 아직 연결하지 않았다. 따라서 앱의 우클릭 정보 메뉴는 여전히 미연결이다.

E1035 고정 Chromium 미션 진입·초기 진행 22건이 모두 통과했다. 원래 작업트리에서 시작한 전체 브라우저 회귀는 작업 중 코드 변경과 섞일 수 있어 중단한 뒤 고정 작업트리의 별도 포트에서 다시 실행했다. E1030 고정 전체 Node 22·26 회귀는 각각 6,564건 모두 통과했다. E1035 고정 Node 26 전체 회귀는 실행 중이다.
