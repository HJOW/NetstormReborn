# dotnetpj 1.077 — DN-MP-01 공통 도움말 setter 교정

2026-11-26, HJOW-Athlon. cpppj TCP/IP 상대 봇 검사에서 드러난 공통 결함의 DN 선행 반영 첫 조각이다. `GumpButtonTree.Ownership.cs`의 `SetNodeHelp`가 LOOK 0x1000/HELP 0x200을 쓰지 않고 빈 문자열까지 새로 소유하던 정적 차이를 cpppj 1363 원문 순서에 맞췄다. DN 코드·실행은 이번에 바꾸지 않았다는 종전 인계 기록을 이번 단위에서 실제 교정·검증으로 넘긴다. CP 재현을 DN 실행 결과로 세지 않는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Gump/GumpButtonTree.Ownership.cs`: 원문 `RawMenuControls.cpp:361~366`(`SetNodeHelp`) 순서로 교정했다. 첫 NUL 뒤는 원문 C 문자열과 같이 버리고, 이전 포인터를 반납한 뒤 0으로 둔다. 비어 있으면 새 문자열을 소유하지 않고 빈 LOOK는 0x1000을 끄고 빈 HELP는 기존 0x200을 유지한 채 돌아간다. 비어 있지 않을 때만 `word ? 0x200 : 0x1000`을 켜고 다른 비트는 보존한다. 주소 영역 소진 검사는 유지했다. `SetHelpText`·`SetHelpWord` 설명도 빈값 오류 기대에서 원문 동작으로 고쳤다. 근거: [CP1363](../cpppj/help-flags-1363-20261126.json)·[cpp-help-flags-1363](docs/exe/cpp-help-flags-1363-20261126.md)·[DN 후속 인계](docs/dotnet-cpp-lan-followup-20261126.md). 1.077에서 수정했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostGumpOwnershipTests.cs`: `CommonOwnedHelpTextUsesNativeRangeAndScalarRelease`를 원문 동작 검사로 교정했다. 첫 별칭 0x61100001·두 문자열 소유·교체 시 이전 주소 반납·빈 HELP의 0x200 유지와 소유 수 감소·빈 LOOK의 0x1000 해제와 소유 수 감소·첫 NUL 절단(`ab\0cd`→`ab`, `\0xyz`→빈 LOOK)·다른 비트(`~0x1200`) 보존·serial 불변·자식 우선 소멸 반납을 확인한다. 종전 빈 문자열 소유 기대는 삭제했다. 1.077에서 수정했다.

- `cpp_sync.py`는 종료 0이다.
