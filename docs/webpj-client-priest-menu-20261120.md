# 실제 사제 건설 메뉴 작성

WB04-E1065는 같은 실제 Session의 사제 건설·기도 메뉴와 Client controlled 메뉴의 중첩 작성, 현재 TYPE 설명 번역, 기술·자금·미리보기 커서 경계를 결합한다. 공통 객체 메뉴와 Tell은 실제 상위 호출자가 제공하도록 강제한다.

실제 Tutorial1 로그인 사제에서 하위 메뉴가 만들어지고 기본 객체 메뉴 경계가 마지막에 호출되며 Gump와 스타일이 반납됨을 확인했다. 원본 사제 메뉴 관측 및 실제 미션 검사 Node 22·26 각 10건이 통과했다. 실제 객체 공통 메뉴, 사용자 우클릭, 건설 선택 명령 처리와 브라우저 완주 검증은 남았다.
