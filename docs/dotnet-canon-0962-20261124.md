2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 0x22 참가자 이동 전체(슬롯 효과 479cf0/478720과 이동 본체 42c2e0)와 0x22 등록을 이식했다. 0.961의 0x20 생성 본체와 제품 기존 경로는 바꾸지 않는다. 세션 결선(0x22 수신의 실제 음향·음악·Chat·메뉴 장치 연결)은 후속에서 잇는다.

- `ClientMetaParticipantMove.Install`은 0x22의 원문 빈 observer·버전·고정 길이(17)·고정 F(004b4820)를 설치한다. 0.962에서 추가됐다.
