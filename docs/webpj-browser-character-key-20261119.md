# WB04-E931: 브라우저 원본 문자 사건

브라우저 Canvas의 키 누름에서 영문·Windows-1252 문자를 원본 한 바이트 문자 사건으로 예약한다. Backspace·Tab·Enter·Escape도 각각 원본 제어 문자로 다루고, Shift/Ctrl/Alt와 현재 포인터 좌표를 보존한다. Ctrl과 영문 키 조합은 원본 제어 바이트로 바꾼다. 조합 중 입력·Dead 키·미지원 Unicode는 이 경계에서 무시하며 E922의 비문자 가상 키 경로와 중복하지 않는다. 원본 입력 소비자가 설치되기 전에는 기존과 같이 적재하지 않는다.

영문 대소문자·1252·Ctrl 문자·기본 제어 키·조합 제외와 원본 키 관측을 포함한 관련 Node 검사 10건이 통과했다. Chromium에서 실제 Canvas의 영문과 Enter가 각각 사건 하나로 예약되었고 관련 브라우저 검사 5건이 통과했다.

키보드 레이아웃별 ToAscii의 전체 조합, 한국어 IME 확정, 실제 텍스트 입력 장치와 미션 이벤트 소비는 아직 남았다.

Node v22.23.3 전체 회귀 6,499건이 실패·취소·건너뜀 없이 통과했다.
