# dotnetpj 1.115 — 정기 전체 회귀

2026-11-27, HJOW-Athlon. 1.114 상태에서 세 테스트 프로젝트의 Release 출력과 게임 폴더의 Assets/Core/Client/Game DLL을 SHA-256으로 비교했다. 처음 Assets·Core 검사 사본이 달라 해당 프로젝트를 재빌드했으며, 비교 가능한 모든 사본이 제품과 일치한 뒤 전체 검사를 실행했다.

- Assets 383건, Core 4,121건, Client 2,906건이 통과했고 실패는 없다. 합계 **7,410건 통과**다.
- Client TRX의 `WindowsSoundHardwareTests.MutedNativeDeviceLoadsDuplicatesAndRestoresAfterReinitialize` 1건은 **NotExecuted**다. 콘솔의 건너뜀 0과 달리 실제 하드웨어 검증 통과로 세지 않는다. 결과는 `extracted/dotnet-1115-regression/`에 있다.
- 게임을 새로 실행하거나 전체 34경로를 재측정하지 않았다. 1.111 대표 세 미션 실행·원본 보존 결과와 M1 0/34 기준은 그대로다.

다음은 실제 생산 격자의 부모 삭제·재부착과 완전 적재 미션의 생산 사건, 내용물 정렬 본체 통합을 검증한다. 사제 포획 안내, 미니맵 남은 픽셀·전환 수명과 채팅 실제 키 입력도 미완료다.
