# WB04-E871 Tutorial1 실제 Session 지형의 cpppj 부분 비교

웹의 실제 `BridgeTheGap` typed Session을 `Load`한 뒤 같은 튜토리얼의 cpppj 기준선 90프레임 덤프와 비교했다. 지면 TYPE 97 및 가장자리 TYPE 121의 763개에 대해 TYPE, X/Y float 원문 비트와 영역 WORD가 모두 일치했다. 이전 독립 마스크 검사에 실제 cpppj Session의 비교를 추가한 것이다.

프레임 DWORD까지 처음에 같다고 가정한 검사는 763개 모두 달라 실패했다. 예를 들면 같은 TYPE 97 위치에서 웹 141, cpppj 145였다. 현재 웹 관측은 독립 `Load` 직후이고 cpppj는 미션 시작 후 90프레임으로, 시계·난수와 시작 수명이 같지 않다. 따라서 이 차이만으로 구현 오류나 정상 애니메이션을 단정할 수 없다. 검사는 위치·영역 일치만 보장하고 프레임 차이를 별도 진단으로 출력한다. 같은 Client 수명·난수·시점에서 지형 프레임과 실제 화면을 다시 비교해야 한다.

실제 Session 집중 검사 1건과 cpppj 자료·fixture 추적 연관 검사 5건이 통과했다. 새 회귀 주기에 따라 전체 회귀는 실행하지 않았다. 원본 게임 창은 실행하지 않았다.
