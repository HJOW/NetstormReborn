# WB04-E915: Client Gump 가상 부착

cpppj `RawButtonControls` 공통 트리와 `RawUberRootControls`는 직접 부착과 `GumpTree::Move`의 가상 부착에서 실제 파생 본체를 호출한다. Client Gump 소유자가 파생 노드별 부착기를 등록하고, 직접 부착과 같은 공통 트리의 재배치·정렬 콜백에서 이를 분배하게 했다. 파생 본체는 `attachBase`로 재분배 없이 원본 기본 부착을 호출한다. 공통 지연 삭제로 노드를 반납할 때 부착기 또한 해제한다.

실제 등록된 배경 파생 노드로 직접 부착과 Move가 같은 처리기에 도달하고 부모·좌표·다시 그리기·삭제를 유지함을 확인했다. 원본 GumpTree 574행과 HudDock 2,150행을 포함한 관련 Node 검사 29건이 통과했다. 구분선의 실제 파생 본체와 하위 UI 공장·HUD 출력은 후속 작업이다.

Node v22.23.3 전체 회귀 6,476건이 실패·취소·건너뜀 없이 통과했다.
