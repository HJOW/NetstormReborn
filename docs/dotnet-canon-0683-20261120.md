- 상태: Core/Client 집중 검증과 인계 정리를 마쳤다. 전체 목표는 미완료다.

## 구현

`RawFactoryResearch`는 예측 내용물 검색/삭제 후 슬롯 재조회와 같은 종류 재검색을 보존한다. 입력의 상위 signed WORD 종류는 전체 DWORD로 검색/생성에 전달하고 송신에는 하위 BYTE만 쓴다. 기존 `FactoryResearchCommand.Write`를 재사용해16바이트 메시지를 중복 구현하지 않았다. 입력 로그 뒤 현재 시각을 읽고, Learn 전에 패킷에 복사한다.

연구 수신은 현재 상태·TYPE genus·owner BYTE와 sender DWORD·현재 아웃포스트 역할·현재 boss를 원문 순서로 검사한다. kind0/mode1은 기존 업그레이드 수신 본체에 위임한다. 내용물 통지는 플레어 뒤 현재 kind를 다시 읽고 중복 예측 내용을 삭제한다. form0을 포함한 flags BYTE·현재 로딩 깊이·감김 dirty·진단 뒤 현재 소유자의 생산 재계산 순서를 유지한다.

`HostSession.BuildFactoryUpgradeCommandWorldDevices`는 같은 현재 TYPE·실제 비용/SP·현재 권한/시각·실제 SharedRegular 확보/초기화/부착을 연결한다. 확보한 같은 객체를 사용하며 부착 후 현재 시각으로 사건을 재설정한다. 외부 채널9 송신·방송·로그를 필수로 받고, 장치 조립 전/중복 조립/반납 뒤 접근을 거부한다. AI 시설 요청은 이 장치의 같은 Request를 지연 조회한다.
