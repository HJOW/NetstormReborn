# 원본 SoundPlayer 재생과 제어 (WB04-E961)

기준선 `225553df`의 10.78 `SoundPlayer`를 기존 `SoundList`와 위치 음향 계산, 명시적인 장치 훅에 연결했다. 원본 재생 준비·동시 재생 제한·지연 적재·버퍼 복제와 실제 항목 반환, 위치별 단발/반복, 재생 여부·정지, 이름 기반 요청, 재생 수 재계산과 전체 음량 보류·갱신 순서를 보존한다. 장치 상태 조회와 현재 화면은 원본이 읽는 시점마다 다시 읽는다.

보호 원본 실행 없이 `soundplay-x86.tsv`의 10.78 재생 관측 1,065행과 `soundcontrol-x86.tsv`의 제어 관측 1,063행을 실제 이름 표·상태표 장치에서 재생해 사건·반환·전체 32,768바이트 표의 Adler 및 전역 상태를 비교했다. 기존 `SoundProcess` 훅과 사전 적재, 위치 재생의 현재 화면 재조회 및 fixture를 포함한 연관 Node v26 검사 22건이 통과했다. 다른 판본은 웹 범위 밖이다.

이는 장치 독립 재생 계층이다. Web Audio에 원본 버퍼·복제·상태·반복·음량/좌우를 제공하는 장치와 비동기 자산 준비, 현재 앱·Session의 위치 음향 연결은 아직 남았다. E958 고정 Node v26 전체 회귀 6,529건은 모두 통과했고, 같은 고정 상태의 Node v22 정기 회귀가 `extracted/webpj-e958-node22-isolated.log`에서 실행 중이다.
