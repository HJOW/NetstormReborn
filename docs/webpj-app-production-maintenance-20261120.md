# 앱 미션 생산 유지 소유자 (WB04-E1002)

Client 수명에 원본 생산 유지 전역을 보유하고 현재 로그인 World에는 별도의 생산 패널 상태와 같은 Session의 유지 실행기를 준비한다. 초기 슬롯 수는 실제 전투 옵션에서 계산하고 기술 내용물 동기화와 실제 시계·난수·Deck·생산 변경 표를 사용한다. 변경 알림은 현재 Renderer를 무효화한다.

실제 Tutorial1 기술 부모에서 유지 실행기를 직접 한 번 실행해 같은 SID 풀의 다리 내용물이 한 개 늘어나는지 확인했다. 원본 생산 유지 관측 86행과 Client 생산 동기화 등 관련 Node 검사 10건이 통과했다. 이는 아직 독립 호출 검사다. 앱 프레임의 정기 호출과 실제 생산 패널·격자 표시 및 다리 취득 입력은 남았다. E998 고정 Node 22 전체 검사는 별도 트리에서 진행 중이다.
