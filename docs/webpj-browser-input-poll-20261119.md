# WB04-E919: 브라우저 입력 폴링

cpppj `Client::Poll`의 원본 코드 마스크, 현재 눌림/뗌·키별 눌린 적 있음 비트, 창 밖 비트와 논리 화면 좌표 제한을 브라우저 입력에 연결했다. Client 수명마다 현재 앱 입력·배치·문서 활성 상태를 다시 읽는다. DOM 마우스 버튼 0/1/2를 원본 좌/중/우 가상 키에 맞추며, Shift·Ctrl·Alt의 좌우 키 상태를 합친다. 실제 최초 눌림은 키별로 기록해 해당 폴링에서 한 번 소비하고 키 자동 반복은 새 눌림으로 취급하지 않는다.

실제 앱의 보조 키 이벤트와 독립 상태에서 세 버튼, modifier, 눌림 기록, 창 밖·비활성·좌표 제한을 확인했다. 연관 Node 검사 18건과 실제 Chromium의 마우스 누름·뗌 및 Ctrl 누름·뗌 1건이 통과했다.

현재 지원은 마우스 세 버튼, Shift·Ctrl·Alt 및 VK 0이다. 그 밖의 키를 폴링하면 미연결 오류를 낸다. OS의 전역 GetAsyncKeyState 기록은 브라우저가 접근할 수 없으므로 눌림 기록은 이 앱에서 관찰한 이벤트를 기준으로 한다. 일반 사건 큐·포인터 경계·Client 프레임 연결은 아직 남았다.
