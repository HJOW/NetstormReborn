# dotnetpj 1.125 — 일반 객체 표시 자산 표 준비

2026-11-27, HJOW-Athlon. R5-3d의 실제 일반 객체 출력을 위한 선행 단계로 `SpriteAssetViews.Build`를 추가했다. cpppj `SpriteDraw.cpp`의 `MakeSpriteAssetViews`처럼 내장 TYPE 0~69를 보존하고 파일 TYPE 70부터 기본 프레임과 casttime·praytime·effecttime을 원문 절삭으로 옮긴다. 표시 셰이프는 각 물리 프레임까지 사본으로 만들어 원본 자산과 구분한다.

- 새 구성 검사는 번호·기본 프레임과 도움말 프레임 구별·양수/음수 절삭·없는 속성·TYPE 범위 오류·프레임 사본을 확인했다. 기존 SpriteDraw 검사와 함께 **15/15 통과**했다. 추가한 실제 게임 자산 검사까지 포함한 별도 재실행은 **3/3 통과**다. 검사 추가 직후 자산 탐색 네임스페이스 누락으로 컴파일이 실패했고 참조를 보완해 재검증했다. Release 빌드 오류 0·기존 경고, `cpp_sync.py` 종료 0이다.
- 구성기는 아직 제품 화면에 연결하지 않았다. SpriteDraw의 가상 프레임·추가 그림·실제 팔레트/상태 장치와 정렬된 kind 0 제출 경로가 남는다. 이번에는 게임 창·대표 미션·전체 회귀를 다시 실행하지 않았으며 기존 1.120 회귀·1.124 대표 덤프 기준을 유지한다.
