# dotnetpj 0.923 — RU-3 NSInfo 배틀 결선 이식

2026-11-24, HJOW-Athlon. RU-3 열다섯 번째 묶음이다. NSInfo 배틀 패널 본문을 같은 실제 호스트 저장소와 외부 장치에 연결하는 생산 결선을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HostNsInfoWindows.LayoutMetaBattle`은 배틀 패널의 전역 조성과 후크 결선을 실제 owner로 연결한다. 같은 CS 전투 기록과 트리 노드/Push·제목 파싱/스크롤/슬라이더·요청·부착을 빌린다. 옵션 값/이름은 배틀 옵션 문자열 표로, 제외 설명은 `Describe` 장치에서 공급받는다.
- `Describe` 장치를 `HostNsInfoDevices`에 추가했다. TYPE 설명/번역/80BYTE 설정 치환의 생산 공급자가 정해지기 전까지 미연결 호출은 명시 실패한다.
- TextFlags 상자는 플레이어 결선과 같은 노드 값 빌림·배치 마침 되돌림을 공유한다. 배틀 경로에 스크롤 상태 읽기가 없으므로 단순 보관·되돌리기로 충분하다.
- 상위 루트 배치의 메타 자식 선택(`AttachBattle`)과 이 결선은 같은 `NativeBattleInfoInput`/`NativeBattleInfoMenus` 실제 본문을 가리킨다. 입력 분배·송신·음향·메뉴 공장·중앙 카메라는 후속 단위에서 잇는다.
