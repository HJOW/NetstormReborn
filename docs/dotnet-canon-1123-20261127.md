# dotnetpj 1.123 — 이전 세션의 미니맵 통지 대여 검증

2026-11-27, HJOW-Athlon. 공통 미니맵·저장소에 실제 `HostSession` 두 개를 순서대로 결선하는 집중 검사를 추가했다. 첫 세션의 대여를 반납하고 둘째 세션을 결선한 뒤 첫 세션의 지형 실행기를 뒤늦게 재구성한다. 이전 실행기의 Pop/Unpop은 현재 미니맵 큐에 전달되지 않고 둘째 실행기의 Pop/Unpop은 전달되며, 이전 세션의 재결선은 현재 공유 전체 갱신 값을 바꾸지 않음을 확인했다.

- 최초 검사 13건 중 신규 1건이 `실제 후처리 영역 Graph 미연결`로 실패했다. 처음에 그래프가 연결되지 않은 Player 경로에서 Pop한 검사 장면의 문제였다. 기존 세션 검사와 같은 실제 지형 Pop/Unpop 실행기로 교정한 뒤 `RawMinimapControlsTests` **13/13 통과**했다. 기존 중복 using·nullable 경고가 출력됐다.
- 이 검사는 세션과 미니맵의 대여 경계만 검증한다. 제품의 메뉴→미션→메뉴 왕복과 실제 미션 교체는 연결·실행하지 않았으며 R5-4c3c의 전환 수명은 여전히 미완료다. 제품 코드나 게임 실행은 이 단위에서 바꾸거나 수행하지 않았다. 전체 회귀 기준은 1.120을 유지한다.
