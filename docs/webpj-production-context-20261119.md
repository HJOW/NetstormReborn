# WB04-E834 생산 UI 실제 문맥

기준선 `225553df`의 `ProductionControlContext.h`와 `RawCampaignSession::ProductionContext`를 이식했다. Client 장기 표면 저장소·게임 전역·Player 기록·87BYTE 옵션과 선택적인 SP·소유자 색표 소유자를 사본 없이 보관한다. Session 설치 전에도 같은 문맥을 조회할 수 있고 반납 뒤에는 새 조회를 거부한다.

실제 Session의 문맥으로 E833 생산 동기화를 호출해 설치 관문과 같은 Deck을 확인했다. 옵션을 원본 배열에서 바꿨을 때 문맥에서도 같은 값을 읽고, 초기화된 실제 색표 소유자와 별도 실제 SP 장기 소유자의 정체성을 유지한다. 초기 색표 없는 상태를 정상으로 가장하지 않고 Client 색표를 먼저 준비했다.

문맥과 동기화 본체를 실제 HUD가 소유·호출하는 앱 수명과 생산 UI 표시는 아직 남는다. 게임이나 별도 창은 실행하지 않았다.

검증: 실제 Session 집중 검사 2건과 Node v26.13.0 전체 6,330건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E827의 Node v22 전체 검사 뒤 v26 회귀 7/8회다.
