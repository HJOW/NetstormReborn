# 1.187 초기 장식 이전 나머지 난수 호출

1.181의 SP 기록과 같은 시드 전이 인덱스를 사용해 2,245회 차이를 구간별로 분해했다. 첫 SP 묶음 이후 CPP 인덱스 1,313→2,117은 804회, 대응 DN 인덱스 33→834는 801회다. 양쪽 모두 구름 생성 `BuildKencloud`/`RawKencloud.Next`가 801회이며 CPP에는 주변 바람 `StepAmbientWind` 3회가 추가됐다.

마지막 SP 쓰기 이후 첫 장식 이전에 CPP 인덱스 3,397→3,456은 59회, 대응 DN 인덱스 1,154→1,211은 57회다. 양쪽 모두 지형 프레임 선택 57회이며 CPP에는 장면 음악 `SceneMusic.Start` 1회와 주변 바람 1회가 추가됐다. 따라서 SP 쓰기 횟수 차이 2,240회 외 **5회는 바람 4회·장면 음악 1회**다. 호출 주소는 별도 CPP 링크 맵의 함수와 대응했고 C#은 호출 메서드를 기록했다.

두 진단 실행은 각각 종료0이고 같은 조건의 제품과 40프레임 전체 픽셀·슬롯이 일치하며 원본 1,392파일은 전후 불변이다. 로그·실행 인자·링크 맵은 `extracted/dotnet-rng-next-1187/`, SP 단계별 전이 위치는 `extracted/dotnet-rng-parent-1181/phase-indices.json`에 있다. 이 관측은 1-1의 해당 고정 입력 경로에 한정한다. 원본의 전체 State 정리와 실제 프레임·음악 호출 순서를 연결해야 하며, 난수만 인위적으로 소비하지 않는다.
