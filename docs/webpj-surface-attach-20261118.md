# WB04-E724: 월드 종속 자산 부착

cpppj `RawSurfaceWorld.cpp`의 `AttachBaseAsset`(412~427, 기준선 `225553df`와 현재 소스 동일)을 웹 월드에 연결했다. 원본 004ad330 순서대로 실제 표시 진단, 부모 좌표 기록, 현재 종속 UI 통지, 공통 부모·이전 링크 갱신, 실제 Pool의 공통 Pop을 실행한다. 공통 Pop은 같은 월드의 서버 권한·Squid 송신·공유 후처리 깊이와 현재 가상 PostPop을 사용한다. Session 2ch 수신의 종속 분기도 이 월드를 호출한다.
