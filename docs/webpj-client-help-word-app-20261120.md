# 앱 도움말 문구 설정 연결

WB04-E1045는 원본 Client 옵션 해석의 helpWord 설정을 같은 Client 장기 캐시에 연결한다. 앱 자산 적재와 설정·진행값 동기화 및 설정 쓰기 시 현재 GameData 값을 해석하며 키 부재·빈 값 보존과 ASCII 대소문자 비교는 기존 원본 캐시 구현을 따른다. 언어 자료의 영어 또는 한국어 문구를 그대로 사용한다.

실제 Tutorial1 영어 설정과 생산 메뉴의 도움말 항목, 앱 캐시의 영문 대소문자·빈 값·한국어 교체를 검사했다. Node 26 관련 33건이 모두 통과했다. 생산 메뉴의 실제 앱 우클릭과 Help 명령 처리는 후속이다.
