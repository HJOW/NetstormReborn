# WB04-E937: Client Slider와 공통 수명

cpppj 기준선 `225553df`의 `RawButtonControls` 조립 일부를 `ClientScrollControls`로 연결했다. 기존 Slider·손잡이·돌 화살표·배경 생성기와 공통 Client 등록표, 입력·부착·방송·삭제를 공유한다. 색상·시계·소리·폴링·자산 상태는 호출자가 공급한다. 생성 중 실패한 미등록 부모와 부분 생성 자식도 각 소유자가 정리한다.

같은 Client 트리에서 실제 화살표 누름과 뗌이 Slider 위치를 40에서 39로 변경하고 전체 자식이 반납되는지 확인했다. 배경 자산 장치 누락과 생성 전 할당 정리도 검사했다. Slider·버튼·공통 Gump 연관 Node 검사 51건과 Node v26.13.0 전체 회귀 6,507건이 모두 통과했다(실패·취소·건너뜀 0).

실제 TextEntry 공장, 앱의 자산·출력 장치와 미션 UI 연결은 남았다. 이 검사는 미션 플레이나 브라우저 화면 출력을 입증하지 않는다.
