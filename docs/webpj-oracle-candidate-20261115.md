# 제품 1313 오라클 후보 수집 (4-R ①)

현행 이식 기준선 `1f00a25a`와 기존 `m1/` 자료는 유지한다. 후보는 cpppj
최종 코드 `979d65b5d`를 포함하며 cpppj 소스 차이가 없는 `225553df`에서
분리 worktree와 Visual Studio 2022 Release로 빌드했다. 이 시스템은
AGENTS.md의 실행 확인 예외인 HJOW-Athlon이다. 실행 파일 SHA-256은
`5b52d96d2e53f4674a40991b78ff64c3c7e2ad8275a0a99b22d18d532b77eb46`이다.
오라클은 시나리오별 빈 사용자 데이터와 `--mute-audio`를 사용했고 원본
게임 파일은 수정하지 않았다. 같은 이름의 웹 자산 30개는 모두 일치했다.

영어 4:3의 8장면 모두 기록한 영역 밖 차이 0이다. 구름 배경은 기존처럼
37,054픽셀(General Help 33,164픽셀)이 남는다. Campaign은 cpppj의 12차
Skirmish 행 추가로 창이 커지고 재배치되어 19,997픽셀이 다르다. Options는
Frame Rate·Difficulty 등 cpppj 추가 행과 기존 플랫폼 전용 행 때문에
23,609픽셀이 다르다. 이 두 영역은 웹의 해당 단계에서 해소할 차이다.
기존에 기록했던 Demo 페이지 이름과 General Help 스크롤 화살표의 색
차이는 새 cpppj에서 해소됐다. 이는 웹 미션 플레이나 세션 비교가 아니다.

첫 재수집 비교는 이전 판의 차이 기록을 그대로 사용해 6건이 실패했다.
cpppj의 실제 메뉴 항목·창 좌표와 원본 비교 모드를 대조한 뒤 후보 전용
시나리오에서 위 영역과 픽셀 수를 기록하고 해소된 세 기록을 제거하자
8장면이 모두 통과했다. 후보 메타와 각 PNG·보고서 해시 및 웹 화면을
`tests/cpp-oracle-candidate.test.mjs`가 검증한다.

집중 검사와 자료 목록 검사 4건이 통과했고, Node v22.23.3·v24.22.3·
v26.13.0 전체 검사도 각각 4,966건 통과·실패 0이다. 현행 기준선의
`port-map.mjs` 검사는 984행·오류 0이다.

남은 4-R: 신규 단위의 MP·Edit·host·스커미시 분류, 기존 변경분 판정과
필요한 재반영, manifest 근거 갱신 및 전체 기준선 전환이다. 후보 자료는
기존 M1 회귀와 나란히 보존하며 기준선 전환 완료로 세지 않는다.
