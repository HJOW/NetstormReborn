# dotnetpj 1.036 — WP-3 전체 Native World 자산 가상 삭제 분배

2026-11-26, HJOW-Athlon. R4-6 월드·경로 묶음의 세 번째 조각이다. 세션 Root급 실제 전체 가상 삭제를
제품 미션 진입 경로에 설치했다. MetaZone 마커 삭제(`ClientStateStorageCleanup.ClearMetaZones` →
`DestroyForState`)가 이 분배를 타며, 일반 삭제 Pre/Post로 대신하지 않는다. 감시 쌍·프로세스 Form은
같은 세션 장치를 등록하고 Gump·내용물 Form은 UI·내용물 본체(R3)에서 잇는다. 자산 뿌리는 원문 83개
생성 가상표 전체를 실제 공통 본체로 보내며, 등록되지 않은 가상표는 명시 거부한다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Host/HostSession.StateDeletion.cs`:
  `BuildWorldDeletionRootDevices()` 신규. 같은 세션의 실제 프로세스 Runtime·장기 저장소·감시 쌍으로
  `RawSquidFormDispatch` 전체 분배기를 만들고 `BindWorldDeletion`으로 설치한다. 자산 재정의
  (`AssetDestroyFull`)는 원문 83개 생성 가상표(`SupportsConstructedVtable`) 전체를 실제 공통 본체로
  보내고 미복원 표는 명시 거부한다. 근거: cpppj `src/client/RawSurfaceWorld.cpp` 373행의 `BindDeletion`과
  `RawCampaignSession.cpp` 3026행의 `MakeCampaignDeletionEffects` 상당 결선이다.
  일반 삭제 Pre/Post로 대신하지 않는다. 1.036에서 추가됐다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 미션 시작 Motion 설치 뒤
  `session.BuildWorldDeletionRootDevices()`를 호출한다. 입력 없이 게임 효과를 내지 않으며 L2 덤프에
  닿지 않는다. 감시 쌍·프로세스 등록과 자산 전체 허용·미복원 거부는 세션 장치에 둔다. 1.036에서 추가됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostWorldDeletionRootTests.cs`: 신규 3건. 제품 Root와 같은
  Native 전송·선택 계약(전송 Broadcast·`BindProcessDevices` 선택 0·해제 빈손, `Scene` 공유 풀·사제·패킷
  장치)으로 전체 분배를 설치하고, 단일·미설치 거부를 대조한다. 실제 ProcessForm 삭제가 같은 전체 분배
  경로로 통지·반납됨을 확인하며, 원문 83개 밖의 가상표는 명시 거부한다. 자산(사제 등) 삭제의
  Damageable·사제 전처리·공통 삭제 장치는 WP-4·R5/R6에서 잇는다. 1.036에서 추가됐다.
