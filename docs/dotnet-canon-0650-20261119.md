# 0.650 AI 런타임 세션 결선 (R4-5)

- 일시: 2026-11-19, HJOW-Athlon
- 범위: AI 준비·전략·통지·등록 본체의 세션 결선과 `PrepareAi`·`InitializeAi` 진입점 연결. 매 프레임 호출과 미이식 하위는 잇지 않는다. 사제 포획·희생·승리 재현은 사용자 확인 범위라 건드리지 않는다.
- 목표: R4-5 입력 중 세션 결선을 잇고 258 완료 판정의 실제 호출 경로를 닫는다.

## 이식 (증거)

- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`: `BuildAiRuntimeDevices`·`PrepareAi`·`InitializeAi`와 `AiPreparation`·`AiStrategySetup`·`AiObjects`·`AiWorld`·`AiRuntime` 접근자, `AiRuntimeLogs`·`AiRuntimeDiagnostics` 기록을 추가했다. `BuildRegionVortexPostPopDevices`에서 Player 정기 분배 다음에 연결했다. 준비 본체는 실제 사제 조회·섬·보상·거리·무효그래프·시각과 초기 전체 등록으로 잇고, 통지는 실제 중심·거리·로그와 소유자·데모·현재 시각으로 잇고, 등록은 실제 중심·로그·진단으로 잇고, 전략은 실제 섬·파괴·진단·다리·시각으로 잇고, 전체 프레임은 실제 초기화·준비·목표와 소멸·반납·벽시각·실행시간·진단으로 잇는다. 수집자·시설·부족스캔·사제·배치·다리·운반·경제·자금·분산 SP·그래프·지역경계·신전생산·지도상한은 R6에서 잇는다. 매 프레임 호출도 R6 틱 결선에서 잇는다. 지형 분배 Pop에 통지를 연결했다(`BindPatchAiNotice`). 근거: cpppj `src/client/RawCampaignSession.cpp` 461~462행의 `PrepareAi`·`InitializeAi`, 2831~2870행의 통지·등록 조립, 2937~2943행의 전체 프레임 조립이다. `PrepareAi`는 brain 없이 거짓, `InitializeAi`는 258 완료 여부를 반환한다.
- 세션 파괴 갈고리를 `BuildSessionDestroy`로 공용화하고 펜스 결선에서 재사용했다. 근거: cpppj `o/RawFencePostPop.cpp`·`o/RawFenceCreate.cpp`의 가상+10 삭제다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionAiRuntimeTests.cs`: 신규 4건(장치 연결, brain 없음 거짓, 준비 진단·초기 스캔, 지역 없음 생략). 실제 자료 장면과 공유 체인·기록으로 대조했다.
