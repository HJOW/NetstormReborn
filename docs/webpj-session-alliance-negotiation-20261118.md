# WB04-E719: 동맹 협상 수신과 현재 Session 등록

`RawPlayerParticipation`의 `RemoveAlly`와 77h 요청, 79h 해제, 6fh 무승부 동의 수신을 현재 Player 기록과 방향표에 이식했다. 서버 중계와 안내가 패킷·현재 Player를 바꿀 수 있는 위치를 보존하고, Draw는 별도 게임 시각 기한만 예약한다. 동맹 입력 처리와 실제 종료 판정은 구현하거나 실행하지 않았다.

외곽 Session은 Carrier 등록의 첫 세 6바이트 직접 수신기를 같은 Player와 현재 boss·무시 목록·Tell·MessageBoard·방송·게임 시계에 부분 연결한다. Login이 있으면 같은 Login이 보관한 상태 안내 장치를 사용한다. 이 수신들은 향후 스커미시의 동맹 설정에도 관련되어 E260의 일괄 웹 제외 판정을 수신 부분에 대해 재검토했다. 일반 멀티플레이와 동맹 키 입력의 범위 판정·연결은 후속이다.

현재 효과가 packet·로컬 owner를 변경하는 순서, 부분 실패, 거부와 예약 기한, 실제 Tutorial 1 Session의 직접 수신을 포함해 집중 검사 59건이 통과했다. 나머지 Carrier 등록, Login Load 콜백의 전체 등록 순서와 서버 후반·응답 왕복은 미완료다. 공중 유닛 전용 생성·행동, 사제 포획·희생·자연 승리, 실제 게임·브라우저 창은 새로 실행하지 않았다.
