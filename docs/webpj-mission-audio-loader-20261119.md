# 미션 음향 선택 적재 (WB04-E959)

E957 공개 자산의 효과음 또는 음악 한 파일을 현재 `AssetLoader`로 받아 `AudioSystem`에 해독·등록하는 비동기 장치를 추가했다. 매니페스트에서 원본 이름을 대소문자 구별 없이 찾으며 동일한 동시 요청은 다운로드와 해독을 공유한다. 등록한 파일은 다시 받지 않고, 실패는 저장하지 않아 재시도할 수 있다. 경로가 포함된 이름과 중복 항목을 거부하며, 반납 또는 오디오 종료 뒤 도착한 결과는 재생기에 등록하지 않는다.

앱은 메뉴 적재에 사용한 같은 매니페스트와 사용자 시작 입력에서 활성화한 실제 오디오 장치를 보유한다. `_prepareMissionSound(name)`과 `_prepareMissionMusic(name)`은 요청된 파일만 받으며, 앱 종료 시 미완료 적재 결과를 반납한다. 실제 미션에서 언제 파일을 준비할지, 효과음 재생 핸들·위치 음향·음악 선택과 재생 수명은 아직 연결하지 않았다. 따라서 미션 시작이나 메뉴 적재 시 모든 음악을 내려받지는 않는다.

검증: 실제 공개 WAV와 MUS 바이트를 읽는 `AssetLoader` 및 `AudioSystem` 검사에서 개별 다운로드·동시 요청 공유·캐시·경로 거부·실패 재시도·비동기 반납을 확인했다. 연관 Node v26 검사 29건과 E958의 Session Load 전체 파일 127건이 통과했다. E958 고정 Node v26 전체 회귀 6,529건은 모두 통과했고, v22 정기 회귀가 같은 고정 상태에서 진행 중이다.
