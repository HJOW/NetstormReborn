# 1.227 실제 Client 값 옵션과 고정 BYTE 문자열

2026-11-28 HJOW-Athlon. State7 정리 후 재해석에 필요한 다섯 값 해석과 기존 채팅 입력 전환 값을 현재 Client 소유자에 연결했다. **Client76·Core15 합계91통과·실패0, 실제 메뉴/1-1 관측·대표3미션 정상 종료**다. 전체435220 옵션 부모나 State7 cleanup/적재를 완료한 단위가 아니다.

## 변경과 실제 소비

ClientValueOptions는 같은 Config/ClientLocalState/Gameplay/Connections/NSInfo/저장 억제 상자를 빌리고, 다른 Client 조합은 구성 단계에서 거부한다. 구성 자체는 설정을 읽거나 소켓·시계·난수를 실행하지 않는다. 현재 값을 재조회하는 다섯 몸체를 추가했다.

- Cursor는 매 해석에서 회전 모드를0으로 쓴 뒤 rotmode 전체 signed 비트를 읽는다.
- MainMenu는 tellTips→tipNumber→autoDemo의 현재 전체 DWORD를 읽으며 누락은 보존한다.
- FortFiles는 readOnlyForts 뒤 기존 NSInfo의 curServer→rootServerBroadcastPort→passedDiags를 읽는다. 외부 클라이언트 검증은 실행하지 않는다.
- ScriptMenu는 같은 Player.Special/별도0055a484를0으로 쓰고 userCheat의 유일한 허용값0x845fed만 보존한다. 기존00594fc4와 합치지 않았다.
- Network는 현재 gameServerPort→같은64BYTE testBattleAddress→현재 lag 분포 순서다. 지연 값1/2/3만 분포를 선택하며 누락·다른 값은 보존한다. 연결이나 지연용 난수를 실행하지 않는다.

ClientStateResources에 같은 readOnlyForts 상자, Gameplay에 별도 SpecialAuxiliary를 추가했다. Game의 실제 생성 경로는 다섯 몸체와 기존 Chat 입력 전환 값을 읽고, 공개 InterpretNativeValueOptions도 같은 소유자를 재사용한다. 채팅 값은 메뉴 안내 뒤/Fort 값 앞에 배치했다. 초기 NSInfo/Chat 중복 해석 함수는 제거했다. ReadOnlyFortOption은 같은 상자를 공개하며 **실제 파일 저장 관문에 이 상자를 공급하는 후속 결선은 아직 남는다.**

원문의 ReadStringBytes를 기존 ConfigInterface의 partial 파일로 추가했다. 누락이면 목적지를 읽지 않고, 기존 Windows1252 인코딩 뒤 첫 불일치/NUL까지만 비교한다. 불일치 뒤에는 처음부터 NUL까지 전방 복사하며 짧은 목적지에서 앞선 쓰기를 보존한다. 전체 목적지를 선검사하거나 주소를 임의 절단하지 않는다.

이는 복원된 값 소비자의 상대 순서다. 실제 전체 옵션 부모의 언어/표시 크기/우선순위/사운드 디렉터리·음향/프레임 설정 등과 초기 Native 시작/SP 순서는 미완료다. 단독 값 해석을 전체435220의 대체로 사용하거나 NativeLoaded를 쓰지 않았다. 옵션 변경마다 이 모든 값을 자동 재해석하는 새 구독도 추가하지 않았다. 이후 전체 부모가 원문 위치에서 각 하위 몸체를 호출해야 한다.

최종 제품 DLL의 메뉴와1-1을60프레임 실행하고20프레임에 실제 Config.Set→InterpretNativeValueOptions→기존 LoadContent 재연결→미지원 lag 재해석을 관측했다. 회전0x80000000, 안내 상위 비트, 억제0xfffffffc, NSInfo 음수, 치트 허용값, 포트7001, CP1252 주소와 inputLineOff=-9를 확인했다. 같은 저장 억제/분포 소유자가 재적재 후 유지되고, lag0이 분포를 되돌리지 않았으며 게임/CRT 난수도 불변이다. 상태/Loaded/시드 주입이나 연결 시작은 하지 않았다. 두 종료0·보호1,392파일 전후 불변이다(extracted/dotnet-1227-options-runtime/run.json). 채팅 값 읽기의 검증이며 물리 키/채팅 창 표시 완료로 세지 않는다.
