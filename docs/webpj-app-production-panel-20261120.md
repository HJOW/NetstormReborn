# 미션 앱 생산 패널

WB04-E1035는 미션 시작 뒤 실제 생산 패널을 만들고 기존 생산 유지의 격자 재부착, 매 프레임 Gump idle, 논리 화면 높이 변경과 World 반납 전 패널 삭제에 연결했다. 생산 공급 상태는 기존 Session과 같은 객체다. 실제 화면에 패널이 생기면서 기존 DIB 검사에서 관측 좌표가 가려져 별도 위치로 옮겼다.

Tutorial1 실제 앱 검사 4건에서 자동 패널 설치, 다리 공급 후 격자 갱신과 기존 렌더·입력 수명이 통과했다. Chromium에서 캠페인 목록 진입, 안내 닫기, 화면의 생산 격자 마우스 클릭·취소, Q 단축키, 사제 이동과 다리 배치가 통과했다. 관련 브라우저 검사는 두 번 통과했고 새 격자 클릭도 두 번째 실행에서 확인했다.

생산 항목 우클릭 정보 메뉴는 아직 연결되지 않았다. 이 입력은 현재 미연결 사실을 콘솔에 기록하고 처리하지 않는다. 전체 HUD·미니맵·지도 도킹, 자연 승리와 다른 미션의 장시간 플레이도 남아 있다. E1030 고정 Node 22 전체 회귀는 실행 중이다.
