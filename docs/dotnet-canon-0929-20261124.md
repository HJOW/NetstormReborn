# dotnetpj 0.929 — RU-3 NSInfo 입력 분배 결선 이식

2026-11-24, HJOW-Athlon. RU-3 열아홉 번째 묶음이다. NSInfo 세 파생 입력을 같은 실제 소유 판정으로 루트·플레이어·배틀·기본 처리에 분배하는 생산 결선을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HostNsInfoWindows.HandleDispatch`는 입력 토큰의 원문 입력 event/first/second를 `NativeNsInfoDispatch.Dispatch`(0.919)에 실제 owner로 연결한다. 소유 판정은 같은 `_roots`·`_players`·`_battles` 집합을 직접 빌리며, 파생 처리는 0.925~0.927의 루트·플레이어·배틀 결선을 재사용하고, 그 외 토큰은 `BaseInput` 장치에 전달한다.
- 새 장치를 추가하지 않았다. 분배에 필요한 소유 집합·파생 결선·기본 장치는 모두 갖춰져 있어 후크 합성만으로 충분하다. 0.929에서 추가됐다.

## 검증

- Release 클라이언트 빌드는 오류 0이다. 신규 경고 0이다.
- 신규 4건(루트 메뉴 분배·플레이어 준비 분배·배틀 정렬 분배·기본 전달/미연결 명시 실패)은 통과/실패 0이다. 이웃 `HostNsInfoWindowsTests`·`NativeNsInfoDispatch` 검사를 포함한 41건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0929-*/`의 각 실행 로그와 요약이다.
