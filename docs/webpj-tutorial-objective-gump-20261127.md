# 튜토리얼 안내의 투명 Gump 표시

WB-TUT-2 / WB04-E1387, 2026-11-27, HJOW-Athlon. 표시 부품 단위 완료이며 실제 앱 연결은 TUT-3에서 진행한다.

`TutorialObjectiveGump`는 현재 ClientGumpRoot·FontSet과 기존 TextGump/StyleText의8비트 글리프 출력을 쓴다. 별도 DOM/Canvas 층이나 배경·패널·반투명 상자를 만들지 않는다. 지도 오른쪽/아래8픽셀 여백·줄 폭 최대440·줄 간격2를 사용하며 같은 font0 보통체에1픽셀 그림자를 더한다. 문맥8DWORD의 첫2는 그림자 플래그이며 글꼴 슬롯은 다음DWORD의0이다.

영문은 가능한 단어 공백에서 나누고 긴 단어나 혼합 문자는 완전한 Unicode 문자 경계를 보존한다. 측정에는 기존 FontSet의 명시 길이를 공급한다. 크기/문구/색이 같고 자기 노드가 살아 있으면 같은 노드를 유지한다. 크기 변경·숨김·부모의 선행 삭제에서는 토큰/serial을 확인해 자기 줄만 정리하거나 다시 만든다.

CP1372의 `SetDisplayOnly`는 같은 GumpEvents에 토큰+serial 쌍으로 반영했다. 전체/직계 선택의 **후보만 제외**한다. 기존 노드 플래그·자식 재귀·기본 필터·직접 Dispatch는 유지한다. 다른serial이 같은 토큰을 재사용하거나 옛serial을 해제해도 새 노드에 영향을 주지 않는다. ClientGumpRoot가 같은 선택기에 전달하고 표시기가 이 실제 입구를 사용한다.
