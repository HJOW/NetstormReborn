# WB04-E762 웹 인수인계 체크 항목 감사

사용자 요청에 따라 `LEFT_JOBS.webpj.md`의 미완료 체크 항목을 현재 코드, 대응표 상태와 E639·E698~E702·E716·E750~E761 단위 기록에 대조했다. 큰 상위 항목에 완료된 부분과 남은 부분이 섞여 있어 완료 부분이 체크 표시로 드러나지 않았던 곳을 확인했다.

완료 범위가 명확한 하위 작업 32개를 `[x]`로 표시했다. 로그인 상태·옵션, Init Zone/공유 Core, 일반·데모 Start와 동맹, 사제 이동, 로컬 송신, 프레임, 사제 메뉴를 통한 워크샾 최초 배치와 기존에 문장으로만 적혀 있던 화면·메뉴·음향 선행 부품이 포함된다. 이미 구현된 사실과 해당 근거의 범위를 그대로 옮긴 것이며 새 게임 기능을 구현한 것은 아니다.

미션 월드 UI, 워크샾 자연 완공/생산, 다른 운반 유닛, Native 경로·32커밋 판정, 앱 연결, 설정 초기화 등은 별도로 남아 있으므로 해당 상위 항목을 완료로 바꾸지 않았다. 4-D의 현재 문서상 상위 체크는 변경 전후 10개 완료·31개 미완료이며, 이전 보관본의 완료분을 합친 54/85 집계도 그대로다. 하위 체크는 상위 진행 수에 중복 가산하지 않는다. 5-C `ClientTitleBitmaps`와 6단계 메뉴·생산 등 대표 잔여 항목의 대응표가 todo/partial인 것도 확인했다.

이번 단위는 Markdown 표시와 근거 링크만 수정했다. 체크 구조·문서 링크·Git 공백 검사와 대응표 검사를 수행하며 코드 회귀는 반복하지 않는다. 직전 E761에서 Node v26.13.0 및 v22.23.3 전체 각각 6,260건이 순차 통과했고, 두 검사 모두 실패·취소·건너뜀은 0건이다.
