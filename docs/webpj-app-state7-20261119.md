# 앱 Client State7과 내부 접속 (WB04-E889, 2026-11-19)

앱 Client가 Kencloud·HTML 전역과 Local State 동기화 칸을 공유하는 연결표·연결 활동표를 소유한다. Session은 같은 연결표와 앱 프레임 번호를 사용하며 앱 종료 때 World 반납 후 연결표를 정리한다. 앱의 State7 진입은 실제 공통 부모에서 현재 요청을 캡처하고 같은 Client 저장소에 선택 Fort의 GameWorld를 설치한 뒤 State8의 내부 접속을 건다.

실제 Tutorial1 Guide에서 요청을 만들어 테스트가 지연 큐를 꺼낸 후 앱 State7 부모와 State8을 실행했다. 원본 상태 순서, 공유 저장소, 요청 소비, 로컬 로그인과 Ready 및 반납을 확인했다. 앱 실제 시계와 로그인 장치의 벽시각이 일치해야 타임아웃을 정확히 판정한다. 진행 창·사운드·카메라는 검사 장치가 대신했다. 집중·연관 Node 검사 15건과 Chromium 검사 1건이 통과했다. Node 26.13.0 전체 회귀 6,438건도 실패·취소·건너뜀 없이 통과했다.

앱 프레임에서 지연 큐와 State를 소비하거나 실제 진행 창·카메라·사운드 장치를 연결하지는 않았다. Guide 이후의 미션 Start와 화면 표시도 남았다.
