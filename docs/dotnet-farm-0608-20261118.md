# dotnetpj 0.608 — 농지 배치 결선 시도와 MayPlace 검증·R6 이관

2026-11-18, HJOW-Athlon. R4-2 잔여 중 농지 배치 파이프라인(타입 121, thewarbegins 152셀)을 이식·결선하고 L2 일치 행 증가를 확인하려 했다. 결과는 기각 후 되돌림이다. 적재 스코프 MayPlace-true 가정이 선택 집합 대조에서 반박됐고(21/152 일치), 실제 MayPlace(R6 캐논 파이프라인)가 필요하다는 0.605 판단을 증거로 확정했다. 제품 코드는 MayPlace-true 실험을 전부 되돌려 0.607 상태로 복귀했으며, 조사 과정에서 확인된 세션 공용 후처리 운반체 결선(캐리어 바인딩)만 R4-1 장기 장치로 남겼다. R4 진행 중·M1 0/34·새 경로 플레이 불가는 유지한다.

## 한 줄 요약

- 농지 군집·단일 배치(RawFarmCluster+RawFortRandomPlacement, L1済)를 호스트 적재 흐름에 결선하고 MayPlace를 적재 스코프 한시 판단(=> true+호출 기록)으로 두는 실험을 했다.
- L2 선택 집합 대조에서 dn 선택과 cpp 152셀이 21셀만 겹쳐 MayPlace-true를 기각하고 결선을 전부 되돌렸다.
- 세션 지형 공용 후처리(_terrainPostPop)의 운반체 몸체(RawCarrierPostPop) 결선은 cpppj 결선과 같은 R4-1 인프라로 유지하고 검사로 잠갔다.

## 한 일

- HostSession에 농지 배치 결선(BuildFarmPlacement: 단일 배치+군집+11개 훅, Repop 몸체 포함)과 MayPlace 호출 기록, ClientHostGame Generate 갈고리 연결을 추가했다가 전부 제거했다.
- 세션 지형 공용 후처리에 운반체 몸체를 연결했다(WireTerrainPostPopGraph末, cpppj RawCampaignSession.cpp 1856행의 MakeNormalTerrainFarmWorldHooks와 RawNormalTerrainWorldBinding.cpp 40행의 SetCarrierPostPop 결선 대응). Damageable 가상표(농지 121 테이블 0x0050A8E8 등)의 분배가 공통 경로 대신 전용 Damageable 몸체로 가게 된다.
- 신규 검사 HostSessionTerrainCarrierTests 2건: (1) 121 Pop이 전용 몸체로 분배되어 미복원으로 멈추지 않고 최초 등록 1건만 집계됨, (2) 운반체 미연결 공용 후처리는 같은 입력에 명시 예외.

## 왜 MayPlace-true를 기각했나 (증거)

실험 흐름은 동작했다(군집 299쿼리, Unpop→Retype(121)→Repop 실행, 운반체 결선 뒤 분배 예외 없음). 그러나 선택 집합이 cpp와 달랐다.

1. 선택 집합 불일치. dn이 고른 144셀과 cpp 152셀이 21셀만 겹친다. 시도 집합(299쿼리)에도 cpp 셀 120개가 없다. 같은 영역·수량·시드라면 시도 자체가 겹쳐야 하므로, MayPlace 판단이 선택을 바꾼다(거부된 후보 뒤 탐색이 어긋나는 연쇄 포함).
2. 범위 밖 프레임. dn이 고른 셀 중 일부는 지면 프레임이 121 셰이프 수(173)를 벗어난다(관측 최대 208). cpp의 농지 152셀 프레임은 전부 29~171(범위 내)이다. cpp가 고른 셀과 dn이 고른 셀은 애초에 다른 집합이다.
3. 리전별 개수 일치. 지역별 농지 수(dn 99/45 대 cpp 101/51)는 맞는다. 군집 영역·수량·시드는 정합하고, 개별 후보 허용·거부가 다르다는 뜻이다. 정확히 MayPlace의 자리다.

## 조사 중 확정한 것 (R6 처방전)

- 농지 Repop(flags 0x40)의 분배는 Damageable 가상표를 타므로 공통 지원표 검사를 통과하지 못한다. 세션 공용 후처리에도 운반체 몸체 결선이 필요하며, 이번 단위에서 그 결선을 넣었다.
- 농지 Repop 뒤처리(공통 몸체, flags 0x40)는 비용·개수·그래프 효과가 모두 없다(Unpop→Retype→Repop 순서와 flags 64는 cpp RepopAsset 경로와 같다). carrier 몸체의 ClaimGround는 121에 갱신 비트(0x400)가 없어 발화하지 않는다.
- 실제 MayPlace는 R6 캐논 파이프라인(RawCanonPlacementPipeline + Relations/Permission, R6-3 I영역 3단위)이다. cpp RawCampaignSession.cpp:1856의 MayPlaceGameplay 결선과 같은 것을 이식해야 한다.
- R6 단위에서 할 일: 파이프라인 이식 → 농지 결선 재적용(이번 단위에서 뗀 BuildFarmPlacement 상당) → 34경로 L2에서 선택 집합 일치(152셀) 확인 → 총계·TotalMade·그래프 파급 확인.
