# Client 장식 Gump

WB04-E1038은 원본 장식 노드의 배경 생성, 실제 fortGump 모서리 네 장면, 현재 픽셀 클립, 확장 영역 재그리기 및 공통 소멸을 Client Gump에 연결했다. 같은 GumpBackground 장치와 TYPE/SHP를 사용한다.

실제 자산·트리·픽셀 표면에서 장식 출력과 확장 영역, 삭제를 검사했다. 원본 장식 관측을 포함한 관련 Node·대응표 검사 32건이 통과했고 마지막 출력 경로 정리 뒤 자산 검사를 다시 통과했다. 메뉴 제목·본문과 원본 메뉴 전체 조립은 남았다.

E1035 고정 Node 26 전체 회귀는 6,564건 모두 통과했으며 실패·취소·건너뜀 0이다.
