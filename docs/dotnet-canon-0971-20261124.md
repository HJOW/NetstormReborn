# dotnetpj 0.971 — Build에 로컬 서버 발견 0x66·메타 geometry 0x26 수신기 연결

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 같은 장기 기본 표를 공유하는 `ClientPacketDispatch.Build`/`InstallDefaults`에 원문 앱 전역 0x66 로컬 서버 발견·0x26 메타 geometry 수신기를 연결했다. 1a/1b Build 연결과 제품 기존 경로는 바꾸지 않는다. 세션·메뉴 결합 후크 중 0x1d(설정·진단 로그·Tell owner 필요)·0x0f(NsInfo owner 필요)·참가자/전투 묶음(NSInfo·생성·좌석 장치 필요)과 Root 송신·제출 갈래, RU-3 나머지·R4-4 정기 두 단위는 후속에서 잇는다.

## 변경과 원문 대응

- 0x66 후크는 실제 장기 장치만 묶는다. 상태·검색 토큰·검색 만료 기한은 `connections.LocalState`의 같은 owner이며 벽시각은 장기 연결 활성, 주소 조회는 같은 Registry의 현재 20바이트 주소다. 현재 36 작성 뒤 동기 Run만 실제 UI State 부모 요구로 명시 실패한다. 0.971에서 추가됐다.
- 0x26 후크는 실제 장기 장치만 묶는다. 최초 배치 좌표·현재 모드는 `challenge`의 같은 owner이며 진단은 실제 선택 줄 소비자다. 화면 한계는 화면 장치가 없어 R5 후속으로 명시 실패한다. CS0/메타 모드/송신자/World 선행 관문이 없는 원문 F 계약을 유지한다. 0.971에서 추가됐다.
- 수송 팩토리(`ClientCampaignTransport.Make`)는 같은 `InstallDefaults`를 공유하므로 두 항목을 자동으로 공유한다. 새로 만든 본체가 없다.
