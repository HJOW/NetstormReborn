# 튜토리얼 진행 조건과39개 번역 키

WB-TUT-1 / WB04-E1386, 2026-11-27, HJOW-Athlon. 조건·문구 단위 완료이며 화면 표시/앱 수명은 TUT-2~4에서 이어간다.

`core/tutorial-objective.js`는 실제 MissionFrameGate의 번호·단계·시작·데모·잠금·타이머와 공식 미션 이름을 읽어 영어 번역 키를 반환한다. CP1371 카탈로그와 같은40단계이며 행동38키와 공통 대기1키다. Tutorial2 F/H·Tutorial5 C에서만0이 아닌 지연 타이머를 대기로 해석하며 모든 단계의 잠금 예약도 대기 문구를 사용한다. `Advance`·승패·난수·SP·기존 조건 판정기를 호출하거나 상태를 수정하지 않는다.

기준선1313 이후의 사용자 추가 기능이므로 `tools/port-map.mjs`의 별도 목록에 사유를 기록했다. 고정 기준선1,007단위의 이식 완료량이나 기존 원본 화면 일치량에는 가산하지 않는다.
