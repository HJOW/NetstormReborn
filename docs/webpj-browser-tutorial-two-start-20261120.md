# 브라우저 Tutorial2 진입 (WB04-E1010)

미션 진입 제한에 두 번째 Tutorial을 추가해 원본 목록의 잠금 해제 상태와 같은 Guide·Session·Tutorial2 단계 판정기를 사용한다. 기존 미션 진행 중 새 월드 교체는 여전히 거부한다.

테스트 저장소에 Tutorial1 완료 값을 넣어 실제 목록의 두 번째 행을 열고, Chromium에서 로그인과 미션 안내를 거쳐 안내를 닫은 뒤 게임 시계 5초 이상 및 월드 프레임이 진행되고 페이지 오류가 없음을 확인했다. 원본 Tutorial2 단계 관측과 앱 Node 검사 7건이 통과했다. 첫 시도는 선행 미션을 완료하지 않아 행이 잠긴 것을 확인했고 이후 올바른 진행 값을 준비했다. Tutorial2 실제 목표 수행 및 자연 완주, 다음 미션과 HUD는 남았다. E998 고정 Node 26 전체 6,558건 통과, E1002 고정 Node 26 전체 회귀 실행 중이다.
