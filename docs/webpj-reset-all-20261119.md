# WB04-E863 웹 설정·진행 초기화

웹 Options 메뉴의 마지막에 `Reset All`을 추가했다. 영어·한국어 확인 창에서 취소하면 아무것도 변경하지 않는다. 확인하면 게임이 현재 소유한 `netstorm.settings`와 `netstorm.progress`만 삭제하고 앱을 정리한 뒤 페이지를 새로 불러온다. 원본 화면 비교 모드에는 새 행을 넣지 않는다.

저장소 읽기나 삭제가 실패하면 콘솔에 원인을 기록하고 사용자에게 안내하며 앱을 유지한다. 두 번째 삭제가 실패하면 첫 항목의 복원을 시도한다. 저장소가 복원까지 거부하면 완전한 복구는 보장할 수 없다. 나중에 게임 소유 영구 저장 키가 추가되면 초기화 범위에도 추가해야 한다.

집중 검사는 취소·확정·최초 실행·다른 앱의 저장값 보존·부분 실패와 차단을 확인했다. Chromium 실제 메뉴 검사에서도 확인 취소와 확정, 새로고침 후 환영 창과 다른 저장값 보존을 확인했다. Node v26.13.0 전체 회귀 6,392건은 실패·취소·건너뜀 없이 통과했다. 최초 집중 검사에서 한국어 메뉴의 예상 목록이 새 항목을 빠뜨려 수정했고, 최초 브라우저 검사의 잘못된 설정 접근자도 고친 뒤 다시 통과했다.
