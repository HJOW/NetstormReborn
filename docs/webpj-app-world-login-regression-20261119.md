# 앱 World 로그인 회귀 교정 (WB04-E958)

E954 기준 격리 Node v26 전체 회귀는 6,526건 중 6,525건 통과·1건 실패·건너뜀 0이었다. 실패한 기존 `Netstorm Client World: 실제 Guide Fort 설치와 로컬 로그인 수명` 검사는 앱에 Gump를 만들지 않은 채 E951에서 추가된 실제 HUD 모드 장치를 호출했다. 이후 E952 진행 창과 E954 Renderer가 필요해진 점도 같은 독립 검사 환경에서 누락되어 있었다.

이 검사는 실제 메뉴 자산·Gump·팔레트·Screen·Renderer를 초기화하도록 교정하고, 시험용 카메라·표면·소유권·입력 큐 대역을 제거했다. 실제 시작 진행 창 표시와 로그인 완료 뒤 닫힘, 원본 카메라 적용 및 기존 Session 반납도 검사한다. 일부 소리·AI 외부 장치는 여전히 검사용이므로 완전한 브라우저 미션 플레이 검증은 아니다. 첫 교정에서 옛 `battlePalette: undefined`가 실제 장치를 가려 실패했고, 이를 제거한 뒤 진행 창이 Ready에서 닫히는 실제 수명에 맞춰 검사를 수정했다.

검증: 실패했던 검사와 실제 앱 State7 로그인 검사 2건, 요청 프레임·진행 창·앱 장치 연관 검사 11건이 Node v26에서 통과했다. Session Load 전체 파일 검사를 별도 실행 중이다. 교정 커밋을 고정한 Node v26 전체 회귀와 Node v22 정기 전체 회귀를 순서대로 다시 실행해야 한다.
