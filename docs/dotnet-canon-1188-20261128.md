# 1.188 State UI 정리와 메뉴 별칭 반납

State 정리에 전달할 실제 UI 입구를 제품 호스트에 마련했다. 현재 트리의 보존 종류 이외 Gump를 지연 삭제하고, 별도 정리 단계에서 실제 수명을 정리한 뒤 해제된 메인 메뉴 버튼·숨김 별칭만 반납한다. 이미 해제된 버튼은 제어점·경계 조회에서 없음으로 반환하며 메뉴 그리기에서도 사용하지 않는다. 살아 있는 버튼은 보존한다. 원문 `UberGump::KillGumpsForState`·`CleanupGumpsForState`의 분리된 순서에 대응한다.

실제 메뉴 버튼 삭제 뒤 조회·그리기, 공통 트리 수명 및 기존 State 정리 관련 집중 검사 **11/11 통과**다. 테스트 분석기의 새 경고를 수정한 뒤 같은 집중 검사를 다시 통과했다. 1.186a Client 전체 회귀의 실행본을 건드리지 않도록 `extracted/dotnet-1188-artifacts/`에 별도 빌드했다.

별도 제품 실행본의 `thewarbegins`·`tutorial1`·`surrounded` 진입/대기는 모두 종료0, 90프레임 DN 덤프는 1.175와 같다. 1-1의 여섯 화면은 1.183과 픽셀 단위로 같고 원본 1,392파일은 전후 불변이다. 자료는 `extracted/dotnet-state-ui-1188/`에 있다. 아직 전체 State 정리의 제품 호출·HUD 재생성·메뉴 복귀 수명은 연결하지 않았다.
