# 생산 패널 화면 크기 변경

WB04-E1034는 생산 패널의 화면 높이 변경을 원본 `RawProductionControls::Resize` 순서로 연결한다. 높이에서 하단 80픽셀을 예약하고 기존 루트를 Push·재부착해 자식을 다시 배치한다. 높이가 같으면 아무것도 변경하지 않는다.

Tutorial1 실제 Session에서 768→700→768 높이를 적용하고 기존 다리 격자의 GumpForm과 예산 등록 ID가 유지됨을 확인했다. 관련 앱 검사 4건은 모두 통과했다. 앱의 실제 화면 크기 변경 호출과 자동 설치는 아직 남아 있다. E1030 고정 Node 22 전체 회귀는 실행 중이다.
