# dotnetpj 0.922 — RU-3 NSInfo 플레이어 결선 이식

2026-11-24, HJOW-Athlon. RU-3 열네 번째 묶음이다. NSInfo 플레이어 패널 본문을 같은 실제 호스트 저장소와 외부 장치에 연결하는 생산 결선을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HostNsInfoWindows.LayoutMetaPlayer`는 플레이어 패널의 전역 조성과 후크 결선을 실제 owner로 연결한다. 같은 CS·정렬표·메타맵/인식/소유자 전역과 같은 트리 노드/Push·제목 파서/맞춤·요청·내용맞춤·단추 활성/값을 빌린다. 슬롯 랭크는 `BattleOptionSlots`의 실제 표 변환을 쓰고 랭크 그림은 아이콘 틀 개수를 아는 호출 측 장치가 공급한다.
- 제목 플래그 상자는 노드 값을 빌린 뒤 배치 마침에 되돌린다. 루트 경로와 같이 배치 중 노드 직접 읽기가 없으므로 단순 보관·되돌리기로 충분하다. 미연결 장치는 일반 성공으로 꾸미지 않고 명시 실패한다.
- `RankPicture` 장치를 `HostNsInfoDevices`에 추가했다. 아이콘 틀 개수는 자산표가 있는 생산 결선에서 공급하며, 그 전까지 미연결 호출은 명시 실패한다.
- `AppendDefault`는 노드의 현재 문맥 사본으로 추가한다. 원문 기본 문맥과 같은 자리이며 노드당 문맥이 하나뿐인 DN 구조에 맞춘다.
- 배틀 패널 결선과 후크 합성(송신·음향·메뉴 공장·중앙 카메라)은 후속 단위에서 잇는다.
