# 1.159 실제 Client 소유자 이름 조회

이미 이식된 `RawPlayerIdentity.NameForOwner`를 기존 `ClientChatIdentityRuntime`에서 현재 Player·로컬 이름·메타·채팅 기록으로 호출하고 원본 실패 대체 이름 `SOMEONE`을 연결했다. 로컬 이름, Player 이름과 구독자의 현재 변경 및 부분 완료 실패를 포함한 실제 Client 집중5/5가 통과했다. 이 getter는 아직 객체 정보 제품 메뉴에 연결되지 않았고 게임을 실행한 단위도 아니다.

작업 중 기존 식별자 구현과 검사를 잘못 중복 작성한 것을 발견해 두 파일과 불필요한 fixture 프로젝트 변경을 즉시 원래 상태로 되돌렸다. 이를 새 구현이나 통과 근거로 사용하지 않는다. 1.158의 Client 전체 회귀 실패에 대한 수정 후 재실행은 여전히 필요하다.
