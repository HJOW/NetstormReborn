# webpj 문자 편집 Gump 원본 관측 연결 (WB04-E483, 2026-11-15)

3.8절 이월 목록의 `text-entry-gump`를 원본 10.78 독립 x86 관측 **2,292행**(1,146입력 × 두 정밀도)에 대조했다. 2,292행 모두 첫 실행에서 일치했고 이식 결함은 나오지 않았다. `PORT_MAP`과 모듈·시험 머리의 "전용 PE fixture 없음/cpppj에도 직접 시험이 없다"는 오기였다.

## 비교한 것

`tests/text-entry-gump-native-fixtures.test.mjs`가 cpppj `TextEntryGumpTests`의 장치 구성을 옮긴다. 앞 13열(입력)만 장치·노드·버퍼에 공급하고 뒤 10열(관측)은 비교에만 쓴다.

- **13개 진입**: handle(1,724)·console(240)·draw(140)·scroll(100)·idle(24)·excluded(16)·construct(12)·consoleConstruct(12)·attach(6)·horizontal(6)·destroy(4)·setText(4)·append(4).
- **입력 구성**: 원문 격리 주소 토큰(노드 `0x01009000`·버퍼 `0x01001000`·Slider `0x0100a000`/`0x0100b000`), 노드 48필드(float32/float64 비트·signed 필드·글자 문맥 8DWORD), 편집 버퍼 10DWORD, 기존 할당 블록 전체(가드 바이트 포함), 제외문자 외부 주소(`0x01006000`), 시계 값 열, 자동완성 결과, 수신 대상 결과, 할당 fill 바이트, clipboard 입력.
- **명시 장치**: 노드 생성/배경/Slider 생성·부착·push/redraw/idle/bubble, Slider 범위/페이지/위치(기록 + 위치 쓰기만), 시계(64비트 double 비트 기록), 글자 측정(바이트당 `4 + 바이트 % 5`, 높이 14), 화면 위치 `(17, 23)`, 배경/글자/사각형 출력, 제외문자 저장소, 자동완성/제출/수신 대상, 단언, 기본 소멸.
- **비교 항목**: 노드 48필드, 두 Slider 11필드, 편집 버퍼 10DWORD, 할당 블록 전체, clipboard 출력, 외부 호출 순서·인자, 반환값, 스택 정리량(4 + 인자 × 4)과 native 명령 수.
