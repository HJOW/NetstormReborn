# 하드너 주문 대상 본문 이식 (WB04-E551)

`o/RawBombHardener`(원문 10.78 0041fe90 자격·0041feb0 다리 강화 효과)를 `webpj/www/core/raw-bomb-hardener.js`로 옮겼다. 주문의 공통 시전/패킷(`raw-bomb-activation.js`·`raw-bomb-effect.js`)과 분리된 대상 가상 함수 본문이다.
기준선 `225553df`와 현재 cpppj 소스가 같음을 확인했다. 같은 raw 풀·현재 188칸 TYPE/프레임 표·공유 `GameRandom`·`SquidFrame`(4acee0 프레임 지정)을 빌리고 별도 월드/난수 상태를 만들지 않는다.

## 옮긴 범위

- `mayTarget(target)`(41fe90): 대상의 현재 genus 중 다리 비트(4)를 그대로 돌려준다. HP·동맹·이미 강화됨은 자격에 더하지 않는다.
- `apply(parent, target)`(41feb0): 대상이 부모의 운반체 WORD(+12)이면 끝낸다. 아니면 현재 방향(`pathSide`, signed BYTE)의 강화 프레임 후보(side 일치·변형 `'P'`·flags 0x40)를 프레임 코드 순서대로 최대 256개 모아,
  하나라도 있으면 난수를 한 번 쓰고 고른 프레임을 지정한 뒤, 후보가 없어도(난수/프레임 없이) 플레어(target, 1, 2)를 호출한다. 플레어가 연결되지 않았으면 이미 수행한 프레임 지정과 난수 소비를 되돌리지 않고 명시 오류로 알린다.

## 시험

`webpj/tests/raw-bomb-hardener.test.mjs` 3건:

1. 원본 관측 `bomb-hardener-x86.tsv` **21행**(자격 E 5·적용 A 16): 자격 마스크·후보 상한·난수 상태·QA 제외·검색 실패 플레어·프레임·효과 순서(S=표시 갱신 두 번째, F=플레어). **첫 실행에서 일치**했다.
2. 계약: 판본/187칸 표/풀 불일치 거부, 플레어 미연결 시 이미 수행한 효과 보존, 현재 TYPE 범위.
3. 변형 확인에서 드러난 미관측 경계: 현재 프레임(+36)을 읽는 위치와 방향, 운반체 WORD 의 높은 바이트(대상 SID 255 초과), 판본 검사의 단독 거부, 189칸 표 거부.

**변형 확인:** 상수·오프셋·검사·후보 조건·난수 한도·효과 인자 30가지를 넣어 28가지가 시험에서 잡혔다(처음 7가지가 살아남았고 3번 시험으로 5가지를 잡았다). 남은 2개는 동등 변형이다:
`read`의 `>>> 0`↔`| 0`과 프레임의 `| 0`↔`>>> 0`은 4바이트 프레임 값이 2^31 이상이면 두 경우 모두 프레임 표 범위 오류가 되어 같다.

`webpj/tests/fixtures/manifest.json`에 `bomb-hardener`(21행) 항목을 추가했다.
