# 앱의 Client 프레임 시계 (WB04-E877)

브라우저 앱이 각 `init` 수명에 `ClientLocalStateGlobals`와 `ClientFrameClock`을 만들고 실제 프레임에서 화면 입력·갱신 전에 게임 프레임을 고정한다. 표시용 rAF 시계는 그대로 유지한다. 앱 `destroy`는 두 Client 객체 참조를 반납하며 다음 `init`은 새 객체를 만든다.

탭 숨김은 게임 시계에 정지 한 겹을 넣고 복귀 때 그 겹만 제거한다. 중복 가시성 통지는 정지 깊이를 다시 바꾸지 않으며 이미 다른 이유로 정지된 게임도 복귀 후 그 정지가 남는다. 최초 `init` 때 숨겨진 문서도 같은 방식으로 정지한다. 벽시계는 계속 진행한다.

집중·연관 Node 검사 17건과 실제 Chromium 시작·종료·재초기화·기본 화면 검사 2건이 통과했다. 실제 앱의 미션 Session·Kernel, 게임 입력과 렌더러는 아직 연결하지 않았다. 따라서 이번 변경이 미션 플레이 가능이나 원본의 전체 프레임 순서·난수 일치를 뜻하지는 않는다. 원본 게임이나 별도 게임 창은 실행하지 않았다.

정해진 주기에 따라 Node v26.13.0 전체 회귀 6,420건이 실패·취소·건너뜀 없이 통과했다.
