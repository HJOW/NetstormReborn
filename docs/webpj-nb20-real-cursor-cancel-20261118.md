# WB04-E804 실제 건설 조각의 사제 선택 취소 검증

E801의 NB20 관문을 실제 TheWarBegins 로컬 Session과 `CampaignGameWorld` 입력으로 검증했다. Session은 Login/Ready까지 실행하고 워크샾 기술과 SP 3,000을 시험에서 직접 준비했다. 실제 사제 메뉴에서 워크샾 건설을 선택해 같은 커서가 Form과 미리보기들을 취득한 뒤 P 입력을 보냈다.

커서의 실제 취소가 Form과 모든 미리보기 SID를 반환하고 잠금을 복구하며, 비용을 차감하거나 패킷을 전송하지 않고 같은 사제를 선택하는 것을 확인했다. 최초 집중 검사에서 기술을 준비하지 않아 `NoTechTheme`으로 거부되는 것을 확인한 뒤 기술을 준비해 통과했다. 실제 게임 시작과 UI에서 기술을 얻는 경로 및 브라우저 조작 검증은 포함하지 않는다. 구현은 변경하지 않았다.

검증: 실제 Session 집중 검사 통과, 대응표 1,160행 오류 0, Node v26.13.0 전체 6,296건 통과(실패·취소·건너뜀 0). E803 Node v22 전체 검사 뒤 v26 회귀 1/8회다.
