# 한국어 및 원본 관측 자료 회귀 검사 교정

WB04-E1060은 E1057 고정 Node 26 전체 회귀 6,577건의 실패 2건을 확인했다. 메뉴의 모든 필수 번역·중복·UTF-8 검사는 유지하되, TYPE 이름과 정보 서식처럼 원본 자산에서 동적으로 들어오는 미션 번역을 메뉴 라벨 집합으로 제한하지 않는다. 공통 유닛 용어와 미션 서식은 별도 `korean-mission.test.mjs`에서 검증한다.

도움말 HTML과 장면 음악의 보호 원본 관측 파일을 이식 추적 목록에 등록하고 해시·소비 검사·근거 소스를 기록했다. Node 22와 26에서 한국어·도움말·장면 음악·추적 목록 관련 31건이 각각 통과했다. 전체 회귀를 수정된 고정 상태에서 다시 실행해야 한다.
