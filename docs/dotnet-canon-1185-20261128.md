# 1.185 State UI 지연 삭제 장치

CPP `RawButtonControls::KillStateGumps`와 원본 00540426의 초기 종류11에 맞춰 실제 `GumpButtonTree`에 현재 보존 종류와 지연 삭제 입구를 두었다. 기존 `GumpLifetime.KillExceptType`에 같은 필드를 참조로 전달하므로 각 등록 칸 처리 시 현재 종류를 다시 읽고 루트는 제외한다. 삭제 예약과 실제 정리는 분리한다.

실제 공통 트리에서 종류11 보존·다른 종류의 지연 삭제·Cleanup 뒤 해제·현재 종류 변경 후 재정리를 검증했고, 기존 원본 reset 관측과 수명 검사 포함 **5/5 통과**다. 진행 중인 1.184 정기 회귀의 바이너리를 변경하지 않도록 `extracted/dotnet-1185-artifacts/`에 별도 빌드했다. 제품 State 전환에 이 장치를 아직 호출하지 않으며 HUD 부모 교체·메뉴 별칭 정리와 전체 전환을 함께 연결해야 한다. 새 게임 실행은 이 단위에서 하지 않았다.
