# 실제 Client 중첩 메뉴 작성

WB04-E1064는 `ClientMenuGump`에서 기존 원본 controlled 스택의 현재 하위 메뉴를 꺼내고 부모 항목·구분선·항목 수를 사용할 수 있게 한다. 실제 로그인된 Tutorial1 Session과 같은 Gump 트리에서 자식 등록 ID, 건설 명령·인자, 부착과 자식 정리를 확인했다. 사제 우클릭과 건설 선택의 앱 연결은 아직 남았다.

Node 22·26의 실제 미션 프레임·사제 메뉴 원본 관측·메뉴 관련 검사 각 27건이 통과했다. 최초 테스트 제목에 원본과 달리 줄바꿈을 빠뜨려 StyleTextBuffer의 미완료 줄 원본 동작으로 조각 하나가 남았다. 실제 사제 메뉴의 `Construct Building\n`을 사용하도록 교정하여 정리를 확인했다.

E1060 고정 전체 회귀는 Node 22와 26 각각 6,580건 통과, 실패·건너뜀 0이다. 이 결과는 이후 변경을 포함하지 않는다.
