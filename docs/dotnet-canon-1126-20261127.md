# dotnetpj 1.126 — 일반 객체 SHP 별칭 조회

2026-11-27, HJOW-Athlon. `SpriteAssetViews.BindShapes`에 cpppj `MakeSpriteAssetShapes`의 현재 그림자 별칭 조회를 이식했다. 조회마다 현재 `ShadowShapeType`을 읽으며 TYPE 70부터 SHP 블록으로 변환한다. 실제 블록 수와 자산 범위 밖 입력은 명시 오류로 남긴다.

- 기존 `SpriteDraw`와 새 자산·별칭 검사는 **17/17 통과**, 실제 SHP의 처음·마지막 자산 블록과 부족한 블록 수를 추가한 자산 검사 재실행은 **4/4 통과**했다. Release 빌드 오류 0·기존 경고다. 최초 테스트 빌드는 `ShapeDatabase` 이름 충돌로 실패했고 화면용 형식을 명시했다. 다음 실행은 빈 SHP 검사 입력이 실제 파서에 거부돼 16통과·1실패였고, 유효한 4블록 자료로 고쳐 재검증했다.
- 아직 제품 출력에 연결하지 않은 기반 코드다. 같은 SID·TYPE별 가상 프레임/추가 Draw, 실제 색표·상태 장치와 kind 0 제출 연결은 R5-3d에 남는다. 이번에는 게임 실행이나 전체 회귀를 수행하지 않았다. 최신 전체 회귀1.120과 대표 덤프1.124는 유지한다.
