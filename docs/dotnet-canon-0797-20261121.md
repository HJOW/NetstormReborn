# dotnetpj 0.797 — 경로 탐색·시작·정리 하위와 실제 Host 검색 공유

2026-11-21 · HJOW-Athlon · 제품11.01 · .NET10 Release. 사용자 요청에 따라 이 단위를 마치고 문서·커밋 후 목표를 일시 중지한다. 전체 목표는 미완료다.

## 구현 범위

`RawPathSearch.cs`와 `.Cells.cs`에 Source의 BFS/역추적·Graph·실제 Bridge 접합을 이식했다. 현재 spot/프레임/TYPE/방향 전제를 읽고, 이전 꼭짓점·방향·시각 prefix와 미사용 큐 흔적을 보존한다. signedWORD 거리표와 두BYTE 큐는 기존 `RawSurfaceStorage.PathSearch`의 같은 Work를 빌린다. Initialized는 실제 유효 셀 검색에서 거리표를 지우는 위치에서만 켠다. PATCH 정책은 같은 Gameplay.PatchDiagnostic의 현재 DWORD를 읽으며 CD에는 이 분기를 추가하지 않았다.

`RawPathStart.cs`와 `.State.cs`에 목적지 clamp/사제 스냅, 같은 종류의 기존 경로 제거와 목표 보존, 실제 Init→명령DWORD→실패 재귀→Prepare→Host 부착→부모 통지를 이식했다. 기존 실제 SquidFrame/ContainedLookup을 사용하고 현재 전역은 UIntBox/BoolBox를 빌릴 수 있다. helper/꼬리 인자를 WORD/BYTE로 미리 좁히지 않는다. 사제 통지는 마지막 간헐천 선택, 두 Regular 사건의 반복 검색/삭제, 현재 metadata 기본 프레임을 처리한다.

`RawPathCleanup.cs`와 `.State.cs`에는 실제 Process 공간 접두 이후의 helper 예약, 너겟/Graph 조회, 제단 의식 요청, 현재 권한에 따른 helper 환불/삭제 요청과 두 finder를 이식했다. 일반 지면의0.9999f와 다른 원문 finder bias를 유지한다. 실제 예약/의식/환불/삭제 장치의 전체 결선은 후속이다.

`HostSession.PathSearch.cs`는 기존 BindSquidPacketDevices에서 같은 실제 Pool/hash/spot/TYPE/WorldFrames와 장기 Work·현재 진단을 연결한다. 세션 반납은 참조만 닫고 Work/Initialized를 초기화하지 않는다. 이것은 전체 RawCampaignPathBindings·Motion·30h 명령 설치 완료가 아니다. `RawPathProcess.Attach`는 Host에 소유권을 넘기기 전의 Pool/부모TYPE/기존 제거 실패 때 전달받은 객체를 Dispose하여 Source unique_ptr 수명을 보존한다.

같은 최종 빌드의 `thewarbegins`·`tutorial1`·`surrounded` 세 시작은 모두 종료0이며 전체 덤프 바이트/지표가 마지막 전체 기준0.796과 같다. 원본1392파일은 실행 전후 불변이고0.796 전체 해시 장부와도 같다. 실제 포획/희생·특정 적 공격·시나리오 승리는 실행하지 않았다.

## 남은 작업과 일시중지 인계

1. **전체 Cleanup 어댑터 미완료.** C# RawConstructionPlace가 없어 Source의 MakePathCleanupHooks를 아직 설치하지 않았다. 실제 건설 환불을 먼저 이식하고 같은 carrier/anchor/host/place를 연결한다. 기존 SquidReward.Refund는 다른 몸체이므로 대체하지 않는다.
2. RawPriestHalt·RawPriestArrival·RawCarrierArrival과 선행 하위를 이식한 뒤 같은 실제 Host/Motion·30h에 Start/프레임/도착/정리/전송을 연결한다. 현재 고정 수신9본문/남은17과 전체26F·Root 설치는 그대로 남았다. 구 RawCampaignSession 또는 일반 삭제 Pre/Post로 전체 가상 삭제를 대신하지 않는다.
3. CD 실제 Host72프레임/도착(0.795), 이번 CD Start256,1037 애니메이션2016관측은 미검증이다. CD171TYPE의 하위 지원이 먼저 필요하다. pathstart 전체512행 파일을 등록한 것이 CD256 통과를 뜻하지 않는다.
4. Host.Attach가 Kernel에 등록한 뒤 예외를 낼 때의 기존 소유권 문제는 별도 미검증이다. 이번 Attach의 선행 실패 Dispose 변경이 그 문제까지 고쳤다고 간주하지 않는다.

전체 목표는 [LEFT_JOBS.dotnetpj.md](../LEFT_JOBS.dotnetpj.md)의 순서를 따른다. M1은 마지막 전체 **0/34**이며 새 Native 경로는 아직 플레이할 수 없다. 다음 단위는0.798, 다음 전체회귀는0.800이다. 사용자 수동 플레이 확인 항목은 유지한다. 디컴파일·CPP Source·보호 원본을 수정하지 않았다.
