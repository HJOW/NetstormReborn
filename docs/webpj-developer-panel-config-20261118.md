# WB04-E746 개발자 추적 설정과 전투 패널 크기

`31h`의 `setTraceLevel`/`stl`과 `combatGumpColsRows`/`cr`를 현재 Session의 Config·미션 설정·입력 큐에 연결했다. 추적 수준은 원본 바이트 문자열을 NUL과 함께 넘긴다. 패널 크기는 원본 범위로 제한하고 면적이 8을 넘으면 타이머를 끈 뒤 현재 명령 DWORD와 두 값을 큐에 넣는다. 입력 큐가 없으면 앞선 설정은 유지하고 해당 위치에서 오류를 낸다.

근거는 기준선 `225553df`의 `RawCampaignSession.cpp`와 `RawGameAuxState.h`이며 기준선 이후 두 파일의 변경은 없다. 새 `developerCombatResizeCommand`의 주소 `0054288c`와 초기값 `02000065`는 보호 원본 PE를 읽어 기존 GameAux 전체 초기값 검사에 포함했다. 새 원본 fixture는 추가하지 않았다.

독립 검사에서 바이트 전달, 입력 기본값·제한·타이머·장치 누락 시 선행 쓰기를 확인했다. Tutorial 1 Session의 실제 `31h` 분배기에서 같은 GameAux와 입력 큐 호출을 확인했다. PE 대조를 포함한 집중 검사 49건이 통과했다. 실제 게임 화면의 패널 변경은 아직 검증하지 않았다.

Node v26.13.0과 v22.23.3 전체 회귀를 순차 실행해 각각 6,234건이 통과했다. 대응표 오류는 0건이며 다음 Node v22 전체 재검사 주기는 0/8회다.

다음은 `31h`의 나머지 개발자 명령과 내부 로그인 서버 후반·응답 왕복이다. Native 분기, 행 base 뒤 변경 판정 및 앱 미션 연결도 남아 있다.
