# 실제 미션 도움말 TYPE 정보

WB04-E1053은 미션 Help 명령의 TYPE 번호에서 현재 Session의 정보 HTML 생성기를 만들고 기존 도움말 창의 별도 정보 본문에 연결한다. 이름·설명·체력·원소·사거리·피해·비용·요구 에너지는 실제 타입, 무기·체력 장치, AST 후처리와 현재 번역·설정에서 읽는다. `<info>`가 없는 원본 주제는 별도 패널을 만들지 않는다.

Tutorial1 실제 격자에서 다리 메뉴 Help 명령을 검사한 뒤, 같은 실제 입력 큐로 썬더 팩토리 TYPE Help를 요청해 정보 본문을 확인했다. 원본 다리 주제는 `<info>`가 없어 최초에 모든 TYPE이 패널을 갖는다고 가정한 검사가 실패했으며, 원본 앵커를 확인하고 교정했다. Chromium에서는 실제 마우스로 다리 도움말을 열고 닫은 뒤 시험 코드로 썬더 팩토리 명령을 큐에 넣어 정보 본문의 행과 닫기를 확인했다(1건 통과). 관련 Node 26 검사 30건과 E1047 고정 Node 26 전체 6,568건이 통과했다.

TYPE 그림 및 그림 유무별 원본 배치는 아직 미연결이며 현재 정보가 있는 경우 본문을 아래로 내린다. 썬더 팩토리 Help를 실제 생산 메뉴에서 선택하는 브라우저 경로와 자연 미션 완주 검증도 남았다.
