# dotnetpj 0.935 — 분배 부모 송신 관찰·버전 응답 결선 검증

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 공통 패킷 분배 부모에 설치된 미션 송신 관찰기와 버전 응답·가변 길이 관찰기의 등록 행을 검증했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 검증 내용

- `ClientPacketDispatch.Build`가 설치하는 네 미션 송신 관찰기(`0x2a`·`0x2b`·`0x67`·`0x81` 순수 패킷 관찰기)는 수신 F를 바꾸지 않는다. 0.935에서 추가된 검사로 고정했다.
- 버전 응답 `0x0b`(관찰기·버전1·길이 가변·고정 `0x004b3af0`)과 가변 길이 관찰기 5종(`0x3f`·`0x30`·`0x7a`·`0x5f`·`0x7d`, 관찰기·버전1·길이 가변)의 등록 행을 같은 분배기에서 대조했다. 0.934의 기본 18행과 같은 묶음의 기존 설치를 밀지 않는다.
