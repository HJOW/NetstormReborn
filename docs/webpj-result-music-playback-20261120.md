# 승리·패배 음악 재생

WB04-E1061은 원본 `SoundMusicSelection`의 분기에 맞춰 `fanfare.mus`와 `defeat.mus`만 Web Audio에서 한 번 재생한다. 다른 곡은 기존대로 반복한다. 자연 종료 시 현재 소스만 해제하고, 이전 소스의 늦은 종료는 새 소스에 영향을 주지 않는다. 재생 요청명은 옵션을 다시 켤 때 쓰도록 보존한다.

Node 22·26에서 음악·자산 적재·메뉴 및 원본 장면 음악 관측 관련 22건이 각각 통과했다. 첫 실행 명령은 저장소 루트에서 테스트 상대 경로를 잘못 사용해 실패했으며 webpj 디렉터리에서 다시 실행했다. 이 단위는 재생기의 반복 정책만 수정했으며 장면 음악의 실제 선택, 비동기 채널·앱 연결과 원본 결과 화면은 아직 남았다.
