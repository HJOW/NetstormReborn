# 도움말 TYPE 정보 HTML

WB04-E1049는 전용 도움말 정보 패널의 원본 제목, 원소, 클래스, 체력, 사거리, 피해, 스톰파워 비용과 요구 에너지 HTML을 현재 TYPE·번역·Config 조회로 만든다. 원본처럼 값을 분기와 서식 시 다시 읽고 0, 특수 피해, 무적, NaN 및 정수 절삭을 구분한다. 앞 단계에서 복원한 마나 프레임도 사용한다.

독립 원본 관측의 TYPE 프로필 8종·패널 상태 2종, 총 16행에 대해 스트림 HTML과 실제 중첩 HTML 파서의 스타일 출력을 대조했다. 한글 도움말·그림을 포함한 관련 Node 26 검사 35건과 확장한 원본 스타일 관측 검사가 통과했다. 현재 미션 TYPE/AST·별도 정보 패널 및 앱 도움말 표시 연결은 남았다.
