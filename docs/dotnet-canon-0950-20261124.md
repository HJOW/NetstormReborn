# dotnetpj 0.950 — 0x66 로컬 서버 검색 도우미 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 0x66 로컬 서버 검색의 송신 패킷 작성과 검색 기한·재송신 순서를 같은 장기 장치에 연결했다. 0.949의 0x66 수신 본체와 테스트 장치를 공유하고 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientLocalServerSearch.MakePacket`은 0040ae10 전체를 이식한다. header 뒤 두 DWORD만 caller 값으로 쓰는 12BYTE를 작성한다. 0.950에서 추가됐다.
- `Announce`·`Broadcast`·`Begin`·`Start`·`Continue`는 004b3fc0/004b4050/State34·35 전체 순서를 이식한다. 세 번 가상 송신, 현재 토큰 재송신, 열기→srand→네 번 rand lowBYTE 토큰 저장→첫 송신, 안내→첫 검색→5초 기한→0.500~0.599초 재송신 기한→팔레트→즉시35, 재송신/만료/서버 창 확인/즉시37와 다음35를 그대로 보존한다. 0.950에서 추가됐다.
- 실제 전송·창 검색·팔레트 결선은 세션·R5 메뉴 연결에서 잇는다.

## 검증

- Release 테스트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 9건(미연결 명시 실패·패킷 header·세 번 송신·토큰 송신·열기 재시드 토큰·전체 순서·재송신 기한·만료 창 없음·만료 창 있음 유예)은 통과/실패 0이다. 로컬 서버 발견·챌린지 로그인 이웃 검사를 포함한 23건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0950-*/`의 각 실행 로그와 요약이다.
