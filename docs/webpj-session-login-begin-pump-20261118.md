# WB04-E714: 미션 Login 시작과 전송 펌프

`RawCampaignSessionLogin.inc`의 미션 `Begin`에서 같은 Client subscriber와 Player·전송을 사용하도록 연결했다. 현재 연결 재배치와 방송 peer, 동맹 요청 패킷, 로컬 전송 여부 및 운반 요청은 실제 Session 장치에 연결한다. 미션 요청의 Zone을 소비하고 시계 수신을 설치한 뒤 독립 상태 8 또는 준비된 상태 7 공통 확정과 즉시 8을 실행한다. 외부 부모가 진행 중인 경우에는 후반만 실행한다.

`Pump`는 현재 벽시각을 기록하고 같은 전송의 flush, 시계, poll, 독립 타이머를 원본 순서대로 호출한다. 선택된 장치가 누락되면 실제 선택 위치에서 중단한다. 일반 LAN 시작은 기존 캠페인 전용 소유자의 웹 제외 범위이며, 요청과 외부 상태 7의 실제 부모·수명은 아직 앱에 연결되지 않았다.

집중 검사 85건에서 독립 Zone과 상태 8 접속, 요청 소비·상태 7/8 확정과 UI 호출 순서, 공유 로컬 전송 값, 동맹 요청 바이트, 빈 실제 전송의 송신·시계·수신 순서를 확인했다. 서버의 27h 로그인 처리·응답 왕복, 실제 Session Load 연결, 외부 전송 수명·Native 분기와 기준선 뒤 32커밋 전체 판정은 남는다. 새 검사에서 공중 유닛 전용 생성·행동이나 사제 포획·희생·승리는 실행하지 않았고, 실제 게임과 브라우저 창도 실행하지 않았다.
