# dotnetpj 1.105 — 정기 전체 회귀

2026-11-27, HJOW-Athlon. 1.104 제품을 기준으로 세 테스트 프로젝트의 Release 출력을 갱신하고 각 검사 출력에 존재하는 Assets/Core/Client/Game DLL을 실제 게임 폴더의 해당 DLL과 SHA-256으로 비교했다. 비교 가능한 DLL은 모두 같았다.

- Assets 383건, Core 4,119건, Client 2,899건이 통과했고 실패는 없다. 합계 **7,401건 통과**다.
- Client TRX에는 `WindowsSoundHardwareTests.MutedNativeDeviceLoadsDuplicatesAndRestoresAfterReinitialize` 1건이 **NotExecuted**로 기록되어 실제 하드웨어 검증 성공으로 세지 않는다. 결과는 `extracted/dotnet-1105-regression/`에 있다.
- 이 단위에서는 게임을 새로 실행하거나 34경로를 재측정하지 않았다. 1.104의 대표 세 미션 실행 및 원본 보존 결과와 기존 M1 0/34 기준은 그대로다.

다음은 공통 내용물 분리의 Native 부모 통지를 현재 세션에 연결하고 실제 부모 삭제 중 UI 중첩 통지와 생산 Form 생성·부착을 검증한다. 사제 포획 안내 본체와 실제 포획 결과, 미니맵 나머지 픽셀·전환 수명 및 채팅 실제 키 입력은 미완료다.
