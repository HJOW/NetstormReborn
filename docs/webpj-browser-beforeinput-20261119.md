# WB04-E934: 편집 요소 직접 텍스트 입력

IME 편집 요소의 `beforeinput`에서 키다운 없이 삽입된 텍스트를 원본 확정 문자 큐에 전달한다. 이미 같은 키다운 또는 조합 확정으로 예약한 후속 `beforeinput`은 같은 이벤트 턴에서 한 번만 건너뛰고, 기록을 다음 턴에 비워 같은 문자의 별도 연속 입력은 보존한다. 조합 중 본문은 기존처럼 건드리지 않는다. 지원하는 직접 텍스트 삽입에서 브라우저 편집 버퍼의 별도 추가는 막는다. 보조 입력 요소의 접근성 이름은 영어·한국어 설정에 맞춘다.

실제 Chromium textarea에서 합성 조합 확정 뒤 중복 beforeinput, 실제 영문 키와 키다운 없는 한글 직접 삽입 두 번, 포커스·정리를 확인했다. 브라우저 검사 1건과 입력·편집 관련 Node 검사 15건이 통과했다.

실제 OS 한글 입력기의 플랫폼별 사건 순서와 후보창은 아직 검증하지 않았다. 붙여넣기·음성 등 다른 inputType과 실제 미션 TextEntry 포커스 연결도 남았다.
