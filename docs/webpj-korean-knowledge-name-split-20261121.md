# 한국어 지식 카드 이름 두 줄 나눔을 바이트 길이로 (WB04-E1142)

한국어 모드에서 F6 지식 창(View Netstorm Knowledge)을 열어 보니 일부 카드 이름이 칸 안에서 잘렸다. 영어는 `Wind` / `Generator` 처럼 두 줄로 나뉘는데 한국어 `윈드 제네레이터` 는 한 줄로 그려져 양옆이 잘렸다.

## 원인

- 원본(`ShowTechnology`, 00492b60)은 카드 이름이 **바이트 수 8 을 넘으면** 마지막 공백/하이픈에서 한 번만 두 줄로 나눈다(위치 1 의 공백은 나누지 않음). 원본 문자 집합에서 한글은 글자당 2바이트이므로 5글자만 넘어도 나뉜다.
- 웹은 JS 문자열의 **글자 수**로 재서(`first.length > 8`) 8글자 이하 한국어 이름(`윈드 제네레이터` 8글자·15바이트, `아이스 캐논` 6글자)이 나뉘지 않았다.

## 수정

| 위치 | 내용 |
| --- | --- |
| `www/core/raw-knowledge-menu.js` | `displayByteLength`(ASCII 가 아닌 글자는 2바이트)와 `splitKnowledgeName` 을 내보내고 카드 작성이 이를 쓴다. 영어 이름은 글자 수와 바이트 수가 같아 기존 경계 그대로이다. |

## 시험

- `tests/raw-knowledge-menu.test.mjs`: 한국어 `윈드 제네레이터`→`윈드`/`제네레이터`, `아이스 캐논`→`아이스`/`캐논`, `썬 캐논`(7바이트)은 불분할, 공백 없는 이름은 불분할, 영어 경계(`ab cd-ef`/`ab cd-efg`)는 그대로.
- 기존 원본 관측 대조 시험과 지식 메뉴 e2e 는 그대로 통과한다.
- 한국어 모드 화면에서 모든 카드 이름이 칸에 들어옴을 눈으로 확인했다.

## 남은 것

- 위치 1 의 공백은 나누지 않는 원본 규칙 때문에 `썬 바리케이드` 처럼 첫 단어가 한 글자인 이름은 한 줄로 남아 칸 오른쪽 끝이 조금 넘친다. 원본 규칙을 따른 것이라 두었다.
