# 1.162 객체 메뉴 공통 서식

`FormatPlayerMenuText`의 고정 `%s`, `%d`, `%%`와 signed 정수, 인자 수·종류 및 256바이트 출력 계약을 이식했다. 인자 문자열에 들어 있는 퍼센트는 다시 해석하지 않으며 번역은 호출자가 수행한다. 현재 원본 좁은 문자 표현을 사용한다.

실제 새 서식 본체를 객체 정보 독립 원본 1,434행의 출력 경계에 연결해 전수 대조했다. 서식 정상·경계·오류 및 세션 정보 포함 집중5/5 통과다. 제품 메뉴 및 완전 적재 연결은 이 단위에서 하지 않았고 게임 실행도 하지 않았다. 1.161 정기 회귀는 이 변경을 포함하지 않는다.
