# 0.693 로그인 서버 패킷과 공유 이름·observer

원본 서버187입력과 fort observer10입력의 바이트 전수 대조를 포함한 **Core 집중55건 통과·실패0**이다. cpppj `RawMissionServerPackets.cpp/.h`의 Player/metadata 송수신, `RawMissionClientPackets.cpp/.h`의 공유 이름 정제·가변길이 observer를 Core에 이식하고 Net의 실제72h 등록으로 연결했다. 전체 클라이언트 수신 본체는 후속이다.

같은 Player9/Zone6바이트와 현재 전역 getter를 빌린다. 이름 정제는 연속 금지문자를 NUL까지 한 칸씩 옮기고 stale 꼬리를 보존한다. 2bh writer는 이름/구독자를 먼저 복사한 뒤 주소 callback이 바꾼 현재 flags·동맹·필드를 다시 읽는다. 실제 송신 hook은 초기 선언길이4의 전체100바이트 예약을 빌리고 실제 연결 gate 뒤 observer가 길이를 확정한다.

Metadata는 Zone bit100 관문·안내·현재 밀도 쓰기·현재 배치 조회 순서다. 배치2는 전용 중앙섬 호출 뒤 바로 반환한다. 나머지는 당시 Zone6바이트를 값형 복사해 중앙섬 하위로 보내고 생성표시와 signed predictableCount 로그를 남긴다. $Random writer는 자기 처리 뒤 현재 로컬 번호를 다시 읽는다. 큰 중앙섬 생성 자체는 외부 실제 하위이며 누락 시 선택 위치에서 거부한다.

공유2a/2b/67/81/72h observer는 수신 방향0에서 버퍼를 읽지 않는다. 송신 진단이 복귀하면 현재 필드를 원문 BYTE/WORD로 다시 읽고16비트 감김을 보존한다. Net 등록은 원문처럼72h version1/정책0·현재 observer·실제 수신기를 같은 표에 설치한다. 실제 LocalMissionTransport 양끝/집합 프레임/공유표를 통한72h 운반도 통과했다. 제품 Root 설치나 전체 Login→Ready→Start 완료를 뜻하지 않는다.

검증 근거는 `extracted/dotnet-0693/mission-server-core-final.trx`와 `core-final.log`다. 원본187입력은 전체Player1620바이트·전역·wire·외부효과 순서를 대조하고 내부 이름 함수 진입 통계 N만 trace에서 제외한다. 원본 fixture를 수정하지 않았다. 실제 callback 뒤 재조회·자기 metadata 조기 반환·누락 하위의 부분효과·현재 배치 두 경로·이름 stale 꼬리·물리 경계·관찰 진단 후 재조회도 확인했다. 기존 fort fixture의 F10입력은 새 공유2a observer에 그대로 공급했다.

첫 검사는17통과·1실패였다. metadata 관찰 검사에서 callback이 BYTE 하나만7로 바꾸고 WORD 전체가7이라고 기대했던 입력 오류다(실제65297). 의도한 WORD 변경으로 검사 입력만 고쳤다. 제품/원본 기대값은 유지했고 관련 복제·분배·로컬 운반 및 매니페스트까지 집중55건을 통과했다. fixture는350개, PORT_MAP에는 검토한8대응을 추가했다. 이번 단위는 실제 게임 창/공격 입력을 실행하지 않았다.

다음0.694는 옵션 전체 수신 부모와 클라이언트8종 수신 본체다. 이후 실제 Source/상태 전이·제품 Root·입력/도움말을 잇는다. 정기 전체 회귀는0.696이며 전체목표와M1은 미완료다.
