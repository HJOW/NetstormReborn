# WB04-E922: 브라우저 비문자 키 큐

cpppj `ClientMain::KeyEvent`의 비문자 가상 키 사건을 브라우저 Canvas 입력에서 원본 40칸 큐로 옮기는 경계를 추가했다. 방향·Home/End·Page·Insert/Delete·F1~F12 및 좌우 Shift/Ctrl/Alt를 Win32 가상 키로 바꾸고 수정자와 현재 signed 포인터 좌표, 누름·뗌을 보존한다. 조합 중이거나 문자·지원 밖 키는 이 경계에서 큐에 넣지 않는다. 기존 마우스와 같이 미션 소비자가 설치되기 전에는 적재하지 않는다.

원본 키 관측을 포함한 연관 Node 검사 12건이 통과했다. 실제 Chromium Canvas에서 방향키 누름·뗌을 큐에 예약했고 관련 브라우저 검사 4건이 통과했다.

문자·Escape 등 ToAscii/문자 경계와 IME 확정 처리는 아직 미연결이다. 폴링은 E919에 기재된 세 마우스 버튼과 보조 키만 지원한다. 실제 미션 입력 소비자와 기존 독립 메뉴 분리는 후속이다.
