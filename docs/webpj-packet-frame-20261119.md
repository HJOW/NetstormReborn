# WB04-E820 공통 패킷 프레임 분배

기준선 `225553df`의 `RawPacketFrame`을 공통 모듈로 옮겨 로컬 미션 전송에서 사용한다. 단일 패킷은 기존 분배기에 맡기고 집합은 길이·버전·시각·기록·관찰·현재 수신기 순서를 유지한다. 폐기된 CD 유효성 검증 패킷은 기존처럼 처리하지 않는다. 관찰기가 패킷과 등록을 바꿔도 저장한 타입의 현재 수신기를 선택한다.

기존 로컬 코드는 지연 표시가 있으면 집합 자체를 거부했다. 기준 구현처럼 수신기가 없는 경우는 통과시키고 선택된 수신기가 있을 때만 미구현 FIFO를 거부한다. 소켓 지연 FIFO는 웹 범위 밖이며 Native 고정 수신기의 실제 Client 수명은 4D-8에 남는다. 실제 게임 창은 실행하지 않았다.

검증: 공통 프레임·로컬 전송·단일 분배 집중 32건과 Node v26.13.0 전체 6,308건 통과(실패·취소·건너뜀 0). 집중 검사에는 로컬 전송 원본 fixture 66행이 포함된다. 대응표 1,160행 오류 0이며 E819 Node v22 전체 검사 뒤 v26 회귀 1/8회다.
