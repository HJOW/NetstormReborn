# WB04-E773 실제 건설 진행과 운반 도착

기준 `225553df`의 `RawCampaignSession.cpp` 4564~4567·6365~6367행에 맞춰 같은 Session의 현재 시각·Player로 건설을 시작하는 공개 경로와 실제 건설 운반 경로 시작을 연결했다. 설치 전 호출은 거부한다.

TheWarBegins의 실제 Pool·TYPE·지형을 사용해 TYPE 76 건설 대상을 준비하고, 건설 진행 TYPE 30과 표시 TYPE 17이 부착되는지 확인했다. 별도 검사에서는 실제 TYPE 134 건설 운반 경로를 원본과 같이 해당 지점에 시작하고 그 경로만 실행해 자연 도착·운반 삭제와 건설 진행/표시 부착을 확인했다. 이후 같은 진행 본체를 시작·종료 시각에 실행해 최대 HP·abstract 비트 해제·두 프로세스 정리를 확인했다. 직접 건설 시작과 운반 도착 두 집중 검사가 통과했다.

다른 미션 프로세스나 사용자 제한 포획·희생·특정 적 공격·승리와 공중 세 종류의 전용 행동은 실행하지 않았다. 이 검사는 격리한 TYPE 76 건설이며, E761에서 메뉴로 배치한 TYPE 85 워크샾의 전체 Kernel 자연 완공·생산과 브라우저 화면을 검증한 것은 아니다.

Node v26.13.0 전체 회귀 6,277건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 검사 오류는 0건이며 E771의 Node v22 전체 회귀 뒤 두 번째 v26 회귀다.
