# 미션 다음 유닛 선택 키 (WB04-E1001)

미션의 N 문자를 같은 입력 큐와 기존 원본 선택 키 처리기로 전달한다. 현재 Session 풀에서 로컬 소유 이동 유닛을 순서대로 찾고 실제 선택·카메라를 갱신한다. Shift 비트는 기존 본체에 보존하며 Ctrl/Alt/Meta 문자는 이 임시 입력 경로에서 가로채지 않는다.

Chromium에서 사제 이동과 12초 진행 뒤 화면을 가장자리로 옮기고 N을 눌러 실제 사제가 선택되고 카메라가 해당 유닛으로 돌아오는지 확인했다. 원본 다음 유닛 선택 410행 등 연관 Node 검사 23건과 Chromium 1건이 통과했다. 일반 입력 전체와 여러 유닛의 실제 브라우저 순환은 남았다. E990 고정 Node 26 전체 검사는 별도 트리에서 진행 중이다.
