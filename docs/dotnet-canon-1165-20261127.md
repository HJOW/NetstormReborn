# 1.165 메뉴 객체 Form 연결

제품의 controlled 메뉴가 같은 장기 물리의 실제 GumpForm 생성·소유·부착을 사용하도록 연결했다. 기존 UI의 삭제 분배와 부모 소실 통지를 공유한다. 아직 생산 정보 메뉴 호출이나 완전한 미션 적재를 구현한 것은 아니다.

실제 세션에서 두 객체 종류에 대해 메뉴 Form을 부착하고 부모 객체 삭제 뒤 Form 반환과 메뉴 정리를 확인했다. 기존 Form·생산 창 포함 집중 12/12 통과.

캠페인 1-1의 고정 입력 다섯 프레임은 1.148과 동일하고 종료0이다. 튜토리얼1·surrounded 진입과 대기 역시 종료0이며 90프레임 덤프는 1.147과 같다. 각 수집에서 원본 1,392파일은 불변이다. 결과는 `extracted/dotnet-form-1165-first/`, `extracted/dotnet-form-1165-missions/`에 있다. 1.161 정기 회귀는 이 변경을 포함하지 않는다.
