# dotnetpj 0.606 — L2 재측정과 격차 분석(R4-2 잔여 특정)

2026-11-17, VM-W11-Codex. cpppj 제품1322 기준에서 R4-2 잔여를 겨냥한 L2 일괄 재측정의 첫 관문으로 3경로(thewarbegins·tutorial1·bc1menu76)를 같은 시드로 수집·대조했다. R4 진행 중·M1 0/34·새 경로 플레이 불가는 유지한다.

## 실행 환경 복구 (이 PC 최초)

VM-W11-Codex는 AGENTS 실행 확인 예외 PC이나 물리 GPU가 없어 dn 호스트(MonoGame DesktopGL)가 그래픽 장치를 만들지 못했다(`NoSuitableGraphicsDevice`). 다음을 `extracted/` 아래에 두어 해결했으며 제품·저장소 코드는 건드리지 않았다.

- Mesa 26.2.7 MinGW x64(`mesa3d-26.2.7-release-mingw.7z`, SHA-256 `19c74aad…eb02`, llvmpipe 포함)의 `x64/opengl32.dll`·`libgallium_wgl.dll`을 dn 실행 복사본 옆에 두었다. MSVC 빌드에는 OpenGL이 없어 MinGW 빌드를 썼다.
- `Netstorm.Client.Host.exe.local` 빈 파일로 KnownDLL 리다이렉션을 걸어 앱 폴더 Mesa를 먼저 읽게 했다.
- `GALLIUM_DRIVER=llvmpipe` 환경에서 실행한다(멀티스레드 llvmpipe가 Hyper-V에서 조용히 죽으므로 강제 단일 경로로 고정한다).
- `cursors/RT_CURSOR_*.bin` 18개를 `assets/game-data/cursors/`에서 오라클 데이터 사본으로 복사했다(10-07 사본에 없던 10-12 추가분, dn 호스트 시작에 필수).
- `dotnetpj/tools/l2_compare.py`에 `--host-exe`를 추가했다(기본값은 기존 빌드 산출물, mesa 동봉 복사본 지정 가능). 기존 도구 검사 4건 통과.
- 오라클을 현행 HEAD로 재빌드했다(`NetstormCpp`·`NetstormRoot`). 구 오라클(11-10)과 신 오라클의 thewarbegins 덤프는 SP 행 1바이트(`116393616`→`2147549270`, 알려진 SP 초기화 변경)만 다르다.

## 격차 분석 — 같은 뿌리 3건

1. **소유자 스탬프 미발화(최대 격차).** isle-97에서 cpp 소유자 1/2 대 dn 0이 thewarbegins 1,353건·tutorial1 694건·bc1menu76 615건이다. 프레임 격차의 같은 슬롯(1353·694·615)과 겹친다. 요새 일반 Pop이 no-op이라 적재 중 Prefix(스탬프·프레임 재선택)가 요새 객체에 발화하지 않기 때문이다. R4-6(개별 삭제 몸체·공통 삭제·피해/해방 상위 결선과 파생 postPop 본체)이 묶여 있어 0.606에서 열지 않았다.
2. **농지 미배치.** cpp 121 대 dn 97이 152·69·67건이다. `GenerateOriginal`·`PostprocessFarms`의 `place`가 no-op이라 edgeFarm 전환·신규 배치가 없기 때문이다. 실제 결선은 R6 캐논 파이프라인(`RawCanonPlacementPipeline` 10모듈 조립)의 `MayPlace`를 요구하므로 0.605 문서의 판단대로 둔다.
3. **cpp 전용 슬롯.** 요새 섬(94)·종유석(95)·연결 객체(155) 등 적재 중 Prefix·Connect 산물과 일부 fort 객체(6·46 등)가 dn에 없다. 1의 다른 얼굴이다. dn 요새 로더의 island 스킵(`type == IslandType → return 0`)도 같은 뿌리이며, Pop 없이 슬롯만 만드는 반쪽 연결은 하지 않았다.

장부는 PostPopBase가 돌아(totalmade 부분 일치) 총계 비용원이 되는 요새 Pop이 없어 totals가 0이다. 커널 행(35 대 3)과 SP 행 차이는 정기 처리·SP 시작 흐름(R4-4·R7) 잔여다.

## 다음

0.607부터 격차별로 잇는다. 권장 순서는 요새 일반 Pop의 지원 타입부터 여는 것(지원표 밖 가상표는 명시 경계 유지, R6 본체 대기분과 충돌 금지)이며, 농지 파이프라인은 R6 조립 뒤에 잇는다. 31경로 전체 재수집은 각 조각이 끝날 때마다 같은 도구·같은 시드로 반복한다.
