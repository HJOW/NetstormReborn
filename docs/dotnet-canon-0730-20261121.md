# 0.730 실제 Client State 전역과 장기 월드 소유자

ClientStateWorldGlobals의 직접 읽기52주소·쓰기46주소, 활동22DWORD, seed.lowWORD와 아홉 double 쓰기를 같은 실제 Client 소유자에 연결했다. Template는 현재9×20헤더의 첫DWORD, Player는 매 호출의 현재 할당, TYPE는 같은 수정 가능한 레코드를 반환한다. signed/float/NaN 비트를 보존하며 bool은 쓰기 전에0/1만 허용한다. Fort/Player와 Battle/Bridge의 기존 별칭에도 같은 쓰기를 전달한다. 미등록 주소와 폭은 거부하며 바인딩 자체는 초기화·UI·재생 효과를 실행하지 않는다.

Gameplay에 실제 장기 World·MapRevision·HideBuildings를 추가하고 실제 HostSession의 WorldGlobals/IslandRevision 소비자를 같은 소유자로 옮겼다. Session 생성/반납은 이를 되감지 않는다. RawGameAuxState에는 원문의 중앙좌표2float와 IncomePrimed를 추가했다. 중앙섬/해당 SP 소비자의 전체 전환은 후속이다.

NSInfo zone·FortCoreSeed·장면 음악 기한은 실제 제품의 같은 상자를 필수 인자로 받는다. 현재 Root에는 이 세 Native 소유자와 전체 Template/공통 팝업 경계가 아직 설치되지 않았다. 따라서 이번 바인딩은 같은 실제 저장소를 연결하는 장치이며 전체 Root의 State 정리를 호출한다고 주장하지 않는다. 실제 음향 owner 동일성·현재 Surface 검증은 해당 Root 소유자 설치 때 닫는다. 빈 콜백이나 기본 성공으로 누락 장치를 덮지 않았다.
