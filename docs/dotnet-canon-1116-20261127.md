# dotnetpj 1.116 — 생산 격자 부모 소실의 Form 수명 수정

2026-11-27, HJOW-Athlon. 실제 공유 Surface·세션·공통 UI와 생산 패널을 구성하고, HUD 모드 사건으로 두 생산 격자에 같은 부모 자산의 GumpForm을 붙인 뒤 부모를 삭제했다. 공간에 배치한 TYPE 80 기본 자산과 TYPE 152 Player 기술 부모 두 경우를 검사했다. 이 검사는 실제 게임 플레이가 아닌 내부 통합 검사다.

- 수정 전에는 두 격자가 부모 소실을 통지받고 Form이 반납된 뒤에도 이전 Form SID와 연결 플래그를 보유했다. 이후 패널 종료 시 반납된 슬롯의 지워진 가상표를 다시 선택해 `PATCH 현재 가상+10의 미지 VT` 예외가 발생했다. 실패 결과는 `extracted/dotnet-1116-grid/grid.trx`에 남겼다. 첫 장면 구성에서는 팝업 메뉴 소유자 누락도 수정했다.
- 생산 격자의 부모 소실 통지에서만 아직 살아 있는 소유 Form을 실제 UI 삭제 경로로 반납하고, 격자의 연결 플래그·객체·Form을 지운 뒤 격자를 재부착하도록 보완했다. 일반 생산 Form 바인딩에 부모 0이 들어올 때의 기존 무동작은 유지한다. 수정 후 두 경우 모두 Form과 UI 참조가 정리되고 삭제 깊이 0으로 복귀하며 패널 종료에 성공했다. 관련 Client 검사 **10건 통과**, `cpp_sync.py` 종료 0, 제품 Release 빌드 오류 0이다.
