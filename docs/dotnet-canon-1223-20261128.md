## 같은 현재 소유자의 실제 처리

ClientBridgeDecay.RunSurface는 같은 권한 identity를 먼저 확인하고 PATCH 저장소의 기존 범위·커서·주기·기한을 RawBridgeDecayScan에 전달한다. FrameTimeBox를 빌리므로 칸 효과 뒤 시각도 현재값이다. 메뉴에서도 실행하며 적격 다리가 선택된 위치에서만 현재 HostSession/전체 Runtime을 pin한다. 스캔 생성이나 Frame 연결이 범위를 강제로 초기화하거나 NativeLoaded를 쓰지 않는다.

HostSession.BuildBridgeDecayDevices는 실제 전체 Surface를 공유하는 세션만 받는다. 풀만 공유하면서 Graph·장부는 따로 소유하는 조합은 거부한다. 같은 지형 머리 지도/Spots/Graph/TYPE/프레임과 가상 삭제·Building.NotifySurface·Display.Update를 RawBridgeDecay에 연결한다. 사제 이동과 같은 현재 역할·그래프 기준점·내용물 Form·PathStarter로 RawBridgeCarriers를 조립한다. 현재 지도 크기와 장기 signed BridgeAvoidLife(최초7)를 읽는다.

이른 한 칸 처리 전에 현재 입자 게임 시각/프레임과 음향 프레임만 준비한다. 실제 균열음은 그 호출 위치의 현재 슬롯 X/Y에서 bridgeCrack.wav를 재생한다. 카메라·AI 전체 준비를 중첩하지 않는다. 세션 프로세스 장치 반납에서 붕괴/대피/이동 기준점 참조도 반납한다. 기존 경로 시작의 아직 미이식 효과는 해당 선택 위치의 오류로 유지한다.

제품 Update는 현재 메뉴 트리의 실제 모달을 주변음에 공급한다. Movie 잠금 없는 가지의 순서는 Ambient→Wind→MonitorTime→BridgeDecay→SceneFrame→Minimap→Gump→Kernel이다. 메뉴의 번개/장기 프로세스도 같은 커널 위치에서 실행한다. 게임 Pause는 붕괴 스캔을 막고 Scene의 동적 벽시각 조회는 유지한다. Movie 잠금은 앞의 갱신 가지와 Kernel을 건너뛰고 기존 Gump Idle 경로를 유지한다.
