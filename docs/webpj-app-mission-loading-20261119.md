# 앱 미션 로그인 진행 창 (WB04-E952)

기준선 `225553df`의 `CampaignClientServices`와 `UberGump::ShowLoginProgress`에 맞춰 앱 소유 로그인 장치의 시작·진행·닫기를 현재 메뉴에 연결했다. 11종 진행 상태의 원문을 현재 번역기로 변환한 뒤 첫 `%s`와 `%d`를 치환한다. 기존 표시 문자 인코딩과 `MissionLoadingMessage`의 NUL 포함 1024바이트 한도를 거쳐 `TellWindow`의 본문과 즉시 Cancel 버튼을 만든다. 이전 창을 반납할 때 다른 대화상자는 닫지 않으며 앱 종료에서도 진행 창을 반납한다.

실제 메뉴 자산으로 영어·한국어 본문, 버튼, 화면 출력, 창 교체와 반납을 검사했다. 실제 Tutorial1 Guide 요청을 앱 State7과 Session에 전달하는 통합 검사에서 가짜 로그인 UI를 제거하고 실제 진행 창·HUD를 거쳐 로그인 Ready까지 확인했다. 검사용 소리·카메라 등 일부 서비스는 여전히 대역이며, 자동 요청 소비와 실제 게임 플레이는 이 검사 범위가 아니다.

현재 구현은 메뉴의 `TellWindow`를 교체하는 웹 어댑터다. 원본의 Gump serial 재사용과 동일하지 않고, 기존 HTML 메타 파서는 Cancel 인자 `3` 뒤에 줄바꿈을 포함한다. `LeaveBattle` 명령의 실제 취소 동작, 기존 World 반납, 미션 입력·표시 및 전체 HUD는 연결되지 않았다.

검증: Node v26에서 진행 창·기존 메시지·Client 로그인 및 실제 요청 관련 검사 29건과 실제 앱 State7 로그인 검사 1건이 통과했다. 고정 커밋 `b4ff359de`의 격리 전체 회귀는 별도 작업 트리에서 진행 중이다.
