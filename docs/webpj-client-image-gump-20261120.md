# Client 이미지 Gump 소유자 (WB04-E1021)

원본 ImageGump 생성·가상 부착·실제 GameAssets SHP 출력·200×200 투명 적중을 같은 Client Gump 트리와 픽셀 장치에 연결했다. 색표와 기본 메뉴 입력은 실제 공급자를 요구하고 출력 중 현재 표면을 보관해 재진입 뒤 이전 문맥으로 되돌린다.

실제 다리 SHP 픽셀 출력·불투명 적중과 삭제를 포함한 Node 검사 12건이 통과했다. 첫 적중 검사는 부모 로컬 좌표 대신 이미지 로컬 좌표를 사용해 실패했고 좌표 계약을 바로잡아 재검증했다. 생산 항목 공장과 UI 설치는 남았다.
