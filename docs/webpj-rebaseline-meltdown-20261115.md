# Meltdown 패킷 확정 재반영

WB04-E503은 4-R에서 기존 이식분 `RawMeltdown`을 기준선 `1f00a25a`와 후보 `225553df` 사이에서 판정한 결과다. 판정은 **② 웹 반영 필요**다.

`FinalizePacket`의 쓰기 경로는 대상 수 DWORD가 `0xffffffff`이면 진단을 호출한다. 후보에서는 진단이 복귀할 수 있고, 이후 현재 대상 수를 다시 읽어 그 하위 WORD에 10을 더한 두 배를 패킷 길이 WORD에 쓴다. 기존 웹 코드는 항상 예외를 던져 복귀와 재조회를 할 수 없었다. 새 선택 인자 `invalidCount`가 진단을 공급하며, 인자가 없으면 기존처럼 오류를 보고한다. 쓰기가 아니면 패킷이나 진단을 건드리지 않는다. 일반 대상 수는 기존과 같은 길이를 만든다.

원본 10.78 독립 관측 `meltdown-x86.tsv` 442행을 유지하고, 별도 검사에서 진단 부재의 오류·읽기 경로 무효과·진단 중 대상 수 변경과 복귀 후 재조회를 확인한다. 실제 세션의 패킷 송신 및 진단 장치 연결은 4-D 이후에 남는다. 이 변경만으로 미션이 플레이 가능해지는 것은 아니다.
