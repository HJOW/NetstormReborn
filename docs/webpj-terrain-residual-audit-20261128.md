## 현재 연결과 기존 검증

연결은 E302·E619에서 구현됐다. E285의 원본 x86 군집 104행, E295의 초기 도장 780행, E302의 실제 성장/도장/군집과 TYPE121 생성·소유자·HP·난수 검사, E619의 같은 풀/현재 전역 검사를 근거로 유지한다. 이번에 골라 대조한 소스·검사 **17개는 E1458 전체 6,932/6,932 때와 원시 해시가 모두 같다.** 기존 결과를 승계한 정적 감사이며 새 집중 검사 통과 수를 만들지 않는다.

이미 수집한 실제 아군 AI 1-1의 E1456 비교 덤프(500 진행 프레임, 전체523)를 독립 집계하면 `island94=13`, `isle97=1353`, `isleBig98=0`, `fringe102=168`, `edgeFarm121=152`다. 실제 Session에서 TYPE121이 존재한다는 보조 근거이며 이 집계 자체가 CPP 오라클이나 희생·승리 검사는 아니다.
