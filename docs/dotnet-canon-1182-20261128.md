# 1.182 지형 장식 난수 상태 통제 실험

원인 분리를 위해 별도 DN 진단본에서만 첫 `fringe` 선택 직전에 게임 난수를 2,245회 전진시켜 1.179의 CPP 관측 상태와 일치시켰다. 제품 소스와 실행본에는 적용하지 않았다. 동일 시드의 실제 1-1 단순 진입·대기에서 진단 실행은 종료0, 원본 1,392파일은 전후 불변이다.

생성 순간 추적에서 CPP와 DN의 위치·프레임 코드·선택 전후 난수 상태·선택 프레임이 **168/168 모두 같았다**. 40프레임 덤프에서는 양쪽 TYPE102 168개 중 **166개**의 프레임이 같다. 생성 이후 상태가 달라진 2개와 그 원인은 별도 조사해야 한다. 전체 슬롯 일치는 공통 1,911개 중 1,508개이고, CPP40과 DN40 전체 화면 차이는 제품의 31,214개에서 통제 실행의 **24,273/786,432픽셀**로 줄었다. 두 실행의 게임 시각은 여전히 다르다.

이 실험은 초기 난수 상태 차이가 장식 생성 결과에 미치는 영향을 보여 주는 통제 관측이다. 누락된 State 정리와 다른 효과를 재현하지 않으므로 플레이 동등성, L2·L4a 완료 또는 난수 강제 전진을 제품에 적용할 근거가 아니다. 실행 인자·화면·덤프·진단 DLL 해시와 원본 감사는 `extracted/dotnet-fringe-aligned-1182/`, 대응 CPP 추적은 `extracted/dotnet-fringe-1179/`에 있다.
