# WB04-E755 Session 프레임과 사제 자연 도착

`RawCampaignSession.prepareFrame(time, paused)`와 `runFrame(time, paused)`를 cpppj 기준선 `225553df`의 `RawCampaignSession.cpp` 4568..4571에 맞춰 연결했다. 4D-3f의 실제 로그인 이동 통합 검사를 진행하기 위해 4D-4a의 해당 네 줄을 먼저 옮겼다. 다리 붕괴 검사, 공유 또는 독립 게임 시각, 건설·에셋·전투·입자·음향, 정지하지 않은 AI, 월드 준비와 단일 Kernel 순서를 유지한다. 준비만 요청할 때는 Kernel을 돌리지 않는다.

캠페인 1-1 TheWarBegins의 실제 Fort를 내부 로그인하고 40h 이동 요청을 전송해 같은 Host에 생성된 사제 경로를 실행했다. 일시정지 중 경로가 유지되고, 원본 경로의 마지막 시각까지 0.025초 간격으로 실제 Kernel을 진행하면 경로가 자연 소멸하며 사제는 `(90, 108)`에 도착하고 SP는 그대로임을 확인했다. 별도의 공유 Client 저장소와 시계 검사에서는 입력 시각이 공유 시각을 덮어쓰지 않고 준비와 정지 프레임에서 Kernel이 돌지 않으며 비정지 프레임에서 한 번 실행됨을 확인했다. 반납 뒤 준비 호출은 거부한다.

공유 시계 검사 초안은 이미 World가 대여된 뒤 장치를 묶으려다 기존 수명 계약으로 실패했다. 실제 Client처럼 World 생성 전에 장기 저장소에 Kernel과 시계를 묶도록 교정했고 집중 검사 2건이 통과했다. 게임 창 실행이나 원본 파일 변경은 없었다.

이 검사는 사제의 일반 이동만 다룬다. 사제 선택 UI 해제, 골렘과 벌룬의 같은 검사, 미션 Start·자연 완주, 카메라와 브라우저 앱 수명 결선은 남아 있다. 공중 세 유닛 전용 행동과 포획·희생·승리도 검사하지 않았다.

Node v26.13.0 전체 회귀 6,250건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 오류는 0건이며 E753의 v22 검사 뒤 두 번째 v26 전체 회귀다.
