# WB04-E845 Client 전투 종료 프레임 연결

기준선 `225553df`의 `UberGump::PollBattleCompletion`을 현재 Client의 Player·동맹·옵션·연결표·LocalState·GameAux와 연결했다. 메뉴에서도 현재 Player 진단을 먼저 실행하고, 선택된 실제 Session의 사제 판정과 현재 벽시계 및 원본 메뉴 명령 입력 고리를 사용한다. 저장 정리·대화상자·무승부 거절·음향 결과 상자는 실제 앱 조립에서 제공해야 하는 장치로 남겼다.

GameAux의 `0055a44c` 대기 카운터를 unsigned BYTE로 추가해 보호된 원본 PE 초기값 0과 대조했다. 일반 월드 초기화는 이 장기 값을 지우지 않으며 프레임 판정기는 같은 BYTE를 signed로 해석한다. World 없는 메뉴의 실제 Player 진단과 내부 로그인 뒤 인위적으로 일반 전투 조건을 구성한 실제 Session에서 대기·결과·명령 예약을 검사했다. 저장과 대화상자는 관측용 장치이며 브라우저 앱 루프에 이 프레임을 아직 설치하지 않았다. 원본 게임 창은 실행하지 않았다.

검증: GameAux 집중 검사 13건과 Client 프레임 집중 검사 2건, Node v26.13.0 전체 6,355건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E843의 Node v22 전체 검사 뒤 v26 회귀 2/8회다.
