# WB04-E720: Carrier 명령 수신 등록 앞부분

미션 Login의 실제 Load 뒤 원본 순서에 맞춰 Carrier 등록 앞부분을 실행한다. 동맹 77h/79h/6fh 다음에 개발자 명령 31h와 공유 미션 설정 32h, 위치 33h, 카메라 34h, 섬 정리 35h, 경로 30h를 등록한다. 31h 해석기는 아직 없으며 해당 명령이 선택되면 명시 오류를 낸다. 다음 Dais·객체·전투·운반 수신 등록은 아직 없어 같은 Load 콜백에서 그 지점에 명시 중단한다.

33h는 예약된 클라이언트 SID를 건너뛰고 그 밖의 현재 실제 World에서 Unpop·원시 프레임 쓰기·Pop을 수행한다. 34h는 실제 화면 크기와 같은 Client 카메라 목표·갱신 DWORD를 사용한다. 35h는 같은 게임 시각으로 건설 효과를 준비해 실제 섬 정리 본문을 호출하고, 30h는 원본 관찰기와 현재 Path 수신 본체에 연결한다.

실제 Tutorial 1 Session에서 앞단 등록의 순서와 metadata, 같은 Client 설정과 카메라 목표, 예약 SID의 자연 반환 및 Login Load 뒤 미완료 경계를 확인했다. 기존 Path·설정·Player 검사를 포함해 집중 54건이 통과했다. 공중 유닛 전용 생성·행동이나 사제 포획·희생·자연 승리는 새로 검사하지 않았고 실제 게임·브라우저 창도 실행하지 않았다.

나머지 Carrier 명령과 Squid/Dais/Gun/Aviary/Flyer 수신(4D-3d), 개발자 명령, Native 등록과 외부 대여 반납이 남는다. 이 구간을 잇기 전에는 건설·연구 등록을 Login 콜백에서 뒤 순서로 실행하거나 서버 응답 왕복을 완료했다고 주장하지 않는다.
