# dotnetpj 0.801 — 실제 Host의 전체 Path/Start/Motion과 Native 30h

2026-11-22 · HJOW-Athlon · 제품11.01 · .NET10 Release. 전체 목표와 M1은 미완료다.

## 구현

`HostSession.Paths.cs`·`PathCommands.cs`에 같은 실제 Pool/공간/TYPE/Kernel의 8종 고정 생성자와 mutable 역할 분배, 부모별 Start 검증, 현재 종속→Host→Form/PID 조회, 대상 변경·재탐색·임시 BFS를 이식했다. 사제54, 텔레포트23, 비행39, 웜40, 벌룬42, Dude24, 벌프41, 워커38의 원문 부모·가상표·수명 경계를 유지한다. 187 전용 부모는 기존 Source의 미연결 경계다.

`HostSession.PlayerWorld.cs`는 독립 Host에 실제로 넘긴 시계 객체를 보관하고, 공유 Host는 같은 장기 State를 빌린다. Start/Process가 이 객체를 직접 사용한다. `HostSession.Motion.cs`는 기존 검색 Work와 사제/내용물/HP/Graph/환불을 재사용해 정리→정지→Carrier→사제→Path 순환을 설치한다. 현재 boss/너겟/진단도 실제 장기 소유자를 읽는다. 의식·예약·전체 가상삭제·재탐색·겹침·음향·선택 부모는 명시적인 실제 외부 효과다.

`HostSession.PathPackets.cs`는 Native489ee0의 현재 boss 진단→Form 검사→free 생성자→현재 Data decoder→실제 가상 Attach→첫점 Pop을 실행한다. live Form은 상세 TYPE 이름 진단 후 반환한다. 같은 현재 metadata/시계/로그 수준과 첫5105 제거를 사용하고 패킷 머리 길이를 실제 입력 범위로 대신하지 않는다. `RawSurfaceStorage.Path.cs`는 공통 SerializeProcessForm 중 Path 분기만 이식했다. 같은2048BYTE·현재헤더·현재TYPE를 사용하며 독자 송신/typed 선행guard를 추가하지 않는다. 다른 클래스의 전체 공통 serializer는 남아 있다.

`ClientSurfaceGlobals`에 실제 Native 전송 장치를 첫 프로세스 Host 생성 전에 설치하는 선택 입력을 추가했다. 기존 생성 순서에서는 사후 설치가 Storage 계약에 의해 거부됐다. 실제 Root의 전체 송수신 장치 공급은 아직 미완료다.

## 남은 범위

이 단위는 전체 Path/Motion 설치 API와 실제 Host 통합까지다. 제품 Root가 월드 입력/표시와 전체 가상삭제·의식/운반/겹침/음향 장치를 공급하는 상위 설치는 남았다. Runtime 대여 반납과 Kernel 정리는 별도 단계이며 외곽 종료자가 프로세스를 명시적으로 정리해야 한다. Kernel 등록 이후 Attach 예외의 소유권 전체 감사도 여전히 미검증이다.

고정 gameplay는30h 추가로10/26본문이며 나머지16본문·전체26F 설치/Bind 검증을 다음0.802에서 이어간다. 먼저2d/2e/65와53/62의 같은 실제 공장/종속/환불/가상삭제를 연결한다. CD Host72/Start256·정지432/도착203,10.37 애니메이션2,016의 미검증을 유지한다. 다음 정기 전체 회귀는0.804다. 마지막 전체 판정은0.800의M1 0/34이며 새 경로는 아직 플레이 불가다. 포획/희생·특정적 공격·승리 GUI 재현은 수행하지 않았다.
