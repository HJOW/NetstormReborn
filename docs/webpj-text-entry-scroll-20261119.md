# WB04-E928: 확장 문자의 수평 스크롤 경계

cpppj `DisplayTextLine`을 웹 표시 바이트에 연결하고, 원본형 TextEntryGump의 두 Slider가 확정한 현재 줄에서 수평 바이트 열을 확인한다. 해당 줄에 유효한 확장 문자가 있으면 문자의 중간 열을 앞 경계로 낮추고 같은 가로 Slider 위치도 갱신한다. 순수 원본 바이트 줄의 Slider 호출 순서는 바꾸지 않는다.

실제 편집 버퍼와 Slider 시험 틀에서 한글 토큰 중간 열이 앞 경계로 보정되는 값과 두 번의 가로 위치 호출을 확인했다. LF 줄 조회와 원본 편집기 관측 2,292행을 포함한 연관 Node 검사 27건이 통과했다.

그리기 단계의 줄 선택·수평 잘라내기 보정, 확장 글꼴의 실제 측정·출력 및 브라우저 IME는 남았다.
