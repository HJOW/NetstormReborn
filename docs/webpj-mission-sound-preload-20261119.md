# 미션 효과음 일괄 준비 (WB04-E964)

미션에 들어가기 전에 현재 언어와 기본 효과음의 파일을 제한된 수의 비동기 요청으로 받아 해독하는 경계를 추가했다. 기본 동시 요청은 8개이며 1~32개를 지정할 수 있다. 진행 수를 받을 수 있고, 실패하면 아직 시작하지 않은 요청은 진행하지 않으며 기존 완료분을 보존해 재시도한다. 음악은 이 경로에서 받지 않는다. 앱의 `_prepareMissionSounds`가 현재 매니페스트와 활성 재생기 수명에 위임한다.

공개된 효과음 218개 전부를 준비하면서 음악 요청이 없음을 검사했다. Chromium의 실제 `OfflineAudioContext.decodeAudioData`에서도 218개 모두 해독됐고, 별도 오프라인 출력에서 Web Audio 좌우 감쇠도 확인했다. Node v26 음향 연관 검사 12건과 Chromium 2건이 통과했다. 해독 실패는 원인과 실제 파일 경로를 함께 보고한다.

이 경계는 아직 미션 진입에서 자동 호출되지 않는다. SoundPlayer·Web Audio 장치를 앱 옵션과 현재 Session에 연결하고, 준비 완료·실패·취소를 미션 전환 수명에 결합해야 실제 게임에서 효과음이 난다. E962 기준 Node v26 정기 전체 회귀는 별도 고정 작업 트리에서 진행 중이다.
