Client 수명으로 현재 CS 슬롯과 실제21328BYTE 할당을 소유한다. 최초 슬롯은0이며 새 생성은 기록/좌표 Construct가 끝난 뒤만 비영 토큰으로 공개한다. 현재 슬롯을 바꿔도 이전 할당과 별도의 장기 좌표는 유지한다. 기존 객체는 미초기화 좌표의 선택 진단 뒤 현재 슬롯을 다시 읽어 기록만 Reset한다. 실제10개 전투/40개 참가자 뷰와 물리 경계를 제공하며 없는 토큰을 자동 생성하지 않는다.
