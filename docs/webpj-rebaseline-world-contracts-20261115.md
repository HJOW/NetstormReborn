# 월드 배치 반환과 마나 볼트 지연 재반영

WB04-E504는 4-R의 기존 이식분 `RawAddRandom`·`RawManaBoltArrival`을 후보 `225553df`와 대조한 결과다. 두 단위 모두 **② 웹 반영 필요**다.

- `RawAddRandom`은 배치 장치의 마지막 결과 DWORD를 반환한다. 일반 대본은 이 값을 무시하지만 최신 `RawCampaignSession`의 Fort 섬 채우기는 임시 객체 SID를 받아 채우기 뒤 실제 객체를 제거한다. 배치 호출 순서와 지역 난수는 바꾸지 않는다. 웹의 실제 세션 조립과 객체 제거 연결은 4-D에 남는다.
- `RawManaBoltArrival`은 두 프로세스 제거와 예약 확보 뒤 현재 공유 지연 float를 읽는다. 선택 조회기 `currentDelay`가 없으면 기존 독립 입력 `delay`를 사용한다. 예약을 확보하지 못하면 지연을 읽지 않는다. 장기 세션 전역의 실제 조회기 연결은 4-D에 남는다.

기존 원본 10.78 독립 관측 AddRandom 720행과 마나 볼트 도착 101행을 유지한다. 추가 검사는 배치 결과 0·일반 SID·DWORD 최대값, 예약 확보 중 지연 변경 및 확보 실패 때 조회하지 않는 순서를 확인한다. 이 단위는 부품 계약을 보완하며 세션 연결 완료를 뜻하지 않는다.
