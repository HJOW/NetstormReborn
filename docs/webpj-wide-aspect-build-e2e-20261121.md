# 건설·메뉴 e2e 의 화면비 선택과 논리 화면 기준 검출 (WB04-E1143)

프로젝트 요구는 4:3 외에 16:9·16:10 지원이다. E1135~E1139 의 건설·메뉴 e2e 는 4:3(1024×768)에서만 돌았으므로 넓은 화면에서도 같은 흐름이 맞는지 확인하고, 시험이 화면비에 상관없이 안정적으로 돌게 고쳤다. 게임 코드 결함은 나오지 않았고 모두 시험 쪽 문제였다.

## 확인한 것

- 16:9(1280×720)·16:10(1280×800)에서 신전·워크샾·제단 건설, HUD 다리 조각 놓기, 제단 우클릭·회수, 비활성 `Temple ›` 표식이 4:3 과 같게 동작한다(미리보기가 마우스를 따르고 화면 원점이 카메라 원점과 같음).
- 가장자리 스크롤은 정확한 화면 가장자리 픽셀(오른쪽 x=끝, 아래 y=끝, 왼쪽 x=0, 위 y=0)에서만 동작한다. 한 칸 안쪽에서는 스크롤하지 않는다. 방향키는 카메라를 움직이지 않는다(원본 조작에 방향키 이동이 있는지는 확인하지 않았다).
- 창 크기를 바꾸거나 카메라를 스크롤해도 건설 미리보기가 쓰는 화면 원점은 살아 있는 카메라 픽셀 원점과 같다.

## 시험 쪽 문제와 수정

| 문제 | 원인 | 수정 |
| --- | --- | --- |
| 넓은 화면에서 미리보기 상자를 못 찾거나 엉뚱한 곳을 잡음 | 표시 캔버스는 화면비에 따라 논리 화면이 줄어 1픽셀 선의 색이 번지고(4:3 만 1:1), 같은 색이 길게 이어진 다른 영역을 상자로 오인함 | 논리 화면 버퍼(`_surface.pixels`)에서 상자 색 팔레트 번호(흰색 `basic[7]`·빨강 `basic[1]`, 원본 goodColor/badColor)만 찾고, 마우스 좌표도 논리 좌표로 바꿔 비교 |
| 16:9·16:10 Tutorial2 가 시작 뒤 멈춘 채 대기 시간 초과 | 안내 창 사이의 짧은 빈 순간에 닫기 반복이 끝나 시계가 정지된 채 남음 | 창이 없고 시계가 흐를 때까지 반복하는 닫기 도우미 |
| 16:10 비활성 `Temple` 표식 시험이 어두운 픽셀을 못 찾음 | 표시 캔버스 좌표를 논리 좌표로 가정함 | 논리 화면 버퍼에서 어두운 갈색 이름 색 번호만 셈 |

## 사용

- `e2e/mission-build-placement.spec.js` 는 환경 변수 `NETSTORM_E2E_ASPECT`(`4:3` 기본, `16:9`, `16:10`)로 화면비를 고른다. 예: `$env:NETSTORM_E2E_ASPECT='16:9'; npx playwright test e2e/mission-build-placement.spec.js`.

## 남은 것

- 우클릭 메뉴 닫기·Bulf 메뉴·사제 이동 e2e 도 E1144 에서 같은 환경 변수로 화면비를 고르게 했고 16:9·16:10 에서 통과했다. 그 밖의 e2e(튜토리얼·캠페인 시작·한국어 등)는 아직 4:3 고정이다.
- 방향키 카메라 이동은 웹에서 동작하지 않는다. 원본에서 방향키로 화면을 옮겼는지 자료(조작 설명·영상)로 확인한 뒤 필요하면 연결한다.
