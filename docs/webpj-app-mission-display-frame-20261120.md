# 웹 앱 미션 화면 프레임 (WB04-E984)

로컬 연결이 완료된 현재 미션은 앱 표시 프레임에서 같은 World·Renderer·Screen을 합성하고 Canvas 표시기로 전달한다. 기존 Tell 창은 미션 위에 합성하고, 창을 열거나 닫을 때 기존 픽셀을 전체 복구한다. 창이 표시되는 동안의 배경 손상을 막기 위해 현재는 매 프레임 전체를 다시 합성한다. 아직 원본 Gump 수집·표시 통합이 아니며 성능 최적화가 필요하다.

미션 화면에서는 가려진 메인 메뉴 돌 버튼에 포인터를 보내지 않고 열린 Tell 창에는 계속 전달한다. 미션 HUD와 게임 입력 소비, 진단·물 표시, 메뉴에서 미션 시작 명령 연결 및 실제 브라우저 사용자 조작 검증은 남았다. 로그인 중에는 기존 진행 창 경로를 유지한다.

실제 Tutorial1 로그인과 Start를 진행한 앱 프레임에서 World 표시, Tell 픽셀 합성, 닫힌 뒤 DIB 행 패딩을 제외한 전체 픽셀 복구, 가려진 버튼 입력 차단과 열린 Tell 입력 전달을 검사했다. 메인 메뉴 원본 스크린샷과 원본 Renderer 앞단·구름 관측 등 연관 Node 검사 49건이 통과했다. E978 고정 Node 26 전체 검사 뒤 E982 고정 Node 22 전체 검사를 순차 실행한다.
