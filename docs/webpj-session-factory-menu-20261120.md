# 실제 Session Factory 메뉴

WB04-E1076은 같은 실제 Session의 Factory 생산 용량·현재 기술·생산 Deck·금지 목록·비용·SP·TYPE 요구 에너지를 원본 Factory 메뉴 작성기에 연결한다. 실제 로그인 후 자연 완공된 썬 워크샾과 기술 부모에서 썬 디스크 발사기 연구 명령의 TYPE/SID 인자와 활성 상태를 확인했다.

실제 워크샾 자연 완공과 원본 Factory Open 39행·관련 계약을 포함한 Node 22·26 각 6건이 통과했다. GUI 작성기와 공통 객체 메뉴, Factory 우클릭·연구 명령의 앱 소비는 남았다.
