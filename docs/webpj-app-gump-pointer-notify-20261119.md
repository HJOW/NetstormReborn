# WB04-E918: Client Gump 포인터 통지 관문

cpppj `RawButtonControls::NotifyPointer`의 공통 Gump 관문을 Client 소유자에 연결했다. 창 밖 코드에서는 overlay와 방송을 모두 건너뛴다. 창 안에서는 현재 대화창이 있거나 허용·기본 모드·포커스 없음·활성 커서 없음이 모두 충족될 때 실제 GumpInput overlay를 호출하고 이어서 실제 GumpFrame에 같은 사건·좌표를 방송한다. 호출하지 않은 overlay는 null, 호출했으나 대상이 없는 경우는 0으로 구별한다.

실제 Client 등록표·overlay·입력·방송을 사용해 호출 순서, 창 밖, 각 차단 조건, 대화창 우선, 미선택과 반납 경계를 확인했다. 포인터 경계와 실제 입력 관련 Node 검사 36건이 통과했다.

현재 포인터 폴링·브라우저 사건 큐·카메라·앱 프레임은 아직 연결하지 않았다. 이 관문은 원본 호스트의 변경/활성 진단 반환을 대체하지 않는다.
