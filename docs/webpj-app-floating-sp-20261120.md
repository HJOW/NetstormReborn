# 실제 건설 비용 표시

WB04-E1074는 원본 FloatingSpGump를 같은 Client의 글자·그림·Gump 수명과 게임 시계에 결합하고 건설 커서의 비용 표시에 연결한다. 선택적 객체 참조는 같은 실제 Form과 월드 투영 플래그를 사용한다. 미션 반납 시 남은 표시를 정리한다.

실제 Chromium 한국어 Tutorial2에서 사제 메뉴로 윈드 신전을 선택하고 유효한 섬 위치를 마우스로 눌러 실제 신전 객체가 생성되는 것과 5000 비용 그림을 확인했다. 원본 비용 표시 426행 및 실제 미션 관련 Node 22·26 각 13건이 통과했다. 최초 브라우저 배치에서 비용 Gump 미연결 예외가 발생해 이를 연결한 뒤 다시 통과했다. 실제 사제의 건설 완료와 후속 안내는 아직 검증하지 않았다.
