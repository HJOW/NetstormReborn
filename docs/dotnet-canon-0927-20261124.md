# dotnetpj 0.927 — RU-3 NSInfo 배틀 입력 결선 이식

2026-11-24, HJOW-Athlon. RU-3 열여덟 번째 묶음이다. NSInfo 배틀 패널 원문 입력을 같은 파생 노드/CS·87BYTE 옵션과 실제 메뉴·송신 장치에 연결하는 생산 결선을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HostNsInfoWindows.HandleBattleInput`은 배틀 패널 토큰의 원문 입력 event/first/second를 `NativeBattleInfoInput.Handle`(0.915)에 실제 owner로 연결한다. 같은 공유 트리에서 0x16c 파생 노드를 해석하고, 메타맵·명령 읽기는 `Read`를, 전투 물리는 `challenge`를 빌린다.
- `BattleGuySound`·`BattleSortMenu`·`BattleOptionsMenu`·`BattleExcludeMenu`·`BattleOptionMenu`·`BattleRemoveMenu`·`BattleData` 7종을 `HostNsInfoDevices`에 추가했다. 음향·정렬/옵션/제외/개별/제거 메뉴·87BYTE 송신의 생산 공급자가 정해지기 전까지 미연결 호출은 명시 실패한다. 0.927에서 추가됐다.
- 자식 serial은 같은 공유 트리의 실제 serial을 직접 빌리며, 재부착 Push/부착은 같은 트리 실제 장치를 직접 빌린다. 처리하지 않은 입력의 0 반환은 기본 처리 위임 없이 그대로 둔다.

## 검증

- Release 클라이언트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 5건(모드2 순환 송신/재부착·정렬 메뉴·제외 추가 송신·비활성 0 반환·미연결 명시 실패)은 통과/실패 0이다. 이웃 `NativeBattleInfoInput` 검사를 포함한 41건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0927-*/`의 각 실행 로그와 요약이다.
