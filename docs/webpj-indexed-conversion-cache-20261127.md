# RGBA 변환의 이전 색 번호 대조 — WB04-E1456

2026-11-27 HJOW-Athlon. E1454 뒤의 실제 와이드 아군 AI 1-1에서 RGBA 변환의 중복을 더 줄였다. 마지막 RGBA 출력에 반영한 색 번호를 한 BYTE씩 보관하고, 네 BYTE가 모두 같으면 해당 네 픽셀 변환을 생략한다. 비교 자체는 호스트 엔디언과 무관하다. **60/120FPS 달성은 여전히 확인하지 못했으며 M5 성능 관문을 닫지 않는다.**

`IndexedPresenter` 내부만 수정했다. 새 팔레트·크기는 전체 변환/사본 복원, 부분 변경은 요청 범위 안만 갱신한다. 정렬된 같은 길이의 독립 Uint8Array만 비교하며 일반 배열·비정렬·길이 차이·출력과 공유한 입력은 원래 BYTE 변환 순서로 처리한다. 추가 예약은 논리 픽셀당1BYTE(1920×1080에서2,073,600BYTE)이고 크기 교체/`release()`에서 놓는다. 게임·시계·난수·AI·음향·Canvas 제출 영역과 횟수는 바꾸지 않았다.

반복문을4/8개씩 펼치거나 DWORD 입력을 분해한 첫 후보들은 독립 Chromium 측정에서 기존보다 느려 적용하지 않았다. CPU 분석용 첫 색 번호 대조 후보는 변환 self 표본을5.189초→0.685초로 줄였고 관측45.964→53.152FPS였다. 이 CPU 후보 뒤 입력 예외/별칭 가드를 보강했으므로, 이를 최종 코드와 완전히 같은 소스의 측정으로 세지 않는다. before 원문의 `product`에 옛 E1450 문구가 남은 것도 출처 요약에서 구분했다.

본 소스와 같은 최종 후보는 각8시점/합계16개의 실제 전체 Canvas에서 독립 RGBA 기대값과0픽셀, 두 실행의 SHA 동일, 실제 AI/게임 덤프 허용 밖 차이0이다. 세 화면비·카메라 이동을 포함했다. 별도의3확대방식×4배율×6변경=72 Canvas 경우도0픽셀이다. 76개 폭/입력 시작 위치의 반복 변경·팔레트·전체 갱신·반납 복원과 배열/길이 차이/출력 버퍼 별칭을 새로 검사했다. 이 두 행동 검사는 기존 코드에서도 통과했으므로 기존 결함 재현 시험이라고 하지 않는다.
