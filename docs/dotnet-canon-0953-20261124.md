# dotnetpj 0.953 — 0x0f Root 응답·2번 연결 종료 설치 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 0x0f Root 로그인의 송신 관찰기와 수신 본체·고정 F 설치, 원문 2번 연결 종료의 고정 F 설치를 같은 분배기에 연결했다. 0.951의 1a/1b 배틀 시작과 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientRootLoginReply.Observe`는 40a070 전체를 이식한다. 수신 방향은 버퍼를 읽지 않으며 세 sentinel 진단 뒤 현재 필드를 다시 읽어 선언 WORD를 `rootServerLen+20+numChals*47+numFriends*5`로 쓴다. 0.953에서 추가됐다.
- `ClientRootLoginReply.Receive`는 4b4250 전체를 이식한다. 버전 거부이면 next12/+50만 쓰고, 수락이면 정리→값→서버 목록→저장→존 기록(compact 3BYTE/전체 47BYTE)→친구→phase 23 분기 순서를 보존한다. 0.953에서 추가됐다.
- `ClientRootLoginReply.Install`은 0x0f의 원문 packet 관찰기·버전·가변 길이와 고정 F를 설치한다. 0.953에서 추가됐다.
- `ClientConnectionEndedReceiver.Install`은 2번의 고정 F만 설치하고 observer/version/length 표는 바꾸지 않는다. 송신자·NULL 연결 비교·서버/동기화/phase/next/프레임·Player 읽기와 저장·끊기·방송 효과는 호출 시점의 실제 owner에서만 선택하며 지난 World/Meta/Session을 캡처하지 않는다. 본체는 `Netstorm.Net/ConnectionEnded.ReceiveConnectionEnded`를 재사용한다. 0.953에서 추가됐다.
- 버전 Tell·목록 저장·마커 삭제의 실제 메뉴·파일·세션 결선은 세션·R5 메뉴 연결에서 잇는다.
