# 앱 미션 생산 유지 프레임 (WB04-E1003)

준비된 미션에서 생산 유지 소유자를 한 번 만들고, 원본 입력 뒤·Kernel 앞의 생산 idle 위치에 현재 기술 내용물 동기화와 재고·다리 공급을 연결했다. 현재 제품 타이머 설정과 다리 TYPE을 같은 Client에서 읽는다. 생산 재계산이 요구하는 `getTeleportTechFree` 설정과 Fort/Battle 진단도 실제 앱 설정·console에 연결했다.

실제 Tutorial1의 앱 프레임과 원본 생산 유지 관측 등 Node 검사 10건이 통과했다. Chromium에서 안내·사제 이동 후 12초 이상 실행하면서 실제 기술 부모의 다리 내용물이 자동 생성되고 페이지 오류가 없는지 확인했다. 생산 패널·격자의 화면 표시와 사용자가 다리를 집는 입력은 아직 연결되지 않았다. E998 고정 Node 22 전체 검사는 별도 트리에서 실행 중이다.
