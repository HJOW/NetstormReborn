## 이식 (증거)

- `dotnetpj/src/Netstorm.Core/Original/RawPlayerRegular.cs`: `PlayerRegularAssertion`·`PlayerRegularHooks`(진단·로그·예약·부착·Template State·변경통지·핀)·`Run`·`Handles`를 추가했다. 로컬 소유자가 아니거나 개수가 0이면 원래 payload를 돌려준다. 사건 1은 소어 루저 로그 두 줄 뒤 전투 중일 때만 새 정기 2(payload 60)를 예약하고 0을 돌려주며, 비전투이면 미시작 로그 뒤 원래 payload를 돌려준다. 사건 2는 전투 중일 때만 Template 칸 첫 바이트에 표시 비트 4를 세우고 변경을 통지한 뒤 0을 돌려준다. 알 수 없는 사건은 진단 뒤 원래 payload를 돌려준다. PATCH·CD 가상표(`0x50ee08`·`0x5002a8`)와 소유자 오프셋(34·32)을 판본대로 읽는다. 근거: cpppj `o/RawPlayerRegular.cpp` 24~43행이다. 난수를 소비하지 않는다.
- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`: `RegularHandlerWithPlayer`·`BuildPlayerRegularDevices`·`RunPlayerRegularSession`과 로그·Template 표시 기록(`PlayerRegularLogs`·`PlayerTemplateMarks`)을 추가하고 `BuildRegionVortexPostPopDevices`에서 장식 분배 다음에 연결했다. Player 사슬이 장식 사슬을 감싸므로 해제 순서는 Player가 먼저다. 근거: cpppj `client/RawCampaignSession.cpp` 1799행의 Native 분기 `0x50ee08`이다. 새 정기 예약 실패(new 40)는 관리 코드에서 일어나지 않으므로 예약은 항상 성공으로 두고 실제 부착은 `SquidProcessHost.AddRegular`로 잇는다. Template State는 세션 적재 header 180바이트(`WorldTemplates`)의 해당 칸 20바이트에서 잇는다. 그룹 29 화면 로그와 DataManager 스트림·UI 통지는 R6에서 잇는다.
