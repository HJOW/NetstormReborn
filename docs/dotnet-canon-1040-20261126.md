# dotnetpj 1.040 — WP-4d World/건설 효과 pin 전달 + 정기 전체 회귀

2026-11-26, HJOW-Athlon. R4-6 월드·경로 묶음의 일곱 번째 조각이다. WP-4의 마지막 조각으로 미션 프레임의
월드·건설 효과를 현재 Runtime pin 안에서 실행하도록 실제 설치했다. 적재 중(Runtime 미공개)에는 pin 없이
종전대로 실행해 L2 덤프에 닿지 않는다. WP-4 네 조각이 모두 끝나 R4-6 월드·경로 묶음도 닫았다. 4단위 만의
정기 전체 회귀도 함께 수행했다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Host/HostSession.Runtime.cs`: `RunPinnedWorldFrame(Action)`을 추가했다.
  미션 Runtime 공개 뒤면 `PinRuntime()` 안에서 효과를 실행하고, 미공개면 그대로 실행한다. 근거: 원문
  프레임 처리의 월드 pin 보유다. 예외가 나도 pin은 반납된다. 1.040에서 추가됐다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 프레임 루프의 미션 월드 작업(연소 준비·Kernel 정기)을
  `RunPinnedWorldFrame` 안으로 옮겼다. 미션 없으면 종전대로 둔다. 1.040에서 추가됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostWorldFramePinTests.cs`: 신규 3건. 공개 뒤 pin 보유 실행과
  종료 뒤 반납, 미공개 폴백 실행, 효과 예외의 pin 반납을 대조한다. 1.040에서 추가됐다.
