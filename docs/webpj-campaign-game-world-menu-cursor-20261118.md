# WB04-E796 World 객체 메뉴와 이동 커서

`GameWorldInput.inc`의 남은 `OpenSelectionMenu`와 `UpdateMovementCursor`를 연결했다. 객체 메뉴는 같은 Session 선택 처리기의 Carrier 또는 Archer 입구를 사용하고 공통 메뉴의 결과를 그대로 반환한다. 이동 커서는 강조 모드 2 또는 5에서만 현재 마우스와 카메라 snapshot을 원본 방식으로 역투영하고 정수 절삭한 뒤 같은 운반체 처리기에 전달한다. 이에 따라 이 파일의 코드 이식은 완료하되, 화면 장치·브라우저 이벤트와 전체 미션 수명에 실제 연결한 것으로 간주하지 않는다.

TheWarBegins 실제 로그인과 사제 선택 상태에서 운반체 메뉴가 입력 이벤트와 공통 메뉴 결과를 보존하고, 모드 5의 커서 갱신 및 모드 0의 생략을 확인했다. 공통 메뉴는 독립 검사 콜백이고 브라우저 화면은 아니다. 아처 메뉴 입구는 이미 이식된 `RawUserSelection`의 같은 몸체를 호출한다. 포획·희생·승패 및 세 비행 유닛 전용 행동은 실행하지 않았다.

검증: Node v26.13.0 전체 6,294건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 마지막 Node v22 전체 검사는 E795이며 이번 단위까지 이후 v26 전체 검사 1/8회다.
