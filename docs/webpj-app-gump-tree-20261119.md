# WB04-E909: 앱 Gump 자식 부착과 입력

앱 Client의 공통 Gump 소유자에 기존 `GumpTree`를 연결했다. 기본 노드의 실제 등록과 사건 처리기를 같은 저장소에 두고, 루트 부착·입력 분배·밀어내기·지연 삭제 및 정리를 원본 부모로 수행한다. 부착 진단은 같은 Client checking과 상세 문자열 전역을 읽고 쓴다. 구조 변경은 현재 앱 화면의 다시 그리기를 요청한다.

현재 이 경로는 기본 Gump 노드만 생성한다. HUD·HTML·진행 창 등의 파생 생성자와 소멸자, 월드 투영, 실제 브라우저 사건 및 전체 RawButtonControls는 연결하지 않았다. 따라서 로그인 `uiMode`나 진행 창이 완성된 것은 아니다.

같은 등록표에서 자식 생성→부착→키 입력→지연 삭제와 재전달, Client 진단 문자열 기록을 확인했다. 원본 Gump 생성·트리·수명·입력 대조를 포함한 Node 집중 검사 39건과 Chromium의 실제 앱 입력·삭제 1건이 통과했다. Node v26.13.0 전체 회귀 6,464건이 통과했다(실패·취소·건너뜀 0).
