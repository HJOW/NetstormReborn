# WB04-E873 Client 지역 테마 설정과 Tutorial1 지형

cpppj `CampaignClientServices`는 지역 도장 때마다 현재 설정의 원문 키 `theammode`를 `ReadInt`로 읽고, 키가 없으면 1을 쓴다. 웹에 같은 Client 설정을 호출 시점마다 읽는 `bindCampaignOwnershipTheme`를 추가했다. 키 누락, 0, 음수 DWORD, 잘못된 숫자와 현재 설정 객체 교체를 실제 `GameData`로 검사했다. 브라우저 Client 장기 조립은 아직 이 바인더를 호출하지 않는다.

E871~E872의 독립 검사 장치는 테마를 0으로 고정했지만 cpppj 실행은 기본 1이었다. 같은 조건으로 바꾸고 웹의 실제 Tutorial1 로그인·Start를 실행하자 cpppj 90프레임과 다른 지형 프레임이 763개에서 45개로 줄었다. 안쪽 지형 613개는 프레임 번호까지 모두 같고 나머지 지형 중 45개가 다르며 방향·변형 코드는 모두 같다. 웹의 관측 시점 게임 난수는 `1442508500`, cpppj 90프레임은 `3241635643`으로 달랐고 CRT 상태는 양쪽 모두 `1451214786`이었다. 서로 다른 난수 소비 수명과 45개 차이의 인과관계는 아직 확인하지 않았다.

집중 검사와 미션·지역 소유·도장·cpppj 자료 연관 검사 39건이 통과했다. 처음 지정한 연관 검사 파일명 하나가 실제 파일명과 달라 해당 파일들이 실행되지 않은 것을 확인한 뒤, 실제 지역 검사 3개 파일을 별도로 실행했다. Node v26.13.0 전체 회귀 6,415건은 실패·취소·건너뜀 없이 통과했다. 브라우저 전체 Client·실제 프레임 시계와 남은 경계 후보 대조는 후속이다. 원본 게임 창은 실행하지 않았다.
