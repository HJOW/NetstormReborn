# WB04-E923: 확정 입력의 원자적 큐 삽입

cpppj `InputQueue::TryPushBatch`와 `FreeSlots`를 웹의 같은 40칸 고리 큐에 추가했다. 구분 칸을 제외한 남은 칸이 부족하면 기존 큐와 새 본문을 보존하고 false를 반환한다. 공간이 충분하면 JS 사건의 코드와 좌표를 전부 먼저 검증한 뒤 원본 Push 순서로 넣는다. 일반 단일 Push의 포화 시 마지막 사건을 버리는 원본 동작은 바꾸지 않았다.

고리 끝 감김, 정확히 39칸 채우기, 공간 부족, 잘못된 중간 사건에 대한 무변경을 검사했다. 최초 기대 목록에 원본 Pop이 Ctrl+Backspace로 바꾸는 0x7f가 포함되어 순서 검사와 충돌했으므로 일반 코드로 교정했다. 기존 입력·메인 루프를 포함한 연관 Node 검사 17건이 통과했다.

실제 문자·IME 확정 사건을 생성하고 이 API를 사용하는 경계와 미션 입력 소비는 아직 남았다.

Node v22.23.3 전체 회귀 6,487건이 실패·취소·건너뜀 없이 통과했다.
