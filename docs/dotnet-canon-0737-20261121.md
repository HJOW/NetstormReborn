# 0.737 NSInfo 장기 전역·서버 레코드와 실제 호스트 소유자

ClientNsInfoGlobals.cpp/.h와 RootServerEndpoint.cpp/.h를 이식했다. NSInfo 현재 토큰·zone DWORD·정렬40DWORD·서버 이름80BYTE·종류BYTE·명령DWORD와 서버 행/체크섬을 한 실제 소유자가 보유한다. 서버 문자열은 원문 좁은 바이트를 Latin1로 보존하고, ASCII 바이트 소문자 변환과 첫NUL 경계를 사용한다. 관리 Unicode 문자의 손실 대체를 넣지 않았다.

레코드 판독은 유효 행의 출력0쓰기→첫세미콜론→목적span-1 복사→선택 subscriber 판독 순서다. 무효 목록 index는 출력과 기존 subscriber를 그대로 둔다. endpoint는 첫 성공한 콜론/십진 숫자 패턴을 선택하고 실패한 앞 콜론의 host를 합치지 않는다. 매치가 없을 때 기본 포트를 먼저 조회한 뒤 명시 비영 포트를 적용한다. 원문80BYTE 경계·NUL과 기존 ConfigNumbers.ParseLong의32비트 감싸기를 그대로 사용한다.

서버 이름은 LAN일 때 복사prefix/NUL만 쓰고 뒤 바이트를 보존하며, 유효 서버 행에서는 전체80BYTE를 먼저 지운다. 무효 선택은 현재 버퍼를 보존한다. Upsert는 endpoint 전체 일치 대신 첫 대소문자 무시 부분 일치를 사용한다. 기존 행 교체는 원문처럼 체크섬을 재계산하지 않고, 새 행 추가/전체 적재만 unsignedBYTE+1 합계를 갱신한다. 같은 endpoint를 가진 뒤 행의 SetServerValue가 첫 부분 일치 행을 바꾸는 원문 동작도 유지한다.

ClientHostGame.NsInfo가 실제 장기 NSInfo 인스턴스를 소유하고 순수 getter로 제공한다. 생성 시 실제 시작 Config에서 curServer→rootServerBroadcastPort→passedDiags를 같은 현재 DWORD에 읽으며 누락 키는 기존 값을 유지한다. 이는 ClientMain의 해당 세 값 이식이며 readOnlyForts와 전체 InterpretOptions 완료를 뜻하지 않는다. 서버 목록 파일의 사용자 루트 읽기/저장, NSInfo HUD·메타 UI와 전체 State 컨텍스트의 같은 zone 연결은 아직 후속이다. 이번 경계는 DNS·소켓·폐기 클라이언트 검증을 실행하지 않는다.
