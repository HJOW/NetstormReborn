# 1.164 부착 메뉴 수명

`RawMenuControls::OpenAttached`의 작성기 직접 부착 경로를 `HostHtmlMenus`에 연결했다. 기존 팝업을 닫아 실제 트리에서 정리하고, 작성기가 반환한 루트의 부착과 controlled 스택을 확인한다. 작성기가 이미 수행한 부착을 반복하지 않는다.

실제 메뉴 트리와 입력을 이용한 집중 테스트 25개가 통과했다. 최초 검사에서 요청 좌표가 화면 경계에 맞게 보정되는 실제 동작을 간과하여 한 건이 실패했고, 부착 직후의 실제 좌표가 유지되는지 검사하도록 수정한 뒤 재실행했다.

아직 제품 생산 정보 메뉴에서 이 장치를 호출하지 않으며, 실제 객체 Form 연결과 완전한 미션 적재도 남아 있다. 이번 단위에서는 게임을 실행하지 않았다.
