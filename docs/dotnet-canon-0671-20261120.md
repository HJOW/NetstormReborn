## 구현

`RawConstructionEffects`는 같은 풀·네 단계 해시·TYPE·spot 지도를 쓴다. 원본 float 발자국과 큰 모서리 보정·가로 폭에 따른 축소, 중심 우선·아래 줄·오른쪽 열 순서, PATCH3칸/CD2칸 거리와 폭/높이+1칸을 유지한다. 이동 위치를 찾은 뒤 PATCH 현재 동맹/적대 허용genus를 판정하며 뒤의 적대 후보가 거부되어도 앞선 이동을 되돌리지 않는다. 경로 삭제→Unpop→현재genus 조회→Pop 순서다.

섬 정리는 현재 억제 관문→현재 서버의16.16 방송→현재 섬TYPE/발자국→실제 탐색→같은 소유자 조각의 낙하/현재 좌표 소리·삭제·현재genus 통지 순서다. 조각 개수9/1/1 보고와 낙하/방송 억제flags를 유지하고 각 효과 뒤 현재TYPE 전역을 다시 읽는다. 실제 건설 진행의 `MakeHooks`는 같은 풀의 보상 최대HP와 이 밀어내기를 연결한다.
