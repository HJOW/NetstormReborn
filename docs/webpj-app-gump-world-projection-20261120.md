# 앱 월드 부착 Gump 투영 (WB04-E989)

Client Gump의 수집기와 트리 부착이 같은 현재 투영 콜백을 사용한다. 앱 콜백은 실제 Client 장기 SID 풀에서 객체의 현재 비정렬 좌표를 읽고 같은 Client 카메라 snapshot으로 투영한다. 현재 풀이 없으면 다른 좌표를 만들어 내지 않고 해당 분기에서 오류를 알린다.

실제 Tutorial1 Session의 객체에 Gump를 부착하고 풀 좌표와 카메라 원점 변경을 투영에 반영하는지 확인했다. Gump Form, 원본 수집·트리 관측과 Client 수명 등 연관 Node 검사 39건이 통과했다. 실제 HUD·월드 부착 UI 공장과 입력은 남았다. E982 고정 Node 22 전체 검사는 실행 중이다.
