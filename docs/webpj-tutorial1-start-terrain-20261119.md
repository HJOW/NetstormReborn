# WB04-E872 Tutorial1 로그인·Start 뒤 지형 프레임 관측

웹에서 `Tutorial1` 스크립트가 선택한 `BridgeTheGap`을 실제 내부 로그인·Ready까지 적재하고 같은 Session의 미션 `Start`를 실행했다. cpppj 기준선 90프레임 덤프와 비교한 763개 지형은 TYPE·좌표가 모두 같았고, 웹에서는 Start 호출 전후 프레임이 바뀌지 않았다.

cpppj의 해당 프레임 번호와는 763개 모두 달랐다. 다만 각 타입의 프레임 코드 표로 해석하면 방향과 변형 글자는 763개 모두 같고, 번호·플래그까지 포함한 코드가 같은 것은 613개였다. 코드는 같아도 프레임 후보 번호는 다를 수 있다. 웹 검사에 cpppj 고정 실행의 Unix 원점과 미션 시작 시각을 전달했지만 로그인 시계, 이전 난수 소비 및 전체 Client 프레임 수명은 아직 일치시키지 않았다. 따라서 이 관측은 차이의 범위를 좁히며 그래픽 일치나 원인을 확정하지 않는다.

실제 Tutorial1 Session 집중 검사 2건과 미션 시작·cpppj 자료·fixture 연관 검사 23건이 통과했다. 새 회귀 주기에 따라 전체 회귀는 실행하지 않았다. 원본 게임 창은 실행하지 않았다.
