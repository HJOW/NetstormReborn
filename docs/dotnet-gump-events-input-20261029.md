## 1. 구현

`GumpEvents`는 현재 dialog의 우선 필터, help 사건의 실제 사각형 경계, 키보드/마우스 플래그를 원본 순서로 판정한다. 직계 선택과 전체 선택을 따로 두며, signed 깊이와 같은 깊이에서 먼저 방문한 노드 우선, 경계 밖 자식 통과, 현재 마스크/좌표/링크 재조회를 보존한다. 선택은 void/dead를 제외하지만 사건 재귀 전달은 visible만 제한한다.

자식이 먼저 성공하면 부모 필터/처리기는 호출하지 않는다. Dispatch는 처리기의 비영 값 대신 성공 노드 토큰을 반환하고, Bubble은 부모 처리기의 전체 DWORD를 반환한다. 위치 계산은 별도 사각형 사본 없이 실제 `GumpCollection`의 노드 캐시와 경계를 사용한다.

`GumpInput`은 첫 캡처를 유지하며 실패한 캡처 뒤 다른 대상으로 다시 전달하지 않는다. 성공한 처리기가 캡처를 바꾸면 호출 뒤 현재 값을 반환하고 지운다. 캡처가 없으면 현재 dialog 또는 실제 등록 루트로 재귀 전달한다. dialog 한도 로그는 중복 검색 전에 실행한다. override 설정은 빈 칸에서만 성공하고 그 외에는 해제하는 원본 동작이다.

overlay는 표 순서·부모 visible·실제 전체 Pick을 사용한다. 별도 OverlayEvent를 처리기에 전달하고 첫 일치 처리기의0을 포함한 전체 반환을 보존한다. 뒤 표 항목은 앞 대상의 콜백 뒤 현재 값으로 읽는다.
