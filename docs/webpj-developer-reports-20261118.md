# WB04-E743 개발자 타입·그래프 진단

`31h`의 `dumpTypes`/`dts`, `dumpType`, `dumpGraph`/`dg`를 현재 Session의 TYPE·그림·그래프 자료와 수준 29 추적에 연결했다. 타입 목록은 0을 제외하고 각 행 출력 직전에 현재 표를 읽으며, 10.78에서 실제로 인식하지 않는 `dt` 별칭은 추가하지 않았다. 그래프의 두 WORD는 부호 있는 값으로 출력한다.

근거는 기준선 `225553df`의 `RawCampaignSession.cpp` `ExecuteDeveloperCommand`이며 기준선 이후 해당 파일 변경은 없다. 새 원본 fixture나 직접 cpppj 검사는 없다. 다른 개발자 명령은 여전히 미연결 오류로 둔다.

독립 검사에서 출력 도중 변경된 다음 타입 행, 별칭·그래프 signed WORD·입력 범위를 확인했다. Tutorial 1 Session의 실제 `31h` 분배기에서 현재 그래프와 추적 소비자를 확인했다. 기존 개발자 명령 회귀를 포함한 집중 검사 38건이 통과했다.

Node v26.13.0 전체 회귀 6,227건을 통과했다. 대응표 오류는 0건이며 Node v22 전체 재검사 주기는 5/8회다.

다음은 `31h`의 나머지 개발자 명령과 내부 로그인 서버 후반·응답 왕복이다. Native 분기, 행 base 뒤 변경 판정 및 앱 미션 연결도 남아 있다.
