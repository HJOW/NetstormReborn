> 입력 `actions.csv`와 프레임 `g65`·`g89`·`g120`·`g163`·`g193`·`g230`·`g258`·`g308`·`g339`·`g386`.
> 좌표는 원본 1024×768 클라이언트 기준이다. 이번에 전체화면이나 해상도를 바꾸지는 않았다.

## 파란 원형 마크는 현재 설정 상태다

**항목 왼쪽의 파란 원형 마크는 항상 그리는 장식이 아니다. 켜진 항목 또는 현재 선택한 값에만 표시한다.**
끄면 해당 마크가 사라진다. 다시 켜면 다시 나타난다(사용자 확인과 영상 일치).
이때 항목 이름이나 행 자체가 없어지는 것은 아니다.

마크와 별도로, 마우스가 가리키는 행에는 **어두운 가로 강조 배경**이 생긴다.
00:08.9의 Sound On은 강조되어 있지만 마크가 없다. 반대로 커서가 다른 행에 있어도
켜진 Play Music / Wind Noise 등에 마크가 남는다. **마우스 위치와 설정 상태를 따로 표시한다.**

마크가 없다고 그 항목을 클릭할 수 없는 것은 아니다. Sound On을 껐다가 같은 행을 다시 클릭해 켤 수 있다.
여기서 ‘활성화’는 기능이 켜졌다는 뜻이며, 잠긴 미션의 흐린 글자와 같은 ‘조작 불가’ 상태와 구분한다.
또한 Resolution 같은 하위 메뉴 진입 항목이나 Pass Server Diagnostic 같은 명령에
불필요한 파란 마크를 붙이지 않는다.

Sound On / Play Music / Wind Noise / Edge Scroll / Auto-Demo / Tell Tips는 **각각의 켜짐 상태**를 나타낸다.
따라서 한 메뉴에서 여러 마크가 동시에 존재한다. 반면 Resolution이나 음량의 하위 목록은
**같은 설정에서 현재 선택한 값 하나**에 마크가 붙는다. 음량의 선택을 바꿔도 목록의 다른 값은 사라지지 않는다.

## 메뉴 항목과 이번 확인 범위

| 표시 이름 | 항목의 성격·내용 | 이번 확인 |
|---|---|---|
| Direct Draw / Full Screen | 화면 모드 전환 | 항목만 확인. 실행하지 않음. |
| Resolution > | 640 by 480 / 800 by 600 / 1024 by 768 | 하위 목록·현재 값 마크. |
| Sound On | 소리 켜기/끄기 | 마크 소멸·복귀. |
| Play Music | 배경 음악 켜기/끄기 | 마크 소멸·복귀와 녹음 재생 변화. |
| Wind Noise | 바람 소리 설정 | 켜짐 마크. 이 행을 바꾸는 조작은 없음. |
| Speaker Swap L/R | 좌우 스피커 교환 설정 | 이름과 이번 마크 없음 상태만 확인. 교환 실행·좌우 음성 판정은 없음. |
| Sound Effect Volume > | Volume 1~5 중 선택 | 3→4 선택 마크 변화. 실제 배율 미측정. |
| Music Volume > | Volume 1~5 중 선택 | 2→3 선택 마크 변화. 실제 배율 미측정. |
| Edge Scroll in Fullscreen | 전체화면에서 화면 끝 스크롤 설정 | 켜짐 마크. 이번에는 창 모드로 플레이함. |
| Auto-Demo | 자동 데모 설정 | 켜짐→꺼짐. |
| Tell Tips at Startup | 시작 시 팁 표시 설정 | 켜짐 마크. 이 행을 바꾸는 조작은 없음. |
| Pass Server Diagnostic | 서버 진단 명령 | 항목만 확인. 진단은 실행하지 않음. |

## 메뉴가 열리고 닫히는 방식

Options 버튼을 클릭하면 돌 무늬의 펼침 메뉴가 열린다. 이번 메뉴 범위는 대략
`(553,294)~(716,548)`이며 줄 간격은 약 17px다. 기능 묶음 사이에 구분선이 있다.
메뉴 높이는 내용에 따라 정하고 기존 다른 시점 캡처의 범위를 그대로 고정하지 않는다.

`>`가 붙은 Resolution·음량 행은 **행을 클릭하면 오른쪽 하위 목록이 열린다**.
다른 하위 메뉴 행을 클릭하면 오른쪽 목록이 바뀌며 부모 Options 메뉴는 유지된다.
단순히 커서를 행에 올렸다는 사실과 하위 목록을 연 클릭을 구분한다.

Sound On·Play Music·Auto-Demo의 켜기/끄기 및 음량 값 선택 뒤에는 펼침 메뉴가 닫힌다.
Options를 다시 열면 바뀐 마크가 나타난다. 00:39.414에 메뉴 밖을 클릭한 뒤에도 메뉴가 닫힌다.
따라서 **값 변경 뒤 다시 연 화면**을 비교해야 클릭 행의 강조를 설정 상태로 잘못 읽지 않는다.
종료·재실행까지 설정이 유지되는지와 저장 파일 쓰기 시점은 이번 영상으로 검증하지 않았다.

클론을 복원할 때에는 ‘기능 켜짐’, ‘목록의 현재 값’, ‘커서가 가리키는 행’, ‘하위 메뉴를 연 상태’를
각각 다루고, 켜짐 마크를 모든 행의 고정 장식으로 그리지 않는다. 이번 작업은 분석·문서화이며 구현 변경은 없다.
