# 클론 UI의 원본 외관 적용 (2026-10-01)

원본 `screenShots/`와 [메인 메뉴 좌표 기록](main-menu.md)을 기준으로 큰 글씨·버튼·대화상자를 줄였다. 기존 메뉴·미션 동작은 그대로 연결하며 `OriginalUiSkin`이 메뉴와 미션의 그리기를 공유한다. 원본 게임은 실행하지 않았다.

**2026-10-02 보완:** 네 번째 녹화의 옵션 마크·메뉴 닫힘, 전체 도움말 탐색, 우클릭 명령, 플레이 조작키를 구현했다. 아래 검증은 10월 1일 당시 기록이며 최신 구현·이전 검증·남은 기능은 [녹화 분석 클론 적용](recorded-ui-clone-20261002.md)에 정리했다. 사용자 지시로 최종 테스트 실행을 보류했으며 [인수인계 문서](../handoffs/clone-recorded-ui-20261002.md)에 재개할 검증을 기록했다.

## 글씨와 버튼

본문은 20 → **13px**, 보조 글씨는 13 → **12px**, 제목은 32 → **16px**이다. D2Coding TTC의 굵은 face를 사용하고 1픽셀 검은 그림자를 붙인다. 원본의 Arial 비트맵 글꼴과는 자폭·글자 형태가 다르므로 한국어와 영어 모두 실제 문구 폭을 재서 줄바꿈과 대화상자 버튼 폭을 정한다.

메인 메뉴는 원본 1024×768 기준 `(356,311)`에서 시작하는 **74×19px 버튼, 가로 간격 79px, 세로 간격 23px**의 두 줄·네 열 배치다. 다른 화면비에서는 화면 중심을 기준으로 옮긴다. 비활성 항목은 흐린 글자로 표시하고 클릭·키보드 실행을 막는다. `[잠금]` 문구를 덧붙이지 않는다.

## 재사용한 원본 자산

| `fortGump.type` 클러스터 | 적용 |
|---|---|
| `A00` | 회색 대리석 대화상자·지식 도움말 본문 |
| `A01` | 밝은 돌 메뉴·목록·텍스트 버튼 |
| `I00`~`I03` | 대화상자의 네 금색 모서리 |
| `J02` | 목록·옵션의 작은 파란 선택 표시. 켜진 상태는 중앙 점으로 구분 |
| `A02` | 왼쪽 생산창의 돌·눈금 장식 |
| `A03`·`A04` | Storm Power 결정 그림·숫자 배경 |

타입의 클러스터 이름으로 셰이프를 찾고 기존 팔레트 변환을 사용한다. 질감과 모서리는 원본 픽셀 크기를 유지한다. 버튼에는 밝은 위·왼쪽과 어두운 아래·오른쪽 테두리를 붙이고, 마우스 호버·누름·키보드 선택을 표시한다. 새 그림 파일은 만들지 않았다.

## 화면별 적용

- **캠페인 선택:** 약 238×304px 돌 창, 작은 세 그룹 목록과 Back 버튼. 첫 장 설명은 원본 세 문단을 영어·한국어로 표시한다.
- **옵션:** 타이틀 버튼 옆의 작은 펼침 메뉴. 해상도·효과음 음량·음악 음량은 클릭으로 하위 목록을 열고 값을 직접 선택한다. 화면 끝에서 하위 목록이 넘어가면 왼쪽에 연다. 바깥 클릭과 Esc로 닫으며, 비활성 항목이 뒤쪽 타이틀 버튼을 실행하지 않게 막는다. 일반 와이드 화면은 기존 결정대로 시야 확장을 사용하고 레터박스는 개발용 명령줄에 남긴다.
- **브리핑·튜토리얼·승패·재도전:** 큰 파란 창을 본문 길이에 맞는 작은 돌 창으로 교체했다. 첫 브리핑의 기본 폭은 350px, 성공 창은 374px이며 문구·버튼이 길면 늘어난다. 본문이 창 높이보다 길 때만 스크롤한다. 지도는 원본처럼 밝기를 유지한다. 미션 창은 사이드바를 제외한 플레이 영역의 가운데에 배치한다.
- **미션 메뉴·떠나기 확인:** 작은 돌 메뉴 막대와 Game 목록, 390×148px 확인 창과 문구 폭에 맞는 세 버튼을 사용한다. 한국어 문구도 적용했다.
- **지식 창:** 기존 원소별 카드 격자와 유닛 그림을 유지하고 원본 돌 질감·금색 모서리·작은 Back/OK 버튼을 적용한다. 상세창은 440×400px이며 긴 본문은 스크롤한다.
- **플레이 HUD:** 폭 84px의 왼쪽 생산 창(덱)에 원본 `A02` 바탕, 다리 칸 2열, 유닛 칸 1열(골렘 → 등록 유닛)과 아래 미니맵을 둔다. 버튼 격자는 없다(2026-10-02, [생산 창 문서](clone-deck.md)). Storm Power 숫자는 원본처럼 실제 값을 천천히 따라가며(차이 300 초과 100·30 초과 10·그 밖 1씩, 초당 약 60번) 표시 숫자로 흰색·노란색·빨간색을 고른다. SP가 모자란 유닛을 누르면 숫자가 깜빡인다. **2026-10-02부터 원본처럼 상단 줄·하단 상태줄이 없다.** 메뉴 막대는 Esc로 열고, 알림은 지도 아래쪽에 잠깐 띄우며, 타이머는 T로 켠다([녹화 최종 판독](../videos/record-play-final-20261002.md#화면)).

## 검증

`vm-debian-codex`의 Linux GUI에서 클론을 실행했다. Release 빌드와 기존 Assets 187·Core 227 검사 **414개 통과**, 실패·건너뜀 0이다. 원본 실행·OS 입력 없이 공통 마우스 상태를 주입하는 UI 검사로 메뉴 → 비활성 항목 → 캠페인 → 브리핑 → 전투 → 건설 커서 → 다리 집기 → 떠나기 → 메뉴 복귀 → 옵션 하위 목록을 확인했다. 1280×720 선택, 전체화면·창 복귀와 효과음 4·음악 3 저장도 확인했다.

640×480·1024×768(4:3), 1280×720(16:9), 1280×800(16:10)의 메뉴·브리핑 PNG를 확인했다. 각 크기의 높이를 `--view-height`에 함께 지정해 원본 크기의 글씨를 검사했다. 크기 전환 직후의 SDL 화면이 안정되도록 자동 캡처 앞에서 45프레임을 기다린다.

승리·실패·확인 창은 Git 제외 폴더의 별도 미션 스크립트에 검사 버튼을 넣고 **기존 Tell/MissionAbort 동작으로** 열어 검사했다. 원본 파일은 수정하지 않았고 실제 전투를 승리·패배까지 완주한 검사는 아니다. 다음 미션 비활성과 승리 창의 메인 메뉴 복귀, 확인 창의 미션 계속 동작을 확인했다.

PNG·로그·검사 스크립트는 Git 제외 `extracted/screens/ui-original-20261001/`에 있다. Windows 검사 스크립트는 새 배치에 맞춰 `tools/clone_ui_smoke.ps1`을 갱신했으며, 그 안과 동일한 논리 좌표 입력을 Linux에서 실행했다. 새 외관의 Windows GUI 실행·실제 소리 청취는 이번 검증에 포함하지 않는다.

## 남은 외관 차이

원본 Arial 캐시 글리프, 체크 표시의 정확한 상태 조합, 메뉴·질감의 전역 정렬과 스크롤바의 모든 장식은 추가 대조가 필요하다. 하단 상태줄은 2026-10-02에 없앴다(원본에 없음). 왼쪽 생산 창의 명령 버튼은 2026-10-02에 없앴다. 실제 유닛별 생산 등록 흐름과 카드 수를 원본처럼 동적으로 구성하는 일은 기존 UI 후속으로 남긴다.
