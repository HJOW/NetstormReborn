# 네 번째 녹화 분석의 클론 적용

2026-10-02, Windows `HJOW-Athlon`. [원본 녹화](../videos/ui-controls-record-play-20261001.md),
[옵션 분석](options-menu.md), [원본 조작키](../gameplay/input-controls.md),
[전체 도움말 원문](../sources/in-game-help.md)을 클론에 반영했다.

## 옵션

파란 원은 켜진 항목이나 현재 선택 값에만 그린다. 꺼진 항목은 원 없이 흰 글씨로 유지하며 다시 클릭할 수 있다.
어두운 행 강조는 마우스 위치만 나타낸다. 해상도·음량 목록을 클릭하면 자식 목록이 열리고 다른 행을 클릭하면 목록을 바꾼다.
토글과 값 선택 뒤 부모·자식 메뉴를 모두 닫으며 재개방하면 저장된 상태를 표시한다. 목록 밖 클릭도 닫힘으로 소비한다.
음량은 `Volume 1~5` 중 한 값에만 마크를 표시한다. 원본 목록에 없던 Pause 행을 메인 옵션에서 제거했다.

메인 메뉴와 미션의 Esc → Options가 같은 구현·설정을 사용한다. Wind Noise는 원본 `distantWindQuiet-3000.wav`를 반복하고,
Sound On·볼륨을 따른다. Speaker Swap L/R은 스테레오 PCM의 두 채널을 교환한다. 이 두 항목은 원본 녹화에서 변경하지 않았으므로
동작 구현은 옵션의 의미와 원본 자산을 사용한 클론 처리이며 원본의 재생 배율·재생 시점까지 실측한 결과는 아니다.

## 도움말

메인 Help·F1·미션 View → General Help·유닛 About·지식 카드에서 같은 창을 사용한다.
배포 아카이브의 `d/help.english` 전체를 읽는다. 138개 앵커 정의 중 대소문자·중복을 합친 목적지는 127개다.
연속 앵커 별칭은 본문을 공유하고 중복 정의는 기존 파서의 첫 정의를 유지한다. 녹화에서 확인한 첫 `unitHelp` 목록이 표시된다.

파란 내부 링크는 해당 주제로 이동한다. Back은 이전 주제와 스크롤 위치를 복원하고 OK는 닫는다.
본문·손잡이 드래그와 휠 스크롤을 지원하며 본문만 창 내부에서 잘린다. `<info>`의 유닛 그림·능력치 머리는 고정한다.
지식 카드에서 연 상세창의 Back은 격자로, OK는 격자까지 닫는다. 일반 도움말은 Esc로 닫히지 않는다.
미션 안에서만 F8 안내를 넣고 태그 경계의 공백·원본 CP1252 문자·인라인 삽화와 링크를 보존한다.
외부 HTTP(S) 링크는 사용자가 클릭하면 기본 브라우저로 연다. 구형 `cmd:Tell,TechSupport`는 회색으로 표시하며 실행하지 않는다.

UI는 한국어·영어를 지원하고 D2Coding을 사용한다. 도움말 한국어 자산이 없으면 기존 자산 로더대로 원본 영어 본문을 사용한다.
문서의 한국어 정리를 게임 번역으로 자동 간주하지 않았다. 일부 공격 유닛의 미확정 Damage 표시는 기존 `?`를 유지한다.

## 우클릭과 생산

- 사제: Construct → Temple / Workshop / Altar, 지식 보기, About. 건설 목록의 이름·비용은 실제 타입 정의를 읽는다.
- 완공 워크샵: View Current Production, Put Knowledge into Production, Upgrade, Salvage, About.
- Available은 원소 조건에 맞고 아직 등록하지 않은 지식이다. 등록하면 목록에서 빠지고 현재 생산·사이드바에 나타난다.
- 템플이 공급하는 Golem은 워크샵 Available에서 제외하고 등록 명령도 거부한다. UI 검증에서 발견한 기존 규칙 누락을 함께 수정했다.
- 등록은 해당 워크샵 ID로 명령을 보내며 기존 2/3/4칸·소유권·완공·중복·기술 허용 규칙을 따른다.
- 생산 항목은 Cost·About을, 실제 내 유닛은 소유 정보·Salvage를 보여 준다. 들고 있지 않은 다리의 About은 Bridge 주제로 연결한다.
- Sun Workshop Upgrade는 표시·실제 차감을 800 SP로 맞췄다. 다른 원소는 기존 1,000 SP를 유지한다. 업그레이드 시간은 이번에 새로 확정하지 않았다.

공개 캠페인의 주요 키와 카메라 조작은 [조작키 문서의 클론 적용 절](../gameplay/input-controls.md#클론-적용-2026-10-02)을 따른다.
팝업이 입력을 소비한 프레임에는 뒤쪽 지도까지 같은 클릭을 전달하지 않으며 가장자리 스크롤을 차단한다.
도움말·옵션·우클릭 목록 중에도 세션 시간은 흐르고 기존 브리핑·승패 안내의 정지는 유지한다.

## 검증과 남은 범위

Release 빌드 성공, 경고·오류 0. Assets 197개·Core 246개 **총 443개 통과**, 실패·건너뜀 0.
원문 별칭·첫 정의·목차 목적지, 링크·그림·미션 조건문, Back의 스크롤 복원, 채널 교환과 이전 설정 호환성,
Sun Workshop 비용·등록·소유권을 검증했다. 테스트 빌드에는 기존 `TextResourceTests`의 CA2014 경고 1개가 있다.

Windows에서 클론 자체 입력을 주입해 도움말 링크·Esc 무반응·본문 드래그·고정 머리·Back/OK,
옵션 꺼짐·음량 선택·닫힘·저장, 사제 건설 메뉴, 미션 옵션, 지식 상세창의 격자 복귀를 확인했다.
워크샵의 Available 3개 → Rain Generator 등록 뒤 2개 → Whirlibase 등록 뒤 두 생산 항목·사이드바 표시,
생산 아이콘의 Cost·About 메뉴도 확인했다. 두 등록 동안 SP는 2,200으로 유지됐다.
F2/F7 표시 변화와 Shift+F9 정지 중 시계 고정·재개 뒤 시계 증가를 PNG로 대조했다.
기존 1-1·1-2 메뉴 진입, 건설 커서·다리 집기·떠나기, 해상도·전체화면·음량 저장 검사도 통과했다.
스크립트는 `tools/clone_help_options_smoke.ps1`·`tools/clone_ui_smoke.ps1`, PNG·로그·미션 입력은
Git 제외 `extracted/screens/ui-analysis-20261002/`에 있다. 원본 게임은 실행하지 않았다.

재실행은 `powershell -File tools/clone_help_options_smoke.ps1`이며 `-Mode Mission` 또는 `-Mode Workshop`으로
미션 팝업·정지 검사와 작업장 등록 검사를 선택한다. Workshop 모드는 클론의 검사 명령으로 `(98,98)`에
Sun Workshop을 짓고 게임 시간 25초를 진행한 뒤 UI를 조작한다. 원본에 입력하지 않는다.

Auto-Demo·Tell Tips at Startup·Pass Server Diagnostic은 기존 미구현 상태로 비활성이다.
채팅·온라인 목록·테마 표시·파일 캡처·마지막 손실 위치의 단축키도 아직 연결하지 않았다.
우클릭 메뉴의 모든 원본 계층·Player 하위 항목·미확정 명령까지 구현한 것은 아니다.
실제 소리 청취·원본과의 채널 교환 청취 비교, 원본 포획·의식 구간의 입력 지연 재현은 이번 검증에 포함하지 않는다.
