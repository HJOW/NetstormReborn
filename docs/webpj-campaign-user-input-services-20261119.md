# WB04-E856 캠페인 Client 사용자 입력 장치

기준선 `225553df`의 `BindCampaignUserInputServices`를 이식해 현재 Client의 정지·객체 진단·이동 진단점·커서 출력과 동일 커서 선택기, 로컬/원격 조기 희생 안내를 GameWorld의 선택·강조·운반 입력에 연결했다. 실제 Session이 아직 제공하지 않는 일반 전투 희생 메뉴는 선택된 때 명시 오류로 남긴다. 기준선 뒤 해당 C++ 파일 변경은 없다.

단위 검사에서 현재 정지 상태와 Session 재조회, 각 장치의 인자·진단·누락 경계를 확인했다. 실제 TheWarBegins `CampaignGameWorld`의 사용자 입력 통합 검사에 이 연결을 적용해 사제 선택, 강조, 일반 클릭·미니맵 이동과 로컬 전송을 확인했다. 집중 검사 2건과 Node v26.13.0 전체 회귀 6,370건이 통과했다(실패·취소·건너뜀 0).

실제 브라우저 Client 장치와 사용자 사건, 일반 전투 희생 메뉴 및 포획·희생 검증은 남아 있다. 원본 게임 창은 실행하지 않았다.
