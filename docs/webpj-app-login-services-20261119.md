# 앱 로컬 Login 공통 장치 (WB04-E897, 2026-11-19)

기준선 `225553df`와 현행 cpppj의 `CampaignClientServices.cpp`를 대조했다. 앱의 실제 `GameData`, Client 전역과 시계에서 로그인 정수 설정·포트·벽시각·게임 시각을 읽고, 현재 메뉴와 표시 무효화 및 Player 안내·진단을 연결했다. Player UI 관문은 원본처럼 비전투·미션·대본 중단을 먼저 제외하고 나머지에서 현재 Session의 전투 종료를 조회한다. 누락된 World를 성공으로 처리하지 않는다. 명시적으로 전달한 Login 장치는 기본 장치보다 우선하며 `null`로 지정하면 기존 누락 관문을 유지한다.

cpppj가 사용하는 C 런타임 `std::clock()`은 브라우저에서 직접 제공하지 않으므로 현재 Client 시각 공급원의 단조 밀리초를 사용한다. 이 값은 로그인 타이머·시간 응답에 쓰이며 cpppj와 L2 비교할 때 차이가 날 수 있다. 고정 시각 모드에서는 같은 Client 공급원의 가상 밀리초를 읽는다. 실제 진행 창·UI 모드·팔레트·Renderer 및 입력 뒤 분리 타이머는 아직 연결하지 않았고 기본 Pump 타이머 동작을 유지한다.

실제 Tutorial1 `BridgeTheGap`의 State7→8 로컬 로그인에서 테스트가 공통 설정·시계·Player 장치를 제공하지 않고 앱 장치를 사용해 Ready까지 진행했다. 진행 창·카메라·소리 등은 여전히 검사 장치다. 앱 Login·설치·시계 검사 6건과 실제 World 검사 2건이 통과했다. 원본 게임 창은 실행하지 않았다.

정해진 주기의 Node v26.13.0 전체 회귀는 6,448건 통과, 실패·취소·건너뜀 0이다. 이식 대응표는 1,160행 구조 오류 0이다.
