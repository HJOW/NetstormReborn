# 세션·화면 허브와 월드 경계 재기준선 판정

WB04-E511은 기존 이식분의 마지막 4단위를 각 행의 base와 후보 `225553df`로 대조했다. 모두 **③ 후속 연결**이다. 기존 37단위의 변경 판정은 끝났지만 이 판정은 허브 구현이나 기준선 전환의 완료를 뜻하지 않는다.

| 단위 | 확인한 변경과 남은 작업 |
| --- | --- |
| `ClientMain` | Client 수명의 저장소·패킷·현재 Session 장치와 Runtime 보유, 프레임·입력 및 설정 연결이 늘었다. 실제 단독 세션과 현재 소유 수명은 4-D에서 조립하고 브라우저 입력·표시 주기·언어·WebMCP 적응은 6·9·10에서 처리한다. CD·Win32 장치는 웹 제외다. 줄바꿈 차이를 제외한 두 소스 차이는 373줄 추가·49줄 삭제다. |
| `UberGump` | World·Session 선택과 정리 순서, 미션 진입·입력·화면 허브, Frame Rate·Difficulty·Skirmish·언어 경로가 확장됐다. 단독 미션은 4-D·5-C·6에서 연결하고 후순위 설정은 9·10에서 처리한다. Editor와 LAN은 제외한다. 후보 오라클의 Campaign·Options 차이도 해당 후순위 기능에서 해소해야 한다. |
| `RawPlayerRegular` | Native와 typed가 공통 `RunPlayerRegular`를 쓰고 Template State 조회부터 현재 owner 통지까지 실제 Runtime을 보유한다. 웹의 현재 독립 처리기는 있으나 명시 반납을 포함한 Session 수명은 4-D 조립에서 연결·검증한다. |
| `RawRunePostPop` | 기존 같은 풀의 Dais 검색을 정적 공유 진입으로 분리했다. 웹은 독립 인스턴스 검색을 갖고 있으며 실제 Native 정기 소비자가 같은 풀·현재 역할 조회를 공유하도록 4-D에서 연결한다. |

기존 메인 루프·카메라·Player 정기·룬 검사 34건이 통과했다. 이들은 독립 부품 계약이며 Tutorial1의 L2 세션·화면 검증이 아니다. 신규 176단위의 도구 규칙·대응표 반영, 오라클 및 기준선 전환, 위 ③과 기존 미이식 작업은 계속 남는다.
