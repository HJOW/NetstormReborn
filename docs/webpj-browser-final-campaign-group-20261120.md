# 마지막 캠페인 묶음 진입과 다리 손상 (WB04-E1016)

Complete Victory의 BreakingThrough·ToTheRescue·Vicious·EnemyTerritory·FinalConfrontation을 실제 목록의 직전 완료 조건과 Guide·World에 연결했다. 마지막 미션의 윈드 플라이어 공격에서 다리 약화가 FrameCodeTable을 코드 배열로 오인하던 오류를 발견해 같은 World 표면의 코드 배열을 연결했다.

실제 Session 다리 약화를 포함한 Node 검사 24건과, 각 미션의 Chromium 목록 선택·브리핑 종료·게임 시계 6초 검사가 통과했다. 테스트에 직전 미션 완료 값을 입력했다. 각 목표·승리·자연 완주와 HUD 및 장시간 전투는 아직 미검증이다.
