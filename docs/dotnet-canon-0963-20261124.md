# dotnetpj 0.963 — Carrier/Construction 고정 F 설치·대여 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 Carrier 15행·건설/연구 8행의 고정 F 설치·대여와 4종 송신 옵저버를 이식했다. 0.962의 0x22 참가자 이동과 제품 기존 경로는 바꾸지 않는다. 각 수신 본체(주문 효과·타이머·Meltdown·건설 확정 등 월드 몸체)는 RU-5/R5 후속에서 잇는다.

## 변경과 원문 대응

- `NativeCarrierPacketReceivers.Install/Bind`는 원문 15행(타입·고정 F·길이·옵저버 구분)과 설치 순서를 이식한다. 빈 행은 비NULL 빈 옵저버, 0x5f·0x7d·0x75는 각 송신 길이 확정 옵저버를 둔다. 수신 람다는 장기 game만 캡처하고 호출 시점에 현재 Session/Runtime을 선택한다. 0.963에서 추가됐다.
- `NativeConstructionPacketReceivers.Install`·`BindCommandReceivers`·`BindDataReceiver`·`BindFactoryResearchReceiver`·`BindReceiver`는 원문 8행과 3e→3f 등록 순서·buildingData 확인 뒤 37 대여·58h 연구 대여 구분을 이식한다. 0x3f는 건설 송신 길이 확정, 0x37은 NULL 옵저버를 둔다. 0.963에서 추가됐다.
- 4종 송신 옵저버(`ObserveBombEffectPacket`·`FinalizeBombTimerPacket`·`FinalizeMeltdownPacket`·`FinalizeConstructionPacket`)는 원문 길이 확정식((count+5)*2·(count+11)*2·(count+10)*2·sidCount*2+0x1b)과 count -1/sidCount 255 진단, 수신 방향 무동작을 보존한다. 0.963에서 추가됐다.
- `HostSession.ReceiveFixedCarrierPacket/ReceiveFixedConstructionPacket`은 고정 F별 호출 자리다. 검토 행은 본체 미연결을 명시 실패하고 미등록 F는 범위로 거부한다. World 수명을 건드리지 않으므로 수명 가드는 각 본체 이식 때 둔다. 0.963에서 추가됐다.
