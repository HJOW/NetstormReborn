# Session 사제 공황 결선 (WB04-E644)

기준선 `225553df`의 `RawCampaignPanic.inc` 12줄을 같은 Session의
실제 `RawPriestPanic`·Pool·신전 조회·HP·지형 해시/지역·공유 게임 난수·
TYPE 속도표·Carrier 대상과 경로 시작기에 결선했다. 관련 cpppj 소스는
기준선 뒤 변경이 없다. `ConnectMotion`의 3930줄 중 공황 부분이며,
의식·명령·경로 송신과 `Load()`는 아직 남았다.

원본 signed 좌표 절삭과 지역 좌표의 단정도 저장, 난수 한 번당 65536
범위 소비를 유지한다. 실제 Host 정리 뒤 공황 callback 대여를 반납한다.
`loaded`를 임의로 바꾸지 않는다.

신규 검사 3건은 선행/중복 설치와 반납, 실제 Pool·지형 해시·좌표 경계·
공유 난수/지역, 부상 사제의 본체 진입·신전 경로 인자 및 일시 속도 두 배와
복원을 확인한다. 마지막 검사의 신전 조회와 경로 시작은 관측용 대역이다.
원본 `priest-panic-x86.tsv`의 600행 직접 소비 검사와 기존 이동 본체를
포함한 집중 검사 10건이 통과했다. fixture SHA-256은
`2edee42327cb649db426ff16470992fb6512bd44864c559b8a45d0ca4b631ffa`다.

Node v22.23.3·v26.13.0 전체는 각각 6,059건 통과, 실패·취소·건너뜀 0이다.
v24는 사용자 지시대로 생략하고 호환을 가정한다. 대응표 1,160행 오류 0이다.
