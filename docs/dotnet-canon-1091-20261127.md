# dotnetpj 1.091 — 제품 GumpForm 통지와 UI 종료 수명

2026-11-27, HJOW-Athlon. 1.090의 장기 GumpForm 통지를 실제 공통 Gump 등록표에 연결했다. 통지 시 현재 등록 ID를 읽고 생산 패널 소유 노드는 생산 가상 부모 소실 처리로, 나머지는 공통 Kill로 보낸다. 같은 UI 수명에서 GumpForm 삭제를 장기 물리에 전달하고 다른 Form의 기존 삭제 경계를 보존한다. 종료 때 생산 패널·채팅과 HTML 창을 세션보다 먼저 정리하고 UI 통지 대여를 반납한다.

- 실제 공통 트리·생산 패널·SID 풀에서 통지를 보내 생산 노드 및 일반 노드의 지연 정리, 기존 삭제 경계 복원을 확인했다. 검사에 마련한 Form 슬롯의 통지 시험이며 제품의 생산 Form 생성/부착이나 플레이 검증은 아니다. 관련 집중 검사 7/7 통과, 실행과 검사 Client DLL 해시 일치.
- Game Release 빌드 성공, `cpp_sync.py` 종료 0. `thewarbegins`, `tutorial1`, `surrounded`의 CPP/DN 실행은 각각 종료 0, DN 90프레임 덤프는 0998과 바이트 일치한다. 원본 1,392파일은 세 감사에서 불변이다. 기존 CPP-DN 차이로 비교 도구 종료 1이며 결과는 `extracted/dotnet-l2-1091-gump-ui/`에 있다.

생산 Form 생성·실제 부착·삭제 본체, 내용물/유지/입력, 전체 UberRoot 및 인벤토리 L4a 일치는 미완료다. 최초 통지의 바탕이 된 GumpForm 몸체는 현재 cpppj의 동적 TYPE/공장 연결과 차이가 있으므로 실제 생산 Form을 활성화하기 전에 그 수명과 분배를 확인한다. 1.089 실제 창 Enter 전달도 여전히 미확인이다.
