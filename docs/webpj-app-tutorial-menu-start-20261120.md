# 웹 첫 튜토리얼 메뉴 시작 (WB04-E985)

Campaign → Early Missions 목록에서 첫 Tutorial 행의 `MissionBegin,Tutorial1`을 선택하면 현재 Client Guide가 미션을 생성한다. 기존 프레임이 이어서 실제 Fort 요청·로컬 로그인·Start·첫 안내와 월드 표시를 진행한다. 중복 시작 및 현재 World의 미구현 교체는 거부하고, 아직 Tutorial1 실행기만 연결되어 다른 미션은 미지원으로 알린다.

이 연결은 원본 명령 큐 전체 소비자가 아직 없어 대화상자 명령에서 Guide를 직접 호출하는 임시 웹 경계다. 명령 고리·일반 입력 소비, 다른 캠페인 미션, HUD·게임 조작, 종료/재시작 및 실제 브라우저 조작 검증은 남았다. 첫 Tutorial이 완전히 플레이 가능하다는 뜻은 아니다.

실제 Campaign 목록의 두 행에 포인터를 보내 Guide 생성부터 Tutorial1 로그인·Start·안내·월드 출력까지 검증하고 중복 및 다른 미션이 현재 Guide를 바꾸지 않음을 확인했다. 미션 명령 원본 1,002행, 대화상자·외부 접근 검사 등 연관 Node 검사 32건이 통과했다. E978 고정 Node 26 전체 6,556건은 실패·건너뜀 없이 통과했고 E982 고정 Node 22 전체 검사가 실행 중이다.
