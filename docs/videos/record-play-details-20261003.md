# TEST01 녹화 후속 구현: 버튼 효과음·선택 사거리·Crossbow 방향 (2026-10-03)

AGENTS.md·LEFT_JOBS.md를 읽고 `playingVideos/20261003T074745758Z-adc787856962/`의 기존 영상·WAV·입력 JSONL을 다시 대조했다. 이번 작업에서는 원본 게임을 새로 실행하지 않았다. 원본 파일과 AGENTS.md는 보존했다.

## 자료와 시각 맞추기

- 기준 녹화는 1280×960, 452.27초, 13,552프레임이다. 게임의 1024×768 화면이 Windows 125% 배율로 캡처됐다. 입력 좌표를 클론 논리 좌표로 옮길 때는 1.25로 나눈다.
- 영상 시각 = `recordingElapsedMs / 1000 - 0.0488`. 녹화 시작과 첫 영상 프레임 사이 48.8ms를 보정했다. `sessionElapsedMs`에는 녹화 전 시간이 포함돼 있다.
- 효과음은 `tools/audiomatch.py`로 원본 sound 파일과 녹음의 정규화 상호 상관(NCC)을 계산했다. 기본 임계값 0.55와 `button.wav`만 낮춘 0.30 결과를 구분했다. 낮은 점수만으로 소리 대응을 확정하지 않았다.
- 원본 실행 파일의 디컴파일과 x86 명령도 대조했다. 아래 함수 주소는 `originals/Netstorm.exe` 10.78 기준이다.

## 선택·배치 사거리

원본 `004d5c90`의 선택 경로가 `00474240`으로 표시 대상 타입을 확인하고 `00474900`으로 Range 객체를 만든다. 생성은 `00474520`, 직선 갱신은 `00474c30`, 원형·부채꼴 갱신은 `00474ed0`이다.

발자국의 화면 중심을 기준으로 칸 좌표를 16:11 지면 비율에 맞춰 그린다. 원형은 화면에서 타원으로 보인다. 사제·워크샵·신전·발전기·방벽에는 이 공격 사거리 표시를 적용하지 않는다.

- 직선 점 개수 = `floor(range / 5)`, 실제 간격 = `range / 개수`. 아이스는 여섯 점·5칸, 썬더는 여덟 점·5.25칸이다. `00474c30`의 FPU 나눗셈·나머지 연산도 확인했다.
- 직선은 15칸/초로 바깥으로 흐르고 처음 열릴 때 중심에서 차례로 나타난다. 원형·부채꼴은 반지름이 15칸/초로 커지고, 선택을 풀면 30칸/초로 줄어든다. 직선은 선택 해제 즉시 사라진다.
- 원형은 최대 사거리에 도달한 뒤 원본의 전역 시각 소수부 × π 회전을 사용한다. Crossbow의 원 밖 점은 가까운 ±30도 경계로 접혀 V를 만든다.
- 선택된 완공 건물과 배치 미리보기가 같은 구현을 사용한다. 배치 커서를 들면 선택 표시를 대신하고, 생산 창 위에서는 미리보기를 숨긴다. 일시정지 시 위치·반짝임 그림을 유지한다.

## Crossbow 배치 회전과 사격

녹화 105.0초는 북쪽 V 표시다. 우클릭 누름/뗌이 **105.878/106.023초**, **107.171/107.294초**에 (624,415)에서 기록됐다. 106.0초에는 동쪽으로 바뀌며 새 표시가 중심에서 열리고, 108.0초에는 남쪽 V를 확인했다.

기존 클론은 고정 캐논 이외의 배치 우클릭을 취소로 처리해 Crossbow가 회전하지 않았다. 이제 우클릭 시 Crossbow의 그림·V 표시가 같이 회전하고 설치 명령에 방위를 전달한다. 저장된 `L/M/N/O` 및 각 묶음의 `P` 조준 그림도 해당 방위로 읽는다. 새로 놓은 그림은 선택한 방위의 기본 프레임을 쓴다.

사격도 표시와 같은 ±30도 안의 목표 중심으로 제한했다. 뒤쪽의 더 가까운 적을 자동 조준하지 않는다. 원본의 큰 목표 가장자리 허용·세부 조준/발사 애니메이션은 아직 복원하지 않았으며 기존 탄속·피해 모델도 근사다.

사용자 확인 캐논 규칙은 유지한다. **썬 캐논은 방향을 정하지 않고 설치한 뒤 목표에 맞춰 스스로 회전한다. 아이스·썬더 캐논은 설치 전에 방향을 정하고 이후 그 방향으로만 공격한다.**

자동 입력은 클론 자체 입력만 사용하며 원본과 OS의 다른 창을 조작하지 않는다. 평소 설정과 분리한 `NETSTORM_SETTINGS_DIR`에 검사 설정을 저장한다.

## 남은 정밀 대조

- `range` 그림의 실제 프레임 간격·개별 초기 위상은 미측정이다. 기존 24Hz 추정을 유지했다. C 묶음 사용 조건도 미확인이다.
- 원본 클릭음의 입력→재생 지연·버튼을 누른 채 유지하는 연출, 브리핑 창 크기·글꼴은 별도 정밀 대조가 남았다. 재생 API의 성공을 실제 청취 대조 완료로 해석하지 않는다.
- 공중 기지 사거리 표시 구현은 Rain/Wind 공중 공격체의 전투 구현 완료를 뜻하지 않는다. 주문의 분홍 표시도 커서·주문 모델이 연결돼야 실제로 사용할 수 있다.
- 배치·건설 연출, 정확한 그림자, 다른 효과음 대응·스테레오 위치, 전투 애니메이션, 안정적인 30FPS와 60/120 설정은 후속이다.
