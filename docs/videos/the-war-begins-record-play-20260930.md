## 구현에 필요한 확인 사항

1. **지식 창의 실제 모양을 확인했다.** 기존 [정적 분석](../exe/show-technology.md)은 원소별 타입을 나열한다고 설명했으나 실제 창은 원소별 4행 그림 카드 격자다. 밝기 차이가 있는 카드가 섞여 있다. 카드가 어두운 정확한 조건은 화면만으로 판정하지 않는다. 현재 클론의 이름 목록 창은 원본의 카드 배치·그림과 다르다.
2. **섬 테마와 소유권 전환을 영상에서 재확인했다.** 폭발 전후 2초 이내에 갈색·빨간색에서 초록·주황색으로 바뀐다. 기존 [섬 소유권 문서](../gameplay/island-ownership.md)의 해석을 뒷받침한다. 신전 파괴 직후 성공 창은 뜨지 않고 약 2분 15초 뒤에 나타난다. 신전 파괴만으로 승리했다고 처리하면 이 플레이와 맞지 않는다. 10 FPS 영상으로 내부 처리 순서까지 구분할 수는 없다.
3. **승리 후 다음 미션 진입 흐름을 확인했다.** 성공 창에서 `Next Mission`을 선택하면 `Master of Whirligigs`의 새 지도와 브리핑, 2,000 SP가 나온다. ~~사제 포획·희생·승리 이벤트의 정확한 연결은 미확정~~ → **2026-10-01 소리·영상·exe·사용자 설명으로 확정**: 신전 파괴 → 적 사제 기절(보호막) → 골렘으로 포획해 내 제단으로 운반 → 의식(희생 음악, 다섯 룬) → 제단 소멸 → 적 사제가 더 없으므로 `[Succeeded][BadTeamDead]` 성공 창(게임 정지). 신전 파괴부터 성공까지 약 2분 15초는 이 과정 때문이다. 상세: [음악·의식 분석](../exe/music.md).
4. ~~설명창 중 게임 시간 정지 여부는 추가 판독이 필요하다.~~ → **2026-10-01 확정: F6 지식 창·상세창은 게임 시간을 멈추지 않는다.** 09:25.0~09:38.2 에 창이 열린 채로 SP 가 3,450(09:26) → 3,650(09:36)으로 늘었고, 창이 열린 네 구간 모두 `whirligigFire`·`whirligigSpin` 전투 소리가 이어졌다. 게임 코드가 직접 여는 창은 멈추지 않는다는 [정적 분석](../gameplay/dialog-pause.md)과 같다. 반대로 스크립트 성공 창은 SP 가 그대로다(사용자 설명: 게임 정지).

## 5. 소리 판독 (2026-10-01)

`python tools/audiomatch.py {level|music|sfx} playingVideos/<세션ID>`로 녹음(48kHz float 스테레오, 7조각)을 11,025Hz 모노로 바꿔 원본 `originals/music/*.mus`·`originals/sound/*.wav`와 FFT 정규화 상호상관으로 대조했다. 시각 기준은 `video-0001.frames.csv` 첫 프레임이다(녹음 시작은 그보다 0.11초 이르다).

- **음악(6초 조각):** 방송 음성은 없지만 바람·전투 효과음이 섞여 상관값이 0.1~0.25로 낮다. 대신 **곡 안 위치가 조각마다 정확히 6초씩 늘어나는 연속 구간**으로 곡을 판정했다. 결과: `ser22`(메뉴, ~00:09) → `rain22` 00:09.1 → `thu22` 03:42.7 → `sun22` 07:27.9 → `wind22` 11:20.8 → `sacrifice` 12:06.4 ~ 녹화 끝 무렵. `fanfare.mus`는 없다.
- **효과음(상관 ≥ 0.55):** 195개 효과음 중 570건. 반복이 많은 것은 `whirligigSpinSlow`(227)·`whirligigFire-1000`(113)·`jimbuild`(48)·`distantWindQuiet-3000`(40)·`priestForceField`(31)이다. `openGump.wav`는 창 열기(00:18.6 등), `bridgeFall.WAV`는 다리 붕괴(07:14.7·08:24.7·10:05.4), `sunCannonFire`·`thunderCannonImpact`는 전투, `workshopComplete`(00:37.0)·`upgradeComplete`(01:38.1)는 건설·업그레이드 완료다. 파일 내용이 같은 `openGump`/`openGump-1000`, `impact`/`thunderCannonImpact`, `influenceIcon`/`teleportEffect`는 구분할 수 없다.
