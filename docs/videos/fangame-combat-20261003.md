- Release 빌드 경고 0·오류 0. Assets 255 + Core 437 = 692개 단위 테스트 통과, 건너뜀 0.
- 신규 16건: 접힌 자세의 첫 조준·네 방향 전환·목표 상실/변경·원반/석궁 이동 회피·제거된 목표의 폭발 위치·폭발 그림 순서·석궁 탄 방위·30/120Hz 시간 진행의 결정론.
- 기존 피해·재성장·방어선 테스트는 즉시 발사를 가정하던 시설에 실제 펼쳐진 저장 자세를 명시했다. 반복 재성장은 재조준 뒤 실제 파괴 시점까지 진행한다. 피해·보상 단언을 완화하지 않았다.
- 클론 화면 검사는 `clone_combat_fixture.py`가 배포 자료를 별도 폴더에 복사하고 6시설 맵을 생성한다. 신전 HP만 검사 복사본에서 50으로 낮춰 짧은 시간에 폭발을 확인한다. **실제 캠페인 전투 시간·피해 검증용 맵은 아니다.** 사용자 설정도 별도 폴더를 사용한다.
