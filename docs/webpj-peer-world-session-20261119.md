# WB04-E823 월드와 로그인 서버의 동기화 연결

기준선 `225553df`의 `RawSurfaceWorld::SynchronizePeer`와 `RawCampaignSessionLogin.inc`의 서버 콜백을 연결했다. 같은 Storage의 전송기·현재 공유 Regular TYPE과 월드의 실제 `unpop`·`repop`을 사용한다. 반납한 월드에서 다시 호출하면 거부한다. 기준선 이후 해당 C++ 연결의 변경은 없다.

실제 월드에서 자산을 적재한 뒤 대상별 연결 관문과 송신이 같은 전역을 이용하는지 확인했다. 별도 Login 앞단에서는 서버 콜백을 호출해 같은 World 전역이 갱신되는지 검사했다. 두 경로 및 기존 미션 로그인 fixture를 포함한 집중 검사 94건이 통과했다. 실제 원격 로그인 패킷으로 이 경로에 도달하는 검사는 웹의 멀티플레이 제외 범위이며, Native 고정 수신기와 실제 브라우저 앱 수명은 여전히 후속이다. 게임 창은 실행하지 않았다.

검증: Node v26.13.0 전체 6,315건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E819 Node v22 전체 검사 뒤 v26 전체 회귀 4/8회다.
