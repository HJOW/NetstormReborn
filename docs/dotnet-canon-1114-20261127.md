# dotnetpj 1.114 — 공간 배치 자산의 UI 중첩 삭제 검증

2026-11-27, HJOW-Athlon. 실제 같은 세션 공장으로 만든 TYPE 80 기본 자산을 `PopWorldObject`로 좌표 (50, 60)의 공간 해시에 등록한 다음 Native GumpForm과 UI 등록 노드를 부착하고 세션 삭제를 실행했다.

- 삭제 전에 자산의 void 비트가 꺼지고 해당 해시 버킷 머리에 실제 SID가 있음을 확인했다. 삭제 후 그 버킷은 비었고 자산·GumpForm이 반납되며 UI 통지와 삭제 대기·정리가 이뤄지고 삭제 깊이는 0으로 복귀한다.
- 미배치 기본 자산·Player, 부모 프로세스 Form과 함께 관련 Client 검사 **5건 통과**다. 제품 코드는 바꾸지 않아 게임 재실행 없이 1.111의 대표 세 미션 결과를 유지한다.
- 생산 격자 파생 노드의 부모 삭제와 실제 미션 플레이 중 건물·유닛 삭제는 아직 검증하지 않았다. TYPE 80 한 종류의 성공을 모든 자산 종류의 동등성으로 확대하지 않는다.
