# dotnetpj 1.003 — R4-7c3b 미션 Fort 경로 읽기

2026-11-25, HJOW-Athlon. R4-7 F3 보류 검사 묶음의 R4-7c3b 첫 묶음이다. 미룬 검사 중 미션 Fort 경로의
읽기 쪽(`CampaignMissionFortPath_ConfigMutationDuringReadCannotRenameThatImage`)을 DN 실제 파일·Config·
작업본 읽기 장치로 대조했다. 같은 장면의 다른 검사와 서버 최초 설치 검사는 세션 `LoadLocalConnection`
제품 작업 뒤에 잇는다.

## 변경과 원문 대응

- `dotnetpj/tests/Netstorm.Client.Tests/CampaignReloadSourceScene.cs`: 신규. cpppj
  `tests/CampaignMissionReloadSourceTests.inc`의 `ReloadSourceScene483`과 같은 보호 VFS·다른 실제 작업
  폴더/장부/Config를 함께 유지한다. 임시 작업 폴더·`maps`/`other`/`d` 배치·원본/변경 Fort 입력·영문 대본·
  `fortSpec` 전환·읽기 경로 관측·미션 생성을 묶었다. Fort 경로·재적재 검사가 같은 장면을 빌린다.
  1.003에서 추가됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/CampaignMissionFortPathTests.cs`: 신규 1건. cpppj
  `tests/CampaignMissionFortPathTests.inc`의 두 번째 검사를 옮겼다. I/O가 다음 `fortSpec`을 바꿔도 이번
  이미지의 이름은 읽기에 사용한 경로이며, Guide 교체 뒤 기본 자산 경계는 명시 작업 source로 오인하지
  않음을 대조한다. DN `MissionScript.FortFileReader`·`FileSource`·`GuideMissionScriptLifetime`의 같은
  순서를 쓴다. 1.003에서 추가됐다.
