# 다중 줄 스타일 UTF-16 입력

WB04-E1040은 다중 줄 스타일 파서의 명시 `Uint16Array` 입력을 코드 단위 폭 그대로 보존한다. 원본 바이트 문자열과 `Uint8Array` 경로는 유지하며, 스타일 구간과 `~~` 리터럴도 같은 입력 폭으로 버퍼에 넘긴다.

한글·서로게이트 쌍·굵게 명령·리터럴·태그가 실제 StyleTextBuffer 조각에서 유지되는 것을 확인했다. 다중 줄 파서·버퍼·앱 관련 Node 검사 27건이 통과했다. 다중 줄 Gump와 실제 한국어 화면 출력 연결은 남아 있다. E1039 고정 Node 26 전체 회귀는 실행 중이다.
