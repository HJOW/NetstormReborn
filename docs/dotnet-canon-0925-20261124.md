# dotnetpj 0.925 — RU-3 NSInfo 루트 입력 결선 이식

2026-11-24, HJOW-Athlon. RU-3 열여섯 번째 묶음이다. NSInfo 루트 원문 입력을 같은 실제 CS·정렬표·메뉴·카메라·송신 장치에 연결하는 생산 결선을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HostNsInfoWindows.HandleRootInput`은 루트 원문 입력 event/first/second를 `NativeNsInfoInput.Handle`에 실제 owner로 연결한다. 명령 읽기는 `Read`를, 정렬표는 `_globals.RosterOrder`를, 참가자 물리는 `challenge.Participant`를 빌린다.
- `MousePoint`·`ParticipantMenu`·`CenterOnSid`·`StatusSend`·`KickoffSound`·`BaseInput` 6종을 `HostNsInfoDevices`에 추가했다. 루트 입력 결선에서 사용하며, 미연결 호출은 명시 실패한다. 0.925에서 추가됐다.
- 26비트 마스킹 비교와 원래 세 DWORD 기본 처리는 `NativeNsInfoInput.Handle`(0.911) 그대로 두었다. 결선은 후크 조성만 담당하고 라우팅 본체를 다시 만들지 않는다.

## 검증

- Release 클라이언트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 5건(정렬 메뉴 열기·SID 중심 전달·직접 추방 패킷/음향·비활성/둘째0 기본 전달·미연결 명시 실패)은 통과/실패 0이다. 이웃 `NativeNsInfoInput` 7건을 포함한 31건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0925-*/`의 각 실행 로그와 요약이다.
