# 0.749 커서 데이터와 취득·취소 수명 본체

RawCursorDrop.h의 공유 데이터와 RawCursorLifecycle.h의 나머지 수명 데이터, RawCursorPlacement.h의 위치 데이터, ClientCursorGlobals.h의 고정 데이터 소유자를 이식했다. 30DWORD/120BYTE 미리보기·현재 signed 개수·개별 경고 치수5쌍·두8DWORD 문맥을 유지한다. 일반 reset은 객체/고정 배열을 교체하지 않고 checking/현재 픽셀 참조와 회전 옵션을 보존한다. Drop의 일반 reset은 별도 recording/recorder를 보존하며 잠금1로 준비한다. 단순 raw 입력의 lockDepth0과 실제 Gameplay 최초1을 구분한다.

RawCursorLifecycle의 Take/Cancel/Activate를 이식했다. 잠금/미리보기·콜백 뒤 현재 전역·캡처한 반환 대상을 구분하고, 큰 미리보기DWORD는 실제 SID 소비 전까지 줄이지 않는다. 취소는 잠겨도 실제 Activate1/프로세스 반납/꼬리 정리를 실행한다. 준비·가상 삭제 뒤 현재 개수/목록을 재조회한다. 반환음 뒤 현재 checking과 진단 복귀 뒤 현재 TYPE 비용을 읽으며 중단된 꼬리를 합성하지 않는다. 취득은 원문 두 인자·Form BYTE/WORD·마나/사정거리·문맥/실제 측정·절삭 비용/그림3 추가헤더·현재 마우스 꼬리 순서다.
