# 0.662 AI 경제의 실제 세션 연결

- 일시: 2026-11-20, HJOW-Athlon.
- 범위: 0.658 경제 본체를 실제 세션 메모리·SP·현재 시계·참여 플래그·사제 상태에 연결한다.
- 근거: `cpppj/src/client/RawCampaignSession.cpp`의 경제 조립·`AiPriestCaptured`·`ReconcileAiEconomy`, `RawMissionOutcome.cpp`의 `PriestCaptured`다.

## 구현

`HostSession.AiEconomy.cs`의 경제 장치는 같은 `AiBrainMemory`와 `Sp`를 빌린다. 현재 Player `+0x50 & 0x22`와 사제의 현재 공유 상태9DWORD를 읽는다. 범위 밖 원본 조회는 진단 후 참을 반환하고, 명시 진입점 `ReconcileAiEconomy(owner)`는 owner1..8만 허용한다. brain이 없으면 SP 초기화나 난수 소비 없이 거짓이다.

`BindAiDemo`는 현재 미션 소유자의 조회기를 빌리고 준비·전략·경제가 같은 getter를 사용하게 한다. 일반 미션 기본값은 0이며 실제 `StartDemo` 연결은 R4-7 잔여다. 런타임 행동의 경제 갈고리도 같은 본체로 연결했다. 매 프레임 자동 호출은 나머지 AI 행동 결선 이후에 잇는다.

## 검증

- Release 세션 집중 검사 `HostSessionAiRuntimeTests` 19/19건 통과·실패 0. 기존 10건과 새 경제 검사 9건이다. 결과: `extracted/dotnet-0662/economy.trx`.
- 새 검사는 brain 부재·난수 불변·범위 거부, 같은 시각 중복 지원 방지와 다음 기한, 참여 마스크·공유 사제 상태 6조합과 현재값 변경, 조립 후 데모 getter 연결·현재값 재조회를 확인했다.
- 사제 포획·희생·특정 적 공격·승리의 실제 플레이는 수행하지 않았다. 참여·상태 조합은 명시 메모리 입력이다. 전체 회귀와 일괄 덤프는 0.664에 수행한다.
- 시작 흐름·매 프레임 자동 호출을 바꾸지 않아 시작 덤프에 경제 효과는 아직 들어오지 않는다. L2 전체 일치 판정은 유지하지 않고 별도 관문으로 남긴다.
