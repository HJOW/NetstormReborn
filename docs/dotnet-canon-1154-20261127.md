# 1.154 생산 변경 알림의 현재 세션 갱신

`RawCampaignSession::UpdateProductionContents`의 완전 적재·모드·현재 기술·dirty 관문과 dirty 삭제→현재 템플릿 Deck 재계산→같은 세션 내용물 동기화 순서를 연결했다. 닫힌 관문은 후속 장치를 읽지 않고 dirty를 보존하며, 재계산 중 새로 발생한 dirty는 지우지 않는다. 선택된 재계산의 오류 직전 지운 dirty는 복구하지 않는다. 제품 패널의 갱신 콜백도 같은 현재 세션을 사용한다.

부분 적재 세션을 완전 적재로 바꾸지 않았고 생산 유지 본체도 아직 제품 결선 전이므로 루트 Idle은 계속 꺼져 있다. 실제 완전 적재 세션의 생산 갱신·HUD 입력 및 플레이는 검증하지 않았다. 관문·호출 순서·오류 부분 효과·부분 적재와 기존 패널 집중 검사는 9/9 통과했다.

캠페인1-1의 고정 드래그 다섯 프레임은 1.148과 같고 종료0이다. 튜토리얼1·surrounded 진입/대기도 종료0이며 90프레임 덤프가 1.147과 같다. 각 수집에서 원본 1,392파일은 변경되지 않았다. `extracted/dotnet-production-1154-first/`와 `extracted/dotnet-production-1154-missions/`를 따른다. 최신 정기 전체 회귀는 이 변경을 포함하지 않는다.
