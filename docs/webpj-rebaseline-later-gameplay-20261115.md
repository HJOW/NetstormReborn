# 후순위 게임 규칙 재기준선 판정

WB04-E510은 기존 이식분 6단위를 각 행의 base와 후보 `225553df`로 대조했다. 모두 **③ 후속 단계에서 반영**이며 이번 판정은 해당 기능이나 버그 수정의 완료를 뜻하지 않는다. 원본 10.78 부품과 기존 관측은 유지한다.

| 단위 | 확인한 변경과 후속 작업 |
| --- | --- |
| `PriestSelectionShortcut` | NB20: 커서에 건설 조각이 붙었으면 P/R 사제 선택 전에 취소한다. 실제 선택 입력 연결과 10차 버그 수정에서 반영한다. |
| `RawGameMenus` | Frame Rate와 Difficulty 하위 메뉴가 추가됐다. 웹 표시 주기 설정은 순서 9, 난이도는 11차에서 연결한다. Scenario/Edit 및 AA·FSR은 웹 제외다. |
| `RawAiCreate` | 잘못된 강제 적 번호를 자동 선택으로 정리하는 NB10과 AI 설정 복사본에 난이도 배율을 적용하는 11차 경로가 추가됐다. 실제 AI 생성·동맹 판단과 함께 처리한다. |
| `RawCarrierPickup` | NB18: 내용물을 든 벌프가 사제를 줍는 경우 요청과 수신 양쪽에서 거부한다. 10차에서 실제 세션 스위치와 함께 반영한다. |
| `RawWorldGeyser` | NB04: Even 모드 9개 구역의 처리 순서를 별도 시간 시드 난수로 섞는다. 10차 및 스커미시 연결에서 반영한다. |
| `RawWorldGeyserBounds` | NB29·12차: 비전투 스커미시의 참가자 수를 사용하고 7~8명 예산이 줄지 않게 하는 선택 분기가 추가됐다. 10차·12차에 반영한다. |

기존 선택·메뉴·AI·운반·간헐천 검사 34건이 통과했다. 이 여섯 변경은 대응표 base를 후보로 올리되 3.6절 후속 표와 해당 단계의 요구사항을 유지한다. 난이도·스커미시·버그 수정은 아직 구현되지 않았다.
