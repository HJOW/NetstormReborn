# 0.795 실제 경로 프로세스·프레임·공통 도착·전송

RawPathProcess의 8종 클래스 선택, 실제 같은 Pool/Host/Kernel 부착과 프레임, 정지·도착·자기 삭제, Path 전송 분배를 이식했다. 선행 RawPathHaltParent/ArrivalParent, Animation의 RestFrame/Stop, Walker/Bulf/Balloon frame, RawPathRetarget과 ProcessRemoval도 같은 실제 저장소를 사용한다. 제품 Host/Motion과 30h 수신 설치는 아직 남아 있으며, 이번 실제 Host 검사는 별도 검사 장면에서 수행했다.

검사 중 공통 Host의 부착 순서 오류를 고쳤다. 이전에는 RawBaseProcessAttach가 별도 필드에 쓴 뒤 OnAttached까지 실행하고 마지막에 프로세스 식별자를 복사해, 경로의 OnAttached가 Form/부모 0을 읽었다. 이제 SquidProcess와 부착 부모는 같은 AttachFields를 공유하고 Kernel 등록 직후 PID를 공개한다. Create/Attach/OnAttached 안에서 현재 필드를 읽을 수 있고, 부분 실패도 이미 쓴 필드를 보존한다. CPP SquidProcess.cpp의 참조 필드와 같은 계약이다. 기존 Host·저장소·Kernel 관련 집중 검사도 함께 통과했다.

공통 정지·도착은 지역 checking 값을 복사하되 빌린 owner는 계속 현재값으로 읽는다. 진단 복귀 뒤 capacity·부모·TYPE·소유자·두 대상을 다시 조회하고, 자기 삭제 뒤에는 외부 watch/진단/저장 부모의 clear만 사용한다. 실제 부모의 Halt/Arrival/Cleanup/Search는 명시 장치 경계이며, 미연결 하위를 성공이나 직선 탐색으로 대체하지 않았다. 실제 일반 finder와 기존 재지정 본체를 사용해 겹침/죽은 대상 분기도 비교했다.

워커는 공유 counter와 레인 예약 시각, 벌프는 walkStep 필드·회전 구간·현재 좌표의 난수 음향, 벌룬은 Step 뒤 현재 시각·float 고도·화염 뒤 현재 위치를 보존한다. 정지 애니메이션은 프레임 표를 값 복사하고 원문 구간의 first+1을 Unpop0→쓰기→Repop40 순서로 적용한다. RawPathSurface.Cell도 float 덧셈으로 먼저 반올림하던 부분을 원문 double 덧셈으로 바로잡았다. 입력 .0001f가 경계 1로 바뀌지 않는 것을 확인했다.

전송은 같은 실제 버퍼·현재 헤더와 마지막 writer 선택을 regular/full/Packet/Transmit에 공유한다. Native writer를 선택하면 typed Pool/Form/부모 guard를 먼저 가져오지 않고 changed/force를 그대로 전달한다. 다른 프로세스는 기존 분배 함수로 이어진다. Native 장치의 제품 설치는 후속이다.
