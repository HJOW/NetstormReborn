# 1.155 생산 유지의 같은 세션 결선

`RawCampaignSession::MakeProductionMaintenance`에 따라 실제 세션의 현재 모드·기술·신전·AI Player 기록·시계·SP·Deck·난수와 내용물 생성/삭제, 허용·비용 및 패널 갱신을 `RawProductionMaintenance`에 연결했다. 제품 생산 패널의 유지 장치도 현재 빌린 세션을 사용한다. 미완성 부분 적재에서는 유지 본체가 반환하며 루트 Idle은 계속 꺼져 있다.

같은 실제 자산의 검사 장면에서 부분 적재 시 유지가 비활성임을 먼저 확인했다. 이후 검사에서만 `_nativeLoaded` 표식을 켜고 현재 신전·SP 변경, 실제 Deck 생성, AI 관문, 게임 난수 소비, 다리 내용물 생성과 격자 갱신을 검증한 뒤 표식을 되돌렸다. 이는 완전한 제품 적재나 사용자 조작을 재현한 검사가 아니다. 실제 세션 검사와 원본 명령열86행 등 집중3/3 통과했다.

캠페인1-1 고정 입력의 다섯 프레임은 1.148과 같고 종료0이며 튜토리얼1·surrounded 진입/대기도 종료0, 90프레임 월드 덤프는 1.147과 같다. 두 수집 모두 원본 1,392파일이 불변이다. 결과는 `extracted/dotnet-production-1155-first/`와 `extracted/dotnet-production-1155-missions/`에 있다. 실제 미션의 완전 적재·생산 HUD·사용자 건설과 전체 회귀는 후속이다.
