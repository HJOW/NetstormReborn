# Client 생산 항목 선택과 내용물 통지

WB04-E1030은 생산 격자의 선택을 실제 Session 커서에 전달한다. 원본 순서대로 비활성·지식 잠금·자본·재고·타입을 검사하고, 다리 단축키는 현재 기술 내용물의 슬롯을 순회한다. 실패 안내와 소리 및 화면 갱신은 호출자의 실제 장치를 요구한다.

실제 Tutorial1의 격자 아이콘을 눌러 동일 내용물 SID가 실제 커서 미리보기가 되는 것과 슬롯 단축키의 취득·취소를 확인했다. 이 검사에서 격자가 실제 GumpForm을 가진 상태로 내용물이 변경되면 Player 내용물 통지의 Gump 등록표·가상 처리기가 연결되지 않아 예외가 발생했다. 앱의 같은 등록표와 직접 가상 처리기로 연결해 재검사했다. 최초 검사에는 테스트 변수 중복 선언도 있었으며 수정했다. 관련 Node·대응표 검사 17건이 통과했다. 생산 패널 본체와 브라우저 설치, 비용 부족 안내 UI는 남았다.

E1026 고정 Node 26 전체 회귀는 6,563건 모두 통과했으며 실패·취소·건너뜀은 0이다. E1027 이후 변경의 고정 전체 회귀도 별도로 실행해야 한다.
