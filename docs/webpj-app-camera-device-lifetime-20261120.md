# 앱 미션 카메라 장치 수명 (WB04-E995)

앱의 Uber 카메라 장치를 매 호출마다 새로 만들지 않고 Client 수명 동안 유지한다. 장치는 현재 Screen·Renderer·World와 Gump를 매번 조회하므로 화면 크기 변경에도 동일한 가장자리 타이머와 포인터 경계를 보존한다. 기존 즉시 카메라 적용도 같은 장치를 사용한다. World는 프레임 말미에 적용된 카메라를 표면·입자·음향에 공개하는 `cameraApplied` 경계를 제공한다.

실제 Tutorial1에서 화면 크기 변경 전후 카메라 장치 동일성과 World 표시 갱신을 확인했다. 원본 카메라·가장자리 계산과 Present 관측 등 관련 Node 검사 27건이 통과했다. 실제 프레임의 가장자리 폴링과 Present 후 카메라 적용은 다음 단계다. E986 고정 Node 26 전체 검사는 별도 트리에서 실행 중이다.
