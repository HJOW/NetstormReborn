# WB04-E766 개발자 장치 명령 연결

기준 `225553df`의 `RawCampaignSession.cpp` 5126~5146행 중 `heaptrace`/`ht`, `querydirectdraw`/`qdd`, `addlabel`/`al`을 실제 Session의 31h 해석기에 연결했다. 힙 추적은 정수 변환 실패 때 수준 29의 `bad command`만 출력하고, 성공하면 현재 Client 장치에 0 여부를 넘긴다. 시스템 조회는 선택된 장치를 호출한다. 라벨은 현재 커서가 기록 중이고 두 번째 토큰이 있을 때만 최대 255바이트 토큰을 기록 장치에 넘긴다. 각 장치가 필요한 시점에 없으면 원본 접합처럼 오류를 전파한다.

독립 검사에서 별칭·정수 및 누락·오류·토큰 길이·기록 관문을 확인했다. 별도 TheWarBegins Session을 실제 31h 분배기로 호출해 세 장치와 같은 현재 커서 상태가 연결되는지도 확인했다. 집중 검사 3건이 통과했다. 이 검사는 사용자 지정 제한 행동이나 실제 DirectDraw 조회를 실행하지 않고 장치 호출을 관찰한다. 웹 Client의 실제 장치 구현과 `getpriest` 명령 등 다른 미연결 경로는 남는다.

Node v26.13.0 전체 회귀 6,264건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 검사는 0오류다. E761의 Node v22 전체 검사 뒤 세 번째 v26 전체 회귀다.
