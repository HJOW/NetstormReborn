# dotnetpj 1.112 — 기본 자산의 UI 중첩 삭제와 Player 전처리 관측

2026-11-27, HJOW-Athlon. 공유 Native Surface·실제 세션 삭제 분배와 공통 UI 트리에서 원본 기본 Squid 생성자인 TYPE 80 자산에 GumpForm을 붙이고 자산을 삭제했다. 이 자산은 아직 공간에 배치되지 않은 상태다.

- 공통 삭제 전후 깊이가 0으로 돌아오고, 부착 Form이 반납되며 UI 등록 노드가 한 번 통지된 뒤 정리된다. 제품과 같은 AI 객체 통지 관문을 검사 장면에도 설치했고 관련 Client 검사 **3건 통과**다. 제품 코드는 바꾸지 않았다.
- 최초 TYPE 152 선택은 Player 파생 가상표의 `0x004906C0` 전처리에서 **실제 호스트 장치 미결합**으로 실패했다. 이는 일반 기본 자산 경로와 구분해야 하는 미완료 경계이며 성공으로 세지 않는다. TYPE 80에서는 검사 장면에 공통 삭제 장치가 없어 한 차례 실패했고, 해당 장치와 실제 AI 통지 관문을 구성해 재검사했다.
- 실제 공간에 배치된 자산, 생산 격자 파생 노드와 전체 미션 플레이 중 삭제는 아직 검증하지 않았다. 게임 재실행 없이 1.111의 대표 세 미션 결과를 유지한다.
