# 0.686 기술 표시·생산 재계산·연구 세션 연결

- 일시: 2026-11-20, HJOW-Athlon.
- 근거: `RawProductionDeck`의 기술 표시, `RawCampaignProductionBindings`, `RawPlayerContentNotice`, `RawCampaignSession`의 같은 세션 장치 조립이다. 디컴파일 자료는 변경하지 않았다.
- 상태: 원문 본체와 실제 세션 연결·대표 시작 검증 완료다. 전체 목표는 미완료다.

## 원문 본체

`RawIndicateTechnology`는 같은 Player의 현재 기술 부모를 읽어 mask4/전체 종류DWORD로 검색한다. 반환값의 저장 kind WORD가0이면 현재 부모를 다시 조회하고 실제 내용물을 생성한다. 저장 종류0과 검색 SID 비영을 같은 조건으로 취급하지 않는다.

`RawCampaignProductionBindings`는 실제 두 Factory VT의 현재 레벨+2에서 서로 다른 생산 종류 수를 뺀다. 후보의 free/dead를 추가 필터하지 않으며 금지 표를 조회한 뒤에도 일반 공장 생산은 Deck에 포함한다. 신전 기본 생산만 금지 결과로 제외한다. 재계산은 같은 현재 Factory 목록/owner/TYPE·내용물과 Player+68의 기존 Deck을 쓰며 power·가중합/압축·현재 모드/역할 조회 순서를 보존한다. 원문 모드 진단 뒤 전체 Deck DWORD 재조회도 이식했다.

기존 `Simulation/TotalMade`에 실제 TYPE·현재 세 집계 배열·외부 금지 표를 빌리는 생성자를 추가했다. 기존 독립 입력 생성자의 동작은 유지한다. 같은 현재 TYPE genus의 변경과 장부/금지 표 쓰기를 복제 없이 읽는다. 동결 배포의 근사 `Core/Rules/ProductionDeck`은 수정하지 않았다.

`RawPlayerContentNotice`는 SP 커서/현재 fallback·검사 횟수·현재 PlayerKnown/SP·첫 배열/정확한 WORD 순열의 접두를 실행한 뒤 현재 종속을 순회한다. Gump 등록ID는 전체 DWORD이며 next는 등록 조회/가상 처리 전에 보존한다. 현재 사건/역할은 원문 위치에서 다시 읽고 실패 전의 부분 쓰기는 되돌리지 않는다.

## 실제 세션

`HostSession.BuildProductionWorldDevices`는 같은 실제 Player·공장/생성기·장부·SP·현재 역할과 장기 Client Deck 저장소/금지 표를 빌린다. 기존 내용물 생성기는 현재 설치된 실제 ContentForm 정렬 부착/부모 통지로 분배한다. 공통 삭제의 ContentForm Unpop도 같은 실제 종속 분리/제거 통지를 실행한다. 실제 가상표의 연구·Mana·Player 통지와 원본 빈 통지를 구분하고 미복원 파생은 명시 오류다.

연구의 검색/슬롯·실제 생성/삭제·dirty·Deck 재계산·실제 플레어와 입력 로그를 연결했다. AI와 생산은 같은 현재 내용물 역할/권한 상태를 공유한다. 실제 생성기·검색기·내용물 부착/제거가 같은 현재 역할을 읽는다. 프로세스 반납 뒤 실제 Player 링크 정리의 정상 복귀 증빙을 소비하고 Deck 블록/모듈을 반납한다. Client 장기 주소는 되감지 않는다.

통합 검사에서 정상 완공한 워크샾이 생산 목록에 들어가지 않는 누락을 발견했다. `HostSession`의 장부가 용량0인 독립 목록을 사용하고 있었으므로, cpppj `RawSurfaceStorage`와 같이 기존 Client의 `SidLists.Factories`/`Providers`를 같은 장부에 연결했다. 임의 재검색으로 누락 목록을 채우거나 별도 생산 목록을 만들지 않는다. 서버 연구의 내용물 Form Pop은 기존 `_worldTransmission.Pop`의 실제 writer/단독 미션 방송을 사용한다.

제품 `StartMission`은 기존 음향/연소/플레어 장치 뒤 생산 장치를 설치한다. 현재 실제 Gump 등록 표/가상 처리·원문 입력 큐·설정·로그를 제공한다. 연구 채널9 운반과 모드별 도움말 UI는 아직 선택 시 명시 오류이며 후속 연결 대상이다. UI/HUD가 이미 완성됐다는 뜻은 아니다.
