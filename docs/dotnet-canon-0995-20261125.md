# dotnetpj 0.995 — RU-5 Chat 점 명령 효과의 실제 Root 연결

2026-11-25, HJOW-Athlon. R4-6 Root 공장 묶음의 RU-5 단계다. 점 명령 분배(0.761~0.763)의 효과를 실제 Root 장치에 연결한다. 치트 상자·설정·입력줄·메뉴 명령·일반 say·오류 출력·진단은 실제 owner에 닿고 번쩍임과 일반 송신은 후속 단계에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Game/ClientHostGame.ChatSubmit.cs`: `InitializeNativeChatSubmit`을 메뉴 진입 경로(`LoadContent`의 채팅 창 설치 다음)에 설치했다. 근거: cpppj `ClientChatRuntime.cpp` 174~212행의 `BindClientChatSubmit`·`BindClientChatMessage`. 제출·일반 say·입력줄·메뉴·오류·진단은 같은 실제 owner(`NativeChatWindows`·`NativeChatGeometry`·`Gameplay.UserCheat`·시작 설정·`ErrorLog`)에 묶고 패킷 후크는 실제 수신자 확장·전역 조회·로그·loopback guard·로컬 수신(`ReceiveNativePacketChat`)을 사용한다. 번쩍임은 `PlayerKnown` 0에서 조용히 넘기고(원문 `RequestThunderFlash`의 같은 관문) 그 밖에는 R6 월드 표시 연결에서 잇는다고 명시 실패한다. 일반 송신은 R11 수송에서 잇는다고 명시 실패한다. `desc`는 원문처럼 미연결로 두어 같은 위치에서 명시 실패한다(cpp도 `description`을 묶지 않는다). 0.995에서 추가됐다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: `LoadContent`에서 채팅 창 설치 다음에 제출 부모를 설치한다.
- PORT_MAP에 2행을 더했다. `cpppj/src/client/ClientChatRuntime.cpp`·`cpppj/src/client/UberHud.inc` → 제출 부모 설치 파일.
