# 앱 미션 소유권·명령 장치 (WB04-E953)

기준선 `225553df`의 `CampaignClientServices` 장치를 앱의 현재 설정·Gump 입력 트리·입력 고리에 연결했다. 소유권과 자산 PostPop의 생산 갱신은 같은 명령 `0x02000003`을 숨김 포함으로 전달하고, 테마 모드는 현재 `theammode` 설정과 원본 기본값 1을 사용한다. 개발자와 자산의 명령은 같은 현재 입력 큐에 원본 폭과 부호로 예약한다. 각 호출은 현재 소유자를 다시 조회하며 누락 또는 반납된 수명을 오류로 드러낸다.

World 설치 시 이 기본 장치를 다른 실제 서비스와 합치며 명시적으로 전달된 개별 시험 장치는 그대로 우선한다. 실제 Tutorial1 Guide→앱 State7→내부 로그인 Ready 검사에서 소유권과 자산 큐 대역을 제거했다. 별도 검사에서 숨겨진 실제 Gump, 두 생산 갱신 경로, 설정 교체, 두 입력 큐의 교체와 명령 정수 폭을 확인했다. 명령의 앱 프레임 소비, 소리·카메라와 완전한 HUD·실제 플레이는 여전히 별도 작업이다.

검증: Node v26에서 앱 장치·기존 Client 장치·실제 Tutorial1 요청 연관 14건이 통과했다. 고정 커밋 `b4ff359de`의 격리 전체 회귀는 6,519건 중 3건 실패·2건 건너뜀으로 끝났다. 격리 트리에서 `screenShots` 누락과 `fonts/Galmuri11-LICENSE.txt`의 CRLF 변환이 원인이었고, 실제 작업 트리의 LF 바이트를 복사하고 스크린샷을 포함한 뒤 관련 38건이 통과했다. 수정된 격리 환경의 전체 회귀는 `extracted/webpj-e950-node26-isolated-corrected.log`에서 재실행 중이다.
