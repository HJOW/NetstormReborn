- Release 제품 빌드는 오류 0이다. 신규 경고 0이다.

  2인자 비트 변환)은 바로잡았고, 초회 1건 실패는 DN 번역의 fixture 정수
  파서 오류(`bit_cast` 비트를 `Int`로 읽음)로 판명돼 `UInt`+`unchecked`로
  바로잡았다.
