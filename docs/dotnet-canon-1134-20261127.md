# dotnetpj 1.134 — 화면색 변환 합성 교정

2026-11-27, HJOW-Athlon. 현재 cpppj `SpritePixelTarget::Shape`와 `DrawTranslatedVfxImage`를 대조해 명시 색표를 소스색에 적용하던 C# 경로를 교정했다. 추상·죽음·그림자는 불투명 그림 마스크 아래의 현재 화면색을 변환한다. 소유자색은 계속 소스색 치환이다. 화면색 변환은 단위 배율도 원본 변환 기하를 사용하며 소스 255는 마스크에서 제외하고 변환 결과 255는 저장한다.

- 독립 변환과 실제 SHP 해제→SpritePixelTarget 출력, 한 행 기하 관문, 소유자색을 포함해 가상 그림·VFX 집중 검사 **33/33 통과**했다. Release 빌드 오류 0·기존 경고다. 게임 픽셀 또는 원본 바이너리와의 신규 대조는 아니다.
- 제품 kind 0 제출 및 나머지 추가 그림은 미연결이다. 게임 창과 전체 회귀는 실행하지 않았다. 기존 단위의 소스색 기반 그림자 기대는 이 단위에서 수정했다.
