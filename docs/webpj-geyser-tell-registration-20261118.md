# WB04-E736 간헐천 채집과 원격 Tell 등록

기존 `5bh` 간헐천 채집과 `70h` 원격 Tell 처리기를 현재 Session의 Carrier 분배기에 등록했다. 채집은 기존 metadata 등록 뒤 현재 Session의 확인 상태를 갱신하는 실제 수신기로 연결한다. Tell은 수신 바이트를 표시 문자열로 해독해 현재 소비자에게 전달하며, 소비자가 없으면 해당 위치에서 오류를 낸다.

근거는 기준선 `225553df`의 `RawCampaignSession.cpp`, `RawGeyserMined.cpp`, `RawRemoteTellPacket.cpp`이며 세 파일의 기준선 이후 변경은 없다. 채집 본체의 원본 10.78 fixture 1,156행은 기존 E108에서 대조했고, Tell은 E559에서 소스 계약을 검사했다. 이번에는 새 fixture를 추가하지 않았다.

Tutorial 1 Session 분배기에서 원격 Tell 전달과 반환된 간헐천 슬롯의 수신을 확인했다. 관련 집중 검사 31건이 통과했다. 실제 채집 진행·소리와 미션 왕복은 이번 검사가 아니다.

Node v26.13.0 전체 회귀 6,213건을 통과했다. 대응표 오류는 0건이며 Node v22 전체 재검사 주기는 6/8회다.

다음은 `40h`부터 운반 수신 명령을 등록하는 것이다. 나머지 Carrier 등록, 로그인 왕복과 앱 미션 연결은 남아 있다.
