# WB04-E858 캠페인 커서 Client 표시 장치

기준선 `225553df`의 `MakeCampaignCursorClientEffects`를 웹 글꼴 경계에 맞춰 이식했다. E857의 Gump 결선에 현재 Client 커서·비용 표시·번역·마우스·Renderer 갱신을 더하고, 8DWORD 글자 문맥은 같은 `GumpText`와 현재 `FontSet`으로 측정한다. 영어는 원본 코드 페이지, 한국어 글꼴 공급자가 있으면 UTF-16을 사용하며 NUL로 끝낸다. 원본의 파일 기반 건설 기록은 Client가 제공할 선택 장치로 남기고 선택 시 미연결이면 명시 오류를 낸다.

집중 검사에서 FontSet의 영어·한국어 측정, 현재 번역·Renderer 교체, 커서 번호와 마우스 입력, 비용·기록 장치 및 누락 진단을 확인했다. 실제 `RawCampaignCursor`의 취득·취소에 같은 Client 효과를 연결해 글자 측정과 화면 갱신을 확인했다. 처음 한국어 검사에서 글꼴 캐시가 재조회 시 공급자를 다시 부르지 않는 동작을 놓쳐 기대 순서를 수정했다. 집중 검사 3건과 Node v26.13.0 전체 회귀 6,374건이 통과했다(실패·취소·건너뜀 0).

실제 브라우저 Client/Gump 트리와 건설 기록 장치, 전체 미션 화면·사용자 입력은 아직 남아 있다. 원본 게임 창은 실행하지 않았다.
