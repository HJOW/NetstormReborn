# cpppj 1322·1325·1326 변경의 웹 재반영 판정 (WB04-E1241)

기준선 `225553df`(제품 1313) 뒤 cpppj 소스가 바뀐 대응표 아홉 행과 대응표 밖 새 파일 다섯 개를 3.6절 기준(① 웹 영향 없음 · ② 웹 재반영 · ③ 해당 소비 단계에서 처리)으로 판정했다. `node webpj/tools/port-map.mjs`의 `cpppj 변경` 보고가 9행에서 0행이 됐다(각 행 base를 판정한 커밋으로 올리고 메모에 근거를 남김). 새 파일 다섯은 재기준선 때 대응표에 등록한다.
