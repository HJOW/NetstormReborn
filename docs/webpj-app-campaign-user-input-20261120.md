# 앱 미션 사용자 입력 소유자 (WB04-E990)

로그인된 현재 World에 선택·강조·운반 입력 서비스를 한 번 설치하고 같은 설정, 입력 큐와 게임 시계를 빌리는 CampaignUserInput을 생성한다. 게임 커서는 실제 앱 커서 선택으로 전달하며 열린 Tell 창은 기존 창 커서를 사용한다. 미션 반납 시 입력 소유자와 커서도 해제한다.

사제 선택은 원본처럼 현재 객체 trace를 먼저 호출하므로 Client 수명의 진단 전역과 실제 SID 풀·게임 전역을 기존 `traceClientObject`에 연결했다. 경로 진단 표시와 커서 즉시 출력은 아직 구현되지 않아 도달하면 명시적으로 오류를 낸다. 이 단위는 입력기를 설치한 것이며 브라우저 사건 큐의 소비와 HUD 조작은 아직 연결하지 않았다.

실제 Tutorial1 로컬 로그인 뒤 같은 사제를 선택·해제하고 원본 진단과 중복 설치 관문을 확인했다. 커서 선택과 실제 진단 등 Node 검사 30건, Chromium의 첫 Tutorial 시작 1건이 통과했다. 처음 존재하지 않는 trace 검사 파일명을 지정했을 때 Node 26이 조용히 건너뛰는 것을 확인해 실제 세 파일로 바로잡아 전체 관련 검사를 다시 실행했다. E982 고정 Node 22 전체 6,556건이 실패·건너뜀 없이 통과했고 같은 고정 상태의 Node 26 전체 검사가 실행 중이다.
