# WB04-E901: 앱 색상표의 미션 대여

## 범위

앱이 준비한 고정 ColorSort 입력, 같은 소유자 표와 현재 Screen 팔레트를 미션 서비스에 대여한다. `CampaignGameWorld` 생성은 현재 Screen 색을 공장 표시기에 적용하고, Session 커서 및 생산 문맥은 같은 Client 소유자 표를 사용한다. 화면 색과 최초 고정 입력은 별개이며 초기 9표의 원래 소유자를 유지한다. 두 소유자 중 하나만 있거나 표가 준비되지 않았다면 거부한다. 별도 독립 검사에서는 기존 파일 팔레트 경로를 유지한다.

현재 로그인에서 전투 팔레트 전환, 실제 표시 장치와 후속 팔레트 변경 통지는 아직 연결하지 않았다. 따라서 이 단위만으로 미션이 브라우저에서 플레이 가능한 것은 아니다.

## 검증

- 실제 Tutorial1 State7·State8·로컬 로그인의 생산 문맥과 커서가 같은 앱 소유자 색표를 참조하는지 확인했다.
- 원본 색상 입력·공장 표시·커서 및 관련 Node 22건과 실제 로그인 2건이 통과했다.
- Chromium의 앱 수명과 실제 Guide·GameWorld 생성 1건이 통과했다. Node v26.13.0 전체 회귀 6,452건이 통과했다(실패·취소·건너뜀 0).
