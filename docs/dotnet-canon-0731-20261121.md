# 0.731 실제 State 저장소 자식과 장기 SID 목록 통일

ClientStateStorageCleanup이 같은 실제 ClientSurfaceGlobals/LocalState/다중선택 개수를 받아 시계 동기화3DWORD·Zone6BYTE·Pool 부모와 열 가지 선택 물리 효과를 연결한다. 색 표는 아직 빌린 World에도 도달하며 나머지 아홉 효과와 Pool은 World 대여가 끝나기 전에 거부한다. 전체 UI/Kernel/Runtime 반납은 호출자가 수행해야 한다. 구성 자체는 정리를 실행하지 않으며 다른 Client와 미지원 Effect를 거부한다.

선택 효과는 등록 SID목록의 개수만0, 세 TotalMade 표의 앞255칸, Hash, 경고255DWORD, spot65536BYTE, Island 기록, Chunk, Graph 표, 다리 붕괴 스캔이다. 기존 작은 몸체와 정확한 보존 영역을 재사용한다. BoardTargetState는 같은 실패점의 ref 접근을 제공해 Pool 부모가 사본 없이 Y→X 순서로 직접 쓴다. 붕괴 스캔은 현재 캐시Frame.game와 float 지연을 먼저 더한 뒤 세DWORD/기한을 쓴다. Zone은 DWORD0 뒤 WORD0을 쓰고 짧은 물리에서 앞선DWORD 효과를 보존한다.

실제 ClientHostGame의 별도 SID목록 할당을 제거하고 같은 장기 Surface.SidLists를 실제 Session에 전달했다. 일반 시작의 기존 명시 PrepareGeneralWorld는 유지했다. 아직 Session이 별도 보유하는 Graph/TotalMade/Island와 전체 Native World 장치의 통일을 뜻하지 않는다.

신규Core2/Client4건을 포함한 집중 Core17·Client19 합계36건이 통과했다. 독립 원문 state-zone-reset-x86.tsv10행의 전체24BYTE와 state-bridge-reset-x86.tsv64행의 전체212BYTE·저장주소/폭을 전수 대조했다. 짧은Zone/색 표, 원시 기한/이웃 물리, 실제 대여 관문, 선택 목록 내용/등록표 보존, 통계256번째 칸·Graph 예약영역/스택 보존, 같은Frame시각과Pool 실패점을 확인했다. 원문 fixture2개만 추가해363개이며 기존해시 변경은 없다.
