# dotnetpj 0.823 — 실제 NSInfo 생성과 공통 UI 소유 연결

작업일 2026-11-22, PC HJOW-Athlon. Root의 세 번째 패널인 NSInfo의 전체 생성과 일반 부착을 이식하고 기존 공통 트리·문자·그림·수명에 조립했다. 메타맵 배치·입력·특수 버튼 그림과 실제 Game Root의 나머지 생산/메시지 공장·Native 장치는 계속 미완료다. 유일한 실행 경로는 `dotnetpj/src/Netstorm.Game/bin/Release/net10.0/Netstorm.exe`다.

## 변경

- `HudNsInfoCreate`는 NSInfo/PlayerInfo/BattleInfo/특수 버튼의 전체 생성과 숨김 wrapper를 이식했다. 독립 생성 장치가 관측한 부모 포함 총50노드의 할당/초기화 순서, current의 성공 뒤 게시, 종류 BYTE 부호 확장, 미작성 바이트 보존, 현재 배경 포인터 재조회와 번역/초기 파싱·맞춤을 보존한다. Battle 설정22쌍의 쓰기 순서와 첫 BYTE만 초기화하는 원문 범위도 유지한다.
- `HudNsInfo`는 기본 부착→현재 배경 Push→축별 현재 크기/배율 쓰기→가상 배경 부착→현재 모드/known 조회를 이식했다. Player/Battle도 실제 기본 부착 뒤에만 메타 후속을 선택한다. 선택된 실제 후속이 없으면 그 위치에서 명시적으로 실패하며 앞선 부분 효과를 되돌리지 않는다.
- `HostNsInfoWindows`는 Source RawMenuControls/RawNsInfoContext의 같은 실제 노드·기본 공장·스크롤·슬라이더·한 줄 문자·돌 버튼·스타일/번역·현재 서버 이름/문자열 고리와 약한 가상 분배를 조립한다. 숨김 루트도 모든 실제 자식을 만든다. Close는 자기 등록 자식과 부분 물리만 공통 수명으로 반납하며 원문 current DWORD를 보존한다. 다른 HTML/메뉴 소유자는 유지한다.
- `HostHtmlText.Single`이 한 줄 문자의 생성/측정/출력/소멸과 현재 종류 전역을 공유한다. HostGumpDrawing과 저장 이름 창도 같은 본체를 빌린다. 기존 공통 외부 텍스트 조회를 보존했다. 최초 그림 TYPE 표의 동일 주소를 비교해 값이 같은 별도 로딩도 거부하고 같은 Gameplay의 권한/보조 owner를 검증한다. NSInfo의 TYPE 범위는 변경 가능한 월드 사본 대신 실제 최초 자산 표를 읽으며 유효한 TYPE0도 비null 논리 레코드 토큰을 반환한다.

## 검증

최종 집중 검사는 **Core 22·Client 388, 합계 410건 통과/실패0**이다. 이전0.822 집중 검사의 모든 이름을 보존했고 신규 이름은 Client 10개다. 같은 솔루션 Release 빌드는 오류0·기존 경고6이며 NETSTORM_DATA 없이 검사했다. 마지막 정기 전체 기준선은0.820의5,848건이고 다음 정기 전체는0.824다.

독립 원본 생성 **170관측(정상120·중단50)**의 모든0x180BYTE 노드/가드·문자열/서버 버퍼·현재 전역·호출 순서·반환/스택을 대조했다. 일반 부착 **310관측(중단8 포함)**도 모든0x11cBYTE 노드/가드와 전역·순서를 대조했다. 부착 자료 등록표의311행은 헤더1행을 포함한 값이며 실제 관측310개와 구별한다. 기존 CPP 자료는 변경/복사하지 않고 Client 소비자 하나에만 링크했다.

실제 설치 자산의 공통 트리에서는 다음을 확인했다.

- Player8/Battle1/특수 버튼8/Start 돌 버튼8/한 줄 문자9/여러 줄 문자12와 실제 슬라이더 하위의 전체 생성, 실제 스타일 조각·측정과 동일 현재 한 줄 종류 전역.
- 일반 부모 부착/현재 배경 크기·현재 모드/known 변경과 메타 후속 누락의 정확한 도달 순서.
- 생성 중 형식화 예외의 current 미게시와 부분 노드/슬라이더/조각 반납, Close/재생성과 기존 메뉴·HTML 수명 보존.
- 선택된 입력/특수 그림의 명시적 누락 실패, 자기 그림 등록 반납, 서로 다른 Gameplay·최초 자산 표 거부와 월드 표를 늘려도 최초 TYPE 경계를 유지하는 검사.
