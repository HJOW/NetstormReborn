# 도움말 그림 자산

WB04-E1054는 원본 QuickHelpWindow의 TYPE Help 프레임과 같은 TYPE 정의, 실제 SHP 프레임·기준점 및 픽셀을 조회한다. 그림이 없는 프레임 -1과 원본 그림 제외 TYPE 109·161은 null이며 특수 프레임은 픽셀 없이 프레임 상태를 유지한다.

실제 Tutorial1 다리 자산의 프레임과 제외 타입·범위, 기존 이미지 Gump 출력 검사를 포함한 Node 26 관련 19건이 통과했다. 최초 검사는 Help 프레임을 TYPE 보기에서 조회해 실패했으며, 실제 프레임이 보기가 아닌 TYPE 정의에 존재함을 확인해 교정했다. 창의 실제 그림 출력과 그림 유무별 본문 배치는 후속이다.
