# dotnetpj 0.991 — RU-4a 실제 Root 미니맵 설치

2026-11-25, HJOW-Athlon. R4-6 Root 공장 묶음의 RU-4 첫 단계다. 실제 게임 Root에 미니맵을 설치하고 같은 미니맵 전역(MapRevision)을 공급한다. 초기 미니맵 공장은 Open이 아닌 Construct를 쓰고, 같은 현재 지도 getter를 재사용한다. HUD 도킹의 지도 저장소 작성과 살아 있는 선택 객체의 수명은 후속 단위에서 잇는다.

## 변경과 원문 대응

- `ClientHostGame.InitializeNativeMinimap`: 같은 실제 메뉴 트리와 장기 저장소로 미니맵을 만들고 현재 bitmap 폭으로 생성한 뒤 실제 화면 팔레트를 입힌다. `GumpButtonTree`·`RawSurfaceStorage`·`MetadisplayDirtyState`·`RawMinimapGlobals`·`MapRevision` owner를 미션보다 오래 살린다. 보기는 실제 카메라 스냅샷과 같은 현재 지도(`HostMainMenu.CurrentMapView`)에서 읽고, 기본 입력은 같은 트리 체인에, 무효·변경은 메뉴 다시 그리기에 연결한다. 중앙·이동·입력 모드·폴링은 R5 입력·카메라 연결에서 잇는다는 명시 오류로 남긴다. 진입 경로에서는 호출되지 않는다. 0.991에서 추가됐다.
- `LoadContent`에서 채팅 공장 다음에 호출한다. 메뉴 경로를 바꾸지 않고 전체 viewport로 지도 영역을 대신하지 않는다.
- PORT_MAP에 2행을 더했다. `cpppj/src/client/RawMenuControls.cpp`·`cpppj/src/client/ClientMain.cpp` → 제품 미니맵 설치 파일.
