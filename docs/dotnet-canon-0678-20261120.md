# 0.678 제품 건설 표시 장치와 공유 목록

- 일시: 2026-11-20, HJOW-Athlon.
- 근거: `cpppj/src/client/RawCampaignParticles.cpp/.h`의 `ConnectConstruction`, 앞 단위의 원본 대조 본체·실제Host·Kernel.
- 범위: 실제 미션의 건설 표시 캡처·공유팔레트·시각/카메라·dirty/화면 출력과 수명 연결이다.

## 구현

`HostSession.WorldConstruction`은 연소와 같은 `WorldRendering`·Host·Kernel·난수와 실제보상 최대HP를 사용한다. 같은 시스템을 중복 연결하면 명시 실패한다. 미션 종료는 건설 표시를 연소/공통목록보다 먼저 반납한다. 건설만 해제하면 같은 목록의 연소는 유지하고, 반납한 색 메모리가 다음 연결에 재사용되지 않도록 공유팔레트 토큰을 비운다.

`HostMissionConstruction`은 현재 제품의 실제SHP 캡처와COL RGBX·원본두색띠(8+3)를 사용한다. Win32 실제색 메모리와 인접DWORD snapshot을 프레임 본체에 제공한다. 제품 프레임 준비와 실제카메라 설정은 연소와 건설 상태를 함께 갱신한다. 출력은 같은8비트 화면 잠금/현재clip의 끝을 제외하는 영역에 한정하고255투명색을 보존한다. 예외 때도 잠금을 반납한다. 실제R5 월드뷰 미연결은 빈화면 성공으로 대신하지 않는다.

Release 집중 **17/17건 통과·실패0**, 명령 종료0이다(`extracted/dotnet-0678/construction-final.trx`, `extracted/dotnet-0678-final.log`). 신규4건과 같은실제세션 사제/연소13건을 확인했다.

- 일반/즉시 표시가 실제공장 생성자·공장SHP·팔레트·현재HP/난수 프레임·현재카메라 출력·abstract 해제뒤 자기삭제로 이어진다. 캡처입력 전체는 초기입자/출력으로 옮긴 색을 되돌려 비교했다.
