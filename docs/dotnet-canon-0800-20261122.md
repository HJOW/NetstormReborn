테스트가 끝난 실제 Host 폴더의 exe/dll6개를 SHA-256으로 고정한 뒤 일반31경로의CPP/DN62회와CPP 데모3회를 수집했다. 각 실행은 영어·1024×768·창 모드·음소거·빈 사용자 루트, 고정Unix1760000000·25ms·120프레임이며90프레임의전체 session-dump를 비교했다. 데이터는extracted/dotnet-oracle-data 사본이고 원본으로 실행하지 않았다.

- **65회 모두 종료0·수집 오류0**. 실행 전후 같은6개 빌드 파일은 불변이다.

- CPP의기존 미초기화owner0 SP열 이외의 변동은 없다. 실제 달라진행/열은audit-summary.json에 별도 기록했다.
- 원본**1,392파일**의 이름/해시가 전후 및0.796 전체 해시 장부와 같다.
- **M1은0/34**, cpp_only997·dn_only21이다. DN 데모 진입은 미연결이며65회 종료0을 전체 상태 일치나 플레이 완료로 확대하지 않는다.

실제 포획/희생·특정 적 공격·시나리오 승리 재현 입력은 보내지 않았다. 캠페인1-1~1-5·스커미시의 아군AI 예외와 그 밖의 미션 사용자 수동 확인 범위는 유지한다. 일반 미션 진입/대기만 수행했다.
