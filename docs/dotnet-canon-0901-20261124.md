# dotnetpj 0.901 — Root 첫 장치 나머지 묶음(RU-1) 조립

2026-11-24, HJOW-Athlon. 0.900 정기 전체 회귀 뒤 첫 단위다. R4-6 Root 장치·UI 묶음 중 RU-1을 잇는다. 제품 코드는 RU-1 범위만 변경했다.

## 변경과 원문 대응

- `ClientSurfaceGlobals.BindNativeRootFirstDevices`는 첫 Process 저장소 생성 뒤·첫 메뉴/World 전에 같은 실제 장치를 설치한다. 근거: `cpppj/src/client/ClientMain.cpp` 447~455행(PostPop)·468~478행(Resource)·484~487행(Reward)·488행(Deletion)·525행(PlayerRecords). Transmission·Process 선택은 0.838에서 완료했다.
- PostPop은 실제 AI 통지(`NotifyAiObject`)·현재 전체 로컬 owner(`BattleOwner`)·기억 선택 재검사를 같은 현재 Player/기억 선택에서 읽는다. 재검사는 원문 da650의 실제 선택 필요 위치만 현재 UI/전체 World를 보유하며 미선택은 자연 반환한다. 세션 본체는 R6에서 잇는다.
- Resource 일곱 항목은 실제 현재 게임 난수와 선택된 큰 하위만 같은 전체 Runtime에서 호출한다. `CheckCarrierPostPop`은 `PriestWorld.CheckCarrier`로, `NotifyGeyserAi`는 `AiWorld.Geyser`로 실제 세션 본체에 연결했다. 나머지 피해·건설·삭제·운반체 정기는 R6 피해·건설 결선에서 잇는다. 미설치를 성공으로 꾸미지 않고 명시 예외로 드러낸다.
- `RawGeyserAiRegistration`은 `cpppj/src/o/RawGeyserAiRegistration.cpp`의 Player1..8 순회를 이식했다. PATCH 실제 하위만 바인딩하며 미연결 nonnull은 첫 요청의 네 DWORD를 예외에 담는다.
- Reward는 같은 SP 저장소(`ClientSpGlobals.Store`)·같은 editor 별칭(`CampaignWorldGlobals.EditorBox`)·실제 SP 표시 갱신·실제 AI 지갑 가산(`CreateAiWallet(...).Credit`)을 같은 owner로 묶는다. `CampaignWorldGlobals.Editor`는 값을 바꾸지 않고 같은 `UIntBox`를 별칭으로 빌리도록 바꿨다.
- Deletion은 같은 실제 선택 기억점·전역 소리를 빌린다. PlayerRecords는 삭제 주소 소비 시점마다 같은 실제 Player owner/base를 읽는다.
- 현재 Menu 데모 getter는 `ClientHostGame._missionDemo`를 실제 owner로 읽는다. `StartMission`에서 미션 스크립트의 `demo` 값을 같은 호스트에 보관한다. 근거: `cpppj/src/client/UberGump.cpp` 226행의 `missionRuntime_->gate.demo`. DN 미션 Runtime은 gate를 아직 노출하지 않아 호스트가 보관한다.
- `ClientHostGame`의 최초 설치 경로에 RU-1을 연결했다. RefreshSp는 실제 메뉴 owner를 확인한 뒤 실제 생산 UI 연결(R5)까지 명시 거부한다. UnitLost는 실제 장기 음향(`HostMissionAudio.PlayGlobal`)을 사용한다. RememberPlacement는 실제 Pool/TYPE/선택으로 `RawUserSelection.Remember`을 실행한다.
- PORT_MAP은 이전 1818행의 값·순서·base를 보존하고 4행을 추가했다(자료 1822행). fixture 496개는 그대로다.
