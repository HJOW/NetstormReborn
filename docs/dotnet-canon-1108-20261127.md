# dotnetpj 1.108 — 공유 세션의 부모 Form과 UI 중첩 삭제 검증

2026-11-27, HJOW-Athlon. 공유 Native Surface와 실제 세션 삭제 분배, 메뉴 트리 및 `HostGumpFormRuntime`을 결합해 프로세스 Form을 부모로 삼는 GumpForm 중첩 삭제를 검사했다.

- 실제 공장으로 만든 GumpForm을 프로세스 Form에 부착하고 실제 UI 등록 ID를 설정했다. 세션 자원 삭제로 부모를 지우면 프로세스 가상 통지와 UI 통지가 각각 한 번 실행되고, GumpForm도 반납되며 UI 노드는 삭제 대기 후 정리된다. 공통 삭제의 전·후 깊이는 0으로 복귀한다.
- 최초 빌드는 새 검사에서 자산 네임스페이스 누락으로 실패했고, 첫 실행은 메뉴의 파일 팔레트를 초기화하지 않아 실패했다. 실제 시작 화면 자산을 읽도록 수정한 뒤 관련 Client 검사 **3건 통과**다.
- 제품 코드는 바꾸지 않았다. 실제 일반 월드 자산 삭제 중의 UI 통지나 생산 패널 Form 부착, 게임 화면 픽셀 일치까지 증명하지 않는다. 게임 재실행 없이 1.107의 대표 세 미션 결과를 유지한다.
