# dotnetpj 1.107 — Native 내용물 통지의 실제 세션 대여

2026-11-27, HJOW-Athlon. 공유 Native 저장소에서 생산·연구 장치를 만드는 세션이 자신의 현재 부모 통지와 외곽 Runtime pin을 장기 저장소에 빌려준다. 자식 프로세스·생산 정리를 마칠 때 같은 대여만 결정적으로 반납한다. 독립 세션은 기존 경로를 유지한다.

- 실제 공유 Surface·세션·생산 장치·Runtime으로 워크샾 부모에 정렬 부착한 내용물 Form을 공통 분리했다. 현재 연구 본문이 생산 변경 카운터를 갱신하고 호출 종료 뒤 pin이 반납되며 세션 종료 후 새 대여가 가능한 것을 확인했다. 다른 소유자의 대여 반납은 거부한다.
- 첫 빌드는 테스트에서 내부 `RawSlot`을 사용해 실패했고 공개 할당 슬롯 API로 고쳤다. 이후 일반 Form 부착기로 ContentForm을 붙인 검사와 외곽 Runtime을 먼저 반납한 검사 순서가 각각 실패해 실제 정렬 부착 및 자식 선반납 순서로 수정했다. 최종 관련 Client 검사 **19건 통과**, `cpp_sync.py` 종료 0이다.
- 제품 Release 빌드 후 `extracted/dotnet-l2-1107-content-runtime/`의 대표 세 미션은 CPP·DN 모두 종료 0, DN `f090.tsv`는 0.998 기준과 바이트 일치, 원본 1,392개 파일 전후 불변이다. 비교기 종료 1은 기존 L2 차이다.

연구·Mana·Player·Carrier 외 파생 통지와 사제 포획 안내 본체는 아직 선택 시 명시 실패한다. 생산 세션의 내용물 정렬 본체 통합, 부모 삭제의 UI 중첩 통지, 생산 Form 생성·부착 및 실제 포획 결과는 미완료다. 34경로를 새로 측정하지 않았다.
