# WB04-E864 Client Kernel 프로세스 소진 진단

기준선 `225553df`의 `WriteRawProcessSummary` 패치판 순회를 브라우저 console 출력으로 적용하고 Client Kernel 진단 바인더를 추가했다. 각 현재 슬롯의 Form TYPE 전체 이름을 찾고 슬롯을 다시 읽은 다음 부모 조건·출력의 두 조회를 보존한다. 부모 0은 `NULL`로 출력하며 물리 SID·TYPE 범위 오류를 숨기지 않는다. 실제 FILE 생성은 웹 범위 밖이고 CD 10.72 요약은 구현하지 않았다.

바인더는 소진 시 현재 Kernel 요약을 출력하고 같은 Surface의 상세 저장과 단언에 연결한다. 제한된 크기의 실제 Kernel 검사에서 요약→상세→단언과 단언 예외 시 슬롯 0 보존을 확인했다. 별도 TheWarBegins 실제 Session에서 생성한 Regular 프로세스의 Form·부모를 같은 풀과 TYPE 표로 요약했다. 부모 필드 누락을 명시적으로 거부하도록 보완한 뒤 Node v26.13.0 전체 회귀 6,397건이 실패·취소·건너뜀 없이 통과했다. 현재 바인더 호출은 명시적이며 브라우저 Client 장기 수명에 자동 설치하지 않았다. 실제 Session 전체 소진, F7 객체 덤프와 건설 기록 장치는 남아 있다. 원본 게임 창은 실행하지 않았다.
