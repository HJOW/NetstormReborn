# dotnetpj 0.969 — Build에 연결 종료 2번 수신기 연결

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 같은 장기 기본 표를 공유하는 `ClientPacketDispatch.Build`/`InstallDefaults`에 원문 앱 전역 2번 연결 종료 수신기를 연결했다. 0x7b·0x7c Build 연결과 제품 기존 경로는 바꾸지 않는다. 세션·메뉴 결합 후크 중 1a/1b·0x1d/0x66·0x0f/0x26·참가자/전투 묶음과 Root Source/Record/Sent·송신/제출, RU-3 나머지·R4-4 정기 두 단위는 후속에서 잇는다.

## 변경과 원문 대응

- `ClientPacketDispatch.InstallDefaults`는 `ClientConnectionEndedReceiver.Install`(0x004b6660)을 같은 기본 표에 설치한다. observer/version/length 표는 바꾸지 않고 고정 F만 설치한다는 0.953 본체 계약을 그대로 공유한다. 0.969에서 추가됐다.
- 9번 장애 저장·소유자 방송 효과는 실제 세션에 묶는다. `game.RequireSession()`+`PinCurrentRuntime` 뒤 R6 본체까지 명시 실패하므로, 세션 없이 성공으로 꾸미지 않고 세션 있어도 가짜 성공을 합성하지 않는다. 연결 끊기(`registry.Disconnect`)·토큰/동기화·phase/next·flags·frames는 기존 `ConnectionEnded.ReceiveConnectionEnded` 본체를 재사용한다. 새로 만든 본체가 없다.
- 수송 팩토리(`ClientCampaignTransport.Make`)는 같은 `InstallDefaults`를 공유하므로 2번 항목을 자동으로 공유한다. `InstallClientPacketDefaults`의 원문 순서(앱 전역 F를 같은 기본 표에 둠)를 유지한다.
