# 1.200 Native HUD 자식과 도킹 재사용

동일 장기 RootFactories가 같은 트리·문자·NSInfo·Gameplay·Storage를 빌리면 기존 집합을 반환한다. 재사용은 새 NSInfo를 만들지 않으며 새 노드는 실제 정리 뒤 `RecreatePrimary`가 만든다. 전체 Uber가 현재 루트이면 네 패널의 실제 소유자·등록 토큰·부모·생존을 확인한다. NSInfo의 공유 Current는 다른 창을 가리킬 수 있으므로 실제 Primary 소유자를 검사한다.

Native 경로는 기존 생산/미니맵 기하와 세 구분선·slave10개를 유지한다. 반복 진입의 수동 구분선/Chat 생성과 생산 Resize·미니맵 강제 크기를 피하고 현재 팔레트·예산·Refresh·Chat 숨김 사건만 실행한다. NSInfo 바깥 배경 조회도 전체 부모가 작성한 생산 전역을 현재 읽는다. 일반 직접 진입의 기존 경로는 유지한다.

같은 자산·트리에서 실제 네 공장으로 두 HUD 세대를 교체하고 노드/도킹/bitmap/로그/공장 수명을 대조했다. 잘못된 owner·죽은 자식·다른 공장·손상 부모도 거부한다. Release 통합 빌드는 오류0·기존 경고25, `extracted/dotnet-1200-build.log`다. 실제 HUD3·RootFactory8·Uber12+2·미니맵3·생산7, 관련 **35/35 통과**다. 통합 집중 전체는79통과·FileStore의 독립 검사1실패였으며 원시 `extracted/dotnet-1200-tests/focus.trx`를 보존한다. 실패는1.202에서 조사하며 HUD 통과로 숨기지 않는다.

현재 제품의 thewarbegins·tutorial1·surrounded를 각각 격리 사용자 루트에서120프레임 진입/대기했다. 세 종료0·기존90프레임 덤프 불변, 1-1의30/40/45/50/60/70 여섯 화면은1.189와 같고 보호 원본1,392파일도 불변이다. `extracted/dotnet-ui-reuse-1200/run.py`·`run.json`에 실행 인자·실행파일 SHA·고정25ms/시드1760000000·옵션·보호 해시 결과가 있다. CPP 미니맵은30/40/45에0픽셀,50/60/70에 기존1픽셀 차이가 남는다. 같은 외부 프레임의 게임 시각은 서로 다르므로 전체 일치로 판정하지 않는다.

검사 장면은 Native mode3 사건을 직접 선택한 뒤 재사용을 검증한다. 제품의 전체 State/UI 모드 호출자·옵션 해석·실제 음악 부모는 아직 미연결이다. 실제 State GUI 왕복이나 R5-4c3c/4d 전체 완료가 아니다. 다음은 같은 채널/장치/음악 소유자를 준비해 실제 State 외부 장치를 잇는다.
