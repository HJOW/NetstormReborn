# WB04-E925: 확장 표시 문자 위치 경계

cpppj `DisplayTextInput`의 확장 표시 문자 존재·앞/뒤 경계·이전/다음 문자 계산을 웹의 같은 표시 codec에 옮겼다. 네 바이트가 실제로 해독 가능한 문자일 때만 한 덩어리로 취급한다. 미완성·미배정 바이트는 기존 한 바이트로 읽으며 위치는 본문 길이에 제한한다. 실제 바이트 배열과 편집 버퍼가 반환하는 바이트 문자열을 모두 받을 수 있다.

영어와 한글이 섞인 본문의 각 토큰 내부·경계·끝을 검증하고 잘못된 토큰과 음수 위치를 구분했다. 표시 부호화 전체 범위와 일괄 큐를 포함한 관련 Node 검사 7건이 통과했다.

이 단계는 안전한 위치 계산만 제공한다. 기존 TextEntryGump의 선택·삭제·확정 문자 삽입 및 붙여넣기, 브라우저 IME 연결은 아직 남았다.

Node v26.13.0 전체 회귀 6,490건이 실패·취소·건너뜀 없이 통과했다.
