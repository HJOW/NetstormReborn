# WB04-E801 사제·다음 유닛 선택과 건설 조각 취소

P/R과 N 선택 키를 같은 `CampaignGameWorld`의 실제 Session 사제 참여 조회·선택 전역·입력 큐·카메라에 연결했다. N은 기존 `selectNextMovingUnit`의 현재 풀 순환과 다중 선택 순서를 사용한다. P/R은 같은 장기 반복 카운터와 사제 조회를 사용하고, 원본 후속 수정 NB20에 따라 커서에 건설 조각을 들고 있으면 선택과 현재 SID 캡처 전에 취소한다. 공통 `selectPriestByKey`에도 선택적 취소 관문을 추가했다.

TheWarBegins 실제 로컬 로그인에서 P/R의 현재 사제 선택·반복 보기 명령, N의 같은 사제 선택과 카메라 경로를 확인했다. 당시 로컬 이동 유닛은 사제뿐임을 먼저 확인했다. 건설 조각 취소가 조회보다 먼저 실행되고 취소 뒤 선택을 다시 읽는 순서는 독립 콜백과 동일 Session의 대체 취소 장치로 확인했다. 실제 건설 조각 취득부터 실제 취소까지의 전체 경로는 후속 검증이 필요하다. 포획·희생·승패 및 세 비행 유닛 전용 행동은 실행하지 않았다.

검증: Node v26.13.0 전체 6,295건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 마지막 Node v22 전체 검사는 E795이며 이번 단위까지 이후 v26 전체 검사 6/8회다.
