# 1.171 지역 도장의 가상 소유자 분배 교정

CPP의 지역 도장은 `RawAssetOwner` 분배를 사용한다. 에지 팜의 가상표 `0x50a8e8`은 요청 소유자와 무관하게 중립 0을 기록한다. DN 세션은 공통 소유자에 직접 연결해 이 분기를 건너뛰고 있었다. `BuildRegionOwnershipDevices`의 도장 소유자 갈고리를 같은 풀·표면 상태·생산 카운터의 기존 `RawAssetOwner.MakeAssetOwnerDispatch`에 연결해 에지 팜과 섬 파생 분배를 보존했다.

기존 CPP 라이브러리에 추적용 객체 두 개만 별도 링크한 실행에서 SID23481이 경계 도장에 세 번 도달했지만 공통 소유자 설정으로 넘어가지 않았다. 그 진단 실행의 40프레임 전체 화면과 슬롯 바이트는 기존 CPP와 같았다(덤프 전체 행은 동일하지 않음). 원본 작업 트리는 수정하지 않았으며 별도 산출물은 `extracted/dotnet-terrain-1171-cpp/`다. DN 추적은 [1.170](dotnet-canon-1170-20261127.md)에 있다.

실제 세션의 지형·에지 팜 경계 도장 검사에서 수정 전 소유자1로 실패했고 수정 뒤 중립0을 확인했다. 관련 지역·신전·거주 구역 **18/18 통과**. 검사의 최초 빌드는 내부 전용 풀 API 사용으로 실패해 공개된 할당 슬롯 API로 교정한 뒤 수정 전 실패를 관측했다. `cpp_sync.py` 종료0이다.

1-1 40프레임의 에지 팜 152개는 수정 전 DN 소유자1/2에서 수정 후 CPP와 같은0으로 바뀌었다. 같은 1,911개 공통 SID의 소유자 일치는 1,728→1,880, 전체 슬롯 바이트 일치는 1,322→1,416이다. 튜토리얼1과 surrounded의 90프레임 공통 SID 소유자 일치는 각각 769→838/838, 5,969→6,401/6,408이다. 세 미션 진입·대기는 모두 종료0이며 원본 1,392파일은 각 수집 전후 불변이다. 새 덤프는 이전 DN과 달라 현재 빌드의 전체34경로 L2 재수집이 필요하다.

1-1의 30·40·45·50·60·70프레임 화면은 수정 전과 픽셀 단위로 같았고 40프레임 CPP와의 차이는 여전히 35,202픽셀이다. 기존 고정 입력의 다섯 화면도 수정 전과 같았다. 즉 이번 상태 교정만으로 화면 차이나 M1/L4a를 완료한 것은 아니다. 결과는 `extracted/dotnet-terrain-1171-fixed/`, `extracted/dotnet-terrain-1171-first/`, `extracted/dotnet-terrain-1171-missions/`에 있다.
