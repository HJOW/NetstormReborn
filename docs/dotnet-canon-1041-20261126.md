# dotnetpj 1.041 — WP-5a 사용자 옵션 경로 결선

2026-11-26, HJOW-Athlon. R4-6 이후 후순위 요구의 첫 조각이다. WP-5(사용자 데이터 경로)를 검증 가능한
네 조각으로 나누고 그 첫 조각을 이었다. 옵션 파일의 읽기·쓰기를 사용자 루트(`Saves/options.cfg`)로
옮겼다. 설치 경로는 읽기만 하며, 사용자 값이 있으면 항상 이긴다. 커스텀 맵 양쪽 읽기·신규 저장(5b)과
Edit 목록 무제한 스크롤(5c)·읽기 전용 설치 확인(5d)은 다음 조각에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Core/Original/ConfigInterface.cs`: `LoadBytes(byte[])`를 추가했다. 사용자
  루트 재정의가 설치 값을 덮을 때 쓰는 진입점이다. 1.041에서 추가됐다.
- `dotnetpj/src/Netstorm.Client/Host/HostStartupScene.cs`: 생성자에 `userOptionsPath`를 추가했다.
  지정하면 시작 설정 위에 사용자 파일을 덧읽고(`OverlayUserOptions`), 저장(`SaveOptions`)도 그곳에만
  한다. 없거나 읽을 수 없으면 설치 값을 그대로 쓴다. 설치 경로는 절대 쓰지 않는다. null이면 종전 설치
  경로 동작을 유지한다. 1.041에서 추가·수정됐다.
- `dotnetpj/src/Netstorm.Game/Program.cs`: 시작 장면에 `UserDataRoot.Resolve().OptionsFile()`을 넘긴다.
  사용자 루트를 정할 수 없으면 종전 설치 경로 동작으로 둔다. 1.041에서 수정됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostUserOptionsRootTests.cs`: 신규 4건. 사용자 저장·설치 파일
  보존, 사용자 값 우선, 누락 폴백·저장 폴더 생성, 읽기 불가 경로 무시를 대조한다. 1.041에서 추가됐다.

- `cpp_sync.py`는 종료 0이다(연결 fixture 513개 OK·신규 fixture 없음).

  (`extracted/dotnet-l2-1041`, 양쪽 exe 종료 0, `NETSTORM_USER_DATA` 분리 루트 사용). DN `f090.tsv`

  M1은 0/34를 유지하고 L2 기준선은 0998을 유지한다.
