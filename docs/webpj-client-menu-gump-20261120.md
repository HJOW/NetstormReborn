# Client 원본 메뉴 Gump 조립

WB04-E1043은 원본 MenuGump의 controlled 스택·생성·레이아웃·스타일·입력·출력·수명을 같은 Client 트리, 실제 자산과 글꼴·장식·다중 줄 제목·Session Form에 조립했다. 일반 세로 메뉴와 장식 메뉴를 만들고 원본 제목·머리·항목 작성 및 객체 참조를 사용할 수 있다. 배경 생성이 실제 생성 플래그를 전달하지 않아 메뉴 클릭이 걸러지던 문제도 수정했다.

Tutorial1 실제 Session에서 세로 메뉴 픽셀, 공통 마우스 입력과 Help 명령 전달, 장식 메뉴의 배경·제목·항목 출력 및 실제 내용물 Form 삭제를 검사했다. 관련 Node·원본 관측·대응표 검사 47건과 최종 앱 검사 4건이 통과했다. 최초 검사는 테스트 변수 이름 중복과 위 입력 플래그 누락으로 실패했고 수정 후 통과했다. 생산 우클릭 메뉴의 앱 설치 및 선택 명령 처리와 브라우저 검증은 남았다.

E1039 고정 Node 26 전체 회귀는 6,566건 모두 통과했으며 실패·취소·건너뜀 0이다.
