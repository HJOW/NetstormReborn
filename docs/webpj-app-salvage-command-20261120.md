# 앱 회수 명령 연결

WB04-E1047은 원본 회수 명령 0x0200005d의 인자를 현재 미션 Session의 RawSalvageCommand에 전달한다. 송신은 같은 로컬 전송에 0x54 패킷을 예약하고, 월드 변경·환불은 원본처럼 후속 수신에서 수행한다. 기존 회수 금지, 소유자, 제단과 다이스 관문은 같은 현재 Session 전역을 사용한다.

실제 Tutorial1에서 건설한 다리에 명령을 넣어 수신 전 상태 보존, 로컬 수신의 0x54와 이후 객체 삭제를 확인했다. 테스트에서 금지 상태는 잠시 해제하고 되돌렸다. 처음에는 수신 패킷 관찰 목록이 송신 시 갱신된다고 잘못 가정해 실패했으며 실제 Pump 뒤 관측으로 수정했다. 원본 회수 관측 3,458행과 생산 정보 3,888행을 포함하는 Node 26 관련 44건이 통과했다.

다른 객체의 회수 메뉴·사용자 화면 조작과 회수 금지 안내를 통한 실제 앱 검증은 남았다.
