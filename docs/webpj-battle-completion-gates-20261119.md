# WB04-E842 일반 전투 종료 관문

기준선 `225553df`의 `RawBattleCompletion` 중 전체 동맹, 팀 종료, 기권, 결합 종료 및 미접속 종료 조회를 이식했다. 9개 Player의 subscriber와 flags, 방향별 동맹, 관전자, 사제 생존, 서버 객체와 boss를 현재 값으로 읽는다. 양방향 동맹, 사제 판정 뒤 flags 재조회, 조건부 장치 요구와 원본의 짧은 반환 순서를 유지한다. 이 본체는 값을 조회하며 승리 처리나 상태 전환을 임의로 실행하지 않는다.

동일 기준선의 C++ `RawBattleCompletion.cpp`와 [관측 도구](../webpj/tools/battle-completion-oracle.cpp)를 MSVC C++20 `/utf-8`로 빌드해 합성 상태 4,096개를 실행했다. 각 상태의 여섯 판정 결과와 서버·사제 조회 순서의 누적값을 LF 정규화 SHA-256으로 고정하고 웹 검사에서 같은 입력을 재생해 일치시켰다. 초기 빌드는 MSVC의 기본 코드 페이지가 UTF-8 원문을 잘못 읽어 실패했으며 `/utf-8` 지정 후 성공했다. 원본 실행 파일과 게임 창은 실행하지 않았다.

판정기의 후반 프레임 `Frame`, 실제 Session의 현재 Player·로그인·사제 소유자 및 메뉴의 결과 처리 연결은 아직 남았다. 따라서 대응표와 인수인계 항목은 부분 구현 상태를 유지한다.

검증: 개별 경계 4건, C++ 관측 비교 4,096개 상태 1건, Node v26.13.0 전체 6,347건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E835의 Node v22 전체 검사 뒤 v26 회귀 7/8회다.
