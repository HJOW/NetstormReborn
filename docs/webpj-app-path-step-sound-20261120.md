# 미션 경로 발소리 연결 (WB04-E997)

사제 이동의 첫 좌표 변화 뒤 실제 경로 Step이 발소리를 요청했을 때 앱에서 해당 장치가 없어 프레임이 중단되는 문제를 수정했다. 같은 Client SoundPlayer의 위치 재생에 현재 좌표·소리 번호와 원본 반복/우선순위 0을 전달한다. 음향이 꺼진 브라우저는 같은 재생기의 비활성 경로를 사용한다.

실제 Tutorial1 Session의 발소리 효과가 Client 재생기에 전달하는 인자를 검사했고 경로·원본 SoundPlayer 관측 등 Node 43건이 통과했다. Chromium은 실제 사제 이동 후 게임 시계가 2초 더 진행되는지 확인해 이전의 조기 검증에서 놓친 Step 오류를 재현·수정했다. 비활성 음향으로 검사했으며 실제 스피커의 소리 출력은 별도 검증이 필요하다. E990 고정 Node 22 전체 검사는 별도 트리에서 진행 중이다.
