# 1.167 생산 항목 정보 메뉴 결선

제품 생산 항목의 우클릭 정보 콜백을 기존 `InventoryAboutMenu` 본체에 연결했다. 현재 세션의 TYPE 정의·생산 비용·플레이어 상태, 장기 역할 번호와 도움말 캐시를 사용한다. 공통 메뉴 작성기, 표시 바이트 번역·치환, 실제 소유자 이름·전역 음향 및 같은 객체 풀의 Form을 사용하며 동기 호출 동안 현재 Runtime을 유지한다. CPP `CampaignObjectMenuClient.cpp`의 생산 메뉴 부분과 `RawMenuControls.cpp`의 부착 경로를 포트 맵에 추가했다.

부분 적재 거부와 검사 전용 적재 표식 뒤의 실제 세션·내용물·공통 트리·Form 부착/정리, 원본 1,296+2,592행 및 기존 부모 삭제를 포함한 집중 6/6이 통과했다. 검사에서만 `_nativeLoaded` 표식을 켰으며 실제 제품의 완전 적재를 대체하지 않는다. 메뉴 항목 Help/회수 명령의 실제 종단과 제품에서 생산 항목을 사용자가 클릭하는 경로는 검증되지 않았다.

별도 Release 빌드로 캠페인1-1 고정 입력 다섯 프레임은 1.148과 같고 종료0이다. 튜토리얼1·surrounded 진입/대기도 종료0이며 90프레임 덤프가 1.147과 같다. 각 수집의 원본 1,392파일은 불변이고 `cpp_sync.py` 종료0이다. 결과는 `extracted/dotnet-about-1167-first/`, `extracted/dotnet-about-1167-missions/`, 별도 빌드는 `extracted/dotnet-about-1167-artifacts/`에 있다. 1.166 전체 회귀에는 이 단위가 포함되지 않는다.
