# 0.790 실제 이름·자산 부착·Host 객체 수신

HostSession의 고정 entry 네 개(433c30/434080/432710/4326e0)를 실제 객체·압축·검증 본체에 연결했다. 같은 공장 Take/WORD·가상 Owner/FirstPop·공간 Pop·현재 TYPE/HP와 GameAux 검증 두 상자·수신TYPE 문맥·LocalState 경고표를 사용한다. 압축 해제는 같은 송수신 owner 캐시를 쓰고 공통 객체 수신을 직접 부른다. 현재 packet 종류·등록표·sender로 본체를 다시 선택하지 않는다. 전체 NativeGameplay26F 등록표와 Root 전송 설치를 완료했다는 뜻은 아니다.

기술 검사는 현재 Core9기록의 owner×16+10 DWORD와 저장한 techBitIndex를 사용한다. 진단 복귀 뒤의 실제 장부 읽기와32비트 시프트 감김을 유지한다. PlayerNoMake는 먼저 현재 Player 이름 뷰를 선택하고 실제 설명 번역/치환 뒤 그 뷰의 현재 이름으로256BYTE 안내를 만든다. 실제 Tell은 마지막 선택 위치에서 조회한다. 안내 중 owner가 바뀌면 기존 owner의 경고 마스크를 유지하고 현재 Player의400 표식을 기록한다. 수신 장치는 같은 Pool/GameAux/TYPE만 빌리며 World 반납 때 참조를 놓고 이후 호출/재연결을 거부한다.

RawSquidName은 현재 TYPE 선택→언어 한 번/두 번 조회→현재 설명→선택 번역→80BYTE 경계→설정 치환을 복원한다. 실제 가상68의83개 표는 CPP SquidNameVtables.inc에서 그대로 옮겼고 순서/DWORD83쌍이 모두 같다.
