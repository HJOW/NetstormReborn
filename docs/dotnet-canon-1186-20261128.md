# 1.186 원본 자료 목록 교정

1.184의 Client 실패는 이미 독립 원본120행 대조를 통과한 `budget-refresh-x86.tsv`가 공통 목록에 빠졌기 때문이다. `cpp_sync.py --update --add budget-refresh:Client`로 해당 원본의 SHA-256 `5751f03a844bf48b56a8043d230e5d416d7fbf0560d66dbc7b9bdba192f24cae`와 120행만 등록했다. 다른 목록 행은 변경하지 않았다.

목록 검사·원본 재부착 120행·실제 State Gump 지연 삭제 집중 검사는 **7/7 통과**했다. 1.185와 목록 교정을 포함한 Client 전체 재실행은 `extracted/dotnet-1186-regression/`에서 진행 중이다. 직전 1.184의 Assets383·Core4121 통과와 Client 실패는 [별도 기록](dotnet-canon-1184-20261128.md)에 보존하며 재실행 완료 전 전체 회귀 통과로 취급하지 않는다.
