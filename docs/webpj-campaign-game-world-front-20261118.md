# WB04-E790 지연 캠페인 GameWorld 앞단

cpppj `client/GameWorld.cpp`의 캠페인 생성자 중 지연 로그인 경로를 시작했다. `CampaignGameWorld`가 같은 Client 전역·실제 `RawCampaignSession`·`RawCampaignFactoryDisplay`를 소유하고, 파일 팔레트와 신전 그림을 표시기에 연결한다. 로더의 초기 카메라는 같은 Session의 실제 초기 선택·적용 장치를 거쳐 바뀐 표면·입자·위치 음향 영역에 전달한다. 비동기 로그인 시작과 State7 후반 준비는 Session에 위임하며 중복 시작을 거부한다. 생성 실패 또는 종료 시 표시기를 먼저 놓고 Session을 반납한다.

TheWarBegins 실제 자산에서 지연 생성 후 Session/카메라/표시기 동일 소유, 실제 내부 로그인 Ready, 초기 카메라 적용과 지도 영역, 현재 자산 표시 목록 수집 및 반납을 검사했다. 화면 적용 장치는 픽셀을 적용하는 명시 독립 검사 장치이며 브라우저 Renderer 전체가 아니다. 화면 크기 오류와 로그인 장치 누락 시 대여가 남지 않는 것도 확인했다. 선택/삭제·객체 보기·로그인 완료 공개·입력·전체 Renderer 및 앱 연결은 남으며 실제 미션 플레이로 간주하지 않는다.

검증: Node v26.13.0 전체 6,293건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 마지막 Node v22 전체 검사는 E787이며 이번 단위까지 이후 v26 전체 검사 3/8회다.

후속 E791에서 실제 로그인 완료 관문과 현재 자산 보기를 연결했다([단위 문서](webpj-campaign-game-world-objects-20261118.md)). 선택 정리·지연 팔레트·입력·앱 연결은 계속 남는다.
