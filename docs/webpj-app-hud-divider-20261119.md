# WB04-E916: Client HUD 구분선 연결

cpppj `RawUberRootControls`의 구분선 연결을 `ClientHudDivider`에 옮겼다. 실제 Client 공통 등록표에서 `HudDividerNode`를 할당하고 같은 배경 생성기, 구분선 생성·가상 부착, 수명 overlay·삭제, 입력, 트리, 부모 사건과 serial 조회를 사용한다. 배경 색과 구분선 색, 비0 타입·프레임과 popup·입력 장치는 호출자의 실제 장치를 사용한다. 도달한 미연결 장치는 성공한 것으로 처리하지 않는다.

실제 공통 루트와 자식에서 구분선을 생성·부착하고 마우스 캡처와 방송 이동으로 연결 자식 크기가 바뀌는 것, release와 전체 수명 삭제를 확인했다. 최초 기대값을 40으로 잡았으나 원본 드래그 기준점 1픽셀의 보정으로 실제 좌표 39가 맞아 교정했다. 비0 타입의 실제 shape·타일 크기 전달도 확인했다. 원본 입력 13,398행과 도킹 2,150행을 포함한 관련 Node 검사 30건이 통과했다.

현재는 실제 Client 공통 소유자 위의 구분선 경계이며 전체 Uber 공장, popup 및 실제 메뉴 장치, 자동 방송, HUD 출력과 미션 화면은 아직 연결하지 않았다. 전체 RawUberRootControls는 partial이다.
