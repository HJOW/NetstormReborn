# dotnetpj 0.966 — 0x7b·0x7c Build 연결과 챌린지 장기 소유

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 같은 장기 CS만으로 묶이는 후크 결합 수신기(0x7b 챌린지 기본값·0x7c 메타 게임 로그인)를 `ClientPacketDispatch.Build`에 연결하고 호스트가 챌린지 CS를 장기 소유하게 했다. 0.965의 지연FIFO와 제품 기존 경로는 바꾸지 않는다. 세션·메뉴·월드가 필요한 나머지 후크 결합(0x71·1a/1b·0x1d·0x66·0x0f·0x26·2번·참가자/전투 묶음)과 수송 생성·재결합·Publish는 후속에서 잇는다.

## 변경과 원문 대응

- `ClientHostGame`은 `ClientChallengeGlobals`를 Client 수명으로 소유한다. 원문 `client.ChallengeGlobals()` 장기 소유에 대응하며 세션 교체로 다시 초기화하지 않는다. 0.966에서 추가됐다.
- `ClientPacketDispatch.Build`는 `ClientChallengeGlobals challenge`를 받아 `ClientChallengePacketDefaults.Install`(0x7b)·`ClientMetaGameLogin.Install`(0x7c)을 같은 기본 표에 설치한다. 두 Install 모두 장기 전역(도전·게임·연결·저장소)만 캡처하고 세션·메뉴·월드를 선조회하지 않으므로 호출 시점 실제 CS·연결로 동작한다. 0.966에서 추가됐다.
- 0x7c 수신 후행은 0.946 본체를 재사용하며, 0x7b 수신 후행(CS0 조기 반환·구독자 일치 시 주소 꼬리 BYTE 복사)은 0.787 본체를 재사용한다. 새로 만든 본체가 없다. 0.966에서 추가됐다.
