# WB04-E930: 한글 Console 자동완성 단어 경계

cpppj `TextEntryGump::HandleConsole`의 확장 표시 문자 단어 검색을 옮겼다. 한글이 포함된 본문은 이전 완전한 문자 경계를 따라 역방향으로 이동하고, 한 바이트짜리 공백·콜론만 단어 구분자로 취급한다. 확장 토큰 내부의 숫자 바이트가 공백 코드여도 단어를 끊지 않는다. 순수 바이트 본문의 기존 경로와 callback 인자는 유지한다.

내부에 공백 분류 바이트 0x0b가 들어가는 실제 한글 ‘갈’을 원본형 Console 버퍼에 입력하고 자동완성 callback이 네 바이트 전체를 받는지 확인했다. 원본 편집기 관측 2,292행을 포함한 관련 Node 검사 28건이 통과했다.

실제 Console 공장·자동완성 장치와 브라우저 IME 및 글꼴 출력 연결은 남았다.
