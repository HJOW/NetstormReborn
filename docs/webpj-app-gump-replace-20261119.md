# WB04-E913: Client Gump 루트 교체

원본 `RawButtonControls`의 루트 별칭은 공통 `GumpLifetime.replaceRoot`가 등록표 0번을 바꾼 뒤 같은 새 토큰을 가리킨다. 웹 Client Gump 소유자도 이 순서로 공통 지연 삭제·정리를 실행한 뒤 현재 루트 별칭을 갱신한다. 호출자는 원본 `UberRootGump.replace/recreate`처럼 새 노드의 임시 등록 칸을 먼저 반환해야 한다.

기본 루트는 원본과 같이 미처리 사건을 0으로 반환한다. 교체된 파생 루트는 등록한 실제 파생 처리기로 사건을 전달하며 기본 루트의 빈 처리로 가로채지 않는다. 전체 Uber 생성자에 실제 미니맵·생산·채팅 공장과 HUD 화면은 아직 연결하지 않았다.

실제 공통 수명과 Uber 파생 노드로 이전 루트 반납, 등록표 0번·Client 별칭 일치, 입력 분배, 크기 변경과 최종 삭제를 확인했다. 원본 Uber 160행·Gump 입력/수명 연관 Node 검사 36건과 Chromium 루트 교체 1건이 통과했다. Node v26.13.0 전체 회귀 6,472건도 통과했다.
