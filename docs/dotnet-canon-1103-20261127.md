# dotnetpj 1.103 — 장기 내용물 수명 장치의 제품 연결

2026-11-27, HJOW-Athlon. 제품의 첫 내용물 본체 전에 같은 커서 미리보기·Player 소유자·내용물 TYPE 상자를 장기 Surface에 연결했다. 선택된 커서 취소는 현재 세션 Runtime을 고정해 세션 본체로, 메뉴 상태는 장기 커서 본체로 전달한다. 로컬 수입은 같은 입력 큐, 원격 수입은 1.102의 현재 연결 송신, 위치 음향은 같은 미션 음향 장치에 연결했다. 각 효과는 선택될 때만 실행한다.

- 실제 파일 자산과 장기 저장소의 ContentForm을 생성하고 공통 Form 삭제 분배로 지워 같은 커서 상자와 취소 효과를 확인했다. 관련 Client 17/17 통과, 검사와 제품 Core/Client/Game DLL 해시 일치. 최초 검사 빌드의 테스트 자산 네임스페이스 누락은 수정했다. 실제 너겟 수입·세션 커서·음향 재생 및 원격 외부 전송을 재현한 검사는 아니다.
- Game Release 빌드 성공, `cpp_sync.py` 종료 0. 대표 세 미션 CPP/DN 각각 종료 0, DN 90프레임 덤프는 0998과 바이트 일치, 원본 1,392파일은 세 감사에서 불변이다. 기존 CPP-DN 상태 차이로 비교 도구 종료 1. 결과 `extracted/dotnet-l2-1103-content-devices/`.

세션의 자체 전체 삭제 분배기에 ContentLifetime 등록, 장기 종속 해제의 Native 내용물 부모 통지와 실제 Gump 부모 삭제 중 UI 중첩 통지/삭제 검증은 아직 남았다. 제품의 세션 커서 본체와 생산 Form 생성·부착, 인벤토리 내용물/유지/입력, 전체 UberRoot/L4a 일치도 미완료다.
