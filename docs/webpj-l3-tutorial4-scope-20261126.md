Tutorial4 단계표는 7,240프레임까지 E1335와 배열 전체가 같다. 기존 수집 파일은 수정하지 않았고, E1~I1 중단본의 16개 파일도 manifest에 보존 자료로 등록했다. 이 자료 등록은 웹 일치 판정을 뜻하지 않는다.
