# 1.231 실제 State 정리 장치와 메뉴 미니맵 프레임

2026-11-29, HJOW-Athlon. **실제 정리 네 경로와 집중81/81 통과**다. H-1의 장치 조립을 진행했으며 원문 State3/7 호출 위치·저장/메타 분기·H-2~3은 미완료다.

## 연결

`ClientHostGame.CleanupNativeWorld(reason)`은 같은 제품의 게임/음향 정지 반납, Gump Kill/Cleanup, UberRoot 교체, SP 표시, Scene Start, 효과음 루프 중지, 옵션 재해석을 기존 `ClientStateWorldCleanup`의 원문 위치에 공급한다. 이미 연결한 커서·채팅·Runtime 반납을 재사용한다. 각 음향 효과에 도달한 순간에만 같은 장기 소유자를 요구하며 미선택 음향을 선행 검사하지 않는다.

개별 장치를 전달하는 기존 overload는 유지한다. Fort/Battle snapshot과 메타 이탈 장치는 이번 기본 조립에 아직 없으므로 해당 선택 분기는 기존 명시 오류를 유지한다. 빈 callback이나 성공값을 넣지 않았다. 개발용 `StartMission`을 감싸거나 원문 위치와 무관하게 시작 때 두 정리를 추가하지 않았다.

## 실제 실행에서 드러난 프레임 누락

초기 실제 메뉴는 reason0·1, SP/Core/장기 소유자, GPU 출력과 Dispose를 통과했다. 1-1도 두 정리와 실제 Runtime 반납은 정상 복귀했으나 다음 그리기에서 미니맵의 bitmap 할당 밖 주소를 읽어 종료1이었다. 첫 실패는 `extracted/dotnet-1231-state-runtime/`에, 추가 관측은 `extracted/dotnet-1231-state-runtime-diagnostic/`에 보존했다. 두 실행의 보호1,392파일은 각각 불변이다.

관측된 기존 미니맵은80×75/crop(8,16), 전체 Uber 생성 직후는80×363/crop(0,-235)였다. 원문 Uber 생성자는 미니맵 구분선을 우선 y=400에 만들고 이후 부모의 HUD 모드 명령으로 최종 배치한다. 따라서 생성자의400이나 crop 수식을 임의로 바꾸지 않았다. 문제는 제품 Update가 `_missionSession != null`에서만 미니맵을 갱신해, Runtime 반납 후 새 메뉴 HUD의 전체 갱신 요청을 소비하지 않는 데 있었다.

CPP `ClientMain.cpp:616`은 영상 갱신 잠금 밖에서 현재 메뉴의 `RefreshMinimap()`을 실행한다. DN도 미션 조건을 제거해 현재 미니맵의 원래 표시/visible/dirty 관문을 사용하도록 맞췄다. 본래의 프레임 갱신이 새 crop을 처리하며 bitmap 접근을 자르거나 범위 검사를 완화하지 않는다. Movie 잠금은 그대로 존중한다. 실제 State 부모의 HUD 모드/최종 패널 배치를 완료한 변경은 아니다.

## 일회성 실행기 사용법

`ContentProbe.exe`는 배포물이 아니다. `dotnet build extracted/dotnet-1231-state-probe/ContentProbe.csproj -c Release`로 현재 제품 DLL을 참조해 빌드하고 `ContentProbe.exe <보고서 절대 경로> [미션 키]`로 실행한다. 미션 키를 생략하면 메뉴다. `NETSTORM_DATA`는 보호 데이터 사본, `NETSTORM_USER_DATA`는 별도 쓰기 루트, `NETSTORM_PROBE_SETTINGS`는 선택 시작 설정이다. 내부 조건은 창·음소거·60프레임·고정25ms·Unix1760000000이다. 실제 창 실행에는 AGENTS의 확인/예외 PC 규칙을 적용한다.

같은 네 경로와 보호 해시를 모으는 명령은 `python -X utf8 extracted/dotnet-1231-run-state.py verified`다. 일반 진입 회귀는 `python -X utf8 extracted/dotnet-1231-run-normal.py baseline`이며 기존 `l2_compare.OPTIONS`와90프레임 덤프 조건을 유지한다. 최초/진단/최종 결과는 다른 디렉터리에 보존했다.
