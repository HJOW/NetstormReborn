# dotnetpj 0.813 — Player 고유 삭제와 현재 기록 owner 연결

2026-11-22 · HJOW-Athlon · 유일한 실행 경로는 `Netstorm.Game/Netstorm.exe`다. 전체 목표와 M1은 미완료다.

## 변경과 범위

전체 Native 삭제 설치의 선행을 확인하면서 `RawPlayerWorld::PreDestroyNative`와 장기 실제 Player 기록 owner 결합이 DN에 빠진 것을 확인했다. PATCH의 고유 Pre 전체를 `RawPlayerWorld.PreDestroy.cs`에 이식했다. 현재 owner와 기록 base를 각 주소 계산에서 다시 읽고, 자신 Technology SID만0 → 비가상 공통 Pre → 다시 현재 flags bit0 해제 → 세 번째 현재 flags bit8 설정 순서를 지킨다. owner를9행으로 선행 제한하지 않고 실제 view의 물리 범위를 각 위치에서 확인한다. 한 DWORD 접근 끝까지 실제 owner를 보유한다.

원문의 `PlayerRecordAccess`를 실제 owner와 `Memory<byte>`로 대응했다. Core가 Client 어셈블리를 참조하지 않도록 Client 전용 `ClientSurfaceGlobals.BindPlayerRecords`가 실제 `ClientPlayerRecords`를 약하게 보유하고 기존 `Storage.BindPlayerPre`에 이 몸체/실제 `CommonDeletion().PreDestroy`를 연결한다. 최초 결합은 기록 배열을 조회하거나 초기화하지 않는다. 중복·대여 중·Native 미설치 결합과 owner 만료를 명시적으로 구분한다. 기존 typed Player 생성/Post/조회 몸체는 부분 클래스 선언 외에 바꾸지 않았다.

**일반 Root의 전체 Native 삭제를 설치 완료한 것은 아니다.** 새 검사는 같은 Client 기록의 실제 재할당과, 고유 SID 정리 뒤 실제 CommonDeletion 장치 미설치가 선택되는 위치까지 확인한다. 이를 성공 no-op이나 다른 삭제 본체로 통과시키지 않는다. 장기 장부/Graph/모드/삭제 깊이 공유, 첫 Host 이전 전송/선택·보상·삭제·후처리 장치와 실제 파생/UI/AI·음향·진단 설치가 남아 있다. 고정 본문은18/26이며 이번 고유 Pre를19번째 패킷으로 세지 않는다.
