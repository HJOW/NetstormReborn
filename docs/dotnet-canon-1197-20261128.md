# 1.197 실제 게임 정지와 UI 보유 표식

CPP `ClientMain::Pause`·`PushGamePause`·`PopGamePause`를 같은 장기 `ClientClockGlobals.Clock`에 연결했다. UI 단일 정지 보유 표식은 실제 Clock의 중첩 깊이와 별도로 두고, 같은 UI 요청은 밀리초 공급도 호출하지 않는다. 실제 Pause/Resume 성공 뒤 표식을 변경하며 최종 Pop은 UI 표식도 해제해 다음 UI의 정지를 막지 않는다. 영상 갱신 잠금과 음소거는 독립이다. 새 Game partial이 실제 현재 밀리초를 이 입구에 전달한다. 전체 State 부모 호출은 아직 미완료다.

실제 시계의 게임/벽 시각·프레임 주소 보존·중복 시각 조회 생략·중첩/최종 Pop·시각 공급 실패의 부분 효과·실제 음소거와 영상 잠금 독립을 검사하는5건을 추가했다. 최초 통합 빌드는 병행 작성 중인 음악 타입이 아직 없어 CS0246 3건으로 실패했다(`extracted/dotnet-1197-tests/test.log`). 이 중간 소스 실패는 제품 회귀로 세지 않으며 팀 전체 소스 동결 뒤 재빌드했다.

별도 단일 소스 검사의 첫 실행은 검사에 필요한 효과음 장치를 생략해4통과1실패였고, 미선택 장치를 모두 명시 오류로 공급한 교정 뒤5/5 통과했다(`extracted/dotnet-1197-pause-isolated/{first-test-fixture-failure,test}.log`). 소스 가림 CS0436 경고가 있는 이 검사를 정식 제품 빌드로 세지 않았다.

이후 실제 Release 제품/검사 빌드에서 새 Pause **5/5**, 음악 선택·기존 음량/효과음·State·자료 목록을 포함한 집중 **46/46 통과**다. 결과는 `extracted/dotnet-1198-tests/pause-selection.trx`, 빌드 로그는 `extracted/dotnet-1198-build.log`이며 오류0·기존 제품 경고8이다. 실제 전체 State 왕복이나 음악 재생의 완료를 뜻하지 않는다. 새 제품 partial의 PORT_MAP2행을 등록했다.
