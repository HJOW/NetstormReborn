# 영어 Tutorial2 완주와 완료 기록 확인 (WB04-E1091)

한국어로만 확인했던 Tutorial2 전체 흐름을 영어 문구로 실제 Chromium에서 시작부터 완료 창과 Tutorial3 시작까지 자연 진행으로 확인했다. 앱 코드 변경은 없고 영어 경로에서도 안내 A~I, 신전·워크샾 건설, 연구 생산, 발사기 배치·에너지 범위·회수, 완료 창이 모두 통과한다.

## 확인한 것

- **영어 흐름.** 새 `e2e/english-tutorial2.spec.js`가 한국어 흐름과 같은 조작(사제 우클릭 → 건설 → 신전, 워크샾, 지식 생산 투입, 발사기 네 개 배치, 신전 선택, 발사기 회수)을 영어 메뉴(`Campaign` ▸ `Early Missions`)에서 반복한다. 안내 창의 단추는 문구 대신 열린 창의 마지막 단추로 눌러 언어에 의존하지 않는다.
- **완료 기록 저장.** 완료 창(`I.`)이 뜨면 미션 대본의 Config 효과(`Done...=1`)가 `localStorage`의 진행 저장소(`netstorm.progress`)에 `DoneTutorial2=1`을 남기는 것까지 확인한다.
- **다음 튜토리얼 시작.** 완료 창의 두 번째 단추(Next)가 현재 미션을 떠나 Tutorial3을 시작한다.

## 남은 경계

Tutorial3 이후 미션(T3~T5는 AI 네 명과 싸우는 전투 미션)의 목표 수행·승리와 자연 완주는 남아 있다. 한국어 흐름과 달리 영어 흐름은 본문 문구를 단언하지 않는다(영어 대본 문구는 원본 자료이며 위치만 확인한다).
