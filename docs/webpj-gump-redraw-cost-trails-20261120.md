# Gump 화면 갱신과 비용 잔상 (WB04-E1081)

기존 앱의 Gump 재그리기 콜백은 화면 표시만 요청해 이동 전 위치가 Renderer의 dirty 목록에 들어가지 않았다. 원본 `GumpRedraw.whole`을 실제 Client 트리와 현재 Renderer에 연결해 위치 변경 전후를 복구한다. 아직 상단 원본 HUD가 없으므로 앱의 지도 밖 dirty는 검은 바탕으로 지운 뒤 살아 있는 UI를 다시 합성한다. 원본 상단 HUD 구현 시 이 임시 바탕을 교체해야 한다. UI 전용 dirty는 배경을 지우지 않는다.

실제 미션 화면의 비용 노드 이전·현재 dirty와 지도 밖 복구 및 UI 전용 경계를 검사했다. 원본 10.78 FloatingSp 관측 426행 등을 포함한 관련 Node 22·26 각 6건과 Chromium 한국어 Tutorial2의 두 건물 자연 완공·생산 후 상단 픽셀 검사가 통과했다. 다른 HUD와 모든 화면비의 시각 검증은 남았다.
