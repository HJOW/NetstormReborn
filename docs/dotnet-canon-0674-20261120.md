# 0.674 건설 표시 프레임·확장·색·영역·Draw

- 일시: 2026-11-20, HJOW-Athlon.
- 근거: `cpppj/src/o/RawConstructionFrame.cpp/.h`, `cpppj/tests/ConstructionFrameTests.cpp`, 불변 `constructionframe-x86.tsv` 1,317행.
- 범위: 실제 시각·HP 활성화·인접 확장·입자 만료/색·dirty 영역과Draw 본체. 실제 표시 프로세스·장치 연결은 후속이다.

## 구현

`RawConstructionFrame`은 생성 단계의 같은 소유 픽셀·입자와 난수를 사용한다. 원본 시각 차이의float 저장·double 누적, PATCH의HP 사전float 저장과CD의최대HP 경계 뒤WORD 재조회, 색 표 역수float/나눗셈 순서를 보존한다. 목표 활성 수는 한 번 계산하며 확장 뒤 바뀐selected/total은 매 반복 다시 읽는다.

인접 선택은 선형 오른쪽·왼쪽·위 순서다. 활성 입자 만료는 마지막 활성/전체 입자를 두 번 복사하고 같은 위치를 다시 처리한다. 미활성 입자는 판본별 덧셈 순서로 수명을 재시작한다. 출력은 현재 색 표 토큰·읽기 경계를 확인하며dirty 이전/새 영역 사이의현재 카메라 변경과마지막 abstract 재조회를 유지한다. capacity가 있으면total0도Draw한다.
