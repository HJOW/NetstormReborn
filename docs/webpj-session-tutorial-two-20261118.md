# WB04-E779 Session 튜토리얼 2 판정 연결

cpppj `RawCampaignSession.cpp`의 `MakeTutorialTwo`를 로그인된 같은 Session의 옵션 갱신기·Player 생산 목록·제작 장부·현재 타입 및 회수 금지 DWORD와 연결했다. 화면 선택·시계·안내는 호출자가 공급하는 실제 경계로 유지한다. 옵션/생산 조회는 해당 판정 시점의 현재 소유자를 읽는다.

TheWarBegins 실제 로그인과 실제 게이트에서 초기 옵션 및 에너지 반경 갱신, 신전/워크샾 제작 판정과 선택 해제 순서, 빈 실제 생산 Deck의 단계 유지, 회수 명령에 따른 금지 해제 및 2초 예약을 검사했다. 회수 명령은 판정기에 전달한 입력이며 실제 유닛 회수나 미션 완주를 실행하지 않았다. 최초 집중 검사에서 생산 Deck 할당 장치가 없는 시험 장면으로 조회해 실패했고, 실제 Deck이 요구하는 명시 할당 장치를 제공해 통과했다. 별도 첫 수정은 같은 모양의 다른 테스트 줄을 선택했으므로 원복 후 정확한 장면에 적용했다. Early3~6·공통 미션 프레임·GameWorld·앱 연결은 남는다.

Node v26.13.0과 v22.23.3 전체 회귀를 순차 실행해 각각 6,282건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 오류는 0건이며 다음 Node v22 검사까지 v26 회귀는 0/8회다.
