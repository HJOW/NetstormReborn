# dotnetpj 1.025 — R4-5b AI 이동 본체 이식

2026-11-25, HJOW-Athlon. R4-5b 하위 행동 본체 묶음의 스무 번째 조각이다.
cpppj `o/RawAiMovement.cpp/.h`의 `RawAiMovement` 전체(MovementForm·Stop·
ToTarget·ToPoint·Home)와 자유 함수(`AiDistanceToFootprint`)·구조체
(`AiMovementHooks`)를 DN
`dotnetpj/src/Netstorm.Core/Original/RawAiMovement.cs`로 옮겼다. 함께 쓰는
운반 명령 헤더/작성기(`CarrierMoveState`·`WriteCarrierMoveCommand`,
cpppj `o/RawCarrierMove.h` 일부)도 DN
`RawCarrierMoveState.cs`로 옮겼다. 세션 호출자(R4-5b 나머지)와 매 프레임
실행(R4-5e)은 아직 잇지 않아 제품 덤프에 영향이 없다.

  이동·희생 분기·권한 재조회·좌표/신전 이동·거리 경계를 둔다.
  1.025에서 추가됐다.

  cpppj `RawCarrierMove.h`의 `CarrierMoveState`와
  `WriteCarrierMoveCommand` 18BYTE 작성기만 옮겼다(전체 `RawCarrierMove`
  수신/요청 본체는 R4-6·R11에서 잇는다). 1.025에서 추가됐다.
- `dotnetpj/tests/Netstorm.Core.Tests/RawAiMovementTests.cs`: 신규
  8건. cpppj `tests/AiMovementTests.cpp` 8건 전부를 옮겼다. 보드 접근점은
  DN `RawBoardTarget` 몸체를 쓴다. 1.025에서 추가됐다.
- `dotnetpj/PORT_MAP.tsv`: 4행 추가. `RawAiMovement.cpp/.h`→
  `RawAiMovement.cs`와 `RawCarrierMove.h`→`RawCarrierMoveState.cs`(헤더
  일부)를 port로 등록했다(기준 rev-parse 65988c6d). 1.025에서 추가됐다.

## 검증

- Release 제품 빌드는 오류 0이다. 신규 경고 0이다.
- 신규 8건(Core 8건)은 통과 8·실패 0이다. 초회 빌드 오류 2건(`uint`→`byte`
  인자)은 바로잡았다.
- `cpp_sync.py`는 종료 0이다(연결 fixture 512개 OK·신규 fixture 없음).
- 제품 세션에 결선하지 않았으므로 L2 덤프에 영향이 없다. L2 기준선은 0998을
  유지한다(M1 0/34).
