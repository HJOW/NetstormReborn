# WB04-E741 개발자 Player·동맹 진단

`31h`의 `dumpPlayers`/`dp`, `dumpAlly`/`dally`를 현재 Session의 Player 기록과 수준 29 추적에 연결했다. Player 플래그·이름과 동맹 비트는 각 출력 직전에 현재 값을 읽으며, 이름 범위나 NUL이 잘못되면 원문의 물리 경계를 명시 오류로 둔다. 공통 명령 토큰과 정수 입력 파싱은 E740의 설정 분기와 공유한다.

근거는 기준선 `225553df`의 `RawCampaignSession.cpp` `ExecuteDeveloperCommand`이며 기준선 이후 해당 파일 변경은 없다. 새 원본 fixture나 직접 cpppj 검사는 없다. 다른 개발자 명령은 여전히 미연결 오류로 둔다.

독립 검사에서 출력 중 Player·동맹 비트가 바뀌는 순서, 이름·입력 경계와 원본 로그를 확인했다. Tutorial 1 Session의 실제 `31h` 분배기에서 같은 Player 기록과 추적 소비자를 확인했다. 설정 회귀를 포함한 집중 검사 33건이 통과했다.

Node v26.13.0 전체 회귀 6,222건을 통과했다. 대응표 오류는 0건이며 Node v22 전체 재검사 주기는 3/8회다.

다음은 `31h`의 나머지 개발자 명령과 내부 로그인 서버 후반·응답 왕복이다. Native 분기, 행 base 뒤 변경 판정 및 앱 미션 연결도 남아 있다.
