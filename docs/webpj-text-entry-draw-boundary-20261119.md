# WB04-E929: 확장 문자의 편집기 출력 경계

cpppj `TextEntryGump::Draw`의 확장 문자 보정을 웹 원본형 편집기에 옮겼다. 복사한 줄에서 스크롤 위치와 선택 앞/뒤를 완전한 토큰 경계로 조정하고, 앞부분을 잘라낸 뒤 표시 길이와 선택 좌표를 함께 줄인다. 화면 왼쪽에서 끝난 선택은 가짜 캐럿으로 바꾸지 않는다. 확장 문자가 없는 줄은 기존 원본 바이트 출력 경로를 유지한다.

실제 편집 버퍼에 영어·한글을 입력한 후 수평 잘라내기와 선택을 적용해 출력 훅에 완전한 한글 바이트가 전달되고, 화면 밖 선택에서 잘못된 캐럿이 생기지 않음을 확인했다. 기존 원본 편집기 관측 2,292행을 포함한 관련 Node 검사 31건이 통과했다.

이 검사는 실제 Gump 출력 훅에 전달할 바이트와 좌표까지다. 앱의 실제 한글 글꼴 측정·Canvas 출력, 클립보드와 브라우저 IME 연결은 남았다.

Node v26.13.0 전체 회귀 6,497건이 실패·취소·건너뜀 없이 통과했다.
