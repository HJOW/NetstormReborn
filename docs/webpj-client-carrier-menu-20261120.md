# 실제 Client 운반체 메뉴

WB04-E1069는 사제 기본 메뉴를 같은 Session의 운반체 메뉴, 회수·공통 객체 메뉴 및 Player 하위 메뉴에 결합한다. 현재 이동 불가, 이동 프로세스, 투하 위치, 건설 배치, SP와 사제 사건은 실제 Session에서 조회한다. 실제 Tutorial1 사제의 건설 하위와 도움말·Player 하위 및 Gump 반납을 확인했다.

운반체 원본 관측 314행, 위치 계산, 사제 메뉴와 실제 미션 검사 Node 22·26 각 15건이 통과했다. 최초 검사에 존재하지 않는 파일명을 사용해 Node 26이 무시했으므로 실제 `carrier-menu.test.mjs`와 `carrier-drop-point.test.mjs`를 확인해 다시 실행했다. 운반 중인 내용물의 실제 미션 메뉴, Cast/Drop 명령과 사용자 우클릭 연결은 아직 검증하지 않았다.
