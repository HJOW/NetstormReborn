# dotnetpj 1.082 — 미니맵 카메라 좌표와 프레임 갱신

2026-11-27, HJOW-Athlon. 미니맵의 `View`가 화면 픽셀 정수를 float로
변환해 월드 좌표로 넘기던 결함을 교정했다. CPP `GameWorld::MinimapView`
와 같이 동일 카메라 snapshot의 `WorldBits`와 현재 `CellPixels`를 사용한다.
미션 중 영상 갱신 잠금이 없으면 미니맵을 지연 삭제·Idle·Kernel 전에
갱신한다. 근거는 CPP `ClientMain.cpp`의 `RefreshMinimap` 호출 순서다.

- Game Release 오류 0, 기존 경고 8건. 기존 미니맵 기하·제어·부착 검사
  13/13 통과(기존 빌드된 검사 어셈블리 사용).
- `thewarbegins`의 동일 조건 실제 100프레임에서 원본과 미니맵 80×75
  RGB 차이가 901/6,000에서 388/6,000으로 감소했고 카메라 외곽선이
  표시됐다. 실행 종료 0·원본 1,392파일 불변. 결과는
  `extracted/dotnet-l4a-1082-camera/`다. 완전 일치는 아니다.
- 대표 `thewarbegins` L2 양쪽 종료 0·DN 0998 덤프 바이트 일치·원본
  1,392파일 불변. 원본과의 기존 차이로 비교 도구는 종료 1이다.
  결과는 `extracted/dotnet-l2-1082-camera/`다.

실제 월드 Pop/Unpop의 변경 알림과 종료 반납, 채팅 구분선의 원본 표시
상태·전체 slave 배치, 미니맵 입력과 픽셀 완전 일치는 남는다. 현재
미션 카메라의 이동을 이용한 미니맵 갱신 실제 입력 시험은 하지 않았다.
