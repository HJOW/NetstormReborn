# dotnetpj 1.059 — SL-6 WorldRuntime 장치 일원화 고정

2026-11-26, HJOW-Athlon. R4-6 시작·수명 묶음의 SL-6이다. Native WorldRuntime 장치의 단일
소유 행렬을 제품 순서로 고정했다. 앞선 Native 초기화 주소 세대는 상수 해킹 없이 R4-8·M1
로드 대 프레임 분해에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/tests/Netstorm.Client.Tests/HostSharedDevicesRootTests.cs`: 신규 2건. 제품
  StartMission과 같은 공유(표면 저장소·SP·Gameplay·풀·템플릿·프로세스 시각·로컬·커널)로
  묶은 세션이 풀·SP·Gameplay·템플릿·프로세스 시각·로컬·연결·커널을 복제 없이 빌리는지,
  엇갈린 소유자는 조립 단계에서 거부되는지를 대조한다. 표면 저장소·템플릿 직렬화 전역의
  선행 연결도 제품과 같은 순서로 둔다. 1.059에서 추가했다.
- 제품 변경은 없다. 공유 소유자 검증·대여는 이미 제품 경로에 있으며 주소 상수는 손대지
  않는다. 근거: 0.714(장기 Player 고정뷰·주소 차이 명시) · [M1 분해](docs/dotnet-m1-load-vs-frame-20261125.md).
