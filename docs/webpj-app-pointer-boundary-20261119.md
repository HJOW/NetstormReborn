# WB04-E920: 앱 Client 포인터 안팎과 입력 큐

앱 Client 수명에 실제 원본 40칸 `InputQueue`와 장기 `GumpPointerBoundaryState`를 두고 기존 브라우저 폴링을 사용해 안팎 보정 함수를 실행한다. 화면 밖으로 나간 시점의 좌·우 버튼을 기억하고 재진입 시 그동안 놓인 뗌 사건을 같은 큐에 예약한다. 재시작하면 큐와 기록은 새 Client 수명으로 초기화된다.

실제 앱 폴링·큐를 사용한 안→밖→안 시험과 원본 관측 3,878행을 포함한 연관 Node 검사 20건이 통과했다. Chromium에서도 Canvas 마우스 누름과 합성 pointerleave, 실제 뗌을 사용해 재진입 release를 확인했고 같은 파일의 검사 2건이 통과했다.

현재 보정 함수는 Client에서 호출 가능하지만 앱 프레임에 자동 호출하지 않는다. 브라우저 일반 입력 사건의 큐 삽입, 미션 입력 소비, Guide·카메라·overlay 호출 순서와 전체 화면 설치는 아직 남았다.
