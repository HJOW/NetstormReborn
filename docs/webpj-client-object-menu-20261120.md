# 실제 Client 공통 객체 메뉴

WB04-E1068은 같은 Session의 현재 소유자·회수 금지·가상 개수·체력·환불과 실제 Player 하위 메뉴를 원본 공통 객체/회수 메뉴에 연결한다. 도움말 캐시와 정적 문자열 토큰, 설정 저장은 현재 Client 장치를 빌린다. 실제 사제의 도움말·Player 항목과 실제 신전의 회수 안내 토큰을 확인했다.

객체 메뉴 원본 717행, Player 원본 292행과 실제 미션 검사를 포함해 Node 22·26 각 14건이 통과했다. 최초 회수 검사는 비용이 0인 다리에 일반 회수 항목이 있다고 잘못 기대해 실패했으며 원본 분기에 맞는 실제 신전의 안내를 검사했다. 사제의 Carrier 기본 메뉴, Factory 파생 메뉴, 실제 우클릭과 정적 Tell 명령 소비는 남았다.
