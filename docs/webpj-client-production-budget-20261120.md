# Client 생산 예산 표시

WB04-E1027은 생산 패널의 원본 예산 한 줄 표시를 실제 Client Gump·TextGump·StyleText 그림에 연결했다. 알려진 자본은 목표까지 차이에 따라 100·10·1씩 이동하고 fort 모드는 즉시 목표를 표시한다. 자본 단계별 색과 스톰 파워 그림을 갱신하며, 부족 경고의 10회 점멸은 원본의 150ms 간격을 따른다. 기존 GumpFrame idle 목록과 소멸을 사용한다.

Tutorial1 실제 Session에서 자본을 설정해 증가·감소 경계, 즉시 이동, 두 점멸 단계와 자식 삭제를 확인했다. 관련 Node 및 이식 대응표 검사 27건이 통과했다. 최초 시험은 Tutorial1의 당시 자본이 300보다 크다는 잘못된 가정으로 실패했으며, Session의 실제 설정 API로 필요한 금액을 준비한 뒤 재검사했다.

예산은 아직 생산 패널에 설치하지 않았다. 생산 격자·배경·구분선 조립, 실제 앱 idle 호출 및 브라우저 표시와 입력 검증이 남아 있다. E1026 고정 Node 26 전체 회귀는 실행 중이다.
