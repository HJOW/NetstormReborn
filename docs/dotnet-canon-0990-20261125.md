## 변경과 원문 대응

- `GumpButtonTree.RegisterChatAlert`: 채팅 알림 버튼의 실제 등록 ID를 같은 칸(`ChatAlertId`, 원문 0x5ca92c BSS0)에 쓴다. 범위·빈 칸·비버튼을 거부하고 serial 검색으로 바꾸지 않는다. receive 경로(`HostChatReceive.Wake` → `PulseRegisteredIfIdle`)가 읽는 같은 칸이며, 실제 호출은 인게임 HUD 생성(R5)에서 잇는다. 0.990에서 추가됐다.
- `HostMenuInput.TryShowTell`: 버전 차이 Tell을 실제 HTML 공장에 알린다. `Blank`는 닫고 참을 돌려주고, 있는 섹션은 열고 참을, 없는 섹션(`MetaVerDiff` 등)은 거짓만 돌려주고 예외로 꾸미지 않는다. 원문 `ShowMetaTell`의 "없으면 진단 로그만 남긴다"와 같은 순서다. 0.990에서 추가됐다.
- `ClientHostGame`의 0x0f·0x1d 버전 확인 갈래: 호출자 Tell을 실제 메뉴 HTML 공장에 묶었다(`TryShowTell`이 거짓이면 `ErrorLog`에 원문 0x1d 진단을 남긴다). 종전 `null`은 받는 즉시 명시 실패였다. 메뉴가 없으면 현재 UI 없음을 명시 실패한다. Run은 세션 State 부모가 없어 후속으로 남는다. 0.990에서 추가됐다.
