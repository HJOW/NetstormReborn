# 실제 Client Factory 메뉴 작성

WB04-E1077은 같은 실제 Session의 Factory 생산·지식·업그레이드 항목과 Client 메뉴 작성기·번역·정적 도움말 토큰·공통 객체 메뉴를 결합한다. 실제 자연 완공 워크샾을 사용한 검사에서 썬 디스크 발사기 연구 명령, 도움말 토큰, 기본 메뉴 호출을 확인했다. 이 검사의 메뉴 작성기는 기록용 경계다.

원본 Factory Open 39행과 실제 워크샾 검사를 포함한 Node 22·26 각 6건이 통과했다. 실제 Client Gump 수명·우클릭과 연구 명령의 앱 분배 및 브라우저 검증은 남았다.
