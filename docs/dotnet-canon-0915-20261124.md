# dotnetpj 0.915 — RU-3 배틀 패널 원문 입력 이식

2026-11-24, HJOW-Athlon. RU-3 아홉 번째 묶음이다. BattleInfo 패널의 원문 입력을 같은 노드/전투 옵션과 실제 메뉴·재부착·송신에 연결했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `NativeBattleInfoInput.Handle`은 `cpppj/src/client/NativeBattleInfoInput.cpp`의 `HandleNativeBattleInfo(0047b8f0)`를 이식했다. 같은 실제 노드/전투 기록/메뉴·재부착·송신 장치를 빌리며 선택되지 않은 자식은 요구하지 않고 미연결 장치는 일반 성공으로 꾸미지 않고 명시 실패로 둔다. 메뉴 자식 본문(정렬/옵션/선택/제외/제거)과 네 공장 설치·바깥 UI·NativeRoot/HUD 창 생성·Enter·HUD 작성자·Root reply 저장은 후속 단위에서 잇는다.
- `ApplyMetaBattleDefaults`는 `0047b180` 전체로 설정 쌍 1..21의 현재 값을 원문 순서로 각 writer에 적용한다. 게임 종류 0은 표준 분기 없이 그대로 둔다.
- 관문은 메타맵 켜짐·전투 번호·전투 flag BYTE1을 순서대로 검사하고 playerKnown 관문을 추가하지 않는다. 좌 태그(`54278c`)는 mode2 전체 순환·일반 모드 첫 행 순환·설정 쌍 쓰기·정렬/옵션/제외/제거/단일 옵션 메뉴를 분기하고, 모드 변경(`542b80`)·직접 설정(`542b7c`)·제외 추가/제거(`5429e0`/`5429e4`)는 변경 누적 뒤 전투 변경 잠금이 풀렸을 때만 87BYTE(`0x57`) 송신·재부착한다.
- `result`/`changed` 지역과 `node.Changed` 잠금·`node.Mode` 쓰기·`second-122` 제거 번호·`>>16` 직접 설정 분해를 원문 순서대로 보존한다. 처리하지 않은 입력은 원문대로 0을 반환한다.

- Release 클라이언트 빌드는 오류 0이다. 신규 경고 0이다.
