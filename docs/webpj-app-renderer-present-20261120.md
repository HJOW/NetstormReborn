# 웹 미션 Renderer 합성·표시 경계 (WB04-E983)

앱의 현재 미션 장치를 이용해 원본 순서대로 Renderer 준비, 전체 Screen clip, DIB 잠금과 미션 합성, 잠금 반납, 구름 dirty 정리, Renderer Present, 세계 redraw 요청 해제를 실행한다. 잠긴 DIB는 예외가 나도 반납하며, 합성이나 출력을 실패한 경우 이후 정상 완료 단계로 넘어가지 않는다. 건물 숨김과 시차 분모는 같은 Client의 현재 값을 조회한다.

현재 창 모드는 구름 배경을 사용한다. 구름이 없는 모드에서 필요한 실제 날씨색 장치는 아직 연결되지 않아 해당 경로를 명시적으로 거부한다. UI 수집·HUD, 진단/물 표시, 프레임의 자동 호출과 사용자 입력은 후속 작업이다.

실제 Tutorial1 로그인·화면 크기 변경 후 전체 갱신 요청을 합성해 앱 색 번호 표면으로 출력하고 Renderer 변경 표와 redraw 요청 소비를 검사했다. 원본 앞단 720행, 구름 695행과 Renderer 표시 관측을 포함한 연관 Node 검사 55건이 통과했다. E978 고정 Node 26 전체 회귀가 실행 중이며 완료 후 E982 고정 Node 22 전체 회귀를 순차 실행한다.
