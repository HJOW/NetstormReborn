# 도움말의 실제 Session TYPE

WB04-E1051은 전용 도움말에 현재 Session의 TYPE 원소·플래그·비용, 실제 무기 사거리와 초당 피해, 같은 AST의 클래스 및 AI·건설에서 공유하는 요구 에너지 후처리 값을 제공한다. 조회 시 살아 있는 현재 표를 읽고 설치되지 않았거나 유효하지 않은 TYPE 및 원본 클래스 범위 초과를 거부한다. 체력은 Session의 기존 typeHitPoints를 사용한다.

실제 Tutorial1의 다리 TYPE과 Session 체력 장치를 조회하고 타입 범위를 검사했다. 요구 에너지 원본 관측과 체력·도움말 정보 검사를 포함하는 Node 26 관련 29건이 통과했다. 현재 TYPE 정보의 창 패널과 브라우저 출력 연결은 후속이다.
