# 1.163 현재 도움말 문구 캐시

`ClientHelpWord`의 원본 NULL·빈 설정 유지, ASCII 대소문자 무시 동일 표기 보존, 다른 문구 교체 규칙을 같은 장기 `ClientLocalStateGlobals`에 연결했다. 게임 시작 시 실제 `helpWord` 설정을 표시 바이트로 한 번 변환해 해석한다. 그 이후 전체 옵션 재해석 경로와 생산 정보 메뉴 소비는 아직 연결하지 않았다.

한국어 설정의 표시 바이트, 기존 장기 상태 및 시작 메뉴를 포함한 집중33/33과 `cpp_sync.py`가 통과했다. 앞서 이식한 객체 정보 본체와 공통 서식, 이번 캐시의 cpppj 대응 세 쌍을 포트 맵에 등록했다. 공통 서식은 `RawPlayerMenu.cpp`의 서식 함수만 이식한 것이며 전체 Player 메뉴 완료를 뜻하지 않는다.

캠페인1-1 고정 입력 다섯 프레임은 1.148과 같고 종료0, 튜토리얼1·surrounded 진입/대기도 종료0이며 90프레임 월드 덤프가 1.147과 같다. 두 수집 모두 원본 1,392파일은 불변이다. 결과는 `extracted/dotnet-helpword-1163-first/`와 `extracted/dotnet-helpword-1163-missions/`에 있다. 1.161 정기 회귀는 이 변경을 포함하지 않는다.
