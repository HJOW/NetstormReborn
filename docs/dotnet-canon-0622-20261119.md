# 0.622 사원 Pop 파생 연결과 L2 3경로 재측정 (R4-2 잔여)

- 일시: 2026-11-19, HJOW-Athlon
- 범위: R4-2 지역 소유자 확정의 사원 Pop 파생. 전용 자산 본체(`RawAssetPostPop`)를 세션 지형 분배에 연결하고 사원 Pop을 열었다. L1 9건과 L2 3경로 재수집으로 확인한다.
- 목표: 0.621에서 막힌 섬 소유자·Player 첫 지역(`+0x78`) 전파를 Pop 성공 뒤 실제 좌표 분배로 동작시키고 소유자 일치율을 확인한다.

## 원인

- 0.621까지 사원은 `TryPopFortTerrain`의 전용 파생 관문에 걸려 Pop되지 않았다(슬롯 void 유지·`FortPopSkips` 기록). 가상 Owner 분배는 연결됐으나 관문(`slot[11]&4`·`extra&9`)이 열리지 않아 섬·첫 지역이 그대로였다.
- cpp 근거는 `RawCampaignAssetBindings.cpp` 149~164행의 PostHooks 조립·181행의 `SetAssetPostPop` 등록과 `RawAssetPostPop.cpp` 91행의 Pop 내 SetOwner 분배다.

## 수정

- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`
  - `BuildRegionOwnershipDevices`의 별도·신전 목록을 세션 공유 목록(`SidLists.Outposts` 100칸·`SidLists.Temples` 20칸)으로 바꿨다. 근거: cpppj `o/RawAssetPostPop.h` 55·59행의 `Temples()`·`Outposts()`와 005e1898·0055a708 헤더다. 기존 독립 목록은 용량 0이라 투표가 항상 공집합이었다.
  - `BuildRegionVortexPostPopDevices`를 추가하고 같은 메서드 끝에서 불렀다. 운반체 본체(`RawCarrierPostPop`, 세션 `TerrainPostPop`·공유 권한/로딩/간헐천 상자)와 자산 본체(`RawAssetPostPop`, `SetAssetPostPop` 등록)를 조립했다. 근거: cpppj `RawCampaignSession.cpp` 1268~1269행과 1610행이다.
  - 자산 갈고리 12종을 세션 실제 장치에 연결했다. 소유자 지정은 가상 Owner 분배(`SetFortObjectOwner`), 섬 조회·존재·사원·등록은 지형 바인딩 섬 런타임, 지역 번호는 청크 지도(`World.At(x/16, y/16)`), 타입 DWORD 0x130·0x134은 프레임표 `Run('A'·'B')` 첫 번호, 충격음은 계수만 세고(R6 음향에서 실제 재생) 생산 갱신은 세션 공용 계수에 합쳤다. 도달 불가 갈고리(지면 소유자·스윕 삭제·내용물 조회/생성)는 명시 예외로 두었다. 근거: cpppj `RawCampaignAssetBindings.cpp` 151~164행이다.
  - `TryPopFortTerrain`에 사원 분기를 두었다. 전용 자산 본체가 연결된 신전 종류는 지형 분배 Pop으로 등록하며 다른 전용 파생은 R6 본체를 기다린다. 적재 갈고리의 신전 판정과 같은 `IsRegionTempleType`을 공유한다.
  - `SetWorldLoadingDepth`에서 자산 상태의 로딩 깊이를 함께 동기화했다. 적재 중에는 내용물 갈고리를 건너뛴다.
  - `RegionAdditional`·`RegionVortexPostPop`·`RegionVortexSoundRequests`를 노출하고 `TempleTypeDword`를 두었다.
- `dotnetpj/src/Netstorm.Client/Host/HostSession.PriestWorld.cs`: `SetWorldLoadingDepth`에 자산 상태 동기화를 이었다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionRegionOwnershipTests.cs`: 공유 목록 동일성·개수·미연결 거부를 확인한다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionRegionVortexTests.cs`: 자산 본체 연결·신전 판정·공유 목록·충격음 계수를 확인한다. 합성 장면은 지형을 생성하지 않아 Pop 자체는 실제 Generate 덤프로 대조한다.
