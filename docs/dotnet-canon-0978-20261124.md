# dotnetpj 0.978 — Build에 참가자 추가 0x20·참가자 이동 0x22 수신기 연결

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 같은 장기 기본 표를 공유하는 `ClientPacketDispatch.Build`/`InstallDefaults`에 원문 앱 전역 0x20 참가자 추가·0x22 참가자 이동 수신기를 연결했다. 0x88·0x67 Build 연결과 제품 기존 경로는 바꾸지 않는다. 세션·메뉴 결합 후크 중 0x23·0x24·0x25(전투 생성·제거 본체·항해 오류의 NSInfo·생성·리그·번역·Chat·표시·음향 장치 필요)와 Root Source 공개·제출 갈래, RU-3 나머지·R4-4 정기 두 단위는 후속에서 잇는다.

## 변경과 원문 대응

- 0x20 후크는 실제 장기 장치를 공유한다. CS·모드·구독자·예약·Core·Player·메타맵·진단은 실제 owner이며, 생성·전투·좌석·Chat·표시·NSInfo만 후속으로 명시 실패한다. 모드 거짓이면 조용히 돌아가고, 무효·유효 기록 모두 생성 앞에서 멈춘다. 새로 만든 본체가 없다. 0.978에서 추가됐다.
- 0x22 후크는 실제 장기 장치를 공유한다. CS·모드·구독자·known·소유자·검사·진단은 실제 owner이며(cpppj 확인: 소유자는 battleOwner, known은 playerKnown), 슬롯 효과·음향·Chat·표시·장부·이름표는 후속으로 명시 실패한다. 모드 거짓이면 조용히 돌아가고, 범위 밖 번호·소유자는 실제 범위를 거부하며, 최소 이동은 참가자 표시 앞에서 멈춘다. 새로 만든 본체가 없다. 0.978에서 추가됐다.
- 수송 팩토리(`ClientCampaignTransport.Make`)는 같은 `InstallDefaults`를 공유하므로 두 항목을 자동으로 공유한다.
