# WB04-E932: 브라우저 조합 확정 사건

Canvas에서 원본 입력을 활성화한 동안 조합 시작·종료 사건을 받는다. 조합 중에는 일반 가상 키·문자 큐 예약과 기존 Enter 등 메뉴 처리를 건너뛰고, 확정된 문자열만 같은 Client 입력 큐에 원자적으로 예약한다. 빈 취소는 무시하고 포커스 상실 시 조합 상태를 비운다. 미지원 문자나 큐 공간 부족은 부분 입력 없이 공통 오류 경계에 보고한다.

앱 상태를 사용한 조합 시작·중간 Enter·한글 확정·중복 종료·포커스 상실과 편집 버퍼 관련 Node 검사 14건이 통과했다. 첫 Chromium 검사는 일반 Event에 data를 기대해 실패했으며, 실제 `CompositionEvent` 객체로 교정한 합성 사건 검사 1건이 통과했다.

이 단계는 Canvas에 도착한 조합 사건의 전달 경계다. Canvas 자체가 OS IME를 활성화하는 편집 가능한 요소는 아니므로 실제 한글 입력기와 편집 요소·포커스 연결 및 실제 사용자 조합 검증은 아직 남았다. 원본 미션 입력 소비자 설치 전에는 이 경로도 비활성이다.
