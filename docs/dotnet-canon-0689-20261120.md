## 본체

`cpppj/src/o/RawPacketCopy.cpp/.h`를 같은 `Netstorm.Net` 모듈로 옮겼다. `RawPacketCopy.Duplicate`는 NULL 입력 조기 반환, 현재 타입 observer의 값 snapshot/pin, 방향1 통지, 변경된 현재 길이WORD 재조회, 자동할당 또는 signed 용량 거부, 낮은 주소부터DWORD 뒤 나머지BYTE 복사를 수행한다. 중첩 배열을 `memmove`로 바꾸지 않으며 각 실제 접근 위치의 물리 오류 앞에 이미 완료한 효과/바이트를 보존한다.

NULL 목적지와 길이0 할당을 `Present`/nullable 메모리/실제 배열로 구별한다. 외부 목적지는 같은 `Memory<byte>`를 반환한다. nullable 분기 입력에는 `(Memory<byte>?)null`을 명시해 빈 `Memory<byte>`와 구별한다. 최초 검사에서 이 조건식의 null 변환을 바로잡았으며 제품 기대값이나 원본 관측은 변경하지 않았다.

`RawPacketCopies`는 같은 완성 배열을 소유하고 단조DWORD token을 발급한다. NULL0, 실제 배열 인계, 같은 배열 대여, 반납 뒤 기존 대여의 유효성, 중복 반납 거부와 token 비재사용을 유지한다. 포인터 절삭이나 미션별 가짜 패킷은 없다.
