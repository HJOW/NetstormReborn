# 1.156 생산 커서 취득·취소 결선

생산 패널의 취득·취소를 현재 세션의 실제 `RawCursorLifecycle`에 연결했다. 호출 중 Runtime을 보유하고, 원문처럼 완전 적재 또는 Editor 후반 설치 관문을 먼저 검사한다. 내용물 동기화의 커서 취소에도 같은 세션 커서를 연결했다. 커서 장치가 설치되지 않은 경우 실제 호출 위치에서 오류를 유지한다.

부분 적재의 취득·취소 거부와 검사 장면에서만 적재 관문을 연 실제 취득 및 배치 조회, 기존 Esc 취소·생산 유지·패널 집중10/10이 통과했다. 제품 전체 적재, 실제 커서 장치 설치, 생산 칸 사용자 입력은 검증되지 않았다.

캠페인1-1 고정 입력 다섯 프레임은 1.148과 같고 종료0, 튜토리얼1·surrounded 진입/대기 역시 종료0이며 90프레임 덤프가 1.147과 같다. 두 수집의 원본 1,392파일은 불변이다. 산출물은 `extracted/dotnet-production-1156-first/`와 `extracted/dotnet-production-1156-missions/`다. 1.153 전체 회귀는 이 변경을 포함하지 않는다.
