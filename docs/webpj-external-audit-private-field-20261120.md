# 외부 접속 감사 오탐 교정

WB04-E1078은 E1072 고정 Node 26 전체 회귀 6,582건 중 유일한 실패를 확인했다. 클래스 비공개 `#opener.open`은 실제 객체 메뉴를 여는 내부 호출인데 기존 정규식이 전역 `opener.open`으로 잘못 판정했다. `#` 바로 뒤의 식별자만 제외하고 `window.opener.open` 등 실제 브라우저 열기 검사는 유지한다.

위반·정상 예시와 전체 소스·자산·외부 서비스 검사 Node 22·26 각 5건이 통과했다. 최초 교정 명령은 잘못된 작업 디렉토리의 경로를 사용해 실패했으며 올바른 위치에서 수정하고 재검사했다. 수정된 상태의 전체 회귀는 다시 필요하다.
