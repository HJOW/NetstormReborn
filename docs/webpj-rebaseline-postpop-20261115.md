# 객체 후처리 기본 분배 재반영

WB04-E508은 `SquidPostPop`의 기존 판정 기준 `b1bf342d`와 후보 `225553df`를 비교해 **② 웹 반영 필요**로 판정했다. 장기 Client 기본 장치가 연결돼 있고 현재 객체에 전용 파생 처리기가 없을 때, 가상 표 `0x502c38`, `0x502cf0`, `0x502db0`, `0x507770`도 실제 장기 자원 후처리로 분배한다.

기본 장치가 없으면 기존 경로를 유지하고, 전용 처리기가 있으면 그 처리기가 우선한다. 장기 자원 후처리가 필요한데 연결되지 않았으면 해당 위치에서 오류를 낸다. 기존 계약 검사에 네 표의 선택·미연결 오류와 Dude·보호막 전용 처리기 우선순위를 더해 7건 모두 통과했다.

이 변경은 분배 표만 보완한다. 자원 후처리와 AI 통지의 실제 장기 몸체, World·Session 등록은 4-D에 여전히 남으며 `SquidPostPop`의 대응표 상태도 partial로 유지한다.
