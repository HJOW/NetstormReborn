# WB04-E926: 원본형 편집기의 확정 한글

기존 원본형 `TextEntryGump`는 바이트 버퍼를 소유한다. 이전에 웹 전체가 UTF-16이므로 확장 토큰 처리가 불필요하다고 한 판정은 이 저수준 경계에는 맞지 않아 정정했다. E924/E925의 확정 문자와 문자 경계를 사용해 실제 큐 사건에서 네 바이트 한글을 삽입하고, 토큰 중간의 외부 선택·Shift 기준을 안전한 경계로 보정한다. 왼쪽/오른쪽·Shift 선택·Backspace/Delete는 확장 문자를 한 단위로 다룬다. 확장 입력은 선택 길이를 제외한 실제 바이트 수와 제외문자 0x1f를 검사한다. 순수 원본 바이트에는 기존 길이·이동 규칙을 유지한다.

실제 원본형 편집 버퍼에 큐를 통해 영어와 한글을 입력하고 이동·선택·대체·삭제, 토큰 내부 선택, 최대 길이와 제외문자를 확인했다. 기존 원본 10.78 편집기 관측 2,292행을 포함한 연관 Node 검사 27건이 통과했다.

붙여넣기의 확장 토큰과 바이트 한도, 실제 글꼴 측정·출력 및 브라우저 IME, 실제 미션 UI 연결은 남았다. 대응표의 TextEntryGump는 이 미완료 경계를 반영해 partial로 정정했다.
