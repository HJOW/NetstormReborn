# WB04-E805 Client 선택 정리

cpppj 기준선 `225553df`의 `ClientUserSelectionCleanup` 중 실제 Gameplay·표면 소유자를 받는 경계를 이식했다. 같은 선택 전역을 `RawUserSelection.clear`와 `RawUserHighlight`에 빌리고, 객체 통지 또는 갱신에 도달한 경우에만 현재 Session을 조회해 풀 동일성을 확인한다. 표시 갱신과 선택 비트는 기존 실제 구현을 사용한다. 기준선 이후 해당 cpppj 파일 변경은 없다.

실제 표면을 사용해 Session 없는 첫 메뉴의 음수 다중 개수 정리와 비활성 선택 보존, 커서 장치의 후반 실패가 앞선 변경을 보존하는 것을 확인했다. TheWarBegins Session에서는 실제 객체의 다중 선택 비트·선택 전역·커서 해제를 확인했고, 다른 풀을 전달하면 객체 효과 전에 거부되는 것을 확인했다. 최초 시험에서 읽기 전용 슬롯 사본에 값을 써서 비트가 바뀌지 않았고 실제 할당 슬롯을 사용하도록 고쳐 통과했다. Client 소유자 overload 및 실제 State 수명 연결은 후속 4D-5b다.

검증: 실제 Session 집중 검사 통과, 대응표 1,160행 오류 0, Node v26.13.0 전체 6,297건 통과(실패·취소·건너뜀 0). E803 Node v22 전체 검사 뒤 v26 회귀 2/8회다.
