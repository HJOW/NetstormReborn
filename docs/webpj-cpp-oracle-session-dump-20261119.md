# WB04-E868 cpppj 오라클 Session 덤프 수집

`tools/cpp-oracle.mjs`는 시나리오의 `session-dump` 단계를 임시 TSV 경로로 변환하고 파일 원문과 SHA-256을 수집한다. 공통 또는 개별 시나리오의 `fixedFrameMs`와 선택적 `fixedUnixSeconds`는 cpppj 고정 시각 인자로 전달한다. 수집 입력 해시에도 이 값을 포함하되 값이 없는 기존 M1 시나리오의 해시는 유지한다. 캡처 이름 검증과 성공·실패 시 임시 폴더 정리도 적용했다.

가짜 실행기 집중 검사에서 옵션·단계표·덤프 원문·오류·정리를 확인했고 기존 기준선 오라클 메타 검사도 통과했다. 첫 전체 회귀에서는 fixture 추적 정규식이 테스트 코드의 속성 접근을 TSV 파일명으로 오인해 1건 실패했다. 같은 속성의 대괄호 접근으로 바로잡은 뒤 Node v26.13.0 전체 회귀 6,408건이 실패·취소·건너뜀 없이 통과했다. AGENTS.md 예외 호스트 HJOW-Athlon에서 기준선 `225553df`의 cpppj 실행 파일을 실제 실행해 고정 25ms, 20프레임의 판번호 1 `world 0` 덤프를 수집했다. 이 관측은 빈 월드 확인이며 Tutorial1 Load/Start 덤프나 웹과의 비교는 아니다.

브라우저 Client의 실제 Session 덤프 호출과 Tutorial1의 고정 시각 시나리오·L2 대조는 남아 있다.
