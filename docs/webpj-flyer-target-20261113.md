# webpj 비행체 표적 검색 RawFlyerTarget (WB04-E356, 2026-11-13, 7-P1 비행 유닛 부품)

3.1절 7-P1 다섯째 항목 "RawFlyerTarget 194줄"(기준선 `.h` 50 + `.cpp` 142 = 192줄 근처, 대응표 줄 수 194)을 `core/raw-flyer-target.js` 로 옮겼다. 맨 오 워(144)·훨리기그(73)가 표적을 정하는 **표적 검색**(0045c4b0)과 표적 경쟁에 쓰는 **가까운 비행체 수**(0045b840)·**자리 수**(0045b9c0)·**자리 번호**(0045ba10)·**포위 위치**(0045bb80)를 담는다. 의존 finder 커서(반환 전 다음 Form 을 저장하는 순회)를 같은 풀에서 직접 실행하고, 일반 finder·발사 가능·감시 조회·복귀 지연·명령은 훅이다. E352 의 `FlyerProcessFields`(112바이트)와 E355 의 `RawFlyerFrame.checkForms`(종속 검사 시험 장면)를 그대로 쓴다.

## 1. 규칙

- **구성:** `new RawFlyerTarget(pool, types, ranges, globals, hooks)` — 풀은 PATCH, TYPE 표(`{ footX, footY, flags2 }`)는 188칸의 **살아 있는 참조**(원문 span 이라 호출 사이에 바뀐 값을 읽는다), 사거리 표(TYPE+44, float)는 188칸 **만들 때 사본**이다. 전역 여섯 개(`server`·`checking`·`now`·`sunType`·`processEnd`·`dependType`)는 현재 값을 읽는 함수이고, 훅은 `assertion`·`checkForms`·`offset`·`begin`·`next`·`mayTarget`·`watcher`·`processParent`·`returnDelay`·`command` 이다. 선택하지 않은 경계는 요구하지 않고 선택된 누락은 앞선 쓰기를 남긴 채 거부한다.
- **`find(fields)` (0045c4b0):** 서버가 아니면 진단 0x3af, 부모의 종속 head 가 비면 0xa4(Parent getter), 종속 검사가 거짓이면 0x3b7. 출발점은 부모 중심에서 이동 보정(`offset`)을 뺀 값이며, 부모 +42/+46 이 **둘 다 0 일 때만** 출발점을 signed64 절삭(하위 DWORD)해 거기에 저장하고 한 축만 0 이면 저장된 정수를 그대로 쓴다(float 로 바꿔 사용). 표적이 이미 있으면 0x3d5 뒤 dirty |= 4·표적 0. 검색 사각형은 출발점으로 시작해 `출발점 ± 사거리`를 1..255 로 자른 뒤 확장하고(기존 꼭짓점이 0/256 경계·NaN 으로 유효하지 않으면 추가 점으로 교체), 오른쪽/아래는 float 0.99999 를 더한 뒤 정수 절삭한다. 후보마다: 발사 가능(현재 부모)·TYPE flags2 0x120000·홈·(훨리기그 부모의 flags2 0x210000) 필터 → 자리(가까운 비행체 수 < 자리 수) → 사거리(float delta 합성) → 엄격한 최소 거리(먼저 나온 동률 유지, 이후 후보는 `distance < best && distance < range`)로 마지막 통과자를 표적으로 쓴다. 부모가 훨리기그이고 귀환 기한이 0 이면 복귀 지연을 받아 `지연 + now`를 기한으로 쓰고 **효과 뒤 현재 부모**에게 명령 2 를 낸다. 마지막은 종속 검사 0x413.
- **`closerCount(target, flyer)` (0045b840):** 표적/비행체가 0 이거나 둘 중 하나가 free/dead(상태 비트 3)이면 0. 표적 중심에서 이 비행체까지 거리(float 로 저장)보다 더 가까운 **다른** 비행체(TYPE flags2 0x100000)의 의존 Form 수. 의존 목록은 부모 head 부터 `next` 를 반환 전에 저장하며, TYPE 69 이하이고 의존 TYPE 전역과 같은 Form 만 돌려주고(후보마다 전역을 다시 읽음) 손상된 순환/범위 밖 next 는 풀 크기로 거부한다. 감시 Form 의 프로세스 TYPE 은 [10, 상한)만 센다.
- **`capacity` / `slotIndex` / `scatter`:** 자리는 죽지 않은 1×1 발자국 표적 1칸, 그 밖 3칸(표적 0 이면 3). 자리 번호는 자기 감시 Form(첫 일치)을 찾고(없으면 checking 일 때 0x374, 0) 다시 돌며 flags2 0x100000 인 비행체 중 **더 작은 Form 번호**의 수(부모 head 가 비면 0xa4). 포위는 자리 1 이면 (0, 0), 아니면 [(0, −1), (−1, 1), (1, 1)] 중 자리 번호.

## 2. 웹 범위와 기준선 뒤 변경

- 10.72(CD)는 범위 밖이다(PATCH 188칸 TYPE 만 받는다). 기준선 뒤 `20261103-192 CP`(공유 checking 과 SID Form 진단 부모)의 변경을 반영했다(PORT_MAP base `8b467ca0`).
- C++ `std::min/max` 는 비교 방향대로 옮겼고, 정수 절삭은 `signed64` 절삭 뒤 하위 DWORD 이며 비유한·범위 밖은 거부한다. 표 밖 TYPE 번호는 거부한다.
- 훅 구현(일반 finder·발사 가능 문맥·감시 조회·복귀 지연·명령 등)은 후속 7-P1 단위와 4-D/6 단계 조립 몫이다. 이 모듈은 DOM 을 쓰지 않는다.

## 4. 변형 확인과 남은 경계

- 한 문자열 치환 변형 216회를 적용했다. 1차에서 80개가 남았고 그중 59개는 **시험의 공백**이라 보강해 잡았다. 원본 관측 1,302행이 쓰는 입력이 좁아(출발점 다섯 가지·발자국 2·SID 100 미만 체인·진단 꺼짐·같은 배치의 후보) 위의 웹 계약 항목들이 가려져 있었다. float 저장 단계는 값이 가려지기 쉬워 탐색으로 입력을 구성했다: 최소 거리 기준과 비교 기준 거리는 두 축을 쓰는 후보의 거리 d2 가 d1 과 float 로 줄인 값 사이에 들어가는 격자 위치를, 출발점은 이동 보정 0.5000001 로 39.9999999 → 40 이 되는 위치를, 포함 점은 float 반올림이 정수 경계를 넘기는 사거리를 골랐다.
- 남은 동등 변형 21개: `RIGHT_BIAS` 를 배정도 0.99999 로 바꾼 것(오른쪽/아래 경계는 항상 1 이상의 float 이고 1 이상 float 중에는 두 상수가 서로 다른 정수로 절삭되는 값이 없다)·`truncate` 의 int32 환산/`asUintN` 두 변형(저장은 하위 바이트만 쓰고 사각형 값은 1..255 로 잘려 같은 비트이다)·`stdMin`/`stdMax` 의 `Math.min/max` 와 동률 방향 바꾼 네 변형(NaN 이 끼어드는 경로가 없고 동률이면 같은 값)·`clamp` 의 `>= 1` 을 `> 1` 로(1 에서 같은 값)·의존 커서의 `steps >= 풀 크기`(서로 다른 노드 수는 풀 크기 미만)·`#center` 의 반올림 생략(발자국이 `int32` 라 `위치 − 정수/2` 는 float 로 정확)·저장 정수 출발점 x 의 반올림 생략(24비트 이내 정수는 정확하고 그보다 큰 출발점은 유효하지 않아 1..255 로 잘림)·`best` 초기값 두 변형(어느 쪽이든 `distance < range` 검사가 더 좁다)·사거리 첫 검사의 float delta 세 변형과 `<=`·한 축 생략 두 변형, 그리고 `measured <= range`·`measured < range` 생략 두 변형(float delta 로 계산하는 첫 검사와 double 거리로 계산하는 둘째 검사가 같은 경계를 겹쳐 확인한다; 두 값이 갈리는 것은 큰 좌표 차이의 float 반올림 경계뿐이다)·후보 선택 때의 `dirty |= 4`(검색 시작에서 이미 켠 비트)이다.

- 변형하지 않은 방어선: 생성자·훅 누락·범위 오류 메시지 문구.
- 앱 수명 연결(실제 일반 finder·발사 가능 문맥·감시 조회·복귀 지연·명령 훅 구현)은 후속 7-P1 단위와 4-D/6 단계 조립 몫이다. 다음 7-P1 항목은 **RawSunFlyerFrame**(184줄)이다.
