# 0.618 지역 칠하기·소유권 이식과 L1 전수 재생 (R4-2 잔여)

- 일시: 2026-11-18, HJOW-Athlon
- 범위: R4-2 잔여 `RawRegionPaint`·`RawRegionOwnership` 이식과 cpp fixture 전수 재생. 세션 Generate 연결은 R4-6·R6 트리거(공장·신전 경로)와 함께 잇는다.
- 목표: 0.617에서 확정한 소유자 격차(DN 전 셀 0 대 cpp 서쪽 1·동쪽 2)와 프레임 island-기준점(244·280 대 DN 172)의 메커니즘인 지역 투표·도장을 DN에 이식하고 L1으로 고정한다.

## 원인

- 0.617 분석 결과 cpp 지면 프레임·소유자는 `Generate` 뒤 지역 투표·도장(`UpdateRegion`→`Vote`→`Paint`→`Flood`+경계 도장)이 덮어쓴 값이다. DN에는 해당 모듈이 없어 stamp 프레임·소유자 0이 그대로 남는다.
- 결정적 증거: paint J-공식이 `JFirst+1+theme*36+...`이며 cpp 섬별 기준점 244·280은 테마 2·3 (`172+72`, `172+108`) 과 일치한다. 테마는 같은 소유자의 마지막 신전 종류에서 정해진다(`kind` 0→2, 1→3, 2→1).
- cpp 테스트에 `regionpaint-x86.tsv`(386+98행)·`regionownership-x86.tsv`(3×440행) oracle이 있어 같은 방식으로 L1 전수 재생한다.
