# 브라우저 사제 건설 메뉴

WB04-E1072는 앱의 빈 커서 우클릭도 실제 사용자 입력에 전달하고, 현재 사제 VT에서 원본 선택·정보·건설·운반체·객체/Player 메뉴를 열도록 연결한다. 메뉴 작성기는 기존 생산 정보 메뉴와 같은 Client Gump·Form 수명을 공유한다. 건설 선택 명령은 같은 Session의 미리보기를 만든다.

실제 Chromium 한국어 Tutorial2에서 사제를 오른쪽 클릭하고 건설 → 신전 → 윈드 신전 세 메뉴 행을 마우스로 선택해 TYPE 123 미리보기와 비용 플래그를 확인했다. 사제 메뉴 캡처를 직접 확인했으며 한국어 Tutorial1·2 Chromium 2건 및 관련 Node 22·26 각 20건이 통과했다. 기존 전체 미션 진입 Chromium은 21건 통과했고 1건은 다른 동시 검사가 같은 출력 경로를 지워 추적 저장에서 실패했다. 그 미션은 별도 출력 경로로 재실행해 통과했다.

첫 브라우저 시도에서 우클릭이 처리되지 않았다. 사제를 실제로 집는 좌표와 입력 상태를 확인해, 빈 커서의 lockDepth가 1인데 이전 프레임 분배가 0일 때만 우클릭을 전달하던 조건을 수정했다. 실제 배치·완공과 나머지 객체 VT·제단 위임, Player 주소/채팅 입력, Cast/Drop 및 정적 Tell 명령은 아직 연결·검증이 필요하다.
