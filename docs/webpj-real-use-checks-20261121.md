# 건설·이동·회수 실사용 점검과 e2e 고정 (WB04-E1139)

E1135~E1138 에서 실제 마우스 조작으로 점검하면 이전 시험이 놓친 결함이 나왔다. 같은 방식으로 건설·이동·회수 흐름을 확인하고 시험으로 고정했다. 이번에는 새 결함 없이 모두 정상이었다.

## 확인한 흐름

| 흐름 | 미션 | 결과 |
| --- | --- | --- |
| HUD 다리 조각 집기 → 지도 위 미리보기 → 유효한 자리에서 클릭 | The War Begins! | 조각을 쥐면 미리보기가 마우스를 따르고(화면 원점이 카메라 원점과 같음), 클릭하면 내 다리 조각 5개가 놓인다. |
| 사제 선택(좌클릭) → 땅 위 이동 커서 → 땅 클릭 | The War Begins! | 선택이 되고 커서 번호 18(이동)이 되며 사제가 클릭 쪽으로 걸어 멈춘다(약 3초에 6칸). |
| 제단 우클릭 → 회수(Salvage) 행 클릭 | The War Begins! | 제단과 받침이 모두 사라진다. |

## 시험

- `e2e/mission-build-placement.spec.js`: 다리 조각 집기·놓기 시험 추가, 제단 시험 끝에 회수 확인 추가. 다리 조각 시험은 E1135 의 카메라 원점 연결을 되돌리면 `다리 조각 화면 원점` 비교에서 실패한다.
- `e2e/mission-priest-move.spec.js`: 사제 선택·이동 시험.

## 확인하지 못한 것

- 다리 조각을 놓은 뒤 HUD 의 다음 조각 보충, 비용 차감은 화면으로만 보았고 단정하지 않았다.
- 회수 뒤 Storm Power 환급 수치는 확인하지 않았다(`Salvage gains 125` 항목의 값만 표시 확인).
- 운반체(Bulf)가 크리스털을 줍고 내려놓는 흐름은 점검하지 않았다.
