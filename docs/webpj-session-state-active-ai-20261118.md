# WB04-E787 실제 AI State 정리 검증

E783의 Session AI 정리·반납 경로를 실제 AI 할당에 적용했다. TheWarBegins Session에서 Player 2의 AI 본체를 만들고 같은 메모리 블록과 Player brain 포인터를 확인했다. AI 행동 프레임을 실행하지 않은 채 State 정리를 호출해 Player brain이 0이 되고 실제 AI 블록이 해제되는 것, 정상 복귀 증빙 소비와 재정리 거부를 확인했다.

게임 코드는 바꾸지 않았다. 적 공격·사제 포획/희생·승리·자연 완주나 세 공중 유닛의 전용 행동은 실행하지 않았다. 실제 Client State 전체 정리와 앱 종료는 남는다.

Node v26.13.0과 v22.23.3 전체 회귀를 순차 실행해 각각 6,290건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 오류는 0건이며 다음 Node v22 검사까지 v26 회귀는 0/8회다.
