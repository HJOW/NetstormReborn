# Session Login 전송 앞단과 Zone (WB04-E703)

`RawCampaignSessionLogin.inc`의 현재 Login 생성자 앞단·`Device`·`InstallZone`을 부분 이식했다. 실제 Player 초기화 뒤 미션 옵션을 필요할 때만 원문 순서로 초기화하고, 같은 Player 기록과 권한을 빌리는 내부 미션 전송 또는 동일 등록표를 가진 외부 전송을 준비한다. 생성만으로 접속하지 않는다. Zone은 같은 서버/boss 권한, 현재 Player와 Core 슬롯, 장기 Zone/연결 활동/기한에 쓰며 실제 이름 정리기가 Player 원문을 직접 수정한다. 이를 위해 기존 Zone 함수는 호출자에게 같은 이름 저장소 보기와 기존 문자열을 함께 건넨다.

실제 Session owner와 원본 Zone을 쓰는 집중 검사 4건 및 기존 관련 검사를 합쳐 24건이 통과했다. 내부 전송은 실제 로그인 수신기를 먼저 등록해야 서버를 열 수 있다. 최초 검사는 이를 놓쳐 서버 열기에서 실패했고, 현재 미완료 선행 조건을 명시적으로 확인하도록 교정했다. Zone 설치의 앞선 쓰기는 원문대로 남는다. 빈 이름 대체는 원문의 제한된 문자열 보기 길이도 보존한다. 패킷 수신기·StateHooks·Begin·Pump, 외곽 Session 연결과 실제 접속은 아직 없다. 원격 Fort·일반 LAN, Native 수신기와 스커미시용 일반 시작은 각각 웹 제외 또는 후속 단계로 남는다.

행 기준 `a328ac1f` 이후 변경 32커밋은 아직 전체 판정하지 않아 대응표 기준을 유지한다. 현재 부분은 HEAD의 `cea41eb09` 소스와 대조했으며 나머지 공유 패킷·시계·진단 변경은 4D-3a 조립 시 판정·반영한다. 실제 게임 창이나 플레이, 공중 3종 전용 행동은 실행하지 않았다.
