# WB04-E933: 브라우저 IME 편집 요소

원본 입력 소비자가 활성일 때 실제 문자 편집을 위해 포커스 가능한 textarea를 필요할 때만 생성한다. 요소는 Canvas의 논리 좌표를 현재 화면 좌표로 바꾼 위치에 보이지 않게 배치한다. 키·조합 사건은 기존 Client 큐 경계에 전달하며, 조합 중 입력 값은 유지하고 확정 뒤 요소 버퍼를 비운다. Canvas와 요소 사이의 포커스 이동은 입력 상태를 지우지 않고, 외부 포커스 이동은 기존 취소를 유지한다. 편집 종료 또는 앱 destroy에서는 요소를 제거하고 수명을 정리한다.

Chromium에서 실제 textarea 생성·포커스·좌표 경로, 합성 CompositionEvent를 통한 한글 확정, 실제 영문 키, Canvas 포커스 복원과 destroy 제거를 확인했다. 관련 브라우저 검사 1건과 입력·편집 관련 Node 검사 22건이 통과했다.

이 요소는 실제 미션 TextEntry의 포커스·캐럿과 아직 연결하지 않았다. OS 한글 입력기를 직접 조작해 조합·후보창·포커스를 검증하지는 못했다. 브라우저 붙여넣기와 텍스트 입력 장치의 다른 경로도 남았다.

Node v26.13.0 전체 회귀 6,500건이 실패·취소·건너뜀 없이 통과했다.
