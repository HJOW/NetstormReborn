# dotnetpj 0.919 — RU-3 NSInfo 입력 토큰 분배 이식

2026-11-24, HJOW-Athlon. RU-3 열두 번째 묶음이다. 세 파생 입력의 토큰 분배 뼈대를 같은 소유 순서로 연결했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `NativeNsInfoDispatch.Dispatch`는 `cpppj/src/client/RawMenuControls.cpp`의 `NsHandle` 분배 뼈대(루트→플레이어→배틀→기본)를 이식했다. 소유 저장소 순서대로 파생 처리에 보내고 그 외는 같은 기본 처리에 전달한다. 선택되지 않은 소유 판정·처리기는 요구하지 않고 미연결 장치는 일반 성공으로 꾸미지 않고 명시 실패로 둔다.
- DN의 `HostNsInfoWindows.Bind`가 토큰 소유자에게 기본 처리를 위임하는 구조와 같은 기본 귀결을 공유한다. 후크 합성(정렬표·CS·메뉴·송신·음향)과 생산 결선은 후속 단위에서 잇는다.
- 합성 소유 판정 검증이라 신규 fixture는 없다.

## 검증

- Release 클라이언트 빌드는 오류 0이다. 신규 경고 0이다.
- 신규 3건(소유 순서·기본 귀결·미연결 명시 실패)은 통과/실패 0이다. 루트·플레이어·배틀 라우팅과 미소유 기본 전달이 이웃 75건과 함께 78건 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.916과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0919-*/`의 각 실행 로그와 요약이다.
