# 언어·파일·도움말 재기준선 판정

WB04-E507은 기존 웹 이식분 12단위를 각 행의 base와 후보 `225553df`로 대조했다. 판정 ①은 웹 적응으로 현재 변경이 불필요하다는 뜻이고, ③은 아래 후속 기능이 아직 남았다는 뜻이다. ③은 기준선 전환 후에도 완료로 간주하지 않는다.

| 단위 | 판정 | 근거와 남은 일 |
| --- | --- | --- |
| `BitmapFont` | ③ | 일본어 글꼴의 대표 전각 폭이 추가됐다. 웹 유니코드 글꼴은 현재 한국어용이므로 13차 일본어 글꼴 선택·측정에서 처리한다. |
| `ConfigFileRead`, `KoreanResources` | ③ | cpppj는 공식 한국어 번들을 정확한 기존 파일보다 뒤에 선택하고 일본어 번역·글꼴도 찾는다. 웹은 현재 한국어 파일 12개와 D2Coding을 준비한다. 나머지 공식 미션 자료와 번들 우선순위는 6차, 일본어는 13차에 연결한다. |
| `InputEvent` | ③ | 조합 문자 확정 이벤트를 남은 39칸에 원자적으로 넣는 일괄 입력이 추가됐다. 웹의 실제 입력·6차 언어 입력에서 처리한다. |
| `LanguageOptions` | ③ | 원문 일본어 번호 5는 이미 표에 있으나 확장 글꼴 선택과 브라우저 언어 선택은 한국어·영어만 지원한다. 13차에 연결한다. |
| `ProductPresentation` | ③ | 영어·한국어 Patch Credits와 Copyright 2026 HJOW는 웹에 있다. 일본어 Credits와 난이도·스커미시 관련 구간은 13차·11차·12차에 남는다. |
| `QuickHelpFileRead` | ① | 웹은 준비된 도움말 파일을 현재 언어로 읽고 UTF-8 또는 원본 문자를 직접 해독한다. cpppj의 BOM 자료를 화면 전용 바이트로 바꾸는 경계는 웹 유니코드에 필요하지 않다. 나머지 언어 자료는 위 번들 작업에서 다룬다. |
| `QuickHelpWindow` | ③ | 새 웹 도움말 창은 현재 언어 파일을 다시 읽지만 이미 열린 창은 재사용한다. 동적 언어 전환 구현 때 현재 창·캐시 수명을 확인한다. 창 레이아웃 등 기존 partial 작업도 남는다. |
| `TellFileMenus` | ③ | 긴 제목의 표시 바이트 제한 NB24와 언어 변경 시 소유 목록 파일 재적재가 추가됐다. 10차 버그 및 언어 전환에서 처리한다. |
| `BaseFile` | ③ | 웹은 파일·영어 대체를 별도 계층으로 구현한다. cpppj의 정확한 한국어 번들 선택과 부분 번역 목록 우선순위는 6차·13차에 대조한다. Windows 루트 경로 수정은 웹 경로 정규화가 대체한다. |
| `FileSpecQuery` | ① | 변경은 Windows 드라이브 없는 루트 패턴의 게임 폴더 기준 해석이다. 웹 `GameFiles`는 선행 구분자를 없애 동일한 자산 이름을 조회한다. |
| `OriginalText` | ① | 변경은 화면 전용 일본어 확장 바이트의 정적 구간과 한자 배정이다. 웹은 UTF-16 표시와 원본 파일 문자 해독을 별도로 사용한다. 일본어 글꼴·자료 지원은 위 13차에 남는다. |

웹에는 `help.korean`이 있으므로 도움말 파일이 없다고 적힌 오래된 주석도 바로잡았다. 관련 기존 문자·파일·언어·도움말 검사 48건이 통과했고 전체 회귀 검사에도 포함한다. 실제 미션 연결, 한국어 미션 자료와 일본어 지원은 완료하지 않았다.
