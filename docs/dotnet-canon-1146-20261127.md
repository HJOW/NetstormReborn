# dotnetpj 1.146 — 실제 사제 자산 출력

2026-11-27, HJOW-Athlon. 실제 게임 TYPE·SHP 자료와 같은 `HostSession`에서 사제를 만들고, 해당 풀·프레임·공장·공통 소유자 색표·프로세스 조회를 `SpriteWorldRenderer`에 연결했다. 현재 사제 위치의 1024×768 픽셀 표면에 실제 SHP가 출력되는 것을 확인했다. 합성 이미지의 카메라 변경 검사 및 실제 세션 조회·상태 타이머 누락 검사와 함께 **4/4 통과**했다. Release 빌드 오류 0·기존 경고다.

- 이 검사는 독립 화면 버퍼를 사용하는 단위·통합 검사이며 게임 창 실행이나 원본 픽셀과의 일치 검사는 아니다. `SubmitWorldDrawing`의 kind 0은 여전히 건너뛰며 실제 제품 화면에 설치하지 않았다.
- 실제 다리·메타·상승음과 상태 효과 타이머, 선택 상태의 실제 프로세스/색상, 제품 화면 CPP/원본 비교를 이어서 검증한다. 전체 회귀는 직전 1.140 결과다.
