# dotnetpj 1.087 — 지형 그래프 재결선의 미니맵 대여

2026-11-27, HJOW-Athlon. `WireTerrainPostPopGraph`가 지형 Pop/Unpop을
새로 만들면 같은 세션의 미니맵 추가 대여를 새 쌍으로 옮긴다. 새 쌍의
물리·중복 검사를 먼저 하고 이전 실행기에는 여전히 같은 큐가 있을
때만 이를 반납한다. 미니맵이 먼저 반납됐거나 이전 쌍이 다른 세션으로
바뀌었으면 영향을 주지 않는다. 세션의 미니맵 참조는 약한 참조다.

- 먼저 그래프 재결선 뒤 새 지형 Pop이 큐에 닿지 않는 실패를 재현했다.
  교정 뒤 미니맵 집중 검사 11/11 통과. 이전 실행기의 Pop/Unpop은
  큐에 닿지 않고 새 실행기는 닿으며, 다른 소유자가 바꾼 이전 큐는
  보존한다. 반납된 미니맵에서 재교체 요청은 거짓을 돌려준다.
- Release 의존 프로젝트·검사 빌드 통과, 기존 Core·Client·검사 경고만
  출력됐다. `cpp_sync.py` 종료 0.
- `thewarbegins` CPP/DN 실행 각 종료 0·DN 0998 덤프 바이트 일치·원본
  1,392파일 불변. 기존 CPP/DN 차이로 비교 도구 종료 1이다. 결과
  `extracted/dotnet-l2-1087-terrain-rebind/`.

이는 그래프 재결선 한 경로의 검증이다. `BuildTerrainPopDevices`와
`BuildIslandPostPopDevices`의 별도 재생성, 미션 전환·실패 수명, 실제
게임에서의 변경 관측은 확인하지 않았다. 미니맵 픽셀 388개 차이와
HUD 전체 도킹도 남는다.
