- 일시: 2026-11-20, HJOW-Athlon.
- 근거: `cpppj/src/o/RawFactoryUpgrade.cpp/.h` 전체와 `cpppj/tests/FactoryUpgradeTests.cpp`의 합성 계약이다.
- 범위: 다음 레벨 조회·예측 그림 생성·완료·현재 AI 통지·그림/진행 조회 본체. 실제 가상·건설·음향·표시·전송의 세션 연결은 후속이다.

## 구현

`RawFactoryUpgrade`는 같은 PATCH 풀과 `SquidProcessHost`를 요구한다. 다음 레벨은 상한3과 두 번째 현재 가상 조회를 보존한다. 시작은 실제 그림 생성 → 현재 다음 레벨 → extra8/추상 상태·인자WORD0 → owner → 현재 좌표의 원본 float Y 오프셋 → Pop → 로그 → 건설 → 감시 쌍 순서다.

완료는 아웃포스트를 먼저 생략하고 레벨·최대HP·프레임/표시·위치 소리·현재 로컬 완료 소리·플레어를 실행한다. 같은 실제 호스트의 모든 사건4를 지운 뒤 사건3을 지우고 종속 그림을 정리한다. 그림은 TYPE·extra8·원본 클라이언트 SID 범위만 검사하며 free/dead/owner 조건을 추가하지 않는다. 감시 Form의 next는 반환 전에 저장하고 원래 TYPE 필터와 진단·체인 손상 거부를 보존한다.

`Finish`는 로그 → 완료 → 현재 owner/AI 재조회·통지 → -1 반환이다. 아웃포스트도 후속 AI 통지는 수행한다. `IsUpgrading`은 그림 → 사건4 → 사건3의 단락 순서를 유지한다.
