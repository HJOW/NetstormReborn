# dotnetpj 0.946 — 0x7c 메타 게임 로그인 수신 본체·설치 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 0x7c 메타 게임 로그인의 상태 분기와 0x1f 마스터 알림 본체, 고정 F 설치를 같은 분배기에 연결했다. 0.945의 master 조회 본체를 재사용하고 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientMetaGameLogin.NotifyMaster`는 0x1f 마스터 알림 전체를 이식한다. 현재 자기 CS 기록을 먼저 캡처하고 flags에 0x2000을 더한 뒤 전역 11의 실제 송신만 선택한다. 0.946에서 추가됐다.
- `ClientMetaGameLogin.Receive`는 004b2c00 전체를 이식한다. 상태 0은 master·구독자·전투·자리 4단계를 모두 만족할 때만 수락하고 수락 응답 뒤에만 끊고 재지정하며 서버를 되돌린다. 상태 1은 master가 있고 구독자가 맞을 때만 알린다. 그외는 캐시한 DWORD만 쓴다. 예외 때 이전 서버값으로 RAII 복원하지 않는 원문 순서를 보존한다. 0.946에서 추가됐다.
- `ClientMetaGameLogin.Install`은 0x7c의 원문 빈 observer·버전·고정 길이와 고정 F를 설치한다. 0.946에서 추가됐다.
- 송신·연결 장치는 세션·R11 수송에서 실제 결선으로 잇는다.

## 검증

- Release 테스트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 7건(미연결·소유자 불일치 거부·설치 metadata·상태 2 캐시·상태 0 거절·상태 0 수락 재지정·상태 1 master 없음·상태 1 구독자 일치 알림)은 통과/실패 0이다. 메타 설명·마스터·챌린지 이웃 검사를 포함한 32건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0946-*/`의 각 실행 로그와 요약이다.
