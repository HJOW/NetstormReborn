# Wind Noise(`playWind`) 원본 분석: 기본 설치에서는 소리가 나지 않는다 (WB04-E1153)

LEFT_JOBS 의 "Wind Noise 확인" 항목을 원본 실행 파일(10.78, `originals/Netstorm.exe`)의 정적 분석으로 확정했다. 웹의 Wind Noise 는 옵션 값만 저장하고 소리를 내지 않는데, 이것이 원본 기본 설치와 같은 동작이다. 코드 변경은 없다.

## 분석 결과 (원본 주소는 10.78 기준)

- 옵션 해석 함수 `FUN_00435220`("Interpret Options.")이 `playWind` 를 정수로 읽어 전역(`0x531884`)에 둔 뒤, 음악·소리 설정에 이어 다음을 부른다.
  - `FUN_004350d0(&0x54de60, "windNoise", playWind)`
- `FUN_004350d0`: **설정 문자열 키 `windNoise`**(바람 소리 파일 이름)를 `0x54de60` 구조체에 읽고, 이전에 재생하던 소리가 있으면 멈춘 뒤 `FUN_004a9de0(playWind, 파일 이름, 반복 1, 0)` 를 부른다.
- `FUN_004a9de0`: 소리 장치가 없거나 **파일 이름이 널이거나** 소리가 꺼져 있으면 아무것도 하지 않고 0 을 돌려준다. `playWind` 가 0 이면 그 소리를 멈추고, 1 이면 같은 채널이 이미 재생 중이 아닐 때 비위치 반복 재생(`FUN_004a9cb0`)을 시작한다.
- `0x54de60` 의 파일 이름 포인터는 정적 초기값이 0(BSS)이며 `windNoise` 키가 설정에 없으면 읽기 함수가 값을 쓰지 않는다. 배포된 `originals/d/setup.cfg` 등 어느 설정·대본에도 `windNoise` 키가 없다.
- 따라서 **기본 설치에서 Wind Noise 옵션은 켜도 꺼도 소리가 달라지지 않는다.** 사용자가 `options.cfg` 에 `windNoise=<파일>.wav` 를 직접 적어야만 반복 재생된다.
- 같은 옵션 메뉴 항목은 `Wind Noise`(`0x515890`)·`playWind=1`·`playWind=0`(`0x51589c`/`0x5158a8`)이며, 웹 옵션·ESC 메뉴의 항목(`playWind` 토글, 기본 켜짐)은 같은 이름·값으로 저장된다.
- 참고: `forWind2.wav` 등 바람 이름 소리 표(`0x532650`)는 별개이다. `FUN_00447e40` 이 위치 효과음(`FUN_004a9d70(x, y, 이름, 0)`)으로 쓰는 이 표는 앱의 효과음 재생기(`SoundPlayer`)가 처리하는 일반 효과음이며 `playWind` 와 무관하다.

## 웹 판본의 결정

- Wind Noise 는 현재처럼 **값만 저장**한다(`playWind` 설정 키, 기본 1). 원본과 동작이 같다.
- 원본의 선택 설정 `windNoise`(파일 이름)는 웹에 설정 파일이 없어 지원하지 않는다. 필요해지면 `Settings` 에 text 종류 키를 더하고 소리 재생기에 비위치 반복 재생을 연결하면 된다(`SoundPlayer` 에 반복 재생 경로 있음).

## 남은 것

- 소리 본체의 실제 청취와 음악 채널 앱 연결은 헤드리스 환경에서는 확인할 수 없는 항목으로 남는다(사람이 듣는 확인).
