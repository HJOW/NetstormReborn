# WB04-E713: Session Login의 채팅·동맹 수신 등록

`RawCampaignSessionLogin.inc`의 연결 활동 등록 뒤에 원본 순서대로 41h 채팅, 52h 전투 이탈, 3dh 동맹 마스크, 78h 동맹 안내를 같은 내부 분배기에 등록했다. 채팅은 실제 연결 주소와 Session의 현재 전투·서버·subscriber 및 공유 수신 마스크를 읽고 실제 UI 수신 장치를 호출한다. 다른 subscriber로의 LAN 중계는 기존 웹 제외 경계를 유지한다.

52h는 같은 Player 기록에 종료 비트를 합친다. 3dh는 같은 참여 객체의 마스크·방향표를 갱신하고 실제 방송을 사용한다. 78h는 현재 boss에서 양방향 동맹과 방송을 수행하고 현재 안내 장치에 종류 7을 전달한다. 빠진 실제 UI나 전투 동맹 송신 장치는 선택된 위치에서 오류로 남긴다.

집중 검사 54건에서 기존 로그인·채팅·전투 이탈·참여 모듈과 공유 마스크, 실제 Player 종료 비트, 동맹 방향표·방송·안내를 확인했다. 새 검사는 공중 유닛 생성·행동이나 사제 포획·희생·승리를 실행하지 않는다.

이는 내부 typed 등록 부분이며 서버의 로그인 큐 소비·응답 왕복, State7 Begin/Pump, 외곽 앱 수명과 외부 전송의 장기 등록 반납·Native 기본 수신기, 개발자 명령 해석기는 아직 연결되지 않았다. 기준선 뒤 32커밋의 전체 판정도 남는다. 실제 게임이나 브라우저 창은 실행하지 않았다.
