# webpj 메시지 생성 MessageGump (WB04-E452, 2026-11-14)

기준선 `1f00a25a`의 `MessageGump.cpp/.h` 공통 TextGump 생성·Pause(11)/시간(16)/Warning(17)을 `www/ui/message-gump.js`로 옮겼다. 같은 실제 파생 노드에 가상 표 `0x517b60`·종류/플레이어/기한/매개변수를 쓰고 이름 조회→번역/Style→기한/Idle→Fit 순서를 보존한다. +ac/+bc 미작성 필드와 기본 TextGump가 남기는 물리는 지우지 않는다. 웹은 고정 10.78이며 CD 10.72는 제외다.

## 기준선 뒤 변경 판정

대응표 base `86b37fff`까지 여섯 커밋을 읽었다. `a60d547f`(동맹/시작)·`37dcdfc2`(응답 지연)·`53df9e61`(송금/자원 지급)·`8d45566d`(접속/이탈)·`3f766a97`(합의/동맹 해제/종료)는 **② 공통 안내 UI 본문을 반영**했다. 실제 온라인/메타 참가자·네트워크 발생원을 새로 연결하지 않는다. `86b37fff`의 CD 분기는 **① 웹 제외**다.

새 안내는 두 색 표(응답 지연 4번 u, 일반 4번 g)·범위 밖 owner의 스타일 생략과 공통 기한·종류별 음향·번역 뒤 현재 이름 BYTE/두 번째 이름 주소·최초 송금 금액과 현재 지급 금액의 차이를 보존한다. 일반 안내는 wall/Idle 장치를 둘 다 먼저 확인하고, 기존 Warning/시간은 기한 쓰기 뒤 Idle을 요구하는 서로 다른 실패 순서다.
