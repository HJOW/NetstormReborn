# 도움말 창 정보 본문

WB04-E1052는 도움말 창에서 선택된 주제의 TYPE 정보 스타일을 별도 ScrollingText 본문으로 만들고 원본 정보 위치 (182,15), 크기 253×126에 그린다. 일반 주제로 전환하면 정보 본문을 제거한다. 현재는 정보가 있을 때 본문 상단을 153으로 내리는 임시 배치이며 원본의 그림 유무에 따른 분기와 TYPE 그림 출력은 후속이다.

별도 정보 본문 생성·표시·위치와 일반 주제 복귀를 검사했다. 기존 F1 원본 스크린샷 대조 및 영어·한국어 도움말과 정보 관측을 포함한 Node 26 검사 26건이 모두 통과했다. 실제 미션 TYPE 제공자와 앱 도움말 창 연결, 그림 출력과 브라우저 검증은 아직 남았다.
