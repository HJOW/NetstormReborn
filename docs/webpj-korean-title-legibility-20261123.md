# 한국어 큰 슬롯(제목) 글자 선명도 확인과 정수 배율 제안 (WB04-E1254, 코드 변경 없음)

[다음 작업 3](../LEFT_JOBS.webpj.md#next)의 "한국어 미션의 실제 화면 확인"을 실제 Chromium(`?lang=ko`, 1024×768)으로 캠페인 브리핑 세 장면(섬을 구하라!(SaveTheIsland)·천둥 같은 힘!(ThunderingPower)·잔혹한 힘!(Vicious))에서 했고, [다음 작업 1 ⑤](../LEFT_JOBS.webpj.md#next)의 근거가 되는 문제를 하나 찾았다. 결정이 필요해 코드는 바꾸지 않았다.

## 확인 결과

- **본문**(작은 슬롯, 갈무리11 11px 보통체): 줄 나눔·글자 모양·표지 서식이 모두 정상이다. 단추(`시작 보기`·`미션 시작`·`다음`), 왼쪽 HUD 스톰 파워 숫자, 오른쪽 위 `메뉴` 단추도 정상이다.
- **제목**(큰 슬롯 3, `<h2>`): 가로획이 이웃 획과 합쳐지거나 빠져 **다른 글자로 읽힌다**. 확대해 비교한 예: `섬을 구하라!` 의 `라` 가 `다` 처럼, `잔혹한 힘!` 의 `잔` 이 `산`, `혹` 이 `폭` 처럼 보인다(번역 원문 `translations/SaveTheIsland.korean`·`Vicious.korean` 은 정확하다). 제목은 미션마다 첫 줄에 크게 나오는 글자라 눈에 잘 띈다.

## 원인

`assets/unicode-font.js` 는 큰 슬롯의 글자 크기를 `emSize = round(슬롯 높이 × 13/14)` 로 정한다(작은 슬롯(높이 ≤ 14)은 11px). 슬롯 높이 표(`assets/bitmap-font.js`)는 `[14, 13, 0, 20, 48, 14, 12]` 이므로 **슬롯 3(제목) 20 → 19px, 슬롯 4(48) → 45px** 이다. 갈무리11 은 11px 비트맵 글꼴이라 **11의 배수가 아닌 크기**로 그리면 Canvas 가 비정수 배율로 보간해 1px 가로획이 사라지거나 번진다.

cpppj 원문(`BitmapFont.cpp:207~221`)은 `scale = max(1, (높이 + 11/2) / 11)` 의 **정수 배율**로 단색 픽셀을 그대로 복제한다("보간·ClearType 없이 단색 원본 픽셀만 복제", 획 두께 유지): 슬롯 3(20) → 2배 = 22px, 슬롯 4(48) → 4배 = 44px, 작은 슬롯은 1배 = 11px. 굵은체 파일(`Galmuri11-Bold`)도 원문은 큰 슬롯에 쓴다(굵기 고정).

## 제안(결정 필요)

1. **크기(가독성 수정, 위험 낮음)**: 큰 슬롯의 `emSize` 를 원문처럼 `11 × max(1, round(슬롯 높이 / 11))` 로 바꾼다. 바뀌는 값은 슬롯 3 의 19→22px 와 슬롯 4 의 45→44px 두 곳뿐이고 작은 슬롯은 그대로다. 제목이 20px 줄 안에서 22px 로 커지므로(원문도 줄 높이를 넘겨 그린다) 제목 폭이 약 16% 늘어 긴 제목이 창 폭을 넘는지 Tell·브리핑·메인 메뉴 제목에서 확인해야 한다. 영향받는 시험: `tests/korean.test.mjs` 의 슬롯 3·4 크기 단언(212·218행)과 폭 계산을 쓰는 한국어 Tell·도움말 시험.
2. **굵기(의도적 선택, 사용자 결정)**: 지금은 한글을 단색으로 그릴 때 작은 글자의 가독성을 위해 굵은체를 쓰지 않는다(E1244 이전 결정, `unicode-font.js` 주석). 원문처럼 큰 슬롯을 **굵은체로 고정**할지는 외관 선택이다. 굵은체 파일이 없는 글자(호환 자모·한자 등 8,271자)는 E1244 에서 일반 글리프로 대체되므로 굵게를 켜도 빈칸이 생기지 않는다.

두 가지는 독립이어서 크기만 먼저 고칠 수 있다.

## 재현

1. `?lang=ko` 로 첫 캠페인(자유를 위한 투쟁)의 임의 미션을 시작해 브리핑 창의 제목을 확대해서 본다(이 단위의 e2e 탐침은 임시 파일이라 남기지 않았다).
2. 같은 글자를 11의 배수(22px)로 그리면 가로획이 보존된다(E1244 의 `e2e/galmuri-bold-fallback.spec.js` 가 같은 래스터라이저로 글리프를 비교하는 틀을 제공).

## 시험

코드 변경이 없어 새 시험은 없다. 전체 회귀: Node 26.13.0 전체 6,790건 모두 통과(실패 0, 407초, 로그 `extracted/webpj-e1254-node26.log`).

## 남은 일

- 결정에 따라 위 1(·2)을 구현하고 한국어 Tell·브리핑·메인 메뉴·캠페인 목록 제목을 다시 확인한다.
- 나머지 한국어 화면(대본 본문 줄 나눔 등) 확인은 이 세 장면 범위에서 이상이 없었고 다른 미션·화면은 하지 않았다.
