# dotnetpj 1.029 — R4-5b 운반 호출자 결선

2026-11-25, HJOW-Athlon. R4-5b 세션 호출자의 세 번째 묶음이다. 세션에
`BuildAiCarriersDevice`를 두고 런타임 `Carriers` 갈고를 실제
`RawAiCarrierActions.Act` 호출로 이었다. 이동 본체·자원 선택·carrierDrop의
실제 하위가 없어 해당 갈고리는 원문 순서 도달 시 명시 거부한다(R6).

  `BuildAiCarriersDevice`가 `Act` 몸체와 `ManageAiCarriers`를 묶는다.
  실제 장치 11종(현재 시각·권한·진단·무효 그래프 전역, 최대 HP·포로 조회·
  다이스 접근점·취약 판정·그래프 조회·크리스털 개수/첫 후보·월드 파괴·진단)과
  미연결 9종(이동 5종·참여 상태·비행 조회·포획 등록/수집/재분류·하역 요청·
  이동 목표 조회)을 잇는다. 첫 크리스털은 원문
  `FindContained(actor,0x20,현재 크리스털 TYPE,0)`과 같은 판정으로 직접
  훑는다(DN에 같은 첫 후보 조회가 없다). 무효점은 원문 BoardTargetState

  `BuildAiRuntimeDevices`에서 운반 장치를 조립하고 `Carriers` 갈고를 실제
  행동 호출로 이었다. 1.029에서 추가됐다.

  3건 추가(장치 연결 단언 포함). brain 없음·범위 밖 거부·빈 목록 무효과·
