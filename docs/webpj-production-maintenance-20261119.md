# WB04-E831 생산 유지 본체 이식

기준선 `225553df`의 `RawProductionMaintenance.cpp/.h`를 웹 코어로 이식했다. 현재 기술 부모의 다리 수와 한 칸 조각 수를 세고 신전 소실, 다리 공급과 품질 변화, 생산 재고 타이머·허용 여부·SP 비용에 따른 삭제와 표시 갱신을 원본 순서대로 처리한다. 벽시각과 게임 시각은 별도로 읽고 signed 절삭과 DWORD 감김을 보존한다. 테스트 전용 다리 순서는 원래 난수 소비와 기본 결정 뒤에만 적용한다.

독립 x86 원본 관측 `production-idle-x86.tsv` 86행을 그대로 사용해 각 입력의 내용물 150바이트, 188개 double 타이머, 패널 필드와 순번 및 효과 순서를 대조했다. 테스트 순서 유효성·실패 시 보존·0번·순환 및 빈 슬롯의 난수 미소비도 검사한다. 기준선 이후 C++ 본체 변경은 없다.

이 단위는 독립 본체다. Session의 실제 Deck·시계·SP·내용물과 생산 HUD 수명 연결, 실제 유닛 생산과 브라우저 입력은 남아 있다. 게임이나 별도 창은 실행하지 않았다.

검증: 집중 검사 3건과 원본 86행 및 Node v26.13.0 전체 6,325건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E827의 Node v22 전체 검사 뒤 v26 회귀 4/8회다. fixture 824개 해시·파일 검사도 불일치와 누락 0이다. 전체 항목의 느린 Git 이력 재조회는 중단했으며 이번 본체의 기준선 이후 변경 없음은 별도 Git 조회와 대응표 검사로 확인했다.
