# dotnetpj 0.909 — RU-3 플레이어 패널 본문 이식

2026-11-24, HJOW-Athlon. RU-3 네 번째 묶음이다. 메타 NSInfo의 기존 일반 부착/관문 뒤 전체 메타 본문을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HudNsInfoMetaPlayer.Layout`는 `cpppj/src/client/HudNsInfoMeta.cpp`의 `LayoutMetaPlayerInfo(00479fb0)`를 이식했다. 같은 실제 CS/노드/가상 부착 장치를 빌리며 미복원 자식 본문을 빈 성공으로 우회하지 않는다. 네 공장 설치·바깥 UI·NativeRoot/HUD 창 생성·Enter·HUD 작성자·메타 입력 UI·Root reply 저장은 후속 단위에서 잇는다.
- 빈 슬롯은 이름 없이 비활성화하고 `"Slot empty\n"` 기본 문맥을 둔다. 마스터 참가자는 미준비자가 있으면 시작 버튼을 끄고, 모두 준비되면 시작 버튼을 켜고 metadata를 둔다. 마스터가 아니면 시작 버튼 없이 마스터 표시를 둔다.
- ready 버튼은 `0x2000` 유무로 항목을 쓰고 비`0x2`면 0으로 끈다. 소유자가 아니면 버튼을 끈다. 이름은 번역·`80BYTE` 설정 치환 뒤 마스터면 정렬행 metadata로 추가하고 아니면 `T+400` 파서로 표시한다. `L1`·`L0` 상태 아이콘과 `T+300` 랭크 그림·`T+100`/`T+200` 아이콘 줄을 원문 순서로 파싱하고 문맥을 복원한다.
- 후행 부착·공유 정기 수신·내용 맞춤 뒤 텍스트 폭을 맞추고 버튼·시작·마스터를 원문 위치에 부착한 뒤 최종 높이를 쓴다. 미연결 장치는 일반 Pre/Post/no-op으로 통과시키지 않고 명시 실패로 둔다.
- PORT_MAP은 이전 1830행의 값·순서·base를 보존한다(같은 HudNsInfoMeta 쌍의 0.906행이 원문을 이미 가리킨다). fixture 496개는 그대로다(합성 CS 기록 검증이라 신규 fixture 없음).
