# dotnetpj 1.046 — DI-3 커서 호출자 결선

2026-11-26, HJOW-Athlon. R4-6 표시·입력 묶음의 두 번째 조각이다. 실제 입력 경로가 같은 세션
풀·TYPE·게임 커서에서 취득·취소·조회·위치를 실행하도록 세션 커서 장치를 조립하고, 실제
포인터 이동과 Esc를 제품 입력 분배에 이었다. 왼쪽 버튼 Drop의 실제 송신과 생산 클릭 Take,
UI·음향·프로세스 하위와 카메라는 R6·DI-4에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Host/HostSession.Cursor.cs`: 신규. `BuildCursorDevices`가 같은
  지형 Pop TYPE 인스턴스에서 수명·배치 본체를 조립한다. 근거: cpppj
  `RawCampaignCursor.cpp`의 HandleInput 분기(왼쪽 Drop·0x1b Cancel)와 Take·GumpsChanged·Update
  결선이다. 도달 가능한 실제 장치는 세션 장치(Source 연관 부모·Unpop·Destroy·프로세스 제거·
  사정거리 판정·로컬 SP 가감·위치 읽기·쓰기)로 잇고, UI·음향·프로세스 하위와 카메라 투영은
  R6·DI-4 명시 거부로 둔다. `TakeCursor`·`CancelCursor`·`QueryCursor`·`PrepareCursor`와
  잡은 커서만 놓는 `TryCancelCursor`가 입력 경로의 호출자다. 1.046에서 추가했다.
- `dotnetpj/src/Netstorm.Client/Host/HostMenuInput.cs`: 실제 포인터 이동을 현재 커서 위치에
  반영하는 `CursorPosition`과 잡은 커서가 있을 때만 놓는 `CursorCancel`을 두었다. `Dispatch`는
  Esc 누름(가상 키 0x1b을 민 코드)이 잡은 커서를 놓았을 때만 소비하고, 없으면 종전 흐름을
  유지한다. `NotifyPointer`는 창 안 포인터를 먼저 현재 커서 위치에 반영한다. 1.046에서 수정했다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 제품 진입 경로에서 `CursorPosition`을 같은
  게임 커서 쓰기에, `CursorCancel`을 미션 세션의 `TryCancelCursor`에 이었다. 1.046에서 수정했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostCursorInputRootTests.cs`: 신규 5건. 장치 조립의
  동일 TYPE·단일 결선 거부, 포인터 이동의 세션 커서 반영과 창 밖 무시, 실제 분배를 거친 Esc
  누름의 놓기 순서(H0·P·S1·D·P)와 뗌·미보유 Esc의 미실행, 실제 Take의 같은 배치 조회 도달과
  Query·Prepare 실행을 대조한다. 1.046에서 추가됐다.
