# dotnetpj 0.822 — 실제 공통 미니맵과 출력·통지 수명

작업일 2026-11-22, PC HJOW-Athlon. 기존 MinimapGeometry/RawMinimapRaster/RawMetadisplayDirty를 재사용해 Source의 실제 공통 미니맵 부모를 조립했다. 실제 게임 Root의 나머지 패널/메시지 공장과 전체 Native 장치는 계속 미완료다. 실행 경로는 `dotnetpj/src/Netstorm.Game/bin/Release/net10.0/Netstorm.exe` 한 곳이다.

## 변경

- `RawMinimapControls`는 같은 GumpButtonTree의 기본 노드·부착·사건/캡처·Idle·scalar 반납과 외부 Draw에 연결한다. Session 이전 생성은 실제 장기 Storage를 받고 별도 World를 만들지 않는다. Construct의 현재 bitmap 폭·command29·가상표·소유 Help·성공 뒤 current/serial 게시, Open/Resize/Close와 crop/클릭/드래그/현재 모드2·5/기본 Help, 실제 전용 팔레트/갱신과 원문 진단을 이식했다.
- 공유 FullRefresh에는 실제 Gameplay.MapRevision의 UIntBox를 공급한다. 다른 owner를 섞으면 거부하며 같은 팔레트 재설정은 갱신을 늘리지 않는다. 같은 현재 World의 Pool/Hash/Unpop.Pool/TYPE/Spots/OwnerMode를 검증해 Pop/Unpop 통지를 연결한다. 짧은 World 모듈은 약한 참조로 빌리고 자기 expected 큐만 해제한다. 기존 Pop 해제는 재사용하고 Unpop의 누락된 같은 owner 해제를 추가했다. 해당 Source 두 파일은 기존 대응 base와 전체 내용이 같아 base를 불필요하게 바꾸지 않았다.
- `GumpExternalDrawing`은 Source RawMenuControls의 공통 버튼→고정 슬롯→독립 소유 등록 순서와 외부 텍스트 조회를 이식했다. 함수 슬롯은 값 복사하며 현재 callback owner는 공유한다. 독립 번호는 재사용하지 않고 자기 등록만 반납한다. 실제 HostGumpDrawing의 기존 수집·정렬·가상 Draw와 같은 픽셀/색/배경 문맥에 연결했다.
- `GumpRedraw`는 실제 현재 노드/지도/요청 장치를 사용하는 Whole/Map/원본 clamp다. 가시 조상을 먼저 보고 Position 뒤의 현재 크기·지도와 캐시를 사용한다. 미니맵은 이 기본 본체로 현재 영역만 요청한다. 기존 RawBitmap/LinesClipped와 실제 Bounds/Position·128stride를 재사용했다.

## 검증

최종 집중 검사는 **Core 22·Client 238, 합계 260건 통과/실패 0**이다. 신규 검사 이름은 Client 13개이며 이전 0.821 집중 검사의 모든 이름을 보존했다. 마지막 정기 전체 기준선은 0.820의 5,848건, 다음 정기 전체는 0.824다. 최종 솔루션 증분 Release 빌드는 오류 0·기존 Client 경고 3이며 새 경고는 없다.

기본 재그리기의 독립 PE **1,474행(Whole728·Map728·Clamp18)** 전체에서 요청·모든 노드 캐시·투영 순서를 대조했다. 투영 효과가 크기/지도를 바꾸는 현재 재조회, 숨은 조상의 자연 반환과 손상 조상 순환 거부도 확인했다. 이전 셀 그림 4,722행·순수 기하 1,028행·블릿 120행의 검사도 같은 집중 범위에서 다시 통과했다. 이전 기하의 외부 콜백 변이·중단 26행 전체를 새 부모 검사로 모두 대조했다고 확대하지 않는다.

같은 실제 공통 트리에서 다음을 검증했다.

- 카메라→현재 기본 영역→캡처/Idle의 호출 순서와 공통 Route/Frame 분배, 바깥 드래그 및 해제.
- 현재 숨김·선택 모드2/5와 카메라 반환 중 숨김의 불필요한 영역 요청 억제.
- 요청 영역만 지워 다시 그린 전체 표면과 별도 전체 출력의 바이트 일치. 행 padding도 보존한다. 같은 카메라에서 owner1→2→중립→지면 제거가 공유 MapRevision에서 셀/영역/실제 전용색 픽셀까지 한 번씩 전파된다.

- 실제 World의 물리 정체성/중복 대여 거부와 후속으로 설치한 다른 Pop/Unpop 큐의 보존. 검사 World의 생성이 전체 Game Root 설치를 증명하지는 않는다.
