# 비트맵 글꼴 캐시 (`d/!<글꼴>.<스타일>.<크기>.<굵기>.chfnt`)

> 분석 상태: **용도 확인, 내부 구조 일부만 확인** (우선순위 낮음)

## 용도

게임이 Windows GDI 글꼴(Arial, Courier New)로 글자 256개를 그려 만든 **런타임 캐시**다.
실행 파일(`FUN_004a34a0`)은 `"!%s.<스타일>.%d.%d.chfnt"` 파일을 먼저 읽고, 없거나 읽기에 실패하면 GDI 로 다시 만들어 저장한다.
따라서 원본 자산이라기보다 재생성 가능한 중간 산출물이다.

* 스타일: `normal`, `italic`, `bold`, `underline`, `strikeout`
* 이름의 숫자: 글자 크기(12/13/14/20/48), 굵기(0 또는 700)
* 256자 = Windows-1252 코드 페이지 → **한글 없음**

## 확인된 구조

| 오프셋 | 내용 |
|---|---|
| 0x00 | 매직 `"BitmapFontData"` + `0x1A 0x00` (16바이트) |
| 0x10 | u32 ×5: 버전(1), 높이, 어센트, 디센트, 글자 수(256) |
| 0x24 | u32 ×256: 글자별 전진 폭(advance) |
| 이후 | 글자별 크기 테이블과 글리프 데이터 (VFX 셰이프 형식 추정, 미확정) |

## 클론 방침

* 한국어: `fonts/` 의 D2Coding (LEFT_JOBS.md 1.5절)
* 영어: 원본 느낌 재현이 필요하면 이 캐시의 글리프를 디코딩해 쓰거나, 호환 TTF 글꼴을 사용 (9·12단계에서 결정)
