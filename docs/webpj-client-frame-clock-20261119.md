# Client 공유 프레임 시계 (WB04-E876)

cpppj `ClientMain.cpp`는 현재 밀리초로 `GameClock`을 초기화하고 Client의 `gameTicks` DWORD를 빌린다. 각 메인 루프에서 고정 시각 검사 모드를 먼저 한 프레임 전진시킨 뒤 `Capture` 결과를 같은 프레임 저장소에 쓴다. 웹 `ClientFrameClock`은 기존 `ClientTimeSource`·`GameClock`·실제 `ClientLocalStateGlobals` 보정 상자를 연결하고 같은 순서와 프레임 객체 수명을 제공한다. 현재 게임·벽시각 조회와 고정 프레임 조회는 구분하며 중첩 정지·복귀도 같은 시계를 사용한다.

고정 시각에서 DWORD 밀리초 감김, 보정 변경, 현재 시각과 직전 프레임의 차이, 중첩 정지·재개를 검사했다. 실제 TheWarBegins GameWorld 로그인 뒤 동일한 프레임 객체를 사용해 Kernel 준비 및 실행을 확인했다. 이는 독립 조립 검사이며 브라우저 앱의 Client 생성·메인 루프와 로그인 시계 공급자는 아직 연결하지 않았다. 원본과 전체 프레임 동기화나 난수 소비 일치를 의미하지 않는다.

Node v26 집중·연관 검사 45건이 통과했다. 최초 집중 검사에서 예외 메시지 정규식이 실제 문구와 달라 수정한 뒤 통과했다. 주기에 따라 이번 단위에서는 전체 회귀를 실행하지 않았다. 게임 창은 실행하지 않았다.
