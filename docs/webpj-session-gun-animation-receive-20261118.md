# WB04-E727: 총 애니메이션 데이터 수신

cpppj `RawCampaignSession.cpp` 기준 `225553df`의 Carrier 3bh·3ch 등록과 `RawCampaignArcherBindings::ReceiveAnimationPacket` 호출을 같은 실제 Session 전투 바인딩에 연결했다. 기존 바인딩이 현재 Pool·TYPE과 Host를 사용해 신규 Form을 부착하거나 현재 PID의 선택 필드를 갱신한다. 고정 가짜 객체나 별도 월드를 만들지 않는다.

일반 Form 부모에 총 애니메이션 데이터를 수신해 두 등록의 신규 부착과 기존 PID 갱신을 확인했다. 새 검사는 프레임·발사를 실행하지 않으며 공중 3종 전용 생성·생산·우클릭·행동, 사제 포획·희생·자연 승리도 실행하지 않았다. 실제 게임이나 브라우저 창은 열지 않았다.

다음은 원본 순서의 아비어리 수신을 사용자 제한에 따라 정적으로 이식하는 것이다. 그 밖의 Carrier 수신·서버 응답 왕복·Native·앱 미션 수명은 남았다.

실제 Session과 기존 전투 바인딩 검사를 함께 실행해 33건이 통과했다.

대응표 오류 0, Node v26 전체 회귀 6,188건 통과다. Node v22는 E722에서 순차 전체 검사했고 현재 v26 주기는 5/8회다.
