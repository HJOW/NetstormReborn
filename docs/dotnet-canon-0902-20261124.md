# dotnetpj 0.902 — RU-2 Root 공급값(언어·화면·치환) 실제 owner 조립

2026-11-24, HJOW-Athlon. 0.901 RU-1 뒤 RU-2 첫 묶음이다. RU-2 전체 중 세션 독립 공급값을 먼저 잇는다. 제품 코드는 공급 도우미만 추가했고 기존 Load 경로는 바꾸지 않았다.

## 변경과 원문 대응

- `ClientSurfaceGlobals.RootSupplyDevices`는 Root 고정 수신이 읽는 공급값을 실제 owner로 제공한다. 근거: `cpppj/src/client/LanguageOptions.h·cpp`의 여덟 이름(`english`×2·`french`·`german`·`spanish`·`japanese`·`portuguese`·`korean`)과 `OriginalLanguageName`·`FindOriginalLanguage`, `cpppj/src/client/CampaignClientServices.cpp` 112·114행의 `names.language/substitute`, `cpppj/src/client/ClientMain.cpp` 854·1154행의 `LogicalScreenSize`다.
- 언어 번호는 원문 순서를 그대로 둔다(0/1 별칭 합치기 없음). `Find`는 정확한 비교이며 미등록/빈 이름은 0이다. `RootLanguageNumber`는 현재 설정 값을 소문자로 정규화해 번호로 읽는다. 확장 번호 판정(일본어 5·한국어 7)은 `IsExtended`에 둔다.
- 화면 크기는 수신 직전의 같은 논리 `Screen`을 읽는다. FSR 출력 픽셀이나 도킹 영역을 사용하지 않는다.
- 설정 치환은 같은 실제 `ConfigInterface.SubstituteLocal`을 빌린다. 이름 `Translate`·`Level`, `FormPacket`, Gun/Flyer/Aviary 등 수신 장치, 장면음악·UI/음향/Pool·전체 State·색표7·zone·세션 InBattle 완전 결선과 `BindSquidPacketDevices` 생산 결선·26F 전체 수신은 0.903에서 잇는다. 미연결 하위는 일반 Pre/Post/no-op으로 통과시키지 않고 명시 실패로 둔다.
- PORT_MAP은 이전 1822행의 값·순서·base를 보존하고 3행을 추가했다(자료 1825행). fixture 496개는 그대로다.
