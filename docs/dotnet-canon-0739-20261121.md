# 0.739 State 장기 자원과 장면 음악 감독

ClientHostGame이 같은 ClientStateResources를 메뉴·미션·음향 장치보다 오래 소유하도록 연결했다. 현재9개 Template manager/직렬화 버전/섹션 이름표, QuickHelp 마지막표식, Fort Core seed 전체DWORD, SceneMusicState가 여기에 있다. 실제 Surface/LocalState/Connections/Cloud/NSInfo와 ClientStateWorldContext를 구성하고 기존 폭별 주소 바인더로 검증·설치한다. 생성과 getter는 파일·곡·정리 효과를 실행하지 않는다. seed의 lowWORD와 음악 songEnd8BYTE는 같은 실제 상자에 직접 쓴다.

현재 Help/Options 팝업도 같은 QuickHelp 표식을 빌리고, Edit 목록의 임시 manager 둘은 장기 Template의 직렬화 버전/이름표를 빌린다. 실제 미션 음향 장치는 같은 SceneMusicState를 받아 장치 반납으로 기한을 초기화하지 않는다. 장면 음악의 currentBattle은 같은 장기 Surface의 현재 OwnerMode를 소비 위치마다 조회한다. 이 연결은 전체 QuickHelp/지식카드 UI와 음악 재생 장치가 설치됐음을 뜻하지 않는다.

SoundSceneMusic.cpp/.h의 상태와 감독 본체를 이식했다. 결과 곡 잠금→같은 곡/잠금/승리 결과 관문→곡 선택/길이/시각, 다음 곡/희생 판정→날씨, 만료 뒤 현재battle 조회, Start 내부Frame의 현재모드 재조회, 팔레트/dirty/번개/효과음 순서를 지킨다. ASCII 바이트 이름비교·32비트 색인 감싸기/C나머지·x87의 비교불가(NaN) 분기를 보존한다. 기본 음악채널+0x18의 실제8BYTE 곡길이를 읽는 순수 경계도 제공한다. 필수 장치를 누락하면 생성 시 거부하고 미선택 하위를 빈 성공으로 채우지 않는다.

기존 독립 기계어 fixture scenemusic-x86.tsv를 원문 그대로 연결했다. originals/originalCD/original1037 각3113개, 합계9339개 입력의 호출별 사건/반환과 최종10전역을 전수 대조했다. 기대값을 C# 결과로 만들거나 바꾸지 않았다. 실제 자료는 시계/곡 선택/월드/화면/설정/효과음을 명시 입력으로 제공하며 실제 희생/공격/승리 플레이를 실행하지 않는다.

첫 집중21건과 신규13건 포함 최종26건이 모두 통과했다. 신규 검사는 위3판본, 만료 전/현재시각NaN/songEndNaN의 currentBattle 미조회, 현재provider/fallback, 선택callback이모드를바꾸는Start내부재조회, 채널8BYTE의부호0/NaNpayload/이웃보존, 장기자원초기값/같은뷰/잘못된Client거부/음소거실제장치수명이다. 대표3시작도 모두 종료0/0.736 전체덤프바이트·지표일치/원본1392파일불변이었다. 근거는 extracted/dotnet-0739/client-final.log·client-final.trx·capture.py·capture.log·capture-summary.json·capture-originals-audit.json·audit.py·final-audit.json이다.
