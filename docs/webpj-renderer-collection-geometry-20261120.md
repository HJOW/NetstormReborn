# WB04-E978 Renderer 수집 범위

원본 `ClientRendererFrame`의 dirty·지도 사각형을 같은 카메라 snapshot의 분수 월드 원점으로 투영하고, 투영된 지도 범위에서 좌표별로 제한한다. 행당 수집 한도는 원본의 signed 나눗셈과 32비트 곱 감김을 따른다. 기존 CameraView의 16·11 역투영을 그대로 사용하며 현재 픽셀 원점만으로 분수 좌표를 재구성하지 않는다.

검증: 보호 원본 10.78 x86 지형 수집 인자·행 한도 90행을 단정도 비트로 전부 대조하고 음수·오버플로·잘못된 입력을 검사했다. 수집기와 Renderer 앱 조립은 아직 이 단위의 범위 밖이다. fixture 목록·대응표를 포함한 Node 12건 통과. E974 고정 Node 22 전체 회귀 6,554건 통과·실패와 건너뜀 0, 같은 상태 Node 26 회귀 실행 중이다.
