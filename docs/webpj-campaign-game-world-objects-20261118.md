# WB04-E791 로그인 완료와 현재 자산 보기

지연 캠페인 `CampaignGameWorld`에서 실제 Session의 로컬 연결이 Ready가 될 때까지 관문을 유지하고, Ready 뒤 `RawSurfaceWorld.objects()`와 같은 풀의 자산에서 표시 보기를 구성한 다음 한 번만 관문을 연다. 각 보기의 SID·TYPE·소유자·좌표·정수 칸·현재 및 초기 프레임·walker 여부·그림 유효성·선택 가능 여부·현재/최대 HP는 cpppj `GameWorld::RefreshCampaignObjects`를 따른다. Session은 같은 `SquidReward`를 공개하며 현재 HP는 같은 슬롯의 +26에서 읽는다. 호출자에게는 목록과 칸의 사본을 돌려준다.

TheWarBegins 실제 자산과 내부 로그인으로 Ready 전후의 관문과 목록을 검사했다. 기존 사제 슬롯을 임시 변경하여 HP·좌표·음수 프레임의 갱신과 칸 절삭, 목록 사본의 독립성을 확인하고 원래 값을 복원했다. 세션이 사용하는 실제 픽셀 화면 장치는 아니며 게임 프레임을 실행하지 않았다. 선택 대상 삭제 시 선택 해제, 지연 팔레트 전달, 입력·프레임·브라우저 앱 연결은 남아 있으므로 GameWorld 전체 완료나 실제 미션 플레이를 의미하지 않는다.

검증: Node v26.13.0 전체 6,293건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 마지막 Node v22 전체 검사는 E787이며 이번 단위까지 이후 v26 전체 검사 4/8회다.

후속 E792에서 지연 팔레트와 실제 커서 전달을 연결했다([단위 문서](webpj-campaign-game-world-palette-20261118.md)). 선택 정리·입력·앱 연결은 계속 남는다.
