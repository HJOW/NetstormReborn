# WB04-E772 상태8 연결과 장기 전송 기록

기준 `225553df`의 `RawCampaignSession.cpp` 4169~4171·4176~4178행과 `RawCampaignSessionLogin.inc`의 Connect·Record에 맞춰 현재 Login에 상태8 연결 인자와 외부 전송의 수신 기록을 전달한다. 연결은 기존 Login의 상태8·20바이트 주소 관문을 사용하고 실제 전송에 같은 주소와 포트를 넘긴다. 일반 전투의 문자열 주소 및 재접속은 웹 후속 경계다.

내부 전송과 장기 전송의 기록은 동일한 Login `record` 본문을 사용한다. Login이 없으면 외곽 기록은 원본처럼 아무 효과 없이 반환하며, Login이 있으면 네 바이트 헤더 확인 뒤 수신 종류를 기록하고 같은 버퍼·현재 sender·권한·로컬 owner를 선택된 관찰기에 전달한다. 반납된 Session의 재사용은 거부한다.

실제 Login 앞단에서 상태·주소 관문과 원문 인자 전달을, TheWarBegins Session에서 Login 전 무효과·Login 후 기록과 오류·반납을 확인했다. 집중 검사 2건이 통과했다. 실제 브라우저 GameWorld의 전송 소유와 Native 수신기 대여는 아직 후속이다.

Node v26.13.0 전체 회귀 6,275건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 검사 오류는 0건이며 E771의 Node v22 전체 회귀 뒤 첫 번째 v26 회귀다.
