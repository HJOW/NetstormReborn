# 캠페인 1-1 플레이 구현 (2026-10-01)

AGENTS.md의 클론 목표와 사용자가 지정한 **메인 메뉴 → 캠페인 목록 → The War Begins!**, **메인 메뉴 → 옵션** 범위를 연결했다. 다른 AI의 기존 전투·수송·희생·지면·오디오 구현 위에 플레이 조작을 추가했다. 원본 게임을 새로 실행하지 않았다.

2026-10-01 UI 외관 후속: 글씨·버튼을 줄이고 원본 돌 질감·금색 모서리·펼침 메뉴·왼쪽 생산창을 적용했다. [적용 내용과 새 검증](../screens/clone-ui.md)을 참고한다.

## 실행과 공개 범위

`dotnet run --project src/Netstorm.Game -c Release -- --language korean` 또는 빌드한 `NetstormClone.exe --language korean`으로 메인 메뉴를 연다. 영어는 `--language english`다. `assets/game-data/`의 게임 데이터와 D2Coding 글꼴을 출력에 자동 포함하므로 `originals/` 없이 실행할 수 있다. [데이터 구성](../../assets/README.md).

> 2026-10-01 후속: **1-2 Master of Whirligigs를 공개**했다(메뉴·성공 창 Next Mission). 아래 "1-2~1-6 잠금" 서술 중 1-2는 [캠페인 1-2 문서](campaign-two.md)로 대체되었다. 타입 기본 비용·가이저 고갈·채집 시간·임시 AI 일반화도 그 문서에 있으며 1-1에도 적용된다.

캠페인 → **자유를 위한 투쟁(Struggle For Freedom)** → **1-1 전쟁의 시작!** → 브리핑의 **미션 시작** 순서다. 원본의 여섯 그룹과 1장 여섯 미션을 표시한다. 메인 메뉴의 Multiplayer·Demo·Help·Edit·Credits, 다른 그룹, 1-2~1-6은 흐린 글자 항목이며 클릭·키보드 실행을 받지 않는다. 성공 창의 Next Mission도 잠겨 있다. Quit는 종료한다. 일반 메뉴는 Tab/↑/↓/Enter와 Back/Esc를 지원하며 미션 브리핑은 화면 버튼으로 진행한다.

기본 개발 환경 확인 화면은 메인 메뉴로 대체했다. `--map`·`--sprites`·다른 미션 명령줄은 기존 분석·검증 진입점이며 일반 메뉴에 공개하지 않는다. 1-1 플레이 UI에서는 P/[ ] 타입 탐색, C 연결 강제, K 생산 규칙 해제, F3 전투 끄기를 막는다.

## 플레이 방법

1. 사제 우클릭 → **Construct → Workshop → Sun Workshop**(800)을 고르고 녹색 판정을 받는 내 섬 위치에 클릭해 짓는다. 건설이 끝나면 워크샵 우클릭 → **Put Knowledge into Production**에서 시작 지식을 등록한다. 등록한 항목만 왼쪽 생산 창(덱)과 **View Current Production**에 나타나며, Available 목록에서는 빠진다. 등록은 실제 2/3/4칸 제한을 따른다. 3개 타입을 모두 쓰려면 워크샵 우클릭 **Upgrade**로 생산 칸을 늘린다. 생산 창의 배치·표시는 [생산 창 문서](../screens/clone-deck.md)를 따른다(2026-10-02, 이전의 버튼 격자와 자동 등록은 없앴다). 강화 비용은 건설 비용과 같다. Sun Workshop만 **800 SP**이고(네 번째 녹화 메뉴), Wind·Rain·Thunder Workshop은 각각 **1,000 SP**다(건설 비용도 동일). 워크샵을 선택하면 하단에 단계가 나온다.
2. 생산 창의 골렘을 클릭해 지도에 놓고, 골렘을 선택한 뒤 가이저를 클릭하면 수확과 신전 전달을 반복한다. 사제도 같은 조작으로 채집한다. 길이 없는 가이저는 먼저 다리를 잇는다. 빈 지면 클릭은 일반 이동이다(클릭 지점에 가장 가까운 칸으로 8방향 이동하고 이동 명령 뒤 선택이 풀린다). 사제·골렘은 그려진 몸통을 눌러 선택한다. 유닛·건물을 놓으면 배치 커서가 풀리고 지도 우클릭으로 취소할 수도 있다.
3. 생산 창 위쪽 다리 칸의 조각 클릭(또는 Q W A S Z X, E) → 지도 클릭으로 배치한다. 집은 조각은 놓을 때까지 제자리에 어둡게 남는다. 우클릭은 회전, C는 반대 회전, Backspace는 반환이다.
4. 발전기의 공급 범위를 이어 공격 위치에 Sun Cannon·Whirlibase를 배치한다. 생산 비용·에너지·소유권·재충전은 기존 코어 판정을 사용한다. 포대와 Whirligig는 자동 공격한다.
5. 적 신전을 무너뜨리고 적 사제가 기절하면 **골렘 선택 → 적 사제 클릭 → 내 제단 클릭**으로 운반한다. **P/R로 내 사제 선택 → 내 제단 클릭**으로 사제를 의식 위치로 보낸다. 기존 다섯 룬·희생·승리 창으로 이어진다. 내 사제가 적에게 희생되면 실패 창이 뜬다.
6. **메뉴/Esc → Game → Leave Mission → Main Menu**로 돌아간다. Restart/Replay는 첫 브리핑·3,000 SP부터 다시 시작한다.

지도 이동은 방향키·우클릭 드래그·미니맵 클릭, 확대는 휠이다. 원본 구름 GIF, 맵 셰이프, 메뉴 `titleMenu.gif`, `fortGump` 돌 질감, 기존 음악·효과음을 재사용한다. 한국어 첫 브리핑·성공·실패 본문과 기본 메뉴를 추가했으며 원본 스크립트의 조건·명령은 유지한다.

## 검증과 한계

Release 빌드, 전체 게임 없이 실행하는 Assets/Core 테스트, `tools/clone_ui_smoke.ps1`의 클론 UI 검사를 수행했다. 신규 `CampaignOneTests`는 원본 맵 시작 조건·적 0 SP/골렘 수입·생산 골렘 수확/정지·정확한 칸 이동·워크샵 3번째 등록·와이드 높이·다음 미션 잠금·AI 결정론/검사합을 확인한다. 적의 침입 사제 포획→희생→실패 검사는 **원본 타입을 사용한 작은 별도 지형**이며 원본 1-1 맵에서 직접 패배까지 플레이한 증거는 아니다. 기존 희생 검사에는 다섯 룬→포로 제거→성공 이벤트가 포함된다.

UI 검사는 `--ui-script-file`로 실제 메뉴·지도 갱신이 읽는 동일한 논리 좌표 마우스 상태를 주입한다. 메인 메뉴 → 그룹/미션 잠금 → 브리핑 → 전투 → 건설 커서 → 다리 집기 → 떠나기 → 메인 메뉴 → 옵션 → 1280×720 → 전체화면/창 복귀를 검증하고 설정 파일의 볼륨 4/3·창 크기를 확인한다. **OS에 실제 마우스·키보드 입력을 보내는 검사가 아니다.** PNG/로그는 Git 제외 `extracted/screens/ui-smoke-20261001/`에 저장한다. 초기 OS 입력 실험의 캡처는 검증 근거로 사용하지 않는다.

원본 1-1과의 가격·AI·타이밍 일대일 일치, 사람이 GUI에서 긴 전투를 끝내는 완주, 실제로 소리를 듣는 음량 평가, Linux GUI는 이번 검증에 포함되지 않았다. 상태·의식 규칙의 검사 통과를 이런 검증으로 확대해 해석하지 않는다.

```powershell
dotnet build Netstorm.sln -c Release --no-restore -m:1 -nr:false -p:UseSharedCompilation=false
dotnet test Netstorm.sln -c Release --no-restore -m:1 -nr:false -p:UseSharedCompilation=false
powershell -NoProfile -ExecutionPolicy Bypass -File tools/clone_ui_smoke.ps1
```
