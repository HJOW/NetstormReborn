# Whirlibase·Whirligig 1차 구현

2026-10-01. `BattleSession.Flyers.cs`와 `FlyerFlight.cs`로 공중 공격체를 전투에 연결했다.
**이번 범위는 Sun 계열 두 타입**이다. Man o'War·Dust Devil은 서로 다른 수명·공격 규칙이 있어
이 동작을 그대로 적용하지 않았다. 원본 게임은 실행하지 않았다.

## 구현한 동작

- 완공·소유된 Whirlibase는 5초 뒤 무료 비행체 1대를 만든다. 대기 중에도 기지당 1대만 유지한다.
- `Docked → Hunting → Returning → Refuelling → Docked`로 진행한다. 목표가 없으면 기지에서 기다린다.
- 가까운 유효 적을 선택하고 동률은 번호순이다. 대상이 유효한 동안 유지한다.
  중립·동맹·기절·체력 0·수송(골렘/풍선 등)은 제외하며, 출발점 반경 30칸과 목표당 최대 3대를 검사한다.
  2026-10-03 후속으로 원본 Bulwark의 공중 공격 면역을 적용했다. Wind Tower의 방향 면역은 비행 공격을 막지 않는다([정적 근거](../videos/crossbow-defense-20261003.md)).
- 이동은 지형·다리와 독립적인 소수 좌표다. 목표 중심 1.5칸 안에서 1초마다 10 피해를 다음 틱에 예약한다.
  지상 `shotblocking`을 비행체 공격에 적용하지 않는다. 기존 포대는 비행체를 체력 있는 공중 목표로 사격할 수 있다.
- 출격 60초가 되거나 목표가 없어지면 귀환한다. 기지에 도착하면 3초 보급 후 다시 목표를 찾는다.
  보급 때 체력을 회복시키지는 않는다.
- 비행체 파괴 시 기지는 사망 시점부터 5초 뒤 다시 만든다. 기지를 회수·파괴해도 출격 중인 비행체는 남는다.
  이후 귀환할 곳이 없으면 보상 없이 사라진다. 기지에서 대기/보급 중 기지가 없어지면 즉시 사라진다.
- 비행체는 지상 점유를 등록·해제하지 않고 파괴되어도 주변 다리를 약화시키지 않는다.
  다리 배치의 점유 콜백에서도 제외한다. 선택용 정수 발자국과 실제 비행 좌표를 분리했다.
- 원본 `A00`~`A07` 본체 그림을 임시 12fps로 돌려 지상·다리 위에 표시한다. 발사음은 기존 `ShotFired` 경로를 사용한다.
- 부모 기지·출발점·소수 좌표·단계·귀환/보급 틱을 검사합에 넣는다. F3 전투 끄기에서는 비행 처리도 멈춘다.

## 추정과 후속 수정 기준

| 임시 정책 | 후속 분석 |
|---|---|
| 생성/재생성 5초, 보급 3초, 처음에는 적이 없어도 생성 | 원본 기지 애니메이션·`AP_*` 타이머·출격 전 대기 상태 대조 |
| 출격 60초에 **귀환 시작**, 귀환 중 별도 연료 소진 없음 | 1분이 귀환 시작·도착 기한·수명 중 무엇인지 확인 |
| 목표 상실도 즉시 귀환, 기지 없으면 귀환 시 소멸 | 원본 탐색·대기·연료 종료 경로 확인 |
| speed 2 = 논리 칸/초, 직선 비행, 접근 거리 1.5칸 | 카메라 고정 연속 프레임으로 픽셀/게임시간 단위를 측정 |
| 매초 10 피해, 다음 틱 명중, 지상 차폐 무시 | 접촉·선회·타격 애니메이션과 피해식·공중 차폐 대조 |
| 기지 대기·보급 중에도 별도 피격 가능 엔티티 | 원본 기지 내부 보관·피격 가능 상태 확인 |
| 사제는 별도 분류라 목표 허용, 다른 체력 있는 비행체도 허용 | 원본 Whirligig의 목표 genus 필터 대조 |
| 번호순으로 목표 예약, 3대 제한은 소유자와 무관 | 다수 플레이어·다른 종류 비행체 동시 접근 시 우선순위 확인 |
| 회전 본체만 표시, 공격체 전용 그림자·기지 개폐·착륙 높이 없음 | 원본 레이어·기지 프레임·이륙/착륙 애니메이션 연결 |

**남은 범위:** Rain/Wind 공격체, 비행 수송의 이륙·착륙 상태, 자동 전략 AI. 지상 수송·포획·제단·미션 이벤트의 첫 모델은 [희생 의식 구현](sacrifice.md)에 있다.
일반 맵의 저장 비행체는 부모 정보가 없으므로 생성 비행체처럼 이동시키지 않는다(`dontSave` 타입).
전투 F3을 오래 껐다 켜면 세션 시각은 진행해 타이머가 만료될 수 있다. 전체 일시정지는 Space다.

## 검증

`dotnet test dotnetpj/Netstorm.sln -c Release --no-restore -m:1 -nr:false -p:UseSharedCompilation=false`:
Assets **186**, Core **184** 통과. 새 비행체 테스트 **14건**은 무료 생성·이동 후 공격·최대 3대·수송 제외·동맹·
출발점 사거리·귀환/재출격·기지 제거·피격/재생성·지상 점유 보존·결정론·전투 끄기를 확인했다.
Release 빌드 성공. 첫 전체 빌드에는 기존 `TextResourceTests.cs:353`의 CA2014 경고 1개가 있었고,
마지막 게임 프로젝트 증분 빌드는 경고·오류 0이었다.
클론의 `masterofwhirligigs` 맵에서 발전기·Whirlibase 배치와 5초 뒤 비행체 생성 이벤트,
기지 옆 원본 본체 그림을 확인했다(`extracted/whirligig-clone-base.png`). 이 화면은 적이 없는 대기 상태이며
공격·귀환의 실시간 화면 대조는 하지 않았다. 해당 동작은 위 헤드리스 테스트로 검증했다.


원본과 일대일 속도/피해 대조, 소리 청취, Linux 실행과 캠페인 완주는 검증하지 않았다.
