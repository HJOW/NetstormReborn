# dotnetpj 0.910 — RU-3 배틀 패널 본문 이식

2026-11-24, HJOW-Athlon. RU-3 다섯 번째 묶음이다. 메타 NSInfo의 일반 부착/두 현재 관문 뒤 비활성 전투도 공통 스크롤/자식 배치를 수행하는 배틀 패널 본문을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HudNsInfoMetaBattle.Layout`은 `cpppj/src/client/HudNsInfoMeta.cpp`의 `LayoutMetaBattleInfo(0047b480)`를 이식했다. 같은 실제 CS/노드/가상 부착 장치를 빌리며 미연결 장치는 일반 성공으로 꾸미지 않고 명시 실패로 둔다. 네 공장 설치·바깥 UI·NativeRoot/HUD 창 생성·Enter·HUD 작성자·메타 입력 UI·Root reply 저장은 후속 단위에서 잇는다.
- `PrepareSettings`는 게임 종류별 현재 설정 쌍을 원문 순서로 쓴다. `0xd4`/`0xe4`/`0x138`/`0x144` 공통 분기 뒤 종류별 분기(`1`/`2`/`3`/`4`/기본)를 원문 쓰기 순서대로 수행하고, 후행 공통행을 같은 순서로 둔다.
- `mode2`는 활성 전체 값/편집 태그를 쓰고 그 외 모드는 현재 값이 기준과 다른 활성행만 쓴다. 분류 그림 문자열은 원문 범위에 맞는 고정 문자열을 반환하며 현재 언어 번역을 추가하지 않는다.
- 제외 목록은 원문대로 개수를 매회 다시 읽고 첫 행 번호 1과 `TYPE+122` 태그를 사용한다. 목록 뒤 `Click To Add` 행을 같은 위치에 둔다.
- 후행 부착은 요약/제목/본문을 원문 위치에 부착하고 최초 1회에만 상단을 요청한다. 미연결 장치는 일반 Pre/Post/no-op으로 통과시키지 않는다.
- PORT_MAP은 이전 1830행의 값·순서·base를 보존한다. 합성 CS 기록 검증이라 신규 fixture는 없다.
