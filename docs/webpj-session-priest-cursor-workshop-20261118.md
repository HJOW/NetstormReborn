# WB04-E761 실제 로그인 뒤 사제 메뉴와 워크샾 배치

기준선 `225553df`의 `RawCampaignSession::MakePriestMenu`, `Cursor`, `CursorDropSettings`, `EnergySupply`, `MayPlaceConstruction`을 같은 Session의 실제 소유자에 연결했다. 사제 메뉴가 현재 Player·기술·자금·제외 목록과 같은 Pool을 빌리고, 호출자가 별도 취득 장치를 제공하지 않으면 이미 설치된 같은 커서에 미리보기를 전달한다. 화면·소리·입력은 호출자가 제공하며 배치 판정과 생성은 실제 몸체를 사용한다.

보호된 TheWarBegins(캠페인 1-1) Fort와 대본을 내부 로그인하고 Start한 뒤, 로컬 사제의 워크샾(TYPE 85)을 메뉴에서 선택했다. 실제 에너지와 전체 배치 판정이 허용하는 지면을 찾고 커서에 마우스 좌표를 전달해 내려놓았다. 원본 3,000 SP가 2,200으로 차감되고 Pump 전에는 수신되지 않으며 Pump 후 sender 1의 25바이트 3eh와 같은 좌표·소유자의 건설 중 워크샾 한 개를 확인했다. 화면·음향 갱신 요청만 관찰하며 배치/비용/생성 결과를 시험 코드에서 대체하지 않았다.

최초 배치 시 실제 소리 재생 경계가 선택되어 테스트의 금지 장치에서 실패했고, 외부 소리 요청을 기록하는 장치를 명시했다. 이후 서버 건설 통지가 실제 화면 갱신 경계를 요구해 해당 외부 장치도 명시한 뒤 성공했다. 기존 사제 메뉴·커서 집중 검사 17건과 실제 로그인 배치 검사 1건이 통과했다. 대응 cpppj 제품 소스는 `225553df` 이후 변경되지 않았다.

워크샾 자연 완공·후속 생산, 실제 브라우저 메뉴/화면·Client 수명과 미션 프레임은 아직 검증하지 않았다. 포획·희생·특정 적 공격·승리 및 세 공중 유닛 전용 행동을 실행하지 않았고 게임 창도 열지 않았다.

Node v26.13.0 전체 회귀 6,260건이 통과한 뒤 Node v22.23.3 전체 회귀 6,260건을 순차 실행해 통과했다. 두 검사 모두 실패·취소·건너뜀 0건이며 대응표 오류는 0건이다. 다음 v22 전체 회귀는 이후 v26 전체 회귀 8회 완료 뒤 실행한다.
