# 튜토리얼 진행 조건 안내 — 세 프로젝트 공통 적용 계약

2026-11-27 사용자 지시: cpppj에 추가한 초기 미션 진행 조건 안내를 dotnetpj와 webpj에도 적용한다. cpppj는1371~1372에서 구현·허용 범위 검증을 완료했다. 이번 문서 정리 단위1381에서는 DN/WB의 후속 요구와 완료 기준을 기록하며, 두 프로젝트의 기능 구현 완료로 세지 않는다.

기준은 [40단계 조건표](exe/cpp-tutorial-objectives-1371-20261127.md), [cpppj 동작·화면·검증](exe/cpp-tutorial-objective-display-1372-20261127.md), [카탈로그](../cpppj/src/client/TutorialObjectiveCatalog.inc)와 [표시/상태 해석](../cpppj/src/client/TutorialObjective.cpp)이다. 기존 원본 이식 기준선과 별개인 추가 기능이므로 기존 L2/L3의 원본 화면 일치 결과나 PORT_MAP 완료율에 포함해 계산하지 않는다.

적용 대상은 공식 Tutorial1~6의40단계다. 현재 단계에서 다음 알림창 또는 미션 종료창이 뜨기 위한 실제 조건을 계속 안내하고, 예약/타이머 대기는 별도 문구로 표시한다. 일반 캠페인·스커미시·데모·멀티플레이·편집 모드에는 표시하지 않는다. 미션 이름/번호·실제 gate·예약/타이머를 읽기만 하며 Advance·알림 순서·완료 판정·난수·SP·공격/승리 조건을 바꾸지 않는다.

현재 지도 영역의 우측 하단에 배경 없는 글자만 표시한다. cpppj의8픽셀 여백·최대440픽셀 줄바꿈 폭·보통체/1픽셀 그림자를 기준으로 플랫폼의 논리 좌표에 맞춘다. 지도 화면이 글자 뒤에 그대로 보여야 하며 패널·반투명 상자를 만들지 않는다. HUD·미니맵을 피하고 긴 문장·혼합 문자 경계를 보존하며 마우스 선택·우클릭 도움말·입력을 소비하지 않는다.

알림창·도움말·지식창·게임 메뉴를 읽을 때 숨기고 닫으면 현재 단계 문구로 복원한다. 미션 종료·중단·재시작·다른 미션 전환·화면 크기/루트 변경 때 기존 표시를 정리하거나 다시 배치한다. 이전 미션 문구가 남아서는 안 된다. 플랫폼에 없는 창은 해당 검증에서 제외 사유를 적는다.

영어38개 행동 문구와 대기 문구1개, 총39개 키를 같은 단계에 대응시킨다. 두 프로젝트의 현재 제공 언어인 영어·한국어를 우선 연결하고, 일본어39키는 각13차 언어 적용 때 함께 연결한다. 한국어는 외부 갈무리11과 AGENTS.md의 사제·신전·다리/유닛 표기 규칙을 따른다. 전체 키 개수575는 cpppj의 현재 번역표 수치이며 DN/WB에 같은 전체 개수를 강제하지 않는다. 누락·중복과39개 안내 키 대응을 별도로 확인한다.

상태·진행 값을 주입하지 않는 실제 F4 단계 변경과 F8 안내 재열기, 재시작·미션 전환·이탈을 확인한다. 전체40단계 조건 대응은 집중 검사로 확인하고, 포획/희생·특정 적 공격·승리 자연 전환의 실제 검사는 기존 사용자 허용 범위를 따른다. 튜토리얼 후반 해당 전환은 사용자 확인으로 남긴다. 다른 언어/화면비의 문구·줄바꿈·위치·배경 없음·입력 보존을 기록하며 cpppj의22검사/19GUI경로 통과를 DN/WB 검증 결과로 대신하지 않는다.

DN은 R5-4c3 중단 검증을 복구한 뒤 R5 표시/R6 수명에 맞춰 진행한다. WB는 보존된 HUD 앱 생성/World 도킹 초안과 State7 수명 연결을 검증한 뒤 이 기능을 별도 단위로 적용한다. 두 프로젝트의 목표 재개는 각 사용자의 재개 지시를 따른다. 현재 작업판은 [DN 인계](../LEFT_JOBS.dotnetpj.md#tutorial-objective-port)·[WB 인계](../LEFT_JOBS.webpj.md#tutorial-objective-port)에 있다.
