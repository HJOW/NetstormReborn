# dotnetpj 0.807 — 구 실행 경로 제거와 Netstorm.Game 이름 승계

2026-11-22 · HJOW-Athlon · 제품11.01. 사용자 요청에 따라 실행 프로젝트를 하나로 전환했다. 월드 플레이와 전체 목표는 아직 미완료다.

## 변경

구 `Netstorm.Game`의 근사 실행기·전용 UI/렌더러를 활성 소스에서 제거하고 직역 호스트 `Netstorm.Client.Host`를 `dotnetpj/src/Netstorm.Game/Netstorm.Game.csproj`로 옮겼다. 출력 어셈블리/실행 파일은 `Netstorm`/`Netstorm.exe`다. 내부 `Netstorm.Client`와 공유 Host API의 이름공간은 유지했다. 이동 전 호스트34파일 중 프로젝트와 진입 설명을 제외한32개 구현은 전체 바이트를 보존했다.

솔루션의 구 프로젝트와 GUID를 제거하고 새 호스트의 GUID를 유지해 Game 이름으로 바꿨다. 테스트 참조, L2/L4a 실제 실행 경로, PORT_MAP52경로, 현재 README/인계를 전환했다. 구 실행기의 전용 자동 실행 검사16개와 사용하지 않는 FontStashSharp 패키지 참조도 제거했다. 공통 Core 부품과 기존 검사는 유지했으며 이를 구 실행기 재진입 경로로 사용하지 않는다.

공통 `assets/Netstorm.ico`를 ApplicationIcon으로 지정하고 사용자 표시 버전을11.01, 카피라이트를 `Copyright 2026 HJOW`로 설정했다. 갈무리11 일반/굵은 TTF와 라이선스를 외부 fonts에 복사하며 관리 game-data 전체를 빌드/게시 출력에 넣는다. 게임 자료에 실행 파일/DLL/PHP가 섞이면 빌드에서 거부한다. 한국어 화면 결선과 사용자 홈 설정 저장은 여전히 후속 작업이다.

배포 스크립트의 필수 파일·라이선스·안내를 현재 경로에 맞췄다. 사용하지 않는 구 CLI와 settings.json 안내를 현재 `--set`/`--window`/크기 인자와 game-data/d/options.cfg로 교정했다. 초기 ZIP의 라이선스 경로에 남은 D2Coding 접두어를 최종 ZIP에서 교정했다.

## 검증

- 솔루션 restore/Release 전체 빌드 종료0, 오류0·기존 테스트 경고6. 새 실행 경로의 Host/옵션/글꼴/음향/로그/사용자 경로 집중 **143건 통과·실패0**다.
- 실제 Netstorm.exe의32×32·16×16 원시 아이콘2개와 그룹 메타데이터가 공통 ICO와 전체 바이트 일치한다. 공통 ICO SHA-256은 `bd4c18c5cb5f42bc49a1de0c6d6623643fd5377f575e95a1de60a05f01e4f068`이다. EXE의 ProductVersion11.01·카피라이트와 외부 글꼴/핵심 데이터 전체 바이트도 확인했다. 개발/게시 EXE도 바이트가 같다. DesktopGL 창·작업 표시줄 및 탐색기의 사람 확인은 별도로 남겼다.
- 실제 배포 ZIP **1,374항목·128.0MB** 생성/CRC 검사 통과. 관리 game-data 전체와 실행기/DLL/네이티브 라이브러리/글꼴/라이선스가 소스/게시본과 같고 구 호스트 이름·D2Coding·FontStashSharp·PDB가 없다. 기본 경로 입력의 빈 값 취소는 종료0이며 DryRun도 통과했다.
- ZIP을 새 폴더에 풀고 NETSTORM_DATA를 제거한 상태에서 동봉 Netstorm.exe로thewarbegins 진입이 종료0·0.804 전체 덤프 바이트 일치였다. 새 이름의 일반 빌드 대표3시작도 종료0·0.804 전체덤프/지표 일치다. 게임 플레이 완료를 뜻하지 않는다.
- 검사 Client DLL과 실행 폴더 DLL이 같고 실행6파일·원본1,392파일이 대표3수집 전후 불변이다. 원본 전체 해시는0.804와도 같다. Source/보호 원본/AGENTS.md와 README 한국어 개요는 수정하지 않았다.
- 등록418자료의 전체 행/머리말/해시는 그대로다. PORT_MAP은52개의 실제 이동 경로만 바뀌었으며1511자료행(port1023/L1 481/session7), 물리1516줄과 기존 기준 커밋/순서를 유지한다.

처음 프로젝트 삭제와 생성물 정리를 묶은 명령은 자동 승인 검토에서 차단됐다. 경로를 별도로 확인하고 구 프로젝트/생성물을 `extracted/dotnet-0807/` 아래에 보관하는 가역 이동으로 완료했다. 이 보관본은 활성 프로젝트/배포물에 포함되지 않는다. 홈의 기존 사용자 저장값은 삭제하지 않았다.
