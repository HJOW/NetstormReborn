**채취량 절반의 실제 생산 검증은 남는다.** 실제 본문의 목표 필드는3/6/6이지만 쉬움/보통은 이 구간에 각각1개까지 도달했다. 어려움의 계수7을 포함해 실제 누적 생산량이나 엄격한 개체 상한이3/6으로 같다고 판정하지 않는다. 연결된 간헐천과 생산/회수 시점의 영향을 분리하는 후속이 필요하다. 기존 Node 계약의 절반·최소1과 이번 실제 목표값 확인을 실제 생산량 증명으로 확대하지 않는다. 소유자별360~600초 다리 정체의 C++ 오라클 대조도 남는다.
