# 0.653 AI 지역 경계 live 연결 (R4-5)

- 일시: 2026-11-19, HJOW-Athlon
- 범위: AI 준비·전략의 지역 경계 조회를 같은 섬 런타임으로 연결하고 세션 결선 검사. 매 프레임 호출과 나머지 미이식 하위는 잇지 않는다. 사제 포획·희생·승리 재현은 사용자 확인 범위라 건드리지 않는다.
- 목표: R4-5 입력 중 지역 경계 조회를 잇고 신전이 없는 경로의 준비·초기를 실제로 실행한다.

## 이식 (증거)

- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`: `AiRegionBounds`·`AiIslands`를 추가하고 준비·전략의 `RegionBounds` 갈고리를 같은 섬 런타임 조회로 이었다. 근거: cpppj `src/client/RawCampaignSession.cpp` 2866·2872행의 `regionBounds` 조립이다. 청크 int 경계의 16배 float 변환과 같다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionAiRuntimeTests.cs`: 신규 2건(적 경계 중심 기록·자기 영역 중심과 258 기록). 섬 기록·경계·Player 지역·기술 부모를 두고 `PrepareAi`·`InitializeAi` 실제 호출로 대조했다.
- `InitializeAi` 전체 경로는 기술 부모·SeedBridges·신전 조회·258 기록까지 실제 몸체로 실행한다(신전 없음·생산 없음·추가 다리 없음).

## L1 (증거)

- `Release` 빌드 오류 0(경고 6, 기존과 동일).
- `HostSessionAiRuntimeTests` 6/6 통과.

- 사용자 지시에 따라 정기 전체 회귀는 0.656에 수행한다.
