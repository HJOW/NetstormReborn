# WB04-E846 Session 무승부 거절

기준선 `225553df`의 `RawCampaignSession::RejectDraw`를 이식하고 Client 종료 프레임의 실제 Session에 연결했다. 현재 `6F 00 00` 거절 패킷을 기존 Player 참여 처리기에 먼저 넘겨 로컬 안내와 각 Player의 동의 비트 정리를 수행한 뒤 같은 패킷을 기존 방송에 보낸다. 안내가 실패하면 앞선 원본 호출이 중단되어 비트 정리와 방송을 실행하지 않는다.

실제 1-1 Fort의 내부 로그인 후 일반 전투 조건과 무승부 기한을 시험용으로 구성해 Client 프레임 → 같은 Session → 6F 거절 경로를 실행했다. 안내 다음 Player 동의 비트가 지워지고 길이 6의 패킷이 방송 장치에 전달되는 순서를 확인했다. 상대 peer와 안내는 관측용 함수다. 안내 실패 시 상태와 방송이 보존되고 Session 반납 뒤 접근이 거부되는 것도 확인했다. 실제 앱 루프·안내 UI·일반 스커미시 수명은 아직 남았다. 원본 게임 창은 실행하지 않았다.

검증: Client 전투 종료 프레임 집중 검사 3건, Node v26.13.0 전체 6,356건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E843의 Node v22 전체 검사 뒤 v26 회귀 3/8회다.
