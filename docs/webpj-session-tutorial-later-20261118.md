# WB04-E780 Session 튜토리얼 3~6 판정 연결

cpppj `RawCampaignSession.cpp`의 `MakeTutorialLater`를 로그인된 같은 Session의 현재 Player·사제 조회·Graph·생산·지역·제작 장부·TYPE/사건 전역과 미션 게이트에 연결했다. 실제 사제 HP 절반 판정도 원본의 signed 정수 및 정수 나눗셈으로 이식했다. 화면 선택·시계·안내는 호출자가 제공한다.

실제 로그인 Session과 게이트에서 튜토리얼 4의 옵션·생산 목록 및 전역/로컬 제작 수 비교, 5의 기술 사건, 6의 사거리 사건과 제작 수 판정을 확인했다. 테스트는 Player 포획·희생·공격·승리·자연 완주와 세 공중 유닛의 전용 행동을 실행하지 않는다. 튜토리얼 3의 포획 관련 분기 및 실제 사제 HP 판정은 사용자 제한에 따라 정적 이식으로만 남는다. 공통 미션 프레임·실제 UI·GameWorld·앱 결선은 남는다.

Node v26.13.0 전체 회귀 6,283건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 오류는 0건이며 E779의 Node v22 전체 회귀 뒤 첫 번째 v26 회귀다.
