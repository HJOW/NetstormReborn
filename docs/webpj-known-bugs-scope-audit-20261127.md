NB01은 E1436에서 실제 +324 목록과 잘못 읽던 +338 개수의 차이를 고쳤고 E1445에서 실제 AI3709초/오류0을 확인했다. 이는 CPP의 기존 미확정 판정을 웹에서 완전 해결로 덮어쓸 근거가 아니다. NB06·13·19·21·25·26·27·28·32도 원본의 재현 조건 또는 정상 동작 자료가 부족하므로 임의 규칙을 새로 만들지 않았다. 해당 자료가 생기면 그 항목을 다시 열어 수정한다.

원격 클라이언트 증상이 웹 범위 밖이라는 판정은 내부 단독 전송 모듈 전체를 제거한다는 뜻이 아니다. 실제 미션의 같은 프로세스 안 패킷/Host는 계속 포함한다. Edit/UCM/공식 존/MP 세션 UI는 기존 사용자 범위 결정대로 제외한다. CP 원본 수정/디컴파일·추가 게임·포획/희생·특정 공격·허용 밖 승리는 하지 않았다. 실제 스커미시 진행/승리는 E1437/E1439/E1443, Outpost 건설/금지는 E1447/E1448의 완료 근거로 남긴다.

10차의 막연한 'CPP 대조/스커미시 검증 남음'은 이 분류와 기존 실행 근거로 정리한다. **34개 버그를 모두 수정했다고 선언하지 않는다.** 위10개 자료 필요와4개 원증상 확인은 기존 공통D4 및 사용자 확인 범위다. E1453 작성 입력 고정 중 문서만 마감했으므로 두 전체 종료 뒤v26/v22에 각각1개 이월한다.
