# 한국어 생산 정보와 TYPE 도움말

WB04-E1057은 프로젝트의 `assets/unit-names.korean.json` 전체 명칭을 한국어 번역표에 반영하고 생산 정보의 소유자·속성·분류·비용과 전용 도움말의 체력·사거리·피해·에너지 문구를 번역한다. 원본 TYPE class 이름도 사용자 규칙에 맞게 표시하고 `%s`, `%d`, 색상 및 그림 태그는 보존한다.

Chromium에서 한국어 Tutorial1의 실제 다리 생산 항목을 우클릭해 한국어 정보 메뉴와 도움말을 열었다. 이어 실제 썬더 워크샾 TYPE 명령을 큐에 넣어 한국어 능력치와 원본 그림을 확인했다. 두 화면을 직접 살펴 메뉴의 제목·정보·비용과 도움말의 그림·정보·본문을 확인했다. 미번역 Tutorial2의 영어 대체도 재검증했다. 공통 이름 및 서식 비교·한국어 도움말·자산 복사 검사를 포함한 Node 26 관련 30건과 Chromium 2건이 통과했다.

다른 생산·객체 메뉴의 실제 조작과 나머지 미션 대본의 번역·검증은 남았다.
