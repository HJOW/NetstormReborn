# WB04-E924: 확정 문자 사건과 원자적 큐

cpppj `DisplayTextInput`의 확정 문자 사건 핵심을 웹에 옮겼다. ASCII·Windows-1252는 원본 한 바이트 사건이고 한국어·일본어 등 기존 표시 확장 문자는 Unicode 코드 포인트를 담은 한 태그 사건이다. 같은 프로세스의 표시 codec으로 태그를 실제 네 바이트로 되돌린다. 전체 문자열과 좌표를 검증한 뒤 E923의 원자적 일괄 큐를 사용하며 제어문자·미지원 문자·큐 부족 시 일부 사건을 넣지 않는다.

영문·1252·한국어, 태그와 실제 표시 바이트, 잘못된 Unicode·제어문자, 공간 부족과 이전 큐 보존을 검증했다. 표시 codec 전체 범위 및 기존 원본 편집 입력을 포함한 관련 Node 검사 24건이 통과했다.

이는 확정 사건과 큐 경계에 한정한다. 기존 원본형 편집기는 아직 태그와 다중 바이트 선택·삭제를 소비하지 않고, 브라우저 IME와 일반 텍스트 이벤트도 아직 연결하지 않았다. `DisplayTextInput.cpp`의 나머지 문자열 선택·클립보드 기능은 별도다.
