# WB04-E841 Client 개발자 명령 입력 큐

기준선 `225553df`의 `MakeCampaignClientServices`가 사용하는 개발자 입력 예약을 Client의 현재 `InputQueue.pushCommand`에 연결했다. 호출 시마다 현재 큐를 조회하고 두 인수의 DWORD 비트를 signed 좌표로 보존하며, 명령 정규화와 39개 보관 한도는 실제 원본 입력 고리에 맡긴다. 같은 연결은 신전 이탈 명령의 입력 장치로도 사용할 수 있다.

실제 1-1 Session에서 31h 개발자 패널 크기 패킷을 분배해 같은 GameAux의 행·열 변경과 실제 입력 큐의 예약 결과를 확인했다. 별도 검사에서는 큐 교체 뒤 현재 큐 조회, 음수 비트 변환, FIFO 및 가득 찬 큐의 새 명령 폐기를 확인했다. 검사에서 Client의 입력 소유자는 큐를 제공하는 간단한 경계이며 실제 브라우저 앱 Client 조립과 후속 패널 입력 소비는 아직 남았다. 원본 게임 창은 실행하지 않았다.

검증: 큐 집중 검사 1건과 Session 패킷 통합 1건, Node v26.13.0 전체 6,342건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E835의 Node v22 전체 검사 뒤 v26 회귀 6/8회다.
