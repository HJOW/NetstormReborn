# 미션 도움말 그림과 본문 배치

WB04-E1055는 실제 미션 TYPE의 Help 프레임을 도움말 창의 원본 157×126 배경 안에 표시한다. ImageGump의 단위 배율 기준점과 프레임 사각형으로 SHP를 배치하고 153×122 자식 영역으로 자른다. 원본처럼 그림이 있을 때만 본문을 y=153으로 내리고 없으면 y=17을 사용한다. 다른 주제로 전환하거나 Back을 누를 때 현재 TYPE 그림을 해제한다.

실제 Tutorial1 다리와 썬더 팩토리 TYPE으로 정보·그림을 만들었고, Chromium에서는 썬더 팩토리 명령을 입력 큐로 넣어 정보 행, 그림 배치와 실제 불투명 SHP 픽셀이 Canvas 화면에 출력되는 것을 확인했다. 기존 F1 스크린샷·한글·ImageGump 등을 포함한 Node 26 관련 40건과 Chromium 1건이 통과했다. E1047 고정 전체 회귀는 Node 22와 26 각각 6,568건 통과, 실패·취소·건너뜀 0이다.

실제 생산 메뉴에서 썬더 팩토리 항목을 선택하는 브라우저 경로 및 타입별 원본 화면 픽셀 비교, 다른 객체 메뉴와 자연 미션 완주 검증은 남았다.
