# webpj 훨리기그 전용 비행 RawSunFlyerFrame (WB04-E357, 2026-11-13, 7-P1 비행 유닛 부품)

3.1절 7-P1 여섯째 항목 "RawSunFlyerFrame 184줄"(기준선 `.h` 55 + `.cpp` 127 = 182줄 근처, 대응표 줄 수 184)을 `core/raw-sun-flyer-frame.js` 로 옮겼다. 훨리기그(73)가 폭탄(163)을 떨어뜨리는 **전용 비행**의 초기화(45bd00)·통지(45bd60)·폭탄 정리(45be00)·홈 통지(45beb0)·장식 프레임(45be40)·전용 Frame(45d2c0)·복귀 지연(45e170)을 담는다. E352 의 `FlyerProcessFields`(`bytes` 112 + `sunTail` 24)를 하나의 136바이트 원문으로 읽고 쓰며, 공통 제어는 E355 의 `RawFlyerFrame`(통지/홈 통지) 훅과 `baseFrame` 훅으로 이어진다.

## 1. 규칙

- **구성:** `new RawSunFlyerFrame(pool, shapes, types, globals, hooks)` — 풀은 PATCH, SHP 표(`{ loaded, frameCount, frames:[{ cellWidth }] }`)는 188칸의 **살아 있는 참조**, 폭탄 TYPE 표(`{ fallingFrames, explosionFirst, explosionEnd, sound }`)는 188칸 **만들 때 사본**이다. 전역 네 개(`boss`·`paused`·`now`·`bombType`)는 현재 값을 읽는 함수이고, 훅은 `assertion`·`robust`·`destroy`·`unpop`·`pop`·`repop`·`mayTarget`·`create`·`sound`·`runCount`·`baseFrame`·`baseNotify`·`baseParentDying` 이다. 선택하지 않은 경계는 요구하지 않고 선택된 누락은 앞선 쓰기를 남긴 채 거부한다.
- **필드(+96 폭탄 번호·+104 투하 시각·+112 다음 투하·+120 다음 폭발 프레임·+128/+132 저장 좌표):** 읽기/쓰기는 offset 이 112 미만이면 `bytes`, 이상이면 `sunTail` 로 가며 두 배열을 이어진 포인터로 취급하지 않는다. 폭탄 번호는 DWORD 전체를 읽어 65535 를 넘으면 범위 오류로 거부한다.
- **`initialize` (45bd00):** 투하 시각 0·폭탄 0·저장 좌표 둘 −10000(float)·공격/착륙 0·최초 20초 타이머(72) = now + 20·초기화 표식 1. **`notify` (45bd60):** 메시지 1 만 전용(info1 0: 공격 해제·다음 투하 0, 아니면 다음 투하 = now + 2), 그 밖은 공통 통지 훅. **`clearBomb` (45be00):** 폭탄 번호가 0..65535 이면 유효성 훅(`robust(번호, true)`)이 참일 때 삭제(0x10)하고 항상 번호를 0 으로 쓴다(DWORD 가 그 밖이면 훅 없이 0). **`parentDying` (45beb0):** 폭탄 정리 뒤 공통 홈 통지 훅.
- **`frame` (45d2c0):** 초기화 전이면 초기화 → 부모 정지(+40 의 0x20)면 boss 삭제 후 반환 → 폭탄이 있고 정지가 아니면 폭탄 처리: 공간 해제(폭탄 +11 의 비트 4 가 없을 때)·프레임(부호 있는 값) < 낙하 프레임 수이면 **낙하**(천장 = 부모 y + 4 를 float 로, 경과 = now − 투하 시각을 float 로 저장, 왼쪽 = x − SHP 폭/2, 낙하 = (경과 × 9 + 10) × 경과 + 부모 y, 천장을 넘지 않으면 낙하 값을 y 로, 프레임 = (프레임 + 1) 을 낙하 프레임 수로 나눈 나머지, Pop; y ≥ 천장이면 폭발 첫 프레임), 아니면 **폭발**(다음 프레임 기한이 지금 이하면 프레임 +1·끝 이상이면 정리 후 전체 반환·그 밖은 바이트 35 = 0xed·기한 = now + 0.03999999910593033, 그 뒤 Repop) → 부모가 저장 y 보다 아래이면 Unpop 후 Pop(y − float 0.05) → 발사 가능(현재 부모, 필드 +12 의 WORD 표적)·다음 투하 기한(0 이 아니고 지금 이하)·폭탄 없음이면 새 폭탄(전역 폭탄 TYPE, flags 2)을 만들어 flags |= 8·프레임 0, 번호·투하 시각·저장 좌표를 쓰고 부모를 Unpop → Pop(y + 0.4) → 소리(생성 폭탄 TYPE 의 소리 토큰)·다음 투하 = now + 2 → 마지막으로 공통 `baseFrame` 훅.
- **`animation` (45be40):** 개수를 float 로 저장하고 (Form WORD fmod 0.14535599946975708) × 6.8796610832214355 + now 를 다시 fmod 한 위상으로 `(개수 − 1) × 위상 × 역수`를 float 로 저장한 뒤 0.5 를 더해 0 방향 절삭한다(비유한·정수 범위 밖은 거부). **`returnDelay` (45e170):** float 60.

- 한 문자열 치환 변형 193회를 적용했다. 1차에서 59개가 남았고 그중 47개는 **시험의 공백**이라 보강해 잡았다. 원본 관측 440행이 쓰는 입력이 좁아(폭탄 TYPE 3/4/6·SHP 20프레임·SID 100 미만·낮은 DWORD 가 0 인 시각 값) 위의 웹 계약 항목들이 가려져 있었다. float 저장 단계는 탐색으로 입력을 구성했다: 장식 프레임은 큰 개수(16777217 이상)에서 주기 상수·개수 float·값 float 가 각각 정수를 바꾸는 입력을, 낙하는 경과 시간의 float 저장이 폭탄 y 를 바꾸는 입력을 골랐고, Pop 좌표는 훅이 받은 수가 float 값인지로 직접 확인한다.
