- `dotnetpj/src/Netstorm.Client/Host/HostSession.SavedState.cs`: 신규. `BuildSavedStateDevices`가

  소비자에서 잇는다. 1.061에서 추가했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSavedStateTests.cs`: 신규 4건. 미조립·누락·
  중복 거부, 세션 값의 전역 반영, 기한 폴링의 한 번 저장·10초 예약, 없는 파일의 0 복귀를
