# 운반체·파생 객체 메뉴 한국어 문구 추가 (WB04-E1140)

E1138 에서 운반체(Bulf·Walker)와 파생 객체 메뉴를 앱에 연결하면서, 한국어 모드에서 이 메뉴의 일부 문구가 영어로 남는 것을 확인했다. `translations/xlat.korean` 에 없는 문구를 더했다.

## 확인

- 한국어 모드(`?lang=ko`)에서 사제 우클릭·건설 하위 메뉴는 이미 번역되어 있었다(`사제 레벨 I`, `소유자: 당신`, `건물 건설`, `신전 ›`·`워크샾 ›`, `1단계 제단 건설 (500)`).
- 운반체 메뉴 본체(`raw-carrier-menu.js`)와 파생 객체 메뉴(`raw-object-menu-variants.js`)가 번역 장치로 요청하는 문구 중 번역표에 없는 것이 있었다. 번역이 없으면 영어 원문이 그대로 나온다.

## 추가한 문구

| 영어 원문(키) | 한국어 |
| --- | --- |
| `~wNothing` | `~w없음` |
| `~r~E(Not while paralyzed)` | `~r~E(마비 중에는 불가)` |
| `~r~E(Not while flying)` | `~r~E(비행 중에는 불가)` |
| `Carrying: ~i%s~.\n` | `운반 중: ~i%s~.\n` |
| `%sDrop~. ~i%s~. %s` | `%s내려놓기~. ~i%s~. %s` |
| `%sCast~. ~i%s~.~[I%d.*] %s` | `%s시전~. ~i%s~.~[I%d.*] %s` |
| `About %s` | `%s 정보` |
| `for %s%d~[IfortGump.3]` | `비용 %s%d~[IfortGump.3]` |
| `Meltdown!` | `멜트다운!` |
| `Storm Power: ~i%d~.\n` | `스톰 파워: ~i%d~.\n` |

번역 문구는 개발자 검수 대상이다. `Detonate!`·`Turn To Obelisk!`·`Turn To Spell!` 은 코드에서 번역을 거치지 않는 리터럴이라 원본처럼 영어로 둔다.

## 시험

- `tests/korean-ingame.test.mjs`: 두 소스 파일의 `format`/`translate` 문자열 리터럴을 직접 뽑아 한국어 번역표에 모두 있는지 본다(앞으로 문구를 더하면 번역표도 더해야 시험이 통과한다).
- 한국어 모드에서 실제 Bulf 를 우클릭해 `… 레벨 I / 소유자 / 속성 / 분류 / 회수 획득 / 정보 / 플레이어` 가 한국어로 나오는 것을 화면으로 확인했다.

## 남은 것

- 제단 업그레이드·`Get 5,000` 등 HTML 기술 목록 문구(`Upgrade Altar to Level %d` 외 4개)는 화면이 아직 앱에 없어 번역을 넣지 않았다.
- 운반체가 내용물을 실을 때의 `운반 중`·`내려놓기` 항목은 문구만 번역했고 실제 화면 확인은 하지 않았다.
