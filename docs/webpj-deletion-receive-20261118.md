# WB04-E733 일반 삭제 수신

`2eh` 삭제 패킷을 8바이트로 등록하고 현재 Session의 월드와 공유 SP 저장소에 연결했다. 수신기는 권한 진단과 타입 로그 뒤 살아 있는 슬롯의 조건부 환급·삭제를 수행하고 SP 추적을 감사한다. 빈 슬롯의 감시 Form은 중복 삭제 로그에서 제외한다. SP 감사는 첫 표본과 조건부 SP 조회 뒤의 표본을 구분하며 현재 추적 오프셋·첫 배열·첫 순열을 사용한다.

근거는 기준선 `225553df`의 `RawSquidMutationReceive.cpp`와 `RawCampaignSession.cpp`다. 수신기 행의 근거 커밋은 `541624a9`이며 기준선 이후 해당 파일 변경은 없다. 새 원본 fixture는 추가하지 않았다.

독립 검사에서 권한 진단·환급·삭제·감사 순서와 빈 슬롯의 타입 분기를 확인했다. Tutorial 1 통합 검사는 실제 분배기에서 빈 감시 슬롯의 수신과 SP 감사까지 확인했다. 집중 검사 30건이 통과했다. 실제 미션의 삭제 왕복과 앱 연결은 아직 검증하지 않았다.

Node v26.13.0 전체 회귀 6,205건을 통과했다. 대응표 오류는 0건이며 Node v22 전체 재검사 주기는 3/8회다.
