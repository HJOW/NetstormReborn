# 첫 캠페인 후속 미션 진입과 섬 경고 (WB04-E1014)

Struggle For Freedom의 SaveTheIsland·FragileFortune·ThunderingPower·DissolvedAlliance를 실제 목록의 선행 완료 조건 및 Guide·World 경로에 연결했다. 마지막 미션의 첫 실행에서 섬 피격 때 Tell 소비자가 없어 프레임이 멈추는 문제를 발견하여 사제 방어·생산 비용과 함께 현재 앱 Tell 창에 연결했다. 별도 WarningMessages의 비미션 경고 삭제 경계는 아직 연결하지 않았다.

각 미션에 테스트용 선행 완료를 기록한 뒤 Chromium 실제 목록·브리핑 종료와 게임 시계 6초를 확인했다. 마지막 미션에서는 실제 전투 중 islandUnderAttack Tell 호출도 관찰했다. 피해 처리와 앱 Node 검사 21건이 통과했다. 목표 수행과 승리·자연 완주, 나머지 캠페인과 HUD는 미검증이다. E1006 고정 Node 22 전체 6,559건 통과, Node 26 전체 회귀 실행 중이다.
