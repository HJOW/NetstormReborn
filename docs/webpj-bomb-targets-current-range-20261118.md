# 주문 표적 검색의 현재 사거리 (WB04-E681)

기준선 `225553df`의 `RawBombTargets.cpp`와 일치하도록 기존 명시 반경 배열 생성자에 더해 현재 TYPE 레코드의 `range`를 직접 읽는 생성자 경로를 구현했다. 조회할 때마다 슬롯의 현재 TYPE과 해당 필드를 다시 읽으므로 Session이 별도의 사거리 사본을 유지하지 않는다. 기존 명시 반경 배열 경로와 signed 정수화는 보존한다. cpppj 해당 소스는 기준선 뒤 변경이 없다.
