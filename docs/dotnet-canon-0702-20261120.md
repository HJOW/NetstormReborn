# 0.702 내부 미션 Source와 전송 조정기

`CompositeMissionTransport.cpp/.h`의 내부 미션 분기를 Net에 이식했다. 같은 실제 Registry·canonical 등록표·내부 두 끝을 유지하며 생성 시에는 열지 않는다. 실제 서버 권한에서 listener를 열고 상태8에서 Client9만 연결하며 수락은 Poll에 남긴다. 이미 열린 listener는 다시 만들지 않는다. 송신은 현재 실제 backend를 선택하고 등록값의 실제 Session 대여와 Source 대여를 송신 끝까지 유지한다. mutable 관찰1은 하위에서 한 번만 실행한다.

Flush는 현재 정상0..21, Poll은 listener 수락→pending-1..-31각1회→정상0..21의 현재ID별 반복을 조립한다. 이전 Source가 소유한 실제 노드도 같은 Registry 가상 flush/수신으로 보낸다. 현재 자기 노드가 아닌 연결 조회/송신은 거부한다. 방 종료는 자기 정상/pending/내부 listener만 정리하고 다른 Source의 표는 유지한다. 실제 수신 예외 뒤에도 두 Poll guard를 반납한다.

`ClientPacketSources.cpp/.h`의 내부 coordinator 경로를 이식했다. 장부와 next7용 weak 배송은 같은 실제 장치를 약하게 기억한다. 실제 노드 주소로 최신 경로를 선택하고, 등록 노드·배송·동기 호출은0.690의 실제 `ConnectionDeviceLifetime`을 빌린다. 외부 Source 소유권을 반납해도 실제 대여가 남으면 장치 반납을 미룬다. App 최종 정리는 실제 Source를 먼저 보유하고 노드→listener 뒤 약한 장부를 비운다. 장부는 실제 노드 생성 전에 게시해야 한다.

실제 내부 로그인/재배치/Client9 응답, observer 단일 호출과 Player 원문 불변, 기존 listener 보존, 같은 node만 Source 선택, 외부 반납 후 등록/배송 수명, 새 Source에서 이전 server1의 type2 종료/반납, 다른 Source의 방 보존, pending각1회와 callback 후 현재 정상ID 교체, 수신 중 반납/중첩 거부, 실제 수신/외부 가상 수신의 예외 복귀, 최종 Shutdown을 확인했다. 장치 순서 단위 검사는 명시 외부 가상 callback을 사용하고, 실제 내부 로그인과 이전 종료는 같은 제품 LocalMissionTransport/Registry를 사용한다. 독립 PE에서 coordinator 전체를 관찰한 신규 fixture 검증으로 확대하지 않는다.

초기 빌드는 검사 장치의 `ReadPlayers` 오기 때문에 실패했고 `Players`로 수정했다. 다음 실행은27통과·3실패였다. 실패는 검사 설정/기대가 원문 계약과 달랐기 때문이다. 실제 type2 종료는 데이터프레임 소비 수에 포함되지 않으므로0을 기대하고 실제 종료 수신기에서 같은 노드 close를 연결했다. 현재 칸 교체에는 찬 칸 진단을 내는 Register 대신 실제 PublishConnect를 사용했다. callback 활성 관찰에는 실제 등록 대여를 먼저 만들었다. 제품 본체/원본 fixture는 변경하지 않았다. 해당3건 재검사 통과, 중복 Shutdown 검사1개를 제거한 현재 고유29건 모두 통과다. 근거는 `extracted/dotnet-0702/core-initial.log`, `core-final.log`, `core-corrected.log`와 대응TRX, `verification-summary.json`이다. 기존 경고3개는 유지됐고 새 경고는 없다. `cpp_sync.py` 종료0, fixture356개를 유지했다.

범위는 InternalMission이다. 실제 Editor/LAN backend와 Meta network 재인계·RebindWorld/서버 인수, 전체 MissionNetwork 배송은 후속이다. 해당 역할 생성은 명시 실패한다. 제품Root에는 아직 설치하지 않았다. 다음0.703은 Clock 동기화, 정기 전체 회귀는0.704다. 실제 게임/공격/포획/희생/승리 재현은 수행하지 않았고 전체 목표는 진행 중이다.
