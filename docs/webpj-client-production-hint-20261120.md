# Client 생산 실패 안내

WB04-E1031은 원본 ProductionHintGump를 같은 Client TextGump·StyleText·글꼴·팔레트·번역·Gump 수명에 결합했다. 항목 serial에서 현재 기준 노드를 찾아 생산 비용 부족 또는 재고 부족 안내를 만들고, 소유 문자열과 조각을 소멸자에서 반납하며 벽시계 4초에 지연 삭제한다. TextGump의 파생 노드용 가상 출력·소멸 경계를 추가했다.

Tutorial1 앱의 실제 글꼴·번역·픽셀 표면에서 안내 출력과 4초 만료·삭제를 검사했다. 기존 원본 10.78 안내 관측 126행을 포함한 관련 Node 검사 13건이 통과했다. 실제 생산 패널의 실패 경로와 브라우저 화면 설치는 남았다. E1030 고정 Node 26 전체 회귀는 실행 중이다.
