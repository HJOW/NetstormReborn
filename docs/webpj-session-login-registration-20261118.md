# Session Login 실제 분배기 등록 (WB04-E712)

서버·클라이언트 Login이 모두 준비된 뒤 같은 내부 분배기에 31h 개발자 명령 관찰기, 27h/63h 서버, 클라이언트 8종, 72h 메타데이터, 32h 설정, 71h 설명과 64h 연결 활동을 원본 순서로 등록한다. 준비 전·중복 등록은 거부하고 등록 도중 실패하면 같은 전송 수명을 반납한다. 개발자 명령 해석기는 아직 없어 실제 호출 시 명시 오류다.

실제 Tutorial 1 자산으로 구성한 Session owner와 내부 전송에서 등록된 처리기·현재 설정 수신을 확인했다. 이어 실제 내부 서버를 열고 State8이 Client9를 연결한 뒤 State9가 0x27 로그인 송신을 내부 큐에 넣고 State10을 확정하는 것까지 확인했다. 큐를 서버에서 처리하거나 응답을 왕복하지는 않았다. 원본 fixture와 관련 집중 검사 74건이 통과했다.

41h 채팅·52h 종료·3dh/78h 동맹 등록, 개발자 명령 해석기, State7·Begin/Pump, 서버의 실제 로그인 처리/응답 왕복, 외곽 Session 연결과 기준선 뒤 32커밋 전체 판정은 미완료다. 짧은 내부 분배기의 등록 수명과 장기 외부 대여의 전체 정리 증빙은 4D-5/8에서 재대조한다. 게임 창·실제 플레이·사제 포획/희생·자연 승리·공중 3종 전용 행동은 실행하지 않았다.
