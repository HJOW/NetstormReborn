# WB04-E792 지연 World 팔레트와 실제 커서

`CampaignGameWorld.setPalette`는 현재 256색을 같은 물리 BGRX 순서로 보관하고 같은 공장 표시기에 적용한다. 로그인 중 커서가 아직 없으면 색을 값으로 보관하고, 실제 Session Ready 이후 `completeLocalConnection`에서 같은 커서에 적용한 다음 보류 색을 지운다. 이미 커서가 있으면 현재 커서에 바로 적용한다. ColorSort 고정 논리색과 맵은 원본처럼 같은 현재 참조를 사용한다. 로그인 시작과 State7 준비의 중복 관문도 전체 Load 완료 여부가 아닌 실제 커서 몸체 존재를 확인한다.

TheWarBegins 실제 로그인 준비에서 호출자 팔레트를 변경한 뒤에도 보류 색 사본이 유지되고, Ready 전에는 공개되지 않으며 완료 시 실제 커서의 경고/비용 색과 공장 표시기에 적용됨을 확인했다. 이후 팔레트 변경은 같은 커서·표시기에 즉시 전달했다. 입력·선택 삭제·전체 Renderer와 브라우저 앱 연결은 남으며 이 검사는 실제 미션 플레이가 아니다.

검증: Node v26.13.0 전체 6,293건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 마지막 Node v22 전체 검사는 E787이며 이번 단위까지 이후 v26 전체 검사 5/8회다.
