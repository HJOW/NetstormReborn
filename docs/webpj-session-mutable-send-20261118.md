# WB04-E771 로컬 로그인 편의 진입과 mutable 송신

기준 `225553df`의 `RawCampaignSession.cpp` 4135~4142·4146~4149·4312~4316행에 맞춰 독립 로컬 로그인 편의 진입, mutable 원본 패킷 송신, 단일/자기 제외 대상 Tell 공개 경계를 연결했다. 편의 진입은 실제 Login을 시작하고 같은 State Poll과 Pump를 한 번씩 실행한 뒤 준비 상태를 검사한다.

기존 건설·Tell 부모는 현재 `owner.login`의 mutable 송신을 기대했으나 외곽 Session이 그 필드를 게시하지 않았고 Login에도 공개 mutable 송신이 없었다. 외곽의 실제 Login을 같은 owner에 게시하고 송신을 연결했으며 반납 때 참조를 지운다. 패킷 송신은 선택된 연결의 관찰기가 원본 버퍼 길이를 먼저 확정하고 큐에 복사하며 수신은 후속 Pump에서 진행한다.

TheWarBegins 실제 로컬 로그인 한 Session에서 31h 패킷의 길이 확정·큐 복사·지연 수신, 70h Tell 작성·관찰·수신을 연속 확인했다. 설치 전·로그인 없는 설치 상태·반납 후 호출도 검사했다. 집중 검사 1건이 통과했다. Editor/LAN 전송과 실제 브라우저 UI 수명은 후속이다.

Node v26.13.0 및 v22.23.3 전체 회귀가 각각 6,273건 통과했고 실패·취소·건너뜀은 0건이다. 두 검사는 사용자 지시대로 순차 실행했으며 v24는 생략·호환 가정한다. 대응표 검사 오류는 0건이다. E761의 v22 검사 뒤 여덟 번째 v26 회귀를 마치고 v22도 실행했으므로 다음 v26 회귀부터 1/8로 센다.
