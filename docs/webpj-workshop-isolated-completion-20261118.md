# WB04-E774 실제 로그인 워크샾 격리 완공

E761의 같은 TheWarBegins 실제 로그인·Start·사제 메뉴·커서·3eh 워크샾 배치 검사를 이어갔다. 사제의 실제 이동 경로만 도착까지 실행한 뒤 해당 워크샾의 기존 6700 건설 재시도 Regular를 실행하고, 실제 건설·표시 프로세스를 시작·중간·완료 시각에 진행했다. 10초 건설의 중간 HP, 최대 HP, abstract 비트 해제와 건설·표시·사운드 Form 반납을 확인했다. 앞선 배치의 SP 3,000→2,200과 실제 패킷 검증도 그대로 유지한다.

최초 시도에서는 사제 도착 직후 건설 프로세스가 부착돼 있다고 잘못 가정해 실패했다. 현재 워크샾에 예약된 실제 6700 재시도 Regular를 확인하고 그 프로세스를 실행한 뒤 정상 진행을 검증했다. 테스트는 이 사제 경로와 해당 워크샾 프로세스만 선택적으로 실행한다. 전체 Kernel의 자연 프레임 순서, 후속 생산 및 브라우저 화면은 아직 남는다. 사제 포획·희생·특정 적 공격·승리와 사용자 제한 공중 세 종류의 전용 행동은 실행하지 않았다.

기존 집중 검사 1건을 확장해 통과했다. 게임 구현은 변경하지 않았다. Node v26.13.0 전체 회귀 6,277건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 검사 오류는 0건이며 E771의 Node v22 전체 회귀 뒤 세 번째 v26 회귀다.
