# Client Gump 직접 가상 명령 (WB04-E1004)

커서가 조각 수신 플래그와 수신 명령에 사용하는 직접 가상 호출을 실제 Client Gump 소유자에 공개했다. 기존 입력과 재귀 분배도 같은 처리기를 호출하며 직접 호출은 토큰 대신 원본 처리기의 DWORD 반환값을 보존한다. 삭제된 토큰과 반납된 수명은 거부한다.

실제 Gump 수명 및 커서 효과 Node 검사 17건이 통과했다. E998 고정 Node 22 전체 회귀는 6,558건 모두 통과했고 E994 고정 Node 26 전체 회귀는 실행 중이다. 앱 커서·생산 단축키와 다리 배치는 후속 작업이다.
