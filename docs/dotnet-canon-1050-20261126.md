# dotnetpj 1.050 — DI-4d Pan 본체와 세션·입력 결선

2026-11-26, HJOW-Athlon. DI-4의 마지막 조각이다. Pan 본체(4d6b54)와 목표 쓰기(497e00)를
이식하고 세션 카메라 조립과 메뉴 진입 결선을 이었다. 이로 DI-4가 닫힌다. 화면 이동·뒤집기·
실제 지도 영역·소리·중심 장치는 R5·R6에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Input/RawCameraPan.cs`: 신규. Pan 본체의 전역·갈고리와
  `ProcessCameraPan`·`RequestCameraDelta`를 이식했다. 근거: cpppj `RawCameraPan.cpp`의
  `ProcessCameraPan`(4d6b54)과 `RawEdgeScroll.cpp`의 `RequestCameraDelta`(497e00)다. 창 밖·
  뗌·대화창 관문, 팝업 정리 뒤 좌표 -1·비활성의 소비, 원문 signed 좌표·FTOL·Shift 축 선택의
  8분할 목표 쓰기, 현재 view와 이동량의 합(절반 가감 상쇄)과 재구성 증가를 보존한다. Shift
  상태 조회 의사 코드(가상 키 0x10)를 상수로 둔다. 1.050에서 추가했다.
- `dotnetpj/src/Netstorm.Client/Host/HostSession.Camera.cs`: 신규. `BuildCameraDevices`가
  같은 세션 카메라에서 저장·Commit·Present·Pan 갈고리를 조립하고 저장 위치를 초기화한다.
  근거: cpppj `UberGumpCamera.cpp`의 CommitCameraNow·CenterViewPoint·ApplyCameraFrame
  결선이다. 잠금·해제·마우스 위치·요청·Present→Commit은 실제 장치이며 화면 이동·뒤집기·
  변경 영역·정지·언어·소리·중심·포착·폴링·전역·팝업은 R5·R6 명시 거부다. 미조립 Pan·저장
  실행자는 메뉴 안전을 위해 거짓을 돌려준다. 1.050에서 추가했다.
- `dotnetpj/src/Netstorm.Client/Host/HostMenuInput.cs`: `CameraPan`·`SavedCameraKey` 진입
  갈고리를 두었다. 저장 숫자·기호 입력은 메뉴 명령보다 먼저 소비하고, 이동 전용 경로가
  소비하면 overlay·이동 통지를 건너뛴다. 미연결·미소비면 종전 흐름을 유지한다. 1.050에서
  수정했다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 제품 진입 경로에서 이동 전용 경로를
  미션 세션 Pan에, 숫자·기호 입력을 저장 카메라 분배에 맡긴다. 미션 없으면 거짓으로 종전
  흐름을 유지한다. 세션 조립 호출은 R5·R6 실제 장치와 함께 잇는다. 1.050에서 수정했다.
- `dotnetpj/tests/Netstorm.Client.Tests/CameraPanTests.cs`: 신규 5건. 관문 거부, 이동량의
  8분할 목표 쓰기, Shift 축 고정, 좌표 -1·비활성의 소비, 목표 쓰기와 재구성 증가를 대조한다.
  1.050에서 추가됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostCameraPanRootTests.cs`: 신규 4건. 미조립
  거부·거짓과 조립의 저장 초기화·중복 거부, 주입 갈고리의 Commit·Present·Pan·저장 실행,
  제품 결선 모양의 메뉴 진입을 대조한다. 1.050에서 추가됐다.
