# WB04-E836 GameWorld 프레임 연결

기준선 `225553df`와 후속 판정 `0817fa87`의 `GameWorld::RunFrame`, `PrepareKernelFrame`, `FinishKernelFrame`, 캠페인 `Step`을 이식했다. 접속 중에는 게임 프레임을 열지 않는다. 외부 프레임 시각이 있으면 현재 화면 영역 설정→실제 로컬 패킷 소비→같은 Session Kernel 실행→현재 자산 보기 갱신 순서다. 외부 단일 Kernel 경로는 준비와 후처리를 분리하며 Kernel을 중복 실행하지 않는다. 외부 시각이 없을 때 명시된 경과 시간은 독립 `Step`으로 누적한다.

실제 1-1 내부 로그인에서 접속 중 조기 반환, Kernel 준비·외부 단일 실행·후처리, 일시정지 및 잘못된 시간차를 확인했다. 시간 경과 뒤 운반 명령에서 원래 음향 요청이 선택돼 기존 미연결 검사 장치가 중단했다. 실제 소리를 재생하지 않는 명시 관찰 장치를 제공하고 요청을 확인했다.

사제·골렘·벌룬은 실제 World 선택→호버→이동 입력→40h 수신 뒤 사제는 경과시간 프레임, 나머지는 명시 Step으로 Session Kernel을 돌려 자연 도착했다. 표시용 객체 보기에도 목적지가 반영된다. 브라우저 앱·실제 Client 메인 루프·전체 Renderer·미션 완주는 아직 남는다. 원본 게임 창은 실행하지 않았다.

검증: 실제 로그인 및 세 운반 유닛 집중 검사 2건과 Node v26.13.0 전체 6,333건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E835의 Node v22 전체 검사 뒤 v26 회귀 1/8회다.
