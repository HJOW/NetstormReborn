# dotnetpj 0.843 — Native 기본 Dais/Path writer와 실제 FormPacket

2026-11-23, HJOW-Athlon. 실제 장기 Process 저장소에 기본 직렬화/송신 장치를 설치하고 기존 Dais/Path 본체를 연결했다. 전체 파생 직렬화와 Native Root/Load/Editor 공개는 계속 미완료다.

## 변경

- Native `RawSurfaceStorage.Processes`는 기본 직렬화/송신·현재 버퍼 prefix·진단 장치를 Host 앞에서 등록한다. 공장/수명과 함께 실제 Host 생성 때만 설치하며 장치 조회/작성/송신/World 대여를 앞당기지 않는다.
- 새 `RawSurfaceStorage.ProcessSerialization.cs`의 `WriteDefaultForm`은 같은 GameAux의2048BYTE 예약에 쓴다. `SerializeProcessForm`은 실제 Dais/RawPathProcess 클래스로 선택한다. Dais의 현재 헤더·식별자·dirty·parentChanged/force와 Path의 같은 Pool/현재 헤더·진단·TYPE+ec를 기존 본체에 전달한다.
- Packet은 범위 검사 뒤 현재 prefix의 배열 사본을 반환한다. 기존 `ProcessFormTransmission.Packet` API가 배열 반환인 계약을 유지한다. Transmit은 기존 `BroadcastProcessForm`의 양수 관문 뒤 실제 전체 가변 예약을 같은 observer에 넘긴다. 작성 길이/선언WORD를 합성하지 않는다.
- 실제 Host에 붙은 Dais는 부착 writer→observer와 Form→현재 PID 객체→전체 writer→대상 packet의 실제 경로를 사용한다. 현재 Runtime의 부분 전송 장치는 기본 writer로 빈 함수를 채우지 않으며 반납 뒤 기본으로 돌아온다.
- Construction/Gun/공중/타이머/애니메이션 파생 writer는 아직 없다. 미이식 파생을 일반 Host writer의 재귀/빈 반환으로 통과시키지 않는다. 일반/공유 Regular 공통 packet은 기존 Host가 처리하며 이번 파생 분배 완료로 세지 않는다.
- 이전 PORT_MAP1644자료행의 순서/값/base를 보존하고 새 부분 파일에2쌍을 추가했다. 자료1646(port1158/L1 481/session7), fixture453개, 대응626/1240단위·106,131/169,438줄은 그대로다. 부분 대응을 플레이 완료율로 해석하지 않는다.

## 검증

검사 도우미에서 실제 TYPE 저장소를 배열로 간주한 컴파일 오류와 protected PID API 접근을 바로잡았다. 제품 보호 조건은 바꾸지 않았으며 사전 로그를 보존했다. 최종 증분 Release 솔루션 빌드는 오류0·경고0, 새7/7과 확대 Core162·Client71 합계233건이 통과했다.

기존 독립 PE Path profile0의 PATCH32관측을 일반/전체 writer 양쪽의 전체2048BYTE로 대조했다. 현재 Dais 헤더·dirty/force·미작성 tail, 같은 전체 예약의 observer 수정, 다른 Pool/미이식 파생 실패, 현재 Runtime 우선, 실제 Dais Host 부착/PID/FormPacket도 확인했다.

같은 최종 실행 빌드의 대표3미션(thewarbegins/tutorial1/surrounded)은 종료0·90프레임 전체 덤프/지표0.836동일이다. 원본1392·실행6·제품/검사/대응1931파일이 관문 전후 불변이며 검사/실행 제품 DLL도 같다. fixture453개/생성 자료 동기화가 통과했다. 포획·희생·공격·승리 입력과 변경 없는 메뉴 반복은 하지 않았다.

근거: `extracted/dotnet-0843/`의 build/core/native-preflight 로그와 TRX, core.trx·client-final.trx·tests.json·port-audit.json·source-audit.json, capture-summary.json·capture-originals-audit.json·build-assemblies-audit.json·inventory.txt. M1 0/34·고정18/26·Native 정기35/83·플레이 불가는 그대로다.
