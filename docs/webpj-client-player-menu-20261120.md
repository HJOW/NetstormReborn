# 실제 Client Player 하위 메뉴

WB04-E1067은 같은 Session의 Player 기록·동맹·사제 상태, 미션·Fort·SP·전투 옵션을 원본 Player 메뉴 및 Client 메뉴 스택에 연결한다. 텍스트 명령의 정적 버퍼는 Session 수명으로 유지하며 실제 채팅·통신 장치는 상위 호출자에게 요구한다. 실제 Tutorial1 로컬 Player의 하위 메뉴와 자식 등록·반납을 확인했다. 검사에서 아직 앱에 설치되지 않은 채팅 입력의 귓속말 조회는 대체 장치를 사용했다.

Player 원본 관측 292행과 실제 미션 관련 Node 22·26 각 8건이 통과했다. 최초 실행의 기존 생산 정보 우클릭 검사는 무작위 다리 그림 중앙이 투명해 실패했다. 재실행은 통과했으며 실제 불투명 픽셀을 찾아 클릭하도록 교정한 뒤 두 Node 버전에서 다시 통과했다. 공통 객체 메뉴와 앱의 실제 채팅 입력·우클릭 연결은 남았다.
