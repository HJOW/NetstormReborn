# 0.713 명시 Runtime 호출 대여의 반납

현재 World/PostPop·Process·Factory·표시·전송·내용물/삭제/표면큰효과는Pin반환값을GC까지보유하지만실제Client의짧은RuntimeCall은IDisposable반납이필요하다. 일반IDisposable게임소유자는반환된강한참조일수있으므로모두Dispose하면안된다. `IRawRuntimeLease`로실제호출대여만구별하고 `RawRuntimePin.Release`가그대여만반납하도록연결한다. 실제Client RuntimeCall도이표식을구현한다.

기존호출계수/현재대여반납요청과후속효과가끝난뒤에만명시대여를반납한다. 두guard는이전에보유한값을먼저소비해중복Dispose와예외복귀를보존한다. 일반소유자는기존GC.KeepAlive계약을유지한다. HostSession에서실제World/건설효과로pin을전달하는결선은여전히후속이다.

집중현재152건(Core137·Client15)이모두통과했다. `extracted/dotnet-0713/core-corrected.log`/`runtime-scoped-core-corrected.trx`의Core는136통과/1실패였고, 공장검사의필수카메라장치가없는준비오류를보완한 `factory-corrected.log`/`runtime-scoped-factory-corrected.trx`의1건이통과했다. Client15건은 `client-corrected.log`/`runtime-scoped-client-corrected.trx`다. `verification-summary.json`은최신동일검사명으로덮어써현재152개통과를확인한다. 실제플레이·사제포획/희생·특정적공격·시나리오승리재현은진행하지않는다. 전체목표와M1은미완료다.

새6건은중첩Process계수/한번반납·예외복귀/일반IDisposable소유자보존·표시현재장치교체/카메라예외·실제Factory Unpop/현재대여보류반납·실제전체HostRuntime의마지막중첩반납/예외후재공개를검사한다. 기존PostPop/Factory/Process/표시/전송/Runtime집중회귀를함께확인했다.

최초일반집중명령은복원후공유MSBuild서버대기로진행되지않아그검사의dotnet/오케스트레이터만식별후종료했다. 소스변경없이 `--no-restore --disable-build-servers -m:1 -nr:false -p:UseSharedCompilation=false`로재실행했다. 첫재실행은Client의새Core형식using참조누락으로컴파일실패했으며이를수정한뒤위집중결과를확인했다. 초기실행/컴파일실패는통과건수에넣지않았다.

실제DN `thewarbegins` 시작1회는종료0·전체덤프0.712동일·원본1392SHA불변이다. 근거는 `extracted/dotnet-0713/smoke/thewarbegins/dn/`와 `smoke-summary.json`/`smoke.log`다. 영어1024×768창/음소거·시드1760000000·25ms/90프레임조건이다. cpp_sync종료0·fixture360개불변이며새marker는C++ shared_ptr호출수명을표현하는관리언어장치라새원본PE/L1확보로판정하지않는다.

다음0.714는실제HostSession의Player상태/단일고정뷰/동맹과현재공장헤더를장기소유자에연결한다. 읽기전용검토메모는 `extracted/dotnet-0713/next-player-adapter.md`다. 제품HostSession에는RawSurfaceWorld객체가없고원문장치들을직접조립하므로존재하지않는World에pin을전달하는수정을하면안된다. 같은실제기존소비자와건설효과에맞춘pin결선·고정App15F/전체로그인bridge는이어진행한다. 다음정기전체회귀는0.716이다.
