# 0.613 농지 월드훅 결선 (HostSession 실결선기)

- 일시: 2026-11-18, HJOW-Athlon
- 범위: R4-2 농지 잔여의 MayPlace 실결선. `HostSession.MakeFarmWorldHooks` 추가와 바인딩 섬 노출, L1 3건 검증이 중심이다.
- 목표: 0.612의 어댑터 결선기를 세션 장치(지형 공장·공간 해제·섬 소유자·청크 지도)에 묶어, Generate 현장에서 바로 쓸 수 있는 형태로 만든다.

## 원인

- 0.612에서 `MakeFortRandomPlacementHooks`(배치·생성·HP 다섯 갈고리 실결선)는 닫혔으나, 나머지 여섯 갈고리(지역·소유자·Pop·Unpop·Repop)는 호출자가 묶어야 했다.
- cpppj `RawNormalTerrainWorldBinding.cpp` 11행의 `MakeNormalTerrainFarmWorldHooks`가 그 묶음의 원본이다.

## 수정

- `dotnetpj/src/Netstorm.Core/Original/RawNormalTerrainBinding.cs`: 바인딩이 소유한 섬 런타임을 빌려주는 `Islands` 접근자를 추가했다. Generate 현장이 바인딩과 같은 섬 소유자를 읽는 데 쓴다.
- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`: `MakeFarmWorldHooks(islands, placement, hp)` 추가.
  - 지형 공장·공간 해제·지형 TYPE·섬 소유자가 없으면 명시 예외로 멈춘다.
  - 다섯 풀(세션·섬·파이프라인·공장·보상)이 같은 인스턴스가 아니면 `ArgumentException`으로 거부한다.
  - 배치·생성·HP 다섯 갈고리는 0.612 결선기에 위임하고, `ChunkRegion`(청크 지도)·`RegionOwner`(섬 목록)·`SetOwner`(다리 분배+섬 소유자)·`Unpop`(지형 공간 해제)·`Repop`(좌표 복원 뒤 지형 Pop)·`Pop`(지형 Pop)을 세션 장치에 연결한다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionFarmHookTests.cs`: 신규 L1 3건.
  - `WiresWorldHooks`: 실자료 장면(지형 Pop·요새 객체·섬 후처리·그래프·바인딩·파이프라인·보상)에서 열한 갈고리가 모두 연결되고, 지역·소유자가 바인딩 섬과 일치한다.
  - `RequiresDevices`: 장치 미연결 세션에서는 명시 예외로 멈춘다.
  - `RejectsForeignPool`: 외부 풀 파이프라인은 거부한다.

## 검증 (증거)

- `dotnet test Netstorm.Client.Tests -c Release --filter "FullyQualifiedName~HostSessionFarmHookTests"`: 0 실패·3 통과(약 1초).
- `dotnet build Netstorm.Client -c Release`: 0경고·0오류.
