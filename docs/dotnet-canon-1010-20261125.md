# dotnetpj 1.010 — R4-5b AI 배치 평가 본체 이식

2026-11-25, HJOW-Athlon. R4-5 하위 행동 본체 묶음의 여섯 번째 조각이다. cpppj
`o/RawAiDropEvaluation.cpp/.h`의 `RawAiDropEvaluation` 전체(DryDistance·
SupplyScore·Evaluate·ConsiderScore·Consider·ConsiderStored)와 2 구조체
(`AiDropEvaluationGlobals`·`AiDropEvaluationHooks`)를 DN
`Netstorm.Core/Original/RawAiDropEvaluation.cs`로 옮겼다. 세션 호출자
(R4-5b 나머지)와 매 프레임 실행(R4-5e)은 아직 잇지 않아 제품 덤프에는 영향이
없다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Core/Original/RawAiDropEvaluation.cs`: 신규. cpppj
  `RawAiDropEvaluation.cpp` 60행 전체를 직역했다. 부족 거리 Manhattan·
  1000-Manhattan 최고(0 제외·float 저장), 공급 반경 경계·C 첫 NUL·signed
  길이 한도·절삭/(길이+1), flags/group 우선순위 분배, 배치→평가→양수 동률→
  에너지 승인→Y/X/점수 쓰기·거부 시 부족 좌표 추가·현재 b00 로그, 외부 점수·
  3e8의 평가 뒤 읽기·승인 뒤 쓰기를 둔다. 원문 `double` 합산 순서를 지켜
  C# `float+int` 잔류를 피한다(1.009와 같은 함정). cpp의 `RiftTypeRecord`는
  DN의 `OriginalTypeRecord`으로 받는다. 1.010에서 추가됐다.
- `dotnetpj/tests/Netstorm.Core.Tests/RawAiDropEvaluationTests.cs`: 신규
  16건. cpppj `tests/AiDropEvaluationTests.cpp` 16건 전부를 옮겼다(부족
  좌표 추가는 실제 DN `RawAiDrySpots` 몸체를 쓴다). 1.010에서 추가됐다.
- `dotnetpj/PORT_MAP.tsv`: 2행 추가. `RawAiDropEvaluation.cpp/.h`→
  `RawAiDropEvaluation.cs`를 port로 등록했다(기준 13d23e51ce1f). 1.010에서
  추가됐다.
