# 0.719 실제 공장 Take·Form 호출의 외곽 대여

기존 RawSquidFactory의 Take·AttachForm·UnpopForm·PopForm 호출 guard에 직접 소유 경로의 현재 pin과 관리 실행 수를 연결했다. 기존 공간/분리/내용물/전송 장치는 바꾸지 않는다. Native Runtime 묶음이 있으면 그 묶음의 pin을 선택하며 명시 NULL도 직접 pin보다 우선한다. 묶음이 없을 때만 실제 Host가 공개한 직접 대여를 사용한다. 이 경계는 C++ 직접 caller의 소유권을 managed 명시 Dispose/반납 관문에 옮기기 위한 것이며 가짜 Runtime이나 성공 효과를 만들지 않는다. 생성자와 순수 Create를 새로운 세계 본문으로 감싸지 않았다.

관리 실행 수는 게임 값과 별개이며 pin이 정상 복귀한 뒤만 늘린다. 중첩 호출은 각각 현재 선택을 보유하고 실행 수를 내린 뒤 marker 대여를 반환한다. 일반 IDisposable 소유자는 기존처럼 보유만 끝낸다. 직접 경로도 중복 반납을 방지한다. 실제 Host의 지형/요새/최소 AI 공장3연결지점을 약한 장부에 등록해 공개전후·최종정리의같은함수값을전달하고, 아직 외곽 Runtime을 공개하지 않은 단계에도 진행 중인 실제 공장 효과가 있으면 전체 반납을 거부한다.
