# 앱의 미션 스크립트·Fort 준비 (WB04-E881)

`ClientMissionAssets`는 앱의 실제 `GameData`와 `GameAssets`로 `MissionScript`를 만들고, 스크립트의 `loadFort` 선택과 `fortSpec`에 따라 실제 Fort를 읽어 같은 TYPE 표로 해석한다. 이 준비 경계는 아직 메뉴 명령에서 호출하지 않는다. 스크립트 등록은 소유자가 반납하며 파일 부재·해석 실패도 등록을 정리한 뒤 원래 오류를 전달한다. 반환한 Fort는 Session이 인수할 수 있으므로 다른 실행에 재사용하지 않는다.

실제 앱 공통 저장소에서 Tutorial1이 `BridgeTheGap`을 선택하고 독립 Session에 적재하는 것을 확인했다. Chromium에서도 공개 자산으로 같은 미션을 준비·반납했다. 이는 원본 Guide 단계·브리핑·`MissionBegin`/`StartDemo` 명령이나 플레이 화면을 연결했다는 뜻이 아니다.

Node v26 집중·연관 검사 64건과 Chromium 2건이 통과했다. 게임 창은 실행하지 않았다.

정기 Node v26 전체 회귀 첫 실행에서 무브라우저 오라클 2건과 자산 요청 검사 1건이 새 Client 공통 수명을 생성하지 않아 실패했다. 실패 원인 확인 뒤 해당 실행을 중지하고 무브라우저 실행기와 자산·언어 검사 장치에 실제 공통 시작을 추가했다. 관련 검사 28건이 통과해 같은 주기의 전체 회귀를 재실행했다.

재실행한 Node v26.13.0 전체 회귀 6,425건은 실패·취소·건너뜀 없이 통과했다.
