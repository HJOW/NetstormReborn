사용자의 전체 작업 지시 중 건설·생산·대기로 끝낼 수 있는 Tutorial5 단계 A를 세분했다. 실행 도중 사용자가 현재 작업과 문서·커밋까지만 마치고 목표를 일시 중지하라고 지시했다. 이 단위는 생산 등록과 실제 스톤 타워 배치까지만 완료 판정하며, 피격에 따른 단계 B 전환이나 워크샾 추가 건설은 후속 단위로 남긴다. 적 공격 명령·포획·희생·승리 재현은 수행하지 않았다.

배치 조사 중 `(133,88)`은 놓이지 않았고 `(133,91)`·`(138,92)`는 놓였다. 최종 단계표는 `(138,92)` 한 기만 사용한다. 기준선의 1,000프레임에서도 게이트는 A(65)이며, 윈드 볼텍스는 피해를 받지만 타워 HP는 2000이다. 따라서 피격 관문을 통과했다고 기록하지 않는다. 원인 조사·성공 위치와 이후 B~C 단계표는 재개 후 별도 단위로 수행한다. 조사용 원시 결과는 Git 제외 `extracted/webpj-e1339/`에 있고 기존 fixture는 수정하지 않았다.
