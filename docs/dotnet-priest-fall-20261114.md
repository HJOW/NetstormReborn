## 낙하 본체와 어댑터

`RawPriestFall.Begin`은 보호막 확보→new(0x28) 시도/공유 Regular0x25b·0.01f 생성→현재 권한이면 Unpop(0)/Repop(0x800)→현재 좌표 소리 요청 순서다. 확보 실패여도 나머지 공간/소리 효과를 계속한다. 권한과 좌표는 선행 효과가 끝난 뒤 다시 읽는다. `TryFall`은 현재 방향이 J인 경우 요청을 생략하고 항상 참이다. 기존 예약의 유무로 요청을 막지 않는다.

주기 처리기는 현재 이동 불가이면 보호막을 확보한 뒤 현재 프레임 방향으로 Set 또는 Advance를 선택한다. 프레임 효과가 바꾼 위치/TYPE를 다시 읽어 지면이 없으면0.1f를 반환한다. 지면 WORD는0/비영만 검사하고65535 같은 비유효 SID도 지면으로 취급한다. 도착 프레임을 지정한 뒤 이동 가능 여부를 다시 조회하고 보호막을 해제한다. count/payload는 읽지 않는다. 좌표 거의 올림은 단정도 상수를 double 합으로 유지한 뒤0방향 절삭한다.

모든 실제 경계는 C++ 생성자와 같이 구성 시 확인하고 함수 객체를 복사한다. `MakePriestFallHooks`는 같은 실제 Host·보호막 생성/조회·삭제를 연결한다. `MakePriestFallFrameHooks`는 같은 실제 지정기/진행기 정체성을 확인하며 DWORD 증분을 signed 비트로 전달한다. Regular/walker 분배기는 현재 실제 VT를 선택하고 미복원 사건/다른 클래스는 명시 fallback 또는 원문 실패를 따른다.

`Sound`는 사제 낙하의 실제 위치 음향 요청 경계다. `SoundPlayer`/`SoundProcess`의 재생·정지 수명과 실제 캠페인 HostSession의 전체 사제 장치 결선은 후속 R4 작업이다. 이 단위의 콜백 대조를 실제 오디오 출력이나 캠페인 전체 완료로 세지 않는다.
