# WB04-E797 사용자 입력 커서 폴링 앞단

cpppj `UserInput.cpp`의 `ReadCursorOptions`와 `UpdateCursor`를 캠페인 World에 부분 연결했다. 폴링한 화면 좌표는 같은 Client 선택 전역에 먼저 보관하고, 창 밖이면 종료한다. 창 안에서 커서가 잠겼으면 기존 이동 커서만 갱신하고, 잠기지 않았으면 두 설정을 지역 기본값 0으로 읽어 실제 커서의 스냅·배치 표시 전역에 기록한 뒤 해당 커서를 갱신한다. 입력 사건 분배와 브라우저 이벤트 수명은 남는다.

TheWarBegins 실제 로컬 로그인과 선택·강조 상태에서 창 밖 좌표 기록/조기 반환, 잠긴 상태의 실제 이동 커서 평가, 잠금 해제 상태의 설정 순서와 실제 커서 상태 갱신을 확인했다. 마지막 `cursor.update` 호출은 독립 검사 콜백으로 관찰했으며 커서의 실제 위치 본체는 별도 기존 시험이 담당한다. 브라우저 장치나 전체 미션 플레이 검사는 아니다.

검증: Node v26.13.0 전체 6,294건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 마지막 Node v22 전체 검사는 E795이며 이번 단위까지 이후 v26 전체 검사 2/8회다.
