# dotnetpj 0.989 — RU-3c NativeRoot/HUD 창 생성·Enter

2026-11-25, HJOW-Athlon. R4-6 Root 공장 묶음의 RU-3c다. ChatWindow 등 NativeRoot 창을 실제 Root에서 생성하고 문자 Enter를 Root 입력 호출자로 잇는다. 상태·기하·전체 부모·공장은 0.767~0.774에서 완료했다.

## 변경과 원문 대응

- `HostMenuInput.BindChatEnter`: 숨은 입력줄의 문자 Enter를 실제 Chat 공장으로 연결한다. 분배기(`Dispatch`)는 메뉴 라우팅·편집기 분배 다음, 팝업·모드·명령 처리 전에 연결된 갈고리를 먼저 수행하고 변경을 알린다. 연결하지 않으면 기존처럼 아래로 흐른다. 0.989에서 추가됐다.
- `ClientHostGame.StartMission`: 미션 진입 Root에서 표시 창을 만들고(`NativeChatWindows.Create`) 같은 트리 루트에 부착한다. 부착 전 Enter는 GumpTree의 void·부모 규칙에 따라 부모 없음으로 거부되며, 생성·부착·Enter가 원문 순서로만 동작한다. 메뉴 경로는 바꾸지 않는다. 0.989에서 추가됐다.
- `ClientHostGame.LoadContent`: 메뉴 입력 분배기에 Chat Enter 갈고리를 연결한다. 창이 없으면 갈고리가 거짓을 돌려 기존 입력 흐름을 보존한다. 0.989에서 추가됐다.
