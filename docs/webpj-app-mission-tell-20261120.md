# WB04-E971 앱 현재 미션 Tell 조회

Tell 본문은 원본 순서대로 등록 객체의 접두어 섹션, 현재 미션 대본, 현재 언어의 tell 파일, 웹 영어 대체 파일을 조회한다. 미션의 빈 섹션도 존재하는 결과로 보존한다. 앱 Tell 창은 현재 Guide Script의 언어별 `section()`을 사용하므로 실제 Tutorial1 `A.` 안내를 찾을 수 있다.

Guide의 `init` Tell 모드 1은 창 없이 설정 치환과 첫 HTML 파서 효과만 실행한다. 첫 파서에서 추출한 인라인 명령은 기존 앱 명령 경로로 전달하고, 창 메타데이터 및 두 번째 파서는 실행하지 않는다. 현재 웹 명령 경로는 Config·Warning만 지원하며 나머지 명령의 일반 입력 큐 분배는 후속이다.

검증: 현재 미션·등록 객체·기본 파일의 조회 우선순위와 빈 본문, 숨긴 init의 인라인 Config와 메타데이터 미실행, 실제 Tutorial1의 `A.` 창, 기존 메뉴·원본 스크린샷·Tell 관측을 포함한 Node 54건 통과. 로그인 완료 후 Guide 자동 진행과 실제 미션 안내 프레임은 아직 연결되지 않았다. E966 고정 Node 22 전체 회귀 뒤 E970 고정 Node 26 회귀를 진행할 검증 트리를 준비했고 자산 검사도 통과했다.
