# dotnetpj 1.051 — SL-1 로그인·Root 등록·Clock 제품 순서 고정

2026-11-26, HJOW-Athlon. R4-6 시작·수명 묶음의 첫 조각이다. 전체 로그인·제품 Root 등록·
제품 Clock 프레임의 제품 순서를 세션 수준에서 고정했다. 세 조각의 배선(StartMission 인라인
로그인·CreatePrepared 공개·결속·Native prefix Clock)은 이미 제품에 있으며, 이번 단위는
순서 회귀 방지가 목적이라 제품 변경은 없다.

## 변경과 원문 대응

- `dotnetpj/tests/Netstorm.Client.Tests/HostLoginRootClockTests.cs`: 신규 3건. 제품
  StartMission과 같은 로그인 순서(Zone→SP→AI설정→Players→Masks→순서→가입→수신→Ready→
  송신→이름)의 기준선 상태, 제품 Root 등록 순서(대여→공개→owner 결속→pin→반납)의 현재
  공개 전이, 제품 Clock 순서(prefix 초기화→매 프레임 캡처)의 게임·벽·차이·번호 전진을
  대조한다. 근거: cpppj `ClientMain.cpp`의 BeginMission 흐름과 DN 제품 `ClientHostGame`
  `StartMission`·`PrepareNativeFrameInput`·`InitializeNativePrefix`·`Dispose`다. 1.051에서
  추가됐다.

## 검증

- Release 전체 빌드는 오류 0이다. 손댄 프로젝트(Client.Tests)는 신규 경고 0이다.
- 신규 3건은 통과 3·실패 0이다.
- 관련 기존 37건(미션 플레이어·Runtime·Native prefix·공유 프레임·시계)은 통과 37·실패 0이다.
- `cpp_sync.py`는 종료 0이다.
- 제품 변경이 없어 L2 수집은 생략한다. DN 실행 파일은 소스 기준으로 바이트 동일하며 L2
  기준선은 0998·M1 0/34를 유지한다.
- 원본 1,392파일은 건드리지 않았다(검사·수집 모두 실행본·사본 경로만 쓴다).
