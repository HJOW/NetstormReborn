# dotnetpj 0.842 — Native 기본 수명과 현재 VT 정기 분배

2026-11-23, HJOW-Athlon. 같은 장기 Host의 기본 삭제·정기·가상 Form 수명 부모를 연결했다. 전체 정기 분배/Native Root·Load/Editor 공개는 계속 미완료다.

## 변경

- Native `RawSurfaceStorage.Processes`가 `BaseDestroy`, `HandleDefaultRegular`, 현재 `ProcessFormDispatch().Hooks()`를 함수 값으로 등록한다. 최초 Host/Kernel/삭제기/가상 Form 생성이나 World 대여를 앞당기지 않는다. 기존 Host의 현재 Runtime 우선 계약을 유지한다.
- 새 `RawSurfaceStorage.Regular.cs`는 현재 슬롯의 VT DWORD로 분배한다. 원문 +5c=00496e70인16종만 payload를 그대로 반환한다. 실제 Damageable14종은 현재 피해/건설 사건의 장기 본체로 보낸다. 기존 스프라이트/Player/간헐천/아이스 타워/펜스 본체의5VT도 같은 Host에서 선택한다. 현재35VT 연결(83행 자료 중32종과 자료 밖3종)이며 나머지 전용은 명시 실패한다. 83행 자료의 나머지51종도 미완료다.
- `ResourceDamageableRegular`는 현재 `DamageRegularEvent`를 비교한 뒤 선택한 피해 장치만 요구한다. 현재 `ConstructionRegularEvent`의 최초6700을 장기 GameAux에 추가하고, 추상 bit·현재 ConstructionProcessType·동일 Pool의 포함 Form을 조회해 필요한 경우만 실제 건설 재시도를 호출한다. 일반 사건은 원문 기본 반환이다.
- 기존 독립 PE `damageable-regular-tables-x86.tsv` 83행을 Core 한 소비자에 읽기 전용으로 연결했다. 기대값은 C# 출력으로 생성하지 않았다. fixture453개이며 이전452행의 순서/해시/값을 모두 보존했다. 도구의 정렬 이동6행은 원래 위치로 복구했다.
- PORT_MAP 이전1642자료행의 순서/값/base를 보존하고 Regular 부분 파일에2쌍을 추가했다. 자료1644(port1156/L1 481/session7)이며 기존 대응 소스이므로 대응626/1240단위·106,131/169,438줄은 그대로다. 부분 대응 수치는 플레이 완료율이 아니다.
