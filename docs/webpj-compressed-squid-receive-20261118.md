# WB04-E735 압축 객체 수신

`7ah` 압축 객체를 35바이트 공통 갱신으로 복원해 같은 Session의 객체 수신기에 전달한다. 원본 순서로 필드를 소비하고 생략된 좌표·타입·HP·zOrder와 현재 소유자 캐시를 사용한다. 마스크 충돌 진단은 복귀 후 처리를 계속하며, 잘린 지역 자료는 진단 후 중단한다. 송신 관찰기는 진단 이후 현재 길이를 다시 읽는다.

근거는 기준선 `225553df`의 `RawSquidCompressedReceive.cpp`와 `RawCampaignSession.cpp`, 수신기 행의 근거 커밋 `96904de5`다. 해당 수신기 파일의 기준선 이후 변경은 없다. 새 원본 fixture나 직접 cpppj 검사는 없다.

독립 검사에서 생략 기본값·명시 필드·충돌 진단·부분 효과·콜백 전 지역 복사·송신 길이를 확인했다. Tutorial 1 통합 검사는 실제 분배기와 공통 객체 검증 상태, 공유 owner 캐시를 확인했다. 집중 검사 26건이 통과했다. 실제 미션의 객체 생성 왕복과 앱 연결은 아직 검증하지 않았다.

Node v26.13.0 전체 회귀 6,212건을 통과했다. 대응표 오류는 0건이며 Node v22 전체 재검사 주기는 5/8회다.

다음은 `5bh` 간헐천 채집과 `70h` 원격 Tell을 포함한 나머지 Carrier 등록이다. 로그인 왕복과 앱 미션 연결은 남아 있다.
