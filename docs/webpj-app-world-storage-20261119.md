# 앱의 실제 자산과 장기 월드 저장소 (WB04-E880)

앱이 받은 가상 파일에서 TYPE 116종·SHP·설정의 `GamePalSpec(fortPal)` 팔레트로 `GameAssets`를 만들고, 같은 자산의 장기 `RawSurfaceStorage`와 `Kernel`을 구성한다. Storage는 실제 Client의 권한·게임 전역·현재 프레임 시각·검사와 콘솔 진단을 공유한다. 앱 종료는 장기 Process 소유자를 먼저 명시 반납하고 다음 시작에는 같은 다운로드 자산을 사용하더라도 새 물리를 만든다.

실제 TheWarBegins Session이 앱 저장소의 같은 풀과 Kernel을 빌려 적재하고 반납하는 것을 확인했다. Chromium에서도 실제 자산 준비 뒤 시작·종료·재시작 및 최초 실행을 검사했다. 아직 앱 메뉴의 미션 진입, Kernel 프레임·Native 장기 장치 전체는 연결하지 않았다.

Node v26 집중·연관 검사 48건과 Chromium 2건이 통과했다. 최초 오류 보고 검사 2건은 모의 앱에 새 저장소 준비 상태가 없어 실패해 모의 입력을 보정했다. 새 Session 검사를 연속 실행하자 이전 검사들이 공유 Fort를 소비해 다음 검사가 실패했으며, 각 추가 검사에 실제 Fort의 별도 입력을 사용해 기존 후속 검사까지 연속 통과했다. 정해진 주기에 따라 이번에는 전체 회귀를 실행하지 않았다. 게임 창은 실행하지 않았다.
