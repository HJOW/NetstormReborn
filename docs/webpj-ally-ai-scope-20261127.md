# webpj 실제 플레이 검사 범위

WB04-E1398, 2026-11-27, HJOW-Athlon. 사용자의 최신 지시를 검사 제어기와 CLI에 반영했다. 실제 미션 플레이는 아군 AI 방식으로 캠페인1-1~1-6과 스커미시만 진행한다. 단순 진입과 첫 안내 확인은 모든 캠페인에서 가능하다.

`installAllyAi`는1-6 `DissolvedAlliance`를 허용하며 현재 SP·이름·동맹·기술을 읽고 보존한 뒤 실제 `createAi`를 호출한다. 원래 로컬 brain이 있으면 C++ 검사 방식처럼 재사용한다. 이번 실제1-6은 기존 brain이 없어 신규 생성했고, 재사용 분기 실행의 증거로 세지 않는다.

자연 승리 CLI도 여섯 미션만 허용한다.1-6에서 승리한 경우에는 Next Mission을 누르지 않고 Leave Missions와 저장 복원을 확인한다. 다음 캠페인의 실제 플레이를 자동으로 이어 가지 않는다. 허용 범위와 실행 방법은 [검사 안내](testing/webpj-autoplay-test-guide.md)에 기록했다.

집중 Chromium 검사는3/3 통과(3.7분)했다. 허용 밖 미션은 페이지 접근 전에 거부했고,1-6은 시작 SP4000·이름 You·동맹2·기술 목록을 보존하고 실제 AI 초기화1/중지0에서600프레임/15초를 진행했다.1-1 기존6000프레임 검사도 통과했다. 이 결과는 검사 제어기의 검증이며1-6 승리 완료가 아니다.

[실행 원문](webpj-e1398-evidence/control.log)과 [출처·해시](webpj-e1398-evidence/provenance.json)를 보존했다. 제품 `www`와 번들은 바꾸지 않았다. E1397 정기 Node26/22 순차 회귀는 별도로 진행 중이며 종료 후 주기를 갱신한다.
