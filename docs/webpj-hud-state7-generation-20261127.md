# State7의 실제 HUD 생성 시점

- 단위: WB04-E1383, 2026-11-27, HJOW-Athlon.
- E1382의 앱 생성/도킹 분리를 State7에 연결하는 후속 단위다. 전체 State 정리 부모와 Runtime 반납의 연결은 별도 단위로 이어간다.

State7은 시작 정보를 보관하고 기존 SP·다리 붕괴 초기화를 수행한 뒤, World 생성과 장면 음악보다 먼저 HUD·생산 패널·Chat을 만든다. Ready에서는 같은 생산 유지 상태에 Session·유지 장치를 연결하고 같은 HUD를 도킹한다. 최초 슬롯·다리 기한·Console 점멸 기한을 Ready 시각으로 다시 쓰지 않는다.

로그인 시 Player 기록이 재할당되므로, 메뉴의 식별자와 소유자 이름은 HUD 생성 시의 Player 뷰를 보관하지 않고 실제 조회/World 연결 시점의 기록을 빌린다. 이 경계를 놓치면 실제 Session Player 메뉴의 기록 정체성 검사에서 실패한다. World 생성 전 실패해도 이미 생성된 HUD를 이탈 정리에서 반납한다.

집중 검사의 옛 가짜 채팅 부모 주입을 제거했다. 뒤쪽 그리기용 독립 노드는 유지하되 실제 채팅 창을 덮어쓰지 않는다. 실제 앱 생성 시 World/Session 없음, Ready 전 같은 HUD 보유, 최초 도킹의 Chat·Console·기한 보존을 확인한다. 도킹 뒤의 정상 Console Idle은 기한을 갱신할 수 있으며 이를 최초 생성 기한과 혼동하지 않는다.
