# 실제 사제 메뉴 열기

WB04-E1071은 원본 사제 VT의 선택 관문과 공통 객체 메뉴 열기를 실제 Client 메뉴·제목·사제/운반체/객체 작성기와 결합한다. 현재 객체 Form을 메뉴에 부착하고 성공한 경우에만 열기 효과음을 재생한다. 다른 객체 VT는 사제 메뉴로 대체하지 않는다.

실제 Tutorial1 사제를 선택해 메뉴를 열고 현재 객체 Form 부모, 효과음과 Gump 정리를 확인했다. 원본 메뉴 열기 788행과 실제 미션 검사를 포함한 Node 22·26 각 8건이 통과했다. 브라우저 우클릭 분배와 다른 객체 VT·제단 위임은 아직 앱에 연결하지 않았다.
