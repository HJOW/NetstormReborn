# 일본어 자산 준비 뒤 Node22 전체 회귀

WB04-E1411, 2026-11-27, HJOW-Athlon. 설치된 Node22.23.5 실행 파일로 `--test --test-concurrency=2 tests/*.test.mjs`를 실행했다. 최종 재검사는 **6,901/6,901 통과**, 실패·취소·건너뜀·todo0, 종료0이며977.044초였다.

최초 전체는6,899통과·2실패·종료1(823.051초)이었다. 새 일본어 지원/설정 두 모듈을 대응표에 등록하지 않은 E1410 누락이 같은 완전성 검사 두 곳에서 검출됐다. 기존 언어 자원 적응 행과 웹 전용 배포 설정 목록에 각각 등록했고 대응표 집중7/7·전체ESLint를 통과했다. 검사 규칙이나 단언을 약하게 바꾸지 않았다. 최초 결과와 최종 전체 재실행을 분리 보존한다.

최초 검사에서는 작성 소스·공개 자산과 원본2982파일, 재검사에서는 대응표TSV도 더해2983파일의 원시 SHA-256이 시작과 종료에 모두 같았다. 줄바꿈만 달라진 파일도 없다. 다른 버전의 전체 Node 검사를 동시에 실행하지 않았다. 별도 실제AI·일본어 후보 브라우저가 함께 실행됐으므로 이 시간은 조용한 환경의 성능 측정이 아니다.

최종 소스는 E1410 공용 일본어 자산 준비와 등록 보완까지다. Git 제외 경로에서 만든 일본어 UI/CDN/줄바꿈 후보와 제단 예약 피해 연결 후보는 아직 본 소스에 적용하지 않았으며 이 통과 결과로 후보 검증을 주장하지 않는다. v22 주기를0/8로 다시 시작하고 v26은 E1405 뒤3/4를 유지한다.
