# dotnetpj 1.081 — 미션 채팅창 최초 위치 교정

2026-11-27, HJOW-Athlon. 미션 시작에서 200×100 채팅창을 (0, 높이-100)에
부착해 미니맵을 덮던 것을 교정했다. 현재 세로 구분선의 오른쪽과 채팅
구분선의 아래를 사용하고, 화면 끝까지의 크기를 실제 채팅 자식 기하에
전달한다. 근거는 CPP `UberRootGump::Layout`의 slave 4·8과 `HudDock`의
가로·세로 계산이다. 구분선 이동 시 전체 slave 재배치는 R5-4d에 남는다.

- Game Release 오류 0, 기존 Core·Client 경고 8건. 기존 채팅 기하·미니맵
  집중 검사 11/11 통과(기존 빌드된 검사 어셈블리 사용).
- `thewarbegins` 실제 100프레임 화면에서 미니맵이 나타났다. CPP와의
  80×75 영역 차이는 6,000/6,000에서 901/6,000 RGB 픽셀로 줄었다.
  화면 전체는 기존 월드·HUD 미연결로 아직 다르다. 실행 종료 0, 원본
  1,392파일 불변. 결과 `extracted/dotnet-l4a-1080-chatfix/`, 비교 원본
  `extracted/dotnet-l4a-1080-minimap/cpp/entry.bmp`.
- `thewarbegins` L2 양쪽 종료 0, DN 90프레임 덤프는 0998과 바이트 일치,
  원본 1,392파일 불변. 기존 CPP/DN 차이로 비교 도구 종료 1이다.
  결과 `extracted/dotnet-l2-1081-chatfix/`.

미니맵 카메라 뷰에 worldBits가 아닌 화면 pixel을 float로 바꿔 넘기는
결함이 남는다. CPP `GameWorld::MinimapView`처럼 실제 WorldBits와 현재
CellPixels를 공급하고, 매 프레임 갱신·월드 알림·수명을 검증한다.
R5-4c3c와 R5-4d의 전체 완료는 아직 아니다.
