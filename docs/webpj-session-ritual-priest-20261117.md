# Session 사제 의식 앞단 (WB04-E645)

기준선 `225553df`의 `RawCampaignRitual.inc` 7..18 및 71..79를
기존 Session의 같은 Pool·Frame·Process Host·시계·위치 음향에 연결했다.
관련 cpppj 소스는 기준선 뒤 변경이 없다. 의식의 나머지 상태/신전/룬/
다이스/제단과 `Load()`는 아직 남았으며 `loaded=false`를 유지한다.

Regular 확보는 하나의 실제 미부착 객체를 유지하고 중첩을 거부한다.
부착 시 같은 객체를 event/payload로 재초기화해 46 또는 61로 넘기고
현재 시각을 적용한다. JavaScript 런타임의 메모리 부족은 C++ `bad_alloc`
복귀값으로 안전하게 재현할 수 없어 별도 성공 대역을 만들지 않았다.
사제의 K~P 프레임 선택과 604 공유 예약, 기존 Regular 분배의 604
처리기는 같은 실체를 사용한다.

신규 검사 3건은 설치/반납 관문, 실제 같은 예약 객체·중첩과 미예약
오류·공유 Host 시각, 실제 K 프레임과 604 부착을 확인한다. 최초 검사
실패는 시험이 `nextTime` 대신 실제 `time` 접근자를 써야 했고, 실제
Frame setter의 사제 후처리에 위치 음향이 필요했기 때문이다. 시험의
접근자와 외부 음향만 바로잡은 뒤 관련 검사 7건이 통과했다.
