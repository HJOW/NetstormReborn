## 1. 구현

`GumpTree`는 형제 머리 삽입, 부모/이전/다음 링크 변경, void 비트, 부모 깊이 상속, 동종 교체의 지연 삭제 요청, 월드 투영과 화면 제한, 정렬 후 redraw 및 현재 자식 재배치를 C++ 순서대로 수행한다. 판본별 화면 int→float 변환과 음수0 비교, DWORD 깊이 감김, 지도 중심의 signed DWORD 합산 뒤 나누기도 유지한다.

콜백 전후의 현재 상태를 구별한다. 교체 요청의 next와 자식 재배치의 next는 가상 호출 전에 보관한다. redraw가 바꾼 child는 그 뒤 다시 읽고, Push가 바꾼 secondaryDepth/부모/기준 노드/크기는 필요한 시점에 현재 값으로 읽는다. 가상 함수가 예외를 내도 이미 쓴 링크/좌표를 원복하지 않는다.

검사 응답의 DWORD 쓰기는 안정된 노드 객체의 필드만 복사한다. 사전에 빌린 C# 참조를 끊는 사전 항목 교체를 하지 않아 C++ 구조체 대입과 같은 저장소를 유지한다. 검사 공유 도우미의 `ApplyDword`가 이 역할을 담당한다.
