# 도움말 정보 본문 파싱

WB04-E1050은 원본 QuickHelpHtml처럼 선택된 주제 안의 소문자 `<info>`에서 호출자가 공급한 TYPE 정보 HTML을 별도 스타일 본문으로 변환한다. 부모 HTML의 문맥과 링크를 사용하되 중첩 파싱에서 소비한 링크 위치는 되돌려 이후 부모 링크를 보존한다. TYPE 공급이 없는 기존 F1 도움말은 같은 동작을 유지한다.

원본 8종 TYPE 프로필·패널 상태 2종의 정보 스타일 16행을 주제 파서까지 연결해 대조했다. 실제 한국어 주제, 링크 및 원본 도움말 스크린샷을 포함한 Node 26 검사 34건과 추가 중첩 링크 검사가 통과했다. 현재 미션 TYPE 및 별도 정보 패널 출력을 창에 설치하는 작업은 남았다.
