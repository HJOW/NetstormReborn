# Client HUD 구분선의 실제 배경

WB04-E1028은 ClientHudDivider가 ClientGumpBackground의 원본 배경 생성·SHP 출력·현재 클립을 사용할 수 있도록 연결했다. 구분선은 기존 입력·방송·부착·수명을 유지하고, 선택된 실제 배경 장치가 같은 파생 노드를 생성하고 그린다. 기존 배경 미연결 독립 경로도 보존한다.

실제 fortGump 자산과 공통 Gump 표면에서 구분선 픽셀 출력, 클립, 삭제를 확인했고 관련 Node 검사 24건이 통과했다. 생산 패널 조립과 실제 브라우저 설치는 남았다. E1026 고정 Node 26 전체 회귀는 실행 중이다.
