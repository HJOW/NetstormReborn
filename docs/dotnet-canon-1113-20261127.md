# dotnetpj 1.113 — Player 삭제 장면의 실제 기록 결합과 정정

2026-11-27, HJOW-Athlon. 1.112의 TYPE 152 실패는 테스트 장면에 실제 Player 기록 장치를 연결하지 않은 것이 원인이다. 제품 `BindNativeRootFirstDevices`는 이미 `BindPlayerRecords`를 호출하며, 이 장치는 같은 장기 기록의 현재 주소와 `RawPlayerWorld.PreDestroyNative`를 사용한다. 제품 결함이라는 추정을 철회한다.

- 테스트 장면에 제품과 같은 기록 결합을 추가하고 미배치 TYPE 152의 실제 삭제를 다시 실행했다. 같은 Player 행의 기술 SID가 0이 되고 플래그 bit0이 내려가고 bit8이 설정되며, 붙은 GumpForm과 UI 노드도 정리된다. TYPE 80 기본 자산과 부모 프로세스 Form을 포함한 Client 검사 **4건 통과**다.
- 제품 코드는 바꾸지 않았다. 공간에 배치된 자산 및 생산 격자 파생 노드의 삭제와 실제 미션 플레이는 아직 검증하지 않았다. 게임 재실행 없이 1.111의 대표 세 미션 결과를 유지한다.
