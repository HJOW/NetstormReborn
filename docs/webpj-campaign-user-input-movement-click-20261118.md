# WB04-E802 이동 모드 좌클릭

cpppj 기준선 `225553df`의 `UserInput::Event`와 `GameWorld::MoveSelected`·`ExtendSelection`을 따라 이동 모드 2·5의 좌클릭을 연결했다. 후보는 Shift와 무관하게 먼저 조회하며 Ctrl 강제 선택은 특수 권한이 있을 때만 적용한다. Shift 클릭은 실제 다중 선택 처리기에 전달한다. 그 외 클릭은 현재 카메라로 역투영하고 원본 절삭을 적용한 뒤 WorldDestSelected를 큐에 넣고, 다중 목록을 순서대로 전송한 다음 현재 기본 선택을 다시 읽어 이동시킨다. 해당 cpppj 세 파일의 기준선 이후 변경은 없다.

TheWarBegins 실제 로컬 Session에서 빈 지점 Shift 클릭의 선택 유지와 일반 클릭의 좌표 `(90, 108)`, 큐 명령 `0x02000044`, 운반 패킷 `0x40`을 확인했다. 별도 분기 검사에서는 모드 2·5, Ctrl 권한·Shift 및 후보 조회 순서를 확인했다. 다중 목록의 실제 이동은 기존 `RawUserSelection` 검사에 의존하며 실제 Session 복수 유닛 통합 검증은 남는다. 일반 좌클릭, 편집 모드와 멀티플레이 항해 및 브라우저 이벤트 수명은 이 단위에서 연결하지 않았다.

검증: 집중 검사 2건 통과, 대응표 1,160행 오류 0, Node v26.13.0 전체 6,296건 통과(실패·취소·건너뜀 0). E795 Node v22 전체 회귀 뒤 v26 회귀 7/8회다.
