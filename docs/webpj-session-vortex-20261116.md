# Session의 신전 상승 결선 (WB04-E589)

`225553df`의 `client/RawCampaignVortex.inc`75줄 중 독립 typed 설치와
모든 공유 helper/명령을 현재 Session owner에 연결했다. 생성자1537과
SendChatMutable4135..4137·handle64/Runtime/snapshot 멤버가 근거다.
이 소스와 `o/RawGameAuxState.h`는 기준선 뒤 변경0이다. cpppj 전체 검사
검색에서 이 바인딩의 직접 시험·전용 원본 관측은 찾지 못했다. 이번 신규
12건은 소스 계약/실제 부품 통합 검사이며 원본 전체 플레이 일치가 아니다.

## 같은 현재 저장소·선택된 효과

- 동일 Pool/Hash/TYPE/spot·섬 목록·장기 난수로 RawVortexAscend와
  RawVortexDeparture를 만든다. noIsland/localOwner/server/revision은
  현재 전역 참조이고 후보80BYTE는 중첩 호출별 실제 수명을 보관한다.
- 같은 Template의 E588 writer, 현재 Runtime reader/snapshot, 소유권,
  섬 조회, 실제 방송·Regular3을 연결한다. Runtime/snapshot/생산 장치가
  없으면 선택 위치에서 오류다. Fort 편집 상태 요청은 웹 제외 오류다.
- 현재 Subscriber 이름64BYTE를 빌리며 NUL 앞 바이트만 이름 장치에
  전달한다. 원문의 표시 부호화 완료 문자열을 NUL 포함하여 Config에
  쓴 뒤 Tell을 연다. 서비스의 install 함수 표는 값 사본으로 보관한다.
- 상태WORD를 먼저 저장하고 보호 PE005411a0의 현재 StateNotifyType일
  때만 실제 건물 공간에 통지한다. GameAux는81칸/TYPE50이며 새 초기값82를
  보호 PE 파일을 읽어 대조했다. 원본 실행은 하지 않았다.
- event3은 방송 뒤 같은 변경 패킷을 receiver9에 넘긴다. event4는 Fort
  지역 조회 뒤 당시 서버/메타 명령으로 두 동일 DWORD를 큐에 보낸다.
  사제 조회는 실제 공유 목록의 첫 살아 있는 항목과 조회 후 현재 free를
  사용한다. 명령의 상위 비트 마스크·상태·확인 인자·선행 WORD/소리·
  설치 전 송신 관문과 공통 ObjectCommand 위임을 유지한다.

## 검증과 최초 실패

실제 보호 자산/World/Template/공유 목록/Kernel로 신규12건을 만들었다.
첫 집중22건 중19건이 통과했다. 실패3건은 검사에서 읽기 사본인
`SidPool.slot()`을 변경한2곳과 Player 접속 BYTE를 +0x50 대신 +33에
쓴1곳이었다. 실제 물리 쓰기 대여와 원문 접속 위치로 검사 입력을 고쳤고
제품 본문의 단언을 완화하지 않았다. 최종 신규12건+GameAux10건=22건 통과다.

새 fixture는 없고 manifest805항목을 유지한다. original-pe-data와
factory-initialization 메타데이터를 갱신했다. Node24는2026-11-16 사용자
지시에 따라 실행하지 않으며 Node22/26 통과 시 호환을 가정한다.
최종 전체 검사는 Node22(v22.23.3)·Node26(v26.13.0) 각각5,611건 통과,
실패·취소·건너뜀0이다. 전체 glob과 `--test-concurrency=4`를 사용했다.
대응표1,160행·오류0이며 port844·partial36·todo127·제외153이다.
남은163단위/34,380줄, 4-D 체크31/46은 유지하며 웹 JS129,967줄·검사759파일이다.
로그는 `extracted/wb-e589-node22.log`·`wb-e589-node26.log`·
`wb-e589-port-map.log`다(Git 제외).

## 부분 완료와 다음 시작점

`ClientConstructionGlobals`/MakeClientVortexDevices·BindVortexDevices
대여는 아직 없다. 이를 typed 몸체로 대체하거나 Native 완료로 세지 않는다.

후속 생성/Session 통합에서 연결한다. 마지막 설치 완료·전체 로그인 송신
