# Tutorial2 워크샾 메뉴와 생산 연결 (WB04-E1079)

실제 Factory 가상 슬롯을 확인하여 월드 우클릭에서 원본 객체 메뉴·요약과 공통 Gump Form을 열고, 연구 및 업그레이드 명령의 packed 인자를 현재 Session에 전달한다. Factory 정적 도움말 토큰도 같은 Help 입력 큐에서 주제로 해석한다.

Chromium에서 한국어 Tutorial2의 사제로 윈드 신전과 썬 워크샾을 직접 건설해 자연 완공을 기다리고, 워크샾 우클릭·지식 메뉴를 거쳐 실제 생산과 D 안내를 확인했다. 원본 공통 메뉴 788행과 Factory Open 39행 및 정적 Help 분배를 포함한 Node 22·26 관련 검사 각 14건이 통과했다. 비용 표시 시각 검사는 두 시계 읽기 사이의 범위로 확인하여 밀리초 경계에서의 허위 실패를 제거했다.

생산 비용 표시의 상단 잔상, 나머지 종류의 객체 메뉴, 업그레이드의 실제 브라우저 결과, Tutorial2 이후 단계와 미션 자연 완주는 아직 검증·구현이 필요하다. E1072 고정 전체 회귀는 Node 22와 26 각각 6,581건 통과·외부 접속 감사 오탐 1건 실패였고, 오탐은 E1078에서 교정했다. 교정 후 E1079 고정 전체 회귀는 Node 22·26 각각 6,582건 전부 통과했다. E1080·E1081은 이 고정 회귀에 포함되지 않는다.
