# dotnetpj 0.926 — RU-3 NSInfo 플레이어 입력 결선 이식

2026-11-24, HJOW-Athlon. RU-3 열일곱 번째 묶음이다. NSInfo 플레이어 패널 원문 입력을 같은 파생 노드/CS·87BYTE 옵션과 실제 메뉴·송신 장치에 연결하는 생산 결선을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HostNsInfoWindows.HandlePlayerInput`은 플레이어 패널 토큰의 원문 입력 event/first/second를 `NativePlayerInfoInput.Handle`(0.913)에 실제 owner로 연결한다. 같은 공유 트리에서 0xbc 파생 노드를 해석하고, 명령 읽기는 `Read`를, 참가자/전투 물리는 `challenge`를, 번역은 `Translate` 장치를, 상태 송신은 `StatusSend` 장치를 빌린다.
- `PlayerSubscriber`·`PlayerAuxiliary`·`PlayerData`·`PlayerMenuBegin`·`PlayerMenuAttach`·`PlayerMenuTitle`·`PlayerMenuItem` 7종을 `HostNsInfoDevices`에 추가했다. 540c74 구독자·594fc4 보조 쓰기·87BYTE 옵션 송신·Fancy 추방 메뉴의 생산 공급자가 정해지기 전까지 미연결 호출은 명시 실패한다. 0.926에서 추가됐다.
- 자식 serial은 같은 공유 트리 노드의 실제 serial을, 버튼값은 같은 특수 버튼 노드의 실제 값을, 소유자는 같은 `Player.BattleOwner`를 직접 빌리며 별도 장치를 두지 않는다.

## 검증

- Release 클라이언트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 5건(준비 플래그 송신·시작 1회 예약·슬롯 변경 옵션 송신·추방 메뉴 생성·미연결 명시 실패)은 통과/실패 0이다. 이웃 `NativePlayerInfoInput` 17건을 포함한 38건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0926-*/`의 각 실행 로그와 요약이다.
