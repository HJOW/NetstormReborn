# 미션 이동점 입력 통지 (WB04-E993)

직접 전달 중인 미션 좌클릭은 원본 순서대로 현재 Tutorial 입력기를 먼저 거쳐 소비되지 않은 경우에만 Client Gump와 World 입력기로 진행한다. 이동이 실제 입력 큐에 예약한 `WorldDestSelected`는 앱 입력 단계에서 같은 Tutorial과 Gump에 전달한다. 아직 처리하지 않는 다른 사건 앞을 추월하거나 소비하지 않도록 큐 머리를 사본으로 조회한다.

실제 Tutorial1 Session에서 다른 명령이 앞에 있을 때 이동 통지를 보존하고 그 명령이 처리된 뒤 같은 큐의 통지를 소비하는지 확인했다. 큐 사본·감김, 원본 Tutorial 및 Gump 입력 등 연관 Node 검사 31건과 Chromium의 사제 선택·실제 좌표 이동·이동 통지 소비 1건이 통과했다. 초기 검사에서 존재하지 않는 테스트 파일명을 Node 26이 조용히 건너뛰어 실제 Tutorial 검사 두 파일을 확인하고 다시 실행했다.

입력 단계 전체는 아직 복원 중이다. 다른 원본 명령이 큐 앞에 남으면 이동 통지도 의도적으로 기다리며, 키보드·우클릭·HUD와 일반 명령 소비는 후속이다. E986 고정 Node 26 전체 검사가 진행 중이며 E990 고정 Node 22 검사는 이후 순차 실행한다.
