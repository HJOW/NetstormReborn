# WB04-E966 효과음 프레임 재계산

원본 Client 메인 루프 3단계처럼 앱 프레임에서 State Poll 다음과 로컬 패킷 처리 전에 SoundPlayer의 재생 수를 다시 센다. 자연 종료한 Web Audio 소스는 `onended`에서 상태가 해제되며, 다음 프레임 재계산으로 동시 재생 한도에 다시 여유가 생긴다. 재생기가 아직 준비되지 않은 프레임에는 이 단계가 없다.

검증: 실제 앱 소리 재생기와 관찰용 Web Audio 장치에서 한도 1에 도달한 뒤 자연 종료·State Poll·재계산·패킷 순서와 재생 재개를 검사했다. 관련 Node 검사 14건 통과, SoundPlayer 10.78 원본 관측 2,128행과 실제 Tutorial1 로그인 포함.

남은 작업: 미션 진입의 비동기 효과음 준비와 실제 미션 렌더링·음악·청취 등은 E965 인계를 따른다. E966 기준 Node 26 및 Node 22 정기 전체 회귀를 차례로 실행한다.
