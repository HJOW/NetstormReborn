# dotnetpj 1.079 — R5-4c2 생산 덱 틀 부착과 DN-MP-01 우클릭 확인

2026-11-26, HJOW-Athlon. R5 HUD·덱·미니맵·인벤토리 묶음의 다섯째 조각이다. 미션 진입 때 생산 덱 틀(예산·격자·배경 8노드)을 실제 HUD 왼쪽에 부착해 그린다. 예산 HELP와 생산창 HELP로 DN-MP-01 우클릭 메뉴 표시를 검증했다. 격자 내용물 population·유지·입력·동기화 본체는 R6/R11에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Game/ClientHostGame.ProductionDeck.cs`: 신규. `EnsureMissionProductionDeck`이 미션 진입에 생산 패널을 만들고 HUD 왼쪽에 부착한다. 근거: cpppj `RawProductionControls.cpp 184~186행`의 예산/격자/배경 생성과 `UberRootGump.cpp 86행`의 생산 공장 부착, `HudDock.cpp`의 왼쪽 도킹이다. `GumpHelp`를 생산 `BaseHandle`에 연결해 예산(`Storm Power Available`/`moneyGump`)과 생산창(`Production Window`/`teleportView`) 우클릭에 About 메뉴를 표시한다. `BindForm`·`Synchronize`·`UpdateContents`·`Maintenance`·`Take`·`About`·`Poll`·`Cursor`는 R6/R11 명시 실패로 둔다. `ClosePopups`·`MenuInstances`는 실제 메뉴 장치를 쓴다. 시작 덤프에는 닿지 않는다. 1.079에서 추가했다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 미션 시작 흐름에 `EnsureMissionProductionDeck()`을 연결했다(`EnsureMissionHudDividers` 뒤). 근거: 같은 생산 공장 부착 순서다. 1.079에서 수정했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostMissionProductionDeckTests.cs`: 신규 2건. 덱 틀 8노드·예산/`BridgeGrid`·배경의 HELP 포인터·`0x1000`/`0x200`·소유 문자열과 `GumpHelp.Handle` 우클릭 1 반환·주제(`moneyGumpHelp`·`teleportViewHelp`)·제목·부착·소리를 확인한다. 뗌 우클릭은 소비하지 않음을 확인한다. 덱 틀 부착 뒤 그리기 픽셀이 바뀌고 루트가 `(0,0)`·폭 80·높이 `화면-80`·루트 직계임을 확인한다. 1.079에서 추가됐다.
