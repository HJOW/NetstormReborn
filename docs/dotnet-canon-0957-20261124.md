# dotnetpj 0.957 — 0x21 참가자 제거 본체·설치 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 0x21 참가자 제거의 송신 관찰기와 수신·파괴 본체·CS 배열 경계·버전 집계·고정 F 설치를 같은 분배기에 연결했다. 0.956의 0x25 항해 오류와 제품 기존 경로는 바꾸지 않는다.

## 변경과 원본 대응

- `ClientMetaParticipantRemove.Observe`는 수신 관찰을 건너뛰고 송신 진단에서 복귀한 뒤 현재 개수를 다시 읽어 선언 WORD를 `numPlayers+5`로 쓴다. 0.957에서 추가됐다.
- `ClientMetaParticipantRemove.Receive/Destroy/Remove`는 참가자 제거의 범위·유효성·좌석·버전·Chat·파괴 순서를 이식한다. 미사용 추가 인자는 수명 정책으로 재해석하지 않으며 0명인 패킷도 마지막 NSInfo를 갱신한다. 0.957에서 추가됐다.
- `ClientMetaParticipantRemove.Install`은 0x21의 원문 packet 관찰기·버전·가변 길이와 고정 F를 설치한다. 0.957에서 추가됐다.
- `ClientChallengeGlobals.AllocateArray/ArrayBytes/ClearArray`는 CS 가변 배열의 토큰 발행·조회·free 순서(0·4·12·8)를 이식한다. 0.957에서 추가됐다.
- `ClientChallengeGlobals.UpdateBattleVersionBounds`는 여덟 슬롯의 상한 후 하한 조회와 최종 두 쓰기 순서를 이식한다. 0.957에서 추가됐다.
