# 앱 State 정리의 장기 소유자

WB04-E1058은 원본 Client State 정리와 도움말 팝업이 공유하는 NSInfo 전역과 QuickHelpPopupState를 앱 Client 시작 시 각각 한 번 만들고 앱 종료 시 반납한다. 값은 미션별 사본이 아니라 같은 Client 수명 동안 유지된다.

같은 소유자의 zone·팝업 명령·인자 보존과 실제 Session 적재·시작·정리 경계를 포함해 Node 26 관련 161건이 통과했다. State 정리 부모의 실제 앱 장치 연결, 음악 소유자·Gump 교체 및 기존 World의 안전한 교체는 아직 남았다.
