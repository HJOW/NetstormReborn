# 0.673 건설 표시 생성·동기화·초기 입자 선택

- 일시: 2026-11-20, HJOW-Athlon.
- 근거: `cpppj/src/o/RawConstructionVisual.cpp/.h`, `cpppj/tests/ConstructionVisualTests.cpp`, 불변 `constructionvisual-x86.tsv` 1,776행.
- 범위: 생성·공유 팔레트·현재 좌표·초기 입자 선택과 건설 시작 어댑터다. 실제 프레임·프로세스 소유자·캡처/색 표/표시 장치의 세션 연결은 후속이다.

## 구현

기존 `ConstructionVisualFields`·등록 구조를 사용해 부모/종속 체인 검사→객체 예약→등록→공유 색 표→수명→캡처/출력 확보→현재 부모 좌표 동기화→입자 선택을 이식했다. 캡처에는 진입 부모를 넘기고 동기화는 등록 경계가 변경한 현재 부모를 읽는다. PATCH의 부모·Form 유효성, signed 깊이, 효과 뒤 현재 팔레트와 배율, 확보 실패의 부분 효과를 보존한다.

입자 선택은 최소500칸·불투명 수/6 용량, 마지막 픽셀 복사/투명화, 중앙 교차 열의 하단 첫 픽셀, 난수 수명, 폭만큼 두 난수를 사용하는 전체 입자 교환 순서다. 기존 누적Selected·활성 수·첫 프레임 표식을 직접Seed에서 초기화하지 않는다. 건설 어댑터는 같은 풀의 표시 생성을 끝낸 뒤 기존 건설 시작이 현재 시각을 읽도록 연결한다.
