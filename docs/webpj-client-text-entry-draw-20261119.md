# WB04-E940: Client TextEntry 실제 Gump 출력

`RawTextEntryControls` 기준선 `225553df`의 편집 배경·글자·선택 사각형 출력을 기존 GumpBackgroundDraw, GumpTextDraw 및 GumpPixelTarget 장치에 연결하는 어댑터를 추가했다. 영문 바이트는 원본 비트맵 글꼴, 확장 문자는 유니코드 글꼴의 실제 글리프를 같은 출력 반복기에 넣어 그림자·본문 패스와 그리기 전진 폭을 유지한다. 출력은 현재 Gump 좌표·클립·색표를 사용한다.

배포된 원본 Arial 비트맵 캐시와 시험용 유니코드 래스터라이저를 사용해 실제 8비트 표면에 영문·한글·영문, 선택 영역, 그림자 패스 및 클립 복원을 검사했다. 원본 편집 관측 2,292행과 Gump 클립 원본 관측 476행을 포함한 연관 Node 검사 46건이 통과했다.

실제 앱 FontSet·갈무리11·렌더러 공급과 미션 UI의 가상 Draw 분배, 실제 OS IME 연결은 아직 검증하지 않았다.
