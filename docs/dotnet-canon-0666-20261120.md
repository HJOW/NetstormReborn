## 구현

`RawFactoryUpgradeCommand`는 같은 PATCH 풀·현재 TYPE과 전역 getter를 빌린다. 요청은 사건4/20초 SharedRegular 예약 뒤 현재시각+15초를 담아16바이트 요청을 송신한다. 예약 실패에도 송신하고, 부착이 현재 시각을 바꾸면 변경된 값을 읽는다.

수신은 현재 상태·mode·genus를 판정한 뒤 실제 TYPE 비용 → 현재 owner SP 가산 → 로그 → 예약 성공 시 사건3 지연 → 현재 권한이면 원문16바이트 방송 순서다. 진단 뒤 genus를 다시 읽고 비용·예약·부착 효과 뒤 owner·시각·권한을 현재 값으로 읽는다. 유한 지연은 최소1초이며 unordered는 원본 차이 NaN을 유지한다. 선택되지 않은 시각 칸은 읽지 않는다.

공통 `FactoryResearchCommand.Write`는 헤더·WORD SID·kind 하위BYTE·mode0·시각 QWORD만 쓰고 버퍼 꼬리를 보존한다. 업그레이드 요청은 kind0·mode1이다. 수신의 상위 헤더 검증은 원본처럼 분배 호출자 책임이며 새 검증 관문을 추가하지 않았다.
