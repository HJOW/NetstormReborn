# 1.172 정기 전체 회귀

1.171까지 포함한 Release 빌드에서 Assets 383/383, Core 4,121/4,121, Client 2,972건이 통과했다. 합계 **7,476통과, 실패0**이다. Client의 음향 하드웨어 검사 1건은 TRX의 개별 `UnitTestResult`가 `NotExecuted`이므로 통과에 포함하지 않는다. Client TRX 총계는 2,973이며 콘솔의 통과 수와 구별한다.

`dotnet test`를 각 프로젝트별 Release `--no-build --no-restore`로 실행하고 결과를 `extracted/dotnet-1172-regression/`에 보존했다. 세 검사 모두 종료0이다. 이 회귀는 실제 음향 하드웨어, 전체 L2 재수집, 미션의 승리나 게임 플레이 완료를 뜻하지 않는다. 1.171 변경 후 전체 34경로 재수집은 별도로 진행한다.
