# WB04-E907: 앱 전투 팔레트 전환

로그인 State7의 `battlePalette`는 호출 시점의 `battlePal`을 조회한다. 같은 Client의 `ClientKencloudGlobals.transition`에 원본 이름 바이트와 게임 난수·실제 VFS·설정을 전달한다. 구름 이름과 캐시 처리 뒤 `GamePalSpec`의 파일을 읽고 Screen에 `clear=1`로 적용하며, 최초 고정 색으로 9표를 다시 만든다. 현재 GameWorld가 있으면 같은 Screen 색과 색표를 표시기에 전달한다. 같은 이름은 원본 부모의 대소문자 무시 비교 뒤 하위 효과 없이 반환한다.

메뉴 표시 자원의 모든 명명색 갱신, 날씨 음향 tint, 완전한 Renderer 연결과 구름을 실제 게임 장면에 그리는 작업은 아직 남았다. 따라서 팔레트 전환을 연결해도 앱의 미션 진입이나 게임 플레이가 완료된 것은 아니다. 웹 파일 해독기는 정규 COL/RGBQUAD를 사용하며 손상된 원본 FILE의 부분 읽기 효과를 재현하지 않는다. 현재 Native Renderer가 없으므로 구름 소유자의 Renderer 존재 토큰을 표시기로 가장하지 않는다.

실제 GIF·COL·설정으로 구름 캐시와 난수, 화면 지우기, 최초 입력 보존 및 같은 이름의 자연 반환을 확인했다. 없는 팔레트 파일에서는 앞선 이름·구름 효과를 남긴다. 실제 Tutorial1 State7·State8 테스트에서 로그인 팔레트와 같은 Session을 연결했고 다른 UI·진행 창은 명시 시험 장치로 남겼다. 하위 구름·팔레트 전환 관련 Node 검사 17건과 실제 로그인 2건이 통과했다. Chromium 실제 전환 1건과 Node v22.23.3 전체 회귀 6,460건이 통과했다(실패·취소·건너뜀 0).
