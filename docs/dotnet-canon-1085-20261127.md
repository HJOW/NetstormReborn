# dotnetpj 1.085 — 미니맵 추가 월드 실행기 대여

2026-11-27, HJOW-Athlon. 공통 저장소 대여 외에도 같은 풀·해시·점유
지도를 사용하는 Pop/Unpop 쌍을 미니맵에 추가로 연결하는 경계를
마련했다. `RawPop`은 동일 공간 검증을 위해 실제 해시·점유 지도를
공개한다. 중복·다른 물리·기본 대여 누락은 설치 전에 거부한다. 추가
실행기는 약한 참조로 보유하며 반납 시 다른 큐로 교체된 실행기는
건드리지 않는다. 이 단위는 API와 검사이며 세션 제품 연결은 다음이다.

- 미니맵 집중 검사 10/10 통과. 신규 검사는 실제 추가 Pop/Unpop의
  등록·제거 알림, 중복·다른 물리 거부, 후속 소유자 큐 보존을 검증했다.
- Release 의존 프로젝트 및 검사 빌드 통과. 변경하지 않은 Core nullable
  경고 6건·Client 중복 using 2건·기존 검사 경고 5건이 출력됐다.
- `cpp_sync.py` 종료 0. 대표 `thewarbegins`의 CPP/DN 실행은 각 종료 0,
  DN 덤프는 0998과 바이트 일치·원본 1,392파일 불변이다. 원본과의 기존
  차이로 비교 도구는 종료 1이다. 결과 `extracted/dotnet-l2-1085-pairs/`.

다음은 HostSession의 현재 지형·Player 실행기 쌍을 이 API에 연결하고
실제 미션 변경·교체·실패·정리 수명을 검증하는 것이다. 미니맵
388픽셀 차이와 R5-4c3c 전체 완료는 남는다.
