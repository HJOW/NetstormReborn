# WB04-E844 일반 전투 종료 프레임

기준선 `225553df`의 `RawBattleCompletion::Frame`을 이식했다. 각 Player의 신전·제단 진단은 메뉴에서도 먼저 수행하며, 일반 전투의 연결·상태 관문 뒤 캡처 기한과 signed BYTE 대기를 처리한다. 팀·기권·미접속 판정의 재조회와 모달 차단, 무승부 기한 및 거절, Player의 기권 비트 정리, 저장 삭제·결과 기록·메뉴 명령 순서를 보존한다.

[C++ 관측 도구](../webpj/tools/battle-completion-frame-oracle.cpp)를 기준선 `RawBattleCompletion.cpp`와 MSVC C++20 `/utf-8`로 빌드해 합성 상태 4,096개를 실행했다. 각 상태의 결과·대기 BYTE·기한·Player flags와 외부 효과 순서를 LF 정규화 SHA-256으로 기록해 웹 검사와 일치시켰다. 별도 검사에서는 진단, signed BYTE 감김, 모달 차단, 결과 확정 순서 및 NaN 무승부 기한을 확인했다. 원본 실행 파일과 게임 창은 실행하지 않았다.

판정기 파일의 본체는 이식했지만 실제 Client 프레임, 결과 창·저장 장치 및 메뉴 복귀에 연결하지 않았다. 완성된 스커미시 승패 실행도 아직 검증하지 않았다.

검증: 프레임 집중 검사 3건, C++ 프레임 관측 비교 4,096개 상태 1건, Node v26.13.0 전체 6,352건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E843의 Node v22 전체 검사 뒤 v26 회귀 1/8회다.
