# WB04-E800 캠페인 사용자 입력 우클릭

캠페인 `CampaignUserInput.event`에 원본 우클릭 분기를 부분 연결했다. 현재 강조 모드가 있으면 먼저 강조를 해제하고 기존 선택을 초기화한다. 일반 모드에서는 Control과 현재 특수 선택 권한을 원본처럼 확인해 실제 World 후보 선택에 전달하고, 후보가 있으면 상위 메뉴가 사용할 SID를 반환한다. 후보가 없으면 Challenge/PlayerKnown 관문에 따라 선택을 초기화한다. 웹에서 제외된 편집 모드의 객체 메뉴는 명시적으로 거부한다.

TheWarBegins 실제 Session에서 사제 선택·강조 중 우클릭이 둘 다 해제하고, 일반 상태의 우클릭이 같은 실제 해시/픽셀 후보의 사제 SID를 반환하며, 화면 밖 좌표의 빈 후보가 정상 복귀하는 것을 확인했다. 좌클릭과 상위 메뉴·브라우저 이벤트 연결은 남으며 미션 플레이를 의미하지 않는다. Challenge 및 편집 분기는 실행하지 않았다.

검증: Node v26.13.0 전체 6,294건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 마지막 Node v22 전체 검사는 E795이며 이번 단위까지 이후 v26 전체 검사 5/8회다.
