# 브라우저 Tutorial3~6 진입과 대포 프레임 (WB04-E1011)

실제 캠페인 목록의 Tutorial3~6을 기존 Guide·Session과 각 원본 단계 판정기에 연결했다. 다른 일반 미션과 현재 미션 교체는 아직 허용하지 않는다. 각 시험은 테스트 저장소에 선행 Tutorial 완료 값을 넣어 목록 잠금 규칙을 유지한다.

Tutorial5 첫 실행에서 썬더 캐논이 Canon 코드 배열을 FrameCodeTable로 잘못 받아 발사 중 예외가 났다. Session 전투 결선이 같은 World의 현재 FrameCodeTable을 빌리도록 수정했다. 대포·아이스 캐논·Archer·Session Node 검사 33건과 Chromium에서 각 Tutorial의 실제 진입·안내 종료·게임 시계 3초 검사가 모두 통과했다. 각 목표 수행, 승리 및 자연 완주와 HUD는 미검증이다. E1002 고정 Node 26 전체 6,558건이 통과했고 E1006 고정 Node 22 전체 회귀를 실행 중이다.
