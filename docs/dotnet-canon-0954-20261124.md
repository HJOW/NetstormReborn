# dotnetpj 0.954 — 0x26 메타 geometry 본체·설치 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 0x26 메타 geometry의 송신 관찰기와 수신 본체·고정 F 설치를 같은 분배기에 연결했다. 0.953의 0x0f Root 응답·2번 연결 종료와 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientMetaGeometry.Observe`는 40a3e0 전체를 이식한다. 수신 방향은 버퍼를 읽지 않으며 두 미작성 길이 진단 뒤 현재 mod/contact 길이로 선언 WORD를 `modLen+contactLen+9`로 쓴다. 0.954에서 추가됐다.
- `ClientMetaGeometry.Receive`는 4b45a0 전체를 이식한다. 화면 한계→mode 0→contact 셋 이하 조기 반환→원점/두 반경→mode 1 순서를 보존한다. 첫 세 DWORD일 때 둘째 반경의 오래된 값을 보존하고 넷 이상이어도 추가 contact는 읽지 않는다. 0.954에서 추가됐다.
- `ClientMetaGeometry.Install`은 0x26의 원문 packet 관찰기·버전·가변 길이와 고정 F를 설치한다. CS0/메타 모드/송신자/known/World 선행 관문은 두지 않는다. 0.954에서 추가됐다.
- `ClientChallengeGlobals.GeometryMode`는 005467d4의 현재 DWORD 장기 owner다. 최초 BSS0이며 공통 CS 배치 반경 선택을 같은 주소에서 읽고 쓴다. 0.954에서 추가됐다.
- 카메라 한계·모드·좌표의 실제 메뉴·세션 결선은 세션·R5 메뉴 연결에서 잇는다.

## 검증

- Release 테스트 빌드는 오류 0이다. 신규 경고 0이다(기존 6건만: Core 검사 3건·Client 검사 3건).
- 신규 9건(미연결·설치 metadata·수신 관찰 무시·송신 길이/진단·짧은 contact 한계/mode 0·긴 contact 좌표/mode 1·stale 둘째 반경 보존·설치 수신 결선·짧은 패킷 거부)은 통과/실패 0이다. Root 응답·연결 종료·배틀 시작·챌린지 이웃 검사를 포함한 35건이 함께 통과한다.
