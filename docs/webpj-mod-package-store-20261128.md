# WB04-E1473 모드 패키지 검증과 기본 꺼짐 보관

`mod-package.js`는 공통 선언/버전·UTF-8·파일/모듈/구문 크기·경로·엔트리/default export를 검사한다. 이미 잠금 설치된 Acorn8.19.0(MIT)을 직접 의존성으로 고정하고 신뢰 호스트가 구문 분석기를 주입한다. 파일 선택/검증 단계에서 모듈은 실행하지 않는다. 실제 모듈 실행/격리·파싱 시간 제한은 다음 격리 실행기 단위다.

AST로 실제 import/re-export를 분석하므로 주석·문자열의 import 문구를 오인하지 않는다. 패키지 안 정적 상대 참조와 순환 그래프는 허용하고, 누락 모듈·경로 탈출·URL/bare/dynamic import·import.meta/속성·async/await를 거절한다. JSON의 덮어쓴 중복 키, Windows 예약 이름·대소문자 경로 충돌, 단독 surrogate도 거절한다. 공통 스키마/명세에 이식 규칙을 반영했고 id/미션 번호의 마지막 줄바꿈 정규식 예외도 닫았다. 코드 원문의 줄바꿈/유니코드는 바꾸지 않는다.

`ModStore`는 단일 `netstorm.mods.v0` 키에 검증된 패키지 원문·활성 상태·마지막 오류를 저장한다. 신규/명시 교체는 항상 꺼짐이고 같은 id는 명시 교체 없이 덮어쓰지 않는다. 작업을 직렬화하며 단일 키 저장 성공 뒤에만 현재 목록을 바꾼다. 용량/접근·손상·다른 탭 변경을 실패로 보고 기존 정상 목록/원문을 보존한다. 저장소 없는 환경을 영구 저장 성공으로 처리하지 않는다. 런타임 오류 시 즉시 실행 중지는 다음 실행 관리자가 먼저 맡고 저장소는 해당 모드의 꺼짐/오류 기록을 담당한다.

검증은 Node26.13.0과 Node22.23.5에서 각각50/50·실패/취소/건너뜀0이다(API20·입력9·신규19·기존큐2). 같은 패키지/RNG/29개 Math double 벡터도 양쪽 V8에서 통과했다. 실제 브라우저 파일 선택/localStorage UI와 자동 실행·CSP/네트워크/무한 루프 격리 검사는 아직 미완료다. E1472의 아군AI1-1 실제 입력 검사를 이 단위에서 반복하지 않았다. [소스 해시/검사 출처](webpj-e1473-evidence/provenance.json).

최종 전체 ESLint 선행 운영 빌드가 종료0(webpack110.949초), 번들3,517,946바이트/이전과 바이트 동일을 확인했다. 아직 앱의 실행 흐름에 자동 연결되지 않아 이전 운영 번들과 같아야 한다. 현재v26=4/4·v22=8/8이므로 소스·공통 적합성 입력을 고정하고 E1474 Node26 전체 → E1475 Node22 전체를 순차 진행한다. 새48검사를 합친 전체 예상은6982건이며 실제 수가 최종 기준이다. 두 전체/원시 해시 확인 전에는 제품·검사·의존성·공통 fixture를 바꾸지 않는다.

다음 제품 단위는 불투명 iframe의 전용 Worker/능력 격리, 허용한 패키지만의 ES 모듈 로드,1000ms 감시 종료와 원래 게임 시계 장벽, Options 파일 선택/관리·Reset All 연결이다. DN 실제 구현 중지는 유지한다.
