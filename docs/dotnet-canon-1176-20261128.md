# 1.176 같은 게임 시각의 1-1 관측

동일 시드·25ms·1024×768에서 기존 1.171 CPP 40프레임과 현재 DN 사본 374프레임을 비교했다. 덤프의 게임 시각 비트는 양쪽 모두 `4621453200119247667`, **9.35초**다. 새 DN은 390프레임까지 단순 대기한 뒤 종료0이며 원본 1,392파일은 실행 전후 불변이다. 포획·공격·승리 입력은 없었다.

두 논리 화면의 전체 차이는 **35,033/786,432픽셀**, 왼쪽 아래 80×75 미니맵 차이는 **0/6,000픽셀**이다. CPP40과 DN374의 공통 SID 1,911개 중 타입 1,838개·소유자 1,880개·프레임 1,545개·전체 슬롯 1,418개가 일치하며 CPP 전용 24개가 있다. CPP40/DN40의 전체 화면 차이 35,202픽셀은 다른 시각 조건의 별도 관측이다.

같은 DN의 40→374프레임에서 22개 슬롯이 바뀌었으며 화면 3,211픽셀이 바뀌었다. TYPE122 14개의 프레임은 CPP40에서 모두4, DN40에서는 모두3, DN374에서는 모두0이다. 따라서 이 시각 일치만으로 진행·난수·애니메이션 상태까지 같다고 볼 수 없고 1픽셀의 생성 원인이나 L4a 완료를 증명하지 않는다. 캡처·덤프·실행 인자와 원본 감사는 `extracted/dotnet-clock-1176/`에 있다.
