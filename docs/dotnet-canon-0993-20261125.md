# dotnetpj 0.993 — RU-4b HUD 도킹 작성자 지도 저장소 공유

2026-11-25, HJOW-Athlon. R4-6 Root 공장 묶음의 RU-4 두 번째 단계다. 같은 실제 메뉴 트리/화면과 FullDeck/MapRevision owner로 HUD 전역과 도킹 본체를 만들고 미션 진입 경로에서 초기화한다. 초기 미니맵 공장처럼 Open이 아닌 같은 owner 공유만 수행하며 구분선/전체 부모 생성과 살아 있는 선택 수명은 후속에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Game/ClientHostGame.HudDock.cs`: 같은 실제 메뉴 트리(owner `HostMainMenu.Tree`)의 `Create`/`TreeState`와 같은 장기 `FullDeckBox`/`MapRevision`으로 `HudDockGlobals`를 만들고 같은 트리에 묶은 `HudDock`을 소유한다. 전체 viewport로 지도 영역을 대체하지 않으며 `NativeMapView`는 기존처럼 같은 메뉴 owner의 `CurrentMapView`를 읽는다. 토큰 getter는 실제 전체 부모(`UberRootNode`)가 없으면 설치 전 명시 실패로 거부하며 RU-3 나머지 전체 부모에서 잇는다. 화면 후처리·채팅 표시/입력·기본 입력 미연결은 R5 표시·RU-5 Chat 효과에서 잇는다는 명시 오류로 남긴다. 진입 경로(`LoadContent`)에서는 미니맵 설치 다음에 호출되며 메뉴 경로를 바꾸지 않는다. 0.993에서 추가됐다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: `InitializeNativeMinimap` 다음에 `InitializeNativeHudDock`을 호출한다. 메뉴 경로·미션 세션 조립·해제는 바꾸지 않는다.
- PORT_MAP에 2행을 더했다. `cpppj/src/client/HudDock.cpp`·`cpppj/src/client/UberHud.inc` → 제품 HUD 도킹 작성자 파일.
