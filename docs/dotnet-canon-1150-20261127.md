# 1.150 타일 묶음의 공통 객체 출력

C++ `ClientRendererFrame::Submit`은 일반 객체뿐 아니라 묶음의 타일 멤버도 같은 `SpriteDraw`로 제출한다. 제품에 실제 `SpriteWorldRenderer`가 연결된 경우 해당 경로를 사용해 현재 가상 프레임과 다리 추가 그림을 읽도록 했다. 별도 출력기를 연결하지 않은 기존 독립 타일 검사는 유지한다. 다리 수명 숫자의 비기본 개발 모드는 미이식 상태다.

실제 미션 세션·자산의 공통 출력과 타일 전용 표를 비운 제출, 독립 타일 제출 검사 3/3과 타일·월드 수집 검사 12/12가 통과했다. 최초 넓은 검사 실행은 장시간 결과가 없어 중단했으며 원인은 확인되지 않았다.

캠페인1-1의 고정 시각·미니맵 드래그 75/81/89/95/105프레임은 1.148과 모두 픽셀 단위로 같고 종료0이다. 해당 CPP 차이는 각각 32,836/53,107/31,994/32,133/31,935픽셀로 그대로다. 튜토리얼1과 surrounded의 진입·대기도 종료0이고 90프레임 월드 덤프가 1.147과 같다. 두 실행에서 원본 1,392파일은 변경되지 않았다. 결과는 `extracted/dotnet-sprite-1150-first/` 및 `extracted/dotnet-sprite-1150-missions/`에 있다. 이 관찰은 승리·전체 미션 일치나 개발용 다리 숫자 복원의 증거가 아니다.
