# dotnetpj 0.903 — RU-2 나머지 Bind 결선·26F Root 공급 수신

2026-11-24, HJOW-Athlon. 0.902 공급값 뒤 RU-2 나머지다. `StartMission`에 고정 26F의 Root 공급 결선을 잇는다. 기존 Load 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientHostGame.StartMission`은 `worldLoad.Load()` 뒤에 `session.BindSquidPacketDevices(storage, names, effects)`를 호출한다. 근거: `cpppj/src/client/RawCampaignSession.cpp` 5325~5562행의 `ReceiveFixedGameplayPacket`과 `cpppj/src/client/CampaignClientServices.cpp` 112·114·190행의 `names/screenSize` 공급이다.
- 이름은 같은 실제 설정 owner로 만든다. `Language`는 `RootLanguageNumber`로 읽고 `Substitute`는 `ExtendedText.DecodeDisplayText` 뒤 실제 `SubstituteLocal`·`EncodeDisplayText`를 거친다. 영어 경로의 `Translate`·가상 레벨과 `FormPacket` 외 큰 본체(Gun/Flyer/Aviary 등)는 R5/R6에서 잇는다. 미연결 하위는 일반 Pre/Post/no-op으로 통과시키지 않고 명시 실패로 둔다.
- 효과는 같은 실제 owner를 빌린다. `Tell`은 같은 세션 수명 동안 실제 바이트를 보관하고 로그에 남기고, `Log`는 같은 실제 로그에 남기고, `Command`는 같은 실제 입력 큐에 넣고, `ScreenSize`는 같은 실제 `Screen`을 읽는다. `FormPacket`은 같은 세션 수명 동안 실제 바이트를 보관한다.
- 장면음악·전체 State·색표7·zone·세션 InBattle 완전 결선 중 이미 연결된 것(`Music.CurrentBattle`·`StateWorldGlobals`·`OwnerMode.Battle`·생산 색표7 소비자)은 0.902 검증대로 유지하고, 나머지는 R5/R6 표시·음향 결선에서 잇는다.
- PORT_MAP은 이전 1825행의 값·순서·base를 보존하고 2행을 추가했다(자료 1827행). fixture 496개는 그대로다.
