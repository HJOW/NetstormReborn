# dotnetpj 0.986 — RU-3a NSInfo 외부 장치 실제 공급 공장

2026-11-25, HJOW-Athlon. R4-6 Root 공장 묶음의 NSInfo 외부 장치 갈래를 잇는다. cpppj `RawMenuControls`의 참가자 메뉴와 `NativeNsInfoInput`의 루트 입력 외부 장치를 같은 Root 실장치 묶음으로 공급한다. 창 생성과 바깥 UI 설치(RU-3b)는 후속에서 잇는다.

## 변경과 원문 대응

- `HostNsInfoRootDevicesHooks`: 같은 Root의 실제 12BYTE 상태 송신과 추방·guy 음향, 참가자 메뉴와 카메라, 마우스와 기본 입력, 메타 배치와 Player·Battle 메뉴 9종을 요구한다. 하나라도 없으면 미션 진입 전에 거부한다. 0.986에서 추가됐다.
- `HostNsInfoRootDevices.SendStatusPacket`: 같은 실제 12BYTE 패킷을 만들고 채운 뒤 전송한다. 원문 1fh 뒤 부분효과 갈래와 같은 순서다. 채우기는 `NativeNsInfoInput`이 4와 8 오프셋의 두 DWORD와 음향 호출로 수행하고, 묶음은 그 앞뒤의 할당과 전송만 맡는다. 0.986에서 추가됐다.
- `HostNsInfoRootDevices.Build`: 위 15 갈래를 `HostNsInfoDevices`의 같은 이름 장치에 묶고 읽기과 번역과 문자열과 변경, 소유자와 기술과 랭크와 설명, Chat 명령 효과(RU-5)와 전투 예약(RU-3b 이후)은 기존 묶음을 그대로 유지한다. 수송 backend(R11)와 음향·메뉴·카메라 실장치(R5·R6)는 호출자가 같은 Root 실장치를 주입한다. 0.986에서 추가됐다.
- PORT_MAP에 2행을 더했다. `client/RawMenuControls.cpp`·`client/NativeNsInfoInput.cpp`→`HostNsInfoRootDevices.cs`.
