# 1.151 정기 회귀의 선택 검사 수명 교정

1.150까지의 Release 전체 회귀에서 Assets 383/383, Core 4,121/4,121, Client 2,954통과·1실패·1미실행이었다. 실패는 `HostSelectionLifetimeTests.RecheckViaActiveClearsMouseType`이며 목록이 비어 있었다. 원시 결과는 `extracted/dotnet-1151-regression/`에 있다. 따라서 전체 회귀 성공으로 세지 않는다.

세션은 의도적으로 선택 링크를 약하게 빌리며, 실제 선택 객체가 링크의 강한 소유자다. 실패한 검사는 `MakeUserSelection` 반환값을 즉시 버려 재확인 전 GC가 링크를 수거할 수 있었다. 실제 UI 소유를 모사하도록 해당 선택을 호출 뒤까지 보존하고 강제 GC를 추가했다. 같은 전제의 다른 세 검사도 `GC.KeepAlive`로 수명을 명시했다. 제품의 약한 참조나 반환 동작은 바꾸지 않았다. 선택 수명 집중 검사는 강제 GC와 만료 분기를 포함해 8/8 통과했다. 전체 회귀는 수정 후 재실행해야 한다.
