# 미션 World 논리 화면 변경 (WB04-E955)

기준선 뒤 `GameWorld::Resize`의 캠페인 경로에 맞춰, 브라우저 레이아웃 변경 시 현재 `CampaignGameWorld`의 논리 크기와 카메라 목표 한계를 갱신하고 새 표면·입자·위치 음향 보기를 공개한다. 기존 카메라 목표 픽셀과 현재 Renderer view·snapshot은 그대로 유지한다. 같은 크기에서는 한계와 변경 표시를 다시 쓰지 않고 현재 보기만 갱신한다. 잘못된 크기와 반납된 World는 거부한다.

실제 TheWarBegins World에서 로그인 전 크기 변경과 로그인 뒤 640×480에서 1024×768로 바꿀 때 두 축의 원본 칸 크기(16×11), 카메라 보존, 표시 영역과 같은 크기 재호출을 확인했다. 실제 Tutorial1의 앱 레이아웃 경로에서도 16:9 전환 시 새 Screen·Renderer와 World 영역이 함께 바뀌는 것을 확인했다. 월드 합성·Present, 입력과 완전한 카메라 적용은 여전히 남아 있어 실제 플레이 검증은 아니다.

검증: Node v26에서 실제 TheWarBegins 로그인 World 검사 1건과 앱 화면·요청 경로 연관 검사 14건이 통과했다. E950 고정 커밋의 격리 전체 회귀는 6,519건 중 6,518건 통과·1건 건너뜀·실패 0이다. 건너뛴 항목은 격리 트리에 dotnetpj 영역 패턴 자료가 없었기 때문이다. 해당 자료를 포함한 E954 기준 Node v26 정기 회귀를 `extracted/webpj-e954-node26-isolated.log`에서 실행 중이며, E955까지의 Node v22 정기 전체 회귀는 v26 종료 뒤 실행해야 한다.
