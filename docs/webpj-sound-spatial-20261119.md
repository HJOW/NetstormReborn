# 위치 음향의 화면·좌우·음량 계산 (WB04-E960)

기준선 `225553df`의 `Sound.cpp`에서 위치 음향의 월드→화면 투영, 화면 주변 여유를 포함한 가시 판정, 스피커 교환을 포함한 좌우 균형과 거리 음량을 이식했다. 원본의 signed DWORD 감김·곱셈, 0쪽 정수 나눗셈과 ±10000 제한을 보존하고, 원본 나누기 예외 경계는 오류로 알린다. 화면 투영은 기존 카메라와 같은 단정도 16×11 계산을 사용한다.

보호 원본 실행 없이 기존 `cpppj/tests/fixtures/soundplay-x86.tsv`의 10.78 화면 투영 399행과 위치 판정·좌우·음량 3,360행을 모두 비교했다. 화면 폭 0과 가운데 좌우 예외, 기존 SoundProcess와 fixture 목록을 포함한 연관 Node v26 검사 18건도 통과했다. 재생·중복 버퍼·재생 핸들·Web Audio 음량/좌우 적용 및 실제 미션 연결은 아직 남아 있다.

E958 고정 Node v26 전체 회귀가 별도 작업 트리에서 진행 중이며, v22 정기 전체 회귀는 그 뒤 실행해야 한다.
