# WB04-E979 미션 Renderer 표시 수집

같은 미션 World·Session·카메라와 화면 크기를 빌려 공통 표시 작업 배열을 소유한다. UI → 입자 → 지면 행 묶음 → 일반 객체 → 커서 미리보기 순서로 기존 실제 수집기에 전달하고, 원본 5,000칸 한도·지면 덮임·UI 전용 dirty 관문과 묶음 토큰을 보존한다. 화면 높이가 바뀌면 지면 묶음 수집기를 다시 만들어야 하며 결과 배열·묶음은 다음 수집 전까지만 유효하다.

검증: 실제 Tutorial1 로그인·Start 후 현재 카메라와 월드에서 지면 묶음 및 일반 객체가 함께 수집되고 UI 전용 dirty에서 나머지가 생략되는 것을 확인했다. 이 시험의 UI 수집기는 명시 관찰 장치다. 공통 제출 원본 322행·지면 묶음 353행, 객체 및 투영과 함께 Node 29건 통과.

남은 범위: 실제 앱 Gump UI 수집·출력과 수집 목록 정렬/제출, 원본 배경·구름, Renderer/Screen 합성 및 픽셀 동일성은 아직 연결하지 않았다. E974 고정 Node 26 전체 회귀가 실행 중이다.
