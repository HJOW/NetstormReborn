# dotnetpj 0.838 — Native Root 전송·선택과 현재 지도 저장소 연결

2026-11-23, HJOW-Athlon. 0.837 이후 목표를 재개했다. 전체 Load/Editor 공개를 위해 필요한 Root 장치 중 첫 전송·Process 선택 장치를 실제 제품 시작 경로에 연결했다. 전체 Native Root와 Load 완료는 아직 미완료다.

## 변경과 원문 대응

- `ClientSurfaceGlobals.BindNativeTransmission`은 첫 Process 저장소 생성 전에 같은 Client의 Registry·Player·약한 Source 장부를 연결한다. 생성 시 현재 시각·Player·선택·송신을 조회하거나 초기화하지 않는다. 다른 Client 연결표는 쓰기 전에 거부한다.
- 방송은 `ClientMain.cpp`의 Player flag → 현재 NULL 연결 → 현재 로컬 제외 → 실제 Source 대여 → 선택 노드 가상 송신 순서를 따른다. 다음 대상에서 현재 Player/owner/슬롯을 다시 읽고 같은2048BYTE 가변 버퍼를 전달한다. 대상 송신은 실제 `SendMutableNative` 관문과 observer/큐를 사용한다. NULL 연결에 Source나 Runtime을 만들지 않는다.
- Process의 선택은 같은 전체 DWORD를 읽는다. 선택 해제는 빈 메뉴에서는 기존 실제 Clear 부모를 호출하고, Session이 대여 중이면 현재 전체 Runtime을 호출 끝까지 고정한다.
- `RawButtonControls::MapViewRect`와 `GumpTreeState::mapView{}`를 대조했다. 기존 DN 공통 트리가 화면 전체로 초기화하던 지도 영역을 원본 BSS0으로 맞췄다. `HostMainMenu.CurrentMapView`와 Game의 Native 표시 장치는 공통 정렬/HUD 도킹이 쓰는 같은 현재 사각형을 읽는다. 화면 크기로 대체하거나 완성된 HUD로 판정하지 않는다.
- PORT_MAP은 이전1635행의 값·순서·base를 보존하고 `ClientMain.cpp → ClientSurfaceGlobals.Transmission.cs` 한 행만 추가했다(자료1636·port1148/L1 481/session7). 연결 fixture452개는 그대로다.

## 검증

Release 솔루션 빌드는 오류0·기존경고6이다. 초기 컴파일에서 현재 선택의 UIntBox와 `Borrowed()` 호출 표기를 교정했다. 첫 집중177건 중176통과/1실패는 테스트 observer를 실제2ch 대신 다른 메시지 번호에 연결한 문제였다.

첫 실제 미션 진입은 Native 삭제기 생성이 표시 장치를 요구하면서 아직 미연결인 Root 지도 getter에서 실패했다. 표시 실행기의 조회 시점은 CPP와 같음을 확인했고, 위의 같은 지도 owner/BSS0 연결로 해결했다. 해당 실패의 로그·사용자 루트·원본 감사는 `extracted/dotnet-0838/first-gate/`에 보존했다.

확대 Client560선정은559통과/1실패였다. 남은1건은 이미 해제한 Source를 검사 장면 종료에서 다시 닫던 정리 오류였다. 제품을 바꾸지 않고 검사 정리만 교정한 뒤 해당 전송 계열8/8을 다시 통과했다. Core 집중69/69도 통과했다. 즉 선정 고유629건의 실패는 교정됐으며, 교정 후629건 전체를 다시 실행한 기록은 아니다. 신규는 전송8사례와 현재 지도 owner1사례다.

같은 제품 빌드에서 `thewarbegins`·`tutorial1`·`surrounded`의120프레임 진입이 모두 종료0이며90프레임 전체 덤프와 지표가0.836과 같다. 양쪽 클론 메뉴의10/40/120프레임 BMP3개도 전체 바이트가 일치한다. 원본1392파일과 실행6파일은 전후 불변이다. 집중 검사·실행 사본의 제품 DLL도 같은 해시다. 최종 감사는 제품/대응표가 고정되고 검사 정리1파일만 바뀌었음을 확인했다. `cpp_sync.py`는 연결452개/생성 자료 감사를 통과했다.

근거는 `extracted/dotnet-0838/`의 build-final.log·client-final.trx·client-correction.trx·core-focused.trx·tests.json·capture-summary.json·menu-summary.json·source-audit.json·port-audit.json이다. 전체 정기 회귀는 반복하지 않았으며 마지막은0.836(5,942통과/65진입), 다음은0.840이다. M1 0/34·고정 수신18/26은 그대로다.
