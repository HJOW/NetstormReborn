# 원본 장면 음악 감독

WB04-E1059는 10.78 장면 음악의 결과 곡 잠금, 현재 곡 요청, 다음 원소 곡, 실시간 기한, 전투·대기실·메뉴 선택, 원본 게임 난수와 팔레트·천둥 효과 순서를 복원한다. 현재 전투 조회는 부수 효과 뒤에도 다시 읽고 NaN 비교는 원본 x87 분기를 따른다.

독립 원본 관측 3,113행의 호출 순서·결과·곡·기한 비트·난수 및 상태를 모두 대조했다. 실제 전투 상태 재조회와 대응표를 포함한 Node 26 관련 9건이 통과했다. 최초 fixture 작성기의 입력 목록 반복과 복수 호출 구분을 교정했고, 현재 전투 재조회 검사에서는 시계 기한을 잘못 설정한 뒤 실제 재조회 시점으로 교정했다. 존재하지 않는 `random.test.mjs`를 최초 명령에서 제거해 유효한 시험만 재실행했다.

아직 실제 음원 채널·원소 팔레트·앱 프레임, State 정리의 음악 소유자와 연결하지 않았다.
