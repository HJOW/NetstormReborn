# WB04-E825 섬 런타임의 현재 Player와 진단

기준선 `225553df`의 `BindCurrentPlayers`와 `assertionAt`을 이식했다. 현재 Player getter는 결합할 때 호출하지 않고 첫 지역을 읽고 쓸 때 각각 다시 조회한다. 고정 기록을 다시 결합하면 getter를 해제한다. 선택된 진단 위치 장치가 있으면 원문의 식과 행 번호를 전달하고, 없으면 기존 enum 진단을 유지한다. 기준선 이후 대응 C++ 파일 변경은 없다.

읽기와 쓰기 사이에 Player base가 교체되는 경우, 지연된 크기 오류와 진단 위치 8개를 확인했다. 원본 섬 런타임 1,009행의 두 Player 모드, 섬 검색과 Vortex 검사를 포함한 집중 검사 16건이 통과했다. 실제 Client 장기 소유자·Native 소비자 연결과 World 없는 건설 소비자 연결은 후속이다. 게임 창은 실행하지 않았다.

검증: Node v26.13.0 전체 6,319건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E819 Node v22 전체 검사 뒤 v26 전체 회귀 6/8회다.
