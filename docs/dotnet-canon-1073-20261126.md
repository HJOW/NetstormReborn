# dotnetpj 1.073 — R5-3c3 프레임 구동 결선

2026-11-26, HJOW-Athlon. R5 타입별 Draw·효과 묶음의 다섯째 조각이다. 미션 월드의 앞단·
수집·제출을 매 프레임 실제 화면 버퍼에 합성하도록 제품 루프에 이었다. 타일이 아직
보이지 않는 원인을 실측으로 규명했고 L4a 타일 일치는 R5-4·R6로 넘긴다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Game/ClientHostGame.WorldDrawing.cs`: 신규. `BindMissionWorldDrawing`·
  `RefreshWorldTileModes`·`RenderMissionWorldFrame`을 두었다. 근거: cpppj
  `ClientRendererFrame`의 수집기 재생성·`PrepareRendererFrame`·`Drawing`·`Finish` 순서다.
  앞단 상태·구름 4칸·SHP·타일 모드를 미션 시작에 묶고, 매 프레임 지도 영역 전역·팔레트 변경
  추적·앞단·수집·배경·제출·present·구름 정리를 수행한다. 출력은 기존 전체 텍스처 경로에
  맡기고 dirty만 여기서 비운다. override 게이트·묶음 숨김·소유자 색표는 R5-4·R6에서 잇는다.
  1.073에서 추가했다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 미션 시작에 프레임 구동 장치를 묶고 매
  프레임 카메라 적용 뒤에 월드 합성을 이었다. 영상 갱신 잠금 중에는 건너뛴다. 1.073에서 수정했다.

## 검증

- 미션 진입 130프레임 실행은 종료 0·FATAL 없음이다.
- L2 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)를 같은 시드로 재수집했다
  (`extracted/dotnet-l2-1073`, 양쪽 exe 종료 0). DN `f090.tsv` 3건은 0998 덤프와 바이트
  일치한다(M1 0/34 유지, L2 기준선 0998 유지). 프레임 구동은 논리 상태·난수·해시 내용에
  닿지 않는다.
- L4a 재측정(`thewarbegins` 100프레임, `extracted/dotnet-l4a-r53c3`)은 불일치
  747,968/786,432픽셀(95.1090%)로 1.069 기준선과 같다(sha256 `a23ceb31…` 동일).
- 원인 규명(임시 진단 출력 후 제거): `NativeMapView`가 미션 내내 (0,0,0,0)이라 수집이
  0건이다. HUD 도크 배치(0x3a/0x46)가 제품에서 한 번도 실행되지 않아 `TreeState.MapView`가
  갱신되지 않는다. 도크 자식 생성·배치는 R5-4에서 잇는다. 메뉴 배경이 월드를 덮는
  메뉴↔미션 전환은 R6 상태 분배에서 잇는다(SL-5 잔여).
- 원본 1,392파일은 실행 전후 불변이다(`originals-audit.json`이 0998 수집과 SHA-256 일치).
