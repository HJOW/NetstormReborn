# 브라우저 다리 배치와 건설 갱신 (WB04-E1008)

건설 통지의 원본 완료 경로가 요구하는 설정 조회·벽시계·현재 Renderer 전체 갱신·간헐천 진단을 실제 앱 장치에 연결했다. 기존 미연결 화면 갱신 때문에 로컬 건설 요청 처리 중 예외가 발생하던 문제를 수정한다.

실제 Tutorial1 신전 주변의 배치 판정으로 가능한 지점을 찾은 뒤 생산 다리를 사용자 입력으로 내려놓아 0x3e 건설 요청과 같은 월드의 다리 객체 증가를 Node와 Chromium에서 각각 확인했다. 원본 미리보기 관측 등을 포함한 Node 9건과 Chromium 미션 검사가 통과했다. 생산 패널, 방향 회전, 여러 다리 조각으로 간헐천 연결 및 자연 완주 검증은 남았다.
