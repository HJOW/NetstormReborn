# 미션 음향 공개 자산 (WB04-E957)

공통 `assets/game-data`의 효과음 218개와 음악 9개가 웹 공개 루트에서 빠짐없이 사용 가능하도록 자산 준비 도구와 매니페스트를 확장했다. 이미 메뉴에서 사용하는 효과음 두 개와 음악 한 곡은 기존 묶음에 유지하고, 나머지 효과음 216개(9,762,888바이트)와 음악 8개(108,288,296바이트)를 각각 `mission-sound`와 `mission-music` 묶음으로 복사했다. 파일은 변환하지 않으며 기존 자산과 같이 크기·SHA-256을 기록한다. 원본 게임 디렉토리는 수정하지 않았다.

새 묶음은 메뉴 적재 경로에 추가하지 않았으므로 메뉴 시작 시 일괄 다운로드되지 않는다. 이는 음향 파일의 배포 준비이며, 미션에서의 선택적 다운로드·해독·위치 음향·반복 재생·음악 선택은 아직 연결되지 않았다. 미션 음악을 모두 내려받으면 약 108MB이므로 실제 재생 장치는 전체 묶음 일괄 다운로드가 아닌 필요한 곡만 선택해 적재해야 한다.

검증: 공통 자산 전체 목록·경로 중복·복사본 바이트와 해시, 같은 출처 및 기존 메뉴 적재 요청 관련 Node v26 검사 14건이 통과했다. `node webpj/tools/prepare-assets.js --check`도 통과했다. E954 기준 격리 Node v26 전체 회귀는 6,526건 중 1건이 실패했다. 이전 독립 World 로그인 검사에 E951의 새 Gump 장치가 준비되지 않아 발생했으며, 이 음향 자산과는 다른 경로다. 해당 검사를 교정하고 전체 회귀를 다시 실행해야 한다.
