# 앱 생산 정보 메뉴

WB04-E1046은 실제 미션 생산 패널에 원본 장식 정보 메뉴를 설치한다. 마우스 오른쪽 버튼도 Gump에 먼저 전달하고, 내용물·TYPE·비용·소유자·도움말 문구는 현재 Session과 Client Player 식별자 및 설정 캐시에서 읽는다. 메뉴의 Help 명령은 실제 큐를 통해 TYPE 이름과 번역 Type 접미사의 주제로 기존 도움말 창을 열며 패널 반납 시 메뉴와 자식도 정리한다. 구분선은 같은 실제 메뉴 인스턴스 수를 조회한다.

Tutorial1 실제 Session에서 격자 항목·Form·Help 큐를 검사했고 원본 정보 3,888행·메뉴 154행을 포함한 Node 26 관련 36건이 통과했다. Chromium에서는 실제 버튼으로 미션을 시작하고 생산 항목을 우클릭해 정보 메뉴와 Help를 열고 OK로 닫았다(1건 통과, 페이지 오류 0). E1043 고정 전체 회귀는 Node 22와 26 각각 6,567건 통과, 실패·취소·건너뜀 0이다.

생산 메뉴의 회수 명령 소비는 아직 연결되지 않았다. 기존 Help 창은 주제를 표시하지만 원본 QuickHelpHtml의 현재 TYPE 상세 치환은 아직 연결되지 않았으며 다른 객체 메뉴와 실제 미션 완주 검증도 남았다. 메뉴가 우클릭으로 열리는 것만으로 전체 생산 및 승리를 완료했다고 보지 않는다.
