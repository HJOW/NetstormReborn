# WB04-E1477 AI 참가자 조회와 유계 결과 사건

공개 조회가 로그인 bit만 확인해 AI-only 참가자를 누락했다. 기존 실제1-1 덤프에서owner2는flags0x20/실제brain비0이고 NativeRawPlayerParticipation.attachBrain도 로그인 bit를 추가하지 않는다. 원래checkLogin/attachBrain으로 만든 후보 검사가[1,2]대신[1]을 반환하는 실패를 재현했다. 현재는 로그인 또는 실제brain이 있는 참가자를 읽고, 제거 뒤 남는flags0x20만으로는 참가자를 포함하지 않는다. 조회로 참여 기록/SP/RNG를 쓰지 않는다.

같은 경계의 commandResult/tick 두 콜백은 각각8명령을 만들 수 있으므로 다음 결과 사건은 최대16항목을 받게 했다. 호스트는 경계당 모드별결과1회/tick1회로 제한해야 결과 자기증폭 없이 다음 대기량도16에 머문다(실제 스케줄러는 다음 단위). 개별 요청 출력은 여전히8개이며 결과는요청사건/명령번호 오름차순·중복금지다. 특정 모드만 결과를 받을 수 있으므로 sequence는각모드의미션안에서독립증가하고 효과는호스트경계/사건종류/모드id순서로확정한다. 공통명세/JSON·DN인계에 같은 보강을 반영했고 공개API이름과 현재예제출력은 같다.

검증: 수정전후 독립 후보0/1→1/1. Node26집중56/56(API23·참가자3·입력9·패키지19·기존큐2), Node22의변경API/참가자26/26을 통과했다. 신규6검사는AI등록/반납·읽기불변/방향동맹·SP초기화전조회차단·16결과/17거부·중복/순서·모드별sequence를 포함한다. Chromium실제아군AI1-1은publicowners[1,2]·원래풀/RNG/프레임불변·원래큐사제선택/게임오류0을1/1확인했다(12.3초). 승리검사는없다. 선행전체ESLint/운영빌드종료0(64.089초), 번들3,517,946바이트는이전과같다. [원문출처/소스해시](webpj-e1477-evidence/provenance.json).
