# WB04-E819 시작된 AI 미션의 Client State 정리

기준선 `225553df`의 State 정리 부모를 실제 `GuardMyBack` 대본·Fort의 내부 Login/Ready와 Start 뒤 호출했다. 생성된 AI brain과 같은 Client의 난수·SP 저장소, Player·Kernel·표면 소유자를 공유했다. 시작 자금 1,200 SP가 정리 뒤 0이 되고 Gump 정리·교체 뒤 실제 Session/표면 대여가 반납되는 것을 확인했다. 집중 검사는 통과했다.

UI·음향·시계는 관찰용 장치다. 실제 앱 Client의 전송·메뉴·음향 수명과 Native 경계, 승패·자연 플레이 후 정리는 아직 검증하지 않았다. 게임 창은 실행하지 않았다.

검증: 집중 검사 1건과 Node v26.13.0·v22.23.3 전체 각각 6,306건 통과(실패·취소·건너뜀 0). 두 버전은 순차 실행했으며 v22 검사 뒤 v26 전체 회귀는 0/8회다. 대응표는 1,160행 오류 0이다.
