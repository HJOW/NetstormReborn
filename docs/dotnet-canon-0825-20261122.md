# dotnetpj 0.825 — 생산 격자·항목·안내와 공통 트리 연결

작업일2026-11-22, PC HJOW-Athlon. 실제 생산 부모의 선행 InventoryGump/InventoryItemGump/ProductionHintGump 전체 본체와 가상 분배를 이식했다. 실행 경로는`dotnetpj/src/Netstorm.Game/bin/Release/net10.0/Netstorm.exe` 한 곳이다. 생산 부모 생성/유지·정보 메뉴와 전체 Game Root/Native 장치는 계속 미완료다.

## 변경

- `InventoryGump`는 실제 같은 RawSidPool/RawContainedFinder와 GumpCreate를 사용한다. 격자/항목 전체 생성, 미작성 필드 보존, 두 번의 현재 목록 순회·mask/slot 최댓값·sqrt의 float 저장/ceil/CRT64절삭·최소/고정 행열·항목 생성/가상 부착, 내용물 통지·부모 전달/삭제·현재 커서와 점멸/표시 갱신 순서를 이식했다. 다른 내용물 목록을 만들지 않는다.
- `InventoryItemGump`는 네 dead 진단과 실제 자식 Kill/Cleanup, 현재 gumpFrame/전체 Canon 패턴 측정·decoder, 품질별 다리 프레임/현재 비용·SP·수량, 이미지/문자 자식과 장식, 현재 지식/입력 관문·픽셀 적중/왼쪽 선택/우클릭 전달/정보 메뉴를 이식했다. 비용은 먼저 float으로 저장하고 에디터에서도 SP를 읽는다. 원문처럼 효과 뒤 현재 필드와 next를 다시 읽는다. 기존 실제 자산/RawCanonPixelShape/CanonTypeDecoder 연결도 포함한다.
- `ProductionHintGump`는 실제 TextGump 파생과 별도 소유 문자열, 두 번역 wrapper, 벽시계4초·Idle/Kill, 기준 영역/좌표 감김·깊이·serial, 빈 head의 실제 출력 호출과 문자열→Text scalar 순서를 이식했다. NaN과 미작성 필드는 보존한다.
- `ProductionInventoryBindings`는 Source RawProductionControls의 해당 가상 분배 부분을 같은 공통 부착/사건/입력/Idle/scalar에 연결한다. 현재 resolver로 자기 파생만 선택하고 이전 다른 UI 슬롯을 보존한다. 물리 할당과 현재 owner의 수명은 전체 부모가 소유한다. 이 분배 연결만으로 생산 Root 생성/Native 설치 완료를 주장하지 않는다.

## 검증

최종 집중 검사는 **Core22·Client407, 합계429통과/실패0**이다. 이전0.823 집중 검사의 모든 이름을 보존했고 직전 전체0.824 대비 실제 신규 이름은 Client7개다. NETSTORM_DATA 없이 같은 솔루션 Release 오류0·경고3로 검사했다. 새 제품 경고는 없으며 예비 재빌드의 기존 Client null 경고3도 보존했다. 마지막 전체는0.824의5,879건이고 다음 정기 전체는0.828이다.

독립 원본 **538관측(격자170·점멸110·항목132·안내126)**을 모두 대조했다. 격자0xc4/항목0xc0의 전체 바이트·canary와 모든 생성 이미지0xb4/문자0xa4, 반환·lastType·시계/Idle500칸 표·현재 내용물 비트·실제 dirty 영역·모든 외부 호출 순서를 비교했다. 안내는 원본이 관측한116바이트·소유 문자열/효과·serial을 비교했으며 전체0xb8 물리를 관측했다고 확대하지 않는다. 격자 자료의 원본 순회 경계 Begin/Next만 기존 C++ 소비자와 같은 기준으로 비교에서 제외했고 실제 목록 계산은 기존 RawContainedFinder가 수행한다.

실제 설치 자산의 골렘/썬 캐논 두 사례에서 같은 기본/파생 트리의 전체 패턴 측정→decoder→이미지 자식→실제 SHP 픽셀/적중→같은 내용물 SID/serial 전달을 검증했다. 목록 재부착 뒤 이전 항목/그림이 지연 삭제되고 기존 메뉴가 유지된다. 실제 공유 Text/Style 조각을 사용하는 안내의 생성/측정→현재 Idle 만료→소유 문자열/조각/노드 반납도 확인했다. 비용/SP·Robust/정책·상위 선택 반환은 이 조합 검사의 명시 외부 장치이며 전체 게임 Native 장치 설치나 월드 내용물 생성 검증은 아니다.

예비 검사 작성 중 기존 Pool getter 중복과 잘못된 호출 표기를 제거하고 기존 속성을 재사용했다. 원문 격리 자료의 음수 DWORD 입력/할당 없는 SID 물리는 검사 전용 변환/입력 뷰로 교정했고 제품의 읽기 전용/할당 검사는 유지했다. 실제 자산 표의 자산 없는 슬롯은 기존 기하 메타 구성과 동일하게 처리했다. 관측 기대값은 수정하지 않았다. 모든 예비 로그/TRX는native-first~fifth와tree-first~third에 보존했으며 최종 새7사례는tree-third에서 통과했다.
