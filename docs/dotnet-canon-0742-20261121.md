ClientStateWorldCleanup.cpp/.h의 부모 바인딩을 이식했다. 기존 RawStateWorldCleanup 본체에 같은 Client/Surface/LocalState/NSInfo/Template/SP를 전달하고, 실제 연결표 정리·시계 보정/리셋·MetaZone·AI/사제 owner·SP·Core 선택·Template 반납·단일 Kernel 정리·Runtime 증빙 반납·Pool/목록/공간/그래프·Player 재구성·Zone을 원문 위치에서 호출한다.
