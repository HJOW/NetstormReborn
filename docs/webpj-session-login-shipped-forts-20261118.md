# WB04-E752 출하 미션 Fort 선택과 내부 로그인

출하 일반 미션 31개와 별도 데모 미션 `DemoStormRages`의 영어 스크립트를 `MissionScript`로 읽고, 각 스크립트가 선택한 원본 Fort를 실제 Session과 내부 전송으로 적재해 `27h`에서 `6eh`까지 로그인했다. 각 세션은 독립 소유자를 쓰고 phase 14·Ready·월드 객체 및 핵심 패킷을 확인한 뒤 반납했다. `GuardMyBack`·`DissolvedAlliance`는 두 Fort를 별도 검사에서도 직접 대조했다.

출하 미션 목록은 `dotnetpj/tools/l2_compare.py`의 31개와 세 데모 목록을 참고했다. 데모 중 두 개는 일반 미션과 같은 스크립트·Fort이므로 서로 다른 스크립트는 32개다. 이 시험은 **데모 모드의 Start·AI나 일반 미션 Start를 실행하지 않는다**. 로그인 전 UI·채팅·소리 장치는 명시적 관찰기로 제공한다. 자연 플레이·화면·소리 동일성은 미검증이다.

첫 시도에서는 실제 Fort 적재 중 사제 낙하 위치 음향을 요청해 시험의 `forbidden` 장치에서 실패했다. 사운드 호출을 기록하는 장치를 명시한 뒤 32개가 모두 통과했다. 실제 게임이나 브라우저 창, 사제 포획·희생·승리 또는 공중 3종 전용 행동은 실행하지 않았다.

## 이전 기록의 미션 식별 정정

WB04-E697 이후 `raw-campaign-session-load.test.mjs`의 공통 `scene()`은 `thewarbegins.fort`와 이름 `thewarbegins`를 사용했다. 이 시험과 이를 인용한 일부 단위 문서의 **“Tutorial 1”은 실제로 캠페인 1-1 TheWarBegins**를 가리킨다. 앞선 E697·E750·E751 문서를 직접 수정하고 시험 이름도 고쳤다. 같은 공통 픽스처를 가리키는 다른 과거 단위 문서의 해당 표현에도 이 정정을 적용해 읽는다. 원래 Early Missions의 `tutorial1`은 스크립트가 `BridgeTheGap` Fort를 선택하며 이번 32개 시험에서 별도로 검증했다. E697의 사제·객체 수 등 기존 관찰값은 바꾸지 않았다. E304의 4-B 통합 시험 역시 TheWarBegins였으므로 실제 Tutorial1 지형·섬의 독립 대조를 재검증 항목으로 되돌렸다.

나머지 31h 개발자 명령, 로그인 소스 base 뒤 32커밋 판정, 미션 Start·프레임/입력 및 브라우저 앱 연결과 L2/L3/L4 검증은 남아 있다.

관련 집중 검사 54건과 Node v26.13.0 전체 회귀 6,246건이 통과했고 실패·취소·건너뜀은 0건이다. 대응표 오류는 0건이며 E746의 v22 검사 뒤 일곱 번째 v26 전체 회귀다.
