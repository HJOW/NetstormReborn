# WB04-E822 참가자별 월드 동기화 본체

기준선 `225553df`의 `RawPeerWorldSync`를 이식했다. 서버 SID 15000~23000의 표면 자산을 먼저, 다른 자산을 다음에 전송하고 각 종속 사슬을 깊이 우선 순회한다. 송신 뒤 현재 child·sibling과 대상 전역을 다시 읽으며, 마지막에 살아 있는 이동 객체를 공간에서 해제·재등록한다. 깊은 종속은 명시 스택으로 처리해 호스트 재귀 한도 대신 원문 Pool 범위에서 진단한다. 기준선 이후 해당 C++ 파일의 변경은 없다.

실제 SID 풀·전송 전역과 `RawSquidTransmission` writer를 사용해 전송 순서, 콜백에 의한 링크·대상 변경, 이동 재등록, 실패 시 앞선 전역 보존과 손상된 sibling 순환을 검사했다. 집중 검사 13건이 통과했다. 이 본체의 실제 Session·Native 수신기 및 월드 가상 장치 결선은 4D-3d/4D-8에 남으며 원본 전용 fixture는 없다. 게임 창은 실행하지 않았다.

검증: Node v26.13.0 전체 6,313건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E819 Node v22 전체 검사 뒤 v26 전체 회귀 3/8회다.
