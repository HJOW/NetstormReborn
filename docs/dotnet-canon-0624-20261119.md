# 0.624 공장 후처리 본체 이식과 L1 전수 재생 (R4-2 공장 정기 트리거)

- 일시: 2026-11-19, HJOW-Athlon
- 범위: R4-2 공장 정기 트리거용 `RawFactoryPostPop` 본체 이식과 L1 전수 재생. 세션 Generate 연결은 잇지 않아 0.623의 L2 기준선을 유지한다.
- 목표: cpppj `o/RawFactoryPostPop.h/.cpp`의 Hooks/Types/본체와 `RawSquidLevel`을 DN에 옮기고, `factorypostpop-x86.tsv` 996행 중 일반 Factory 372행(원본·CD 각 186행)을 전수 재생한다.

## 원인

- 0.623까지 공장 정기 트리거(R6 공장 파생)가 비어 있어 `surrounded` 이후 경로의 공장 파생·아웃포스트 목록 전파를 L1에서 먼저 고정해야 했다.
- cpp 근거는 `o/RawFactoryPostPop.h` 11~72행의 `FactoryPostPopTypes`·`FactoryPostPopHooks`·`RawFactoryPostPop`과 `o/RawFactoryPostPop.cpp` 36~131행의 생성·판정·예약·공통·프레임·중복·상태 순서다.

## 검증 (증거)

- `dotnet test Netstorm.Core.Tests -c Release --filter X86RawFactoryPostPopTests`: 0 실패·24 통과.
  - `ReplaysOriginals` 186행, `ReplaysCd` 186행 전수 재생 통과.
  - `NativeBodyAndDynamicFinder` 996행(원본·CD 전체, 일반·wrapper 포함) 통과.
- Core 전체 회귀는 백그라운드에서 실행 중이다. 공장 분기는 신규 분배 뒤에 있어 기존 경로에 영향을 주지 않으며, 공장 24건 통과를 단위 증거로 한다.
- 세션 Generate 연결은 잇지 않았다. L2 3경로 기준선은 0.623(`surrounded` 첫 지역 9행 일치)을 유지한다.
