# WB04-E830 워크샾 연구 플레어의 자연 수명

기준선 `225553df`의 `CampaignSession_NaturalWorkshopPlacement` 연구 뒤 수명 검사를 E828의 같은 1-1 로그인·Start·워크샾 자연 완공·58h 연구·생산 동기화 검사에 연장했다. 현재 클라이언트 풀에서 활성 TYPE 106만 조회한다. 예측·서버 연구 직후 12개의 플레어에 대해 현재 소유자, 표시 비트와 워크샾보다 한 단계 뒤인 깊이를 확인했다.

별도 생성·삭제 지시 없이 같은 Session Kernel을 6초간 진행해 후속 효과가 12개보다 많아진 후 전부 자연 반납되는 것을 검사했다. SP 2,200, 생산 Deck과 확정된 서버 내용물이 보존되고 공통 생성·삭제 장부 깊이가 0으로 돌아오는지 확인했다. 같은 종류를 재연구해 두 번째 58h를 수신해도 내용물과 플레어가 중복되지 않는다.

검사는 실제 풀과 Kernel 논리를 사용하되 화면 출력·음향은 재생하지 않는다. cpppj의 실제 화면 픽셀 대조와 브라우저 전체 월드 프레임, 유닛 생산은 남는다. 원본이나 게임 창은 실행하지 않았다.

검증: 집중 검사 1건과 Node v26.13.0 전체 6,322건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E827의 Node v22 전체 검사 뒤 v26 회귀 3/8회다.
