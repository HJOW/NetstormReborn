# dotnetpj 0.930 — RU-3 NSInfo 메타맵/특수 그림 분배 결선 검증

2026-11-24, HJOW-Athlon. RU-3 스무 번째 묶음이다. NSInfo 전체 메타맵 배치와 특수 버튼 그림의 실제 분배 경로를 검증하고 장치 경계를 확정했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 검증 내용

- `HudNsInfo.Attach`는 메타맵(`0x594fc8`)·지식(`0x595344`) 관문이 모두 열릴 때만 `MetamapLayout` 장치에 전체 본문을 맡긴다. 관문이 닫히면 일반 부착까지만 수행하고 장치를 요구하지 않는다.
- `HudNsInfoCreate.AttachChild`는 같은 두 관문이 열릴 때만 `MetamapLayout`(`MetaChildLayout` 장치)에 파생 배치를 맡긴다. 관문이 닫히면 기본 부착까지만 수행한다. `Create()` 도중에도 관문이 열려 있으면 자식 배치 장치가 필요하므로, 루트 배치 시험은 자식 배치 장치와 함께 연결한다.
- 외부 그림 등록(`ExternalDrawing`)은 소유한 특수 버튼 토큰만 실제 그리기 장치에 전달하고, 소유하지 않은 토큰은 장치에 닿지 않고 실패한다.

## 검증

- Release 테스트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 4건(루트 배치 발화·미연결 명시 실패·특수 버튼 전달·미소유 무시)은 통과/실패 0이다. `HostNsInfoWindowsTests` 42건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0930-*/`의 각 실행 로그와 요약이다.
