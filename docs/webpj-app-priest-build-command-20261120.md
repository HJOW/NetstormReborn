# 앱 사제 건설 선택 명령

WB04-E1066은 원본 `0x02000060` 명령의 상위 WORD TYPE·하위 WORD 사제 SID를 현재 Session의 원본 건설 선택 관문에 전달한다. 실제 자금·기술 검사를 거쳐 같은 커서에 내용물 미리보기가 만들어지고 거부 시 실제 Tell 안내가 열린다.

실제 로그인된 Tutorial1 Session에 명령을 큐로 넣어 윈드 신전 TYPE, 비용 플래그, 커서 취소를 확인했다. Node 22·26 관련 각 10건과 Chromium 한국어 미션 2건이 통과했다. 최초 검사에서 미리보기 자체의 종류가 대상 건물이 아니라 Form임을 확인하고 Form의 실제 내용물 TYPE 필드를 검사하도록 고쳤다. 메뉴를 마우스로 열고 선택하는 연결과 완주 검증은 남았다.
