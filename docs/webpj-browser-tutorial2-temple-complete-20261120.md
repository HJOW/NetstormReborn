# Tutorial2 신전 자연 완공

WB04-E1075는 한국어 Tutorial2에서 브라우저 마우스로 사제 건설 메뉴를 열고 윈드 신전 배치 위치를 선택한 뒤, 게임 상태나 시간을 강제로 바꾸지 않고 실제 프레임으로 사제 이동·신전 완공을 기다렸다. 같은 실제 신전의 건설 중 플래그가 해제되고 `B.`의 한국어 ‘신전 완성’ 안내가 열리는 Chromium 1건이 통과했으며 캡처를 직접 확인했다.

이 검사는 신전 완공까지의 자연 경로이다. 이어지는 썬 워크샾 건설, 생산 지식·무기 배치, 회수와 미션 전체 완주는 아직 확인하지 않았다. E1072 고정 Node 22·26 전체 회귀는 별도로 실행 중이다.
