# WB04-E799 실제 World 후보 선택

캠페인 `GameWorld::Pick`을 같은 Session의 원본 SID 풀·타입·해시·카메라 snapshot·`RawUserPick`과 `RawCampaignFactoryDisplay.hit`에 연결했다. 화면 밖과 정지 관문을 유지하고, 원본 snap 뒤 실제 해시 후보를 찾으며 현재 건물 숨김·소유자·픽셀 판정·근접 유닛 규칙을 사용한다. 다리 추가 그림도 같은 Session에 위임한다. 기본 건물 숨김 값은 0이며 Client가 현재 조회기를 연결할 수 있다.

TheWarBegins 실제 로컬 로그인에서 화면 밖/정지 관문과 원본 역투영 오프셋을 반영한 사제 주변 선택을 확인했다. 동일 실제 해시 후보와 픽셀 판정 호출을 관찰하고 사제 선택 결과를 검증했다. 이 결과는 픽셀 일치만으로 선택되었다는 뜻이 아니라 원본의 근접 후보 규칙을 포함한다. 브라우저 마우스 이벤트와 일반 클릭 분배는 남는다.

검증: Node v26.13.0 전체 6,294건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 마지막 Node v22 전체 검사는 E795이며 이번 단위까지 이후 v26 전체 검사 4/8회다.
