# 1.174 L2 비교의 게임 시각 노출

`l2_compare.py`가 양쪽 덤프의 프레임 번호, 게임 시각 원시 64비트와 배정밀도 초 및 시각 비트 일치 여부를 결과에 기록한다. 누락·중복된 프레임 행, 범위 밖 정수, 비유한 시각은 오류로 거부한다. 기존 전체 행 일치 조건과 슬롯 통계는 바꾸지 않았다. 실제 0.998의 1-1 덤프를 새 비교기로 읽어 CPP 90프레임 10.6초, DN 90프레임 2.25초, 시각 불일치를 확인했다.

`python -m unittest discover -s dotnetpj/tools -p test_l2_compare.py -v`는 **6/6 통과**다. 검사에는 같은 번호의 다른 시각, 중복·누락·범위 초과·NaN 거부가 포함된다. `HostTimeSource` 설명의 같은 프레임이면 같은 시각이라는 과도한 문장도 정정했다. 제품 동작은 변경하지 않았다.

진행 중인 34경로 수집은 수정 전 메모리의 비교기를 사용하므로 기존 요약은 보존하고, 완료 뒤 실제 덤프를 새 비교기로 별도 집계해야 한다. 시각을 표시하는 것과 양쪽 시간을 정렬하거나 L2/L4a를 달성하는 것은 다르다.
