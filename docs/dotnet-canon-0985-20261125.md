# dotnetpj 0.985 — SL-8 파일 계열 나머지(BaseFile 고리·ClientStaticStrings 소비자) 이식

2026-11-25, HJOW-Athlon. R4-6 시작·수명 묶음의 남은 파일 계열을 잇는다. cpppj `o/RawStaticStrings`·`client/ClientStaticStrings`·`client/SavedStateFiles`의 본체와 `ClientMain`·`SavedStateFileRead/Write` 호출자 연결을 이식했다. RU-3 나머지·R4-4 정기 두 단위는 후속에서 잇는다.

## 변경과 원문 대응

- `RawStaticStrings.Initialize/Reserve/Format`: 004b92b0·004b9320·004b9390의 새 할당 뒤 전체 0과 첫 D5, 최초 8192와 부호 없는 감김, 예약과 서식 주소가 같을 때 CRT 생략을 같은 네 DWORD에 실행했다. 도달 장치만 요구하며 last는 Initialize가 쓰지 않는다. 0.985에서 추가됐다.
- `ClientStaticStrings`: 최초 네 BSS0과 실제 VFS 경로 고리 공유, 0x20000000 발급기와 할당별 실제 물리, `Tail`의 같은 할당 끝 대여와 `Memory`의 폭 검사를 원문 순서로 유지한다. `Reserve` 뒤도 같은 할당 안에서는 쓸 수 있으며 임의 절단하지 않는다. `FormatInteger`는 한 정수 외 CRT와 값인자 하나 초과를 거부하고, `FormatCaptureRange`는 80 예약과 고정 Wrote 서식을 공유 고리에 쓴다. 0.985에서 추가됐다.
- `SavedStateFiles.SavedStateFilePath/Delete`: 004b5470의 빈 root와 d와 !state.dat를 같은 경로 고리로 작성한 뒤 사용자 파일이 비어 있지 않으면 사용자 홈 Saves의 !state.dat로 바꾼다. 설치 폴더에는 쓰지 않는다. 0.985에서 추가됐다.
- `ClientHostGame.StaticStrings/SavedStatePath`: `HostStartupScene.Files.FileNameOwner`를 같은 `ClientStaticStrings`에 공유하고 저장 상태 경로를 같은 고리로 계산한다. cpppj `ClientMain` 253행과 1534행의 생성과 조회, `SavedStateFiles`의 게임 폴더와 사용자 분기를 제품 경로에서 잇는다. 세션 읽기와 쓰기 결선은 R6에서 잇는다. 0.985에서 추가됐다.
- PORT_MAP에 8행을 더했다. `o/RawStaticStrings.cpp/.h`→`RawStaticStrings.cs`, `client/ClientStaticStrings.cpp/.h`→`ClientStaticStrings.cs`, `client/SavedStateFiles.h/.cpp`→`SavedStateFiles.cs`, `client/ClientMain.cpp/.h`→`ClientStaticStrings.cs`(253행 공유).
