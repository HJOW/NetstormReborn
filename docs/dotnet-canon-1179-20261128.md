# 1.179 초기 지형 장식의 난수 상태 추적

1-1에서 지형 `fringe`(TYPE102) 선택 직전·직후 난수 상태와 선택 프레임을 별도 CPP/DN 진단 빌드로 기록했다. 두 실행 모두 종료0이며 각각 40프레임의 전체 화면 및 모든 슬롯이 같은 조건의 제품 관측과 일치했다. 원본 1,392파일은 전후 불변이다. 진단 코드는 `extracted/dotnet-fringe-1179/`의 복사본과 별도 링크 산출물에만 넣었다.

각 실행의 선택은 **168회**이고 위치·입력 코드 순서가 모두 같다. 선택 결과 프레임은 74회만 일치하며 94회는 다르다. 첫 선택 전 상태는 CPP `1412417004`, DN `139366971`이다. DN 상태에서 원본 LCG `state*0x10003+3`을 **2,245회** 전진하면 CPP 상태가 되며, 이 거리는 168개 대응 선택 전부에서 일정하다. 같은 유닉스 입력 `1760000000`으로 초기 시드 산술을 계산하면 게임 시드는 `4097495276`이고 첫 선택 전 상태는 그 전이열의 DN 1,211번째, CPP 3,456번째다. 이는 최초 선택보다 앞선 상태 격차의 실측·산술 관계이며, 실제 어떤 호출이 2,245회 차이를 만드는지는 아직 계측하지 않았다.

따라서 장식 선택기나 프레임을 임의로 보정하지 않는다. 초기화·적재 순서와 그 이전의 실제 난수 소비 호출을 추적해야 하며, 게임 시각과 전체 미션 진행이 같은 조건이라는 뜻도 아니다. 추적 로그·진단 실행 인자·화면·슬롯·전이 계산은 `extracted/dotnet-fringe-1179/`에 있다. 포획·공격·승리 조작은 수행하지 않았다.
