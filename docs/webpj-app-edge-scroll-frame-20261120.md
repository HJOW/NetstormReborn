# 웹 미션 가장자리 카메라 프레임 (WB04-E996)

미션 입력 프레임에서 원본 Tutorial 폴링 뒤 같은 장기 Uber 카메라에 가장자리 포인터를 전달한다. 화면 출력 뒤 원본 카메라 목표 제한·적용을 수행하고, 위치가 바뀌면 현재 World의 표면·입자·음향 보기를 갱신한다. 포커스가 없거나 포인터가 Canvas 밖이면 웹에서 가장자리 이동을 활성화하지 않는다. 기존 설정·차단 팝업·모달과 실제 Gump 등록표를 읽는다.

실제 Tutorial1 앱과 원본 카메라/가장자리·Present 검사 등 Node 30건이 통과했다. Chromium 1280×720 화면에서 안내를 닫고 사제 이동을 확인한 뒤 Canvas 오른쪽 끝에 마우스를 두자 현재 카메라 X 원점이 실제로 증가했다. 비활성 음향과 단일 화면비의 자동 검사이며 전체 HUD와 모든 가장자리/창 크기 검증은 남았다.

E986 고정 Node 26 전체 6,556건이 실패·건너뜀 없이 통과했다. E990 고정 Node 22 전체 검사가 실행 중이며 같은 상태 Node 26 검증 트리를 준비했다.
