# 0.726 실제 장기 ProcessHost 대여와 TYPE 물리 뷰

실제 HostSession이 Client의 장기 RawProcessHostStorage를 빌리도록 연결했다. 생성자는 실제 외부 장치가 설치됐고 Kernel이 같은지 Player 구성 전에 확인한다. Player 월드의 같은 삭제/공장/Regular/전송 묶음을 Bind하고, 실제 프로세스들은 장기 Host를 사용한다. 외곽 Runtime의 pin 전달과 실행 중 반납 관문은 유지한다. 독립 조합은 기존 세션 전용 Host/약한 현재 슬롯을 유지한다.

일반 종료는 장기 Host 전체의 Owns로 지우지 않고 현재 Use의 DrainOwnedForShutdown으로 현재 Runtime이 부착한 프로세스만 지운다. 다른 Kernel 프로세스와 이전 대여의 잔류를 보존한다. 자식/사제/생산 등의 기존 정리가 정상 복귀한 뒤만 Use를 반납한다. 전체 Native State의 ClearPass/ReturnForState 연결을 대신하지 않는다.

Root의 자산 설치 뒤 TYPE 소비자들을 같은 Storage.Types로 연결했다. AI 생성도 기술 이름 조회용 RiftTypeTable과 현재 월드 TYPE를 구분하고 실제 월드의 현재 목록을 사용한다. 최초 Client 집중125건은121통과/4실패였으며, 실패는 장기 Types의 List가 보상 계산의 실제 배열/뷰 관문에서 거부된 것이었다. 복사본으로 우회하지 않고 RawTypeTableStorage가 실제 배열을 소유하도록 바꿨다. 초기 AddRange 뒤 같은 배열의 ArraySegment/ReadOnlyMemory를 빌리며 장치 대여 뒤의 재확장은 호출자 계약 밖이다. 보상/HP는 이 실제 부분 뷰를 사용하고 일반 List 거부는 유지한다.

최종 Core52/Client125, 합계177건이 모두 통과했다(신규 Core2/Client5). 실제 장기 Host의 공개 전후 같은 Frame 시각/현재 Runtime, 중첩 반납 거부, 예외 뒤 외곽 대여 반환, 같은 Host 재대여와 외부 Kernel 슬롯 생존, 잘못된 Kernel 선행 거부를 확인했다. TYPE 슬롯 변경의 양방향 물리 별칭과 동일 레코드 참조가 중복돼도 실제 배열 위치로 this 번호를 계산하는 경우도 확인했다. 기존 원본 HP/보상·저장소 검사도 통과했다. 근거는 extracted/dotnet-0726/client-initial.log·client-long-process-storage.trx, core-physical.log·core-physical-types.trx, client-fixed.log·client-long-process-storage-fixed.trx다.

실제 thewarbegins/tutorial1/surrounded 3시작은 모두 종료0이며0.725와 전체 파일 바이트/기존 비교 지표가 같다. 원본1392파일 SHA가 불변이다. 시드1760000000·25ms/90프레임 덤프·영어1024×768 창/음소거 조건이며 포획/희생·특정 적 공격·승리는 재현하지 않았다. 실제 실행 전후 게임 EXE/자체 DLL 6개의 SHA-256도 같았다. 근거는 extracted/dotnet-0726/capture.py·capture.log·capture-summary.json·capture-originals-audit.json·build-assemblies.json과각capture/<mission>/dn/run.json·f090.tsv다.

TYPE 배열 소유자에 RawSurfaceStorage.cpp/RawSurfaceWorld.h 두 매핑을 추가했다. 부분 검증만으로 기존 큰 파일의 기준 SHA를 올리지 않았다. cpp_sync 종료0·fixture360개 불변이다. M1은0/34 유지이며 전체 Native World/공장/건설효과 장치 일원화와 State/Login/전송·나머지 R4/R5/R6는 남는다.

다음0.727은 ProcessHostStorage의 현재 Runtime/정리 증빙 소유를 원문 weak_ptr와 대조해 보완한다. 원문 current_ 및 ClearPass는 weak_ptr지만 현재 C#은 강한 참조가 남아 있고, 같은 장치 재결합의 현재 대여 관문도 추가 대조가 필요하다. 실제 장기 저장소가 미사용 Runtime을 역소유하지 않도록 수정한 뒤0.728 전체 회귀를 수행한다.
