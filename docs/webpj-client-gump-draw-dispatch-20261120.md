# Client Gump 가상 출력 분배 (WB04-E987)

Client Gump 루트가 같은 토큰의 가상 출력기를 등록·해제하고, 실제 Gump 수집기와 공통 클립 보호, 같은 8비트 픽셀 장치로 분배한다. 기본 Gump는 원본 기본 출력처럼 아무것도 그리지 않고, 출력기가 빠진 파생 Gump는 명시적으로 거부한다. 정상 삭제와 미등록 할당 반납은 출력 등록도 함께 지운다.

실제 파생 배경 노드를 Client 트리에 부착해 클립 안의 픽셀만 바뀌는지, 실패 시 clip 복구와 출력기 해제·삭제 수명을 확인했다. 기존 돌 버튼·Gump 수집과 출력 등 연관 Node 검사 35건이 통과했다.

이 단위는 공통 소유자의 가상 출력 경계다. 아직 Renderer kind 2 연결, 실제 배경·버튼별 출력기, HUD 생성과 미션 UI 입력은 남았다. E982 고정 Node 22 전체 검사는 별도 검증 트리에서 진행 중이다.
