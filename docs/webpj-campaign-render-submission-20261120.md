# WB04-E980 미션 Renderer 표시 제출

현재 수집한 원본 16바이트 항목을 CRT 순서로 정렬해 실제 지면·일반 자산 출력기, 입자, 커서와 제공된 UI 출력기에 분배한다. 지면 행은 묶음 내부 순서를 유지하며 숨김 설정을 각 묶음에서 다시 읽는다. 카메라 픽셀 원점·로컬 소유자·건물 숨김도 각 자산 출력 때 현재 값을 읽는다. 수집 전 제출과 잘못된 표면을 거부한다.

검증: 실제 Tutorial1 World의 수집 목록을 8비트 픽셀 배열에 출력해 지면·자산 픽셀과 UI 토큰, 지면 묶음 숨김에 따른 화면 차이를 확인했다. 공통 제출 원본 322행·지면 353행과 Renderer dirty/정렬 검사 등 Node 47건 통과. UI 출력은 관찰 장치이며 화면 배경·실제 Gump·Screen/Canvas와 cpppj 픽셀 대조는 아직 연결하지 않았다. E974 고정 Node 26 전체 회귀가 실행 중이다.
