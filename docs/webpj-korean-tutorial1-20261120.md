# 한국어 Tutorial1 대본과 실제 화면

WB04-E1056은 Tutorial1의 실행 설정과 모든 단계·버튼 명령을 보존한 UTF-8 한국어 대본을 추가하고 한국어 자산 묶음에 포함한다. 간헐천·사제·신전·다리 명칭과 게임 내 스톰 파워 용어를 사용한다. 한국어 대본이 없는 다른 미션은 기존 영어 대체를 유지한다.

원본 영어 대본과 Header 실행 키, 섹션 순서, 모든 버튼·설정 명령 및 그림 태그를 비교했다. `MissionScript`로 Tutorial1의 실제 설정·번역 본문과 Tutorial2의 영어 대체를 확인했다. 실제 Chromium에서 한국어 메뉴로 두 미션을 각각 시작했고 Tutorial1의 처음 두 브리핑 페이지, NetStorm/F4 혼합 글자, 갈무리11과 글자 폭·줄바꿈, Tutorial2 영어 대체를 확인했다. 첫 브리핑 두 화면은 캡처를 직접 살펴 잘림이 없는 것을 확인했다. 관련 Node 26 검사 34건, Chromium 2건 및 자산 복사본·매니페스트 검사가 통과했다.

최초 화면 검사에서 원본 줄 나누기가 줄 끝 공백의 전진 폭까지 계산해 본문 폭보다 2픽셀 길게 나와 실패했으며, 그 공백을 제외한 실제 글자 폭을 검사하도록 교정했다. 최초 Node 명령에 존재하지 않는 `asset-manifest.test.mjs`가 포함되었으나 Node가 이를 무시하므로 실제 `assets.test.mjs`를 확인해 다시 실행했다. 다른 튜토리얼과 캠페인 미션의 한국어 대본은 아직 미작성이다.
