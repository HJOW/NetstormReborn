# Session Login의 공유 옵션과 타입 사용표 (WB04-E704)

`RawCampaignSessionLogin.inc`의 실제 `RawMissionBattleOptions` 생성 연결을 이식했다. `RawGameAuxState`의 005451f8 타입 사용 256BYTE를 Client 수명의 공유 목록으로 추가해 로그인 `ClearTypes`와 기술 목록 69h가 같은 배열을 쓰며 일반 월드 준비가 이를 지우지 않는다. 원본 기본 미션 옵션을 파생하면 현재 마나 반경 30·제곱 반경 900·현재 간헐천 TYPE 비용 3000·환불 비율 50이 같은 실제 owner에 기록된다.

공유 마나 반경과 제곱 반경은 단정도 물리의 비트 접근자를 추가해 신호 NaN을 조용한 NaN으로 바꾸는 기존 옵션 처리기의 원문 동작을 유지한다. 값형 사본이나 임시 타입 목록은 만들지 않는다. 옵션 생성 실패 때에는 이미 얻은 내부 전송 또는 외부 등록 대여를 반납한다. 실제 owner와 69h 부품의 공유, 기본 파생값, NaN 비트를 포함한 집중 검사 43건이 통과했다.

Login의 서버·클라이언트 패킷, 상태 전이와 외곽 Session 연결은 아직 미완료다. 행 base 이후 32커밋의 전체 판정도 계속 남는다. 게임 창·플레이·공중 3종 전용 행동은 실행하지 않았다.
