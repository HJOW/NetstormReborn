# 1.169 미니맵 다리 생성 전후 프레임 비교

동일 1-1·시드·25ms·1024×768 조건에서 CPP와 DN을 별도 빈 사용자 루트로 실행하고 미니맵 80×75 논리 픽셀을 비교했다. 양쪽 종료0, 원본 1,392파일 전후 불변이다. 제품 DN은 1.167 별도 Release 빌드다.

| 프레임 | 다른 픽셀 | CPP 관련 객체 |
| --- | ---: | --- |
| 30 | 0 | 해당 프레임 객체 보고 없음 |
| 40·45 | 0 | 아래 다리 네 칸과 연결 객체 없음 |
| 50 | 1 | TYPE82 SID15182~15185 및 TYPE155 연결 객체 SID81 등장 |
| 60·70 | 1 | 해당 프레임 객체 보고 없음 |

차이는 미니맵 상대 좌표 `(70,48)` 한 픽셀이다. CPP 50프레임의 다리 네 칸은 소유자2이고 좌표는 `(156,128)`, `(155,129)`, `(156,129)`, `(157,129)`다. 연결 객체 SID81은 소유자2·`(154,129)`다. 45에서 50 사이에 객체와 픽셀 차이가 함께 나타난 관측이며, 실제 생성 호출이 AI인지 여부와 이후 동일성은 아직 확인하지 않았다. 첫 생성 전 미니맵이 일치한다는 관측은 미션 전환·다른 미션·실제 입력의 전체 검증을 대체하지 않는다.

스크립트·스크린샷·CPP 상세 보고·실행 해시는 `extracted/dotnet-minimap-1169-before-bridge/`에 보관한다. 실제 게임 플레이 승리·공격·포획 조작은 수행하지 않았다.
