# dotnetpj 0.826 — 생산 정보·단축키·내용물 동기화·재고 유지

작업일2026-11-22, PC HJOW-Athlon. 실제 생산 부모가 사용할 네 Source 본체 전체를 이식하고 독립 원본 자료와 대조했다. 유일한 실행 경로는`dotnetpj/src/Netstorm.Game/bin/Release/net10.0/Netstorm.exe`다. ClientProductionSync의 현재 장기 문맥/Session 설치 관문과 전체 생산 부모·예산·공통 색표·Game Root 연결은 후속이다.

## 변경

- `InventoryAboutMenu`는 현재 내용물 종류/클래스·비용·편집·SP와 제단/다이스/너겟 별칭을 원문 소비 위치에서 읽는다. 실제 설명→비용 머리→SP 부족→회수/Help→현재 Root 부착→음향 순서를 이식했다. NULL과 빈 Help, float 비용 저장·quarter·절삭, 효과 뒤 별칭 변경을 보존한다. 메뉴 작성 장치는 명시 외부 경계이며 실제 fancy 메뉴와의 설치는 남았다.
- `ProductionShortcuts`는 일반 키의 release/정지 관문, 여섯 슬롯·전체 예약·최근 종류 반복을 이식했다. 각 예약 직전 현재 명령을 다시 읽고 실제 InputQueue의 포화/FIFO 정책을 사용한다. 부분 실패의 앞선 효과를 되돌리지 않으며 D/d는 별도 현재 반복 명령을 읽는다. 일반 UserInput의 실제 호출 설치는 후속이다.
- `RawProductionSync`는 같은 Deck 메모리와 RawContainedFinder로 현재 기술 부모를 순회한다. 다음 후보 선조회→현재 flags/kind→255BYTE 중복 카운터→신전/Deck power/fullDeck→선택 취소/가상 삭제, 현재 부모/Deck 개수 재조회→중복 진단/실제 생성 순서를 보존한다. SID0과 음수 Deck 개수를 빈 성공 장치로 대체하지 않는다. 생성 뒤 seen을 올리지 않는 원문 동작도 유지한다.
- `RawProductionMaintenance`는 실제 패널 상태와 장기 재고 시계를 분리한다. 현재 모드/기술 관문, 다리 개수와 단일 조각 개수, 신전 소실 삭제, 난수/감기는 순서/강제·개발용 지정 패턴, 벽시계 공급 기한과 게임시계 품질 기한, 수량 BYTE 감김/재고 상한/옵션 간격, 현재 허용 여부/비용/SP 전환·삭제/재부착을 이식했다. 개발용 패턴 설정은 전부 검증한 뒤 교체하며 원본 난수/순서 소비를 보존한다.
