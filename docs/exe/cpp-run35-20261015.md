# 단위35: 피격 Warning의 비모달 표시와 수명

2026-10-15, **VM-W11-Codex**. 기준 `20e055e`에서 AGENTS와 양 LEFT를 다시 읽었다. 직전 단위34는 레인 신전 본체·물결 연결과 실제 창 픽셀/전체 검사를 완료한 진척이다. 현재/마지막 정밀 디컴파일 PC는 **VM-W11-Codex, 2026-10-15**다. 사용자 요청으로 **이 단위의 검사·인수인계·로컬 커밋까지만 완료하고 목표를 일시정지**한다.

## 확인한 원본 동작

- 보호 `tell.english [PriestImmobile]`의 `<$Warning,"~B~E~yOur Priest has been Immobilized">`는 일반 대화상자가 아니다. 실제 명령 분기 `004d88c5`는 **`004d3090(17,0,1,0,text)`**를 호출한다. 게임 정지와 OK 버튼을 요구하지 않는다.
- 메시지 표는20개의 serial이며 첫 -1에서 전체0으로 초기화한다. `00464060`은 루트 직계 자식에서 같은 serial·비 dead를 찾는다. stale 칸은 검색 중0으로 바꾸고 최초 빈 칸을 보관한다. 종류17은 일치해도 검색을 멈추지 않으므로 같은 Warning도 별도 행으로 추가된다. 빈 칸이 없으면 생성/소리를 실행하지 않는다. 다른 종류의 일치/삭제/억제 예외도 원문 순서로 보존했다.
- Warning 생성자의 실제 분기 `004d06e5 → 004d2c02`는 `newWarnMessage.wav`, 스타일 문자열 Parse, **10초 기한**, idle 등록, TextGump Fit을 실행한다. 표의 행 번호×12를 y로 사용하고 x는 화면 폭에서 `baseWidth(+3c)`의 ftol 결과를 뺀다. 실제 Gump Attach가 화면 제한을 처리한다.
- 기한 helper `00418070`은 실제 명령이 **`fld float delay → fadd double now → fstp double`**다. 정밀 C에 표시된 현재 시각 float 변환을 적용하지 않았다. x87 제어어027f는 double 정밀도다. `004d3030`은 기한0을 유지하고 벽 시각이 비영 기한에 도달하면 Kill한다. NaN 비교는 삭제하지 않는다.

## 구현과 실제 클라이언트 연결

- `MessageBoard`는 원본20칸 검색/삭제/생성/부착을 명시 Gump 경계에 연결한다. `WarningMessages`는 기존 **GumpCreate/GumpTree/GumpLifetime/GumpFrame/TextGump/StyleText/GumpText**를 실제 같은 노드 저장소에서 사용한다. 문자열은 `~B` bold, `~E` 검정1/1 그림자, `~y` 원본 노란색 문맥을 유지한다.
- `DialogScript`는 따옴표 안 쉼표/꺾쇠와 스타일 바이트를 보존하여 inline Warning 인자를 분리한다. `UberGump::Tell`은 Warning만 있는 섹션에서 안내를 추가하고 기존 미션/페이지/입력/정지를 유지한다. 따라서 이전 Game 라벨을 모달에 재사용하던 경로로 들어가지 않는다.
- `UberGump::Input`의 실제 프레임 처리에서 Warning idle/지연 삭제를 실행한다. TextGump의 실제 측정/기준선/클립을 Renderer 글자 목록으로 제출한다. `RenderText.clip`을 추가해 내부 클립을 글리프와 그림자 픽셀에 적용한다. 실제 Client의 벽 시각과 단일 WorldAudio 이름표/재생 계층을 사용한다.

## 재개할 때 남은 경계

- **일반 비동기 Tell**이 Kernel 중 페이지를 바꿀 때 이전 버튼/입력 트리를 재사용하는 문제는 남아 있다. 이번 Warning은 원본의 비모달 명령 경로로 수정했다. 승패/튜토리얼의 실제 대화상자 교체와 controls 변경 상태를 구별해야 한다.
- Warning의 실제 TextGump 수명은 이 관리자 안에서 공유하지만 현재 RawButtonControls와는 별도의 Gump 루트/등록표다. 전체 클라이언트의 단일 Gump 트리·전역 serial 통합, 다른 메시지 종류의 실제 생성자, 원본 UI 교체/해상도 변경 시의 전체 수명은 후속이다. CD Warning 대응도 이번 범위 밖이다.
- 레인 신전/다른 객체의 그림자·색상 상태·전체 ObjectCollection/SpriteDraw 연결, 레인 원소 지형, 실제 건설/생산/다리/수확/운반·튜토리얼 단계/승패/저장과 Early Missions/1-1~1-2 완주 동일성은 미완료다. 단위34의 옵션 저장용 파일 열기 실패1회도 원인 미확정으로 유지한다. DirectDraw 전체화면 오류는 기존 요청대로 제외한다.

인수인계 후 `20261015-23 실제 피격 Warning 표시와 비모달 수명 복원 검증`으로 로컬 커밋하고 원격 push는 하지 않는다. 그 뒤 목표를 일시정지하고 작업을 멈춘다.
