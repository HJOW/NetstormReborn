## 실제 Config·파서·부모 링크

[RawMenuHtml](../../cpppj/src/client/RawMenuHtml.inc)의 전체 공장은 실제 Config.SubstituteLocal/OkButton조회/기존HtmlTextParser·조건·그림/원문메타/같은본문·Fit/정상공통수명에 연결된다. 같은 HtmlTextParserState를 두 번 사용하므로 첫 변환에서 열린 조건의 shown/hiddenDepth도 유지한다. 단락 억제 전역은 Tell/Help와 같은 외부 소유자를 빌린다. 선택된 Config/파서 장치가 없으면 생성 후 부분 효과를 보존하고 명시 실패한다.

링크는 Help/80칸고리와 겹치지 않는 재사용 없는 호스트 주소 별칭을 부여하고 **실제 부모html8192BYTE**를 사용한다. 각 링크 효과 전에 현재 부모 바이트를 읽고 효과 직후 같은 배열에 써서 다음 명령도 즉시 볼 수 있다. 두 번째 출력 설정은cursor를0으로 되돌리되 기존 바이트를 지우지 않는다. 다른 파서 콜백이 바꾼 현재 배열을 오래된 별도 복사본으로 덮지 않는다. Html Handle의 **Kill→실제 링크 처리→Cleanup** 동안 같은 저장소가 살아 있고 scalar반납 후 오래된 링크를 거부한다. 실제 링크 요청의 Help/cmd/외부프로토콜 분배를 설치한 전체 게임 경로와는 구별한다.
