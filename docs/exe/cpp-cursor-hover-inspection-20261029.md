## 이전 신전 검사창의 실행 방식

575의 이전/수정판 실행에는 `--ui-script`, `--ui-report`, `--frames`, `--window`, `--mute-audio`와 화면/프레임/음향 검사 설정을 사용했다. 초기 브리핑 버튼 확인을 자동화한 뒤 플레이 입력을 추가하지 않는 계획이었다.

`src/app/main.cpp`의 자동 입력은 마지막 클릭/포인터 위치를 `scriptPointer`에 저장하고 `Client::inspectPoll`로 계속 반환한다. 좌/우/가운데 버튼·ffff·Alt/Ctrl 폴링은 이 좌표를 사용한다. 실제 OS 마우스 포인터를 옮기는 동작은 아니다. 브리핑 클릭 이후에도 해당 위치가 유지된다.
