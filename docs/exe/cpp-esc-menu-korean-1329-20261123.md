# cpppj1329 — 한국어 ESC 메뉴 점검과 누락 번역

2026-11-23, HJOW-Athlon. 마지막 디컴파일 호스트도 같으며 원문/디컴파일은 변경하지 않았다.

The War Begins의 한국어 게임·보기·옵션·플레이어·정보 메뉴를 실제 GUI로 열었다. 플레이어 목록과 자기/적 하위의 제목·사제 상태·동맹 문구는 정상 표시됐고 webpj에서 제보된 글자 깨짐은 cpppj에서 재현되지 않았다. `The Jailer`는 기존 시나리오의 고유 이름이므로 유지한다.

보기의 섬 테마·넷스톰 지식, 옵션의 반시계 회전, 플레이어의 스톰파워 보내기와 금액 등의 번역이 없었다. 실제 대소문자·서식·단축키 코드를 그대로 등록하고, 해상도 열의 `by`를 `×`로, 프레임 속도의 `(Original)`을 `(원본)`으로 표시했다. 한국어 번역표23키를 추가했다(현재 게임 외 구역 새로 고침·관전자·시나리오·귓속말 키 포함). 프레임 속도 행은 원래 번역 함수를 통과하지 않아 `RawGameMenus::Options`에서 현재 번역을 적용했다. 각 언어 이름과 FPS/FSR/Direct Draw 등 고유 기술 이름은 유지한다.

실제 GUI 세 실행은 모두 종료0이다. 메인 다섯 메뉴와 자기/적/자원 보내기, 해상도·언어·프레임 속도·난이도·효과음/음악 음량 하위를 확인했다. 음량은 `--mute-audio`로 실제 장치를 열고 두 하위의1~5행을 확인했으며 소리 청취는 하지 않았다. 나머지 화면은 `--no-audio`로 검증했다.
