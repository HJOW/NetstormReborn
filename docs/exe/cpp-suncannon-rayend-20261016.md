# 썬 캐논 실제 Missile 사정선 종점 (2026-10-16)

현재/마지막 전체 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-16**이다. 보호된 10.78 디컴파일과 PE를 정적으로 확인했으며 게임/GUI는 실행하지 않았다.

## 원본 방향·종점

`00481750`은 포구→목표 중심 또는 코너의 방향을 `0041ce90(..., cardinal=1)`로 네 방향 중 하나로 양자화한다. TYPE128이면 발사 자산의 현재 frame으로 `00466df0` 방향 허용 표를 검사하고, 현재 프레임에서 발사 가능한 방향을 고른다. 방향이 이미 일치할 때 원본 반환점은 북/남 `({from.x, to.y})`, 동/서 `({to.x, from.y})`다.

`RawGunTarget::MayFire`는 자산 중심→표적 중심으로 프레임/방향 조합을 제한한다. 그러나 `RawMissile::Construct`는 SHP/TYPE 핫스폿으로 보정한 포구와 목표 중심 또는 코너를 `rayEnd`에 전달한다. 두 방향 계산의 입력이 다르므로 사전 발사 허용을 `rayEnd`의 방향 일치 보장으로 간주하지 않는다. 현재 구현은 방향이 일치하는 입력만 지원한다.

원본 PE의 표와 분기에서 확인한 10.78 Sun Cannon 발사 프레임0..3 및24..27의 방향은 각각 남·북·서·동(`4,0,6,2`)으로 대응한다. 현재 프레임의 허용 방향과 목표 방향이 다르면 원본은 선택 방향과 난수 좌표를 써서 끝점을 보정한다. 그 보정은 아직 구현하지 않았으므로 현재 연결은 그 경우를 명시 오류로 남긴다.

## 구현·검증 범위

`RawProjectileGeometry::CannonRayEnd`가 원본 방향 일치 분기의 종점을 계산하며 `RawCampaignSession`의 Missile `rayEnd` callback에 연결했다. 바로 앞 단위의 TYPE128 raw 포구 getter와 함께 실제 생성 경로의 조회 경계를 연결한 것이다. TYPE71 및 다른 판본/타입을 이 함수로 처리하지 않는다.

`RawMissile::Construct`는 비영 효과 타입의 `flightEffect` 연결 여부를 포구 조회 전에 검사한다. 따라서 현재 비행 효과11이 미연결인 전체 Session에서는 새 포구·종점 조회까지 도달하지 못한다. 기하 단위 검사 통과를 실제 썬 캐논 생성·Pop·비행 성공으로 합산하지 않는다.
