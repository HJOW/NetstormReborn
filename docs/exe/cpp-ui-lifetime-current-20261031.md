# 실제 UI 캡처 취소·채팅 도킹 재검증 — 단위640

현재 PC와 마지막 전체 정밀 디컴파일 PC는 HJOW-Athlon/2026-10-23이다. 기존 정밀 자료와 제품을 사용했고 제품 소스·EXE·ZIP·디컴파일 출력은 변경하지 않았다. 단위639 뒤 전체 목표를 계속 진행한다.

## 실제 ESC 메뉴를 사용하는 검사

`cpp_rawbuttons_smoke.py`는 제거된 임시 Game 버튼과 3개 노드 UI를 기대하던 검사를 은퇴시켰다. 실제 브리핑 Play Mission과 ESC→Game→Leave Mission을 사용한다. 브리핑 버튼을 누른 뒤 바깥에서 떼면 시작하지 않고, 중단 확인의 Continue Mission을 누른 뒤 바깥에서 떼면 확인창이 유지된다. 두 경우 공통 캡처는 반납된다. 이후 정상 클릭으로 같은 HUD/소유자를 유지하며 미션에 돌아온다. 메인 복귀→Campaign→같은 미션 재진입에서는 새 HUD 토큰과 증가한 등록 serial, 정상 진행·미션 키/종류/객체 수를 확인한다. 마지막 Leave→메인→Quit도 정상 종료했다.

실행 사본과 출력 경로를 인자로 받을 수 있고 기존 `protected_run`의 원본 해시·설정 복원·실제 PID/종료 코드 관측을 재사용한다. 원문 명령 번호는 표시된 실제 메뉴 행의 좌표를 찾는 데만 사용하며 명령/월드 상태를 직접 주입하지 않는다. 물리 입력 검사가 아니다.

최초 실행의 게임 종료 코드는 0이지만 최종 미션 식별자 비교가 실패했다. CLI 입력은 `thewarbegins`, 실제 메뉴 입력은 `TheWarBegins`였고 종류/객체 수는 같았다. 검사 기대를 느슨하게 바꾸지 않고 최초 CLI 키를 메뉴와 똑같은 `TheWarBegins`로 고친 후 전체 입력열을 새 디렉터리에서 재실행해 통과했다. 최초 원시는 보존한다.
