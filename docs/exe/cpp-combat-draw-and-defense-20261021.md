# 전투 본체·비행 그림자 표시와 테스트 방어 배치

현재 PC와 마지막 정밀 디컴파일 PC는 **VM-W11-CODEX / 2026-10-21**이다. 원본 10.78 PE와 기존 정밀 자료를 읽었고 새 디컴파일은 없다. 원본/CD/AGENTS/dotnetpj는 변경하지 않는다.

## 표시 원인과 수정

기존 `GameWorld::Sprites`의 단일 현재 프레임 출력은 추가 그림을 쓰는 타입의 고정 본체를 생략했다. 썬 디스크 발사기71/VT50b888은 +78의 TYPE baseFrame32 뒤 +a4의 현재 동작/포구 디스크를 출력해야 한다. 훨리베이스72/VT509930은 +78의 구간별 기본 그림 뒤 +a4의 현재 그림을 출력한다. 이미 원본 격리 검사로 복원한 `DrawBurningArcherCapture`, `SunAviaryCaptureMainFrame`, `DrawSunAviaryCapture`를 실제 `SpriteDraw` 소비자에 연결했다. 썬 캐논128도 같은 일반 Draw의 현재 전체 프레임/TYPE 기준점을 사용한다. 표시 수정은 테스트 임시 조작이 아닌 기존 원본 몸체의 연결이다.

`flyershadow`는 같은 타입의 별도 SID와 두 번째 물리 프레임 묶음으로 표현한다. 기존 경로는 이를 일반 원색으로 출력했고 부모 본체에는 TYPE 발 기준점 보정도 빠져 있었다. 그림자 SID는 원본 수집기와 `SpriteDraw`의 tail4/그림자 색표 경로로, 본체는 같은 TYPE 기준점으로 출력한다. 부모·그림자 위치와 프레임은 직접 쓰지 않는다. 적용 타입은 **73 훨리기그, 111 썬 벌룬, 138 더스트 데빌, 141 윈드 벌룬, 144 맨 오 워, 146 레인 벌룬**이다. 부모의 이동·선택·생산 방식은 기존 경로를 사용한다.

보호 PE의 생성자/가상 표를 추가 점검했다. 생성자에서 extra bit2를 켜는 **14종 가상 표**, 자산 생성자의 +a4가 빈 함수41c100이 아닌 **33종 가상 표**를 구별했다. 워크샾/아웃포스트·세 신전·썬더 캐논·간헐천·다이스의 기존 전용 연결도 확인했다. 이번 전투 건물에서 고정 본체 연결이 누락된 것은 위71/72였다. 마나103/마나볼트105, 지도 섬 표시108/109/161, 폭탄·주문·간헐천 추가 효과의 전체 GUI 출력은 별도 점검 대상이다. 모든 게임 효과와 모든 상태가 원본과 같다고 판정한 것은 아니다. 원시 목록은 `extracted/draw-additional-audit-20261021.json`, `draw-all-custom-audit-20261021.json`에 보존한다.

`cpppj/tests/fixtures/tutorial-five-fixed-bridge-ui-input.tsv`는 **테스트 전용이며 원본 분석 결과가 아니다.** 4번 ㅏ자 조각을 지정 공급한다. 첫 타워135,93을 유지하고 파괴 뒤 같은 자리에 재건한다. 남쪽 다리는5조각만 설치해 캐논 건설 공간을 남긴다. 발사기는 제네레이터138,107로 접근하는 훨리기그를 막는138,101에 배치한다. HP/SP/적 좌표/미션 단계는 직접 바꾸지 않는다.
