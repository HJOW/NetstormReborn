# AI 생성자의 현재 무효 그래프 번호 조회

현재/마지막 정밀 디컴파일 PC는 **HJOW-Athlon, 2026-10-15**다. 같은 PC의 정밀 프로젝트에서 `ai-brain` 두 함수(`00416860`, `00410100`)를 `-Refined`·읽기 전용으로 다시 내보냈다. 원본 게임/GUI 실행은 없고 보호 PE와 AGENTS.md를 변경하지 않았다.

기존 `AiBrainConstructorGlobals.invalidGraph`는 `const uint32_t&`여서 실제 세션 장부인 `SquidPostPopState::invalidGraph`의 BYTE를 바로 연결할 수 없었다. 형 변환 임시값에 참조를 걸면 객체 수명 문제를 만들고, 별도 DWORD를 계속 동기화하면 같은 현재 저장소를 읽는 의미가 약해진다.

필수 `std::function<uint32_t()>`로 변경하고 본체 `+0x298`, `+0x2ac`의 각 쓰기 지점에서 따로 호출한다. 누락된 조회기는 생성자에서 거부한다. 별도 장부나 임시 참조 없이 실제 `core.bookkeeping.invalidGraph`를 확장해 반환하는 조회기를 후속 Session 조립에 공급할 수 있다. 실제 Session AI 활성화는 이 단위에서 켜지 않는다.

원본 명령 `00416d20`, `00416d3a`는 **`[00540410]` DWORD 읽기**다. BYTE는 현재 클론 장부의 저장 폭이며 원본 전역의 폭을 BYTE로 판정한 것이 아니다. 본체 출력도 DWORD를 유지한다. 기존 254 입력의 전체 본체/Player/동맹/섬/할당/해제를 기존 **160개 고유입력**으로 다시 대조한다. 기존 입력의 재검증이며 신규 고유 관찰로 합산하지 않는다.

추가 집중 검사는 BYTE backing의 두 현재 읽기, 첫 `+0x298` 쓰기와 중간 `+0x2a8=0` 쓰기 이후 두 번째 조회, 조회기 누락 시 본체 할당 전 거부를 확인한다. 조회기 내부에서 값을 바꾸는 검사는 API 조회 시점을 확인하는 합성 입력이며 원본 게임에서 동시 변경을 관찰했다는 뜻은 아니다. 기존 원본160 대조와 구분한다.

기계어 관찰기는 실행 호스트를 보고서에 기록하도록 변경했다. 실제 메모리 소유/기존 할당 대체·사제/지역/TYPE 응답의 외부 경계와 초기 갱신/전략 미검증 경계는 유지한다. 빌드·집중/전체 검사 결과는 LEFT_JOBS 최신 절에 기록한다. mana 메타데이터의 미등록 초안과 실제 Session AI 시작·전략 복원은 후속이다.

소스 고정 후 AI2객체 재컴파일/게임·검사 링크를 마쳤다. 최종 Release 경고0·오류0, 집중24개와 공통 전체 CTest **1,238개 실패0·195.14초**가 통과했다. SP와 AI 두 변경을 함께 반영한 작업트리의 결과이며 미등록 mana 검사는 포함하지 않는다. 사용자 중지 요청으로 인수인계/로컬 커밋 뒤 후속 구현을 진행하지 않는다.
