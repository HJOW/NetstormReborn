# 일반 타입·패턴 배치의 로컬 미리보기와 표면 관계

2026-10-09, **마지막 디컴파일 수행 PC: HJOW-Athlon, 2026-10-09.** AGENTS.md·두 인계 문서·cpppj 내부 문서를 읽고 현재/마지막 호스트 일치를 확인했다. `canonpreview` 목록을 같은 PC에서 읽기 전용으로 내보냈다(10.78 9개·CD/추가 10.37 각각 7개). 원본 게임/복사본·클론 창을 실행하지 않았으며 원본·AGENTS.md·dotnetpj는 변경하지 않았다.

## 복원한 계약

[`RawCanonPlacementPreview`](../../cpppj/src/o/RawCanonPlacementPreview.h)는 일반 배치 접두가 캡처한 로컬 소유 여부와 **타입/별도 패턴 인자**를 받는다. 접두→미리보기→후반 충돌/지형 경계의 연결은 `MakeCanonPlacementPreviewHooks`, 실제 decoder의 범위 연결은 `MakeCanonGeometryPreviewHooks`다. 범위 연결은 `(type,argument,flags,x,y,false)`를 전달하며 명시 프레임 모드를 켜지 않는다.

원본의 미리보기 구간은 타입별 충돌/지형 분기보다 앞선다. 따라서 기존 사제 전용 구현을 공통 구현으로 옮겼고, `RawPriestPlacementPreview`는 기존 여섯 값 인자와 `argument=type`으로 위임한다. 공개 사제 상태/콜백과 풀/자료/필수 경계 검사를 유지했다. 두 경로는 같은 144바이트 배열과 관계 전역을 공유할 수 있다.

비로컬 요청은 배열 초기화/범위 조회를 생략하고 후반 경계로 간다. 로컬 요청은 배열 전체를 지우고 left/top을 최소 1로 맞춘 범위에서 오른쪽 아래+1→왼쪽 위−1을 y/x 감소 순서로 순회한다. 인덱스는 **`(right-x+1)×12+(bottom-y+1)`**다. spot `0x10`, 고정 표면 없음, 현재 표면 genus `0x2`와 허용되지 않은 소유 관계가 차단 표시를 만든다. 표면 raw의 free/dead/void 상태로 추가 필터링하지 않는다.

관계는 편집기→동일 소유자→활성 동맹 표의 순서다. 요청자의 low BYTE는 부호 확장하고 표면 소유자는 부호 없이 읽는다. 표의 방향은 `표면 소유자×9+요청자`이며 실제 계산된 인덱스만 검사한다. 지도/타입/소유 관계는 조회 경계 뒤의 현재 값을 사용한다.

패치는 x≥256 또는 y≥254 등에서 즉시 거부하며 앞선 초기화/부분 배열 효과를 보존한다. CD는 spot의 선형 주소를 먼저 읽고 표면 조회에서 x/y 범위를 확인한다. x=256의 다음 행 spot 읽기와 y=254/255 차이를 유지했다. 배열·할당 지도·관계 표 밖 접근과 잘못된 자료는 C++에서 예외로 진단한다. 상세 산술/조회 규칙은 [기존 사제 미리보기 기록](cpp-priest-preview-reconstruction.md)과 같다.

**차단 표시의 존재가 실제 배치 거부를 결정하지 않는다.** 후반 충돌/지형 정책은 필수 콜백이며 임의로 허용하지 않는다. 실제 3×3 받침 decoder 연결 검사는 36개 표시와 후반 거부·비로컬 배열 보존을 두 판본에서 확인한다. 일반 타입의 전체 MayPlace·일반 Pop·GUI·건설을 완성한 것은 아니다.

## 독립 기계어 대조

[`decomp_canonpreview_oracle.py`](../../tools/decomp_canonpreview_oracle.py)는 세 실제 PE 각 **1,620개, 총 4,860개**를 두 x87 정밀도로 실행했다. 사각형 12종×지도 5종×소유자/전역 9종×조회 중 변화 3종에 일반 타입 10종·별도 argument 6종·genus 7종/즉시 허용을 분산했다. 기존 사제/일반 접두 fixture와 감사 도구는 변경하지 않았다.

실제 접두/여백/미리보기/표면/genus/관계/반환을 실행하고, 모양 getter·decoder 생성/범위 조회는 **함수 진입에서 대체**한다. 미리보기 이후 충돌/지형은 위 표의 중간 지점에서 허용/거부 반환으로 **명시 대체**한다. C++의 실제 decoder 연결 검사는 별도 합성이며 이번 원본 실행에서 decoder 몸체까지 함께 실행했다는 근거가 아니다.

두 정밀도 합계로 각 PE의 실제 배치 진입은 3,240회, CRT는 2,780회다. 패치 표면 조회 34,588회·genus/래퍼 22,924회·관계 14,114회, CD/10.37 genus는 각 25,506회다. 모양 진입 대체는 각 2,780회, decoder/범위 진입 대체는 각 2,432회다. 후반 충돌 구간 대체는 패치 2,172회·CD/10.37 각 2,780회다.

반환·144바이트 배열 전체·현재 전역/genus·표면 raw 전체·두 지도 Adler·외부 호출 인자/순서를 관찰값으로 재생한다. 기대값을 C++/Python 규칙으로 재계산하지 않는다. thiscall 스택/보존 레지스터/x87·허용 코드/쓰기·assert/OS 0회·SHA·실제/대체 호출 수도 감사했다. 새 근거는 [`recovery-canonpreview-evidence.json`](../../cpppj/recovery-canonpreview-evidence.json)이다.
