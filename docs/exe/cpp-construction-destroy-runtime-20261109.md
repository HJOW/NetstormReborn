# cpppj 1195 — 실제 삭제 반환값과 장기 건설 실행기

제품은 **1195 / 11.01**이다. Native 건설 실행기의 삭제 콜백이 짧은 World 주소 대신 장기 Storage를 보유한다. 삭제가 선택되면 Storage→현재 Client 장치→실제 전체 Runtime pin→Session의 기존 World 가상 삭제로 들어가며, 실제 수락/거부 bool을 그대로 돌려준다. 별도 World 생성, 성공값 합성, 삭제 거부 우회는 없다. 독립 typed World의 기존 참조 계약은 유지한다.

원본 다리 삭제는 조건에 따라 공통 삭제 본문에 들어가지 않고 반환한다. 호스트의 기존 bool 계약은 이 수락 여부를 나타내며 원본 함수 자체의 반환형을 bool로 바꿔 해석한 것이 아니다. PATCH `004220f0`와 예측 정리 `00441fd0`, CD `004cff80`의 C/PE를 확인했다. CD 다리 삭제 `00449820`은 정밀 C 함수 목록에 없으므로 실제 PE `00449820~0044988e`와 마지막 `ret 4`를 확인했다. 정밀 디컴파일 소스를 수정하거나 이 누락을 C 대조 완료로 세지 않았다.

Release/x64 NetstormCpp·NetstormRoot·두 집중 대상의 빌드는 종료0이며 경고/오류0이다. 고정7소스는 최종 빌드 뒤 불변이다. 최초 빌드 뒤 제품6파일은 바꾸지 않았고, 새 수명 검사에 빠진 Native editor·보상·공통 삭제 장치를 보완한 뒤 검사만 다시 컴파일했다. 최초 검사1실패와 최종 결과를 각각 보존했다.

비MP 소유권/충돌13개와 기존 명시 건설17개, 합계 **30검사 실패0/신규2개**다. 새 검사는 삭제 장치 부재의 명시 거부, World 반납 뒤 현재 장치의 false/true/예외 전파, 같은 물리 수명과 최종 해제, 난수·세대·대여가 바뀌지 않음을 확인한다. 선택되지 않은 전송/큰 효과는 금지 콜백으로 유지한다. 결합 Notice/패킷2개와 신규 MP/통신 검사는 실행하지 않았다. 정적9조건도 모두 통과했다.

최종 클론 GUI는 Tutorial4에서 정상 생산·건설 요청→실제 TYPE75/owner1 생성→600프레임 대기→정상 종료0을 확인했다. 원본/CD/fixture와 AGENTS를 포함한 보호2800파일, 격리 설치 자료와 실행 파일은 불변이다. 원본 게임, MP, 포획/희생, 특정 적 공격, 승리, 공중3종, 사용자 수동 지정 검사는 실행하지 않았다. 건물 완성이나 모든 삭제 분기의 실제 플레이 검증으로 확대하지 않는다.

**전체 건설 본체는 여전히 Session 소유다.** 다음은 별도 Client owner의 본체와 큰 효과의 선택된 Runtime pin, 큰 NoWorld/AI/Carrier·다른 Form/일반 삭제, Source/listener/등록표/Poll·63F·지연큐/JoinTestBattle다. M6 전체, M7/M8, K/S/B도 미완료다. 최신 ZIP1092와 큐OFF 상태는 유지한다.
