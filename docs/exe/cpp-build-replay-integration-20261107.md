# 1043 — 기록 재생의 실제 부모 접합

1042의 판독·Run·라벨 몸체를 실제 Client/ProcessForm/Kernel·파일/일반 입력·건설 확정과 선택에 연결했다. 이는 코드 연결·컴파일 완료이며 **재생·멀티플레이 동작 검증은 수행하지 않았다.** 마지막 전체 정밀 디컴파일은 **2026-11-03 / HJOW-Athlon**이다. 이번 PE 대조는 기존 전체 산출물을 변경하지 않는다.

현재 재생 전역은 Client 수명의 동일 playing DWORD와 현재 객체 참조다. 실제 프로세스가 이벤트/장치를 소유하고 같은 표면의 ProcessHost에 붙는다. 생성자는 현재 객체/playing1을 판독 전에 공개하고, 판독/시각 저장 뒤 현재 Player의 source(+9c)와 현재 TYPE541134(초기49), flags10h로 부착한다. Run의 정상 완료는 playing0 뒤 실제 Host Kill(this,0)을 호출한다. Kill 도중 this가 반납돼도 이벤트/장치는 호출 스택의 공유 소유자가 유지한다. 외부 Kernel이 Client보다 오래 살아도 해제된 Client를 접근하지 않도록 호스트 수명 토큰을 둔다. 원문의 해제 포인터 접근은 약한 참조 만료의 명시 오류로 구별하며 StateClear에서 playing을 임의로0으로 만들지 않는다.

파일은 기록 writer와 같은 사용자 홈 Captures/BuildRecords/d에서 찾는다.495910처럼0.rec부터 첫 누락 번호에서 멈춰 바로 앞 파일을 읽고, 파일은 판독뿐 아니라 실제 부착까지 유지한 뒤 닫는다. 설치 디렉터리나 보호 originals에 쓰지 않는다. 일반 Ctrl+F7은 기존 모달/정지/specialAuxiliary/Ctrl/메타 모드 관문 안에서 호출한다. **Ctrl+Shift+F7은 재생 인덱스 건너뛰기가 아니라 현재542a40 명령(020000d3 NextStage)의 일반 FIFO 예약**임을 PE로 확인했다. 기존 튜토리얼 소비자를 재사용하며 개발자 플래그를 새로 켜지 않는다.

40a7c0은 현재52ede6/7/8의 타입3eh·프로토콜1·길이25와 시각0만 초기화한다. 이 GameAux를 기존 실제 건설 송신도 공유하도록 연결했다. 품질BYTE16을 원문 생성자가 쓰지 않는 사실을 유지한다. C++ 프로세스 패킷 저장소의 최초0은 호스트의 결정이며 원문 미정 stack의 값이0이라는 주장은 하지 않는다.

건설 확정은 broadcast→자기 수신 이후 현재 playing을 다시 읽고 현재 객체의495710/495730을 각각 호출한다.4958d0은 라벨 문구를 사용하지 않고 가상7c(1)→가상88→4d5c90(SID,0,1)을 수행한다. 기존 기본/자산 생성자의 **83 VT 전체**를 PE로 대조했다.7c는41c0b0/44b2b0 두 몸체이며 후자는 표시 갱신 뒤 bit2를 쓴다.88은45ac90/473770/4787c0/4791b0/4ad500 다섯 몸체다. 모두 기존 RawSquidSelection·표시 실행기와 현재 GameWorld 사용자 선택을 사용한다. 단순 bit 쓰기나 별도 선택 캐시로 바꾸지 않았다.

첫 Release 빌드는 종료0·오류0·경고3이었다. 모두 수명 토큰의 make_shared<uint8_t>(int) 한 축소 초기화에서 나왔으며 uint8_t 명시값으로 교정했다. 최종 NetstormCpp Release는 **종료0·경고/오류0**, EXE 12,145,664바이트/SHA-256 `e54dc05d24d939cb870ee8b6d90bcd64683ad2e16b2937846cea6d1ae8862177`다. 보호 2800파일 불변·새 fixture0이다. 사용자 지정에 따라 신규 MP/단위/게임/통신·실제 기록/재생 검사는0이다. 제외된 실행 검사를 구현 잔여로 되풀이하지 않는다. 다음 순서는 LAN 나머지 수신/송신·재동기화/Activate·메타/Outpost/checking5→한국어 후속→Edit 시나리오 UI다.
