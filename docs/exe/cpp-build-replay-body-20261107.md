기록 재생4955b0/495710/495730과 기존 gaps.tsv의4957a0/180BYTE를 RawBuildReplay.h/cpp로 복원해 컴파일했다. **실제 Client/Kernel/일반 입력·파일 선택/건설 Confirm 부모에는 아직 연결하지 않았다.** 재생 기능을 제품에서 사용할 수 있게 됐거나 실제 동작 검증을 마쳤다는 뜻이 아니다. 마지막 전체 정밀 디컴파일은 **2026-11-03 / HJOW-Athlon**이며 정밀 C 산출물은 변경하지 않았다. 빠진 Run은 보호 PE180바이트를 직접 디스어셈블해 대조했다.

Run은 signed 현재위치/개수 비교에서 완료면0059a7e4를0으로 쓰고 실제 Kill(this,0)을 요청한다. 미완료는 현재 이벤트를 고정한 뒤 현재 double 시각−직전 double 시각이 이벤트 float delay보다 **엄격히 큰 경우**만 소비한다. 같음/NaN은 fcompp의C0/C3 관문에서 대기한다. 소비 시각을 새로 읽어 저장한 뒤 현재 인덱스를 먼저 증가한다. 이벤트를 여러 개 따라잡는 while 반복은 없다.
