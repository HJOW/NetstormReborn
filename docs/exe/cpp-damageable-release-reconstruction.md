2026-10-09. **마지막 디컴파일 수행 PC: HJOW-Athlon, 2026-10-08.** 작업 중 한국 시각 자정이 지났다. AGENTS.md·LEFT_JOBS.md·LEFT_JOBS.dotnetpj.md와 호스트 일치를 확인한 뒤 새 `damageablerelease` 목록을 같은 PC에서 읽기 전용으로 내보냈다(10.78 17개·CD/추가 10.37 각각 15개). 원본 게임/복사본·클론 창 실행, 보호 파일·AGENTS.md·dotnetpj 변경, 커밋/푸시 없이 정적 분석·제한 기계어·콘솔 검사를 수행했다.

[`RawDamageableRelease`](../../cpppj/src/o/RawDamageableRelease.h)는 상위 Damageable가 ordinary·현재 boss·flags `&0x800==0`을 확인한 뒤 실행하는 몸체다. 이 조건을 내부에서 다시 평가하지 않는다. 같은 풀의 `MakeDamageableReleaseHooks`로 기존 `releaseContained`만 연결하며 다른 효과/소리/공통 호출은 유지한다.

1. 부모 타입 `footX==1`이면 현재 raw 좌표를, 아니면 `(x-footX/2,y-footY/2)` 중심을 선택한다. 중심은 두 좌표를 각각 float에 저장한다. 최초 선택에는 footY==1 조건을 추가하지 않는다.
2. 각 좌표에 `0.99999f`를 넓은 정밀도로 더하고 CRT 방식으로 절삭한 정수를 float에 저장한다. 이 위치는 일반 자산 배치용으로 순회 동안 고정된다. 공간 조회의 `0.9999f`와 서로 다른 상수다.
3. 실제 contained finder를 `yesIKnow=1`로 다시 순회한다. 각 후보의 `+0x14` BYTE `&0x20`이 있고, 현재 전투 모드이거나 후보 kind 타입의 genus가 현재 허용 마스크에 걸리면 해방 대상이다. 허용 마스크의 실제 초기값은 `0x40480002`다.
4. 후보 genus `&0x200000`이면 **사제 분기**다. 이전 인계의 일반적인 “walker” 표현을 이 정확한 마스크로 구체화했다. 부모의 현재 raw 좌표를 다시 읽고 현재 부모 genus `&0x80400000`이면 현재 중심을 다시 구한 뒤 각 좌표에 0.5를 더한다. 사제 생성/자리 탐색 함수에 `(x,y,kind,현재 후보 WORD +0xc)`를 전달한다. WORD의 상위 비트를 이 호출 전에 제거하지 않는다.
5. 일반 자산은 고정된 보정 위치의 spot `&0x10==0`이고 `&6!=0`일 때 `(kind,0)`으로 생성한다. **생성 콜백 뒤** 후보의 현재 WORD `+0xc`를 읽어 새 자산에 실제로 복사한다. 새 자산의 현재 타입이 현재 다리 타입 DWORD와 같으면 표면 알림을 부른다. 이어 가상 소유자 `(new,0)`→가상 Pop `(new,고정 x,고정 y,0)` 순서다.

kind는 해당 후보의 분기 전에 WORD로 읽어 고정한다. finder는 후보를 반환하기 전에 next를 저장하고, 콜백 뒤 아직 읽지 않은 후보/전역/공간은 새로 읽는다. 부모 좌표가 바뀌어도 일반 자산 배치 위치는 유지되며 이후 사제 생성 위치에는 변경이 반영된다. 후보 free/dead/void/contained 상태를 추가 제외하지 않는다. 타입 표는 참조 span으로 유지하여 사용 시점의 값을 조회한다.

## 연결과 제한

기존 두 판본 × server/client 사제 삭제 통합 검사에 실제 해방 순회를 연결했다. 실제 사제 생성자·보호막 조회/삭제·회복 Regular/ProcessForm/Kernel·공통 장부/깊이·SID 반납을 유지하며, 회복 form 타입 46은 기본 finder 타입 6에서 제외된다. 이 통합의 해방 후보는 없으며 실제 일반 자산 생성/배치의 공간 수명을 검증한 것이 아니다.

사제 자리 탐색/생성 함수, 일반 생성, 가상 소유자/Pop, 표면 알림의 하위 몸체는 명시적인 훅이다. 새 자산 WORD 복사 자체는 실제 C++ 구현이다. 파편/소리 출력·Carrier 전역 후처리, 보호막 생성/해제·낙하·일반 사제 Pop/GUI·전체 공간 수명은 남아 있다. 원본이 보드/타입 표 밖 메모리를 읽는 손상 입력은 지원하지 않는다.
