Native의 Canon 프레임·기본 프레임·핫스폿·SHP/기하 진단을 같은 RawSurfaceStorage가 한 번 소유한다. 같은 실제 Source를 검증한 Session은 이 자산을 빌리고, 독립 typed Session은 종전 local 변환을 유지한다. 장기 자산은 해당 참조를 사용하는 Host/모듈보다 나중에 반납한다. 현재 checking 뷰와 실제 Client AssertDisplay를 연결하며 Session 생성자가 Native 진단을 자기 this로 덮어쓰지 않는다. 이미 구성된 자산도 진단 owner 교체를 읽는다. 새 World/Player/Acquire/reset/난수/등록은 만들지 않는다.
