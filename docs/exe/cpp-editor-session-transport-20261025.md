## 연결 순서와 소유자

Session 생성 전에 같은 실제 Player9를 빌리는 `EditorLocalTransport`를 서비스로 공급한다. 준비 ExistingEditor에 한정하며 Campaign Login과 동시 사용 또는 다른 Player 물리를 거부한다. 이동·포획·회수의 송신 장치는 `ConnectMotion()`에서 값으로 복사되므로 생성 입력에서부터 같은 Send를 연결해야 한다.
