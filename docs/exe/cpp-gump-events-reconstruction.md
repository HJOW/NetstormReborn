## 복원한 동작

- **기본 필터:** 현재 dialog와 같은 객체이면 노드 필드를 읽기 전에 통과한다. 사건 종류는 `event & 0x03ffffff`다. help 플래그 `0x200`이고 종류가 `0x10000`/`0x20000`이면 실제 경계로 좌표를 판정한다. 밖에 있으면 키보드/마우스 플래그로 다시 통과시키지 않는다. 그 외에는 키보드 `0x400`·마우스 `0x800`과 사건의 `0x02000000` 비트를 검사한다. 사각형은 왼쪽/위를 포함하고 오른쪽/아래를 제외한다.
- **직계 선택:** 등록 슬롯 0의 루트에서 직접 자식만 방문한다. 경계를 먼저 계산한 뒤 visible/dead와 signed DWORD 깊이를 검사한다. 초기 깊이는 **1000**이며 void는 허용한다. 엄격한 작은 깊이 비교 때문에 동률에서는 먼저 방문한 객체가 남는다.
- **전체 선택:** 좌표/마스크/최소 깊이 **10000**/선택 0을 초기화한다. 각 자식의 실제 경계를 먼저 계산하고 현재 전역 좌표를 사용한다. visible이고 dead/void가 아니며 내부이거나 `0x20` 자식 통과 플래그가 있어야 진입한다. 마스크는 후보만 제한하므로 마스크와 맞지 않는 부모 아래의 자식도 탐색할 수 있다. 성공 후보의 raw 깊이를 저장하고, 재귀 뒤 현재 형제 링크를 읽는다.
- **자식 우선 전달:** visible 자식부터 재귀 호출하고, 강제 모드는 숨은 자식도 방문한다. dead/void는 전달 제외 조건에 없다. 자식 성공이면 부모 필터/처리기를 생략한다. 모두 실패하면 자기 필터→처리기 순으로 실행한다. 성공 반환은 처리기 값 대신 **그 객체 토큰**이다. 실패한 자식의 콜백이 `next`를 바꾸면 새 링크를 사용한다.
- **부모 전파:** 자신을 제외한 부모부터 가상 처리기만 호출한다. 필터를 거치지 않으며 첫 비영 처리기 값의 **전체 DWORD**를 반환한다. 실패한 부모가 자기 부모 링크를 바꾸면 현재 링크를 다시 읽는다.

## 같은 저장소 연결과 호스트 계약

생성→실제 트리 부착→직계/전체 선택→같은 위치 캐시→기본 필터를 사용하는 전달→dialog 등록→실제 삭제 요청→후속 선택 제외를 검사했다. 루트는 `GumpCreateState.entries[0]`, 현재 dialog는 `GumpLifetimeState.currentDialog`를 사용한다. 전체 선택 상태만 `GumpEventState`에 별도로 둔다.

처리 중 노드 주소는 안정되어 있어야 한다. 가상 처리기는 링크/플래그/선택 전역을 바꾸거나 지연 삭제를 요청할 수 있다. 자기 객체의 즉시 해제는 이 API의 계약에 포함하지 않는다. 필터를 공급하지 않으면 실제 복원한 기본 필터를 사용한다. 처리기 없이 선택/필터만 사용할 수 있으며 전달/전파에 도달하면 처리기를 요구한다.

잘못된 토큰·누락 처리기·부모/형제/자식 순환은 호스트 예외로 거부한다. 콜백 예외 이전의 상태 쓰기는 되돌리지 않는다. 손상 입력의 원본 assert나 실제 PE 예외 전파는 독립 근거에 포함하지 않는다. 실제 메뉴/게임 전체 프레임이 새 저장소로 전환된 단계는 아니다.
