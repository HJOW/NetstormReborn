## 같은 AI 본체의 피해 반응

새 `RawAiDamage`는 실제 `00415460`·목록 helper `00411200/00414450`을 같은0xb08 AI 본체와 네 backing 목록에 적용한다. Player+0xb0의 현재 token을 기존 `RawPlayerDamageNotice`가 조회한다. 중복·용량·full에서도 발생하는 로그·현재 재조회 순서를 보존한다. 비행 공격자의 홈은 실제 프로세스31의 Home이며 자산 raw+12로 추정하지 않는다. 로그는 좌표 절삭·서식 구성 뒤 현재 brain+b00으로 출력 여부를 판단한다. 전체 AI 전략 프레임은 여전히 미복원이다.

[AI 도구](../../tools/decomp_ai_damage.py)와 [보고서](../../cpppj/ai-damage.json)는 본체0xb08·목록 backing128BYTE·입력 슬롯 전체·이벤트 순서와 ABI를 대조한다. 홈 `0045c100`과 로그 출력 `004105b0`은 명시 외부 경계다. TYPE164 제단의 판별 전역은 관찰한10.78 값이며 가변 전역 전체 계약을 새로 증명한 것이 아니다.

최초 원본147입력의 Pool 용량20000은 C++ SidPool의 예측 시작23001보다 작았다. C++ 대조 전에 실제 Session과 같은24000 및23999/24000 경계로 원본을 다시 관찰했다. 변하지 않은135행 전체와 변경된 경계12입력을 구별하고 최초 fixture/report SHA와 로컬 사본을 보존했다. 제품 알고리즘과 C++ 기대값 계산으로 원본 출력을 바꾸지 않았다.

이후 C++를 통과한147행 전체를 보존하면서 실제 캐논 genus `08040010`의 tracked0/1 두 입력을 원본에 추가했다. **감시 목록에 없는 썬더 캐논은 피해를 받아도 hate/very 목록을 바꾸지 않는 것이 정상**이다. tracked1이면 두 목록을 갱신한다. 최초 통합 검사의 ‘모든 피격은 반응’ 기대를 이 원본 분기로 바로잡았다. 두 추가 입력의 비제단 TYPE 필드는71이며, 이 함수가 검사하는 실제131 genus를 독립 공급한 범위를 보고서에 명시했다.
