## 변경과 실제 소비자

복제는 생성자가 만든16384BYTE 버퍼도 먼저 반납하고 원문end로 다시 할당한다. 원문data가NULL이면 대입을 건너뛰므로 새16384BYTE 할당이 남는다. `CopyMemStream`은 쓰기 함수와 달리 pos를 진행시키지 않으며 할당이 정한0을 유지한다. 실제 메모리 복사를 일반 memcpy/memmove로 치환하지 않았다. 같은 객체의 대입은 첫16BYTE를 비운 뒤 원문end를 읽으므로 길이0 할당이 되는 합성 검사도 작성했다.
