# AI 건물 배치의 표적 점수와 Gun·블로커 후보 평가

2026-10-22 단위293. 시작 HEAD는 `ad0e3061`이며 AGENTS/공통·dotnetpj 인수인계와 깨끗한 작업 트리를 확인했다. 현재 PC와 마지막 전체 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-21**로 같다. 기존 정밀 원문/보호 PE 정적 읽기만 했으며 새 디컴파일/원본/CD/AGENTS/dotnetpj 변경과 원본/native/C++ 검사/CTest/게임 실행은 없다. 기존 검사·게임 중지를 유지한다.

`RawAiDropTargets`는 원본 `00412770/004128f0/00412950/0048ece0` 네 몸체를 복원한다. 같은0xb08 본체/실제 목록·물리 SID 풀·현재 TYPE의 flags2/group, 실제 내용물·HP/TYPE+48·Gun/블로커 검색·발자국 중심을 사용한다. `ScoreAiTarget/ScoreAiGun/ScoreAiBlockers` 명시 API에 연결했다. 이 단위는 배치 후보의 점수 평가이며 전체 배치 스캔/선택/실행이나 자동 AI 프레임 완료가 아니다.

## 기계어에서 보완한 점수

기존 정밀 C의 `00412770`은 flags/group과 내용물 getter의 반환이 버려진 것처럼 보이며 기본/분류 가산이 없다. 보호 PE의 정밀 명령 경계를 읽으면 아래 계산이 존재한다. 기존 정밀 산출물을 편집하지 않고 실제 복원 소스/근거에 기록했다.

| 입력 | 원본 점수 |
|---|---:|
| flags2에4000000h 없음/있음 | 기본10/5 |
| flags2에200000h, 본체2a8이0/비영 | +200/+5 |
| flags2에200h | +6 |
| 현재 group6 | +7 |
| 현재 raw TYPE가 현재 altarType | +8 |
| 최초 flags2의30000h와 실제 mask20/genus200000 사제 내용물 존재 | +400 |

기본/분류 가산은 먼저 정수로 계산한다. 그 뒤 **현재 TYPE의 float hpPerSec(+48h)와 정수 가산을 합산한 다음 ftol**한다. 원본은 `0041284a call49acf0→0041284f fiadd[integer]→00412853 call4e49c0` 순서다. hpPerSec부터 절삭하면 예를 들어-0.9f+기본10이10이 되어 원본9와 달라진다. 기존 `RawGunHit`가 사용하는 같은 `hitTypes[type].damagePerSecond`가 이 실제+48 자료다.

운반체의 내용물 하위 뒤 TYPE/owner가 변경되더라도 처음 flags/group 가산은 유지하고 현재 TYPE의 hpPerSec를 새로 읽는다. 원본 SID0 운반체 진단은 문자열`sid`/Ai.cpp:0xaeb이며 진단 후 내용물 조회를 계속한다. 실제 내용물 getter를 임의 boolean으로 대체하지 않는다.

이후 본체36c/374 및378/380의 각 최초 목록 포인터/count를 읽고 표적 SID가 한 번이라도 있으면 **각 목록마다100점**을 더한다. 중복 등장으로 같은 목록 가산을 반복하지 않는다. 본체3f8의 집중 대상이면 현재HP를 최대HP getter **전에** 저장하고, 저장HP>=최대HP/2일 때50을 더한다. 나눗셈은 signed0쪽 절삭이다. 마지막 현재 ownerBYTE(+22h)가 현재 적 ownerDWORD264와 같지 않으면 전체 점수를 signed2로 나눈다. 적 owner를 BYTE로 줄이지 않는다. 가산/총점은 원본 DWORD 감김을 보존한다.

## 실제 Gun 검색과 출력 순서

`004128f0`은 현재 owner260/명시 TYPE·floatXY·방향으로 같은 `RawGunTarget::FindTarget`을 호출한다. 검색 결과를 **먼저 출력 SID에 쓰며 결과0도0으로 쓴다**. 비영일 때만 `Score`를 호출한다. 선택된 점수 하위가 누락되어 실패해도 앞서 기록한 출력 SID는 보존한다. 실제 검색/해시·동맹·사거리 조건을 새 추천 목록으로 바꾸지 않는다.

`00412950`은 원본 임시 `new(78h)`/capacity30과 같은 한도로 `RawGunBlocker::Collect`를 호출한다. 각 후보 등장마다 점수를 계산하고 중복도 모두 합산한다. 명시 TYPE가 현재 `00541290` 윈드 블로커 TYPE(초기142)이면, 입력 두 float축에 각각 **PE005012d0의float1을 뺀 값을 저장한 뒤** 방향 필터를 적용한다. 스톤 타워 발자국 절반으로 대신하지 않는다. 점수 계산은 방향 제외보다 먼저다.

`0048ece0`은 현재 flags2의100000h 표적을 중심 조회 전에 제외한다. 나머지는 같은 `core.neighbors.Center→RawSquidNeighbors::Direction`으로 네 방향(0/2/4/6)을 구한다. 홀수/기타 방향도 중심·방향을 먼저 조회하고 그 뒤 false다. 같은 대각 차이는 기존 원본처럼 세로 방향이다.

최고 점수의 초기값은0이며 엄격히 큰 점수만 갱신한다. 원본 `00412a29 mov edx,[eax]`는 **현재 후보가 아닌 목록 첫 SID를 출력**한다. 따라서 첫 점수가0이고 둘째가30이어도 출력은 첫 SID다. 이 동작을 임의로 고치지 않았다. 모든 점수가0/음수이거나 목록이 비면 출력 SID는 기존 값을 유지하며 총점에는0/음수도 포함한다.
