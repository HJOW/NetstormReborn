## 원본 정렬과 소비

`RawEnergySupply::SortSources`는 실제474970을 복원한다. new28의10DWORD를 확보한 뒤 요구 문자열의 첫NUL 또는 첫 미선택까지 같은 마지막 공급원 목록을 읽는다. 문자 내용이나 원소를 다시 검사하지 않는다. 매 선택은 초기 float999와 현재 raw x/y의 **제곱근 거리41cfc0**를 비교한다. 결과는 float에 저장하고 다음 후보의 확장된 거리와 비교하므로, 거리를 미리 float로 바꾸거나 제곱 거리와999를 비교하면 원본과 달라진다.

0 SID는 건너뛰고, 범위 밖/free는 원본 진단 뒤 현재 유효성을 다시 검사한다. dead 자체는 제외하지 않는다. 진단 소비자가 없으면 C++는 조용한 성공 대신 예외를 낸다. 정렬에 성공한 원래 칸을0으로 쓰고 처음10개만 임시 보관한다. 문자열이 길면10개 이후도 계속 선택·소모한다. 끝에 count만0으로 바꾼 뒤 현재 용량까지 앞 칸에 다시 쓰며, 나머지 꼬리를 일괄 지우지 않는다. 빈 문자열도 확보/반납을 거치고 count를0으로 만든다.

기존473570 소비도 signed count가0 이하이면 빈 조회라는 조건을 보완했다. 같은 목록의 첫 비영 DWORD만0으로 바꾸며 count는 줄이지 않는다. 소비된 번호를 WORD로 줄이지 않는다.
