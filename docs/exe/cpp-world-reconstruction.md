# cpppj 저장 미션의 지형·선택·이동 연결

2026-10-05. [실제 플레이 복원 계획](../cpp-playable-plan.md)의 **3단계 기본 월드/조작**을 연결했다. 기본 메뉴에서 1-1을 시작하면 실제 섬 지형과 객체를 만들고, 사제를 선택해 땅으로 이동시킬 수 있다. TEST01도 같은 경로로 초기화·선택·이동한다. **건설·채집·전투·AI·승패가 없어 미션을 완주할 수는 없다.** 원본의 Squid/SID/생성자 전체를 복원한 것으로 표시하지 않는다.

`o/TerrainBuilder`, `o/Player`, `o/Squid`는 위 일부 데이터와 동작을 연결한 부분 구현이다. `client/GameWorld`는 현재 복원 범위를 조립하는 **새 어댑터**다. 객체의 런타임 번호는 월드 수명 안에서만 유효하며 원본 SID 비트·세대/해시 형식이 아니다. `SOURCE_MAP.md`의 파일 존재 표시는 해당 원본 모듈 전체의 복원 완료를 뜻하지 않는다.

`GameWorld`는 Kernel이 소유한다. UI State가 다음 프레임에 미션을 교체하고, 기존 UserInput 참조→커널 월드→미션 설정 순으로 해제한다. 입력→Kernel 이동 갱신→장면 제출→Renderer 표시 순서다. `InspectView`는 독립 검사 모드에만 남는다. 조작 화면은 실제 지형/객체의 현재 좌표 목록을 Renderer에 제출하고, `SceneImage`는 정지한 월드 위 대화상자를 합성할 때만 사용한다. 선택 표시의 투명 이미지는 Renderer가 수명을 보유한다.

## 실행과 조작

```powershell
cpppj/build/bin/Release/NetstormCpp.exe --run originals --window
cpppj/build/bin/Release/NetstormCpp.exe --run originals --window --mission TEST01
cpppj/build/bin/Release/NetstormCpp.exe --dump-world originals thewarbegins
```

- 기본 경로: Campaign→Struggle For Freedom→1 The War Begins!→Play Mission.
- 사제/유닛의 **몸통을 좌클릭**해 선택한다. 땅을 **좌클릭**하면 내 지상 이동 유닛이 이동하고 선택이 풀린다. 이동 경로가 없는 허공도 선택만 해제한다. 적 객체를 선택할 수 있지만 이동 명령은 내 유닛만 받는다.
- 우클릭은 객체 메뉴다. 내 사제의 Construct 등 미복원 동작은 비활성화되어 있다. ESC/메뉴 바깥 클릭으로 닫는다. 이동 명령에 우클릭을 사용하지 않는다.
- 화살표 또는 Alt/가운데 버튼의 커서 방향으로 카메라 이동. F4/H는 내 신전, F5는 내 사제 보기, P/R은 내 사제 선택이다. 카메라 속도는 기존 검사 화면의 12px/14ms를 초 단위로 옮긴 임시값이다.
- Game/ESC와 우클릭 메뉴·Tell 대화상자는 게임 시간을 정지한다. 닫기/Stay 후 재개하며 이동·걷기 그림도 같은 게임 시간으로 진행한다. Leave Battle→Leave Honorably로 메뉴에 돌아온다.

`--mission`은 메뉴 목록에 등록되지 않은 TEST01도 **동일 State→Loading→Briefing→월드**로 검사하는 진입점이다. 기본 실행은 메인 메뉴를 유지한다. `--view TEST01`은 옛 정적 검사 화면이므로 실제 조작 검사와 구분한다. `--view`와 `--mission`은 함께 사용하지 않는다.

`--dump-world`는 창/게임 구동 없이 읽기만 하고, 초기 플레이어·객체·65,536바이트 본섬 마스크를 TSV로 내보낸다. UI 검사 TSV는 기존 동작에 `key`/`keyup`(left/up/right/down/home/priest)와 좌표 라벨 `world:priest`·`cell:x,y`를 추가했다. `--ui-report`의 객체 좌표·게임/벽시계는 실제 이동과 정지를 관찰한다. 테스트는 입력 큐로 사건을 넣으며 WndProc/물리 마우스 전체 경로 검사는 아니다.

## 검사 결과

Windows Release 빌드와 CTest **69개 검사**를 통과했다. 새 10개는 지형 난수/방향·영역 경계·8방향 경로·모서리/허공/점유/적 다리 거부·동맹 다리·직선/대각선 거리·분할 시간차·새 점유·시작 상태·투명 선택 표시 수명을 검사한다. 기존 두 판본 x86 기대값 **5,365개**는 유지하며 **새 월드 함수의 x86 격리 실행 대조를 추가한 것은 아니다.**

TEST01의 시작 SP·동맹·AI 색도 확인했다. 원본 게임 프로세스는 실행하지 않았고 설정/시작 표시를 `finally`에서 복구한 뒤 원본 두 폴더 전체 파일의 해시와 존재 상태를 확인한다. 결과 TSV·BMP·JSON은 `extracted/cpp-world-smoke/`에 있다. 설정을 공유하는 창 스모크는 서로 순차 실행한다.

## 다음 작업과 미완료 범위

**다음은 4단계의 첫 부분인 다리·배치/건설·생산 덱·에너지/채집이다.** 현재 자원은 시작값을 표시할 뿐 경제 갱신이 없다. 그 다음 전투·AI·포획/운반/희생·미션 판정·결과/재시작·소리를 연결해 1-1 완주로 이어 간다.

3단계의 원본 전체 복원도 계속 필요하다. 원본 생성자/가상 함수 표·파생 프로세스·SID/세대/좌표 해시·내용물의 실제 객체화, Battle/Normal의 재배치·전투 옵션, 런타임 기술/생산 덱, 튜토리얼 단계 및 동적 가이저, 동적 받침/불완전 받침·소유자 전파·edgeFarm, 전체 zorder/그림자/소유자 표·상황별 커서·정지 객체의 애니메이션·원본 전역 난수 소비가 남았다. 시작 HP는 타입 최대값이며 저장 QA/QB의 타입별 상태 의미는 아직 실행하지 않는다.

경로는 8방향 다익스트라 어댑터로 직선 10·대각선 14의 비용을 사용한다. 대각선 걸음의 실제 이동 시간은 sqrt(2)이며 네 지지 칸이 모두 지면일 때만 허용한다. 동적 경로 갱신·통과 예약/충돌 회피·낙하/기절·비행 수송·수확/운반 목표·원본 출발 지연은 아직 없다. 새 점유가 다음 칸을 막으면 현재 논리 칸으로 돌아와 정지하는 임시 정책이다. 메뉴 위치·HUD·선택 표시의 정확한 비례와 그림 모양 클릭, 구름 움직임/시차·카메라 복사 최적화도 추가 대조가 필요하다. 기본 조작이 된 것을 원본 게임 전체 복원이나 미션 플레이 완료로 판단하지 않는다.
