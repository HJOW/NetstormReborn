## 복원 동작

일반 타입의 첫 점이 거부되면 **북→동→남→서→북동→남동→남서→북서** 순서로 탐색한다. 각 방향의 시작점은 원본 정수 방향 표를 fild32로 올린 뒤 현재 기준점에 더해 float로 저장한다. 각 방향에서49bfe0 전체가 대상 TYPE의 `footX`를 바깥 반복, `footY`를 안쪽 반복으로 순회한다. 가장 가까운 거리 계산이나 중복 후보 제거를 추가하지 않는다. 첫 허용점이 없으면 현재 실패 전역을 그대로 반환한다.

주변 후보는 두 축 모두0 초과, 현재 signed 지도 한계를 float로 저장한 값 미만이어야 채택한다. NaN의 unordered 결과도 거부한다. 주 호출의 소유자는 각 방향 helper 진입 때 현재 BYTE를 읽으며 helper 내부에서는 받은 DWORD를 유지한다. 외부 판정 뒤 바뀐 TYPE footX/Y는 반복 조건에서 다시 읽는다. 입력 기준점은 처음 저장한 값을 유지한다.
