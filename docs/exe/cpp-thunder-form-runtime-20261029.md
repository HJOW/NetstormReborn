# 번개 효과의 실제 Form·기술 부모·Kernel 수명 연결

2026-10-29 단위559, 작업/마지막 전체 디컴파일 PC는 HJOW-Athlon이다. 전체 디컴파일 기준일은 2026-10-23이며 이번에 보호 PE·디컴파일 산출물을 수정하지 않았다.

번개만 `BaseProcess`로 Kernel에 직접 들어가던 어댑터를 제거했다. 이제 다른 실제 프로세스처럼 `SquidProcess`와 같은 Host를 사용한다. 일반 Player의 현재 기술 부모에 TYPE55/flags0x10 Form이 붙고, 부착 뒤 팔레트를 초기화한다. 자연 종료는 Form 삭제를 통해 Kernel을 반납한다. 부모 삭제도 같은 프로세스를 지우며, 해상도·월드 종료의 중단은 팔레트와 Form을 함께 정리한다. Windows10/11 장치 교체 전에 효과를 먼저 반납하는 호환성 처리는 원본과의 차이를 코드 주석에 명시했다.

## 원문과 변경

- 생성자 `00470d40`: `PlayerKnown`0이면 부모 조회를 생략한다. 일반 모드의 `0048fc60`은 현재 Player base + battleOwner×180 +0x9c의 DWORD다. 부모0이면 부착하지 않는다. 현재 월드 존재 여부로 이 조건을 대신하지 않는다.
- 원문 `0054114c` 초기 DWORD는55다. `0041bd20(this,type,parent,0,0x10)`의 실제 공통 Attach를 사용한다. Form/PID/부모가 연결된 뒤 가상+14(`00470e30`)에서 초기화한다.
- 프레임 `00471650`은 팔레트 진행 종료 뒤 `0041bf10(this,0)`을 호출한다. `Kernel.Remove` 직접 호출을 `Host.Kill`로 바꿔 종속 링크와 실제 Form도 반납한다.
- 소멸 `00471820`의 복구는 기존 원문 대조된 `PaletteFlash.Cancel`이 담당한다. 정상 종료는 initialized를 먼저 해제하므로 소멸 때 재복구하지 않는다.
- 메타맵의 다른 부모 getter `00479650`은 실제 기록 owner가 아직 없으므로 명시 미복원 오류다. 일반 Player 기록으로 대체하지 않는다. 이번 범위는 일반 싱글플레이/편집에 필요한 실제 번개 Form이다.
