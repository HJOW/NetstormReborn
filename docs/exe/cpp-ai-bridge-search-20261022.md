# AI 다리 모양·끝점 평가·8개 예산 검색 복원

현재 작업 PC와 마지막 전체 정밀 디컴파일 PC는 **VM-W11-Codex / 2026-10-22**다. 이 단위는 보호 PE와 같은 호스트의 정밀 결과로 `0040f400`, `0040f880`, `0040f910`, `004144b0`을 복원했다. 원래 목표인15개 미션·Edit·사용자 플레이 전체 완료를 뜻하지 않는다.

`RawAiBridgeSearch`는 실제 `CanonDecoder`/26개 원본 다리 패턴·현재 bridge 프레임·65536BYTE spot·현재 Brain·공용 `GameRandom`을 참조한다. 모양은8×8 grid에 실제 코드 글자를 기록하고 decoder 순서로 J의 북/남, K의 동/서 열린 끝점을 만든다. helper 자체는 caller grid나 미사용 끝점 여백을 초기화하지 않는다. 점유 검사는 y절삭→x절삭 후 flat `y*256+x`의 첫 비제로BYTE에서 실패한다.

끝점 평가는 연결에 쓴 끝점을 제외한다. 목표와의 signed 거리에서 X 절대 좌표는 x87에 유지하고 Y 절대 좌표는 먼저float에 저장하는 원본의 차이를 보존했다. 거리2의 방향 제한·반대쪽 끝 금지·방향 불일치의+4/최소6 벌점·strict 최소점 선택도 같다. 대각선 방향-1의 반대표 조회는 표 바로 앞의float -1 원문 비트를 읽는 것까지 보존한다. 정수 절삭/절대값/합산은 원본 signed64 CRT의 낮은DWORD와32비트 감김이다.

검색은 회전0/2/4/6, 마지막 재고부터 역순, 연결점 정순으로 진행한다. 한 호출 예산8개는 **연결점×조각×회전의 평가 수**이며 한 모양의 여러 끝점은 모두 검사한다. 예산 중단 시 본체의 회전/재고/연결점 진행 필드를 그대로 이어 쓴다. 점수가 작으면 즉시 선택하고 같은 점수일 때만 공용 난수 `Next(100)<50`으로 교체한다. 후보 배치XY·패턴·회전·끝점·점수만 원래 위치에 기록한다.

원본 평가 함수는 개선되는 끝점이 없으면 caller의 임시XY를 쓰지 않는다. 검색은 점수65536 동점에서도 그 임시 바이트를 복사할 수 있다. 이를 임의의0이나 성공 좌표로 대체하지 않도록 `Search`/`Score`는 원본 caller 임시값에 대응하는 명시적 `endpointScratch` 입력/출력을 받는다. 실제 Session 자동 호출부의 연결은 후속 작업이며 아직 완료했다고 표시하지 않는다.

새 격리 도구 `tools/decomp_ai_bridge_search.py`는 실제 네 함수와 decoder 생성/진행/셀/코드/프레임 검색·CRT·난수 기계어까지 실행했다. 게임 진입점·창·OS API·계산 스텁을 실행하지 않았다. 독립 기대는 다음과 같다.

- 모양 **208개 전체0xbcBYTE**:26개×4회전×두 caller 초기 바이트.
- 점유 **416개 반환**:모든 모양/회전과 빈 지도·전체 점유·비대칭 점유·단일 세로열.
- 평가 **640개 점수/출력8BYTE**:소수·음수0·큰 좌표·각 방향·signed 경계·출력 미갱신.
- 검색 **72장면/288정상 반환**:0~8개 재고·1~6개 연결점·회전 종료·인덱스 보정·재개·전체0xb08 본체·공용 난수·임시XY.

실제 검색 관측의 공용 난수 진입은33회다. `tools/decomp_ai_bridge_search_verify.py`는 기존 fixture를 수정하지 않고 x87 제어워드 `0x27f`/`0x37f`에서 위 입력을 모두 재실행해 동일함과 제어워드 복구를 확인했다. 두 보호 PE와 생성 도구/fixture7개 SHA도 확인했다. 원본 출처는 `cpppj/ai-bridge-search-20261022.json`, 별도 정밀도 근거는 `cpppj/ai-bridge-search-precision-20261022.json`이다.

Release 빌드는 **종료0·경고0·오류0**, 다리 관련 **22개·실패check0**다. 조립 검사는 실제 초기화→24칸 후보 준비→8개 검색의 중단/재개→Step4대기→Step5끝점 반환까지 수행한다. 이후 전체 CTest는 **내부2,226개·실패check0·종료0·전체176.17초**로 통과했다. 새9개 초기화/후보/검색 검사도 이번 전체에 포함됐다. `extracted/cpp-ai-bridge-search-20261022-{build,tests,ctest,all-tests}.log`와 `cpppj/ai-bridge-search-regression-20261022.json`에 실제 로그/요약/SHA를 보존했다.

다음은 `00410b10` 시작점 선택과 `0040faa0` 유효 연결점 판정이다. 원본은 현재 맵 사각형을 X 우선/안쪽Y 순으로 훑고, Brain+298 graph/+260 owner·실제surface·빈 이웃·현재코드의 연결을 확인한 뒤 목표와의 strict 최소Manhattan거리로 선택한다. 이후 실제 Session의 Step/Extend·네 전략/전체 자동 프레임/종료를 연결해야 한다.15개 미션·Edit/custom Fort·언어별 시나리오 수명·자연 플레이·표시/음향 동일성은 계속 미완료다.
