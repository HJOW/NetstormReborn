## 원래 순서와 상태

1. `280` fake TYPE0이면 다른 필드/하위를 읽지 않고 반환한다. TYPE가 있으면 signed `ae0>=adc`일 때 **먼저** index0을 제거한다. 이후 신전/점수/후보가 없더라도 제거는 되돌리지 않는다.
2. 공급시설 count `2fc==0`이면 현재 신전 `294`가 없을 때 반환한다. 있으면 **중심이 아닌 raw X/Y**로 현재 fake TYPE를 Add한다. 중복/full 등 bool 결과를 무시하고 Added 로그를 요청한다. `af0/af4`는 갱신하지 않고 Seed/유효성 확인도 하지 않는다.
3. count가 비영이되 signed 양수가 아니면 시설 순회는 건너뛴다. 양수이면 최초 count와 `2f4` 포인터를 잡고 각 SID DWORD/현재 raw 좌표를 읽어 실제 부족거리 점수를 구한다. strict `score>best`에서만 갱신하므로 동률은 첫 시설을 유지한다. 디컴파일의 SID/index float 표기를 사용하지 않는다.
4. 양수 최고점수가 있으면 선택 시설의 현재 중심을 구한다. **중심 조회 뒤 현재 `ae4`**를 읽고 저장한 Dry Spot index에서 두 float를 읽어 각각1을 뺀 뒤 float 저장한다. 경로 시작 인자는 실제 `0041612f/0041614e/00416153/54` 명령대로 **`(중심Y,중심Y)`**다. 이후 거리 비교는 원래 `(중심X,중심Y)`를 사용한다.
5. 반환 후보가 현재 지도크기의 strict 유효 좌표이면 중심과의 거리를 구한다. 현재 마나 반경에 float `00501784=0.699999988079071`을 곱한 값보다 **커야** 채택한다. less/equal/unordered는 Discarded 로그다. 유효하지 않은 후보는 이 로그 없이 넘어간다.
6. 채택 시 현재 fake TYPE로 Add하고 반환을 무시한다. `af0→af4`를 기록하고 현재 전략이4이면 `3cc=0→3d4=-10000→3d0=-10000→3d8=1`을 원래 순서로 쓴다. 현재 디버그 종류29이면 실제 표식을 추가한다. Add가 거절돼도 이 상태 쓰기/표식은 진행한다.
7. 공급시설 분기에서는 현재 `af0/af4`가 유효하지 않으면 기존 실제 Seed를 요청한다. Seed 자체의 BYTE20h 능력 관문을 공유하며 전체 Extend에 별도 능력 관문을 추가하지 않는다. 이 보충은 채택되지 않은 경우에도 가능하다. 채택 플래그가 없으면 반환하고, 있으면 **원래 후보 local 좌표**로 Added 로그를 낸다. 표식이나 Seed가 본체 좌표를 바꿔도 로그 좌표를 바꾸지 않는다.
