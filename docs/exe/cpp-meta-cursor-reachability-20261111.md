# M7.2 메타 맵 활성 커서 도달성 재판정 — 작업1273

2026-11-11 / HJOW-Athlon. 마지막 Client 디컴파일 2026-11-03/HJOW-Athlon과 현재 호스트가 같고 새 디컴파일은 없다. **원문 C와 보호 PE를 다시 대조해, 메타 맵의 카메라 커밋이 커서 잠금 깊이 0 분기(활성 커서 본문)에 도달하는 원문 경로가 없음을 정적으로 확인했다.** 코드 변경은 없다. MP·메타 맵 실행은 0이며, 이 결론은 정적 증거에 기대고 실제 MP 메타 맵 실행으로 확인하지 않았다.

## 근거 (원문 `extracted/refined/originals/Netstorm.c`)

- 커서 잠금 깊이 `DAT_005325c8`의 쓰기는 **`FUN_00446e70`(리셋: `Activate(1)` 후 `= 1`, 57705행)**, **`FUN_00447000`(월드 커서 초기화: `= 0` 후 `00445b30` 미리보기 생성, 57753행)**, `Lock`(`00446a10`)/`Unlock`(`00446a40`)의 증감, 그리고 몇몇 `Cancel`류 증감뿐이다.
- `Lock(00446a10)`과 `Unlock(00446a40)`의 호출자는 **각각 1곳, 둘 다 카메라 커밋 `00497960`**(121932행 Lock, 122047행 Unlock)이다. 서로 균형 잡힌 쌍이며 zoom 변경 분기에서는 부르지 않는다.
- 메타 맵을 여는 `004789b0`(98971~99077행)과 `00479390`(99328~99363행)은 `00446xxx`/`00447xxx`/`FUN_00445aa0`/`005325c8`을 **전혀 참조하지 않는다**. 즉 메타 맵 진입은 깊이를 0으로 만드는 `00447000`을 부르지 않는다. 깊이는 `00446e70`이 쓴 1(전투 종료/초기 상태)로 남고 카메라 커밋은 1→2→1로 균형을 이룬다.
- 현재 구현은 같은 불변을 지킨다. `ClientGameplayGlobals`는 `CursorDropState{.lockDepth=1}`로 시작/재설정하고(`ClientGameplayGlobals.cpp:22`), `UberGump::CommitCameraNow`는 깊이가 비영이면 Session 없이 같은 DWORD만 증감하며 원문과 같다. 깊이 0에서만 "미설치 World의 활성 커서 … 경계 필요"로 던지는데 위 근거로 메타 맵 정상 흐름에서는 도달하지 않는다. `ClientMetaPointerInput`의 `lockDepth==0 && Cursor().HandleInput`도 같은 이유로 메타 맵에서는 거짓이다.

## 결론과 한계

- **메타 맵용 활성 커서 런타임(`RawCampaignCursor`) 설치는 원문 동작에 필요하지 않다.** 전체 `Connect*` 사슬을 메타 Session에 이식하면 원문에 없는 `00447000` 효과(깊이 0·미리보기 생성)를 만들게 되어 오히려 어긋난다. 따라서 구현하지 않고, 깊이 0에서의 명시 오류를 유지한다(빈 성공으로 바꾸지 않음).
- 한계: 이 판정은 정적 호출자 근거다. 만약 MP 실행에서 메타 맵 카메라가 깊이 0에서 불리는 반례가 나오면(예: 전투 종료 후 `00446e70`이 아닌 경로로 깊이가 0이 된 채 메타 맵에 진입) 해당 경로의 원문 호출자를 먼저 찾아 그 `00447000` 효과를 구현해야 한다. 사용자 MP 직접 확인 대상이다.
