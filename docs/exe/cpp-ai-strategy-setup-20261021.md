## 정밀도와 검사 범위

- 원본 기계어의 다리 기한은 `fadd QWORD now`다. 디컴파일에 보이는 now의 float 축소를 적용하지 않는다. 중심은 float 경계의 차이를 더 넓은 중간값으로 계산한 뒤 각각 float 저장한다.
- 목표의 비용+1200은 DWORD 감김 후 signed 비교하며 `>` 경계를 유지한다. 목표가 같으면 본체를 변경하지 않는다. 특정 좌표는0과 지도 끝을 제외하며 NaN도 유효하지 않다.
- 원본 재고는8DWORD다. 손상 입력/과도한 설정이 이를 넘어가면 호스트 계약 오류로 중단한다. 이웃 필드 덮어쓰기/스택·힙 손상을 재현하지 않는다.
- 전체 x87 확장 정밀도/비정상 부동소수점 예외, 원본 진단 문자열의 파일/줄 번호 장치 효과 전체, CD10.72의 대응 없는 AI는 이번 동일성 증거가 아니다.

새 검사9개는 초기 양쪽 지역 관문과 적 재선택, 로컬/원격 생산 차이, 보류 다리 총수, 난수 소비와 signed serial, 중복 진단/삭제, 선택된 효과 누락, 목표 우선순위/비용 감김/좌표 경계/변경 때만 초기화, 실제 Session의 같은258/내용물 연결을 다룬다. **작성·컴파일만 한 검사이며 실행 통과로 세지 않는다.**

Release 전체 빌드는 **종료0·경고0·오류0**으로 완료했다. 빌드 로그/실제 종료 코드는 `extracted/cpp-ai-strategy-setup-20261021-build1*`에 별도로 보존한다. PowerShell의 UTF-16 로그는 텍스트 내용 변경 없이 UTF-8로 변환했다.
