단위416 `90ae1b15` 뒤 AGENTS와 양 인계를 재독했다. 현재/마지막 전체 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-23**이다. 이전 턴은 실제 Edit 선택 연결·전체 검사·로컬 커밋을 남긴 진척이다. 새 전체 디컴파일·원본 게임 실행·원격 push는 없다. 보호 기준1821파일은 `extracted/cpp-hud-lifetime-417-baseline.json`이다.

## 원문 순서에 필요한 소유 구조

기존 `RawButtonControls`는 생산/미니맵 C++ 처리기를 한 개씩 소유하고 외부 출력을 고정 슬롯0/1에 덮어썼다. 이 구조는 원문 Uber의 새 자식 생성 후 이전 루트 정리 순서를 지원하지 못했다. 같은 공통 Gump 등록표·트리·입력·수명을 유지하면서 실제 처리기를 여러 개 보유하고, 모든 파생 분배는 토큰을 소유한 처리기를 찾도록 바꿨다. 공통 scalar가 해당 노드들을 모두 반납한 뒤 C++ 처리기를 정리한다. 부분 생성의 미부착 노드도 실제 Close까지 유지한다.

외부 출력에는 고정 슬롯과 별개인 소유 등록을 추가했다. 생산/미니맵은 받은 등록만 반납한다. 이전 처리기의 소멸자가 새 처리기의 Draw/Text 연결을 지우지 않으며 기존 고정 슬롯 API도 보존한다. `Production()`은 현재 생성serial을 검색하고 죽은 최신 대상 대신 이전 생산을 선택하지 않는다. `Minimap()`도 원문 현재 표시 포인터의 별칭을 해석한다. 새 실제 대상을 만드는 `ConstructProduction`/`ConstructMinimap`은 이전 노드와 함께 존재할 수 있다.

미니맵의 포인터/serial·비트맵·큐·색상은 개별 표시 수명과 구별해 공유한다. `ConstructMinimap`은 현재 비트맵 폭으로 미부착 노드를 만들고 Help/HelpWord 뒤 serial과 현재 포인터를 쓴다. 초기 폭0에서 비트맵 확보·도킹·128폭 설정을 선행하지 않는다. 기존 Client용 `Open`의 준비/배치는 별도 호스트 어댑터로 유지한다. 기존 영어 Help 문구는 개별 노드가 소유하는 실제 문자열로 설치하고 반납한다. Native 번역 호출 전체를 새로 복원한 것은 아니다.

Pop/Unpop의 관측 대여에는 같은 반납자와 일치할 때만 연결을 끊는 경계를 추가했다. 새 미니맵이 같은 월드에 연결된 후 이전 미니맵이 소멸해도 현재 통지 연결이 유지된다. 게임의 Pop/Unpop 공간 계산은 바꾸지 않았다.
