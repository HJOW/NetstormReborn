10.78의37h/004427b0·00442760과00443bd0→004426d0을 실제 Session의 같은 건설 본체/Kernel/공통 전송에 연결했다. 마지막 전체 정밀 디컴파일은 **2026-11-03 / HJOW-Athlon**이다. 이번에는 원문과 보호 PE를 정적으로 읽었으며 원본 실행/변경과 신규 MP 검사는 하지 않았다.

기존 RawConstructionData/RegisterConstructionData 부품은 실제 Session에서 생성/등록되지 않았었다. ConnectBuilding이 같은 RawConstructionProcess와 RawConstructionData를 소유하고 실제 일반/Editor 등록·Editor 반납 목록에37h를 연결했다. 원문 NULL observer/버전1/정책0/가변 길이를 사용한다. 일반/전체 writer·packet/transmit은 현재 RawSquidTransmissionState의 공통2048BYTE 버퍼를 빌려 기존30BYTE writer를 호출하고 같은 방송/대상별 전송 경로에 인계한다. 선언 길이나 새 버퍼 사본은 추가하지 않는다.

신규 free Form의dirty ff와 live Form의부모bit1 진단은 실제 Storage.AssertDisplay에 전달하고 정상 복귀하면 원문 본문을 계속한다. decoder는 부모DWORD·시작8BYTE·끝8BYTE·추가BYTE를 선택된 순서로 해석하고,뒤 필드가 부족해도 앞선 실제 쓰기를 되돌리지 않는다. 부모0은 공통 Attach에 맡기며 WORD/물리 풀 밖 DWORD만 호스트 경계에서 거부한다. 같은 PID의 객체 필드가 선택되지 않으면 NULL에서도 저장 없이 반환한다. Form 재검증/재부착/현재 시각 덮어쓰기를 추가하지 않는다. 기본 생성자는dirty ff/시작·끝0만 쓰며 기존 추가/소리 저장소의 미작성 영역은 보존한다. new 실패/미정값의 실제 OS 메모리 일치는 기존 호스트 한계다.
