## 동작과 원본 경계

`ScreenResolutions.h`는 원본 세4:3 행과 호환 세 행을 구별해 공개한다. `RawGameMenus`의 추가 목록은 기본적으로 비어 있어 원문 검사/소비자의 조회 순서를 바꾸지 않는다. 실제 Windows10/11 Client만 추가 span을 공급한다. 원본과 다른 화면비 지원은 요구된 DIB 호환 확장이며 이유를 한국어 주석에 명시했다.

원본 `SETSIZE`는 해상도 변경 경고에 Yes/No를 표시한다. Yes는 `SetSize2(width,height)`로 두 설정을 쓰고 OnExit의 `QuitApp,99`를 실행한다. No는 `DoNothing`으로 돌아간다. 실제 화면 크기는 새 프로세스에서 적용된다. 기존 ESC는 이 흐름을 사용했지만 메인 메뉴는 `ChangeResolution`으로 즉시 바꾸고 있었으므로, 메인도 같은 원본 Tell을 사용하도록 수정했다. 원본 세 행과 호환 세 행 모두 같은 확인/저장/종료 절차를 거친다.

해상도 검사에 쓰던 기존 `cpp_modern_fullscreen_smoke.py`도 이 흐름에 맞췄다. 같은 프로세스에서 모드 전환을 이어가는 menu 사례는 경고에서 No를 누르고 `resolution-cancelled`를 관측한다. 실제 승인/새 크기/재실행은 새 전용 도구가 확인한다. 과거495 관측과 캡처는 수정하지 않았다.
