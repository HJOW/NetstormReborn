## 원문과 복원 범위

`499fe0` Present는 dirty 출력/개수0·worldRedraw0·`4a17e0` 뒤 `49a081..49a1c9`에서 카메라 목표를 처리한다. 이 단위의 `PresentCameraTarget`은 그 마지막 구간을 복원한다. `4994b0` Draw를 목표 적용 부모로 보는 이전 기록은497에서 정정했다.

- 현재 진단 `005318ec`이 정확1이면 flip과 적용 호출을 모두 생략하고 목표도 보존한다. 장치 연결을 요구하는 호스트 검사는 이 원문 관문보다 앞서 실행하지 않는다.
- `4a16d0` flip 뒤 현재 Renderer의 targetX/limitX, targetY/limitY로 각각 `max(0,min(...))`을 수행한다. 현재값을 flip 이전에 복사하지 않는다.
- 별도 `00531928` signed 세계 크기와 화면 폭/높이로 `cells*16-width`, `cells*11-height`를 하위32비트 감김으로 계산한다. zoom에 따른 Renderer 한계와 구별하며 이 별도 상한으로 두 목표를 다시 제한한다.
- 실제 원문은 네 번의 FTOL로 결과를 저장한다. 입력/최소 결과가 모두 int32여서 double에 정확히 표현되며 동일한 `CameraFtolLow` 저장을 사용한다.
- 마지막 `497960` 적용을 호출한다. 여기에서 현재 Renderer view나 전역 snapshot을 직접 바꾸지 않는다. 이 단위의 독립 검사는 적용 **호출**을 관측하며497960 본체 전체의 복원/실행으로 합산하지 않는다.

공유 진단은 [497](cpp-patch-diagnostic-owner-20261027.md)의 실제 Client 장기 DWORD를 사용한다. 현재 프레임에 이 본체를 붙이기 전00531928 소유권과497960의 커서/dirty/시차·zoom 적용을 계속 복원한다.
