# 지역 소유권 도장 몸체 복원

마지막 디컴파일 수행 PC: **HJOW-Athlon, 2026-10-13**. Ghidra 12.1.4의 현재 정밀 프로젝트를 읽기 전용으로 사용했다. 보호 원본은 변경하지 않았다.

## 복원 범위

기존 `RawRegionOwnership`의 투표·원소 결정 몸체는 그대로 사용한다. 새 `RawRegionPaint`는 투표 결과를 받는 패치판 `00470900/0046fe40/004703b0`과 CD판 `004bd2d0/004bd0b0`의 지면 방문·소유자 지정·프레임 도장을 구현한다. `MakeRegionPaintOwnershipHooks`가 기존 투표의 paint 경계에 이 몸체를 연결하며 서로 다른 SID 풀은 거부한다.

| 동작 | 패치판 10.78 | CD판 10.72 |
| --- | --- | --- |
| 시작 조건 | 현재 표면 머리가 지면 타입일 때 요청을 저장 | 동일 |
| 방문 표시 | 소유자 BYTE와 요청 DWORD를 비교한 뒤 가상 소유자 지정 | 동일, 판본별 오프셋 적용 |
| 이웃 | 기존 프레임의 북·동·남·서 연결 순서 | 동일 |
| 프레임 | 실제 DWORD 직접 쓰기, SetFrame 호출 없음 | 프레임 변경 없음 |
| 빈 칸 | 고유 정수 좌표 후보 누적, edgeFarm finder와 지역 기록 | 추가 후보 없음 |
| 호출 종료 | 유효한 시작 여부와 무관하게 revision 1 증가 | 동일 |

원본 재귀의 방문 순서는 역순 push를 사용하는 명시 스택으로 보존한다. 경계 처리 중 새로 추가된 후보도 같은 호출에서 처리한다. 영향 지역 목록은 지역 번호로 중복을 제거하며, 좌표 저장은 원본이 남기는 정수 비트를 그대로 float 필드에 옮긴다.

AA 프레임은 내부·경계의 독립된 99개 캐시를 사용한다. 각 항목마다 seed 0으로 시작하는 원본 생성 동작을 유지하므로 이 캐시 생성은 전역 게임 난수를 소비하지 않는다. 일반 프레임은 최대 256개 후보·방향 정규화·A 변형·동일 방향 폴백과 원소별 반열린 quartile 난수 구간을 사용한다.

## 독립 원본 관찰

`tools/decomp_regionpaint_oracle.py`가 두 보호 PE의 실제 기계어를 Unicorn에서 실행한다. Python으로 도장 기대값을 계산하지 않는다. 입력은 여섯 작은 지도·AA/일반 프레임·기존 소유자·잘못된 타입·빈 시작·월드 경계·edgeFarm 후보·난수 상태를 포함한다. 각 입력은 x87 53비트와 64비트로 각각 정상 반환하며 결과가 같다.

| 판본 | 고유 입력 | 정상 반환 |
| --- | ---: | ---: |
| 10.78 | 386 | 772 |
| 10.72 | 98 | 196 |
| 합계 | 484 | 968 |

CRT 메모리 확보/복사·벡터 삽입, 가상 소유자 효과, edgeFarm finder는 명시 경계다. 실제 flood·프레임 선택·PRNG·방향 정규화·좌표/지역 중복 제거·형 변환은 원본 몸체를 실행한다. C++ 재생은 같은 원본 입력과 기존 `RawCanonPlacementTerrain::RegionAt`을 사용해 소유자·프레임·효과 호출 순서·좌표 후보·영향 지역 비트·drawer·revision·난수를 비교한다.

근거는 `cpppj/regionpaint.json`과 `cpppj/tests/fixtures/regionpaint-x86.tsv`다. 감사 명령 `python tools/decomp_regionpaint_oracle.py --verify`는 보호 PE·도구·소스·현호스트 내보내기·fixture SHA와 판본별 고유 입력/정상 반환 수를 확인한다. 최종 원본 실행 로그는 `extracted/regionpaint-native-final.log`다.

최종 Release의 두 집중 검사에서484개가 모두 C++ 결과와 같았으며 전체958개 검사도 통과했다. 최초 C++ 검사 입력의 타입 표 크기를 원본188/171개로 교정했으며 production 도장 몸체의 변경은 없었다. 최종 로그는 `extracted/run4-RegionPaint_-final.log`다.

## 한계와 후속 연결

합성 프레임 입력은 원본 quartile 범위가 유효하도록 12개 비연결 후보를 제공한다. 후보가 하나인 초기 합성 입력은 원본의 범위 밖 접근으로 실패했으며 해당 진단 로그를 보존했다. 이 결과를 원본 결함 수정이나 모든 잘못된 입력의 동등성으로 해석하지 않는다.

이 단위는 GameWorld·실제 미션 로딩·원본/클론 GUI·캠페인 완주 대조를 포함하지 않는다. 후속에서는 실제 outposts/temples 목록과 지형 생성·소유자/Display 효과를 같은 월드에서 공유해야 한다. `RawIslandPostPop::SetSupportOwner`의 `0044bd20/CD00461f00`은 이미 복원돼 있으므로 지면 소유자 경계에 기존 몸체를 재사용한다.
