## 실제 연결과 발견한 누락

원문 읽기 부모를 추가 관측하자 소모량이 처음 예상보다 한 칸 많았다. **459900 장치 getter 자체가 같은0055a760/0055b160 고리를 선증가/clear**하고 FileSpec 전체를 복사한다. 비장치 이름도 첫BYTE만 NUL로 바꾸며 이후 바이트는 남긴다. UNC는 서버 뒤 첫 구분자, drive는 colon 다음에 NUL을 쓴다. 기존 순수 bool 판정에 이 효과가 빠져 있었다. 전체 getter를 복원하고 실제 TryRead/Probe/ReadOnly에 연결했다.
