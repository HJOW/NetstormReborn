# 로그인 재읽기의 선행 객체 파싱 제거 (단위666)

로그인 Reload의 두 reader에서 FortTemplate 전체 파싱을 제거했다. 현재 타입 수로 파일 서명과 원시 섹션만 설치한 뒤 실제 World의 Objects 부모가 읽기/생성을 진행한다. 실제 경로를 포함한 reader와 기존 BYTE reader의 이름/실패 계약을 유지한다.

정상/손상 입력을 두 reader에 각각 제공한 실제 Session4장면을 검사했다. 정상은 편의 Chaff/TypeNames 사본이 없는 채 저장 좌표145개를 생성한다. 손상 Chaff는 지형이 만들어진 뒤 원문 진단890에서 중단한다. 현재표·부분 객체·cursor2·외곽 깊이1을 보존하고 Ready14/커서 공개에 도달하지 않는다. 입력은 명시 메모리 파일 이미지이며 실제 디스크/GUI 관측으로 기록하지 않는다.
