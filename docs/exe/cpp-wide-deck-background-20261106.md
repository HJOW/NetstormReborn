## 수정

`GumpBackgroundDraw.h/.cpp`에 선택적인 반복 본문 정책을 추가했다. 실제 GameAssets 공급은 **PATCH10.78 fortGump의 A02 프레임2에만** 설치한다. CD/다른 타입·프레임과 기존 독립 바인딩의 기본값은 원문 반복이다. 원문 메타·픽셀·파일은 그대로다.
