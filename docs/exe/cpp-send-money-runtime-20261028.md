2026-10-28, HJOW-Athlon. 사용자의 요청대로 이전 cpp 작업의 인수인계와 제품 커밋 `0dbfd0c8`(단위546)을 먼저 완료한 뒤 진행했다. 마지막 전체 정밀 디컴파일은 같은 PC의 2026-10-23 산출물이며 변경하지 않았다. 이번 단위의 문서·커밋을 마친 뒤 전체 목표를 일시 정지하라는 사용자 요청을 반영한다. 재개 요청 전에는 후속 단위를 시작하지 않는다.

AI의 생산 지갑과 분산 SP는 서로 다른 상태다. 적 AI에게 돈을 줄 때 별도 SP를 덧붙이거나 가상의 자금 저장소를 만들지 않았다. 기존 SP·난수·HUD 갱신과 실제 AI 지갑 처리기를 사용하고, 동맹 여부를 추가 자격 조건으로 넣지 않았다. 따라서 적 AI에게도 생산 자금이 이전된다.

원본 일반 입력의 고정 금액 분기와 메시지 생성자를 **888고유입력 × 두 x87 정밀도 = 1776관측**, 정밀도 차이0으로 제품 수정 전에 보존했다. Guide/Gump·누름/뗌·수정키·정지·현재 플래그와 효과 순서·11BYTE 패킷을 대조했다. 자금 판정·SP 가산·AI 지갑·송신 등은 명시 외부 장치이며, 이 수치를 원본 게임 창이나 실제 네트워크 실행으로 세지 않는다. 일반 송금 명령은 console 검사보다 앞에 있으므로 초기 검사기의 잘못된 선행 관문 가정도 원문 관측에 맞춰 교정했다.
