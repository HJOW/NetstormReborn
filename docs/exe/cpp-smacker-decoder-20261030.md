## 구현

`SmackerDecoder`는 DLL 함수표와 압축 원문/스트림을 단일 수명으로 보관한다. 실행 파일 옆의 명시 DLL을 W API로 로드하고 마지막 스트림을 닫은 뒤 라이브러리를 반납한다. 파일/라이브러리 열기 실패는 nullptr이며 잘못된 프레임을 성공으로 반환하지 않는다. C++ 파일 장치를 통해 한글 경로의 원문을 읽고 메모리 API에 전달한다. 원본 ANSI/32비트 DLL과 달라지는 Windows10/11 x64 호환 이유를 코드에 주석으로 남겼다.

정보는 원래 크기/프레임 수/간격/세로 배율과7개 트랙의 PCM 규격이다. Next는 첫 호출에서 첫 프레임을, 이후에는 다음 프레임을 해제하고 마지막 유효 프레임/EOF/오류를 구분한다. 팔레트 인덱스·RGB256색·PCM span은 실제 디코더 저장소를 빌리며 다음 디코딩 전에 필요하면 소비자가 복사한다. 자동 영상 반복이나 재양자화는 하지 않는다.

독립 DLL 구조로 배포 소스만 다시 빌드해 교체할 수 있다. 원래 C 소스·헤더·할당 헤더·README·COPYING은 변경하지 않았다. CMake/한국어 설명/provenance.json을 추가했다. FFmpeg는 검증에 사용했으며 배포 실행용 디코더는 동봉한 DLL이다.
