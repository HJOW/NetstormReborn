## 픽셀 사각형과 기준점

출력 기준점 두 값은 현재 픽셀 배율(패치 `0059a92c/0059a930`, CD `00565c44/00565c48`)로 초기화한다. 사각형은 **left/top=1000, right/bottom=0**으로 시작한다. 기본 프레임 -1이면 SHP를 읽지 않고 이 사각형과 초기 기준점을 그대로 반환한다. 빈 모양을 임의의 0 사각형으로 바꾸지 않는다.

유효 프레임의 SHP 추가 헤더는 width/height **+0x18/+0x1a**, hotspotX/hotspotY **+0x1c/+0x1e**의 signed short다. 타입 기준점은 패치 **+0x1dc/+0x1e0**, CD **+0x1bc/+0x1c0**의 signed DWORD다. 두 기준점의 차는 실제 x86 `sub`의 low DWORD를 보존한다. C++ signed 정수 넘침을 발생시키지 않는다.

프레임 주소는 `SHP + offsetTable[frame] - 0x24`다. 패치에서는 실제 `00419850`이 프레임 개수와 `flags1 & 0x440000`에 따른 두 배 범위, SHP 포인터와 타입 해제 표식 `-0x22222223/-0x32323233`을 검사한다. CD는 이를 인라인으로 직접 읽는다. C++는 CD의 물리 프레임 표 밖 접근도 예외로 진단하며 원본의 잘못된 메모리 접근을 재현하지 않는다. 패치의 논리 프레임 개수는 기존 decoder 메타 자료의 프레임 코드 개수에서 읽는다.

left/top이 이전 최솟값보다 엄격히 작을 때만 출력 기준점을 해당 차로 바꾼다. 실제 사각형 최솟값 갱신은 같은 값도 받아들이며, right/bottom은 초기 0보다 큰 방향만 확장한다. 따라서 음수/큰 타입 기준점이나 signed 음수 크기는 실제 초기 범위에 의해 잘릴 수 있다.

패치는 X 기준점 차를 정수 x87 값으로 유지하고 Y 차를 먼저 float로 저장한다. left는 float로 저장한 값을 width에 더하며 top의 덧셈은 넓은 중간값을 사용한다. CD는 X/Y 차와 투영 좌표를 모두 float로 저장하고 `(width-offsetX)+pixelX`, `(height-offsetY)+pixelY` 순서로 최댓값을 계산한다. 패치 최댓값 선택은 같아도 저장하고 CD는 기존 값보다 엄격히 클 때 저장한다. 음수 배율과 0 크기에서 나오는 **부호 있는 0**까지 원본 출력 비트를 보존한다.

## 배치와 생성 연결

`MakePriestShapePlacementHooks`는 기존 배치 접두의 `shape(type,argument,flags)`만 이 getter에 연결한다. 같은 SID 풀을 검사하고 미리보기·충돌·모양 순회 훅을 유지한다. 현재 기본 프레임/SHP/타입 기준점은 호출 시의 자료를 읽는다. 자료와 전역 상태의 참조 수명은 호출자가 보장한다.

두 판본의 생성 통합에서 임시 `(0,0,16,11)` 반환 훅을 실제 SHP 헤더 조회로 교체했다. 실제 픽셀 범위→배치 여백→decoder 정수 범위→미리보기→finder/후보→나선 생성→실제 사제 생성자/postCreate를 연결한다. 첫 **21,22** 거부→다음 **21,21** 생성, SID **15001/6001**, WORD **0x8101**, 미리보기 **16칸**을 유지한다. 별도 연결 검사는 160×110 SHP의 여백 10으로 좌표 9를 거부하고, 현재 기본 프레임을 16×11 헤더로 바꾼 뒤 기존 geometry 경계로 진행하는 것을 확인한다.

## 독립 원본 대조

[`decomp_priestshape_oracle.py`](../../tools/decomp_priestshape_oracle.py)는 패치 **4,032개**, CD/10.37 각각 **2,016개**, 총 **8,064개**를 세 실제 PE에서 실행했다. 전체 getter·decoder·패치 SHP helper를 **대체 호출 없이 정상 반환까지** 실행한다. getter의 cdecl/ESP·보존 레지스터·x87 균형을 검사한다. FPCW **0x027f/0x037f** 관찰이 모두 같다.

기본/명시/누락/이중 레이어 프레임, 프레임 개수 밖 기본값을 읽는 CD 차이, signed WORD 극값과 DWORD 뺄셈 넘침, 2^24 주변 float 반올림, 초기 1000/0 경계, 네 픽셀 배율과 패치 홀수/signed 방향을 포함한다. SHP 주소 표는 프레임 주소를 역순·비연속으로 두고 각 프레임에 다른 헤더를 공급하여 실제 offset 조회를 검사한다. 출력 사각형/기준점 여섯 값은 float 비트로 저장해 C++와 대조한다.

패치·두 정밀도 합산 실제 getter/생성/비패턴 조회 **8,064회**, Advance **14,112회**, 타입 getter **16,128회**, SHP helper **6,048회**다. CD/10.37 각각 getter/생성/비패턴 조회 **4,032회**, Advance **7,168회**다. assert/OS 실행은 **0회**이며 저장 fixture·PE·내보내기·도구 SHA와 호출 횟수를 새 `--verify`로 감사한다.

## 남은 경계

특수 패턴 번호와 타입/SHP 메타 자료, 타입 기준점·픽셀 배율은 분석 입력이다. **타입 기준점 초기화 및 자산 로더 연결의 원본 몸체, 특수 패턴 분기, 후보별 bridge/표면/지형/지역/관계와 최종 판정, 일반 사제 Pop/보호막·회복 예약/Carrier 검사**는 후속 작업이다. 전체 MayPlace 또는 원본 게임/OS를 기계어 실행했다고 해석하지 않는다. 정상 fixture에 포함하지 않은 assert/손상된 입력은 별도 C++ 예외 검사와 구분한다.

Release 경고/오류 **0**, CTest 내부 **348개·실패 0**(108.73초), 감사 **48종 모두 통과**, 누적 독립 x86 **245,145개**다. 최종 빌드/전체 회귀·감사와 로그는 [LEFT_JOBS.md](../../LEFT_JOBS.md)의 최신 완료 기록을 따른다. 기존 독립 fixture와 감사 도구는 변경하지 않았다.
