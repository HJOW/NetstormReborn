# 일본어 튜토리얼3~4

2026-11-23, HJOW-Athlon. 마지막 디컴파일 PC도 HJOW-Athlon이며 디컴파일 변경은 없다. CD10.72·QuickJS 추가 연동·프레임 보간의 보류를 유지한다.

`tutorial3.japanese`15섹션과 `tutorial4.japanese`16섹션의 안내·성공·버튼 라벨을 번역했다. UTF-8 BOM/CRLF이며 제목 외의 실행 설정, 버튼 명령/인자, 완료 키, 매크로, 그림의 섹션/순서는 한국어 구조와 일치한다. 공식 번들은13/43파일이며 동적 한자464자로 슬롯 한계 안이다.

사용자 지시에 따라 그림5개/3구간을 실제 확인했다. Tutorial3 A1의 켜진 썬 에너지와 D1의 레인/윈드/썬더 제네레이터, Tutorial4 A의 썬 캐논이 라벨과 함께 표시된다. 제네레이터는 각 그림/라벨마다 명시 줄바꿈을 두어 자동 줄바꿈 뒤 잘리는 배치를 피했다. [검증 JSON](../../cpppj/japanese-tutorials-1336-20261123.json). 원시 입력/보고/BMP/실행 결과는 `extracted/cpp-followups-1328/*1336*`에 있다.
