## 번역과 구조

`assets/lang/japanese/d/tutorial1.japanese`, `tutorial2.japanese`의 모든 안내·성공/주의 문장·버튼 라벨을 번역했다. UTF-8 BOM/CRLF이며, 한국어와 원본 영어의 섹션·명령 인자·AI/SP 설정·치환·그림 순서를 유지한다. 일본어 공식 번들은11/43파일이다. 원본 영어의 `Euclidius, 4th Century`는 일본어에서도4세기 인물이라는 뜻으로 옮겼다.

사용자의 추가 지시로 그림을 독립 확인 대상으로 삼았다. 구조 감사 도구는 단순 그림 개수 외에 그림이 속한 섹션/도움말 앵커와 순서도 대조한다.

## 마나 그림 보완

10.78의 `mana.type`/SHP에는8프레임만 있지만, 원본 HTML은 켜진 원소를8~11번, 생산 슬롯을17번으로 참조한다. 현행 원본 그림의 켜진4원소는4~7번이며, 실제 메뉴의 생산 슬롯 번호는9번이다. 기본 HTML helper의 원문 바이트 계약은 보존하고 제품 PATCH의 HTML 연결에서만8→4,9→5,10→6,11→7,17→9를 교정한다. 일반 `~[I...]` 메뉴 식은 다시 매핑하지 않는다. 이 교정은 언어와 무관하게 안내/도움말에 적용된다.

CD SHP에는25개의 마나 프레임이 남아 있다. 앞8개는10.78과 전체 픽셀·투명도·36바이트 추가 헤더가 일치한다. `tools/extract_cpp_mana_pictures.py`는 이 일치를 확인하고 원본을 읽기만 하여8,016바이트의 단일 SHP 블록을 생성한다. `ManaPictureData.inc`에 보관한 원본 그림을 Markup의 UI 측정/제한 검사/출력에서 함께 사용한다. 기존 월드의 타입·8프레임 SHP·AI·커서 동작은 그대로다. CD판 실행/게임 복원을 재개한 작업이 아니다.
