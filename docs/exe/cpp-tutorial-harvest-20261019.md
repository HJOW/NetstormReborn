## 입력 검사 보완

- 검사 전용 `placement-reach`는 현재 취득한 실제 다리의 Canon 패턴·회전·새 칸을 읽어 목표에 가까운 합법 마우스 위치를 찾는다. 같은 커서/MayPlace를 사용하고 기존 다리와 겹친 칸은 전진으로 세지 않는다. 실제 건설은 후속 좌클릭이 수행한다. 기존 placement-near/fire와 일반 사용자 입력은 그대로다.
- `raw_piece`는 실제 조각 번호/회전을 읽는 관측 항목이다. 첫 삽입 위치가 raw_sp 제목을 끊을 수 있음을 빌드 뒤 GUI 전에 확인하고 기존 raw_cursor/raw_sp 줄을 보존하도록 옮겼다.
- 검사 전용 `when`은 현재 보고서 하나에서 정규식 조건을 읽는다. &&와 각 조건 앞 !를 지원하며 허용된 입력 동작만 기존 분배기에 전달한다. surface-delete·kernel-tell·기타 상태 변경 경계는 허용하지 않는다. 기존 엄격 입력/오류/큐 순서는 보존한다.
- 새 수동 입력987행은 실제 안내창이 열린 경우에만 버튼을 누르고 현재 B/C/D에서만 다리를 놓는다. E에서는 실제 사제 선택과 간헐천 클릭으로40h가 관측되면 명령을 다시 보내지 않는다. 필드 읽기로 다음 행동을 선택하며 진행 결과는 쓰지 않는다.
