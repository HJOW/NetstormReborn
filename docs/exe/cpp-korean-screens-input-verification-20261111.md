## K2 — 한글 입력

- 미션(`tutorial1`) 안에서 Enter로 채팅 입력줄을 열고 MCP `text`로 `안녕하세요 NetStorm 한글 입력`을 넣으면 입력줄에 한글이 D2Coding으로 정상 표시된다(`input5/chat-typed-korean.png`). MCP `text`는 IME 확정 결과와 같은 `QueueCommittedText`(UTF-8→표시 시퀀스) 경로를 쓴다. ESC 뒤에는 옵션 메뉴 줄(`게임 보기 옵션 플레이어 정보`)이 한국어로 열린다.
- 단위 검사는 `KoreanInput_` 11 + `KoreanIntegration_` 12가 통과한다(1270).
- **검증 못 한 것:** 실제 물리 IME 조합/후보창, OS 유니코드 클립보드 실패 경로, Save as Fort의 한글 파일명(원래 ASCII/공백 정책 유지)은 이 환경에서 확인할 수 없다(물리 입력/캡처 환경 제한). 사용자 직접 확인 대상이다.

## K3 — 한국어 본문과 용어

- 본문: 한국어 모드로 `tutorial1`에 들어가면 브리핑 첫 장(`NetStorm!`, 목표·조작 설명, `다음` 버튼)과 둘째 장(`화면 이동`, `뒤로`/`확인`)이 정상 표시된다(`input3/briefing-korean.png`, `input4/briefing-korean.png`). 도움말 창은 제목·본문·링크 목록·버튼이 정상 표시된다(`help4ko/help-window-korean.png`). 128개 주제 모두 파서 8192바이트 미만임은 1270 검사가 보장한다.
- 용어 자동 검사: 44개 한국어 자산에서 AGENTS 명칭 규칙에 어긋나는 24개 대표 표기(작업장/워크샵/발전기/제너레이터/휠리·윌리 변형/반더타워/프리스트/템플/브릿지/스로어/가이저/알타/레지던스 등)가 **0건**이고, 규칙 표기는 워크샾 105·제네레이터 64·훨리베이스 13·훨리기그 24·반더 타워 7·사제 278·신전 143·다리 183·발사기 71·간헐천 63·제단 66·거주 구역 5·고갈된 2회 쓰인다. 전수 문장 교정(번역 품질)은 사람 검수 몫이며 하지 않았다.

## K4 — 화면별 UI 문구

메인 메뉴 8버튼(`캠페인/멀티플레이어/데모/도움말/편집/크레딧/옵션/종료`), 도움말 팝업(`일반 도움말 - F1/기술 도움말/버전`), 캠페인 선택창(`초기 미션/사제 훈련/자유를 위한 투쟁/국가의 탄생/완전한 승리/사용자 제작 캠페인`, `뒤로`), 편집 맵 불러오기 창(`전투 맵 불러오기`, `새 맵 만들기`/`취소`), 옵션 메뉴(`해상도 >`, `언어 >`, `소리 켜기`, 음악·바람·스피커·음량·가장자리 스크롤·자동 데모·시작 시 팁·`안티앨리어싱`·`FSR 1.0 업스케일링`)가 모두 한국어로 렌더링된다. 메인 버튼은 돌 버튼 그림 위에 글꼴로 그려지는 방식이라 별도 한글 그림 자산이 필요 없다. **남은 영어 문구:** 옵션 메뉴 끝의 `Pass Server Diagnostic`(종료된 온라인 서버 진단 잔재, 번역표에 키 없음). 맵 목록 이동행(이전/다음)은 빈 맵 목록 사본이라 이번에 보지 못했다.

## 새로 발견: 메인 메뉴 `Multiplayer` 버튼

한국어 화면 시험 중 `Multiplayer` 버튼을 누르자 `State 6` 뒤 `std::logic_error("캠페인 설치의 alternate Fort populate 미연결")`(`RawCampaignWorldRuntime.cpp:64`의 `populateIsland`, 원문 `0046e630` 부모)로 종료했다. 새 오류 로그(`logs\*.log`)가 원인과 직전 활동을 남겼다. 영어에서도 같은 경로일 가능성이 높으며 MP 월드 생성/섬 채움의 미구현 경계다. 이 시험에서는 MP를 실행/검증하지 않았다(버튼 클릭 1회). 3차(LAN) 후속에서 `0046e630`와 이를 부르는 Fort 읽기 상태를 원문 대조로 구현해야 하며 LEFT_JOBS M6에 기록한다.
