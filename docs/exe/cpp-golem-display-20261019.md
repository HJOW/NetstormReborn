# 골렘 다리 보행의 발 기준점 — 2026-10-19

골렘이 다리 위에서 오른쪽으로 쏠려 보인 원인은 일반 표시 경로에서 원본 TYPE의 발 기준점을 누락한 것이다. 원본 `sunWalker`의 `hotFootRatioX=0.5`, `hotFootRatioY=0.2`를 16×11 칸 크기로 정수 변환하면 `(8,2)`가 된다. 원본 `498220`은 화면 좌표에서 TYPE의 두 값을 차감한다. 클론의 골렘은 이 차감 없이 SHP 프레임을 제출했다.

`GameWorld.cpp`에서 실제 10.78 골렘 `133/VT50e568`의 본체를 왼쪽8·위쪽2픽셀로 옮기고, 클릭 영역에도 같은 기준점을 적용했다. 보행의 실제 소수 좌표나 경로에 임의의 보정값을 넣지 않는다. 북·남 방향을 포함한8방향 전체가 같은 원본 규칙을 사용한다.
