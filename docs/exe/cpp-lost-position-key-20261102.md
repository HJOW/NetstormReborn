## 복원한 동작

원본10.78의 `004d98e2..004d990d`는 U/u를 누르면 현재 `005c848c/005c8490`의 최근 손실 위치를 `0040e800`으로 검사하고, 유효하면 `00433aa0(x,y)`으로 즉시 중심을 이동한다. 정지·Console·모달 관문 뒤의 일반 키이며 Shift/Ctrl/Alt를 별도로 거부하지 않는다. 뗌은 공통 관문에서 제외한다. 큐 사건의 outside 표시는 원문의 키 비교 마스크에서 제거되므로 별도의 거부 조건을 추가하지 않았다.

유효점은 각 축이 모두0보다 크고 `float(signed worldCells)`보다 작아야 한다.0·세계 상한·음수·NaN은 유효하지 않다. Tab이 이미 사용하는 같은 `0040e800` 판정 몸체를 재사용한다. 일반 숫자 카메라 저장의0 허용 판정과 혼동하지 않는다.
