# 공유 빔 프레임·굵기 선·소진 요청 — 단위105

현재/마지막 전체 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-16**으로 일치한다. 직전 커밋은 `7a5d297`이다. AGENTS.md와 양 LEFT를 다시 읽었으며 새 디컴파일·원본 게임/GUI 실행은 없다. 이번 작업은 단위104의 경로 생성에 실제 프레임/Draw 본체를 더한다.

## 실제 시간과 수명

`RawLightningFrame`은 `00472310`의 같은 raw 부모 조회와 시간 조각, 기존 `RawLightningPath`의 실제 Seed/Step, 용량 전체 수명과 흔들림 계산을 실행한다. 시간 전역은 다른 입자와 같은 구조를 사용하고 게임 난수도 경로와 공유한다. 별도 난수나 렌더링 전용 시간을 만들지 않는다.

최초 프레임은 현재 raw 부모 좌표×배율로 영역을 설정하고 마지막 시각/누적 시간을 초기화한 뒤 Seed한다. 파일명 포인터가 있으면 **raw 부모 좌표·파일명·flags0**을 `004a9d70`에 한 번 전달한다. 이는 SoundHandle 재생과 다른 경계다. 파일명이 NULL인 맨 오 워에 임의 소리를 더하지 않는다. 최초 프레임에는 수명 감소·jitter·dirty가 없다.

후속 프레임은 실제 `00418470`의 최대0.5×0.1초로 나눈다. 넓은 시간 차이를 먼저 float delta에 저장하고, 제한 여부는 넓은 차이로 검사한다. delta는10배가 되고 scaledDelta에는 현재 배율을 곱한다. elapsed는 저장한 delta를 double에 누적한다. 경로에는 **float(elapsed), 현재 delta**를 전달한다. 두 인자를 elapsed로 합치지 않는다. 시간 후퇴/0간격도 원문대로 처리한다.

매 조각 **사용 꼬리와 무관한 용량 전체**에서 수명을 감소시킨다.0/음수와 미사용 입자도 감소 대상이다. 양수로 남은 입자는 X/Y 순서로 구간 난수를 뽑아 jitterWeight×scaledDelta와 곱하고 현재 좌표에 더한다. strength는 흔들림 가중치가 아니다. 첫 점의 가중치0도 난수를 소비한다. 원본 float 저장 위치를 지킨다.

같은 프레임의 로컬 영역은 모든 조각에 걸쳐 누적한다. 살아 있는 점마다 실제 `004239f0`의 오른쪽/아래쪽1픽셀을 포함한다. 생존 입자가 있으면 이전 영역→새 영역 dirty를 원래 순서로 보낸다. 없으면 dirty 갱신 전에 `0041bf10(this,0)`의 **Form 삭제 요청**을 보내고 즉시 반환한다. 실제 삭제/등록 반납은 다음 Host 연결에서 수행한다.

## 실제 Draw

`004724f0`은 firstLive 다음부터 사용 꼬리까지만 살피고 양수 수명인 현재 점을 이전 포인터의 점에 연결한다. 이전 점이 죽었어도 참조하며, 포인터는 같은 고정 입자 저장소의 index+1 토큰으로 표현한다. 중심선 방향은 **이전 점→현재 점**, 색은195다.

카메라 좌표를 뺀 결과는 먼저 float에 저장한 뒤 CRT의0방향 절삭을 한다. strength≥float0.25이면 두 X에1을 더한 색85의 선, strength>float0.5이면 두 Y에서1을 뺀 색85의 선을 차례로 출력한다. 보조선 간격은 저장한 float 좌표에서 넓게 더하고 빼므로 절삭한 정수에 간격을 더하는 구현과 다르다. 공유 팔레트를 임의 조회해 원본의 리터럴 색195/85를 바꾸지 않는다.
