# 미복원 Path 시작 상위 몸체의 ABI와 전달 순서

**미복원 분석 기록**이다. 실제 상위 몸체의 native 실행 및 C++ 대조 추가는 **0개**이며, 완료된 `RawPathData`768개/가상 Prepare48개와 합산하지 않는다. 최종 디컴파일 PC **VM-W11-CODEX**, 날짜 **2026-10-13**. 읽기 전용 정밀 내보내기는 `pathstart-functions.json`의 판본별2개다. 처음에 추정한 래퍼 주소가 함수 시작이 아니라 내보내기2/3개로 종료1이었으며 정확히 확인된 두 함수만 남겨 재실행한 결과 종료0이다. 실패/최종 로그를 함께 보존한다.

실제 시작 함수는 패치 **00489080** / CD **0047d150**, 타입별 프로세스 선택은 **00488fe0** / **0047d020**이다. 기존 C 디컴파일은3인자와 `unaff_*`로 인식했지만 기계어의 스택 오프셋 및 패치 실패 후 재귀 호출의 **0x20바이트** 정리에 의해8인자 전달을 확인한다. CD는7번째까지 직접 읽으며8번째는 이 본체에서 읽지 않는다.

| cdecl 인자 | 전달 및 원본 필드 |
|---|---|
| 1(parent) | 시작 부모 SID; Init 첫 인자와 Attach 첫 인자로 전달 |
| 2/3(destination X/Y) | 각0..254로 제한; 패치 +186dc/+186e0에도 보존; 부모 +44로 전달 |
| 4(replaceStart) | nonzero면 시작에 연속한 거의올림 좌표를 현재 실제 부모 좌표로 교체 |
| 5(helper) | 패치 +186d4 / CD +2f14; WriteData +11 WORD에 기록되는 값 |
| 6(tailWord) | 패치 +186e4 / CD +2f1c; WriteData +21 WORD에 기록되는 값 |
| 7(tailByte) | 패치 +186e8 / CD +2f20; WriteData +23 BYTE에 기록되는 값 |
| 8 | 패치 실패 뒤 재귀에서 그대로 보존; 정상 본체/CD에는 직접 사용 없음 |

정상 진행 순서는 **타입 분배 → 해당 타입 생성 포인터 호출(0,0) → 가상 +20 Init → 이전 targetA/targetB 및 helper/tail/finished0 필드 쓰기 → 유효 경로 확인/시작좌표 선택적 교체 → 가상 +30 Prepare(0,현재 부모 타입 포인터) → 가상 +2c Attach(parent,0,타입별 flags) → 부모 +44(destinationX,destinationY,process) → 부모 +40**이다. `OnAttached`·공유 버퍼 직렬화는 이 실제 Attach 내부에서 수행된다.

가상 +20 실제 주소는 패치 텔레포트/사제 모두 **0048bb10**, CD 텔레포트 **0047feb0**/사제 **00480910**이다. 이 래퍼들은5인자(parent,destinationX,Y,startX,Y)를 받고 이미 복원한 기본 Init에 **검색 flags0을 삽입**한다. type23/54의 Attach +2c는 패치 **0048b680** / **0048bd30**, CD **0047fe90** / **004808b0**이며, Prepare +30은 패치 **0048a200** / CD **0047e710**이다. 이 주소는 실제 PE vtable byte로 확인했다.

보스 권한에서는 기존 같은 종류 경로를 찾아 targetA/targetB를 보존한 뒤 삭제한다. 패치는 이때 현재 시작 X/Y가 목적지보다 작으면 해당 축을 **0.5**씩 빼서 Init에 넘기지만 CD는 이 보정을 하지 않는다. 선택 타입3개에는 client 부착 flags0x10을 지정하며 일반 사제/텔레포트는 서버 flags0이다. 선택 전역이 켜진 사제의 목적지는 거의올림 뒤 **0.5**를 뺀다. 정확한 타입 번호/전역은 각 export에 보존했으며 임의 분류로 바꾸지 않는다.

패치의 무효 경로 분기는 부모 영역의 실제 finder로 겹친 genus0x8c044200을 검사하고 `00443800` 정리를 요청한다. 프로세스 scalar 삭제 후 전역 **005951b0** 재귀 가드를 검사하며 정리가 있었으면 원래8인자로 한 번 다시 시작한다. **재귀 반환값을 직접 반환하지 않고 외부 함수는0을 반환**한다. CD의 무효 경로는 scalar 삭제 후 바로0을 반환한다. 이 겹침 정리/재귀·부모 +44/+40·이전 경로 전체 수명은 이번 직렬화 단위에 구현하지 않았다.

`tools/analyze_pathstart.py`는 정확한 함수 범위·원본 vtable·명령 필드와 가상 호출 주소를 정적으로 검사하고 `recovery-pathstart-analysis.json` 및 `extracted/pathstart/abi-disassembly.tsv`에 SHA/기계어를 보존한다. 다음 부모 조립은 이 상위 몸체를 실제 same pool/hash/spot/Kernel/서버 직렬화에 연결하고 실제 사제 부모의 +44/+40·이전 경로 삭제·실패 정리·명령 메타 필드를 복원해야 한다. 임시 직선 경로/빈 부모 콜백으로 이를 대체하지 않는다.
