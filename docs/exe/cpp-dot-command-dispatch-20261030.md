## 원본 근거와 복원 범위

마지막 전체 디컴파일은 **HJOW-Athlon / 2026-10-23**, 이번 PC도 HJOW-Athlon이다. 보호된 원본10.78 PE와 정밀 함수표를 읽고, 격리 메모리에서 분배 본문295BYTE와 실제 Regexp 컴파일러/검색 엔진/캡처/오프셋 함수를 실행했다. 게임 프로세스를 시작한 검사가 아니다.

정적 생성자004fc860은00506a30의 다음 고정 패턴을00557df0에 컴파일한다. 아래의 `\t`, `\n`, `\r` 표기는 실제 해당 제어 바이트를 읽기 쉽게 표현한 것이다.

```text
^[\t\n\r ]*\.([^\t\n\r ;$]+)([^;$]*)(;|$)
```

- 선행 공백은 TAB/LF/CR/space 네 가지다. VT/FF 및 비ASCII 바이트를 추가 공백으로 취급하지 않는다.
- 명령 이름은 대소문자를 무시해 현재 표를 순서대로 찾는다. 첫 중복 이름이 선택되며 signed count가0/음수이면 기본 명령으로 간다.
- 이름 캡처는80BYTE, 인자 캡처는127BYTE와NUL이다. 앞 공백을 포함한 인자를 그대로 전달한다. 등록 이름의 기존31BYTE 제한은 바꾸지 않았다.
- 세미콜론 뒤는 다음 검색으로 이어진다. 알 수 없는 명령이나 패턴 실패는 **남은 입력 전체**를 현재 기본 슬롯에 전달한다. 기본 슬롯0의 원본 함수는 say0042f1e0이다.
- 비영 반환의 오류 이름은 콜백 뒤의 현재 표에서 읽는다. 기본 명령의 오류 슬롯도 콜백 뒤 재조회한다.
- 다음 위치는 명령/오류 콜백 뒤의 공유 Regexp 그룹3을 읽는다. 같은 상태로 중첩 분배하면 바깥 진행 위치에도 그 효과가 남는다.

`RawDotCommandDispatch`는 원문 이름/함수/count의 같은 실제 인접 표를 빌린다. 기본 슬롯과 마지막 구분자 상대 위치는 `DotCommandDispatchState`가 보유한다. 명령 본문과 오류 출력은 실제 식별자/현재 이름을 받는 선택 장치다. 미연결 장치에 도달하면 명시 예외이며 성공으로 삼키지 않는다. 실제 할당 밖의 포인터 접근도 명시 예외다. 임의 Regexp 문법 전체와 원문 미정의 메모리 접근을 지원한다고 주장하지 않는다.
