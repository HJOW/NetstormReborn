사용자는 Edit에서 비석을 스펠로 전환한 뒤 효과 발생 시 도움말 이미지가 나오는 부분을 **일단 표시하지 않는 방향으로 임시 구현하고 넘어가 달라**고 요청했다. 원본10.78과 다르게 표시하는 명시적 예외로 처리했다. 이 항목의 추가 원인 분석은 보류한다.

현재 프레임을 다른 번호로 바꾸거나 원래 예약을 취소하지 않는다. 프레임 진행·효과 발동·삭제와 도움말 창의 별도 표시 코드, 원본 자산은 변경하지 않았다. 다른 타입의 도움말 프레임이나 CD10.72에는 이 예외를 적용하지 않는다.

## 먼저 확보한 원본 관측

사용자의 임시 처리 요청 전에 원본10.78의 같은 경로에서도 도움말 그림이 깜빡이는 것을 직접 확인했다. computer-use의 원본 창 캡처는 두 번 시간 초과로 실패해, 기존 analyzeManager/ns_driver의 게임 전용 캡처/입력으로 전환했다. 직접 사본1개와 분석기 사본1개를 실행했으며 원본 디렉터리에 쓰지 않았다. 현재 호스트는 AGENTS.md의 실행 확인 예외다.

입력 직후와 후속9장의 총10장 중6장은 이전 클론의 그림 내부 **80×110=8,800픽셀이 전부 일치**했다. 나머지4장은 일치하지 않았으며 시간순으로 표시→비표시→재표시를 확인했다. 가장자리/앞쪽 간헐천이 겹치는 전체 그림 사각형과 전체 화면의 동일성은 판정하지 않았다. `compare_spell_help_frame.py`는 이미 저장한 캡처만 읽고 게임을 실행하지 않는다.
