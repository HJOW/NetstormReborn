## 원인과 수정

State에 현재 World battle을 빌리는 `sharedHalfHealthMode`와 getter를 더하고 Session에 연결했다. 공통 SalvageRefund가 이 현재 값을 읽으므로 메뉴와 실제 환불 계산이 같은 원천을 사용한다. 독립 구성은 기존 bool을 읽으며 PATCH/CD/10.37 보상 fixture의 기대는 유지한다.
