# cpppj1321 — 공통 Pop 검사 기준선과 일반 Sprite 기대값

제품1320을 유지하고, 오래된 `pop_context` 실패 기준선 중 허용된 공통 검사 **325건**을 현행 라이브러리로 확인했다. **초기324건 통과·1건 실패(2단언)**였으며, 일반 Sprite 지원을 빠뜨린 검사 기대값을 교정한 뒤 해당1건도 통과했다. 전체1175건 통과를 뜻하지 않는다.

## 실패 원인과 교정

`SquidUnpop_VtableMetadata_MatchesActualCommonDisplayPaths`는 `unpop-vtables.tsv`의 오래된 공통 표시 mask에 이후 복원한 예외 주소를 더해 비교한다. 제품은 `2c6ab7cc1 / 20261110-21 CP`부터 일반 Sprite 가상표 `0050cc08`을 메타 Sprite `0050c9f0`과 함께 지원하지만, 검사는 메타 주소 하나만 허용했다. 따라서 일반/부분 표시 flags0·0x2000에서 각각 실패했다.

기대값의 주소 조건에 `0050cc08`을 추가했다. 이는 [원문 주소 기록](cpp-asset-postpop-noworld-20261111.md)의 메타·일반 Sprite 공통 경로와 일치한다. **제품 코드·원본 fixture의 주소/mask·행 수151은 변경하지 않았다.** 실제 메타/MP 장치를 호출하지 않고 지원 여부만 조회한다.

## 검증 범위

혼합 집중 대상 `netstorm_pop_context_tests`에는1175건이 등록돼 있다. 아래38파일에서 검토한325개 이름만 골라 검사별 별도 프로세스로 실행했다. 첫 선택127건, 후속158건은 모두 통과했고, 마지막40건 중 위1건이 실패했다. 원시 이름 목록과 전체 결과를 [기계 판독 기록](../../cpppj/pop-test-baseline-1321-20261117.json)에 남겼다.

- 공통 Pop·후처리·프레임·그래프·표시 15파일127건.
- 지상 객체·보호막·섬·다리·사제 초기화와 일반 Factory, 거주 구역·간헐천의 선택된 본문 16파일158건.
- Unpop·표시·건설·생산 정보·보호막 정기·비용·간헐천 채굴 7파일40건.

Factory/Asset 혼합 파일은 일반 Factory와 거주 구역·간헐천 접두만 선택했다. 기존 Outpost·공중3종·MP 전용·전투·포획/희생·승리 검사는 실행하지 않았다. 게임 창/원본 게임 실행은0이다. 기존 fixture **988파일의 실행 전후 SHA-256은 세 묶음 모두 불변**이다.

Release 최초 빌드와 교정 뒤 증분 빌드 모두 종료0이다. VS 업데이트 후 이 집중 대상의192개 소스를 MSVC14.52로 갱신했다. 제품 실행 파일과 라이브러리는 바꾸지 않았으며, 교정 뒤에는 변경된 기대값의 해당 검사만 재실행했다. 다른324건의 기존 결과를 최종 전체1175건 실행으로 확대하지 않는다.

325건 밖의 과거 실패가 해결됐다는 증거는 없으므로, **옛 실패24건이라는 숫자는 과거 기준선으로만 보존한다.** 다음에는 guide_fort_request·menu_session·main_popup·file의 허용 범위와 아직 분류되지 않은 기존 실패를 이어서 확인한다. M8 사전 점검은1436항목·MSVC14.52 런타임 선택까지 통과했고, 실제 ZIP 작성/배포본 관문은 미완료다.
