# cpppj 한국어 명칭 교정과 검증 근거 연결

작업일: 2026-10-16. 작업 PC와 마지막 전체 디컴파일 PC는 **VM-W11-Codex**이며, 마지막 전체 디컴파일 날짜는 **2026-10-16**이다. 이번 작업에서 새 디컴파일이나 원본·클론 게임 실행은 하지 않았다.

## 변경 범위

사용자가 AGENTS.md의 명칭 변경에 맞춘 cpppj 작업을 요청했다. 앞선 `20261016-23 CM` 점검에서 보류한 해시 고정 파일까지 교정했다. 기준 커밋은 `442eb18`이다.

- Altar의 두 이전 발음 표기를 **제단**, Residence와 그 변이 번역을 **거주 구역**, Geyser를 **간헐천**으로 맞췄다.
- Whirlibase·Whirligig는 **훨리베이스·훨리기그**, Workshop은 **워크샾**, Barricade는 공유 표의 **바리케이드**로 맞췄다. 신전·제네레이터 등 기존 확정 표기도 같은 규칙으로 점검했다.
- 내부 타입명을 한글로 적은 실제 자산 설명은 대응표의 표시 이름으로 맞췄다. 예를 들어 TYPE71은 **썬 디스크 발사기**, TYPE136은 **썬 바리케이드**, TYPE85는 **썬 워크샾**, TYPE140은 **크로스보우**다. 내부 `Factory` 분류를 설명하는 일반 용어와 원본 영어 심벌은 실제 건물의 표시 이름과 구별한다.
- 소스·검사의 주석과 한국어 진단 문구, 분석 도구의 설명·주석 경계 문자열, 현재 보고서의 설명, 분석 문서와 `LEFT_JOBS.md`의 서술을 교정했다. 조사도 새 명칭의 받침에 맞췄다.

기준 커밋과 대조하는 변경은 **200파일**이다. 소스 47·검사/fixture 29·분석 도구/목록 30·분석 문서 26·기존 보고서 68개이며, 유효 SHA 연결 **497개**를 갱신했다. 이 수에는 새 감사 도구·후속 JSON·작업 문서와 공통 명칭 문서·인수인계 갱신은 포함하지 않는다.

영어 심벌·타입 번호·주소·설정 키·원본 영어 문구와 게임 동작은 바뀌지 않는다. cpppj의 한국어 UI 연결은 기존 로드맵의 3차 목표다.

## SHA 연결 처리

기존 관찰 보고서를 새 원본 실행 결과로 다시 만들지 않는다. 현재 파일과 **교정 직전에도 일치하던** `files`/`sha256` 연결만 새 바이트 SHA로 갱신한다. 이미 실패하던 출처 SHA를 현재 값으로 덮지 않는다. 원본 관찰 수·반환 횟수·게임 실행 수와 역사 원문·diff·`cpppj/hist` 사본은 유지한다. `dudenotice-x86.tsv`는 첫 설명 주석만 바꾸며 입력·출력 행은 바이트 단위로 동일하다.

[korean-name-migration.json](../../cpppj/korean-name-migration.json)은 기준 커밋, 전후 SHA, 작업 사본 줄 끝, 유효한 연결의 갱신 목록을 가진 독립 후속 기록이다. [analyze_cpp_korean_names.py](../../tools/analyze_cpp_korean_names.py)는 다음을 검사한다.

1. Git 기준 객체를 기록된 줄 끝으로 복원한 바이트가 교정 전 SHA와 일치한다.
2. 코드·문서는 도구에 고정된 한국어 명칭·조사 치환만 포함한다. `템플릿` 같은 일반 단어는 치환하지 않는다.
3. JSON은 현재 설명 필드와 교정 직전 유효했던 SHA 연결만 다르다. 수치·역사 원문·내장 diff는 동일하다.
4. fixture의 주석 밖 전체 바이트는 그대로이고, 신규 원본 관찰·게임 실행은 0이다.

```powershell
python tools/analyze_cpp_korean_names.py --verify
cmake --build cpppj/build --config Release --parallel 3
ctest --test-dir cpppj/build -C Release --output-on-failure
```

## 검증

변경 전 기존 `tools/*.py --verify` **348개 중 87개 통과·261개 실패**를 보존했다. 기존 실패는 이후 단위의 변경으로 이미 어긋난 출처 SHA와 로컬 자료 부재 등을 포함한다. 그 실패를 이번 명칭 작업의 성공으로 처리하지 않는다.

기존 검증 도구를 실제 표시 이름 보완 후까지 다시 전수 실행하여 **87개 통과·261개 기존 실패**와 통과 도구 집합이 동일함을 확인했다. 새로 실패한 도구와 타임아웃은 0이다. 신규 명칭 감사는 200파일/497연결 전체가 통과했고, 변경한 Python 도구와 신규 감사 도구의 구문 검사 27개도 통과했다. 기존 BOM이 있는 Python 파일은 BOM을 인식하는 방식으로 구문을 검사했다.

최종 Release 빌드는 **경고0·오류0**이다. 전체 CTest는 검사 프로그램 하나 안의 **1379개 중1377통과·2실패**, 전체 **124.91초·종료8**이다. 실패는 다음 두 개이며 직전 `extracted/goal-flyer-frame-20261016-ctest.log`의 실패 집합·내부 검사 수와 동일하다.

- `CampaignKernelFrames_TheStormRages`
- `CampaignKernelFrames_DissolvedAlliance`

새 회귀는 없다. 두 실패는 기존 맨 오 워 표적 검색과 다른 총 animation 미복원 경계이며 이번 명칭 작업에서 완료 처리하지 않는다. UTF-8 206파일·문서 상대 링크·공백·스테이징 범위 검사가 통과했고, 현재 cpppj 소스·검사에는 치환 대상 옛 명칭이 남지 않았다.

로그와 변경 전후 도구별 전체 출력은 `extracted/korean-names-20261016/`에 있으며 로컬 자료다. `baseline.json`과 최종 `final-expanded.json`은 동일한 기존 도구 348개의 전체 결과를 담는다. 중간 `after.json`에는 `sha256` 형식 추가 반영 전 검증 4개의 실패가 남아 있다. 단일 컴파일로 진행한 첫 빌드는 병렬 컴파일로 전환하기 위해 중단했고 `build.log`에 보존했다. 최종 빌드는 `/MP3`으로 번역 단위를 병렬화한 `final-build.log`, 전체 검사는 `ctest.log`다. 중간 실패·중단 로그를 최종 실패나 완료 검사로 합산하지 않는다.

## 인수인계

명칭 교정으로 게임 복원의 미완료 항목을 완료 처리하지 않는다. 맨 오 워 표적 검색·비행 파생 삭제와 종료 효과, 다른 총 animation 등 다음 기능 작업은 `LEFT_JOBS.md`의 단위86 재개 지점을 따른다. 보호 원본·AGENTS.md·dotnetpj는 수정하지 않는다.
