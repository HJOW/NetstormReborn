[`RawPriestPlacementCollision`](../../cpppj/src/o/RawPriestPlacementCollision.h)은 한 후보의 타입/좌표 조회→클라이언트 SID 조건→타입별 무시 조건→로컬 표시→extra/mode 거부를 복원한다. `InspectArea`는 기존 **실제 `RawSquidFinder`의 flag 0/default filter Begin/Next**로 후보를 받으며 첫 거부 뒤 Next를 호출하지 않는다. finder는 buried(extra 0x8)만 제외하고 free/dead/void/contained를 추가로 제외하지 않는다.

## 무시 함수의 분기와 판본 차이

`PlacementIgnoreValue`는 사제에만 한정되지 않는 원본 타입 함수다. 아래 순서를 보존하며 반환을 bool로 축소하지 않는다. `own`은 배치 타입 flags2, `other`는 후보 타입 flags2다.

| 순서 | 조건 | 반환 |
|---|---|---|
| 1 | mode=0이고 own&0x20000 | 1 |
| 2 | other&0x02000000 | 1 |
| 3 | other&0x120000 | 1 |
| 4 | own&4이고 other&판본 마스크 | 1; 패치 마스크 0x200000, CD 마스크 0x208000 |
| 5 | other&2이고 배치 flags1&0x800이 없음 | 1 |
| 6 | other&0x30006이고 own&0x208100 | 1 |
| 7 | 전역 무시 마스크&own | **other&판본 마스크 자체**; 패치 0x218000, CD 0x210000 |
| 8 | mode=0이고 own&0x30000 | 1 |
| 9 | 나머지 | 0 |

7번의 0 반환은 뒤의 8번을 실행하지 않고 즉시 돌아간다. 따라서 walker 사제라도 전역 마스크가 겹치고 후보 비트가 0이면 충돌 검사에 들어간다. 전역값/모드를 배치 진입 시 bool로 캐시하지 않는다.

## 한 후보의 표시와 거부

현재 후보의 raw 타입과 float x/y를 읽는다. client mode가 0이 아니고 SID가 **5 이상·15000 미만(패치)/6000 미만(CD)**이면 충돌 검사에서 무시한다. 그 밖에는 위 함수를 실제 순서로 평가한다. 이 무시 조건은 후보가 뒤의 지형/지역 처리를 받지 않는다는 뜻이 아니다.

무시되지 않은 로컬 후보는 후보 footY/footX의 y/x 증가 순서로 각 칸을 검사한다. 아래 값은 float로 중간 저장하지 않고 넓게 유지하여 CRT처럼 0 방향으로 절삭한다.

```text
dx = trunc(query.x - (candidate.x - cx))
dy = trunc(query.y - (candidate.y - cy))
0 <= dx < placing.footX, 0 <= dy < placing.footY
blocked[dx * 12 + dy + 13] = 1
```

기존 배열을 초기화하지 않는다. 비로컬이면 배열 전체를 유지한다. 무시되지 않은 후보는 **extra&1이 없거나 mode DWORD가 0이 아니면 거부**한다. extra&1이고 mode=0이면 표시 후 허용한다. 표시 그 자체는 거부 조건이 아니다. C++의 잘못된 타입/비유한 좌표/발자국/배열 범위 예외는 원본의 미정의 입력과 별도 계약이다.

## 연결과 남은 경계

`MakePriestPlacementCollisionHooks`는 같은 풀의 미리보기 `inspectCollisions`만 연결한다. `inspectRegions`는 현재 **CanonDecoder 모양 순회·모양별 finder 정수 사각형 계산·지형/지역/관계 처리** 경계이며 동기적으로 전달된 `scan(area)`를 호출한다. scan이 거부한 뒤 경계가 true를 반환해도 실제 결과는 false다. `inspectCandidateTerrain`은 무시한 후보를 포함해 충돌에서 허용한 후보마다 호출하고 그 뒤 Next로 진행한다. 이 경계에서 현재 raw next를 바꾸어도 finder가 미리 저장한 다음 SID를 사용하며, 다음 후보는 경계가 변경한 현재 전역/타입을 사용한다. 두 훅은 필수이고, 동기 호출의 참조 수명과 같은 미리보기 상태 공유는 호출자가 보장한다. 실제 모양 순회나 후보별 지형/관계 효과 몸체는 후속 복원 대상이다.

두 판본 생성 통합은 접두→로컬 미리보기→실제 finder/후보 거부→다음 나선 위치→실제 서버 SID/사제 생성자/postCreate→WORD 0x8101→기록 소유자/Pop/Carrier 검사 요청을 확인한다. 첫 후보 **21,22**에서 서버 객체와 충돌하고 다음 **21,21**에서 생성된다. 새 SID는 **15001/6001**이다. 모양/지형과 일반 Pop/가상 Carrier 검사 몸체는 공급한 경계다.

별도 실제 finder 검사는 첫 후보의 raw next=0xffff여도 충돌 거부 뒤 이를 읽지 않는지, buried 제외, 패치/CD의 전역 0x8000 반환 차이를 확인한다. 두 후보 체인에서는 첫 후보의 충돌 무시→지형 경계→현재 raw next 초기화/전역 변경→미리 저장한 두 번째 후보→현재 전역에 의한 실제 충돌 거부를 확인한다. 이러한 연결 검사는 C++ 통합 검사이며 아래 원본 후보 구간 실행과 구분한다.

## 독립 원본 대조

[`decomp_priestcollision_oracle.py`](../../tools/decomp_priestcollision_oracle.py)은 기존 fixture/도구를 변경하지 않고 세 PE 각각 **3,840개**, 총 **11,520개**를 실행한다. 판본별 무시 함수 입력 **2,160개**, 한 후보 입력 **1,680개**다. x87 FPCW 0x027f/0x037f 관찰이 모두 일치한다.

무시 함수는 실제 thiscall 호출/정상 반환·ESP·보존 레지스터·x87·전체 DWORD 반환을 검사한다. 후보는 **MayPlace 중간 구간에 현재 SID/필요 지역 변수/배치 타입을 공급하고 지형 진입 또는 실제 거부 분기에서 관찰을 종료한다.** 후보 입력을 전체 MayPlace ABI/모양/finder/미리보기/지형 실행 대조로 해석하지 않는다. helper/현재 타입/CRT/표시/거부 분기는 대체 없이 실제 명령으로 실행한다.

각 PE·두 정밀도 합산 실제 helper **7,008회**, 후보 구간 진입/종료 **3,360회**, 현재 타입 조회 **3,360회**다. 패치 타입 getter **3,360회**, CRT **3,400회**, CD/10.37 CRT 각각 **4,352회**다. 현재 raw 전체/144바이트 표시/반환, 허용 코드/쓰기와 assert/OS **0회**를 검사한다. 저장 fixture/SHA 근거의 감사는 새 도구 `--verify`로 수행한다.

최종 Release 경고/오류 **0**, CTest 내부 **337개·실패 0**(103.23초), 감사 **46종 모두 통과**, 누적 독립 x86 **232,729개**다. 로그와 인계는 [LEFT_JOBS.md](../../LEFT_JOBS.md)의 이 작업 완료 기록을 따른다. 다음은 실제 CanonDecoder 모양 순회와 후보별 지형/관계 효과, 이어 일반 사제 Pop/보호막·회복 예약/Carrier 상태 검사다.
