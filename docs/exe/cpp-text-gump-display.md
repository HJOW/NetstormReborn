## 한 줄 TextGump

- 기본 Gump `(0,0,0,1)` 등록 생성 뒤 파생 가상 표/head 초기화, **signed 정렬 BYTE(초기값 45)**, 정수 폭/높이, `{0,font,color,0,0,0,1,1}` 문맥, 클립 비트를 설정한다.
- `AppendText`는 **-1만** 범위 안 NUL 탐색이며 길이 0은 조각을 만들지 않는다. 명시 길이는 기존 `StyleText::NewText`로 복사하고 태그 0으로 소유 체인에 붙인다. 그 밖의 음수나 범위 밖 복사는 호스트 예외로 거부한다.
- `Fit`은 같은 조각/폰트/그림의 전체 측정 뒤 정수 여백을 DWORD로 더한다. 기본 크기는 float32로 저장하지만 배율 크기는 **저장 전 정수×현재 scale**로 계산한다.
- `Draw`는 빈 head면 반환한다. 그 밖에는 현재 Bounds → 내부 클립 → 현재 Position → **현재 head** 출력 순서다. 공통 Gump Draw의 바깥 클립과 별도로 원본 파생 Draw의 내부 클립을 적용한다.
- 파생 소멸자는 원본 가상 표로 복귀하고 **Clear를 두 번** 수행한 뒤 기존 기본/scalar 소멸자로 위임한다. 자식 우선 삭제·등록 해제·객체 저장소 반납은 기존 `GumpLifetime`이 맡는다.

## 다중 줄 배치와 크기

노드 dirty bit 1 또는 연결 버퍼 dirty가 있을 때 두 변경 상태를 먼저 비우고 Layout한다. 패치는 버퍼→노드, CD는 노드→버퍼 순서다. bit 2가 있으면 기본 폭에서 현재 slider의 **기본 폭**을 뺀다. CD만 차이를 float32에 저장한 뒤 CRT 절삭한다. 폭 0 이하의 이전 표시 목록 유지/dirty 소실도 원본 버퍼와 같다.

`FitHeight`는 강제 배치 후 전체 높이+1을 저장하므로 빈 버퍼의 높이는 1이다. `FitContent`는 임시 폭 **10000**으로 배치한 뒤 최대 폭+가로 여백+선택적 slider 폭+1과 전체 높이+세로 여백을 저장한다. 배율 폭에는 float32 저장 전 합계를 사용한다. Append는 기존 LF 완료 줄 버퍼를 사용하며 이후 현재 textFlags의 dirty를 세우고 `Redraw(false)`를 통지한다. 현재 문맥 입력은 통지 전에 문맥을 복사한다.

## 스크롤과 출력

`SetScroll`은 현재 내용 높이와 `max(baseHeight,0)`의 CRT 절삭 값으로 요청을 제한하고 scroll을 저장한다. 이어 slider의 **range(0,content) → page(viewport) → position(현재 scroll)**을 호출한다. 각 호출 직전에 현재 slider 토큰을 읽으며 마지막에도 현재 slider 위치를 다시 조회해 scroll에 쓴다. 이 세 실제 Slider 몸체·자식 Attach/손잡이 입력과 `BindScrollingTextSlider` 공급 연결은 [2026-10-13 후속](cpp-scroll-gump-state.md)에서 구현했다. 전체 Slider 생성/Draw는 후속이다.

절대/상대 요청과 맨 아래 요청은 재그리기를 통지하며 `Draw`의 `ProcessRequest`에서 적용한다. -1은 무동작, -2는 맨 아래다. 처리 콜백이 다른 요청을 써도 정상 반환 뒤 요청을 -1로 덮는다. **맨 아래 이동 함수는 extra 인자를 읽지 않는다.** 실제 명령은 전체 높이-기본 높이만 절삭한다. extra 필드의 저장과 전달은 유지한다. 맨 아래 판정은 **전체 높이-기본 높이-10 <= scroll**이며 두 판본 모두 NaN이면 false다.

Draw는 Layout→스크롤 요청→Bounds→내부 클립→Position 순서다. 시작 줄은 y+높이가 scroll보다 **작은** 동안만 넘기므로 끝점 동률은 유지한다. 가시 줄마다 첫 순회로 최대 ascent를 구하고, 두 번째 순회에서 ascent 재조회→조각 크기→`(절대 x+누적 폭, 절대 y+줄 offset+최대 ascent-현재 ascent)` 출력을 한다. 출력 뒤 측정 폭으로 전진하고 현재 next를 조회한다. 첫 줄 이후의 y는 저장 y를 다시 읽지 않고 **이전 줄 높이**를 누적한다. 빈 줄도 높이를 누적한다.

viewport 비교는 정수를 float32로 좁히지 않는 실제 x87 FILD 결과다. CD는 C0만 검사해 NaN 높이에서도 행을 순회하고, 패치는 C0/C2 parity로 NaN을 제외한다. 잘못된 센티널 초과/순환/미등록 토큰은 호스트 예외로 거부한다. 출력 콜백 도중 현재 줄/조각 반납이나 버퍼 교체는 지원하는 수명 계약이 아니다.

## 조각 선택과 공통 연결

`HitTest`는 현재 half-open 화면 경계 안에서 시작 줄을 찾고, 줄 폭으로 조기 거부한 뒤 조각 폭을 누적한다. 세로 선택 조건은 ascent가 아닌 **줄 높이-조각 높이+줄 offset < 지역 y**다. 따라서 정확한 조각 위쪽 경계는 선택하지 않는다. 원본 함수처럼 Layout/대기 스크롤을 자동 적용하지 않는다.

`GumpClipScope`는 기존 공통 Draw의 보호 객체를 공개 재사용하도록 정리한 것이다. 논리 half-open/VFX inclusive 클립을 함께 설정하고 정상/예외 반환에서 복구한다. `BindTextGumpDraw`는 같은 kind 2 가상 Draw에 두 텍스트 처리기를 연결하고 기존 버튼/배경 처리를 보존한다. `BindTextGumpLifetime`은 한 줄 파생 소멸을 기존 수명 분배에 연결한다. 호출자는 기존 조각/버퍼와 같은 표·안정된 노드·실제 Slider/Redraw 경계를 공급해야 한다.
