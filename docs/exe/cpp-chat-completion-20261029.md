# 실제 채팅 이름 자동완성 — 단위574

Tab/Shift+Tab의 원본 이름 완성을 실제 Console에 연결했다. 원문189개 연속 입력을 별도 CPU/BSS에서 두 번 관측한 결과와 C++의 전체 물리 상태가 일치했다. 재관측 차이도0이다. 최종 집중52개·선행14개를 합쳐66회 실행/실패0, 등록3447개이며 Release 검사2회·게임1회 빌드의 경고와 오류는0이다. [원문 관측](../../cpppj/chat-completion-native-20261029.json)·[검증 집계](../../cpppj/chat-completion-runtime-20261029.json)를 따른다.

## 원본 동작과 실제 연결

`0042e540`은 새 단어를 받았을 때 원본 채널 문자열 표의 번역된 BATTLE/EVERYONE/ALLIES/OBSERVER를 먼저 넣고, 실제 Chat100행 중 Subscriber(+2c)가 비영인 이름을 이어 넣는다. 이름을 정렬하거나 중복을 지우지 않는다. 채널은 번역 전의 빈 문자열을 제외하지만, Chat 행의 빈 이름은 포함한다. 길이128 이상인 원본 행 이름은 제외한다.

Client 수명의 `00548810..0054c89f`를 같은0x4090BYTE 배치로 보관한다. 인덱스·접두 길이·128BYTE 접두·후보 개수·미사용 DWORD·128×128BYTE 후보가 같은 상태에 있다. `strncpy`는 지정 길이만 쓰므로 짧게 다시 입력한 접두 뒤의 이전 바이트를 지우지 않는다. 후보가 줄어도 이전 후보의 꼬리는 남긴다. 번역 결과는 원본 `strcpy`처럼 슬롯128로 잘라내지 않아, 다음 슬롯에 걸치는 복사와 그 뒤의 덮어쓰기도 같은 물리에서 처리한다. 전체 물리를 벗어나는 입력은 명시 오류 경계이며 손상 값을 정상 후보로 보정하지 않는다.

NULL 단어는 저장된 후보의 다음/이전 순환이다. 이때 현재 기록과 번역을 다시 읽지 않는다. 새 단어에서만 후보를 재수집한다. 첫 검색은 Shift 여부와 관계없이 인덱스0에서 시작하고, 이후 정방향/역방향으로 이동한다. signed 범위를 한 번 감을 수 있고 두 번째 이탈에서NULL을 반환한다. 접두 비교는 원본 C locale의 ASCII 대소문자 무시 비교다. 길이127 이상은 원문354 진단 뒤 복귀하면 복사를 계속한다.

`BindClientChatRecipients`가 현재 Client의 이 상태·Chat 기록·번역을 Console callback `0042e540`에 연결한다. 이름 입력 창이 TextEntry를 먼저 생성한 경우에도 완성 callback을 같은 처리기에 설치한다. 기존 편집 버퍼·clipboard·시계·제출 장치를 다시 만들지 않는다. Chat 생성/해제와 미션 교체가 장기 후보 상태를 초기화하지 않는다. 실제 단어 선택·공백/콜론 경계·선택 대체는 기존 TextEntry/Console 본체를 그대로 사용한다.

## 독립 관측과 검사 범위

[관측 도구](../../tools/decomp_chat_completion.py)는 보호10.78 SHA `a305414c…`를 검사하고 실제 `0042e540`, `004e51f0 strncpy`, `004ef5a0 ascii_strnicmp`를 실행한다. 번역은 명시 입력이고, `__strnicmp`의 TLS/locale 준비 대신 실제 C locale ASCII 몸체로 진입한다. 진단은 줄 번호를 기록하고 계속하는 장치다. 게임·OS·네트워크를 실행하는 관측은 아니다.

189행은 빈/희소/100개/40BYTE/128BYTE 경계 기록, 별칭·중복·빈 번역·127/128BYTE 번역, 새 단어·NULL 순환·중간 기록 변경·접두 잔류·비ASCII 바이트를 포함한다. 별도 CPU/BSS의378회 관측이 일치하며 재실행은 최초 fixture와 보고서를 덮어쓰지 않고 같은 바이트인지 검사한다. C++ 검사는 결과 문자열/NULL·전체 물리 상태·번역/진단 trace를 대조한다. GUI 표시나 임의 locale 전체의 동일성을 이 관측으로 주장하지 않는다.

실제 Client 결합 검사는 늦은 바인딩, Tab→BATTLE→EVERYONE, Shift+Tab 역순환과 감김, 콜론·공백 경계, Chat 해제/재생성 뒤 장기 상태 보존을 확인한다. 최종52개는 이 신규 검사3개와 기존 입력줄/채팅/기하/HUD/표시 키/TextEntry/대상 검사/Client Chat/State/MainMenu 관련 검사다. 선행14회 성공도 원시 자료에 보관했다. 전체 C++ 검사는 실행하지 않았다.
