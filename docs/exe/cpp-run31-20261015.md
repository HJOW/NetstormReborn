## 원본 근거

`form-packet-functions.json`으로 현재 정밀 프로젝트에서 PATCH6/CD8 함수를 읽기 전용으로 내보냈다. 누락된 짧은 Form 부모 getter/가상 writer는 내보내기 세션 안에서 함수로 정의했으며 프로젝트/보호 PE에는 저장하지 않았다. Native 허용 범위는 이14함수만 사용한다.

| 역할 | PATCH10.78 | CD10.72 |
| --- | --- | --- |
| DependForm 가상+54 | `004ae560` | `004af750` |
| ContentForm 가상+54 | `004aeb40` | `004aff30` |
| 공통 삭제 가상+58 | `004ac340` | `004abc10` |
| 송신 wrapper | `004ac260` | `004abb40` |
| Form 부모 getter | `004ad010` | `004b04a0` |
| 헤더 작성 | `004df590` | `00418b60` → `00419090` |
| 최근 삭제 표식 | writer에 포함 | `004aaa00` |

세 헤더의 초기 메시지/프로토콜/길이는 두 판본이 각각 `(65h,1,13)`, `(2dh,1,18)`, `(2eh,1,8)`로 같다. PATCH 헤더 전역은 BYTE/BYTE/WORD이고 CD 전역은 각각 DWORD다. 이번 헤더 입력 범위는 프로토콜/메시지 BYTE와 선언 길이16비트다. 프로토콜의 bit7을 지우고 길이가4보다 작으면4로 쓴다. erase 인자0은 출력 버퍼를 초기화하지 않는다.

디컴파일 C의 wrapper 인자 일부는 잘못 회복되어 있다. 실제 PATCH`004ac2af~004ac2d1`, `004ac2f9` 및 CD 대응 기계어에서 **첫 인자는 수신자**, 둘째는 command, 셋째는 data 인자, 넷째는 flags인 것을 확인했다. command=-2이면 가상+58에 `(buffer,data,flags)`를 넘기며 data는 공통 삭제 writer에서 읽지 않는다. 다른 command는+54에 `(buffer,data)`를 넘긴다. data writer는 현재 미사용 두 번째 인자를 유지한다. 첫 인자=-1은 같은 broadcast를 호출한다. 특정 수신자 조회/송신은 이번 연결 범위 밖이다.

## 구현과 실제 연결

`RawFormPacket`은 같은 Pool과 현재 헤더/최근 표식을 참조한다. 실제 VT로 Depend/Content를 고르고 상태 BYTE에 free/dead/void 필터를 추가하지 않는다. 부모/상대 Form의 client SID assert 경계는 호스트 예외로 드러낸다. 미복원 가상 getter/writer를 다른 클래스의 몸체로 처리하지 않는다.

| 패킷 | 헤더 뒤 실제 필드 |
| --- | --- |
| Depend13 | SID WORD, 부모 WORD, 현재+0b BYTE, +12 WORD, +14 WORD |
| Content18 | SID WORD, +0c/+12/+14 WORD, PATCH+18/CD+17 WORD, 부모+10 WORD, PATCH+17/CD+16 BYTE, 현재+0b BYTE |
| 삭제8 | SID WORD, `((flags>>16)&fff0h) OR 최근 표식 WORD` |

최근 표식의 SID DWORD가 현재 SID와 같으면 SID만0으로 지운다. 표식 값의 낮은 WORD 전체를 사용하고 상위 플래그와 OR하므로 낮은4비트로 제한하지 않는다. token DWORD는 보존한다. 원본 생성자 표의 PATCH82개 자산 VT+58도 전부 공통`004ac340`인 것을 PE에서 읽었다.

실제 세션은2048바이트 버퍼와 같은 writer/최근 표식을 보관한다. 미제공 DependForm Pop 송신과 ContentFormHost 송신을 writer→같은 `RawBattleBroadcast`에 연결했다. 삭제의 Transmit 사건도 같은 writer/버퍼를 사용한다. LAN 연결 표가 NULL이어도 직렬화는 수행하고 실제 분배기가 자연 반환한다. `formPacket` 관찰/장치 경계는 직렬화 **후**의 바이트만 받는다.

GameWorld의 삭제 선택 조회와 ClearSelection은 실제 `selected_`/Select에 연결한다. 세션 프로세스가 이 저장소를 참조하는 동안 정리되도록 GameWorld 소멸자 본문에서 캠페인을 해제한다. 다른 파생 삭제는 명시 소비자를 계속 요구한다. Gun/Path의 기존 별도 버퍼를 전체 원본 공용 송신 버퍼와 합치는 작업과 수신 명령이 최근 표식을 설정하는 연결은 후속이다.

## 독립 원본과 C++ 대조

새 Native 루트 **1,152개**, 각 판본576개가 정상 반환했고 assert0이다. 직접 writer3종과 실제 broadcast wrapper3종을 판본마다96입력씩 실행했다. 현재 헤더, 상대0/각 쌍, 임의 raw 상태 BYTE, 임의 필드/미사용 인자, 상위 flags, 삭제 표식0/일치/다름/상위DWORD, 반환 뒤 stale 바이트를 포함한다. 실제 원본 writer·헤더·부모 getter·표식 helper를 실행했고 broadcast 장치 요청만 관찰했다. 실제 네트워크 I/O는 없다.
