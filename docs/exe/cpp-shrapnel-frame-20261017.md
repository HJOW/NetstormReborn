2026-10-17, 작업 PC **HJOW-Athlon**. 마지막 전체 정밀 디컴파일은 **HJOW-Athlon / 2026-10-16**이며 현재 PC와 일치한다. 기존 `originals/Netstorm.exe` 10.78의 바이트와 정밀 함수표를 읽었다. 새 디컴파일이나 원본 게임/GUI 실행은 없다. CD 10.72는 이번 비교 대상이 아니다.

데모1의 자연 프레임 검사가 232프레임/5.8초에 맨 오 워(TYPE144 SID15082)의 전투 삭제에서 멈춘다. 해당 VT `0050a388`의 공통 삭제 `004af780`은 전용 Pre `0045e7e0`와 Damageable Post `0044b9e0`를 호출한다. 전투 사망의 `0x100000` 플래그는 실제 폭발을 요구한다. 이 문서는 그 전용 Pre와 폭발에 필요한 픽셀 계산 본체를 완료한 단위다. 실제 파괴/캡처/효과 프로세스의 캠페인 연결은 다음 단위다.

`RawFlyerPreDestroy`는 현재 raw+8의 **WORD**가 비영이면 해당 SID의 가상 삭제(flags0)를 먼저 호출하고, 이후 같은 this와 flags로 Damageable Pre에 진입한다. DWORD로 넓혀 읽으면 TYPE와 상태 바이트까지 대상에 섞인다. `decomp_flyer_predestroy.py`는 실제 `0045e7e0`을 고유96입력·두 x87 정밀도192회 정상 반환으로 관찰했다. 대상 삭제와 Damageable 하위는 명시 callback 경계이며, callback이 부모/대상을 바꾸는 경우를 포함한 네 슬롯200BYTE와 요청 순서가 C++와 일치한다.

`RawShrapnelFrame`은 다음 원본을 복원한다.

- `00460000/0045fc70`: 부모 위치와 캡처 기준점의 정수화, 불투명 픽셀 수(최소1)의 용량 확보, 작업 복사본, 행/열 순회, 타이머 초기화.
- `00460200/004602f0/004603e0/004600a0`: 세 가상 속도/수명과 픽셀 묶음. 묶음의 가로/세로 반복 **조건을 검사할 때마다** CRT rand를 새로 뽑는다. 첫 행/열은 묶음의 유효 좌표에서 제외한다. 원래 캡처 이미지는 변경하지 않고 작업 복사본만255로 표시한다.
- `0045fd60`: 제한 없는10배 시각 간격, 저장된 float 가속도, 넓은 새 y속도/좌표, 용량 전체의 진입 양수 수명 갱신, 이전/새 dirty 영역. 이번 프레임에 수명이 끝나도 다음 Frame에서 소진을 판정한다.
- `0045fef0/004a2230`: 입자 좌표를 먼저 정수화하고 카메라를 뺀다. X 차이는 float에 저장한 뒤 절삭하고 Y 차이는 넓은 값으로 절삭한다. 캡처 색 한 바이트를 실제 반열린 clip/pitch에 직접 쓴다.

새 `CrtRandom`은 실제 `_rand` `004e64ab`의 TLS+`0x14` 상태를 `state*214013+2531011`의 low32로 갱신하고 상위15비트를 반환한다. 게임 `GameRandom`과 별개이며0도 재시드하지 않는다. 원본 새 TLS 초기값1과 명시 상태를 지원하고, 향후 실제 소비자는 미션마다 초기화하지 않는 같은 스레드 스트림을 사용한다. 애플리케이션의 다른 srand/rand 호출 전체 수명은 아직 연결하지 않았다.

`decomp_shrapnel_frame.py`는 실제 세 생성기·Append·CRT rand·GameRandom·시간·Frame·Draw·픽셀 몸체를 실행한다. new/free, TLS 주소, dirty 큐 소비와 Form 삭제만 명시 외부 경계다. 캡처 그림과 부모는 입력이다. 기본53비트와 비교64비트의 관찰은 각각1016행이며 정상 반환은 합계3200회, 정밀도 차이는0이다. 중복 제거한 **980고유 입력은 준비198개와 Frame/Draw782개**다. C++는 의미76BYTE·용량 전체24BYTE 입자·두 난수·요청 순서·64×48 화면과68바이트 pitch의 padding 전체가 일치했다. 색 포인터만 같은 캡처 bitmap의 offset+1로 정규화했다. 원본 기대값을 C++ 계산으로 만들지 않았다.

Release 수정 빌드는 경고0·오류0·종료0이며 집중3개가 통과했다. 전체 CTest 내부 **1448개 중1447통과·기존1실패,227.52초,종료8**이다. 데모1은 여전히232프레임의 실제 전투 삭제 경계에서 멈추며 추가 실패는 없다. 새96/980 및 기존2352입력의 SHA 감사를 통과했다. 모든 실행기/빌드/검사 핸들은 종료했다. 로그 접두사는 `extracted/goal-shrapnel-20261017-`다. 전체 목표는 active이며, 모듈 대조만으로 사용자 플레이 완료나 전체 그래픽/음향 동일성을 선언하지 않는다.
