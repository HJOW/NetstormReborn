## 원본 자료와 계획

보호 TYPE 원문에서 썬 캐논 비용400·HP600·사거리20·초당 피해16·발사 간격5초, 썬더 캐논 사거리42·HP1000, 스톤 타워 비용400·HP2000, 썬 디스크 발사기 비용300·사거리9·초당 피해15/공중20, 윈드 제네레이터 비용400·HP700을 읽었다. 원본 D/D1 안내는 다리를 전진시키고 타워 뒤 캐논과 공중 방어를 배치하도록 설명한다.

계획은 기존 자연 A→B→워크샾/네 생산 지식→C/C1→적 훨리베이스 선택→D까지 실제 입력을 이어 사용한다. 이후 생산 조각을 취득하고 기존 `placement-reach`가 찾은 합법 다리 위치를 클릭한다. 타워는 실제 가까운 합법 자리, 캐논은 같은 실제 `MayTarget`/사선을 통과한 합법 자리에서 배치한다. 탐색은 마우스 위치만 정하며 원본 배치·전송·건설이 실제 객체를 만든다.

## 훨리기그 방송 연결 복원 중

원본45c946..45c987의 최초 표적 명령2,45cc29..45cc62의 귀환 명령3은40a890 헤더 생성 뒤 부모SID DWORD(+4)/명령 DWORD(+12)을 쓰고4e2e30 원격 방송을 호출한다. 현재 로컬 표적/복귀 기한은 그 앞에서 이미 쓴 상태다.20BYTE의+8/+16은 이 caller들이 쓰지 않는 미정 바이트다.

새 독립 관측기는 실제 두 caller 구간과40a890/4df230/41bfb0을 실행해30입력/두 정밀도60구간 완료를 동결했다. 방송은 인수 관측 경계이고 전체 함수 정상 반환이나 게임 실행의 증거가 아니다. 초기에는 명령2 caller의 즉시값을 바꾸는 모형을 만들었으나 명령3 입력에서도2가 관측됐다. 해당 초기 도구/관측과 비교 실패를 보존하고 실제 두 caller를 코드 수정 없이 실행하는 방식으로 바꿨다. C++ 대조는 최종 원문 동결 뒤 수행한다.

제품 작성기는 정의된 필드만 쓰고 미정 두 DWORD를 보존한다. Session의 새 패킷 저장소는 미정 필드를0으로 초기화하며 원본의 정의된 값으로 주장하지 않는다. 실제 Session의 두 명령 훅은 기존4e2e30 `RawBattleBroadcast::Send`로 연결한다. 기존 정상 NULL peer의 단독 캠페인 분기를 사용하며 표적/HP/비행 상태를 별도로 변경하지 않는다. 원본 비교·전체 회귀·수정 후 실제 전투를 이어서 확인한다.
