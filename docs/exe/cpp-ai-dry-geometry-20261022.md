## 복원 범위

`RawAiDryGeometry`는 같은 실제 PATCH 풀과 현재 경계/디버그 종류/표식 TYPE를 참조하며 `00415bb0`, `0041cfc0`, `00414d30`, `00410540`을 처리한다. 실제 Session은 기존 `aiDropScanBounds`, `aiDrySpotLog`와 현재 TYPE104를 공유하고 현재 해시0 지도/실제 월드 생성·kind WORD 쓰기·다리 통지·가상 Pop/삭제에 연결한다. 명시 API `ComputeAiDryCandidate(source,target)`는 이 하위 계산이며 전체 가짜좌표 전략은 후속이다.

1. 디버그 종류29이면 기존 TYPE/kind93 표식을 제거하고 시작점/끝점을 순서대로 표시한다. 이 최초 분기 안의 두 표시 사이에는 디버그 종류를 재검사하지 않는다.
2. 두 float 좌표 차이의 제곱합/제곱근은 중간 float 저장 없이 계산한다. 호출자에서는 거리를 float에 저장하고 역수는 두 정규화 방향을 float로 저장할 때까지 넓혀 계산한다. 중점은 두 좌표 합에0.5를 곱한 후 float로 저장한다.
3. 시작점에서 정규화 방향으로 선분을 한 칸씩 진행하는 원본 반복을 보존한다. 디버그가 켜져 있으면 이동 뒤 각 점을 실제 표시한다. 선분의 마지막 이동은 거리의 올림 횟수이며 부동소수점 누적/종료 비교 위치도 유지한다.
4. 중점에서 왼쪽 `(-dy,+dx)`, 오른쪽 `(+dy,-dx)`을 매 반복에서 순서대로 진행한다. **이동 전** 현재 네 경계와 비교하며 원본 `test ah,41h / jp`에 따라 끝값을 포함하고 NaN은 제외한다. 끝값에서 한 번 이동한 뒤 경계 밖의 칸을 읽을 수도 있다.
5. 이동 뒤 각 축에 원본 float `00500edc=0.9998999834060669`를 넓혀 더해 CRT ftol한다. 사제용0.99999/일반 ceil과 구분한다. signed64 절삭의 낮은 DWORD를 사용하며 잘못된 FISTP의 낮은 값은0이다. 물리256범위 밖은 빈칸으로 세고 지도는 읽지 않는다.
6. 해당 방향에서 빈칸이면 연속 횟수 증가, 점유 칸이면0이다. 두 방향을 모두 이동/평가/표시한 뒤 왼쪽이4이면 반환한다. 오른쪽만4이면 다음 반복의 첫 관문에서 오른쪽을 반환한다. 같은 반복에서 양쪽 모두4이면 왼쪽 우선이다.

원본에는 임의 반복 예산/대체점/경계 clamp가 없다. 두 방향이 경계 밖에서 진행을 멈추거나 퇴화 선분이 생기는 입력에서는 종료되지 않을 수 있다. 이번 복원은 이 동작을 임의 성공으로 바꾸지 않는다. 전체 x87 확장 정밀도/예외 및 CD10.72는 검증하지 않았다.

## 표식 수명과 지도 근거

`00414d30`은 iterator SID1에서 Next를 먼저 호출한다. free bit만 건너뛰고 dead는 방문한다. 각 항목에서 **삭제 전에 다음 SID를 먼저 확보**한다. 삭제 효과가 다음 항목을 free로 바꿔도 저장된 다음 SID는 그 다음 본문에서 방문한다. 삭제 후 풀 기준 주소/현재 TYPE를 다시 읽는다.

타입 비교는 객체의 TYPE BYTE를 zero extend한 DWORD와 **현재 TYPE 전역 전체 DWORD**의 비교다(`00414db6/00414dbd`). TYPE 전역의 상위 비트를 잘라 비교하면 원본보다 삭제 대상을 늘리게 된다. kind는 WORD93이다. `00410540`은 현재 TYPE/flags2로 생성→kind93 쓰기→가상 Pop(flags0)을 수행한다. kind 쓰기의 다리 통지도 `004ac22d`에서 현재 다리 TYPE **전체 DWORD**와 비교한다. 도달한 실제 하위가 없으면 앞선 효과를 보존하고 명시 오류로 남긴다.

현재 지도 `00542514`는 `004b2b50`이 생성하는 해시 객체 `00542508`의 첫 배열 포인터(+c)다. `004b28f0` 초기화에서 이 배열을 `005c84bc`에도 기록한다. Session은 매 조회마다 같은 `core.hash.Cell(0,x,y)`를 읽는다. 현재 해시 단계가 달라져도 이 주소는 첫 배열을 뜻한다. 원본처럼 두 포인터를 별도 교체하는 추가 환경의 동등성까지 입증하지는 않았다.
