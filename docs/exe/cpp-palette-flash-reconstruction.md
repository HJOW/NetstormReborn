# 번개 팔레트 프로세스 복원과 장면 음악 연결

2026-10-10, **HJOW-Athlon**. AGENTS.md·두 인계 문서를 먼저 읽었으며 현재/마지막 디컴파일 PC가 일치한다. `paletteflash` 목록 **6/6/6개**를 같은 PC에서 읽기 전용으로 내보냈다. **마지막 디컴파일 수행 PC: HJOW-Athlon, 2026-10-10**. 원본 게임·분석 프로그램은 실행하지 않았다.

천둥 곡의 `thunderFlash` 경계를 실제 번개 프로세스에 연결했다. 복원 목표 **10.78**의 생성·RGB 변경·64단계 진행·정상 종료·중단 복구를 사용한다. 현재 클라이언트는 창 모드 장치만 지원하므로 **원본처럼 번개가 화면 팔레트를 바꾸지는 않는다**. 전체화면 장치에서의 실제 표시/DirectDraw 확인은 후속이다.

## 원본과 구현

| 경로 | 10.78 | CD/10.37 | 구현/근거 |
| --- | --- | --- | --- |
| 공개 생성 | `00470fa0` | `004b10d0` | 밝기 0→64, 색 번호 228~245, 모드별 수명 선택 |
| 생성자 | `00470d40` | 공개 생성 안에 인라인 | 0x840 객체·부모 조회·프로세스 종류/인자·초기화 요청 |
| 초기화 | `00470e30` | `004b1310` | 현재 부분 팔레트 두 번 읽기·RGB 밝기/목표 색·64단계 |
| 프레임 | `00471650` | `004b1450` | 실시간으로 단계 진행·부분 적용·전체 복구·삭제 요청 |
| 중단 소멸 | `00471820` | `004b15d0`/`004b165b` | 초기화된 전체화면 효과의 저장 팔레트 복구 |
| 현재 색 읽기 | `004a2800` | `004246c0` | 실제 RGBQUAD 복사 몸체 실행 |

[`PaletteFlash`](../../cpppj/src/client/PaletteFlash.h)는 계산·종료 판정을 맡는다. [`ClientMain.cpp`](../../cpppj/src/client/ClientMain.cpp)의 `ThunderProcess`는 효과를 Kernel에 등록하고 실시간 프레임을 공급한다. 천둥 효과음보다 먼저 생성하며, `ascendancyPalette`와 소리/음악 옵션이 꺼져 있어도 진행한다. `--no-audio` 실행에서는 장면 음악 묶음 자체를 만들지 않으므로 이 호출도 없다.

현재 월드의 존재를 원본 부모 조회 경계에 연결했다. 브리핑 중에도 월드는 살아 있으며 게임 시간이 멈춰도 벽시계로 진행한다. 월드 해제·해상도 장치 교체·클라이언트 종료 때 남은 효과를 제거한다. 파괴 콜백이 번호 목록을 바로 지워 Kernel의 재사용된 슬롯을 잘못 지우지 않게 했다. **원본 Squid/SpStore 부모 등록/종속 삭제는 현재 어댑터 경계이며 전체 복원으로 취급하지 않는다.**

## 유지한 계약과 판본 차이

- 기본 밝기 64를 각 RGB에 더하고 255 위를 포화시킨다. 예약 바이트는 보존한다. 음수/큰 signed 밝기는 원본 32비트 감김과 byte 저장을 유지한다.
- 초기화에서 팔레트를 표시하지 않는다. 첫 프레임이 변경 색을 적용한다. 모드별 수명은 생성 당시 선택하지만 적용/복구 여부는 매 프레임의 모드를 다시 읽는다.
- 전체화면 수명은 0.5초, 창 모드는 1/60초다. 간격은 수명/64이며 경과 시간이 **간격보다 클 때만** 한 단계 진행한다. 느린 프레임은 남은 단계를 반복해서 따라잡는다. 밝기를 바꿔도 단계 수는 64다.
- 각 단계는 RGB를 원래 값 쪽으로 1씩 옮긴다. 마지막 시각에 간격을 반복 더하고 남은 경과 시간에서 반복 빼는 double 저장 순서를 유지한다. 비교 불가 시간은 진행하지 않는다.
- 종료/중단 복구는 생성 당시 읽은 부분 색 배열이 아니라 **당시의 저장 팔레트 전체**(`SetPalette(0,256,nullptr,true)`)를 사용한다. 효과 도중 새 저장 팔레트가 로드돼도 최신 색으로 복구한다.
- 범위 밖 부분 배열/빈 필수 경계는 안전 API에서 거부한다. 중단 소멸 뒤 읽을 수 없던 원본 flag는 안전 API에서 0으로 정리하여 중복 취소를 막는다.

**CD/10.37 프레임에는 구형 버그가 있다.** `004b1537`·`004b1541`이 아직 초기화하지 않은 스택의 double을 경과 시간에 복사한 뒤 `004b1545`에서 새 값을 저장한다. 정상 양수 간격에서 진행 단계가 10.78과 달라진다. 독립 관찰은 이 스택 입력(`STACK-8`)을 매 호출 0으로 고정해 이전 입력의 스택이 섞이지 않게 했다. C++는 목표 판본 10.78의 정상 진행을 유지한다. CD 자산을 사용하는 검사도 10.78 진행을 사용하며 이 버그를 복제하지 않는다.

## 검증

[`decomp_paletteflash_oracle.py`](../../tools/decomp_paletteflash_oracle.py)는 세 실제 PE의 전체 생성/초기화/프레임/중단과 현재 색 복사를 제한 x86으로 실행한다. 새 독립 입력 **768개**(256×3), 두 x87 정밀도에서 직접 전체 진입/정상 반환 **3,072회**다. 보존 레지스터·스택·SEH·x87 균형·허용 실행/쓰기·입력 팔레트 불변·실제 몸체/경계 호출 수·입력 순서·SHA를 감사한다. 원본 게임/OS 호출은 0이다.

메모리 할당·부모 조회/등록·OS 팔레트 적용·프로세스 해제·기반 소멸자는 명시 경계로 대체한다. 등록 경계에서 **실제 원본 초기화 몸체를 실행한다**. 부모가 없는 생성 실패/할당 실패·원본 부모 등록/삭제 내부·실제 DirectDraw 적용은 이 실행 범위 밖이다. 표시 경계는 호출 당시의 부분 색을 기록하며 OS 팔레트 함수 내부의 끝 색 수정은 실행하지 않는다.

[`PaletteFlashTests.cpp`](../../cpppj/tests/PaletteFlashTests.cpp)는 **세 판본 초기화/간격/색 복사 768개**, **10.78 전체 경로 256개**(중단 8개 포함), **CD/10.37 중단 16개**를 대조한다. CD/10.37의 나머지 프레임은 판본 차이 기록이며 C++ 진행이 같다고 주장하지 않는다. 추가 검사에서 게임 정지·모드 변경과 실제 창 없는 GDI DC의 부분 적용/최신 저장 팔레트 복구를 확인한다.

새 [`cpp_thunder_smoke.py`](../../tools/cpp_thunder_smoke.py)는 무음 실제 클론 창 **38개 상태·8개 화면**으로 천둥 곡에서만 같은 프레임 등록·실시간 종료·창 팔레트 불변·메뉴 부모 없음·복귀/재진입·소리/음악 끄기와 worker 정상 상태를 확인했다. 보호 대상 원본 **1,392개** 불변이며 허용 설정 파일은 성공/실패 모두 원상 복구한다. 이 검사는 사람의 실제 청취를 포함하지 않는다.

빌드/전체 검사 최종 수치와 기존 날씨·소리·월드·메뉴·창 회귀 결과는 [LEFT_JOBS.md](../../LEFT_JOBS.md)의 최신 절에 기록한다. 새 독립 입력 포함 누적은 **455,362개**다. 로그는 Git 제외 `extracted/paletteflash-*.log`, 관찰 화면은 `extracted/cpp-audio-smoke/thunder-*`다.
