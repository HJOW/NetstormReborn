10.78 `00433fe0/00432a10/00434080`의 압축 객체 생성/16필드 복원과 `0040b2a0` 송신 길이 관찰기를 같은 실제 Session에 연결했다. 마지막 전체 정밀 디컴파일은 **2026-11-03 / HJOW-Athlon**이다. 이번에는 원문을 읽기만 했고 산출물/보호 바이너리를 수정하지 않았다. CD10.72의004891f0은 공통 필드 처리의 비교 근거이며 PATCH7ah 수신과 혼합하지 않는다.

지역 복사한 실제 압축 데이터와 마스크를0..15 순서로 소비한다. −10000 좌표·수량/추가/프레임/extra0·현재 bridge TYPE/현재 owner의 생성자 기본값을 보존한다. 4번 필드 뒤에는 비트4가 없어도 현재 선택 TYPE의 실제 최대HP와 zOrder를 채운다. BYTE 수량/HP/프레임은 낮은 바이트만 쓰고 나머지 기본값을 유지하며, 14/15는 무효과다. 상충 마스크 진단이 정상 복귀하면 원문대로 다음 처리도 계속한다.
