클라우드 플로터는단위332에서연결했고데빌메이커는 [단위335](cpp-wind-flyer-20261022.md)에서연결했다. [단위337](cpp-arc-spire-20261022.md)에서아크 스파이어도전용주기/연쇄공격/삭제를연결했다. 애시드 바리케이드의 전용 주기/공격, 아이스 타워의 파괴 후 재성장과 데빌메이커 잔여 분기를 이어 복원한다. 소리·그림·내용물·공급·피해·삭제의 추가 파생이 드러나면 같은 목록에 기록한다. 사용자 플레이/원본 GUI 검증과 창을 띄우지 않는 빌드·원문 대조·실제 Kernel 검사는 구분한다.

현재·마지막 전체 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-22**다. 원본/CD/AGENTS는 수정하지 않으며 새 게임 실행은 아직 없다. 단위335에서주소근거25행을다시생성·대조하여모두동일함을확인했다. 이전JSON에남아있던 `TypeLoadOrder.cpp`의옛SHA만현재입력으로갱신했으며그소스파일자체는바꾸지않았다.
