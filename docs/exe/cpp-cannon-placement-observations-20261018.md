# 캠페인 1-1 캐논 배치 관측과 테스트 보류 (2026-10-18)

기준 커밋은71379b0a이며 현재 PC와 마지막 정밀 디컴파일 PC는 HJOW-Athlon / 2026-10-16이다. AGENTS.md와 양 LEFT를 다시 읽었다. 새 디컴파일과 제품 코드 변경은 없다. 원본 전체화면 DirectDraw 문제는 범위에서 제외한다.

사용자 확인에 따라, 제네레이터 없이도 신전 주변에 썬 캐논을 건설할 자리는 있다. 다만 그 위치에서는 적을 타격할 수 없어, 적 공격을 관측하려면 하나 이상의 제네레이터로 공급 범위를 연장해야 한다. 기존의 신전 주변 캐논 완공 검증을 적 공격 검증으로 확대하지 않는다. 캠페인1-1 워크샾에서 연구하는 제네레이터는 TYPE76 rainBattery, 실제 이름 Rain Generator(레인 제네레이터)다. 팬게임의 커스텀 썬 제네레이터를 도입하지 않는다.

이번 자동 입력은 섬 경계에 걸쳐 건설할 수 없는 후보에도 배치를 시도하고 그 뒤의 전투를 기다렸다. 사용자가 직접 이를 지적하며 테스트를 일단 넘어가라고 요청했으므로 추가 배치 탐색과 창/전투 테스트를 중단했다. 전투 성공을 기다릴 상태가 아니었으며, 공격 실패나 전투 구현 결함으로 판정하지 않는다. 배치 제약을 우회하거나 공급 반경/사거리/HP/소유자를 수정하지 않았다.

관측에서 `raw_cursor[1]`이 최종 배치 허용 값이다. `raw_cursor[8..10]`의 개별 진단 값만으로 허용이라고 판단했던 초기 해석은 잘못이었다. 전방118,115는 최종0이었고 캐논 생성/400 SP 차감이 없었다. 허용되지 않은 클릭 뒤의 대기는 공격 관측 근거가 아니다. 향후 재개 시 캐논 전체 발자국이 섬 경계 안에 들어가는 실제 허용 위치와 현재 공급 조건을 먼저 확인해야 한다.

레인 제네레이터는 실제 GUI의 워크샾 건설→연구→생산 클릭→서버 배치로95,110에 건설됐다. `generator3/summary.json`에는 SP2200→1800, HP0→700, construction extra129→128이 남아 있다. 같은 실행의 캐논113,115는 최종0이고 건설되지 않았으므로 전투 통과 자료가 아니다. 헤드리스의 별도 후보99,109에서도 제네레이터 자연 완공은 확인했으나 캐논118,115는 거부됐다. 이때 마지막 진단의 실제 공급 반경 제곱은196이었다. 독립 모듈 초기값484를 실제 세션의 현재값으로 간주하지 않는다.

실험 중 추가한 실패 테스트와 기존 자연 건설 테스트의 변경은 모두 기준 커밋 내용으로 되돌렸다. 미완성 테스트를 제품 검사에 남기지 않는다. 상세 실험 소스와 실패 로그/GUI 관측은 무시 경로 `extracted/goal-cannon-gameplay-20261018-*`에 보존한다. 실행 파일 `NetstormCpp.exe`는 직전182의 제품 그대로이며 추가 원본/클론 게임 실행은 하지 않는다. 무시 경로의 `netstorm_tests.exe`는 실험 빌드이므로 다음 검사 실행 전 정상 빌드로 갱신해야 한다. 이번 정리는 문서와 인수인계만 커밋하며 새 테스트 통과를 주장하지 않는다.

목표 전체는 계속 진행 상태다. 캐논 전투 검증은 보류하고, 실제 Quick Help/회수 명령 등 미복원 사용자 조작 연결을 다음 구현 후보로 둔다. 운반 왕복·희생·승패·후속 미션·전략AI 및 목표11단계 자연 완주/원본 전체 동일성은 여전히 미완료다.
