## 원문과 구현

`RiftTypeRecord`에 최초0인 `defaultFrame`을 추가하고 실제 자산 Parse의 `specialFrames.defaultFrame`을 Table 로딩 때 연결했다. 내장/빈 TYPE의0을 보존한다. 이미 실제 `RawSurfaceStorage`가 Table의 Record를 복사하고 World/SquidDisplay가 같은 배열을 참조하므로 현재값을 표시 시점에 읽는다. 새 검사에서 default 태그1과 baseframe 태그2를 양판본 실제 Table로 로드해 구분을 확인했다.

부분표시는 표시 억제 전에 현재 TYPE의 기본 외형을 조회한다. 기존 bounds로 확대/카메라/핫스폿을 적용하고 **그 뒤** 위/아래50픽셀씩을 줄인다. 여백에는 확대율을 곱하지 않는다. 모서리별 viewport clamp 뒤 양수 면적만 flags0으로 등록한다. 일반88의 기존 현재 프레임/선택/그림자 부모는 유지했다. `Validate`도 현재 애니메이션 프레임 대신 같은 기본 외형의 물리 범위를 검사한다.
