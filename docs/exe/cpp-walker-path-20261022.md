현재 PC와 마지막 전체 정밀 디컴파일 PC는 모두 **HJOW-Athlon / 2026-10-22**다. 단위336은 사용자가 지정한 썬6·레인7·윈드6·썬더6종의 미비 유닛 복원을 우선한다. 시작 HEAD는 `edc257f9 / 20261022-62 CP`이고 작업 트리는 깨끗했다. AGENTS.md, LEFT_JOBS.md, LEFT_JOBS.dotnetpj.md와 [25종 점검표](cpp-unit-restoration-20261022.md)를 읽었다. 원본/CD/AGENTS는 수정하지 않았으며 실제 게임 창도 실행하지 않았다.

`tools/audit_unit_restoration.py --verify`로 원본 PE/TYPE/생성자에 근거한 25행을 다시 확인했다. 기존 Carrier/Steal 모듈이 있어도 세일 스케이터137과 크리스탈 크랩156은 실제 이동38을 만들지 못했다. 이번에는 해당 두 부모의 이동 시작·프레임·도착·삭제를 연결한다. 다른 23종의 모든 행동이 완성됐다는 의미는 아니다.

윈드의 `005951c4`는 모든 세일 스케이터가 공유하는 DWORD다. 프레임마다 증가 후 `&3`하며 0/90/180/270도는 각0/12/8/4를 더한다. 회전은 `(1-angle*float(1/360))*19`를 float에 저장한 뒤43fa50의 `+0.5`와 CRT signed64 절삭 결과 하위 DWORD에16을 더한다. 레인은 같은 counter를 쓰지 않는다. 현재 시각이 예약 이상일 때447790의 A/B 구간을 진행하고 다음 시각을 `now+0.07999999821186066`에 저장한다. 예약이 지난 비직각 각도는 좌표 갱신도 건너뛴다. 프레임이 같아도 좌표가 달라지면 Pop한다.

크랩의 `00545428` 포획 counter는 애니메이션 counter와 별개다. 이번 연결은 이미 복원한42ab80을 호출하여 공유 signed 나머지4·포획/공통 Halt 순서를 유지한다. 운반체가 포획 도중 현재 경로를 삭제할 수 있으므로 하위 효과 뒤에는 기존 shared watch로 생존을 확인한다.

원문 관측은 새 `tools/decomp_walker_path.py`와 [근거 JSON](../../cpppj/walker-path-20261022.json), `cpppj/tests/fixtures/walker-path-x86.tsv`에 고정했다. **348개 고유 입력·두 x87 정밀도696회 정상 복귀·136742명령**이며 두 정밀도의 저장 결과 차이는0이다. 원문 실행 범위는 생성자/전체 Frame/447790/43fa50/40e850/40eab0와 CRT4e49c0이다. 할당·immobile·Halt·Step·지면·도착·TYPE getter·가상 공간은 명시 외부 경계다. 전체100080바이트와 부모50바이트, 공유 counter, 효과 순서, 스택/비휘발 레지스터/canary/x87 균형, 읽기·쓰기 범위를 검사한다.
