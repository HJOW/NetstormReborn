# cpppj Help 링크와 Windows 실행 연결 — 단위601

2026-10-30, HJOW-Athlon(192.168.0.94, Windows 10 19045). AGENTS.md와 두 인계를 다시 읽었으며 마지막 전체 정밀 디컴파일은 같은 PC의2026-10-23이다. 원본/CD·AGENTS·정밀 C/함수 표는 수정하지 않았다.

## 복원한 동작

공통 메뉴의 `HelpLink`와 실제 `UberGump` 외부 콜백을 원문004a00c0/004a0030에 연결했다. 링크는 단순 첫 콜론 분할이 아니라00487710→00487620의 기존 토큰 파서를 사용한다. 선행 공백/인용 제거·78개 입력 바이트 상한·연속 콜론 소비·첫NUL을 유지한다. `cmd:`는 전체 접두 일치가 아닌 첫4바이트의 대소문자 무시 비교다. 접두가 없거나 본문이 `#`로 시작하면 원래 내부 Help(모드1/학습0)를 호출한다.

외부 경로는 같은 현재 Config의 `PathSpec("autoOpen")`을 대소문자 구별 substring으로 검사하고, 선택된 경우 원래 전체 링크를 Shell에 넘긴다. Shell 실패/미선택이면 접두 키를 `ReadString`하고, 반환false 또는 첫문자`{`이면 같은 출력값으로 접두+`2`를 다시 읽는다. 이 bool은 존재 여부가 아니라 값 변경 여부다. 두 번째 실패도 첫문자`{`도 원문대로 실패한다. 반환true의 빈 값은 유효하다. OS 레지스트리 연관 명령을 대신 읽지 않는다.

프로토콜 명령이 없으면 본문만 비대기로 실행한다. 명령이 있으면 첫`%`와 바로 다음 한 바이트를 공백 둘로 바꾸고 본문을 추가 구분자 없이 붙인다. `%1`만 특별 취급하지 않으며 나머지`%`도 보존한다. 끝의 외톨이`%` 역시 공백 둘로 늘어난다. 미도달 장치를 미리 요구하거나 실행 실패를 다른 프로그램 실행으로 바꾸지 않는다.

Windows 경계는 원본 ShellExecuteA/CreateProcessA 대신 UTF-8→UTF-16/W API를 사용한다. 원문과 같은 desktop/open/SHOW5·성공32초과, 비대기 program0/wait0·상속false/flags0·현재 작업 폴더/환경을 유지한다. 원본512BYTE 명령 버퍼는 한글 경로와 긴 명령을 위해 동적 문자열로 바꾸고 자식 프로세스/스레드 핸들을 즉시 닫는다. 이 Win10/11 호환 차이를 코드 주석에 명시했다. 원본 링크 CP1252와 현재 Config UTF-8은 별도로 변환한다. 자산/창이 필요 없는 경계는 기존 `Client::Edition()`으로 판본을 읽는다.

## 검증과 최초 실패

[Native 집계](../../cpppj/help-links-native-20261030.json)와 [관측 도구](../../tools/decomp_help_links.py)는 보호PE의 부모/프로토콜 helper/두 토큰 helper를 실제 CPU로 실행한다. 최종 같은 검사 EXE의 HelpLinkPolicy/ExternalHelpClient/ScriptCommand/QuickHelpControl/RawMenuControls/HtmlWindowFactoryClient 집중37개는 실패0, 등록3498개다. 게임/검사 Release 빌드 경고·오류0이다. 전체3498개를 실행한 결과가 아니다.
