# 시나리오 공통 객체 명령 — 단위686, 2026-11-01

- 이름은 기존 `GameMenuScriptCode`를 거쳐 HTML/메타/대본과 버튼 입력 큐가 공유한다. 메뉴 버튼 허용도 같은 다섯 명령 표를 읽는다.
