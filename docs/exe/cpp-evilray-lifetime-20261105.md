# EvilRay의 독립 생성·3색·중단·소멸 몸체

단위880 완료 기록이다. 현재/마지막 전체 정밀 디컴파일은 **HJOW-Athlon / 2026-11-03** 일치이며 산출물 변경0이다. 직전879는 `f409d3f2 / 20261105-13 CP`, 현재 빌드는880/11.01이다. **이번 범위는 독립 수명 부품이며 실제 Session/Host/Frame/Draw와 Teleport 분배는 미연결**이다. 게임에 새 효과를 붙였거나 전체 Pop을 완료한 것으로 세지 않는다.

PATCH004530b0은00541098의 현재 TYPE를 먼저 인자로 저장해 공통00488190→00487fd0 등록/부착을 수행한다. 그 뒤00595128의 현재 source 전체 DWORD를 읽고 nextEmission/stopping을0으로 만든다. source를 parentSID로 대체하거나16비트로 줄이지 않는다. 실제00453103의50입자·24BYTE(1200BYTE)를 초기화하며 공통 생성자가 쓰지 않는 delta/scaledDelta는 유지한다. 공유0055a6f0이0일 때만8BYTE 색 객체와 단일3색 gradient/12BYTE 병합을 만든다. 이 실제 순서를 독립 RawEvilRayLifetime과 값 저장소로 복원했다. 현재 전역의 장기 Client owner와 실제 Host 연결은 다음 범위다.

3색은 PE00508e60/68/58의 시작 RGB와00508e78/70/68의 끝 RGB, 폭2.4를 원문 binary64로 공급한다. 끝색의1.0784313725490196 성분도 잘라내지 않고 기존 실제 색 정렬/선택/병합을 호출한다. 공유 색은 각 효과의 소멸 때 반납하지 않는다. 생성 중 장치 누락도 원문 위치에서 요구하여 첫 공유 객체 장치가 없으면 앞선 등록/50입자를 남기고 명시 실패한다. 실제 할당 실패/SEH의 전체 동작 동일성으로 확대하지 않는다.

00453240의 첫 인자mode3만 stopping DWORD를1로 쓴다. 이미 비영이면 `stopping == false`, `.\Evilray.cpp:0x48` 진단 뒤1을 쓰고, 다른 mode는 `false`, 같은 파일0x4e 진단 뒤 쓰기 없이 반환한다. 가상 메서드의 나머지 두 인자는 원문에서 읽지 않는다. 선택 진단 callable은 사본으로 보존한다. 공통004882c0 소멸은 입자→등록/base 표식→flags bit0 객체 순서이며 공유 색은 유지한다. CD004b3080/004b3230 정적 본문도 보존했지만 CD용 구현/실행으로 세지 않는다.
