## 원본 생성 경로

004c8f60은 현재 Mission의 설정에서 전체 이름을 조회하고, 없으면 매번 새 `tell` Config를 만들어 현재 `missionSpec` 파일을 적재한다. 임시 Config는 조회 결과를 소유한 뒤 UI 생성 전에 소멸한다. 등록된 기존 `tell` 객체나 이름 첫 점의 다른 등록 객체를 대신 조회하지 않는다.

섹션이 없으면 경고 후0을 반환한다. 존재하는 빈 섹션도 new0x40a4→0046c9c0→0046cc60을 수행한 뒤 현재+2c serial을 반환한다. 일반 팝업의 이름 기록/이력, 지역 param 파싱, BLANK 처리, 빈 팝업 생략, 모달/phase 갱신을 수행하지 않는다.

`EmbeddedTell`과 `ShowEmbeddedTellInConfig`는 이 순서와 실제 Config 수명을 복원한다. `RawMenuControls::ShowEmbeddedTell`은 같은 공통 HtmlBody/다중 줄/글꼴·태그·링크·수명에 연결하고 실제 serial을 반환한다. UTF-8 Config 본문은 UI 파서 경계에서 기존 원본 좁은 바이트로 변환한다. 실제 창 생성자는 반환 serial로00464020에 해당하는 `RawButtonControls::SerialGump`를 조회해 자식으로 부착하면 된다.
