# 1023 — 검증4Ah/4Bh 진입과 이전 SID 간격

10.78 `00432600/004326e0/00432710`을 같은 실제 Session/Pool/TYPE/등록표에 연결했다. 마지막 전체 정밀 디컴파일은 **2026-11-03 / HJOW-Athlon**이며 이번에는 읽기 전용 대조만 했다. CD10.72 `00487ae0/00487be0`은 비교 근거이고 PATCH15000 시작 위치와 섞지 않는다.

현재 검증 SID0054d4d8과 별도 이전 위치0054d4dc는 같은 장기 게임 보조 owner의 서로 다른 BSS0이다. 최초 이전 위치0이면 현재 SID만 저장하고 복귀한다. 이후에는 DWORD 증가→signed65535 비교→15000 순환→목표 직전 복귀를 원문 순서로 처리한다. 중간 슬롯은 free이거나 TYPE70 미만인지 확인하고 실제 TYPE가0인지 별도로 비교해 수준1d의 VERIFY 로그를 남긴다. 죽음/void/owner 조건을 추가하지 않았다.

4bh6BYTE는 기존 sid 비영 진단이 정상 복귀하면 현재 입력 WORD를 저장하고 간격 부모를 실행한다. 다음 전체 객체2ch/압축7ah가 검증만 하도록 sid를 유지한다. 4ah7BYTE는 수신 SID의 free/type를 비교하고 간격 부모를 거친 뒤 sid만0으로 만든다. 이전 위치는 지우지 않는다. 첫 로그 뒤에도 저장한 슬롯의 현재 TYPE를 비교하며 로그 이름에는 그 시점의 실제 현재 SID/TYPE를 사용한다. 예외 때 이미 쓴 DWORD나 로그를 되돌리지 않는다.

두 패킷은 버전1/정책0/고정7·6BYTE/빈 observer로 등록했고 Editor 충돌 확인/수신 반납 목록에도 포함했다. 1021의 전체 객체 검증과1022의 압축 수신을 같은 전역으로 제어한다. 새 검증용 풀/TYPE/Player 사본은 없다.

Release 제품 빌드는 종료0·경고/오류0이다. 제품1023/11.01은11,981,824바이트이며 SHA-256은 `8cc591f219df984de00feaff0715c6a93df8cb7943ec9fbdc23434740fbb3b33`다. 신규MP/단위/게임/통신 검사·fixture 생성은0이고 보호2800파일은 불변이다. 원문 정적 대조와 컴파일을 실제 LAN 검증으로 세지 않는다.
