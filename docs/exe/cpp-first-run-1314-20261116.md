- `client/ClientAudio.h`: 두 음량 기본값을5·5로 교정한다. 명시적인 사용자 설정은 기존 `ReadInt` 경로가 우선하므로 저장된3·2를 초기화하지 않는다.

- 기존 Welcome→Welcome2·첫 메뉴·Tips, `$Checked`의 자기 완료 체크/직전 완료 해금, 800×600·전체화면 초기 요청은 유지하고 실제 시작 경로에서 확인한다. 서비스를 종료한 온라인 검증도 계속 비활성화한다.
