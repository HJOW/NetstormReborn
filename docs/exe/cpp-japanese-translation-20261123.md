## 유지할 번역 경계

새 본문은 `assets/lang/japanese/d/`의 UTF-8 BOM 파일로 둔다. 게임 원본과 별도 배포 `lang/japanese/d/`에 놓고 누락 파일은 기존 영어 대체를 유지한다. 한국어43본문은 구조/명령 대조 자료로 사용하되 숫자·AI/SP·플레이 조건을 번역 과정에서 변경하지 않는다. 번역표의 `%s/%d`, 원문 색상/단축키, `{…}` 치환, `<a name/href>`와 그림 자산은 유지한다. 사용자 지도는 공식 allowlist 밖이므로 덮어쓰지 않는다.

1333 실제 화면의 About 제목·미션 본문은 아직 영어다. 이는 `config.japanese`/본문 연결이 다음 단계라는 뜻이며 전체 일본어 완료로 표시하지 않는다. 원시 입력/보고·실행별 SHA는 `extracted/cpp-followups-1328/menus-final-ja*`와 `japanese-ui-1333-tests.log`에 있다. UI만 바뀌어 게임 재빌드는 필요하지 않았고 현재 제품 EXE SHA는1330의 `99514ed7…b69da45`다.
