# 썬 캐논 Fiery Tail process11 정적 분석

현재/마지막 전체 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-16**이다. 아래 내용은 보호10.78 PE의 명령·vtable·상수와 현재 PC 디컴파일을 대조한 정적 분석이다. 이 효과의 새 원본 실행 관찰은0이며 구현·동작 완료 증거로 합산하지 않는다.

## 생성과 공통 등록

- TYPE11의 `+0x1d0`은 `00458700`이다. `new(0x68)` 뒤 실제 Fiery Tail 생성자 `00457ea0(parent)`를 호출한다. `00458680`은 TYPE12용 별도 생성자로, TYPE11과 혼동하지 않는다.
- `00457ea0 → 00488190 → 00487fd0` 순서로 System/RenderProcess를 만든다. 실제 공통 표시 목록은 `00595138` 포인터·`0059513c` 용량이며40칸씩 확장한다. 목록 등록 뒤 같은 부모에 process11/flags0x10을 부착하고 파생 초기화를 진행한다. 생성 중 프레임/그리기의 재진입을 허용해서는 안 된다.
- 용량은 디컴파일의 누락된 인자에 의존하지 않고 `00457ee7 push 0x78 → 00488100`으로 확인했다. 입자120개, 각24바이트이며 저장소 전체를0으로 지운다.
- Fiery Tail vtable은 `00509538`이다. `+0x18 → 004580f0`은 프레임, `+0x20 → 004583a0`은 그리기, `+0x0c → 00487960`은 공통 표시 변경, `+0 → 004882c0`은 공유 scalar 삭제 경로다.
- 파생 초기값은 `+0x50` 공유 색 표, `+0x54 = 4`(입자 수명의 기준 정수), `+0x58/+0x5c = 0`(직전 픽셀 좌표), `+0x60 = 0`(좌표 오프셋), `+0x20 = -25`(깊이)다. `00458680`의 수명2·오프셋-8·깊이-20은 TYPE12의 값이다.

## 프레임과 입자

- `004580f0`은 현재 부모의 raw 좌표에 `0059a924/28`(16/11) 배율을 곱한다. 최초 프레임에는 시계 `00418400`을 초기화하고 현재 표시 영역·직전 좌표를 맞춘 뒤10개를 만든다. 입자마다 Y 난수와 X 난수를 차례로 구한 뒤 슬롯을 요청한다. 초기 수명은4다.
- 다음 프레임은 `00418470(timer, 0.5)`로 시각을 나눈다. 이 함수의 실제 최대 간격은 `0.5 × double[00501960](0.1) = 0.05초`다. 저장하는 delta는 간격×float[00500fc8](10)이고, Fiery Tail은 `+0x40` delta로 수명을 감소시킨다. 나머지 간격이 있으면 반복한다.
- 조각마다 입자2개를 추가하고 용량 전체120개를 순회해 양수 수명만 감소시킨다. 살아 있던 입자의 좌표±10을 새 표시 영역에 포함한 뒤 `00487ba0`으로 이전/새 dirty 영역과 사각형을 갱신한다.
- `00487b40`은 사용 수가 용량보다 작으면 꼬리에 추가하고, 꽉 찼으면 첫 수명<=0 입자를 재사용한다. 자리가 없어도 앞서 수행한 난수 호출은 되돌리지 않는다.
- `00455930(-3,3)`은 공유 게임 난수 상태 `00532710`을 실제로 전진시킨다. 사정선 보정에서 호출하는 `004e49c0`과 다른 함수다.

## 색상표와 실제 그리기

- 공유 팔레트는 `0055a750`이며 처음 한 번 `00487cb0`(8바이트 객체), `0043ad20`(색 띠) 두 번, `00487d20`(병합)으로 만든다. 두 색 띠는8색과3색이고 보정 인자는 double2.4다. 이 공통 색 띠/병합의 실제 제품 구현을 확인·복원해야 한다. 기존 건설/불타는 표시의 외부 경계를 빈 성공으로 연결하지 않는다.
- 첫 띠 RGB는 `(1,195/255,6/255) → (185/255,0,0)`, 둘째는 `(1,195/255,6/255) → (1,1,173/255)`다. 실제 PE double 비트를 보존해야 하므로 분수 표현을 별도 반올림한 상수로 바꾸기 전에 원본과 대조한다.
- `004583a0`은 사용 수만큼 순회하며 양수 수명에 대해 `00487e50`으로 색을 읽고 픽셀 출력을 수행한다. 색 표 조회의 공통 기계어는 기존 `RawConstructionFrame::Color`에서도 복원했으나, 수명==최댓값이 배열 끝의 인접 DWORD를 읽는 계약까지 확인해야 한다.
- 전역 `005318ec == 2`일 때 공유 색 표 첫 DWORD와 `+0x54`를 바꾸는 별도 분기가 있다. 전역의 의미·정상 도달 여부와 그리기 인자/카메라 변환은 추가 기계어/실행 대조가 필요하다. 임의의 화면 모드 의미를 붙이지 않는다.

## 다음 실제 연결

같은 Session의 Host/World/Kernel과 실제 공통 표시 목록·색 표·dirty/픽셀 출력에 연결한다. Missile 생성 중에는 표시 자산 Pop→effect11 생성/부착→Missile 부착 순서를 유지해야 한다. 효과가 먼저 Kernel에 들어가는 순서를 바꾸면 같은 프레임의 부모 위치 관찰도 달라진다. 실제 `flightEffect`를 연결한 뒤 데모3의113프레임 이후를 다시 검증하고, 새 경계를 인수인계에 기록한다.
