# 데모 나머지 2개의 첫360초 재시작 — 단위569

같은 **568제품**의 실제 Demo 메뉴에서 **GuardMyBack과 DissolvedAlliance**를 각각 선택해 **첫360초 만료→동일 미션 재적재→(안내가 있는 경우) 두 번째 Demo 안내/자연 재개→ESC/Game/Exit Demo→메인/Quit**을 확인했다. 두 데모 모두 정상 종료0이다. 567의 The Storm Rages 1개와 합쳐 **데모3개의 첫360초 재시작**이 각각 한 번씩 확인됐다. [집계](../../cpppj/demo-repeat-two-runtime-20261029.json)를 따른다. 마지막 전체 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-23**이며 현재도 같다. 디컴파일 산출물·게임 C++·바이너리·검사 도구·원본/CD/AGENTS 변경과 추가 빌드/C++검사는 없다.

두 번째 세션의 **전체360초 반복**(재시작 뒤 다시 만료)과 추가 연속 주기는 아직 확인하지 않았다. 이 두 사슬을 데모 전체 수명·AI/전투·승패·원본 픽셀/음향 동일성 완료로 세지 않는다.

## 원문과 관측 경계

원본 언어파일의 GuardMyBack·DissolvedAlliance는 모두 `demoRestartTimer=360`이다. GuardMyBack에는 `[Demo]` 안내가 있고 DissolvedAlliance에는 해당 섹션이 없다(`tool.reference`가 원본 `netstorm.tarc`의 `.english`를 독립으로 읽어 대조). 따라서 GuardMyBack은 첫 실행/재시작 뒤 모두 모달 안내와 자연 재개를 요구하고, DissolvedAlliance는 안내가 생기지 않아야 한다(없는 안내를 만들지 않는다). 기한·만료 예약·Guide 교체의 원문 근거는 [567](cpp-demo-repeat-20261029.md)과 [Guide 교체](cpp-guide-transitions-20261021.md)를 그대로 따르며 이번에 다시 복원/수정하지 않았다.

567의 `tools/cpp_demo_repeat_smoke.py`를 **바이트 그대로** 사용했다(실행 때 적재한 도구 SHA와 커밋 대상 SHA가 같다). 별도 게임 자료 사본(`originals`에서 Netstorm.exe/d/music/netstorm.tarc/sound만 복사)에서 실제 Demo 메뉴와 원문 제목을 누른 뒤 자연 게임 시각을 관측한다. 사용자 공격·포획·희생·승리·재시작 명령과 안내의 OK도 입력하지 않았다. 안내가 있는 GuardMyBack도 프레임 콜백이 자연 재개했다. no-audio/1024×768 창·maxFPS15/sleep1은 관측 설정이며 원래 기한·게임 시계·AI 옵션을 쓰지 않는다. 같은 자료 사본을 세 실행이 차례로 재사용했고 각 실행은 `--set`으로만 화면 설정을 바꿨다.

## 최초 실패와 도구 교정 없음

| 원시 경로 | 종료 / 범위 |
| --- | --- |
| guard-v1 | 게임 종료0·421.090초. 검증기의 **창 활성 단언**(`mouse_cursor[1]==1`)이 4080프레임 한 관측(게임 253.077초)에서 실패해 미수락. 같은 원시의 다른 148관측은 활성이며 재시작(361.747→362.008)·메인 복귀는 정상이었다 |
| guard-v2 | 같은 도구/제품/데이터 사본의 재실행. 최종 수락 |
| dissolved-v1 | 최초 실행에서 수락 |

`mouse_cursor`의 둘째 값은 실제 `Client::Active()`(창 활성)이다. 제품 코드가 비활성을 만들지 않으며 입력 계획도 그 시점에 아무 입력을 보내지 않았다. 다른 세션의 작업/사용자 조작에 의한 일시적 포커스 손실로 보지만 원인은 확인하지 않았다. 검증기의 활성창 단언은 약화하지 않았고 guard-v1은 실패로 보존하며 성공 수에 합산하지 않았다. 읽기 전용 점검(`diagnose_guard_v1.py`)은 비활성 관측이 정확히 1개임을 보였을 뿐 수락 근거로 쓰지 않았다.

## 검증과 남은 범위

두 수락 원시마다 567의 **8변이**(조기 재시작·이전 HUD/세대 재사용·다른 미션·데모 해제·두 번째 정지·메인 미복귀·강제 timeout)를 다시 적용해 **16건 모두 거부**했다. 캡처 3장(GuardMyBack 첫 안내·재시작 뒤 안내, DissolvedAlliance 재시작 뒤 전투)을 직접 확인했으며 원본 실행과 픽셀을 비교한 것은 아니다.

보호 **2542파일**의 해시 차이는0이고 기존 fixture722개도 그대로이며 현재 723개다. 제품 SHA는 `d45745a61e448a77674eec4248ee566070592afd60da5627c4d1ad2e33b9206e`(568)다. 등록3435는568의 기존 근거이며 이번에는 추가 C++/전체34경로/전체CppSuite·Windows11 검사를 하지 않았다. 마지막34경로는560제품/561, 배포 런처는563제품, Credits18기한은565제품/566, Storm 첫360초는565제품/567의 역사 근거를 유지한다. 모든 게임/검사 자식은 종료됐다. 원시는 `extracted/cpp-demo-repeat-569-20261029/`에 있다.
