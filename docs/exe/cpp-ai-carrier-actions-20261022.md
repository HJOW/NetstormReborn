## 전체 행동 순서

1. 적 사제2a0가 물리 SID1..capacity-1이면 결과가 버려져도 실제 최대HP getter를 호출한다. free/dead 필터를 추가하지 않는다.

3. 일반 수집자2dc count가0이면 종료한다. 생각 기한5a8은 native `now→due / test ah,1`을 따른다. **less/unordered 모두 미도달**이며 C++ `!(now >= due)`와 같다. `now < due`를 그대로 쓰지 않는다.

7. 포획하지 않으면 현재 사제 내용물 유무로 다이스/신전에 귀환하거나, 기존 `00411900` 수집·귀환 판단을 실행한다. 일반 수집 호출 뒤 현재 포획 목록에 actor가 있으면 모든 중복을 제거한다. 일반 사제 귀환 분기는 포획 목록을 축소하지 않는다.
8. 기존 경로가 있는 actor가 포획 목록에 있으면 경로를 유지한다. 자기 신전/유효 그래프가 없으면 대상 조회 없이 정지한다. 대상 조회의 TargetA가0이면 정지하지 않는다. 살아 있는 등록 간헐천이 목표이고 비행하거나 같은 그래프이면 유지한다. 그 외는 같은330/348 간헐천 재분류 후 실제 현재 경로를 삭제한다. TargetB는 읽어 반환하되 이 판단에는 사용하지 않는다.
