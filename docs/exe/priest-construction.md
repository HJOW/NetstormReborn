## 현재 수집 경로의 범위

`HarvestGeyserCommand`는 소유 사제와 완공 신전을 찾고 섬·소유 다리 칸을 네 방향으로 탐색한다. 연결 방향이 맞는 다리만 통과하고, 다리 버전이 바뀌면 길을 다시 찾는다. 사제는 가이저 둘레에서 결정 하나를 집고 신전 둘레까지 되돌아와 200 SP를 받는다. 왕복을 반복하며 경로가 사라지거나 대상이 없어지면 멈춘다. 상태는 세션 검사합에 들어간다.

`speed` 값의 **실제 거리/시간 단위**, 원본의 곡선 경로·충돌·운반 애니메이션, 복수 사제의 대상 선택은 확인하지 못했다. 클론은 `speed`를 칸/초로 해석하는 임시 변환을 쓴다. 다른 이동형 유닛의 값을 각 타입에서 읽을 준비는 했지만, 현재 틱에서 움직이는 것은 수집 명령을 받은 사제뿐이다. **(2026-10-04 갱신)** 건설은 이제 사제가 현장까지 걸어가는 과정(수집과 같은 `speed` 이동)과 도착 뒤 건설 작업을 분리한다. 비용은 설치 때 차감하고 사제가 도착해야 건설이 시작되며, 도착 전 중단은 환불한다([건설 흐름](../gameplay/priest-construction-flow.md)).

### 비행형 이동과 공격 기지 (2026-09-30 사용자 확인, 후속 구현)

비행형 **이동유닛**은 출발 시 떠오르고, 이동한 뒤 목적지에서 착륙한다. 따라서 이동 구현에는 지상 유닛과 별도로 이륙 → 공중 이동 → 착륙 상태가 필요하다. 원본 `.type`의 `balloon` 계열(예: Balloon·Cloud Floater·Air Ship)은 공중 수송 유닛으로 분류되어 있다. 이륙·착륙 시간, 해당 구간의 높이·속도, 착륙 가능 위치와 점유 판정은 아직 분석하지 않았다. 튜토리얼 1·2에는 이 비행형 이동이 등장하지 않는다.

일부 **건물형 유닛**은 적이 사정거리 안에 들어오면 공격용 비행체를 생성해 보낸다. 원본 타입에서 `class = "Air Attack Base"`인 Whirlibase(`sunaviary`), Devil Maker(`windaviary`), Man o'War Pool(`rainaviary`)과 `flyer` 타입 Whirligig(`sunflyer`), Dust Devil(`windflyer`), Man o'War(`rainflyer`)를 구분할 수 있다. 생성 조건·발진/이동·목표 공격·소멸 또는 귀환 조건은 미분석이다. 공중 수송 유닛의 이륙·착륙 규칙을 기지 생성 공격체에도 그대로 적용할지는 확인하지 않았다.

공식 캠페인 1-1 **The War Begins!**는 Whirlibase를 등록·건설할 수 있고 적이 0 SP로 시작하므로 공중 공격 기지 관찰 후보이다. 같은 미션에서 기절한 적 사제의 포획과 Altar 희생도 함께 재현할 수 있다. 시작 조건·기존 캡처·구체적인 관찰 순서는 [캠페인 1-1 후속 분석 시나리오](../screens/the-war-begins-start.md#0-a-후속-분석-시나리오-공중-공격-기지와-사제-포획altar)에 정리했다.

## 후속 분석 지점

1. 타입 구조체 `+0x50`을 읽는 실제 건설 갱신 경로를 확인한다. `Build.cpp`의 `00422d90`·`00422f00` 등은 이름과 달리 건설 작업이 아니라 입자 효과를 갱신한다.
2. 사제 건설 목표까지의 경로, 도착 판정, 비용 차감 뒤 중단·환불 처리와 생산 유닛 건설 경로를 분리해 확인한다. (클론은 2026-10-04에 원본 관찰·웹 팬게임 기준으로 구현했으나 exe 정적 확인은 아직 없다.)
3. `FUN_00486360`·`FUN_00486130`의 가이저 위치 선택을 복원하고, 튜토리얼 단계 B/C의 다리 수를 누적 제작 수로 옮긴다.
4. Golem·Balloon·Sail Skater·Crystal Crab 등의 이동 명령을 구현할 때 각 `.type`의 `speed`를 사용하고, 원본 좌표·시간 단위를 확인한다.
5. 비행형 이동유닛의 이륙·공중 이동·착륙을 상태별로 분석한다. 이륙·착륙 중 명령 변경, 높이, 통과·착륙 가능 지형과 점유 판정을 확인한다.
6. 공중 공격 기지의 사정거리 진입 감지, 공격체 생성과 목표 선택, 공격체의 이동·공격·종료 조건을 분석한다.
