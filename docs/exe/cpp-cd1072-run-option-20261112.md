# CD 10.72 일반 실행 판본 옵션 (제품 1303, 2026-11-12)

마지막 디컴파일 PC: HJOW-Athlon. 기존 산출물을 사용했고 재디컴파일이나 원문 변경은 없다.

일반 실행의 판본 선택을 옵션 순회 안으로 옮겼다. `--run <자료> --cd --window`와 `--run <자료> --window --cd`처럼 게임 자료 경로 뒤 어느 위치에서든 `--cd`가 독립 옵션이면 CD 10.72를 선택한다. 기본은 10.78이다. `--view --cd`처럼 값을 받는 옵션 다음의 문자열은 옵션 값으로 취급하며 판본을 바꾸지 않는다. 경로 없이 `--run --cd`만 주면 기존처럼 경로 누락 오류다. 분석 CLI의 마지막 `--cd` 규칙은 변경하지 않았다.

이전 C2 문서의 `Unknown --run option: --cd` 관찰과 달리 작업 전 현재 소스는 `TakeEdition`을 통해 **마지막 위치의 `--cd`를 이미 처리**했다. 당시 실행 파일과 소스의 차이 등 원인은 확인하지 못했다. 이번 작업은 위치에 따른 차이와 옵션 값 오인을 해소한 것이며 CD판 메뉴나 미션의 실행 가능성을 증명하지 않는다.

정식 Release `NetstormCpp` 및 `netstorm_cd_presence_tests` 빌드가 완료됐다. 이전 1302에서 중단한 정식 링크도 포함됐다. 기존 `TextClipboard.cpp`에서 MSVC C4244 변환 경고가 있었고 오류는 없었다. `CdDirectory` 집중 검사 3건(원본 15행, 유니코드, CD 표시 파일·대체 탐색)이 모두 통과했다. 실제 실행 파일의 인자 충돌·누락·알 수 없는 옵션 검사 9건은 창과 Client 생성 전에 끝나는 입력을 사용했다. 이 검사만으로 Client에 전달된 판본이나 CD판 메뉴 실행까지 검증한 것은 아니다. 사제 포획·희생, 특정 적 공격, 시나리오 승리 및 MP 게임 검사는 하지 않았다.

후속: 임의 `CDDir` 설정 연결, CD판 시작·메뉴·튜토리얼 판본 게이트와 실제 CD 자료 실행 확인은 미완료다. M8 배포 관문은 후속 코드가 모두 끝난 뒤 다시 실행한다.
