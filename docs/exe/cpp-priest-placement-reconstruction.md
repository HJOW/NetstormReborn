[`RawPriestPlacement`](../../cpppj/src/o/RawPriestPlacement.h)는 사제 genus `0x200000`의 배치 검사 **접두만** 복원한다. 일반 자산의 배치 정책은 이 클래스에 포함하지 않는다. 사제 생성 호출에서는 this의 타입과 첫 인자가 같으며 모양 훅에도 두 값을 그대로 전달한다.

1. 진입마다 차단 관계 DWORD를 0으로 지운다. 강제 허용 DWORD가 0이 아니거나 타입의 flags2에 `0x02000000`이 있으면 모양/지도/후반 처리 없이 true를 반환한다.
2. owner의 low BYTE를 **부호 확장**해 로컬 플레이어의 전체 DWORD와 비교한다. 별도의 `0x7f` 마스크는 적용하지 않는다. 이 비교는 모양 조회 전에 캡처하므로 조회 중 로컬 플레이어가 바뀌어도 후반 경계에 전달하는 값은 유지한다. 모양 조회 뒤 강제 허용이나 genus를 다시 검사하지 않는다. 배치 인자도 값으로 보존하므로 조회 중 호출자의 요청 객체를 바꾸어도 후반 처리에 전달하는 인자는 유지된다.
3. `(타입 번호, 첫 인자, flags)`의 모양 사각형을 받는다. 원본의 추가 출력 두 개와 마지막 0 인자는 이 접두에서 사용되지 않는다. 모양 조회 자체는 외부 경계다.
4. 모양에서 가로/세로 지도 여백을 구하고 큰 값을 CRT 방식으로 0 방향 절삭한 뒤 float로 저장한다. 패치는 **가로 차×1/16을 넓은 정밀도로 유지**하고 **세로 차×원본 float 계수를 float로 저장**한다. CD는 음수/양수 계수를 각각 곱해 더하고 **두 축 모두 float로 저장**한다. 평균·절댓값·올림은 추가하지 않는다.
5. `x<여백`, `256-x<여백`, `y<여백`, `256-y<여백` 가운데 하나라도 성립하면 false다. 여백과 같은 좌표는 통과한다. 통과하면 캡처한 로컬 소유 여부와 원래 배치 인자 전부를 후반 처리 경계로 넘긴다.

C++는 잘못된 타입 표/비사제 genus·누락 훅·NaN/무한대 좌표/모양·정수 변환 범위 밖 여백을 예외로 진단한다. 이 입력 계약은 원본의 정상 반환 fixture와 별도 검사이며, 비유한 좌표를 강제 허용하는 원본 경로는 지원하지 않는다.

## 사제 생성 연결과 남은 경계

`MakePriestPlacementHooks`는 같은 풀의 `RawPriestSpawn`에서 `mayPlace`만 이 접두로 연결한다. 두 판본 통합 검사는 spot=6인 지도에서 첫 후보의 후반 처리 실패→두 번째 성공→**실제 서버 SID/사제 생성자·공통 postCreate**→WORD `0x8101` 쓰기→소유자/Pop/Carrier 검사 요청을 확인한다. 새 사제 SID는 패치 15000/CD 6000, 선택 좌표는 `(21,21)`이다. 빈 공간에서 배치 검사가 생략되는 기존 생성 검사는 유지한다.

**후반 미리보기·충돌·지역/관계 본체는 아직 복원하지 않았다.** `inspectGeometry`가 그 본체의 bool 반환과 전역 효과를 공급한다. 통합의 모양 조회·후반 처리·소유자/일반 Pop/가상 Carrier 검사도 기록 경계다. 이 단계는 실제 충돌 판정·지도 등록·일반 사제 생존 수명의 완료가 아니다.

원본 뒤쪽을 확인하면 사제 genus는 마지막 일반 자산의 지면/관계 거부 조건을 우회하지만, 앞선 충돌 루프에서는 먼저 false로 반환할 수 있다. 따라서 사제를 무조건 배치 가능하게 처리하지 않는다. 다음 단계는 이 후반 구간에서 미리보기/모양 순회와 충돌 후보의 무시 조건을 분리해 기존 실제 finder/관계 조회에 연결하는 것이다. 이후 일반 사제 Pop/보호막·회복 예약·가상 Carrier 상태 검사/낙하를 진행한다.

## 독립 기계어 대조

[`decomp_priestplacement_oracle.py`](../../tools/decomp_priestplacement_oracle.py)는 실제 세 PE에서 **각 1,008개, 총 3,024개**를 두 x87 정밀도로 실행한다. 두 정밀도 관찰이 같다. 입력은 모양 9종×좌표 16종×전역/소유자 7종이며 지도 밖/여백과 같은 좌표/미세 경계, 상위 소유자 비트·음수 BYTE·전체 로컬 DWORD, 강제 허용 두 경로와 모양/후반 처리 중 전역 변화를 포함한다.

특히 `(left=2^-20, right=32, top=bottom=0)`은 패치에서 여백 **1**, CD에서 **2**다. 원본 관찰의 판본 차이를 보존해 float 저장을 너무 일찍 하거나 생략하는 구현을 잡는다. 이 모양의 모양 조회 수행 80행에서 여백 차이가 관찰된다.

각 PE·두 정밀도 합계: 실제 배치 진입 **2,016회**, 실제 CRT **1,440회**, CD/10.37 실제 타입 번호 조회 **1,440회**다. 모양 함수 진입 대체는 각 **1,440회**이며 후반 **중간 구간 대체**는 패치 **730회**, CD/10.37 **700회**다. 구간은 `0049b661`→`0049bfbb` 또는 거부 반환, CD `0044537c`→`00445ce2` 또는 거부 반환이다. 해당 구간의 실제 명령을 실행했다고 해석하면 안 된다. 진입 초기화·즉시 허용·타입 번호·여백/지도 조건·보존 레지스터/스택 복구·반환은 실제 명령이다.
