## 내 회귀 발견·교정

한국어 도움말 화면을 보려고 MCP로 F1 키를 보냈더니 영어/한국어 모두 `std::out_of_range("스크립트 문자열의 해제되었거나 잘못된 토큰")`으로 종료했다. 1269의 오류 로그가 원인 후보를 바로 남겼고, 호출 경로를 따라 **내가 1268(M7.1)에서 만든 결함**임을 확인했다: `RawMenuControls.cpp::HelpText`의 한 줄에서 `0x61000002` 분기를 `{ ... }`로 바꾸며 덧붙인 `//` 주석이 같은 줄 뒤쪽의 `0x61000003("F1Help")`/`0x61000004("Sky Overview")`/`0x61000005("minimapGump")` 분기까지 주석 처리했다. F1 키는 `PushCommand(0x02000017,0,0x61000003)`을 쓰므로 토큰이 소유 문자열 고리에서 조회되어 실패했다(Help 팝업 항목 클릭 경로는 고리 별칭을 써서 영향이 없었다). 주석을 줄 끝으로 옮겨 세 분기를 되살렸고, 회귀 검사 `RawMenuControls_StaticHelpTokensResolveWithoutScriptRing`(세 토큰을 각각 열기)을 추가했다. 1268 이후 내 모든 편집 줄을 다시 점검해 같은 유형의 "주석이 뒤 코드를 가림"이 이것 한 곳뿐임을 확인했다(앞서 `ClientHelpWordTests.cpp`에서 같은 실수를 한 번 교정했다). 1268/1269/1271/1272 보고의 "Tutorial4·메뉴 검사 통과"는 이 경로(F1 단축키)를 지나지 않아 놓쳤고, 1269의 오류 로그와 한국어 화면 시험이 잡았다.

## 한국어 실제 화면 확인 (K1 병합 산출물)

`--set currentLanguage=korean`으로 실제 클론을 띄워 MCP로 화면을 저장했다(1024 논리 800x600, 격리 사용자 폴더). 메인 메뉴 여덟 버튼이 `캠페인`/`멀티플레이어`/`데모`/`도움말`/`편집`/`크레딧`/`옵션`/`종료`로 D2Coding 글꼴(외부 `fonts` 파일)로 정상 렌더링되고, 도움말 팝업은 `일반 도움말 - F1`/`기술 도움말`/`버전`, 도움말 창은 제목 `NetStorm 도움말`과 한국어 본문·링크 목록·`뒤로`/`확인` 버튼이 정상 표시된다. 교정 후 F1 키로도 같은 창이 열린다(영어/한국어 모두 로그 파일 없음). 증거 PNG는 `extracted/cpp-resume-1275/`이다.
