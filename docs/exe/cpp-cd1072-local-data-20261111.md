# CD 10.72 로컬 자료 경로 선택 (제품 1302, 2026-11-11)

마지막 디컴파일 PC: HJOW-Athlon(기존 결과 사용, 재디컴파일 없음).

CD 자료 폴더에 `CD.NETSTORM.TITANIC.ACTIVISION` 일반 파일이 있으면 10.72 클라이언트의 시작 설정이 해당 폴더의 절대 UTF-8 경로를 `CDDir` 및 보조 자산 탐색에 사용한다. 표시 파일이 없거나 폴더가 비었으면 기존 광학 드라이브 탐색을 사용한다. 10.78의 경로는 변경하지 않았다. 이 동작은 CD 복사본을 다루기 위한 클론의 호환성 처리이며 원본과 동일하다고 주장하지 않는다.

`CdDirectory_Local1072MarkerPrecedesOpticalFallback`은 유니코드 경로, 일반 파일과 동명 디렉터리 구별, 누락 시 대체 탐색, 빈 입력 및 콜백 없는 경우를 검사한다. 변경한 `CdDirectory.cpp`와 기존 라이브러리를 이용한 독립 집중 빌드에서 기존 CD 열거 관측 검사를 포함해 **3건 통과, 실패 0**이다. `ClientMain.cpp`도 별도 MSVC 컴파일이 통과했다. 원본 파일은 읽기 전용으로 두며 게임 실행은 하지 않았다.

정식 `netstorm_cd_presence_tests` CMake 대상은 기존 대형 라이브러리의 광범위한 재컴파일이 필요해 완료 전에 중단했다. 따라서 전체 제품 링크와 정식 검사 실행은 이번 단위에서 확인하지 못했다. 다음 빌드 시 해당 대상을 다시 빌드해 확인한다.

이 단계는 CD 확인 정책 전체나 10.72 실행 복원을 완료하지 않는다. 현재 일반 실행의 `--cd` 인자, 메뉴·미션 등의 판본 게이트와 임의의 설정된 CDDir 지원은 후속이다. 메인 메뉴·튜토리얼 실행 가능 여부는 검증하지 않았다. M8 관문은 후속 코드 작업이 끝난 뒤 다시 수행한다.
