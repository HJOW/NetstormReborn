## 원본 수명과 복원

45c090은139 자산의 PreDestroy가 아니라59 생산 프로세스의 **inner VT509ddc+0c**다. 현재 Host의 `OnFormDestroy`에 대응한다. 부모의 Dying 통지(+10)와 혼동하면 직접 Form 삭제에서 빠진다. 기존 `WindAviaryProcess`는 이 가상 함수를 재정의하지 않아 생산 도중 표시한 임시138이 남을 수 있었다.

실제 홈 파괴 검사에서139의 파편 캡처도 연결되지 않아 삭제 도중 예외가 발생했다. 보호 PE의 VT509aa0은 +78=4acfe0/+a0=41c0f0/+a4=41c100의 공통 캡처다. 정확한 타입/VT 쌍만 기존 건물 캡처에 추가하여 현재 원본 프레임·TYPE 기준점·빈 추가 그림을 사용한다.139를 다른 비행체나 공장 그림으로 대체하지 않는다.
