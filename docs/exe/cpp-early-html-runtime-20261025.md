## 실제 버튼 관측과 같은 프레임의 캡처

`RawMenuControls::Report`에 실제 HTML 부모가 소유한 돌 버튼의 자식 토큰·명령·인자·serial·경계·조상 표시 상태·현재 문구를 읽는 `raw_html_button`을 추가했다. 게임 변경은 진단8줄뿐이며, 실제 버튼을 구형 `control` 목록에 복제하지 않는다. 읽기 도구는 새 `html_buttons` 목록을 따로 수집하고 실제 HTML 부모/모달/인스턴스가 모두1일 때 표시된 버튼을 검사한다. 과거 저장 관측은 옛 계약으로 읽는다.

Early1의 입력 계획에 `nextBriefing` 상태 보고와 **같은7420프레임**의 `nextBriefing.bmp`를 추가했다. 기존 `next.bmp`는7404프레임의 전환 직후 관측으로 그대로 유지한다. Early2는 원래4520프레임에 두 관측이 있다. 두 검사 도구는 실행 계획의 report/snapshot 프레임과 실제 보고 프레임, 파일 존재를 함께 검사한다. 정상 클릭·다리 여섯 단축키·배치·사제 명령만 사용하며 SP·HP·단계·완료값·다리 패턴을 주입하지 않는다.
