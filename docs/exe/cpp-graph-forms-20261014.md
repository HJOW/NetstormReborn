# 내부 Form이 있는 전체 그래프 재구성

현재/마지막 디컴파일 PC는 **HJOW-Athlon, 2026-10-14**다. 10.78의 `00463110`과 CD10.72의 `0045bd60` 및 실제 flags getter를 같은 PC의 기존 읽기 전용 내보내기에서 확인했다.

## 원본 관찰

표면 자산 하나와 공간 해시에 없는 내부 Form 여섯 개를 같은32768 슬롯 풀에 준비했다. 내부 타입6/14/24/46의 flags1/flags2는0인 합성 입력이며 live/dead/void/contained 상태와 Rebuild(false/true)를 각각 실행했다. 각 내부 Form의 NaN/무한 좌표와 오래된 graph/frame 필드는 원본이 읽거나 변경하지 않았다.

두 PE 각각32, 총 **64개 정상 고유 입력/assert0/외부효과 대체0**이다. 각 입력은 x87 53/64비트 정밀도에서 동일 정상 반환했고 반복 반환128회를 고유 입력에 다시 더하지 않았다. 별도 초기 smoke4도 새64에 합산하지 않는다. 전체 일곱 raw 슬롯·255 그래프 레코드·4096 flood DWORD를 직접 저장했다.

자료는 `decomp_graphforms_oracle.py`, `graphforms-x86.tsv`, `recovery-graphforms-evidence.json`이다. 현재 전체 SHA 감사가 통과했다. 기존 Graph 재구성288의 결과/도구/보고서는 변경하지 않았다.

## 최소 C++ 확장

이전 `RawGraph::Calculate`는 전체풀에서 발견한 모든 live 내부 타입을 거부했다. 실제 비표면 Form은 공간 머리에 없으면 생략하도록 조건만 확장했다. 공간 머리의 내부 Form과 타입 표 범위 밖 자산은 계속 거부한다. 기존 표면 계획/번호/표/스택/부분 검증/실패 전 쓰기 보호 전체는 보존한다.

기준12 **db9b626**의 전체 Graph 소스·관련 보고서/fixture/검사와 준비된 Fort 부모/binding/소비자 골든 **25파일**을 Git/당시 작업 원문으로 구분해 저장했다. `analyze_graph_forms_lineage.py`가 현재 소스의 정확 역변환과 기존 관찰 불변을 감사한다. 옛 Fort binding의52개 의존성에서 그래프 source SHA는 당시 전체 바이트를 제공해 검증하며 과거 보고서를 현재 SHA로 바꾸지 않는다.

새 `GraphFormsTests.cpp`의2검사는64행 전체 슬롯/레코드/스택과 해시/spot 불변, 공간 머리의 Form이 쓰기 전에 거부되는지 확인한다. 현재 첫 공유 Release/실행을 준비 중이다.

## 남은 범위

이 자료는 비표면 내부 Form 입력이 있는 전체순회의 대조다. 실제 Form 생성/부착/이동·복수 표면/실제 캠페인 전체 월드·렌더/음향/경제/AI/생산/운반을 완료한 근거로 확대하지 않는다. 실제 부모의 Graph 마지막 단계는 Rebuild(false)이며 전체 초기화로 대체하지 않는다.
