# 총 직접 피해와 압축 시각 (2026-10-13)

작업/마지막 정밀 디컴파일 PC는 **HJOW-Athlon**이다. `gunhit`은 현재 정밀 프로젝트에서 패치/CD 각7개 함수가 읽기 전용 내보내기에 성공했다.

`RawGunHit`은 실제 Unit.cpp의 총 시각 조회/기록, DPS×양자화 경과시간, 현재 표적에 대한 가상 피해 전달을 복원한다. `MakeMissileGunHitHooks`는 실제 Missile 소비자의 정상 표적 Hit와 빗나감/배리어 시각 갱신을 이 몸체에 연결한다.

총 자산 `+0xc` WORD의 bit0은 기존 출력 상태로 보존하고 나머지15비트는 1/8초 시각이다. 정수초와 소수8분의1초를 CRT 방식으로 절삭하고 OR한다. 시간 조회는 WORD>>1의 상위 정수초와 하위3비트×0.125이다. 4096초 감김을 임의로 펼치지 않는다.

원본 패치의 `004d4f00`과 CD 10.72의 `004432f0`은 DPS×양자화 시각차가1 이상이면 정수 피해를 전달한다. 두 판본 모두 시각차를 float에도 저장하고, 그 차이가 음수이거나 **30초를 초과**하면 실제 피해를 **DPS×3초분**으로 바꾼다. 정확히30초는 전체 피해다. 곱은 x87에 남은 시각차를 사용하며 패치는 이를 바로 절삭한다. CD는 선택한 곱을 float에 저장한 뒤 다시 읽어 절삭한다. 패치 DPS getter `004d4d40`에는 flyer/balloon genus `0x120000`에 대한 별도 DPS 선택도 있다.

초기 C++ 대조에서 패치의 정확히30초 입력은240 대신24, CD의31.25초 입력은24 대신250을 출력했다. 실제 PE의 패치 `004d4f97~004d4fb7` 비교와 CD `0044336b~004433a6` 비교/float 저장을 재확인해 위 조건을 교정했다. CD의 `00501970/00501978/0050197c` 상수는 각각1.0/30.0/3.0이다. native fixture2058행은 그대로 유지한다.

`Apply`는 현재 표적 SID0/free/dead를 자연스럽게 건너뛰고 살아 있는 표적의 가상 `+0x98`에 피해/발사 소유자/공격자 SID를 보낸다. Hit는 이 판단 뒤에도 현재 시각을 기록하고 공간 통지를 실행한다. 실제 HP 변경이나 사제의 저HP 전환을 일반 정수 빼기로 대체하지 않는다.

독립 제한 x86 관찰은 **2058개 고유 입력**, 판본별1029개 정상 반환이다. 첫2064행 격자에서 특수DPS와 기본 격자의 동일 입력3개씩을 찾아 제거했다. 이 반복은 누적에 더하지 않는다. 패치는 실제 DPS getter453회와 단일 PE float getter444회를 실행했다. CD DPS는 명시 float 반환 경계이며 원작의 실제 getter 몸체가 실행됐다고 주장하지 않는다. type/group/genus query·표적+0x98 피해·공간 통지도 명시 경계다.

자료는 `GunHitTests.cpp`, `gunhit-x86.tsv`, `recovery-gunhit-evidence.json`, `tools/decomp_gunhit_oracle.py`다. `--verify`는 현재 SHA/고유 입력/행수/정상 반환/assert 및 실제 패치 DPS 실행을 감사한다. 원본 assert/게임/OS 호출은0이다. 최신 Release의 집중3개 검사/2058개 전수 C++ 대조와 전체968개 검사가 실패0으로 통과했다. 로그는 `extracted/campaign-runtime5-GunHit_-final-tests.log`다. 초기30초 경계/판본 제한/float 저장 순서 차이 로그는 보존했다.

후속 실제 표적 피격은 `victimdamage-functions.json`이다. 사제 `00494380/CD0040cb10`은 HP를1 아래로 내리지 않고 기존 회복 사건/죽은 모양·피해 보정·`RawPriestState.SetHitPoints`·소유자 피해 통지·burning·저HP 감시 해제를 처리한다. 기본 자산 `004add10/CD004aeda0`과 Damageable override `0044c8e0/CD00462300`은 서버 파괴/효과 경로를 가진다. 이 몸체들은 아직 이 숫자 단위의 완료 범위가 아니며 최종 전투 동일성에는 복원이 필요하다.
