# cpppj 1325 — Options 설정·캠페인 진행 초기화

2026-11-22, HJOW-Athlon. AGENTS.md 15차 요구에 따라 메인 Options 최하단에 Reset All을 추가했다. 마지막 디컴파일 호스트도 HJOW-Athlon이며 이번 기능은 새 요구사항이므로 원본의 대응 함수를 만들지 않았다. 기존 원본·CD·fixture·AGENTS.md·DN/WB 코드는 변경하지 않는다.

## 변경과 저장 범위

메인 Options의 마지막 항목은 `Tell,Patch1101.ResetAll`로 기존 HTML 확인 창을 연다. 영어·한국어·일본어 모두 초기화 범위와 게임 종료를 안내하며 확정과 취소가 별도 버튼이다. 실제 확인 HTML 부모의 serial과 그 부모가 제출한 문자열 토큰이 일치할 때만 `Patch1101.ResetAllConfirmed`가 동작한다. 일반 Tell 입력에서 해당 토큰을 한 번 소비하며, 직접 Tell/스크립트 명령으로 보낸 확정은 창 안팎에서 모두 초기화하지 않는다. 취소·ESC·다른 Tell 뒤에는 이전 확인 부모와 제출 토큰을 재사용하지 않는다. 게임 중 Options에는 이 항목을 노출하지 않는다.

확정하면 같은 Client의 사용자 루트 아래 `Saves/options.cfg`를 빈 파일로 초기화하고 `!state.dat`·`fullscreenStateFile.dat`·`!rootservers.dat`를 삭제한 뒤 기존 WM_CLOSE로 정상 종료한다. `options.cfg`는 삭제만 하지 않는다. 사용자 파일이 없으면 설치의 옛 `d/options.cfg`를 이관하는 기존 정책 때문에 진행이 되살아날 수 있어, 빈 사용자 파일로 옛 옵션의 재이관을 차단한다. 다음 시작은 원래 setup 기본값과 최초 Welcome·잠금 상태를 사용한다.

초기화 성공부터 종료까지 `SaveOptions`가 기존 메모리의 설정·진행을 다시 기록하지 않게 한다. 지정 파일의 조회·쓰기·삭제 오류는 기존 상세 오류 경계로 전달하며 성공 종료로 숨기지 않는다. 지정 경로가 디렉터리나 심볼릭 링크이면 쓰기 전에 거부한다. 사용자 폴더 전체의 재귀 삭제나 설치 자료의 삭제는 하지 않는다. `CustomMaps`·`logs`·캡처·편집 장부·다른 사용자 파일은 유지한다.

## 실제 입력에서 찾은 결함과 교정

최초 GUI에서 정상 확인 버튼은 초기화하지 않았고 반대로 열린 창에서 직접 보낸 확정 Tell은 초기화했다. HTML 부모가 버튼 명령을 먼저 큐에 넣은 뒤 자신을 Kill하고, 일반 입력에서 다음 명령을 처리하기 전에 표시 phase와 현재 모달 포인터가 이미 복귀했기 때문이다. 최초의 Dialog/현재 serial 검사만으로 확인 여부를 판정한 것이 원인이었다. 정상 버튼 실행 뒤 `options.cfg` 397바이트와 체크포인트가 남았으며, 직접확정 실행은 빈 옵션·체크포인트 삭제 후 나머지 입력 단계 전에 종료했다. `first-confirm-*`·`first-bypass-real-*`·`first-failures.json`을 보존했다.

교정은 실제 HTML의 `queue→Kill` 순서를 변경하지 않는다. queue callback에서 현재 Reset 확인 부모의 serial과 Confirm 문자열 토큰만 보유하고 같은 일반 입력 큐에서 해당 토큰을 소비한다. 직접 명령은 이 제출 callback을 거치지 않는다. 같은 큐에서 소비되지 않은 토큰은 다음 프레임에 남기지 않는다. 초기화 성공 뒤의 파일 범위·자동 저장 차단·정상 종료는 기존 구현을 유지한다.

한 번의 추가 탐침은 수동 준비한 서명 없는 옵션의 첫 키가 저장 서명 줄에 합쳐져 다음 시작에서 Welcome이 뜨는 검사 준비 오류였다. 기존 `nscfg.encode_text`와 첫 CRLF로 검사 입력을 교정했고 이 원시도 `first-bypass-*`에 별도로 남겼다. 실제 제품 파일 형식이나 원본 fixture는 바꾸지 않았다. 정상 취소 전용 실행은 종료 0이며 Done 두 키·음량 2/3·체크포인트가 보존됐다.

**1325 완료.** 설정 초기화 구현·새 집중 6건·실제 GUI 8경로·설치/보존 파일 대조·화면 검토를 마쳤다. 전체 M8 배포 관문은 별도 단위에서 수행하며, CD10.72 실행·물리 IME·실기/전체 플레이·MP는 이번 검증에 포함하지 않았다.
