# M8 최종 관문 재실행: 배포 ZIP 전수 대조·배포본 실행·외부 접속 재감사 (제품 1294, 2026-11-11)

마지막 디컴파일 PC 호스트명: HJOW-Athlon(변경 없음, 재디컴파일 없음). B·11차 난이도·12차 스커미시·카피라이트로 코드 변경이 끝난 뒤 1280 관문과 같은 도구로 다시 실행했다([1차 문서](cpp-m8-final-gate-20261111.md)). 일본어 L 1차(1288) 이후 첫 전체 재실행이다.

## 1. 배포 ZIP

`cmake --build cpppj/build --config Release --target NetstormCpp NetstormRoot`(최신) → `powershell -File cpppj\package-cpppj.ps1 -NoBuild extracted\cpp-m8-1294\netstorm-cpp-1294.zip`(항목 **1433개**, 압축 199.5MB, 23초) → `python tools/verify_cpp_package.py <zip> --extract <폴더> --json <보고서>`.

| 항목 | 결과 |
| --- | --- |
| 원천과 해시 일치 | **1426개** + 생성 텍스트 4개 + 런타임 DLL 3개 = 1433, `passed: true` |
| 필수 누락 / 금지 항목 | 0 / 0 (`forbidden: []`) |
| exe 안 글꼴 시그니처 | 0 (`ttcf`/`wOF2`/`OTTO` 없음). 글꼴은 `fonts\`(D2Coding·Noto Sans JP와 라이선스)에서만 적재 |
| BUILD_INFO | Netstorm.exe `f23f5ef2…cc2d`, R.exe `d0093273…0ff9`가 ZIP 실제 바이트와 일치 |
| 압축 해제 | 1433파일/251,702,223바이트가 ZIP과 같음 |

| 영어 Campaign → Skirmish 설정(AI 3명·AI별 난이도/동맹·금지 Outpost) → Start → 브리핑 → 전투 | 종료 코드 0, 오류 로그 없음, 설치 폴더 불변 |

## 3. 외부 접속·클라이언트 검증 비활성화 재감사

| 대상 | 결과 |
| --- | --- |
| `Netstorm.exe` | `wininet.dll`/`winhttp.dll`/`urlmon.dll` import 0. `master.`/`security.dat`/`Not Validated`/`PIRATE`/`bugs@`/`setup.exe`/`nsLaunch` 0건 |
| `R.exe` | 세 DLL import 0. `master.` 1건은 로그 문구 `is not the master.`(배틀 마스터 권한 거부), `PIRATE` 1건은 R 로그인 결과 이름표(`DEMO/PIRATE/BADVER/BADDIAG/BETA`)로 **접속 코드가 아니다**. 폐기 온라인 유효성 검증은 복구하지 않았다 |
| 새 단위(난이도·스커미시·카피라이트·NB10/NB18/NB20) | 설정 파일/생성 가상 파일/메모리 계산만 하며 새 외부 접속·`checking` 소비자를 만들지 않았다. 외부 접속 정책은 [외부 서비스 문서](cpp-external-services-20261101.md) 그대로다 |

## 4. 남은 것

사용자 확인 항목([LEFT_JOBS 4절](../../LEFT_JOBS.md#user-checks)): 실제 Program Files/UAC 설치, 다른 모니터/DPI, Windows 11/ARM, 물리 IME, MP 실행. 일본어 본문 번역(13차 후속)은 번역 방식 결정을 기다린다. 코드를 다시 고치면 이 관문을 다시 실행해야 한다(고친 뒤 ZIP을 새로 만든다).
