## 복원한 원문과 선택 규칙

- **0045c4b0 표적 검색:** 현재 부모의 종속 진단→홈 snapshot→현재 TYPE 사거리/발자국→가상+cc offset→출발점→표적WORD 초기화→일반 공간 finder→현재 발사 문맥/MayTarget→genus·홈·경쟁 수→거리→현재 부모/복귀 기한/명령→마지막 진단 순서를 보존한다. 선택된 후보는 WORD로만 쓰고 dirty4를 켠다. 의존 생성·Form 전송은 기존 공통 Frame이 검색 반환 뒤 수행한다.
- 첫 출발점은 부모의 실제 중심에서 offset을 뺀 **float 좌표**다. 부모 raw+42/+46이 둘 다0이면 `ftol`로 정수 좌표를 저장하지만 **이번 검색은 절삭 전 float 출발점**을 계속 사용한다. 다음 검색부터 저장한 정수 좌표를 float로 읽는다. 둘 중 하나라도 비영이면 기존 두 좌표를 사용한다.
- 검색 사각형은 출발점 하나로 시작해 `origin+range`, `origin-range`를 원본 순서로 포함한다. **추가 점을 먼저1..255로 clamp하고 기존 꼭짓점이 유효하지 않으면 교체**한다. 단순한 `origin±range` 최소/최대와 다르다. 실제0041def0의 왼쪽/위는0방향 절삭, 오른쪽/아래는 `0.99999f`를 더한 뒤 절삭이다. 음수 좌표에서 floor/ceil로 바꾸지 않는다. flags1의 같은 `RawSquidFinder`에 이 사각형을 넘긴다.
- 원문은 후보마다 현재 부모의8DWORD 발사 문맥을 다시 만든다. 후보 TYPE genus는 MayTarget 호출 전 snapshot이다. 공통 `0x120000`, 홈, 훨리기그일 때 `0x210000` 대상 배제를 유지한다. 후보의 첫 거리 계산은 **float delta 저장 후 제곱근**, 최선 거리 비교는 **현재 중심과 출발점의 차이를 double로 계산한 거리**다. 사거리와 최선 거리보다 모두 엄격히 작아야 한다. 동률은 먼저 발견한 후보를 유지하며 후보 순서를 SID 정렬로 바꾸지 않는다.
- **0045b840 경쟁 수:** 표적과 현재 비행체의 free/dead 관문을 먼저 확인한다. 현재 비행체의 표적까지 거리는 float로 저장하고, 다른 비행체 거리는 double 상태로 엄격하게 비교한다. 같은 표적의 의존 Form에서 현재 watcher→실제 process Form→현재 Host 부모를 찾아 비행 genus를 확인한다. 자기 자신은 제외한다. 다른 비행체에 원문에 없는 free/dead 필터를 추가하지 않는다.
- **0045b9c0 수용 수:** 비사망1×1 표적은1, 그 밖과0은3이다. 표적 free 비트를 추가 배제하지 않는다.
- **0045ba10/0045bb80 포위:** 자기 비행체를 가리키는 첫 의존 Form을 찾은 뒤 목록을 다시 시작한다. 그 Form보다 **번호가 작은** 다른 비행 의존 Form 수가 자리 번호다. 순회 순서와 번호 순서는 다를 수 있다.1×1 표적은0/0이며 그 밖의 세 위치는 PE00532794의 **(0,-1),(-1,1),(1,1)**이다. 자리가 수용 수 이상이면0/0이다. 자기 Form이 없을 때 checking 진단374 후0을 반환하는 원문도 보존한다.

모든 의존 순회는 현재 후보를 반환하기 **전에 next를 저장**한다. getter 경계가 현재 next를 바꿔도 이미 저장한 다음 후보는 유지한다. 같은 목록의 두 번째 검색은 바뀐 현재 체인을 새로 읽는다. 손상된 범위 밖/순환 체인은 명시 거부하지만 정상 입력에 원문에 없는 필터를 넣지 않는다.
