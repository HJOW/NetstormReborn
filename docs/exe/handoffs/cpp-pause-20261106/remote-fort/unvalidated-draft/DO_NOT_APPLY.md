# 적용 금지: 미검증 중단 스케치

이 폴더의 두 소스 사본과 패치는 원문 분석 뒤 작성되던 임시 스케치이다. 사용자 중지 지시가 도착하여 곧바로 구현을 중단했고 출처 보존만을 위해 분리했다. **제품 미반영·미컴파일·실행0·신규 MP 검사0이며 적용하지 않는다.** 상위 PLAN.md/FUNCTION_MAP.md의 설계 완료와 이 스케치의 구현 완료를 혼동하지 않는다.

두 소스 파일의 바이트와 SHA를 보존했다. 다음 명시적 재개에서 전체 접합 설계와 실제 현재 제품을 다시 대조해야 하며, 패치의 적용 점검 성공은 C++ 구문/예외/수명/행동 검증을 뜻하지 않는다. 지역 MarkStream/실제 섹션 어댑터의 완전한 최종 리뷰도 수행하지 않았다.

제품 기준은985/1f00a25a이며 원격 경로004606d0·Session 소비자·실제 namespace/파일 장치 접합은 이 스케치에도 없다. 단순 ReadImage 조각을 원격 Fort 완성으로 적용하지 않는다.
