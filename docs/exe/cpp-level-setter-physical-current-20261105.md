# 공통 레벨 setter의 물리 슬롯·진단 복귀 쓰기 복원 (단위923)

RawSquidLevel.Set이 예약/free 슬롯과 진단 중 반납된 슬롯을 거부하던 차이를 원문처럼 수정했다. 제품923/11.01을 빌드했고 새2/기존19 고유21사례가 최종 통과했다.

## 원문과 변경

같은 HJOW-Athlon의 마지막 전체 정밀 디컴파일은2026-11-03이다. PATCH `004ad110`·CD `004ace20`은 Has→signed 범위 진단→현재 상태BYTE+b의하위5비트/레벨3비트 저장 순서다. 예약 번호/할당/free를 다시 검사하지 않는다. CD의 XOR와 PATCH의 OR는 두 비트 영역이 겹치지 않아 같다. 현재 구현의 마지막 AllocatedBytes는 이 위치에서 원문에 없는 할당 검사를 추가했다.

SidPool의 좁은 RawSquidLevel friend를 통해 이 setter만 Offset으로 물리 범위를 확인하고 현재 상태BYTE를 쓴다. 일반 AllocatedBytes의 할당 검사는 유지한다. Has의 현재 TYPE 물리 범위와 진단/정수 폭도 유지한다. 진단 후 Has를 반복하지 않아 callback에서 TYPE가 바뀌어도 원문 마지막 저장이 진행된다. 자유 목록/카운터·다른 필드는 쓰지 않는다.
