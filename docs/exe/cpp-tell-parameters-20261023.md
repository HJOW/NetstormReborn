# Tell 이름과 지역 param 복원

2026-10-23, 현재 PC와 마지막 전체 정밀 디컴파일 PC는 **VM-W11-Codex / 2026-10-23**으로 일치한다. 기존 정밀 원문과 보호 10.78 PE를 재사용했다. 이 독립 조사는 원본/클론 게임이나 GUI를 실행하지 않았으며 보호 파일을 변경하지 않았다.

기존 `UberGump::TryTell`은 전체 문자열을 그대로 섹션 이름으로 조회했다. 원본 메뉴의 `SETSIZE(800,600)`이나 `SetIslands(1)`은 각각 이름과 숫자 인자를 분리해야 하므로, 메뉴 행만 복원하고 이 부모를 생략하면 원문 명령이 실행되지 않는다.

원본 `004cf730`은 BLANK를 먼저 구별한 뒤 현재 Registry에 지역 `Config("param")`를 등록한다. `004c8ea0`으로 이름/인자를 준비하고, 이름을256BYTE 지역 버퍼에 복사하여 실제 섹션을 조회하고 `004cf270`으로 본문을 처리한다. param은 본문 처리 뒤에만 Clear/소멸한다. 이름에 점이 있으면 먼저 현재 이름의 등록 Config를 찾고, 이어 현재 Mission, 마지막에 기본 스크립트를 조회한다. 이 전체 Tell 조회/표시 부모와 이름 파싱의 복원 범위를 구별한다.

새 `TellParameters.h/.cpp`의 `ParseTellParameters`는 `004c8ea0` 전체 부모를 복원한다.

- 먼저 원문 C문자열을1024BYTE 지역 입력으로 복사한다. 호스트에서는 종료 NUL을 포함해 이 물리 범위를 넘는 무효 복사를 쓰기 전에 명시 거부한다. 첫 NUL 뒤 바이트는 입력 크기에 포함하지 않는다.
- 기존 `ReadRawTextToken`을 사용해 첫 이름은 구분자 **`(`**로, 뒤 인자는 **`,)`**로 읽는다. 두 문자열은 PE `005152c8/005152c4`의 실제 값이다. 기존 토큰 helper의 따옴표 제거·앞 space/tab·뒤 공백 첫 바이트 보존·입력78BYTE 제한을 그대로 공유한다.
- 숫자 인자 키는1에서 시작한다. **첫 빈 토큰에서 즉시 종료**한다. 빈 따옴표 토큰 뒤에 있는 다음 값을 다시 찾아 계속하지 않는다. 원본의 연속 구분자 소비와78BYTE 제한 때문에 긴 문자열이 나뉘는 동작도 임의 수정하지 않는다.
- 비어 있지 않은 각 토큰은 실제 `00441740(text,1024,0,0,0)`에 전달한다. 이 함수는 이미 복원한 **`ConfigInterface::SubstituteLocal`**이며 인용부호 escape 함수가 아니다.
- 치환 결과를 원본 고정 서식 **`%d="%s"`**로 만들고 같은 현재 param 객체에 **Append**한다. 임의 escape, Set, 별도 값 목록으로 바꾸지 않는다. 앞선 param.1이 다음 인자 `{param.1}`의 치환에서 바로 보여야 한다. `%s`는 결과의 첫 NUL에서 끝난다.
- 마지막에 첫 이름의 소유 바이트를 반환한다. 실제 Client가 본문을 처리하는 동안 같은 지역 param Config를 유지해야 한다.

`TellParameterHooks`는 현재 Config 치환과 완성된 한 행의 Append만 명시 경계로 둔다. 토큰 분리/종료/숫자 키/서식 순서는 제품 본체가 담당한다. 원본 바이트와 현재 내부 UTF-8 Config의 변환은 기존 Client 문자열 경계에 연결한다.

`tools/decomp_tell_parameters.py`는 **실제 `004c8ea0` 전체와 `00487710/00487620` 토큰 helper, CRT strchr**를 격리 실행했다. Config 치환/Append/반환 이름 문자열 고리만 명시 경계다. 정상 메뉴 두 종류, 빈/인용/공백/연속 구분자, 원본78BYTE 제한과1023BYTE 입력, 비ASCII BYTE, NUL, 순차 치환·빈 치환·따옴표/개행 결과를 포함한 **535입력×두 x87 정밀도=1,070관측·정밀도 차이0**을 새 `tell-parameters-x86.tsv`에 보존했다. 제품 기대 목록을 Python에서 생성하지 않는다.

집중 검사는 전체1,070행 직접 대조, **실제 ConfigRegistry/ConfigInterface**의 지역 이름 가림·이전 인자의 후속 치환·본문 기간 생존·소멸 뒤 바깥 param 복귀, 누락 의존/물리 입력 한계를 포함한다. 독립 Tell 컴파일/링크는 종료0·경고/오류0이다. `extracted/cpp-game-menus-audit-20261023/tell-focused1.log`의 합계9검사에서 기존 메뉴 부모1,958행과 새 Tell1,070행, 실제 Session/Config 검사가 실패0이다. 이 격리 검사는 기존 라이브러리의 읽기 복사본과 독립 objects를 썼고 공통 빌드 산출물을 덮지 않았다.

실제 Session 추가 컴파일에서 수정 가능한 TYPE라고 가정한 검사 오류와, Start 전0인 SP 배열이 회전 뒤 달라져야 한다고 가정한 검사 오류를 수정했다. 제품의 분기나 원문 fixture를 검사에 맞춰 바꾸지 않았다. Session 포함 직접 cl 빌드9에는 명령줄 옵션 전체 적용 경고 D9026 한 건이 있으므로 최종 정식 CMake 빌드의 경고 판정과 구별한다.

이 기록만으로 실제 Resolution/섬 테마 행의 GUI 실행, 전체 Tell 본문/조회 수명, 모든 메뉴 소비자와 캠페인 완주를 완료로 계산하지 않는다. 최종 Client 연결과 정식 빌드/집중·전체/GUI 검증은 통합 작업에서 이어간다.
