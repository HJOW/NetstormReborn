## 입력 줄과 미완료 끝 칸

`StyleTextBufferState`는 전체 입력 칸과 **개행으로 완료된 줄 수**를 구분한다. `hardLines[lineCount]`는 아직 LF를 받지 않은 끝 칸이며, 표시 줄 재생성은 그 앞의 완료 줄만 순회한다. 원본 UI의 128칸 버퍼에서는 최대 127줄과 끝 칸 하나를 보관한다. C++ 생성자는 원본처럼 양수 최대 칸 수를 받는다.

`AppendText`는 문자열 통지 → 길이 결정 → LF 분할 순서다. 음수 길이는 범위 안 NUL까지, 비음수 길이는 명시 범위를 사용한다. 통지는 길이 0에도 수행하며 그림 추가에서는 수행하지 않는다. LF 앞의 빈 구간도 실제 빈 문자열 조각으로 만든다. CR/탭은 LF로 정규화하지 않는다. 각 구간의 현재 문맥과 전달 태그를 같은 공통 조각 표에 저장한다.

LF를 만나 끝 칸이 가득 차면 첫 완료 줄을 삭제한다. 삭제는 next를 먼저 저장하고 실제 문자열/그림 scalar 반납을 수행한 뒤 **전체 최대 칸 수까지** 앞으로 이동한다. 따라서 이전 미완료 끝 체인도 함께 옮겨진다. 마지막 미완료 구간은 빈 경우 새 조각을 만들지 않으며 완료 줄 수도 늘리지 않는다. 문자열/그림 추가와 삭제는 dirty를 1로 만든다.

`AppendPicture`는 현재 끝 칸에 새 그림을 붙인다. 맞춤 폭/높이 중 하나라도 비0이면 기존 판본별 `Markup::Fit`을 호출한다. 그림 추가 자체는 개행하지 않으며 공통 태그를 보존한다.

배열 범위 밖 접근, 최대 칸 수 1에서 첫 줄을 버리려는 입력, signed 길이 범위를 넘는 호스트 문자열, 소멸 뒤 접근은 예외로 거부한다. 원본 assert 뒤의 잘못된 메모리 접근은 재현하지 않는다.

## 표시 줄·폭 비교·공백 복사

표시 줄은 원본의 24바이트 필드에 대응하는 head/높이/폭/y/양방향 링크를 가진다. 토큰 0은 센티널이며 실제 줄은 별도 안정된 map 토큰으로 보관한다. 새 줄의 y는 **삽입 시 전임 y+높이**로 정한다. 이후 다른 줄의 높이가 바뀌어도 좌표를 다시 계산하지 않는다.

`Layout`은 폭이 양수일 때만 기존 표시 조각을 scalar 반납하고 완료 입력 줄마다 빈 표시 줄을 먼저 만든다. **폭 0 이하이면 기존 표시 목록도 유지**한다. noWrap 비0은 폭에 따른 분할을 생략한다. dirty는 원본처럼 호출자가 관리하며 Layout이 자동으로 지우지 않는다.

문자열 전체 폭이 현재 줄 폭과 합쳐 **제한 폭 미만**이면 전체 문자열을 새로 복사한다. 정확히 같은 경우는 분할 경로다. 문자열 조각은 원본의 CloneText를 사용하지 않고 NUL 탐색/원래 문맥/원래 태그로 직접 생성한다.

분할은 ASCII space만 단어 경계로 삼는다. 다음 단어까지의 전체 접두 폭을 명시 길이로 측정하며, 허용한 구간은 뒤 space까지 복사한다. 문자열 마지막 단어를 복사할 때는 **원래 NUL도 명시 길이에 포함**할 수 있다. 생성한 조각의 실제 크기는 다시 NUL 탐색으로 측정해 줄의 폭/높이에 더한다.

- 첫 단어가 들어가지 않고 현재 줄의 폭이 비0이면 먼저 새 빈 표시 줄로 옮긴다.
- 빈 줄에서도 첫 단어가 크거나 폭과 같으면 그 단어를 강제로 배치한다. 단어를 글자 단위로 쪼개지 않는다.
- 이 분기에서 줄바꿈 표식은 마지막 단어 뒤에도 새 빈 표시 줄을 만들 수 있다.
- 연속 space/탭/빈 문자열과 원본 태그를 유지한다. signed 폭/y/카운터 합산은 DWORD 감김으로 계산한다.

## 그림 복제와 수명

비문자 조각은 가상 측정/복제로 처리한다. 원본은 **이동 전에 현재 줄의 높이를 갱신**하고, 폭 조건으로 새 줄을 만들더라도 새 줄 높이에 같은 값을 다시 쓰지 않는다. 이전 줄의 이 갱신과 새 줄의 초기 높이 0을 그대로 유지했다.

`BindStyleTextBufferMarkup`은 같은 Markup의 그림 복제를 공급한다. 원본처럼 복제의 배율은 1, 색 치환 BYTE는 0으로 초기화된다. 레이아웃에는 복제 전 원본 조각의 측정 폭/높이를 사용한다. 입력 조각의 Fit/색 필드를 표시 복제에 임의로 복사하지 않는다. 그림 외 비문자/기본 조각의 가상 복제는 기존 외부 경계가 필요하다.

입력과 표시 줄의 조각은 서로 다른 소유권이다. 입력 줄 삭제는 현재 표시 복제를 직접 삭제하지 않으며 다음 양수 폭 Layout에서 이전 표시 목록을 반납한다. `Destroy`는 완료 입력 줄 → 입력 배열 반납 → 표시 줄 → 센티널 조각 순서다. 카운터를 재초기화하지 않는다.

**원본 소멸자는 미완료 끝 칸을 삭제하지 않는다.** 같은 누락을 유지했으므로 호출자는 소멸 전에 이 칸을 LF로 닫거나 해당 소유 head를 직접 반납해야 한다. 미완료 칸의 토큰은 공통 저장소에 남으며 C++ 배열 반납이 해당 토큰을 자동 삭제하지 않는다.

## 기존 자산/폰트 연결

`BindStyleTextBufferFonts`는 실제 GumpText/FontStore의 첫 폭 표·별도 논리 슬롯 높이와 명시 길이/NUL 측정을 공급한다. 생성한 부분 조각의 측정/삭제는 이미 구성한 StyleText의 실제 글꼴/그림 분배를 사용한다. 같은 공통 저장소를 전달해야 한다.

```cpp
// 기존 글꼴/팔레트/그림 처리기가 연결된 StyleText와 공통 조각 표를 사용한다.
StyleTextBufferState bufferState;
StyleTextBufferHooks bufferHooks;
BindStyleTextBufferFonts(bufferHooks, gumpText);
BindStyleTextBufferMarkup(bufferHooks, pictures);
StyleTextBuffer buffer(bufferState, styleState, styleText, 128, std::move(bufferHooks));
// content는 NUL 범위를 포함하며 LF로 완료한 입력 줄만 표시 목록에 들어간다.
buffer.AppendText(content, context, -1, tag);
// 원본 폭 규칙으로 표시 복제를 만들고 후속 TextGump에 줄 링크/크기를 공급한다.
buffer.Layout(viewWidth);
```

최대 폭은 현재 표시 줄 수만큼 순회해 signed 최대값을 구한다. 전체 높이는 마지막 표시 줄의 y+높이며 표시 줄이 없으면 0이다. 후자는 원본 TextGump 스크롤 상한에 사용되는 두 필드의 합을 공급한다.
