# Quick Help 창 재사용·이력·전체 입력과 공용 팝업 상태

단위254의 시작 커밋은 `05df64c0`다. 현재 PC와 마지막 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-20**로 일치한다. AGENTS와 양 인수인계를 다시 읽었고 새 디컴파일·원본/CD·AGENTS 변경은 없다. 직전 단위는 전체 지식 카드/원본 공용 정렬/실제 메뉴 입력을 구현·기록·커밋한 진행 턴이다. 전체11미션 목표는 진행 중이다.

## 복원한 제어 계층

`QuickHelpControl`은 원본 `004c62a0`의 팝업 닫기→Help/대체 등록 창 조회→현재 모달 관문→필요한 경우 전용 생성/부착/깊이 가산→모달 진입→요청 분배를 옮겼다. 이미 존재한 Help는 다른 모달에 막혀도 반환하며, 새 창은 영역 중앙·y40에 부착한다. `004652b0`는 설정 함수가 아니라 자식까지 깊이를 더하는 함수이므로 현재 depth120에서는 delta44를 더해164가 된다. mode0은 QuickHelpRequest02000057,그 외는 Help02000017이다.

`QuickHelpHistory`는 `004c5260/004c52c0/004c6d00`의 첫NUL·ASCII 대소문자 비교·머리 연속 중복 생략·원래 주제 문자열·단일 pop을 유지한다. 중간 중복은 보존한다. 빈 주제 노드도 유효하며 이력 없음과 구별한다. 원본의 next 포인터를 안전한 소유 문자열 목록으로 바꾸되 Back의 반환과 호출 순서는 같다.

`DispatchQuickHelpWindow`는 `004c6e00/004c70a7`의 모든 입력 분기를 옮겼다. 모든 사건에서 좌표 변환이 먼저이며 창 밖 왼쪽 누름만 Kill한다. PgUp/PgDn은 실제 페이지 높이를 signed64 절삭한 하위 DWORD로 이동하고 Up/Down은 ±10이다. 해제/일반 키와 미처리 명령은 실제 기본 GumpHelp 경계로 전달한다. Help/요청은 둘째 인자의 signed32 값이256미만이고0이 아니면 TYPE 이름+번역 Type 접미,나머지는 둘째 또는 첫째 문자열을 쓴다. 음수 비트도 임의로 문자열로 바꾸지 않는다. 링크 명령은 현재 문자열을 실제 링크 경계로 보낸다.

Cancel/Learn/Back은 자식의 등록 ID가 아닌 **+2c serial**과 첫째 인자를 비교한다. Learn은 TYPE가 있으면 학습을 요청한 뒤 창을 닫고,0이면 바로 닫는다. Back은 현재 이력을 하나 pop하고 새 머리가 있으면 링크를 연다. 마지막 이력이 사라질 때는 이전 popup command를 Kill 전에 보관하고,인자 문자열은 **Kill 뒤 현재 저장소**에서 읽어 같은 문자열을 두 번 예약한다. Kill 중 command가 바뀌어도 예약 code는 이전 값이다. 처음부터 이력이 없으면 Kill만 한다.

`QuickHelpPopupState`는 `004c5340`의 command+80BYTE 저장소다. null은 전체80바이트를 지우고 비null은 첫NUL까지 복사해 뒤의 바이트를 유지한다. 지식 카드의 실제 `RawMenuControls` 표식을 이 저장소로 옮겼고 `PopupState()`가 같은 주소를 반환한다. 안전한 호스트는80바이트 초과/NUL 없는 문자열과 유효하지 않은 Gump 토큰을 거부한다. 원본의 버퍼 밖 쓰기를 정상 결과로 만들지 않는다.
