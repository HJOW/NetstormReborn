# cpppj 1323 실행 파일 아이콘

2026-11-19 HJOW-Athlon에서 원본 10.78의 두 아이콘 그룹을 추출해 cpppj Release의 `Netstorm.exe`에 넣었다. 공통 ICO에는 32×32와 16×16의 4비트 이미지를 모두 담았다. 제품 파일 버전은 11.01이다.

## 추출과 빌드

Python 3.13과 `pefile` 2024.8.26으로 `originals/Netstorm.exe`의 PE 리소스 디렉터리를 읽었다. 언어 1033의 `RT_GROUP_ICON` 102와 144가 각각 가리키는 `RT_ICON` 1과 2의 데이터를 복사했다. ICO 디렉터리는 각 그룹 항목의 앞 12바이트를 사용하고, 그룹 내 이미지 ID 자리에 ICO 내 이미지 시작 위치를 32비트 리틀 엔디언으로 기록했다. 원본 이미지의 팔레트와 픽셀, 투명 마스크를 바이트 단위로 보존했다.

| 파일 | 내용 | SHA-256 |
| --- | --- | --- |
| `originals/Netstorm.exe` | 추출 원본 10.78 | `a305414cfe0b94494bb32fef2b359e920e9daba225e0821b76aea1f9f8e7d236` |
| [assets/Netstorm.ico](../../assets/Netstorm.ico) | 재사용용 32×32·16×16, 1,078바이트 | `bd4c18c5cb5f42bc49a1de0c6d6623643fd5377f575e95a1de60a05f01e4f068` |
| `cpppj/src/app/Netstorm-32.ico` | 그룹 102용 32×32, 766바이트 | `d029cb8a03d113afecb5b868b46e1ae967d99e569f303c04ebe6adc5b0d47a8e` |
| `cpppj/src/app/Netstorm-16.ico` | 그룹 144용 16×16, 318바이트 | `01c8779ca0d8c4cea3a99aca97894397ff6322952952493339423d5aaf15577b` |

`cpppj/src/app/ProductVersion.rc`는 원본처럼 한 그룹에 이미지 한 장씩 들어가도록 단일 이미지 ICO 두 개를 사용한다. CMake가 ICO를 리소스 컴파일 입력으로 추적하며 MSBuild의 리소스 읽기 기록에서도 두 경로를 확인했다. 공통 ICO는 dotnetpj의 실행 파일 아이콘과 webpj의 favicon에 사용할 수 있다.

## 확인 결과

- Visual Studio 18, Windows SDK 10.0.26100.0에서 `NetstormCpp`·`NetstormRoot`의 x64 Release 빌드 종료 코드 0.
- Release `Netstorm.exe`의 `RT_GROUP_ICON` 102·144와 `RT_ICON` 1·2의 리소스 ID·언어·바이트가 원본과 모두 일치했다. ICO 세 파일의 디렉터리와 이미지 바이트도 원본과 일치했다. `R.exe`의 아이콘 리소스는 0개다.
- Windows `ExtractIconExW`로 원본과 Release 실행 파일의 두 그룹을 읽었고, `LoadImageW`로 공통 ICO에 담긴 두 크기를 읽었다. 게임 실행 없이 검증했다.
- 배포 스크립트의 `-DryRun`에서 최상위 `Netstorm.exe`의 원천이 검증한 Release 산출물임을 확인했다. 압축 해제본의 탐색기 표시는 사용자 확인 항목이다.

원본 실행 파일의 SHA-256은 추출 전후 동일했다. 마지막 디컴파일 호스트는 HJOW-Athlon이다.
