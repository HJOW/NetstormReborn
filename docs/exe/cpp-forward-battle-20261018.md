## 실제 창 검사

다리 조각 모양이 달라도 실제 허용점에서 건설하도록 자동입력 전용 placement-near:x,y를 추가했다. 목표24칸/현재 화면 안에서 실제 커서의 공간/공급 판정만 질의하고, 선택한 좌표의 기존 실제 클릭이 생산/서버 건설을 수행한다. 원본 배치 허용값/성공/자원/HP를 쓰지 않는다. 허용점이 없으면 명시 실패이며 무한 대기하지 않는다.

첫 실제 창은 **926.523초/20,003프레임 정상 종료**했다.18개 건설 준비가 실제 허용됐고 스톤15018/15022의 자연 삭제를 관측했다. 다리 모양에 따라 전진 캐논은127,121에 놓였으며 적 신전은HP5000으로 남았다. 이 창의 스톤 파괴/수명 검증과 창 없는129,126의 신전 파괴를 구별한다. 시작부터 존재한 Done 설정은 승리 증거로 사용하지 않는다.

자동입력 전용 placement-fire:x,y,targetSID는 같은 현재 RawGunTarget를 조회하고 실제 MayTarget/포구 ray를 통과하는 허용 캐논 자리만 선택한다. 생산/배치/공격 판정을 우회하지 않는다. 실제 판정 검사에서127,121은 신전 사격 불가,129,126은 가능했다.

두 번째 실제 창은24개 다리를 놓은 뒤 사격 가능한 합법점이 없어 마지막보고345.452초에서 명시 종료1이었다. 세 번째는 창 없는 검사와 같은 cursorSnapToGrid=1로 비교했으나344.597초에서 같은 이유로 종료1이었다. 진단은 **허용146곳/신전 사격0곳, 요청129,126은 공급1·공간0, owner1/camera1444,793**이었다. 공급 연장만으로 캐논 발자국 전체가 확보되지 않았으며, 다리 회전/빈 발자국 칸을 고려한 플랫폼 배치가 다음 실제 창 과제다. snap 설정으로 해결됐다고 하거나 카메라/마우스 오류로 단정하지 않는다. 세 창 모두 전체 originals 스냅샷이 같다.
