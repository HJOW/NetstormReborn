# CD 10.72 설정 CDDir 연결 (제품 1307, 2026-11-14)

마지막 디컴파일 PC: HJOW-Athlon(변경 없음). 기존 산출물을 사용했으며 재디컴파일·원문 변경은 없다.

1302의 로컬 CD 표시 파일 선택은 자료 폴더만 검사했고, `ConfigInterface::Startup`이 설정에서 읽은 `CDDir`을 자동 탐색 결과로 덮어썼다. 이제 CD 클라이언트는 설정을 모두 읽고 `InstallDir`을 확정한 뒤 현재 치환된 `CDDir`을 선택 장치에 전달한다. 선택한 경로만 같은 파일 시스템의 보조 디렉터리와 보조 TAFF 등록에 연결한다.

경로 우선순위는 **설정 CDDir → 게임 자료 폴더 → 기존 광학 장치 탐색**이다. 앞의 두 후보는 `CD.NETSTORM.TITANIC.ACTIVISION` 일반 파일이 있어야 선택한다. 잘못된 후보와 동명 디렉터리는 다음 후보로 넘어간다. 상대 CDDir은 게임 자료 폴더를 기준으로 해석하며, Unicode 경로는 UTF-8/W API로 보존한다. CD 삽입 안내나 대기, 온라인 검증은 추가하지 않았다. 이는 원본 CD 확인을 대신하는 클론의 호환 처리다.

공용 `StartupOptions::resolveCdDirectory`는 CD 클라이언트만 지정한다. 지정하지 않은 기존 10.78·독립 분석 호출자는 원래 시작 규칙을 유지한다. 빈 선택 결과는 기존처럼 InstallDir을 CDDir으로 사용한다. 기존 보조 아카이브 등록 목록을 유지하는 파일 시스템 계약은 바꾸지 않는다.

Release 통합 빌드가 종료 코드 0으로 완료됐다. `CdDirectory` 집중 4건(원본 15관측 포함)과 `ConfigInterface` 집중 11건이 모두 통과했다. 새 검사는 설정 우선·상대·한글/보충 문자·잘못된 표시 파일의 대체, 저장 설정·명령줄 우선·치환 시점·빈 결과의 대체를 확인한다.

실제 CD 사본 실행은 로컬 자료, 상대 한글 CDDir을 지정한 최소 설치 사본, 저장된 CDDir만 사용하는 재실행이 모두 자산 초기화를 지나 `RawBattleCompletion`의 Player/동맹/옵션 물리 검사에서 같은 오류로 종료했다. 최소 설치 사본에는 원본과 같은 NETSTORM.TARC와 D/setup.cfg만 있고 SHP는 외부 CDDir에만 있다. 잘못된 CDDir은 `Game file not found: d/_shapes.shp`로 종료하므로 설정 경로가 실제 파일 탐색에 연결됐음을 구별했다. **CD 메뉴 표시는 아직 미완료**다.

처음 만든 최소 설치 시험 자료는 D/setup.cfg를 빠뜨려 빈 팔레트 경로에서 실패했다. 그 원시 결과를 보존한 뒤 setup.cfg 사본을 추가하여 위 결과를 얻었다. 관측 스크립트의 콘솔 인코딩 오류도 UTF-8 실행으로 바로잡았고 제품 동작의 성공으로 세지 않았다. 원시는 `extracted/cpp-cd1072-1307/`에 있다. 보호 originalCD 전 파일의 실행 전후 SHA-256은 일치했으며, 10.78 일반 메뉴의 40프레임 대조 실행은 종료 코드 0이다. 사제 포획/희생·특정 적 공격·승리·MP·사용자 확인 검사는 실행하지 않았다.
