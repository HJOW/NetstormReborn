`DrawMappedShape`는 `0040229f`의 소스 색 치환을 기존 실제 SHP 해제/투명 마스크에 연결한다. 불투명 픽셀만 현재256바이트 표로 치환하고, 투명 건너뛰기와 소스 색0/255를 구분한다. `RawShapeToBuffer`는 현재 type/owner 색표 토큰이 있을 때만 실제 공급자에서 변환표를 읽는다. owner0은 원문처럼 plain으로 우회하며 색 번호0인 소유자의 mapped 표는 항등이다. 기존 plain 함수의 서명이나 기대 픽셀은 바꾸지 않았다.

`decomp_owner_capture.py`는 실제 색표 생성·TYPE/헤더 조회·캡처·색표 선택·plain/mapped RLE를 실행한다. new만 격리 메모리에 연결한다. 원래72DWORD 및 높은 비트/다른 후보, 타입/다리 특례의 **18고유 입력**으로9개 색표2304바이트 전체를 보존한다.
