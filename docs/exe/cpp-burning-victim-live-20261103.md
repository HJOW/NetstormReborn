# 연소 세 실제 소비자의 현재 SID·진단 연결

단위798은797에서 원문과 대조한 앞단을 실제 RawBurningFrame::Capture/Step과 RawBurningSources::Select에 연결한다. Capture는 기존 이미지/행/입자를 비운 뒤, Step은 capacity0/첫 캡처 단계 뒤에 조회한다. Sources와 Step의 이후 처리에는 통과 시 고정한 SID를 쓰며, Capture의 이후 이미지 요청은 원문처럼 그때의 현재 필드 SID를 읽는다. 진단이 복귀하면 기존 몸체를 계속한다.

BurningVictimState는 같은 Client checking DWORD 뷰·현재 상세 SID 조회·원문 진단 장치만 갖는다. 실제 Session은 기존 RawIsSidRobust 몸체를 CurrentSidRobust로 옮겨 연소와 이전 소비자가 같은 장기 Client의 최근 진단 DWORD 두 개를 사용하도록 했다. 이동한 기존 몸체는 들여쓰기를 제외하고 불변임을 대조했다. 이전 공중 소비자는 코드 연결만 유지했으며 공중 전용 검사는 실행하지 않는다.

실제 슬롯의 가상 표 비영/현재 TYPE의 HP 표식은 MakeBurningVictimHooks가 같은 풀에서 읽는다. Dais는 extra bit1, 일반 자산은 flags1 bit10이다. 독립 기본 checking0은 기존 RawIsSidRobust의 번호 판정 계약을 유지한다. 독립 checking이 비영인데 상세 장치를 주지 않았다면 선택한 상세 조회 지점에서 미연결 오류로 멈춘다. 실제 Client에는 같은 풀/전역/진단 owner를 사용하는 상세 장치를 항상 공급한다. CD의 기존 인라인 무진단 경로는 보존한다.
