## 본체 레이어

tail bit 2가 없으면 본체다. 부모 Gump가 없고 타입 flags2의 `0x100004`가 없으며 지정된 윤곽 제외 타입이 아니면 배치 영역의 윤곽을 그린다. legal 비영은 좋은 색, 0은 불법 배치 색을 사용한다.

그림 기준점은 raw 화면 XY에서 타입의 픽셀 hotspot을 뺀 값이다. **패치 프레임은 raw +36의 DWORD, CD는 +34의 BYTE**다. legal이면 타입별 소유자 표가 있고 signed 현재 플레이어가 양수일 때 현재 플레이어 색 표를 선택한 뒤 mapped 그림을 출력한다. 그 외는 원색이다. 지정한 특수 타입은 별도의 보조 타입 frame 0을 같은 기준점에서 추가로 그린다.

legal이 0이면 현재 선택 타입과 파괴 타입을 비교한다. 파괴 모드는 파괴 색 표를 선택한 뒤 mapped 출력, 나머지는 불법 배치 표를 해당 그림에만 적용한다. 원색과 명시 변환은 현재 mapped 문맥을 바꾸지 않는다.

## 보조 레이어

tail bit 2가 있으면 격자/문구 레이어다. 불법 배치·윤곽 가능·격자 옵션 bit 1 또는 글자 표시 상태일 때 raw 월드 위치를 **floor(x+0.5)**로 반올림하고 float로 저장한 뒤, ×16/11+0.5와 CRT 절삭으로 화면 기준을 만든다. 원본 타입 footprint와 분수 `<0.5` 판정으로 -1 또는 0부터 순회한다. 음수도 절삭으로 floor를 대신하지 않는다.

행을 먼저 순회하지만 판정 표의 주소는 **(열+1)×12+(행+1)**이다. 원본의 12×12 표와 최대 footprint 10을 사용한다. 각 칸은 배치 영역의 네 좌표를 독립 clamp한 뒤 체크 무늬 출력으로 전달한다. 비어 있거나 퇴화한 사각형도 원본 호출열에는 남는다. 실제 픽셀 출력은 오른쪽·아래쪽을 제외하고 절대 화면 좌표의 `(x^y)&1`이 1인 칸만 쓴다. 윤곽은 네 선으로 구현하여 클립 경계에 새 선을 만들지 않고 폭/높이 0의 원본 끝점도 보존한다.

부모 Gump가 있으면 격자 이후 글자·설명·비용 출력을 생략한다. 문자열은 MSVC signed char로 `'a'`와 비교한다. 소문자 이상은 별도 표시 상태가 켜져야 그리며, 숨긴 글자도 spacing만큼 y를 이동한다. 각 글자는 색 표를 선택한 +1/+1 그림과 원색 그림으로 두 번 출력한다. 바이트 → frame 표는 상위 자산 계층이 공급한다.

flags bit `0x20`과 override는 실패 사유 표시를 제어한다. 불법+blocked는 문구 2, 그 외 powered 0은 문구 3, 그 외 불법+reachable 0은 문구 4다. 타입 표시 폭·높이와 원본 측정 문구 크기를 각각 0쪽 정수 나누기로 반씩 나눈 뒤 가운데에 배치한다. flags bit `0x40`이면 비용 문자열 5와 별도 비용 이미지 frame 3을 footprint 가운데에 배치한다.

CD 디컴파일은 겹친 스택 지역 변수 때문에 보조 이미지/문구/비용 아이콘의 x·y가 뒤바뀐 것처럼 보였다. **실제 기계어 호출 인수와 독립 재생은 두 판본 모두 원래 화면 x·y를 사용함을 확인했다.** 디컴파일의 잘못된 표현을 새 동작으로 옮기지 않았다.

## 실제 출력과 계약

`PreviewPixelTarget`은 실제 `ShapeDatabase`·블록·frame을 받아 기존 VFX 해제/투명 합성 경로를 사용한다. 프레임 상대 사각형을 화면 기준점에 더하고 준비한 실제 256색 표로 치환한다. 표와 SHP는 출력 대상보다 오래 살아야 한다. 같은 프레임은 해제 결과를 캐시한다. 메타데이터 전용 프레임은 픽셀을 합성하지 않는다.

상위 계층은 실제 비용 이미지, 초기화한 색 표, signed 글자 frame 표, 번역/비트맵 글꼴 출력을 연결해야 한다. `text`는 원본 메시지 번호와 계산된 위치를 기존 계층에 전달하는 경계다. 전체 글꼴·번역 자산을 새로 만든 완료 범위는 아니다.

0/풀 밖/정렬되지 않은 대리 토큰, 타입/소유자 표/출력 콜백 부족, 실제 SHP 블록/frame 밖 접근, 표면/clip 부족을 사용하는 분기에서 거부한다. 원본 격자 크기를 넘는 footprint와 비유한/64비트 범위 밖 격자 좌표는 안전 계약으로 거부한다. 출력 콜백이 현재 footprint를 바꾸는 경우에도 각 격자 조회에서 실제 배열 경계를 확인한다. native 관찰은 finite 입력의 기본 x87 floor 경로이며 CRT의 모든 SSE/NaN 예외 분기를 복원했다는 근거가 아니다.
