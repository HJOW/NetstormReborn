## 변경

`RawCampaignSession`이 단일 raw 월드, Pool, 장부, 해시, Kernel과 기존 실제 설치·지형·소유권·사제·경로·총·투사체·피해·소리 모듈의 수명을 소유한다. 테스트 헤더에 의존하지 않는다. 보호 GameAssets의 전체 TYPE 자료를 사용하며, 기존 설치 검사에서 사용했던 TYPE74 변경을 적용하지 않는다.

실제 재시드 모듈에 Unix 초와 공유 CRT 상태를 공급한다. 효과음은 외부 클라이언트가 소유하는 단일 SoundList에서 이름으로 조회한다. TYPE 번호를 소리 토큰으로 대신하지 않는다. 누락된 큰 하위 서비스는 실제로 선택될 때 오류를 보고한다.

`GameWorld`에 실제 세션 생성자를 추가했다. 캠페인 객체 목록은 raw SID·현재 위치·프레임·HP를 읽는 화면 뷰다. 세션 경로에서는 기존 별도 객체의 보행 계산을 실행하지 않는다. 선택된 내 사제의 이동 명령은 같은 Graph/BFS/Host54를 사용한다. 프레임 처리, 변경 영역, 그림 자료도 같은 raw 월드를 읽는다.

## 검증 범위

새 검사4개는 production 소유자를 사용한다.

1. 보호 캠페인 1-1 설치, 같은 SID/위치, 그림 자료와 paused 프레임.
2. 보호 캠페인 1-2 설치와 같은 상태 조회.
3. 같은 Graph의 자유 칸으로 선택·좌클릭 입력 후 실제 Host54 생성, 이동과 화면 위치 동기화.
4. 명시 재배치한 1-1 사제의 실제 교전, 충돌 자산, HP1, 보호막 소리 프로세스, 총의 감시 해제와 잔여 투사체/충돌 효과 삭제.

장치·UI·송신·no-fencemark 표적점은 명시 검사 경계다. 이 관찰 콜백은 실제 GUI/음향/네트워크 구현으로 간주하지 않는다. 이번 새 직접 PE 실행 입력은0이며 이전 Native 관찰을 재합산하지 않는다.

생산 세션 교전의 첫 피해는 frame173, HP1은 frame178이었다. frame898까지 같은 Kernel을 실행한 뒤 감시/잔여 효과 종료 검사가 통과했다. 이 수치는 명시 재배치·Unix 초 입력과 검사 외부 경계의 결과이며 실제 GUI 캠페인 완주를 뜻하지 않는다.

최종 Release 경고/오류0, 집중4개 성공, 전체CTest 1/1·내부1,135개·실패 체크0(183.00초)다. 결과는 `cpppj/run25.json` 및 `extracted/run25-*.log`에 고정했다. 전체 소스/fixture/실행 파일과 정밀 export의 SHA를 `tools/check_campaign25.py finalize/verify`로 확인한다.

## 남은 작업

- `UberGump::BeginMission`의 Battle 거부는 유지되어 있다. 실제 창 제목·카메라·로컬 단독 송신·UI·음향·소유자 통지 서비스부터 연결해야 한다.
- raw 세션의9 Player 초기 기록은 현재 설치 전제다. 상위 Ready/login·미션의 돈/기술/동맹 입력 전체와 경제·생산은 아직 연결하지 않았다. GameWorld의 MissionPlayers UI 자료가 raw 게임 상태를 초기화하는 것은 아니다.
- 실제 fencemark 코너 선택, nonzero Burning/Dude 대피·다른 파생 삭제, 운반·의식·AI·Guide·승패 소비자가 남아 있다.
- 실제 표시 순서/깊이/선택 판정과 전체 GUI 그림·음향 동일성은 검증하지 않았다. Early Missions 및 1-1~1-2 플레이/완주 목표는 미완료다.
- DirectDraw 전체화면 오류 수정은 이번 목표에서 제외한다. dotnetpj와 보호 원본을 변경하지 않았으며 원격 push하지 않는다.
