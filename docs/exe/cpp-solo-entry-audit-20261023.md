## 검사 방법과 범위

`tools/cpp_solo_entry_smoke.py`는 읽기 전용 원본 `offical1~5.english`의 `$Checked=...,MissionBegin,...`에서 Early6·Priest Training9·캠페인16 목록을 읽는다. Demo3은 기존 원본 DEMOVILLE 라벨로 실제 메인 메뉴 → Demo → 항목을 누른다. 일반 미션은 CLI의 MissionBegin 후 현재 보고서에 존재하는 안내 버튼만 누르며, 내부 단계·시계·완료·SP·기술을 직접 쓰지 않는다.

이전 `cpp_goal_stage_entry_smoke.py`의 sequence1/즉시 재개 기대를 사용하지 않는다. 현재 원문 계약은 Init1 → 설치2 → Start3 → First4이며, 안내 종료 뒤 일곱 프레임 재개 관문이 있다. 새 도구는 정확한 현재 미션, Guide started1/sequence4, 실제 raw 월드, 비정지 Mission 단계, 로딩 부모 반납과 프로세스 정상 종료를 함께 요구한다. Demo3은 demo1과 로컬 AI 존재도 확인한다.

## 재시도와 관측 한계

Surrounded는 첫226프레임 계획에서65초 상한에 걸렸다. 마지막 기록은148프레임/비정지 Mission/진행 중 게임 시각56.306초다. 이를 정지나 게임 예외로 단정하지 않는다. 일반 진입 계획을98프레임으로 줄이고 동일한 최종 정상 종료·Mission·비정지·Guide·월드 조건으로 재검사하여 통과했다. 이 PC에서 해당 맵의 렌더링/전체 프레임 비용은 후속 성능 조사 대상으로 남긴다.

첫 훈련 도구는 실제 시작 라벨 `Lets do this!`를 처리하지 않아8개가 안내창에 남았다. 원본 스크립트에서 라벨을 확인하고 실제 버튼 조건을 추가했다. 재검사에서는8개가 통과하고 Fury War 하나만 남았다. Fury의 원소 선택은 Sun 분기만 시도했으며 다른 세 원소 분기를 검증했다고 확대하지 않는다.

첫 Demo 관측은1102프레임/루프16ms·상한65초였다. DemoStormRages와 GuardMyBack은 이미 비정지 플레이로 계속 진행한 뒤 상한 직전에서 종료되어 실패로 보존했다. 최종은602프레임/루프30ms로 최소18초 벽시계를 확보해 원본15초 안내 timeout을 기다리고, 전체 렌더링을 포함한 상한180초를 사용했다. 제품에 추가 대기시간이나 timeout 우회를 넣지 않았다. 세 항목 모두 최종 정상 종료와 실제 비정지 월드/로컬 AI를 통과했다.

## Fury War의 실제 잔여 문제

`bc8fury76`는 A.의 `Lets do this!` 뒤 @1에서 원소를 선택한다. 원본 `[S]`는 명령 전용 본문 `<$CheatAllTechnology,3>`이며 W/R/T도0/1/2를 사용한다. 최종 보고서는 @1/Briefing/정지1에 남고 stderr에 `스크립트 명령 미연결: CheatAllTechnology`를 기록한다. 재시도 횟수나 기본 성공값으로 이를 통과 처리하지 않았다.

보호 PE의 문자열 `00518d68`, 이름/전역 쌍 `00542cc8/00542ccc → 00542798`과 초기 DWORD를 확인했다. 명령 ID는 **02000028**, 일반 입력 분배기는 **00492ae0**을 호출한다. 같은 PC의 정밀 C는 `117801`행 부근이다.

00492ae0은 타입 순서대로 group(+9c)≠10, theme(+98)≠5이면서 선택 theme와 같은 항목을 찾는다. 현재 기술 부모를 조회하고 FindContained(mask4,type,index0)가 없을 때 다시 현재 부모를 조회해 실제 내용물 생성 `4afa70(parent,type,0,4,0x10,0)`을 호출한다. 일반 AddTechnology 목록으로 필터나 기존 내용물 확인 순서를 바꾸지 않는다.

후속은 이름/정수 큐 분배와 위 실제 기술 생성 경로를 구현하고, 명령 전용 Tell 본문과 기존 비 Instant 버튼 부모 종료 수명도 원본 c79b0에 대조한다. 현재 TryTell의 내용 없는 본문은 기존 안내를 교체하지 않는 경계이므로, 단순히 Cheat 이름을 등록하는 것만으로 선택 창의 종료까지 해결됐다고 보지 않는다. 원문 명령·관련 검사·실제 Fury 진입을 끝낸 뒤 나머지 원소와 사제 희생 뒤 같은 명령 경로도 확인해야 한다.
