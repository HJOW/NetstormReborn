# 1049 — 제외 방송의 실제 진단과 정상 복귀

10.78의4e2e80과10.72의4c0480은 server가0이면 단언 장치를 호출하고, 그 장치가 복귀하면 당시 로컬 번호를 저장한 뒤 후보1..8을 순회한다. 기존 RawBattleBroadcast는 곧바로 C++예외로 끝나 실제 Client 진단/정상 복귀가 생략됐다. 같은 장기 RawSurfaceStorage의 AssertDisplay를 Session 생성 시 연결하고 원문의 진단 뒤 진행을 복원했다.

진단 뒤 server를 다시 검사하지 않으며 localOwner는 진단이 끝난 뒤 한 번만 읽는다. 이후 각 후보는 현재 Player 접속 비트→제외 번호→보관한 로컬 번호→현재 연결 순서로 읽는다. 각 가상 송신이 다음 후보의 접속/연결을 바꾸는 기존 효과는 보존한다. 일반 방송4e2e30은 현재 localOwner를 각 후보에서 읽는 별도 계약이므로 바꾸지 않았다. 독립 부품에서 실제 진단 장치가 없으면 해당 분기에서만 명시 오류를 유지한다. 추가 생성자 인자에도 임시 DWORD 참조를 금지하는 삭제 오버로드를 유지했다.

직접 caller도 추적했다.4e2e80의 정밀 C 직접 호출자는 **004dc050 신전 섬 상승 수신** 한 곳이다. 채팅 중계가 아니다. 현재 제품에 SendExcept 실제 호출이 없어 이번 진단 연결만으로 서버 중계 완료라 할 수 없다.004dc050은 유효 신전 진단→섬 존재 조회→제거 플래그이면004dbce0→그 외 server일 때 제외 방송→Regular event3 생성→소유자별 번역 경고/음향 순서다.004dbce0은 실제 territory/현재 Fort 슬롯·스냅샷·섬 삭제·자산 정리/카메라·공통 재평가를 포함하므로 단순 DropIsland로 대체하지 않고 다음 단위에서 원문 부모를 연결한다. 신전 command004dbac0과 Descend/event4도 해당 메타 수명에 이어 남는다.
