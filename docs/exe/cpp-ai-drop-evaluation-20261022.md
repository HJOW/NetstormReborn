## 별도 지상 검색

`0046b540`은 명시 XY에서 실제 TYPE 발자국 절반을 뺀 float 중심과 방향0/프레임0/현재 owner의8DWORD 문맥을 만든다. `00422230`처럼 **float0.99999 보정→ftol→float 저장→다시ftol**한 중심과 절삭 사거리로 일반 finder5를 시작한다. 일반 Archer의0.9999 보정이나 일반 Gun 검색으로 대신하지 않는다. 최초 후보를 준비한 뒤 현재 자기 동맹을 검사하며 원본 진단이 반환하면 계속한다.

각 후보의 현재 flags1에10h가 있고 별도 `0046b360`을 통과할 때만 점수를 계산한다. 이 필터는 flags2의120000h(비행/벌룬)를 먼저 제외한다. 보행 운반체10000h는 명시 source TYPE가 현재 `00541178`(초기72)이면 제외하고, 그 외 **현재 Depend Form이 있으면 제외**한다. 일반 포획물/너겟 개수 검사가 아니다. 그 뒤 기존 실제 `RawGunTarget::MayTarget`으로 HP/서버 SID/동맹/extra/사제 수량/같은 위치/종류별 MayShoot를 검사한다.

Depend 검색은 현재 checking/metamap/dead 부모/boss 진단 뒤 **현재 head WORD(+6)**를 읽고, 현재 next WORD(+4)를 저장한 뒤 BYTE TYPE70이상인 자산을 건너뛴다. 나머지는 현재 `00541074` Depend TYPE(초기1)와 전체DWORD 비교의 첫 일치를 반환한다. free/dead 자식을 추가 배제하지 않는다. 실제 가상 표 `00508f14→00453740`의 명령은 `call004b1bd0 / ret4`다. 이 thunk는 기존 functions.tsv의 독립 항목이 없으므로 실제 가상 표 진입점/6바이트·해시를 별도로 기록했다.

거리 `00469440`은 현재 확장 발자국의 중심 방향에서 반대쪽 경계 중점을 구하고 source 중심과의 제곱거리를 반환한다. 초기 최고는 **float로 저장한 range²**다. 비교 전에 후보 거리를 float로 줄이지 않고 엄격히 작은 경우만 선택한 뒤 최고값을 float로 저장한다. 따라서 사거리 경계/등거리는 기존 첫 선택을 유지하며 Archer의 지상1000 페널티를 더하지 않는다. 이 별도 검색 자체에는 일반 Gun의 최종 표적 표시 요청이 없다.

## 부족 좌표와 마나 점수

`00412640`은 현재 ae0 count/ae4의12BYTE 기록을 순서대로 읽고 `abs(record.x-x)+abs(record.y-y)`를 계산한다. TYPE/capacity/cursor로 추가 필터하지 않으며 **정확한0거리와 NaN은 제외**한다.0에서 시작한 최고값보다 `1000-distance`가 엄격히 클 때만 index를 기록하고 값을 float로 저장해 다음 비교에 사용한다. 아무것도 선택하지 못하면 출력 index를 보존한다. 정밀 C의 void 반환 표기는 따르지 않았다. 원본 명령은 최고값을 x87 st0에 유지해 반환하며 실제 호출자가 이 값을 사용한다.

이 float 저장 위치를 평범한 최근접 검색으로 바꾸지 않았다. 예를 들어 원점에서 거리가0.000002인 첫 기록은 최고float1000을 저장할 수 있다. 그 뒤0.000001인 더 가까운 기록의 축소 전 점수도 저장된1000보다 작아 첫 기록을 유지한다. 비교용 축소 전 값과 저장용float를 구분한다.

`004126c0`은 이 최고값이 **1000-현재 마나반경×2보다 엄격히 클 때만** 실제 `RawEnergySupply::Collect`를 호출한다. 현재 probe TYPE `00541174`(초기71), 현재 owner260, theme-1, 초기 빈 문자열을 사용한다. 실제 공급이 갱신한 같은 selected 목록 효과도 유지한다. 공급 문자열은 첫NUL까지 센다. 길이가 비영이고 하위 효과 뒤 현재 signed ad8보다 작을 때만 **저장float 점수의 ftol/(길이+1)**을 반환한다. 빈 문자열/동률 길이/음수 한도는0이다.

## 시설별 분배와 실제 후보 승인

`00412ab0`은 먼저 현재 flags2와 group을 읽고 아래 우선순위로 단 한 경로를 선택한다.

| 조건 | 실제 평가 |

공급 평가는 표적 출력을 바꾸지 않는다. 지상/Gun 검색은 결과0도 출력하며, 비영 결과를 기록한 뒤 점수 하위를 호출한다. 낮은 점수/후속 승인 실패가 이 출력 효과를 되돌리지 않는다. 원본 `004105b0`의 b00 비영 출력 조건과 내부/외부 개행도 같은 실제 로그로 연결했다.

`00412b90`은 먼저 같은 전체 `MayPlaceGameplay`를 **argument0/flags0/현재 owner하위BYTE/mode1**으로 호출한다. 평가의 방향 인자를 배치 flags에 넣지 않는다. 통과하면 위 실제 평가를 수행하고 **기존 최고보다 크거나, 양수이면서 같은 점수**일 때만 에너지 승인으로 간다. 음수라도 기존 음수보다 개선이면 진행하며0/음수 동률은 진행하지 않는다.
