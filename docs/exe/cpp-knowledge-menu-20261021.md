# Review Knowledge의 실제 기술 카드와 메뉴 연결

단위253의 시작 커밋은 `bf68f0d4`다. 현재 PC와 마지막 정밀 디컴파일 PC는 **HJOW-Athlon / 2026-10-20**로 일치한다. AGENTS와 양 인수인계를 다시 읽었고 새 디컴파일·원본/CD·AGENTS 변경은 없다. 직전 턴은 Early 기술 허용 목록을 구현·기록·커밋한 진행 턴이다. 전체11미션 목표는 진행 중이다.

## 실제 전체 지식 창

원본 `ShowTechnology=020000a0`·`00492b60`의 카드 작성을 `RawKnowledgeMenu`에 옮겼다. 차단 모드가 아니면 실제 커서를 취소하고 현재 Player 기술 부모를 한 번 읽는다. 모든 타입에서 group10·사제 flags·템플 제품을 제외하고 실제 내용물을 조회한 뒤 theme0..3만 행으로 만든다. 마나 길이가0인 타입은 보유 내용물이 없어도 사용 가능하다. 원본 행 작성의 생산 포함 조회도 생략하지 않는다.

Factory가 사용하던 flags 우선순위/ASCII 설명 비교와 원본 CRT의 피벗·동률 교환을 `KnowledgeSort`로 옮겨 두 창에서 공유한다. `std::sort`의 다른 순서로 바꾸지 않는다. 기존 몸체를 시작 커밋과 역대조하며 유효 타입 범위 검사 외의 본문은 같은 내용이다. 기존 원본 Factory fixture와 검사 기대값은 바꾸지 않았다.

먼저 WIND/RAIN/THUN./SUN 머리를 만들고 정렬한 기술 카드를 네 줄에 누적한다. 보유 여부에 따라 원본 `#`/`&` 그림과 글자 enabled를 구별하고,제외 목록은 Excluded 줄을 쓴다. 긴 설명은 마지막 공백/하이픈에서 한 번만 나눈다. 원본 언어3에서는 일반 설명 두 줄을 비운다. 현재 언어 번호는 Client의 번역 표와 같다.

카드는 기존 BeginVertical/controlled AddTitle·AddText/StyleText/SHP와 실제 Gump 부착·폭/높이/Push·Pop을 사용한다. 현재 화면 크기와 원본 PE의 아이콘 치수65×60을 공급한다. 행별 정수 위치,1.1배 폭,목표 폭의 중간값,행별 누적을 원래 순서대로 계산한다. 작성 중에는 앞 카드의 popup bit를 끄고 마지막에 전부 켠다. 마지막 명령/80BYTE 빈 표식도 보존한다. 원본의 사용되지 않는 전체 경계 계산은 현재 위치 getter 호출을 유지하되 외부 기능으로 새로 쓰지 않는다.

## 실제 Session과 사용자 입력

실제 Session의 현재 Player/flags4 내용물/마나/Deck/건설 제외 목록을 같은 몸체에 연결했다. UI가 기술 보유나 정렬 정답을 공급하지 않는다. Review Knowledge 버튼·inline ShowTechnology·사제의 View Netstorm Knowledge는 같은 원본 명령 번호를 사용한다. 버튼은 기존 parser/40칸 입력 큐로 예약하고 일반 미션의 modifier 없는 F6도 같은 큐에 넣는다. 실제 PlayerKnown/메타맵·뗌 관문을 유지한다.

지식 카드는 공통 루트에 붙어 원래 브리핑을 유지한 채 위에 그려진다. 카드가 열리면 마우스는 실제 Gump 입력으로 전달하며 ESC는 같은 지연 popup 삭제를 요청한다. 별도 열림 bool 대신 실제 카드 노드의 등록/visible/dead/부모를 읽는다. 카드 popup bit는 기존 미션 재개 관문도 직접 사용한다. 월드 해제 전에 같은 메뉴를 닫는다.

카드의 `Help02000017` 상세 화면과 정적 themeHelp 인자 소비자,다른 팝업의 공용 마지막 표식·전체 키/중첩 모달 동작은 후속 작업이다. 기존 Help 명령을 임의의 간략 정보 화면으로 대체하지 않았다. 따라서 이번 연결만으로 지식/도움말의 전체 원본 동일성을 주장하지 않는다.
