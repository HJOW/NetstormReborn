# cpppj 메인 메뉴·캠페인·미션 진입 연결

2026-10-05. [실제 플레이 복원 계획](../cpp-playable-plan.md)의 **2단계 탐색 경로**를 연결했다. 이어서 [3단계 기본 월드/조작](cpp-world-reconstruction.md)으로 정적 미션 어댑터를 교체했다. `--run originals --window`에서 캠페인 선택→브리핑→지형/객체·사제 선택/이동→메뉴 복귀를 실행한다. **건설·채집·전투·AI·승패는 아직 없다.**

## 현재 동작

- 기본 실행: 원본 타이틀, 구름 타일, Campaign/Multiplayer/Demo/Help/Edit/Credits/Options/Quit. 돌 버튼은 호버 변화가 없고, 목록은 호버 강조와 누름 즉시 실행을 구분한다. 오른쪽 버튼·잠금 항목·밖에서 뗀 돌 버튼은 실행하지 않는다.
- 캠페인: 원본 `offical*.english`를 VFS에서 모으고 제목·정렬·구분 항목을 표시한다. `Done...` 값으로 완료/잠금 상태를 읽으며 클론이 임의로 완료 값을 쓰지 않는다. Back은 이전 목록/메인 메뉴로 돌아간다.
- 미션: 스크립트/요새에서 저장 위치를 쓰는 Tutorial 월드를 만들고 로딩→A. 브리핑을 표시한다. `Tell,A1.`/`Tell,A.`의 MORE/BACK, 정지/확인을 처리한다. 확인 뒤 GameWorld의 실제 입력·갱신·표시를 활성화한다. Battle/Normal의 영역 재배치는 미복원이다.
- 복귀: Game/ESC→Leave Battle→Stay 또는 Leave Honorably. 게임 시간을 정지/재개하고 입력 참조·커널 월드·미션 설정을 해제한 뒤 메인 메뉴로 돌아간다. 실제 전황·신뢰도에 따른 LeaveEarly/LeaveNormal 판정은 아직 없고 LeaveNormal을 사용한다.
- 옵션: 640×480·800×600·1024×768은 장치·Renderer·창 크기까지 변경한다. 소리·음량 등은 원본 키를 저장하고 재실행 시 읽는다. **오디오 출력과 가장자리 이동·자동 데모·시작 팁의 실제 기능은 아직 연결하지 않았다.** 전체화면/서버 진단은 비활성화한다.
- Help는 About, Credits는 원본 목록/본문, Demo는 원본 선택창까지만 연결한다. 멀티플레이/에디터는 원본 NotImplemented 본문을 표시한다. 데모 시작·기술 조회 등 미복원 명령은 해당 항목을 비활성화한다.

CD판은 `offical*.english`와 UCampaign이 없어 해당 메뉴의 완료 기준에 포함하지 않는다. 그 판본의 원본 Campaign 섹션으로 분기하며 GIF·기존 표시 기반의 회귀 자료로 쓴다. 기준 동작은 10.78이다.

## 검사

```powershell
cmake --build cpppj/build --config Release --parallel
ctest --test-dir cpppj/build --build-config Release --output-on-failure
python tools/cpp_menu_smoke.py
```

CTest 내부 **69개 검사** 중 메뉴의 7개는 돌 버튼 캡처·경계·포커스, 목록 누름/장면 교체, 조건/명령 인자, 다음 프레임 전환, GIF 인터레이스/투명/잘림, 배경 소유 수명과 화면 합성/출력 분리, 파일 목록 검색을 검사한다. 기존 두 판본 x86 기대값 **5,365개**는 유지한다. **새 메뉴 함수의 기계어 전수 대조를 추가한 것은 아니다.**

`cpp_menu_smoke.py`는 새 `NetstormCpp.exe`의 네이티브 창을 띄우고 `--ui-script`로 **InputQueue에 실제 버튼 좌표/누름/뗌 사건**을 넣는다. 명령 실행 함수를 직접 호출하지 않는다. 원본 게임 프로세스는 실행하지 않는다.

- 두 판본의 타이틀/구름 GIF 각각 **831,008픽셀**의 번호·투명을 Pillow와 비교한다. 큰 실제 GIF가 LZW 사전 폭 증가도 검사한다.
- 실제 1024×768 메인 메뉴의 버튼 영역을 제외한 **774,432픽셀**을 GIF 번호/게임 COL 팔레트의 독립 합성과 비교한다. 버튼 좌표·상태는 입력 보고서와 단위 검사로 확인한다. 원본 실행 화면 전체와 픽셀 비교한 것은 아니다.
- **54개 프레임 상태**에서 1-1 로드 **172개**, 튜토리얼 1 로드 **3개**의 요새 오브젝트 레코드와 브리핑/복귀 경로, 잠금/ESC/해상도/음량·마크·재실행 설정 유지를 검사한다. 레코드 수는 살아 있는 게임 객체 수와 구분한다.
- `extracted/cpp-menu-smoke/`에 BMP·프레임 상태·결과 JSON을 남긴다. 두 허용 설정 파일을 `finally`에서 복구하고 원본 폴더의 모든 파일 해시·존재 상태를 비교한다.

검사용 TSV는 `프레임번호<TAB>동작<TAB>라벨/파일경로`다. `click`·`right`·`down`·`up`·`esc`·`outside`·`report`·`snapshot`을 지원한다. 월드 단계에서 `key`/`keyup`·`world:priest`/`cell:x,y`도 추가했다. `phase`는 0 메인 메뉴, 1 Tell 대화상자, 2 로딩, 3 브리핑, 4 **실제 미션 월드**다. `--dump-gif`는 폭/높이 u32와 색 번호·투명 마스크를 출력한다. 이 인터페이스는 검사 도구이며 게임 제품 UI나 MCP가 아니다.

## 남은 연결점

**기본 월드/조작은 후속 연결했다.** [범위와 미완료 항목](cpp-world-reconstruction.md)을 참고한다. 실제 객체/지형 목록은 GameWorld가 제출하고 SceneImage는 정지한 대화상자 배경에만 사용한다. 다음은 다리·건설·덱·채집·전투·AI·승패다. 원본 미션 종류 객체·생성자/SID 전체·그림자·상황별 커서·요소별 애니메이션 복원도 계속 필요하다.

UI에도 전체 StyleText의 색 제어·본문 폭/스타일 흐름·이미지/링크/스크롤, Help 전체, 기술 조회·입력창·단축키·인라인 스크립트 명령·OnExit, 정확한 조건 길이 제한, 오른쪽에 부모를 유지하는 하위 메뉴·구분선·세부 위치, 구름 시차/애니메이션·효과음이 남았다. 긴 본문은 현재 패널 경계에서 잘리며 전체 Credits/Help 탐색 완료가 아니다. 기본 메뉴 탐색이 된 것을 원본 UI/State/Mission 전체 또는 플레이 완료로 표시하지 않는다.
