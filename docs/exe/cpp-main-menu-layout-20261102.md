2026-11-02, HJOW-Athlon. 마지막 전체 정밀 디컴파일은 같은 PC의 2026-10-23 자료다. 단위697의 Help/Options 팝업 연결을 유지하고 메인 버튼의 표시/클릭 경계를 원문 배치로 바꿨다.

## 차이와 복원

기존 메인 버튼은 고정 폭75·높이20으로 `SCREENH/2-73`, 두 번째 행은 그 아래23에 배치했다. 이 y는 1024×768에서 원문과 우연히 같지만 다른 해상도에서는 다르다. 원문 `004ce940`은 모든 실제 Stone 버튼을 `00424f90`으로 측정하고 최대 폭으로 통일한 뒤, 첫4개와 나머지의 두 행을 각각 가운데에 둔다. y는 **signed SCREENH/3+55**, **+78**이다.

`RawButtonControls::LayoutMainMenuControls`가 실제 Stone의 FitToText·공통 폭·Attach를 사용하고 그 결과 Bounds를 같은 `GumpControl`에 되쓴다. 따라서 그림과 라벨 클릭 조회가 같은 위치를 사용한다. 기존 원문 메인 가족 깊이(-83/배경-82)를 보존한다. 현재 호스트가 이미 임시 부착한 버튼은 재배치 전에 공통 Push로 형제 링크를 해제한다. 원문 전체 메인 부모의 처음 미부착 자식과 다른 이 어댑터 경계를 주석에 명시했다. CD 호스트의 배치는 변경하지 않았다.
