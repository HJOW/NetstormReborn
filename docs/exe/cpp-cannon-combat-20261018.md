# 캐논 실제 포구와 제네레이터 연장 전투 관측 — 단위185

현재 PC와 마지막 정밀 디컴파일은 **HJOW-Athlon / 2026-10-16**이다. 기준32f66434에서 AGENTS와 양 인계를 다시 읽었다. 사용자의 창 실행·테스트 재개 요청에 따라 단위183의 보류를 해제했다. 새 디컴파일·보호 원본/AGENTS/DN 수정·원격 push는 없다. 원본 전체화면 DirectDraw는 계속 제외한다.

캠페인1-1에서 제네레이터 없이 신전 주변에 캐논을 지을 수는 있지만 적을 타격할 공급 범위는 없다는 사용자 관측을 전제로 진행했다. 실제 세션의 반경제곱196을 유지했다. 레인 제네레이터(TYPE76)를 실제 연구·생산·배치하고 자연 완공한 뒤 그 공급으로 다음 제네레이터를 건설했다. HP·비용·소유자·공급 범위·발자국 규칙은 우회하지 않았다.

## 발견과 수정

두 제네레이터99,109와112,108을 완공하고 캐논118,115를 지은 첫 창 관측에서는 실제 발사까지 진행했지만 적 HP가 줄지 않았다. 포구를 읽는 탄체 경로와 표적 탐색용 사정선이 달랐다. `RawGunTarget::CannonRay`는 화면 기준점을 사용했지만 실제00469190은 SHP+0x20/+0x22의 signed short 포구를 사용한다. 예를 들어 실제 프레임3의 화면 기준점은47,38이고 포구는-1,-25다. TYPE128의 별도 타입 기준점은0,6이다.

`SquidDisplayFrame`에 포구 두 필드를 분리하고 같은 실제36바이트 SHP 헤더에서 로드한다. 화면·월드 기준점의 의미는 유지한다. `CannonRay`만 포구 필드로 계산하도록 고쳤다. 기존 합성 native 검사 어댑터도 원본+0x20/+0x22 입력을 새 필드에 전달하며 기존 기대 fixture는 수정하지 않았다.

수정 전에 실제 PE00469190과 호출 helper/getter/CRT, 보호SHP의 전체 헤더로 새 독립 관측을 동결했다. 6위치×8방향의 **48입력·96정상 반환·29,042명령**, x87 두 정밀도 차이0이다. 새 자산 회귀 검사는 실제 GameAssets와 같은 로더를 사용해 전체48행의4DWORD를 대조한다. 이전 GunTarget 관측기가 참조하는 미존재 `extracted/pathmath` 파일을 복구한 것으로 세지 않는다.

## 실제 테스트와 한계

최종 집중 검사는 GunTarget5개와 LocalLogin4개 모두 실패0이다. 새 `CampaignSession_LocalLoginGeneratorExtendsCannonFirstHit`는 실제 로그인/시작SP3000·워크샾·연구·제네레이터 두 개의 자연 완공·전방 캐논118,118 허용/생성/자연 완공을 거쳐 적15010(TYPE71)의 HP300→276까지 진행한다. 실제 탄체80, 표적·발사 단계, 여러 캐논 그림과 SP1000도 확인한다. **이 검사의 범위는 첫 적중까지다.**

같은 위치의 수정 후 전체 창 테스트는 적 HP **300→276→192**를 관측한 뒤 실패했다. HP 절반 미만에서 필요한 `hitEffects.burning.create`가 `RawCampaignSession.cpp`의 명시 미연결 소비자여서 중단됐다. 마지막 보존 보고는combat3370이다. 이 창에서 완공 캐논 그림은3만 관측됐으므로 회전을 확인했다고 주장하지 않는다. 두 제네레이터700/캐논600·실제 피해는 확인했으나 전체 전투 종료·적 파괴·자연 미션 완주는 **미통과**다. 실패한 전체 검사를 첫 적중 통과로 대체해 완료 판정하지 않는다.

UI 스크립트에 `require`를 추가했다. 직전 완성 프레임의 실제 보고가 조건을 만족해야 다음 입력으로 진행한다. 배치 전에는 최종legal(`raw_cursor[1]`), 배치 뒤에는 실제 SP·건물 좌표·HP를 확인한다. 실패하면 보고와 실패 화면을 보존한다. 의도적 거부 검사는 다음 입력이 실행되지 않음을 확인했다. 일반 실행 중 예외에도 누적 보고를 저장한다. 전투 도구는 실패 시 반환값·오류·마지막 보고를 별도 요약으로 남기며, 이미 적 방향을 향한 캐논에 불필요한 회전을 요구하지 않는다.

수정 전 피해0 로그·포구 진단·수정 후 저HP 실패·첫 적중 회귀 통과를 `extracted/goal-cannon-combat-20261018-*`에 각각 보존한다. `gui2-smoke.py`는 당시 창 실행 도구 사본이고, 이후 도구의 실패 요약 보강과 구별한다. 현재 핀56보고서76개만 갱신하고 과거 값/이력·기존397fixture는 보존한다. 감사111종은100통과/기존11실패동일/새0이다.

전체 CTest는 **1,683개 중 실패3개/220.81초**다. 포구 수정 후 도달한 `CampaignKernelFrames_Tutorial5`의 공격131→표적123 가상 총 피해, `CampaignKernelFrames_DissolvedAlliance`와 `CampaignThunderMissile_DissolvedAllianceNaturalShot`의 파생 방어가 미연결이다. 기존 검사를 삭제하거나 시간을 줄이지 않았으며 이 결과를 통과로 세지 않는다. 실제 첫 적중 수정이 다른 미완성 전투 경로도 드러낸 상태다. 목표11단계 실제 창 진입 결과 및 파일 SHA는 [기계 판독 기록](../../cpppj/campaign-cannon-combat.json)에 기록한다. 진입 검사는 이400프레임 검사나 플레이 완주의 통과를 뜻하지 않는다.
