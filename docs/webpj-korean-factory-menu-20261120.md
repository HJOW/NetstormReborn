# 워크샾 생산 메뉴 한국어 (WB04-E1080)

워크샾의 현재 생산, 지식, 남은 칸, 업그레이드 및 공통 회수 비용·획득 문구를 번역했다. Tutorial2 생산 안내의 메뉴 이름과 썬 디스크 발사기 명칭을 실제 선택지와 일치시켰다. 원본의 서식 인자·그림 명령·끝 줄바꿈과 튜토리얼 단계·명령·그림은 유지했다.
