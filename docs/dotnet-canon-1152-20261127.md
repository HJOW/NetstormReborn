# 1.152 공통 효과의 월드 출력

월드 수집기에 같은 세션 `RenderProcessSystem`의 kind 3 목록을 원본 순서로 연결했다. 제품 제출은 같은 `HostMissionBurning`의 건설·연소·파편 장치로 토큰을 그리며, 현재 dirty 클립을 설정한 뒤 예외가 나도 기존 화면 클립을 복원한다. 효과 장치가 없는 비제품 검사에서 실제 효과가 선택되면 명시 실패한다.

실제 자산과 공장 건설 표시를 생성해 같은 세션에서 수집·제출하고, 단일 픽셀 클립과 이전 클립 복원을 검사했다. 관련 건설·진행 집중 검사는 10/10 통과했다. 창 없이 생성한 실제 건설 프로세스의 통합 검사이며 게임 내 건설 조작이나 CPP 효과 픽셀 일치의 증거는 아니다.

독립 빌드로 캠페인1-1의 미니맵 드래그 75/81/89/95/105프레임을 실행한 결과 모두 종료0이고 1.148 화면과 동일하다. 튜토리얼1과 surrounded의 진입·대기 역시 종료0이고 90프레임 월드 덤프가 기존과 같다. 두 수집에서 원본 1,392파일은 불변이다. `extracted/dotnet-effects-1152-first/`와 `extracted/dotnet-effects-1152-missions/`에 결과가 있다. 실제 게임 건설·연소·파편의 출력과 CPP 비교, 전체 회귀는 후속이다.
