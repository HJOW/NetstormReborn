# WB04-E850 Dude 실제 경로 속도와 도착

기준선 `225553df`의 cpppj `CampaignDude_ActualPathNoticeSpeedAndArrival`을 웹 실제 Session 검사로 이어갔다. TheWarBegins의 실제 표면·공간 해시에서 연속된 통행 가능 칸을 찾아 Dude의 느린 경로를 만들고, 같은 목적지 재요청이 그 경로를 보존하는지 확인한다. 이어 기존 경로를 종료하고 빠른 경로의 점·방향과 각 직진 구간 시간표를 비교한다. 최초 TYPE 속도 1.5와 정수 복원 뒤 빠른 속도 2의 원본 차이를 보존한다.

원본 검사처럼 명시적인 task·Regular를 설정하고 실제 경로 프로세스만 시각에 따라 전진해 도착 시 경로와 Dude가 삭제되는지 검사했다. 집중 검사 1건과 Node v26.13.0 전체 6,364건이 통과했다(실패·취소·건너뜀 0). 이는 격리된 경로 수명이므로 전체 Kernel·브라우저 플레이의 자연 생성/대피 검증은 남는다. 원본 게임 창은 실행하지 않았다.
