# webpj 더스트 데빌 전용 비행 RawWindFlyer (WB04-E358, 2026-11-13, 7-P1 비행 유닛 부품 마감)

3.1절 7-P1 마지막 항목 "RawWindFlyer 132줄"(기준선 `.h` 41 + `.cpp` 89 = 130줄 근처, 대응표 줄 수 132)을 `core/raw-wind-flyer.js` 로 옮겼다. 더스트 데빌(138)의 전용 초기화(45e230)·애니메이션(45c020)·주기 처리(45e8b0)·한 칸 범위 피해(45e9a0)를 담고, 전용 표 쓰기(45e1c0)는 E352 의 `specializeWind` 를 재사용한다. 이로써 **7-P1 비행 유닛 부품 7개가 모두 끝났다**(RawFlyerProcess E352·RawSunAviaryProcess E353·RawRainAviaryProcess E354·RawFlyerFrame E355·RawFlyerTarget E356·RawSunFlyerFrame E357·RawWindFlyer E358).

## 1. 규칙

- **구성:** `new RawWindFlyer(pool, hash, types, soundFrames, activeSounds, globals, hooks)` — 풀은 PATCH, 공간 해시는 `SquidHash`, TYPE 표(`{ footX, footY, flags2 }`)는 188칸의 **살아 있는 참조**(후보의 현재 genus 를 읽음), 소리 장부(타입별 마지막 재생 프레임)와 activeSound 표는 길이 188 이다. 전역 세 개(`now`·`boss`·`frame`)는 현재 값을 읽는 함수이고, 훅은 `runCount`·`assertion`·`damageable`·`destroy`·`sound`·`mayTarget`·`damageRate`·`damage`·`weaken` 이다. 선택하지 않은 경계는 요구하지 않고 선택된 누락은 앞선 효과를 남긴 채 거부한다.
- **`specialize` / `initialize`:** 전용 표·inner VT·타이머 96·단계 84 만 쓰고(`specializeWind` 와 같은 쓰기), 초기화는 애니메이션 타이머 96 = now·공격/착륙 0·초기화 표식 1·최초 20초 타이머(72) = now + 20 이다.
- **`animation` (45c020):** 부모(`fields.parent`)를 읽을 때마다 종속 head(+6, +7)가 둘 다 0 이면 진단 0xa4 를 낸다(반환 뒤에도 다시 읽는다). 부모가 정지(+40 의 0x20)이거나 애니메이션 기한(96)이 아직이면 현재 프레임(부호 있는 값)을 돌려주고, 기한이 되면 기한 = now + 0.07999999821186066 을 쓰고 `(프레임 + 1) % 글자 수`(부호 있는 나머지; 글자 수 0, INT_MIN / −1 은 거부; −0 은 0)를 돌려준다.
- **`handle` (45e8b0):** 사건이 0 이 아니면 공통 피해 훅의 반환을 그대로 쓴다. 사건 0: 횟수(부호 있는 값) < 80 이면 주기가 0.25 가 아닐 때 진단 0x19e 를 내고 주기 0.25 로 범위 피해, 80 이상이면 boss 일 때 삭제(−1 반환). 횟수가 40 의 배수이면 현재 TYPE 의 소리 장부가 현재 프레임과 다를 때만 장부를 현재 프레임으로 쓰고 소리(현재 위치, activeSound)를 낸다. 정상 반환 0.25.
- **`attack` (45e9a0):** 현재 위치를 `cell(v) = 절삭(float(절삭(v + float 0.9999899864196777)))` 로 칸으로 바꿔 칸 하나의 사각형(반경 0·flags 0)으로 일반 finder 를 돌려 후보를 모두 모은다(최대 10개: 발사 가능이고 flags2 에 0x120000 이 없는 후보, 또 flags2 비트 4 인 후보 — 두 조건을 모두 만족하면 두 번 저장). 그 뒤 각 후보의 **현재** free 비트가 서 있으면 건너뛰고, flags2 비트 4 이면 약화, 아니면 `피해율(공격자, 대상)` 을 정수 절삭한 `rate × period` 와 공격자의 현재 owner 로 피해를 준다. 정수 절삭(`truncate`)은 signed64 범위 밖이나 NaN 이면 0, 범위 안은 하위 DWORD(int32)이다.

## 2. 웹 범위와 기준선 뒤 변경

- 10.72(CD)는 범위 밖이다(PATCH 188칸만 받는다). 이 파일은 기준선 뒤 변경이 없다(마지막 변경 `edc257f9a 20261022-62 CP` 가 기준선 안; PORT_MAP base `edc257f9`).
- 칸 계산의 float 저장 단계는 정수가 2^24 를 넘을 때만 값이 달라지며, 그 값은 일반 finder 의 사각형이 보드 밖이라 후보가 없다. 표 밖 TYPE 번호는 거부한다. 훅 구현(글자 수·공통 피해·삭제·소리·발사 가능·피해율·피해·약화)은 후속 단계 조립 몫이다. 이 모듈은 DOM 을 쓰지 않는다.

## 4. 변형 확인과 남은 경계

- 한 문자열 치환 변형 116회를 적용했다. 1차에서 18개가 남았고 그중 12개는 **시험의 공백**이라 보강해 잡았다. 원본 관측 334행이 쓰는 입력이 좁아(후보 세 개·위치 50 근처·낮은 DWORD 가 0 인 값·40 의 배수 몇 개) 위의 웹 계약 항목들이 가려져 있었다. 칸 계산의 float 상수는 1 미만 입력에서, 정수 절삭 범위는 낮은 DWORD 가 0 이 아닌 9.3e18 근처 입력에서 갈린다.
- 남은 동등 변형 6개: `truncate` 의 정확한 경계 `−2^63`/`2^63` 두 변형(두 값의 하위 DWORD 가 0 이라 범위 안으로 넣어도 같은 0)·칸 계산의 float 저장 단계 세 변형(정수가 2^24 를 넘을 때만 값이 달라지는데 그때는 finder 사각형이 보드 밖이라 후보가 없다)·나머지의 `Math.abs(count)`(JS 나머지는 피제수의 부호를 따라 같다)이다.

- 변형하지 않은 방어선: 생성자·훅 누락·범위 오류 메시지 문구.
- 앱 수명 연결(글자 수·공통 피해·삭제·소리·발사 가능·피해율·피해·약화 훅 구현)은 후속 단계 조립 몫이다. 7-P1 은 이 항목으로 마감되며 다음 후보는 **7-P2 총·투사체 부품**(RawGunProcess 423줄 +33 외)이다.
