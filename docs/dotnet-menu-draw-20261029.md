## 1. 구현

MenuGumpDraw는 자체 경계 클립→실제 기본 배경→저장 Position→현재 항목별 출력→클립 복구 순서를 사용한다. compact/세로/가로의 선택 강조 rect는 float32 인자 저장과 CRT 절삭을 보존한다. Rect의 bottom Y만 패치에서 float32로 좁히며 CD는 원래 정수를 double로 확장한다. C# 조건식의 공통형 추론으로 CD도 float가 되지 않도록 두 분기를 명시 double로 썼다.

세로 구분선은 두1픽셀 명암 배경이며 pass마다 현재 전역 타입/프레임을 재조회하고 클립을 개별 복구한다. 체크 그림→현재 flags/크기의 글자→현재 항목 측정 뒤 하위 표시 순서를 유지한다. 현재 개수는 매 반복 끝에 다시 읽는다. 일반 항목은 실제60바이트/NUL과 임시 문맥을 사용하고 스타일 항목은 소유 조각의 저장 문맥으로 출력한다. 비활성 임시 색/스타일을 저장 조각에 덮어쓰지 않는다. 하위 ` >` 표시는 같은 실제 글꼴과 DrawGump의 현재 Position을 사용한다. 가로 분기는 체크/구분선/하위 표시를 별도로 출력하지 않는다.

현재 메뉴의 실제 Draw 분배와 체크 그림의 **J 첫 프레임+2**를 같은 장식 원색 SHP 캐시에 연결했다. 기존 cpppj의 I 구간 개수 오인 수정도 그대로 반영했다. 전체 GameAssets가 아직 이식되지 않아 현재 J 첫 프레임의 조회자를 명시 외부 경계로 받는다. 실제 전체 타입/자산 소유 조립은 후속이며 임의 기본 프레임으로 대체하지 않는다.
