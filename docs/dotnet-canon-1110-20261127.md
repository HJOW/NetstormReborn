# dotnetpj 1.110 — 정기 전체 회귀

2026-11-27, HJOW-Athlon. 1.109 제품을 기준으로 세 테스트 프로젝트의 Release 출력을 다시 빌드하고, 각 검사 출력에 존재하는 Assets/Core/Client/Game DLL을 실제 게임 폴더의 해당 DLL과 SHA-256으로 비교했다. 비교 가능한 DLL은 모두 같았다.

- Assets 383건, Core 4,121건, Client 2,901건이 통과했고 실패는 없다. 합계 **7,405건 통과**다.
- Client TRX의 `WindowsSoundHardwareTests.MutedNativeDeviceLoadsDuplicatesAndRestoresAfterReinitialize` 1건은 **NotExecuted**다. 콘솔의 건너뜀 0과 달리 이 하드웨어 검사를 통과한 것으로 세지 않는다. 결과는 `extracted/dotnet-1110-regression/`에 있다.
- 게임을 새로 실행하거나 전체 34경로를 재측정하지 않았다. 1.109의 대표 세 미션 실행·원본 보존 결과와 M1 0/34 기준은 그대로다.

다음은 기존 생산 동기화 본체를 제품 패널에 연결하고 실제 생산 사건의 두 격자 부착 및 일반 자산 삭제 통지를 검증한다. 내용물 정렬 본체 통합, 사제 포획 안내, 미니맵 남은 픽셀·전환 수명과 채팅 실제 키 입력은 미완료다.
