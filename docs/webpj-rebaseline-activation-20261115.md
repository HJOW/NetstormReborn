# 제품 1313 이식 기준선과 오라클 전환 (WB04-E513)

웹 이식 기준선을 제품 985 `1f00a25a`에서 제품 1313 `225553df`로 바꿨다.
후보와 cpppj 마지막 변경 `979d65b5d`의 `cpppj/src` 내용은 같다. E497에서
별도 VS2022 빌드로 수집한 M1 8장면을 기본 오라클로 쓰며, Campaign·Options의
기록된 변경 영역과 구름 차이 밖에서는 픽셀 차이가 없다. 실제 미션 화면과
플레이는 이 검사 범위가 아니다.

기준선 단위 집합을 비교해 이전 984개 중 삭제되거나 대표 파일이 바뀐 단위가
없음을 확인했다. 대응표 재생성 전후 비교에서 기존 984행의 분류·웹 경로·
`base`·상태·사람 메모는 모두 같고 신규 176행만 추가됐다. 신규 분류와 근거는
[E512](webpj-rebaseline-rules-20261115.md)와 E498~E502에 있으며, 이 중
100개 port와 7개 adapt는 모두 `todo`다. 전체는 1,160행, 이식 대상 1,004행,
제외 156행이다. 기존 ③ 판정은 해당 기능이 구현된 뜻이 아니며 이후 단계의
실제 연결과 검증에 남는다. 기존 행 메모의 '대응표 밖'은 메모를 작성한 당시
상태를 뜻하며, E513에서 등록된 새 단위에도 그 과거 기록을 그대로 보존한다.
신규 107행은 보수적으로 `todo`로 등록했다. 이름이 같은 웹 모듈이 이미 있는
9행은 소스·검사·실제 범위를 대조한 뒤 개별 상태를 판정해야 한다. 같은 이름만으로
완료로 세지 않는다(`ClientHelpWord`, `ClientTimeSource`, `SystemNewsTime`,
`RawClockSynchronization`, `RawDaisDeletion`, `RawFactoryRegular`, `RawPacketCopy`,
`RawResidenceRegular`, `RawRitualRegular`).

기본 오라클 경로와 수집·비교 도구의 기본값을 제품 1313 자료로 전환했다.
제품 985의 메타·시나리오·각 캡처와 보고서는 그대로 두고 해시를 검사한다.
manifest에는 새 자료의 실제 검사 소비자만 추가했다. 기존 fixture의
`cpppjBasis`는 웹 모듈 구현 당시의 소스 이력을 뜻하므로 일괄 갱신하지 않았고,
기존 대응표의 `base`도 보존했다.

집중 검사에서 신·구 오라클과 대응표 11건이 통과했고, 대응표 검사는
1,160행·오류 0·미판정 ②/③ 0이다. Node 22·24·26 전체 회귀 검사를
수행했다. 다음 작업은 기존 4-D 선행 조건과 E498~E502에 기록한 새 단위의
이식·연결이며, Session 조립과 미션 진입은 아직 남아 있다.
