# dotnetpj 0.814 — 첫 장치 설치 경계와 장기 Surface 상태 공유

작업일: 2026-11-22. 현재 PC: HJOW-Athlon. 제품 실행 경로는 `dotnetpj/src/Netstorm.Game/bin/Release/net10.0/Netstorm.exe` 하나다. 이전 경로 정리(0.807)를 유지한다.

## 구현 범위

`ClientSurfaceGlobals`는 같은 Clock의 실제 LocalState/Gameplay를 확인하고 Storage·Checking·선택적 Native 전송을 준비한 뒤 `installDevices`를 실행한다. Graph 시계와 Process/Kernel/Frame은 그 뒤에 연결한다. 콜백에서 현재 시각·선택·전송을 선행 실행하지 않으며 예외가 나면 설치한 접두는 남기되 뒤의 Process 저장소를 만들지 않는다. 기존 생성자 호출은 선택적 인자가 생략된 계약을 유지한다. 설치 콜백 자체가 전체 Native Root 설치 완료를 뜻하지 않는다.

일반 Root는 실제 SP 초기화를 Surface 생성보다 먼저 수행한다. 첫 Process 전에 같은 장기 Template의 `FortSerializationGlobals`와 실제 오류 진단을 설치한다. SP 재시드 횟수나 미션별 재시드를 추가하지 않는다. 같은 `ClientSurfaceGlobals`를 HostSession의 `sharedSurface`에 공급한다.

Host는 같은 Pool·장부·TotalMade·SID 목록·Graph 물리·OwnerMode·BridgeState·로딩 깊이를 빌린다. 명시된 Kernel/Gameplay/Pool/목록/Process/Frame.game/LocalState/Connection owner와 Template 깊이가 다르면 Player 고정뷰 초기화보다 먼저 거부한다. 공유 시각과 로컬 상태 인자가 생략되면 같은 Surface Clock의 실제 owner를 사용한다. 공유 생성자는 Graph/집계/모드/깊이를 초기화하지 않는다. 준비 대여·반납·재대여도 같은 상태를 보존한다.

공유 Graph는 `storage.GraphExecutor()` 한 개다. 별도 실행기/표를 만든 뒤 덤프에 복사하는 경로를 제거했고 같은 장기 진단·시계·전체 풀 복구 정책을 유지한다. 명시 TYPE·셰이프·공장·공간 인자가 실제 Storage 소유자와 다르면 섞지 않는다. 독립 typed 조합은 종전 지역 Graph와 복사 덤프 계약을 유지한다.

Native 장치가 설치된 공유 Host는 `storage.BaseDestroy()`의 실제 pre/post 깊이를 사용한다. 독립 typed는 원문 `RawSurfaceWorld.cpp192`처럼 지역 삭제 본체를 유지한다. 기존 `BindWorldDeletion`의 DestroyBody 동일성 검사를 풀지 않았다. 실제 전체83VT 분배기를 새로 조립하거나 일부 테스트용 VT 묶음을 제품에 복사하지 않았다.

Host의 로딩 깊이 조회/쓰기와 섬 후처리·Template 소비자는 같은 현재 `Storage.LoadingDepthBox`를 사용한다. `TotalCost` 공개 관측은 `CurrentTotalCost`로 같은 `GameAux.TotalCostBox`를 읽고 쓴다. 기존 독립 조합은 자체 상자/비용을 유지한다.

일반 미션의 종전 새 Host 기본값 중 Graph 표 초기화·집계 세 표·공통 깊이/비용/생산 알림·전투 모드는 명시 일반 미션 부모로 옮겼다. 준비 대여나 Host 생성자에서 실행하지 않는다. 기존 Runtime 또는 Surface가 대여 중이면 이 초기화 전에 거부한다. 이는 기존 일반 진입 호환 준비이며 전체 Native 로그인 prefix 복원을 완료한 것이 아니다.
