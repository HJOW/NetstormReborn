# WB04-E862 브라우저 실행 오류 보고

웹 앱 초기화, 필수 자산·준비 훅의 비동기 적재, 프레임과 앱이 등록한 입력·가시성 이벤트에서 발생한 예외를 공통 콘솔 보고에 연결했다. 단계, 앱 상태, UTC 시각과 상황별 적재 세대·프레임 시각·이벤트 종류를 남기고 원본 예외 객체를 함께 전달해 스택과 원인을 확인할 수 있다. 콘솔이 실패해도 원래 오류를 가리지 않는다.

초기화·프레임·이벤트 예외는 기존처럼 호출자 또는 브라우저로 다시 전달하고, 적재 오류는 기존 오류 화면과 재시도 흐름을 유지한다. 취소된 이전 적재 세대의 실패는 보고하지 않는다. 전역 오류 리스너는 설치하지 않아 호스트 페이지의 다른 스크립트까지 가로채지 않는다.

집중 검사 6건은 초기화·적재·이전 세대 취소·프레임·입력과 콘솔 자체 실패를 검증한다. Node v26.13.0 전체 회귀 6,386건은 실패·취소·건너뜀 없이 통과했고 대응표 검사도 오류 0이다. 실제 Client·Session의 브라우저 수명, ResizeObserver 등 별도 비동기 경계, 아직 연결되지 않은 게임 코드의 예외 보고와 브라우저 실기 검증은 남아 있다. 원본 게임 창은 실행하지 않았다.
