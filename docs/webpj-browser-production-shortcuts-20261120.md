# 브라우저 생산 단축키 (WB04-E1006)

Q/W/A/S/Z/Y/X/E 문자 키를 기존 원본 사용자 입력과 같은 FIFO 큐에 넣고, 원본 생산 슬롯 명령을 Guide와 Gump 다음에 처리한다. 현재 template owner의 실제 Player 기술 SID를 읽어 같은 내용물 검색기로 0x40 플래그와 슬롯 번호가 일치하는 첫 다리를 선택하고 실제 커서와 소리를 호출한다. 활성 커서의 Escape 취소도 브라우저 문자 입력으로 연결했다. UI가 명령을 먼저 소비하면 중복 처리하지 않는다.

기존 원본 생산 키 관측과 앱 Node 검사 6건이 통과했다. Chromium에서 실제 Tutorial1 자동 생산 후 Q로 다리를 집고 미리보기 프레임을 그린 뒤 Escape로 돌려놓는 흐름이 통과했다. W/A/S/Z/Y/X/E의 실제 브라우저 검증, 생산 패널과 다리 배치는 남았다. E994 고정 Node 26 전체 회귀 6,558건이 통과했으며 E998 고정 Node 26 전체 회귀는 실행 중이다.
