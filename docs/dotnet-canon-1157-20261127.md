# 1.157 객체 정보 작성 본체

`RawObjectMenuInfo`의 10.78 정보 설명, 원소·레벨 이름, 객체 요약과 포획 상태를 이식했다. 네 인자와 현재 TYPE·소유자·편집 상태를 원본 위치에서 읽고, 외부 효과가 현재 값을 바꾼 뒤 필요한 값을 다시 조회한다. 실제 제목·정보 머리·번역·서식·소유자 이름 및 게임 판정은 호출자가 제공한다.

독립 원본 `object-menu-info-x86.tsv` 1,434행을 사용해 각 외부 효과의 순서와 바이트, 반환값 및 전체 현재 슬롯/전역/TYPE 상태를 비교했다. 기존 인벤토리 정보 3개 검사와 합쳐 집중4/4 통과다. 이 단위는 실제 제품 메뉴나 게임 실행을 변경하지 않았으며 제품 우클릭 경로와 실제 Player·번역·메뉴 소유자 결선은 후속이다. 최신 전체 회귀는 이 변경을 포함하지 않는다.
