# dotnetpj 1.141 — 제품 타일 화면색 합성

2026-11-27, HJOW-Athlon. `RawTileSprites`의 그림자·죽음·추상 표시를 cpppj `SpritePixelTarget`의 원본 `004dab90` 변환과 같은 마스크 아래 현재 화면색 처리로 교정했다. 일반 원색과 소유자 색표는 계속 소스색에 적용한다. 단위 배율에서도 같은 원본 기하와 소스255 마스크 처리를 사용한다.

- 실제 SHP의 죽음·추상 그림에서 소스색과 다른 기존 화면색을 준비해 각 색표가 화면색을 변환함을 검증했다. 타일·SpriteDraw·VFX 집중 검사 **33/33 통과**, Release 빌드 오류 0·기존 경고다.
- 캠페인1-1을 새 사용자 루트, 1024×768 창, 고정 25ms·120프레임으로 실행하고 1.121과 같은 미니맵 누름·드래그·놓기를 수행했다. DN 정상 종료 0이며 75·81·89·95·105프레임의 전체 BMP가 1.121 DN과 각각 픽셀 일치했다. 이는 해당 장면에서 특수 상태의 효과가 시각적으로 달라졌음을 증명하지 않는다. 원본 1,392파일은 실행 전후 불변이다. 원시 화면과 결과는 `extracted/dotnet-tile-1141-screen/`에 있다.
- 특수 상태가 실제 게임에서 나타나는 장면의 CPP/원본 대조, 일반 객체 kind 0 제출과 관련 세션 장치 결선, 미니맵 1픽셀·미션 전환은 미완료다. 전체 회귀는 직전 1.140 결과이며 이 단위에서 반복하지 않았다.
