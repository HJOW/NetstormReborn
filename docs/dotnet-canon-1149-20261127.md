# 1.149 다리 추가 그림 관문

`RawBridgeDraw::Additional`은 현재 다리 수명 숫자 전역이 0이면 SID와 좌표를 읽기 전에 반환한다. 제품 일반 객체 출력기의 다리 추가 그림을 같은 세션의 `Gameplay.BridgeLifeNumbers`에 연결했다. 0이 아닌 개발용 숫자 표시는 아직 이식되지 않아 명시적으로 실패한다.

실제 세션에서 유효하지 않은 SID·좌표로 0 관문이 반환하고, 전역이 1일 때 미이식 오류가 나는지 검증했다. 다리·타일·세션 표시 집중 검사 13/13과 `cpp_sync.py`가 통과했다. 이 단위에서는 실제 게임을 실행하지 않았고 타일 묶음의 제품 출력 경로는 아직 교체하지 않았다.
