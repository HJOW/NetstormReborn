# WB04-E860 Client 임시 고리 정수 서식

기준선 `225553df`의 `ClientStaticStrings::FormatInteger`를 같은 임시 고리와 실제 물리에 연결했다. 서식이 같은 고리 할당을 빌리면 주소 토큰을 사용해 예약 결과와 같은 주소일 때 서식을 생략한다. 그 밖에는 예약 이후 현재 NUL 종료 바이트를 읽고 정수 인자 하나의 `d/i/u/o/x/X/c`, 리터럴 `%`, 플래그·폭·정밀도를 처리한다. 잘못된 서식은 예약 뒤 거부하며 물리 범위 초과는 앞선 출력만 남긴다.

cpppj의 고리 별칭·예약 30 초과·서식 오류 검사에 대응하는 집중 검사와 Windows `msvcrt._snprintf`의 2,205개 조합(7개 변환·7개 플래그·3개 폭·3개 정밀도·정수 5값)을 바이트 단위로 비교했다. 처음에는 `%c`의 0 채움 및 정밀도 조합이 달라 수정했고 재대조 결과 불일치 0이다. Node v26.13.0 전체 회귀 6,378건이 통과했다(실패·취소·건너뜀 0). 이는 호스트 `msvcrt` 비교이며 cpppj 빌드의 CRT나 원본 x86 실행 결과를 직접 수집한 것은 아니다.

실제 Client 장기 소유·호출자 연결과 다른 CRT/브라우저 검증은 남아 있다. 원본 게임 창은 실행하지 않았다.
