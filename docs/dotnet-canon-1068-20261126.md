# dotnetpj 1.068 — R5-2d3 세션 수집 결선과 전체 회귀

2026-11-26, HJOW-Athlon. R5 월드 그리기 묶음의 둘째 조각 마지막 결선이다. 세션 수집
조립을 제품 미션 시작에 이어 정기 전체 회귀를 수행했다. R5-2는 수집 결선까지로 닫고,
L4a 타일 일치는 Submit·프레임 구동이 이는 R5-3에서 닫는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Host/HostSession.WorldDrawing.cs`: 신규. `BuildWorldDrawingDevices`·
  `CollectWorldDrawing`을 두었다. 근거: cpppj `ClientRendererFrame.cpp`의 `Collect`가 같은
  Pool/해시/타입/셰이프로 수집기를 다시 만드는 결선이다. 저장소·높이가 바뀌면 타일·객체
  수집기를 다시 만들고, 실제 지도 영역 전역으로 viewport·행 제한 뒤 묶음→객체 순서로
  수집한다. 배경·제출·매 프레임 구동은 R5-3에서 잇는다. 1.068에서 추가했다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 미션 시작에 수집 조립을 이었다. 같은
  저장소·화면 크기로 타일·객체 수집기를 묶으며 시작 덤프에는 닿지 않는다. 1.068에서 수정했다.
- `dotnetpj/src/Netstorm.Core/Original/RawTileGroupCollection.cs`: 생략 상태의 0 초기화
  함정을 주석으로 적었다. `default`·인자 없는 `new()`는 선택적 기본값이 아닌 0 초기화를
  넘겨 토큰 영역 검사에 걸리므로 표준 상태는 명시한다. 동작 변경은 없다. 1.068에서 수정했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostWorldDrawingTests.cs`: 신규 4건. 미조립 거부·
  묶음→객체 순서·토큰·덮음, 빈 월드 0건, 높이 변경 재조립을 대조한다. 1.068에서 추가됐다.
