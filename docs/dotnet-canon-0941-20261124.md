# dotnetpj 0.941 — 메타 전투 설명 수신·확정 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 0x71 전투 설명 수신의 수신 본체와 확정 본체를 같은 CS/진단/표시 장치에 연결했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `NativeMetaBattleDescription.Receive`는 0042cad0 전체를 이식한다. 무효 전투는 로그만 쓰고, 초과 길이는 로그 뒤 현재 번호 갱신만 하며, 유효 설명은 DWORD·잔여 BYTE 복사 뒤 종단 NUL을 쓰고 일곱 ASCII 제어 문자를 공백으로 바꾼다. 마지막에 객체 새로고침과 전투 갱신을 수행한다. 0.941에서 추가됐다.
- `Confirm`은 004c92c0 확정을 이식한다. 256BYTE 복사를 NUL로 끝내고 첫 LF를 잘라 반환하며, 후행 공백은 임의로 제거하지 않는다. 0.941에서 추가됐다.
- 송신 본문과 0x71 설치는 챌린지 보유·전송 장치가 마련되는 대로 잇는다. 수신 본문은 0x71 길이 0의 f8 NUL 쓰기 규칙을 그대로 둔다.

## 검증

- Release 테스트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 5건(무효 로그·초과 갱신·복사 정제 새로고침·확정 절단·미연결 명시 실패)은 통과/실패 0이다. 메타 버전·챌린지 이웃 검사를 포함한 18건이 함께 통과한다.
- 같은 최종 빌드에서 대표 3경로(`thewarbegins`·`tutorial1`·`surrounded`)는 모두 L2 미일치(예상)이며 전체 덤프/지표가 0.920과 같다(`thewarbegins` cpp1941/dn1911/only30, `tutorial1` cpp843/dn838/only5, `surrounded` cpp6420/dn6408/only12). 원본 파일은 작업 전후 `git status`에 없고 전후 불변이다. 근거는 `extracted/dotnet-l2-0941-*/`의 각 실행 로그와 요약이다.
