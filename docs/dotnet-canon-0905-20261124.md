# dotnetpj 0.905 — RU-3 메시지 공장 팔레트 프로브 이식

2026-11-24, HJOW-Athlon. RU-3 첫 묶음이다. 실제 게임 Root의 네 공장 중 메시지 공장 팔레트 프로브 경로를 이식했다. 제품 기존 경로는 바꾸지 않았다.

## 변경과 원문 대응

- `RawUberMessageProbe`는 `cpppj/src/client/UberHud.inc` 51~61행의 `savedMessage`/`equalText`/`constructMessage`/`formatMessage`/`testMessage`/`visitMessage`/`messageEvent`를 이식했다. `GumpButtonTree`의 동일 저장소·가상 분배를 전제로 하며 실제 네 공장 설치·바깥 UI 장치·NativeRoot/HUD 창 생성·Enter는 후속 단위에서 잇는다.
- `SavedMessage`는 보호PE의 빈 root 메시지 주소(`0x565e70`)다. `EqualText`는 주소 일치와 현재 배경 이름의 대소문자 무시 일치를 함께 판정한다.
- `FormatMessage`는 보호PE의 빈 root/d/현재 이름/.col 순서인 실제 9인자를 그대로 요구하고, 같은 9인자를 전체 원문 작성기의 네 부품(`-2,""`·`-2,"d"`·`-3,배경`·`-4,"col"`)으로 전달해 `RawFileName.Format`으로 작성한 뒤 같은 안정된 문자열 토큰으로 게시한다. 원문 인자 변경은 명시 거부한다.
- `TestMessage`는 실제 VFS 조회 결과만 조건으로 사용하고 없는 파일을 만들지 않으며, 원문 진단 줄을 같은 실제 로그에 남긴다. `VisitMessage`는 끝 NUL을 포함한 같은 메시지 포인터를 실제 전체 부모(`ChangeFortPalette`)에 전달한다. `ConstructMessage`는 Uber 실제 배경 이름 주소가 아니면 명시 거부한다. 미연결 장치는 일반 Pre/Post/no-op으로 통과시키지 않고 명시 실패로 둔다.
- PORT_MAP은 이전 1827행의 값·순서·base를 보존하고 1행을 추가했다(자료 1828행). fixture 496개는 그대로다.
