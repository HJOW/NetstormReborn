# dotnetpj 0.799 — 사제 정지·사제/운반체 도착과 실제 Host 부모

2026-11-22 · HJOW-Athlon · 제품11.01 · .NET10 Release. 전체 목표와 M1은 미완료다.

## 구현

`RawPriestHalt.cs`에 사제 가상38과 공통 Carrier Halt를 이식했다. 최초 좌표를 보관한 지면/저HP 정지, 서로 다른 두 float bias, 기존 CarrierCheck와 일반 finder, PATCH의12/CD의비영 반환 조건을 보존한다. 큰 포획/너겟 전달은 필수 실제 경계다.

`RawCarrierArrival.cs/.State.cs`에는 전체 공통 도착 부모와 PickupCandidate·ValidGeyser·ValidReturn을 이식했다. 현재 경로·내용물·Graph·제단·동맹을 원문 소비 위치에서 조회하며 포획/귀환/채굴 요청, CD의 SP 환원·통지·위치 소리, 마지막 비표면 회피와 PATCH Robust 접두를 유지한다. 기존 내용물/발자국/HP/검색 본체를 재작성하지 않았다.

`RawPriestArrival.cs`에는 현재 지면 지역→섬목록 Temple, 축별 signed거리와 PATCH/CD float 저장 차이, 중립 사제 귀환·내용물 생성→자기삭제, 일반 Carrier 도착 위임을 이식했다. 독립 PE 관측이 없는 이 wrapper의 검증은 Source 계약 검사로 구별한다.

`HostSession.PathParents.cs`는 같은 실제 사제/공간/내용물/HP에 부모를 조립하고 장기 현재 권한·TYPE·포획 허용·적재·미션 후처리·Player AI 존재·방향별 동맹표를 연결한다. 현재 경로는 종속 체인→현재 Host→같은 Pool/부모/Form으로 매번 찾는다. 복원된 부모의 실제 TYPE/가상표/이동 종류를 검사하며 다른 부모를 정상null로 숨기지 않는다. 큰 운반·의식·회피·가상 삭제는 실제 장치를 받아야 한다. 기존 일반 삭제 Pre/Post를 전체 가상 삭제로 대체하지 않았다.

## 검증

- Core 제품 빌드와 Client 빌드 오류0·제품 경고0. 관련 검사 빌드의 기존 테스트 경고는 유지했다.
- 독립 PE **PATCH635관측**: 사제 정지432와 Carrier 도착203의 반환·효과 순서·부모 슬롯50BYTE 전체가 일치했다. 기존 HP/공간/내용물/Graph 본체를 사용한다.
- Core 최종 집중13건 통과. 중립 wrapper의 Source 계약(현재 귀환 억제·권한·적재)과 현재 AI 존재/Robust 소비도 포함한다.
- Client 선정63건 모두 통과 후 부모 검증을 보강한 해당1건을 다시 확인했다. 실제 Host의 정지·현재경로없음·도착 getter·장기 TYPE/포획 허용 공유·잘못된 가상표 거부·반납 뒤 조회 실패를 검사한다. 신규 검사는 Core4·Client1이다.
- 기존414자료의 항목/머리말을 보존해416개로 늘렸고 기존 PORT_MAP 행을 유지하며 실제 부분 대응12쌍을 추가했다. Source와 fixture는 수정하지 않았다. `cpp_sync.py` 종료0.

부모 가상표 진단 검사를 추가한 초회에는 Client 검사에서 Core 내부 전용 RawSlot을 부른 컴파일 오류가 있었다. 공개된 같은 할당 슬롯의 AllocatedBytes로 수정하고 해당1건을 통과했다. 초기 실패 로그와 교정 로그를 따로 보존했으며 제품이나 기대 관측값을 바꾸지 않았다.

CD 정지432·도착203은 **미검증**이다. 기존 RawSquidReward가188TYPE만 받으므로 같은171TYPE/CD HP 장치가 아직 없다. 자료 전체를 링크/등록한 것이 CD 검증 완료를 뜻하지 않는다. CD Host72/Start256과10.37 애니메이션2,016의 기존 미검증도 유지한다. 실제 사제 포획·희생·특정 적 공격·승리 입력이나 GUI 플레이는 수행하지 않았다.

이 단위는 새 부모의 실제 세션 조립 API와 현재 조회까지다. 제품 Root가 전체 Motion/Start/8종 경로를 설치하고30h를 수신하는 상위 호출자는 아직 없다. 다음0.800 정기 전체 회귀에서 같은 빌드65시작을 수집하고,0.801에서 전체 경로 조립·30h를 이어간다. M1의 마지막 전체 판정은0.796의0/34다.
