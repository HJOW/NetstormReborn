# 경로 이관 즉시 중단 인수인계

2026-10-14 사용자가 현재 작업도 즉시 중단하고 인수인계 작성·git 커밋을 요청했다. 모든 해당 Python 작업을 종료하고 현재 변경분을 보존한다. 현재/마지막 디컴파일 PC는 **HJOW-Athlon, 2026-10-14**다. 기준은 단위15 완료 커밋 **9d7acad** (`20261014-07`)이며 이번 보존 커밋은 `20261014-08`이다.

단위15의 캠페인 부모·Player 예약·Burning 프레임 등록은 Release 경고/오류0, 새7/전체1088 검사 실패0으로 완료했다. 이 결과는 경로 이관 전이며 현재 이관 상태의 최종검증 결과가 아니다. 실제 캠페인 월드 전체 설치와 목표 미션 완주 동일성은 남아 있다.

경로 정리는 **미완료**다. 최초 조사에서 Git추적 최장 절대경로280자,240자 초과55개/200자 초과200개였다. 상당수 이력을 `cpppj/hist/<18자 이내 이름>`으로 옮기고, 보고서의 반복 접두/접미·긴 도구명·로그명을 줄였다. 문서/소스/도구/해시 장부의 참조도 변경했다. 변경은 부분 상태이며 전체 감사 전이다. 보호 원본과 AGENTS.md는 수정하지 않았다.

첫 이관 도구는 마지막 단계에서 새 검사 도구의 내용 변경을 감지해 종료했다. 기준 Git 원문과 중단 시점 원문을 재구성하는 도구는 쓰기 단계에서 SquidHash.cpp에 OSError22를 받았다. 당시 파일은 읽기 가능하고4287바이트였다. 변경이 불필요한 파일의 재쓰기를 막고 쓰기 전에 대응표/짧은 캐시를 남기는 보강을 추가했다. 보강 후 재구성은 사용자 즉시 중단 요청으로 종료했다. **docs/path-map.json은 아직 생성되지 않았다.** 최초 이관을 현재 상태에서 단순 재실행하지 않는다.

재개할 때는 다음 순서로 처리한다.

1. AGENTS.md와 양 LEFT를 다시 읽고 호스트와 보호 원본 상태를 확인한다. 다른 PC면 디컴파일을 다시 수행한다.
2. `git ls-tree -r 9d7acad`의 이전 이름과 현재 파일을 대조한다. 이미 이동한 파일을 다시 복사하지 않는다. 이전/현재 SHA를 구분해 누락 참조와 장부를 복구한다. `tools/path_move.py`, `tools/path_fix.py`는 진행분이며 실행 전 검토한다.
3. 대응표를 쓰기 전에 보존하고, 같으면 쓰지 않는 방식으로 남은 교정을 수행한다. 원본 fixture/기대출력을 바꾸지 않는다. 전체길이/이름충돌/공간경계와 파일별SHA를 검사한다.
4. [경로 기준](path-rules.md)과 `tools/path_audit.py` 및 CI를 검증한다. 현재 대응표가 없어 기존파일 예외가 적용되지 않으므로 CI 통과를 가정하지 않는다.
5. 축약 후 분석 도구·동적 경로·import·문서 링크·CMake와 원본소비자 검사를 확인하고 LEFT를 갱신한다. 이후 실제 Player 기록 공유API, Path cleanup 연결, 단일Graph(false) 최종화, 실제172개 설치와 목표미션 플레이를 이어간다.

Git에는 현재 이관 진행분과 복구 도구·정책·인수인계를 보존한다. 원격push는 하지 않는다. 사용자 요청에 따라 커밋 후 목표를일시중지하며 추가 작업을 수행하지 않는다.
