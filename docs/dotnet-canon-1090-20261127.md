# dotnetpj 1.090 — 장기 GumpForm의 현재 통지 대여

2026-11-27, HJOW-Athlon. 인벤토리의 실제 Form 수명 연결에 필요한 선행 조각이다. 장기 `RawSurfaceStorage.GumpForms()`가 통지 대상 없이 만든 GumpForm을 현재 World 또는 화면의 등록표 통지에 전달하도록 연결했다. World에 통지가 있으면 우선하고, 없으면 UI를 선택한다. 호출 중 해당 World와 UI의 소유자 대여를 유지하고 예외 시에도 역순으로 반납한다. 살아 있는 다른 대여를 덮거나 다른 소유자의 대여를 반납하지 않는다.

- 같은 실제 SID 풀의 GumpForm으로 현재 통지 선택·UI 대체·중복/다른 소유자 거부·예외 정리를 검사해 집중 2/2 통과했다. 최초 검사는 장면의 표시 장치 누락으로 2건 실패했고 검사 장면에 실제 표시 장치를 연결한 뒤 통과했다.
- Game Release 빌드 오류 0, `cpp_sync.py` 종료 0. `thewarbegins`, `tutorial1`, `surrounded`의 CPP/DN 실행은 각각 종료 0이고 DN 90프레임 덤프는 0998과 바이트 일치한다. 원본 1,392파일은 세 감사에서 모두 불변이다. 기존 CPP-DN 상태 차이로 비교 도구 종료 1이다. 결과는 `extracted/dotnet-l2-1090-gump/`에 있다.

이 단위는 통지 전달 기반만 복원했으며 제품 UI의 등록표 대여, 생산 Form 생성·부착·삭제 분배와 인벤토리 갱신은 아직 연결하지 않았다. 생산 패널은 현재 호스트 종료 시 명시 Dispose되지 않는 점도 다음 수명 결선에서 확인한다. 생산 내용물·유지·입력 본체, 전체 UberRoot와 L4a 일치는 계속 미완료다.
