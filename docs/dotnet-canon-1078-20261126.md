# dotnetpj 1.078 — R5-4c1 미션 중 메뉴 배경 숨김

2026-11-26, HJOW-Athlon. R5 HUD·덱·미니맵·인벤토리 묶음의 넷째 조각이다. 미션 진입 뒤에도 메인 메뉴 돌 버튼·배경이 월드를 덮던 문제를 제품 결선으로 막았다. 생산 덱·미니맵·인벤토리 부착과 UberRoot 제품 결선은 R5-4c 나머지·R5-4d에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Host/HostMainMenu.cs`: `IsMissionActive` 판별과 `HidesMainMenuForMission`을 추가했다. 근거: cpppj `UberGump.cpp 2111~2112행`의 MainMenu 단계 조건이다. 미션에서는 여덟 돌 버튼·배경 자식에 대한 입력을 소비하지 않고 같은 트리의 임무 UI(채팅·HUD)는 그대로 전달한다. 1.078에서 추가·수정했다.
- `dotnetpj/src/Netstorm.Client/Host/HostGumpDrawing.cs`: `IsMissionActive` 판별을 추가하고 돌 버튼·배경 분기에서 미션 중 메뉴 부품을 건너뛴다. 근거: 같은 MainMenu 단계 조건이다. 모달 숨김(`HideWithModal`) 집합을 재사용하며 팝업 메뉴는 제외하지 않는다. 1.078에서 추가·수정했다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: `_gumpDrawing` 생성 뒤 두 장치에 `() => _missionSession is not null`을 연결했다. 근거: 같은 MainMenu 단계 조건의 제품 진입 판정이다. 시작 덤프·L2 상태에는 닿지 않는다. 1.078에서 수정했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostMissionMenuHideTests.cs`: 신규 2건. 메뉴 상태 그리기 뒤 버튼 중심이 바뀌고 미션 그리기 뒤 시작 배경 그대로임을 확인한다. 메뉴 상태 입력은 버튼을 소비하고 미션 입력은 소비하지 않음을 확인한다. 1.078에서 추가됐다.
