# dotnetpj 0.921 — RU-3 NSInfo 메타 루트 결선 이식

2026-11-24, HJOW-Athlon. RU-3 열세 번째 묶음이다. NSInfo 메타 루트 본문을 같은 실제 호스트 저장소와 외부 장치에 연결하는 생산 결선을 이식했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `HostNsInfoWindows.LayoutMetaRoot`는 `cpppj/src/client/RawMenuControls.cpp`의 `NsMetaGlobals`/`NsMetaHooks` 조성과 `LayoutMetaNsInfo` 호출을 실제 owner로 조립한다. 같은 CS·정렬표·메타맵/인식/소유자 전역과 같은 트리 노드/Push/부착·제목 파서/맞춤·줄나눔·스크롤 장치를 빌린다. 플레이어·배틀 패널 전용 후크(시작 버튼·값·랭크·설명·스크롤러 등)는 해당 경로 단위에서 잇는다.
- 도움말 문자열은 공통 트리 소유 표(`GumpButtonTree.SetHelpText`/`SetHelpWord`)에 둔다. 원문 순서(기존 반납·포인터 0·새 주소 게시)를 따르며 소멸자 반납(`DestructBase`→트리 실제 해제)과 같은 저장소를 공유한다. 호스트별 별도 표를 두지 않는다.
- 제목 본문 바이트는 파싱에 NUL 없는 원본 글꼴 바이트를, 교체·추가에는 NUL 끝 바이트를 쓴다. 교체·추가가 길이 -1 NUL 탐색으로 기록하므로 끝바이트를 붙인다.
- 메타 제목은 번역→zone 캡처→현재 서버 조회→256BYTE 서식을 원문 순서로 수행한다. 서버 이름은 `ResolveServerName`의 공유 80BYTE 버퍼에서 읽는다.
- 소유자·기술합계 장치는 `HostNsInfoDevices.ObjectOwner`·`TechWeight` 새 슬롯으로 받는다. 미연결이면 해당 패널 배치에서 명시 실패한다.
