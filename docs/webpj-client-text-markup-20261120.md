# Client 글자 Gump의 실제 스타일 그림

WB04-E1026은 한 줄 TextGump에서 실제 게임의 스타일 색상·대괄호 그림과 소리를 사용할 수 있도록 기존 StyleTextMarkup 및 Markup을 같은 조각 저장소와 Gump 픽셀 표면에 결합했다. 출력 때 현재 팔레트와 그림 색표를 읽으며, 그림의 측정·출력·소멸은 기존 원본 이식 구현을 따른다. ClientTextGump는 스타일 훅 공장에 자신의 조각 저장소와 현재 출력 표면 접근자를 제공한다.

실제 Tutorial1 앱과 원본 자산에서 생산 예산 형식 `~3~E~w100~[I92.3]`을 해석하고, 그림이 없는 같은 문자열과 출력 픽셀이 다름과 조각 반납을 확인했다. 관련 Node 검사와 대응표 검사 53건은 모두 통과했다. 실제 생산 패널의 배치·표시와 상호작용은 아직 연결하지 않았다.

E1023 고정 상태의 Node 26 전체 회귀는 6,562건 중 6,560건 통과, 2건 실패했다. 두 실패는 E1019~E1022에서 추가한 세 Client 조립 모듈의 이식 대응표 누락이며, 이번에 E1024~E1026의 조립 모듈까지 함께 대응표에 등록했다. 수정 후 전체 회귀는 별도로 다시 실행해야 한다.
