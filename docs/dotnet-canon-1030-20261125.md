# dotnetpj 1.030 — R4-5b 사제 호출자 결선

2026-11-25, HJOW-Athlon. R4-5b 세션 호출자의 네 번째 묶음이다. 세션에
`BuildAiPriestDevice`를 두고 런타임 `Priest` 갈고를 실제
`RawAiPriestActions.Act` 호출에 이었다. 원문 SID 범위 검사도 런타임 갈고리에서
같은 순서로 수행한다. 탐색·이동·건설 선택·자원 선택·제단·발자국·회수 명령의
실제 하위가 없어 해당 갈고리는 원문 순서 도달 시 명시 거부한다(R6).
