  두었다. 근거: cpppj `ClientRendererFrame.cpp`의 `Submit`이 같은 원문 5,000칸을 정렬하고
  종류 0..4를 실제 현재 출력기에 분배한다. 수집→정렬→묶음 조회→분배를 한 호출에서 수행해
  수집·제출 사이 상태 공유를 없앴다. 타일 멤버(kind 1)는 `RawTileSprites`로 직접 합성하고
  타일 외 종류·UI·건설·미리보기는 각 단계의 명시 실패로 둔다. 픽셀 버퍼는 ref 구조체 캡처
  제한 탓에 배열로 받는다. 1.072에서 추가했다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostWorldDrawingTests.cs`: 3건 추가. 미조립 거부·
  수집 타일의 정렬·분배·배치 일치 제출·타일 외 종류 거부를 실제 `_shapes.shp`로 대조한다.
