# 브라우저 조각 회전 (WB04-E1009)

실제 조각을 든 동안 오른쪽 마우스 버튼과 좌우 화살표를 원본 입력 큐·사용자 입력기의 커서 회전 경로에 연결했다. 버튼 뗌은 원본 큐에서 처리하며 커서를 들지 않은 일반 우클릭 메뉴는 아직 연결하지 않았다.

원본 회전 289행과 브라우저 입력 등 Node 검사 10건 및 앱 Node 4건이 통과했다. Chromium에서 실제 Q 조각 취득 후 오른쪽 클릭으로 +2, 왼쪽 화살표로 -2 회전하고 취소 및 이후 실제 배치까지 진행했다. 미존재 테스트 파일 이름을 지정한 첫 실행은 실제 존재하는 앱 검사 4건만 실행했으며 별도 실제 파일 10건으로 다시 검증했다.
