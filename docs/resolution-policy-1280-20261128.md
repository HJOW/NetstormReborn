2026-11-28 사용자 요구와 후속 정정을 적용한다. `3840×2560`은 오타이며 16:9·16:10·4:3의 높이는 각각2160·2400·2880이다. AGENTS.md 자체는 수정하지 않는다.

5:4는 요청한1280×1024에 대응한다. 원본640×480·800×600·1024×768도 유지한다. 1366×768·1600×900은 일반 목록에서 제거하고 저장값을 가장 가까운 화면비의1280 화면으로 옮긴다. 1920 이상의 목록은 실제 FSR 출력기가 준비돼야 허용하고 자동으로FSR을 켠다. FSR 미지원 환경은 같은 화면비의1280 출력으로 복구한다.

## cpppj — CP1384 완료

공유 ScreenResolutions 정책·두 Options 메뉴·Client 최초 설정 해석/논리 표면 할당에 적용했다. Direct3D11의 기존 공식 EASU/RCAS 출력을 재사용하며 입력은 각 화면비의1280 폭이다. 게임 Release 빌드와 정책3/3·기존 상수/실제 GPU 및 추가12출력 GPU 검사6/6이 통과했다. GPU 검사에서 실제1280 입력을 모든12출력으로 그린 뒤 크기·균일색을 읽었다. 장치 미지원/옛 설정 복구도 검사했다. 로그는 `extracted/resolution-1280-cpp-*.log`다.

원본 파일·디컴파일 자료는 변경하지 않았다. 마지막 디컴파일 PC와 이번 PC는 모두 **HJOW-Athlon**이다. ZIP은 재작성하지 않았다.
