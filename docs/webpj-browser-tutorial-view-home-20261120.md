# 미션 F4 홈 보기와 튜토리얼 단계 (WB04-E998)

미션의 F4 누름·뗌을 같은 브라우저 가상 키 변환과 입력 큐로 예약한다. Tutorial과 Gump가 소비하지 않은 F4는 기존 선택 키 본체를 통해 원본 `ViewHome` 명령을 큐에 넣고, 그 명령은 같은 Tutorial·Gump 관문과 원본 GameMenuActions의 현재 Player·홈 객체 판정을 거쳐 실제 카메라를 이동한다. 다른 키와 미연결 명령은 아직 이 경로에서 소비하지 않는다.

실제 Chromium에서 안내를 넘기고 사제를 이동한 뒤 가장자리로 카메라를 옮긴 다음 F4를 눌렀다. 카메라가 홈으로 돌아가고 Tutorial1 단계가 A에서 B로 진행했으며 처리되지 않은 페이지 오류가 없었다. 원본 메뉴 명령·선택 키·Tutorial 관측 등 연관 Node 검사 26건과 Chromium 1건이 통과했다. 발소리 누락으로 앞선 브라우저 프레임이 멈추던 문제는 E997에서 먼저 수정했다. E990 고정 Node 22 전체 검사는 별도 트리에서 진행 중이다.
