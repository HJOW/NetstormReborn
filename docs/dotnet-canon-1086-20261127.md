# dotnetpj 1.086 — 세션 공간 변경과 미니맵 결선

2026-11-27, HJOW-Athlon. 미션 `HostSession`이 실제 지형과 Player의
Pop/Unpop 두 쌍을 1.085의 미니맵 큐에 연결한다. 공통 저장소 실행기와
별도로 존재하는 같은 풀·해시·점유 지도의 실행기다. 추가 쌍 전체를 먼저
검사하고 모두 유효할 때만 설치해 뒤쪽 실패가 앞쪽 큐를 남기지 않는다.
미션 시작 실패와 호스트 종료는 기존 `UnbindWorld`/`Dispose`로 반납한다.

- 미니맵 집중 11/11 통과. 새 HostSession 검사는 실제 지형·Player의
  Pop/Unpop 알림과 반납 후 Player Pop에서 알림이 중단됨을 확인한다.
  다중 입력 뒤쪽이 다른 물리일 때 앞쪽도 설치되지 않음을 검사했다.
  최초 컴파일은 테스트의 `Netstorm.Client.Host` using 누락으로 실패했으며
  이를 추가한 뒤 검사 빌드·실행이 통과했다.
- 대표 세 미션의 CPP/DN 실행 6건 종료 0, DN 90프레임 덤프는 0998과
  각각 바이트 일치, 원본 1,392파일 전후 불변이다. 기존 CPP/DN 차이로
  비교 도구 종료 1이다. 결과 `extracted/dotnet-l2-1086-session/`.
- `cpp_sync.py` 종료 0. 정기 전체 회귀는 1.084의 7,386통과이며 다음은
  1.088이다. 실제 게임 중 건설·삭제로 알림을 관측한 검사는 하지 않았다.

미션 전환·실패 수명과 세션 실행기 교체 뒤 재연결은 별도 확인이 필요하다.
채팅 표시 상태를 포함한 HUD 도킹과 미니맵 388픽셀 차이도 남는다.
