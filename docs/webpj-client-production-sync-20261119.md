# WB04-E833 Client 생산 동기화

기준선 `225553df`의 `ClientProductionSync.cpp`와 같은 Client 장기 표면·게임 전역·Player 기록을 연결했다. Runtime 대여 중이면 현재 Session의 설치 관문과 실제 생산 동기화를 사용한다. 대여가 없으면 실제 Player Deck 저장소를 가져온 뒤 같은 Pool·TYPE·내용물 검색기를 원본 동기화 본체에 연결한다. 선택된 생성·삭제·커서 취소는 현재 Runtime을 요구한다. 별도의 가짜 월드나 성공 효과는 만들지 않는다.

월드 없이 Deck을 처음 만들고 동일 블록을 재사용하며 templateOwner 변경 시 새 소유자 블록을 사용하는 것을 확인했다. SID 0의 실제 체인 오류는 Deck 할당 뒤에 발생하고, SID 0 내용물·선택된 삭제·권한 없는 dead 부모 진단도 현재 실제 상태를 사용한다. 현재 게임 전역이나 저장소가 공개 전 대여 상태일 때 무월드 경로로 우회하지 않는지 검사했다. 실제 Session은 적재 전 관문에서 거부하고 적재 뒤 같은 Deck을 재사용한다.

첫 진단 검사에서는 독립 필드에 값을 넣었으나 실제 Client finder는 공유 checking 전역을 사용해 기대한 진단 대신 다음 선택 경계에 도달했다. 같은 장기 전역에 값을 써서 교정했다. 실제 HUD 이벤트와 Client 전체 정리·브라우저 화면은 아직 남아 있다. 게임 창은 실행하지 않았다.

검증: 월드 없는 검사 3건과 실제 Session 검사 1건, Node v26.13.0 전체 6,330건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. E827의 Node v22 전체 검사 뒤 v26 회귀 6/8회다.
