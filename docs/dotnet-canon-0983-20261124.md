# dotnetpj 0.983 — RawFileName 나머지 조회(Name·Directory·Full) 이식

2026-11-24, HJOW-Athlon. R4-6 시작·수명 묶음의 남은 과제 중 파일 계열을 잇는다. cpppj `o/RawFileName`의 459b20 이름·459990 디렉터리·459890 전체 조회를 이식했다(Format·Device·고리 수명은 기존). RU-3 나머지·R4-4 정기 두 단위는 후속에서 잇는다.

## 변경과 원문 대응

- `RawFileName.Name`: 전체 입력을 고리에 복사한 뒤 마지막 구분자/colon 다음 내부 뷰를 빌린다. 구분자가 없으면 빈 뷰를 둔다. `extension` 거짓이면 459550 규칙으로 끝 확장자만 제거한다(선두 dot 유지·구분자/colon 중단). 0.983에서 추가됐다.
- `RawFileName.Directory`: 459990의 전체(-1)/단계별 디렉터리와 부분 버퍼를 같은 고리에 반환한다. UNC 시작·dot 단계·역방향 탐색의 offset0 검사 제외·고정 역슬래시 연결을 원문 순서대로 유지한다. 0.983에서 추가됐다.
- `RawFileName.Full`: 459890의 전체 또는 무조건 +2주소 복사를 수행한다. `.\\` 검사를 하지 않으며 2BYTE 미만 입력의 `prefix=false`는 거부한다. 0.983에서 추가됐다.
- NUL 뒤 바이트 보존·256BYTE 물리 범위·고리 선증가/10칸 순환·실패 시 현재 칸 전진 규칙은 기존 Format/Device와 같다. 새로 만든 검사 전용 본체가 아니라 실제 조회 경로다.
