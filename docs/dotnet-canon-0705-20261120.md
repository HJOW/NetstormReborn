# 0.705 장기 Client 전역과 실제 기존 소비자 공유

`ClientLocalStateGlobals.h`의 상태/로그인/시계 저장소와 `ClientConnectionGlobals.h/.cpp`의 실제 Registry/동기화/Source 부분을 이식했다. Host는 한 개의 장기 소유자를 만들어 같은 HostSession에 전달한다. 새 Client 최초값과 실제720바이트는 한 번만 구성하고 Session 생성으로 재설정하지 않는다.

메뉴창은 immediate+84의 같은4바이트다. Zone은 실제8바이트의 앞6바이트를 빌리고 상위WORD를 보존한다. BattleTerritory DWORD와 BattleByte도 같은4바이트를 공유한다. Clock의 연결/응답/게임보정과70표본을 장기 소유하며 Registry의 현재 동기화 뷰도 같은 연결DWORD를 직접 읽고 쓴다. 각 Native 주소의 최초1/ffffffff/명령 값과 독립 타이머/캐시/기록도 분리해 보존했다.

기존 ClientGameplay.SavedGameBox와 Host의 AmbientSoundState를 직접 빌린다. 주변음 기한은 같은 실제 Deadline의 DoubleBox 어댑터이고, HostSession.WorldLoginEnd도 같은 장기 LoginEnd를 반환한다. 값의 사본이나 세션별 억제 기한을 만들지 않는다. HostSession에 공유 LocalState/Connections 선택인자를 추가했고 같은 실제 Gameplay/LocalState인지 Pool 생성 전에 검사한다. 독립 기존 호출은 기존0초/false 기본동작을 유지한다. Host 종료에서는 UI/음향/장기 전역 반납 전에 실제 연결/Source/listener 정리를 수행한다.

집중12건(새6·기존Carrier2·실제Flare4)이 통과했고 실패는0건이다. 새 Client 최초값과 전체블록/메뉴창·Zone6/8·BattleBYTE 별칭, 기존 저장/주변음 값 보존과 양방향 쓰기, 두 실제HostSession의 같은owner/플레어 기한 보존, 실제 내부Client9 종료의 현재 동기화0과최종Source 반납, 소유자 유도/다른Client 조합 거부를 확인했다. 처음 두 실행에서는 플레어 파일명이 partial클래스명과 달라 해당 필터가 실제로 선택되지 않았다. 실제 `HostPriestWorldLiveTests.Flare*`·`ProductFlare*`를 따로 지정해4건 통과했다. 근거는 `extracted/dotnet-0705/client-local-state-initial.trx`, `client-local-state-owner-flare.trx`, `client-local-state-actual-flare.trx`와각로그, `verification-summary.json`이다. 기존 nullable 경고3개 외 새경고는 없다.

호스트 생성/최종종료도 변경돼 실제 DN `thewarbegins`를 독립사용자루트·영어1024×768/음소거·시드1760000000·25ms프레임으로 한 번 실행했다. 종료0이며 f090덤프 전체바이트가0.704와 같고 원본1392파일SHA가 불변이다. 근거는 `extracted/dotnet-0705/smoke/thewarbegins/dn/`와 `smoke-summary.json`, `smoke.log`다. 기존게임 실행이나 공격/포획/희생/승리 재현은 수행하지 않았다. `cpp_sync.py` 종료0, fixture357개를 유지했다.

범위는 실제 저장소와현재소비자 공유다. LocalState의 ClientHelpWord/MonitorTime 소비자와 Connection의 PacketDelays는 후속이다. 전체 Login/Ready/Start와 제품게임시계/Root 상태기는 아직 연결하지 않았다. HostTimeSource는 UI/벽시각이고 GameClock이 아니므로0.703의 보정검사를 제품프레임 설치로 확대하지 않는다. 다음0.706에서 실제 현재HostSession의 Runtime대여/고정F를 연결하고 장기 옵션/Core필드·전체로그인bridge를 잇는다. 정기 전체회귀는0.708이며 전체목표와M1은 진행 중이다.
