# 도움말 요구 에너지 그림

WB04-E1048은 10.78 QuickHelpHtml이 사용하는 요구 에너지 그림 문자열을 복원한다. 원본 ASCII 문자별 SHP 프레임, 점 구분자 건너뛰기, 지정된 앞쪽 아이콘 강조와 256·250바이트 한도를 유지한다. 호출자는 현재 프레임 전역과 TYPE을 직접 공급할 수도 있다.

원본 독립 관측의 마나 M행 24건과 현재 프레임 표·NUL·범위 검사를 포함한 관련 Node 26 검사 29건이 통과했다. TYPE 정보 HTML과 별도 정보 패널, 실제 앱 Help 연결은 후속이다. E1047 고정 Node 22·26 전체 회귀는 별도 작업본에서 진행 중이다.
