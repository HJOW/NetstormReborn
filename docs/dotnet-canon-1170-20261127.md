# 1.170 진입 화면의 에지 팜 상태 추적

1-1의 동일 40프레임 CPP/DN 덤프를 비교했다. 에지 팜(TYPE121)은 양쪽 152개이고 좌표·SID가 대응하지만 CPP의 소유자는 모두 0이며 DN은 1이 101개, 2가 51개다. 섬(TYPE97)은 1,353개·소유자 분포가 같고, 프린지(TYPE102)는 양쪽 168개·소유자0이다. 간헐천(TYPE122)은 양쪽 14개·소유자0이나 CPP 프레임4, DN 프레임3이다. 화면 전체의 40프레임 차이는 35,202픽셀이고 미니맵은 차이0이다. 이 수치는 색표·애니메이션·상태 등 여러 원인이 섞여 있어 에지 팜 소유권만의 픽셀 수가 아니다.

대표 SID23481, 좌표 `(98,111)`은 양쪽 타입121·프레임171이나 CPP 소유자0, DN 소유자1이다. 임시 진단 빌드에서 DN은 먼저 타입97·소유자0으로 도장한 뒤 동일 슬롯을 타입121로 바꾸고, 미션 신전 적재 중 `RegisterRegionTemple`·`DispatchRegionTempleOwner`에서 이어지는 `RawRegionOwnership.Update`와 `RawRegionPaint.Boundary`가 여러 차례 0/1로 바꿨다. 최종 소유자1은 관측값이며 CPP의 동일 호출 순서, 영역 검색 및 원본 동작은 아직 확인하지 않았다. 코드에서 소유자를 강제로 0으로 바꾸지 않았다.

실행과 상세 덤프는 `extracted/dotnet-terrain-1170-same-frame/`, DN 추적은 `extracted/dotnet-terrain-1170-trace/`에 있다. 정상 제품 CPP/DN 실행과 DN 진단 실행 모두 종료0, 각 실행의 원본 1,392파일은 불변이다. 진단 소스는 빌드 직후 원래 바이트로 복원했고 픽셀은 기존 제품과 같았다.
