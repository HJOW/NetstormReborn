## 1. 이식 범위

`StyleTextBuffer`는 입력 원본과 표시 복제를 따로 소유한다. LF에서만 입력 줄을 완료하고, 끝 칸이 차면 첫 완료 줄을 반납한 뒤 미완료 끝 칸까지 옮긴다. 추가 통지는 길이/NUL 검사 전에 호출한다. 양수 폭에서만 이전 표시를 반납하며 마지막 미완료 입력은 표시하지 않는다. 폭의 엄격한 비교, 공백 포함 접두 복사, 첫 단어 강제 배치, 마지막NUL의 명시 복사, 비문자 높이를 새 줄 이동 전에 쓰는 순서와 삽입 시점의 y를 유지했다. 소멸은 완료 입력→표시→센티널 순서이고 원본처럼 미완료 끝 조각과 개수 필드는 남긴다.

`Markup`은 공통/파생 토큰을 공유하며 생성/복제/기본 분류 전환/scalar 반납을 연결한다. 복제는 배율1/색 치환0으로 초기화한다. 현재 타입/프레임 조회, 타입 기준점의 signed WORD 감김, 패치 세로 비율의 float32 저장과 CD NaN 분기, CRT 절삭, 색표 설치 뒤 현재 프레임 재조회를 보존했다. `MarkupAssets`는 실제 SHP의 논리 헤더와 물리 프레임 범위를 구별하며, `MarkupPixelTarget`은 실제 일반/직교 배율/투명/현재 공유 색표 출력으로 연결한다. 전체 GameAssets 로더가 아직 없으므로 해당 전용 생성자 대신 타입 수/블록/논리 수/기준점의 명시 바인딩을 받는다. 전체 로더 연결은 후속이며 근사 자산을 만들지 않았다.

`ScrollingTextGump`는 두 dirty 조건과 판본별 저장 순서, 선택적 슬라이더 폭, CD 중간 float32, 강제 높이/내용 맞춤, 기본 문맥의 사전 복사, 완료 줄만 교체하는 동작을 연결한다. 스크롤 range→page→position→현재 위치 순서에서 각 현재 슬라이더/scroll을 다시 읽는다. 요청 정상 반환 뒤-1 저장과 예외 시 부분 저장, 아래 요청의 미사용 인자, ordered 아래 판정도 보존한다. 선택은 현재 표시의 엄격한 위 경계와 행 아래 정렬 높이를 쓰고 자동 배치하지 않는다. Draw는 배치→요청→내부 클립→현재 위치→가시 줄 최대상승/현재head 재조회→크기/실제 출력 순서다. 첫 줄만 저장y를 쓰고 뒤는 현재 높이를 누적하며 CD의 NaN viewport 분기도 유지한다. 한 줄/다중 줄/기존 파생을 잇는 원본3인자 Draw 분배도 연결했다.

C++17 대입은 우변 평가 뒤 좌변을 구하지만 C#은 좌변 객체를 먼저 평가한다. 슬라이더 위치 콜백이 끝난 뒤 현재 노드에 쓰도록 반환값을 지역 변수에 저장한 다음 Node를 다시 조회한다. 별도 검사에서 콜백이 노드를 교체해도 옛 노드의32는 유지되고 새 노드에13이 기록됨을 확인했다.
