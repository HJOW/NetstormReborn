## 최초 수집과 수정

최초 수집의 튜토리얼 DN 시작이 `건설 소리는 같은 미션의 소리 프로세스 연결이 필요합니다`로 종료됐다. `HostMissionBurning` 생성자가 건설 음향을 빌릴 때, 실제 `StartMission`은 아직 `HostMissionAudio.BindPriest`를 호출하지 않았다. 집중 검사 장면은 음향을 먼저 설치하므로 이 제품 시작 순서 문제를 드러내지 못했다.

실제 `StartMission`에서 같은 사제/음향 프로세스를 먼저 설치한 뒤 연소/건설 표시를 조립하도록 순서를 맞췄다. 실패한 전체/수집 실행의 명령줄과 자식 PID를 확인해 해당 트리만 중단했다. 최초 자료는 `extracted/dotnet-0684/first/`와 `extracted/dotnet-l2-0684-first/`에 보관했다. Assets366건 통과 뒤 중단한 전체 검사를 완료된 회귀로 계산하지 않는다.

수정 후 Host Release 빌드는 경고0/오류0으로 통과했다(`fix-build.log`). 실패했던 튜토리얼1을 별도 수집한 양쪽 실행은 종료0이며 지표와 DN 덤프 전체 바이트가0.680과 같았다(`extracted/dotnet-l2-0684-check/`, `check-capture.log`). 전체 검사와65실행은 빈 새 출력 디렉토리로 다시 수집한다.
