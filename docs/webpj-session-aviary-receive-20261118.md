# WB04-E728: 아비어리 데이터 수신 정적 이식

cpppj `RawCampaignSession.cpp` 기준 `225553df`의 `ReceiveAviaryPacket`(5203~5229)과 Carrier 38h·73h·74h 등록을 정적으로 이식했다. 세 수신은 현재 Session의 실제 아비어리 본체와 Process Host를 사용하며 신규 Form의 현재 TYPE 선택·초기화·부모 DWORD 검증·부착과 기존 Form의 현재 PID 선택·필드 갱신을 원본 순서대로 연결한다. 선택된 필드가 없는 NULL PID는 빈 물리 범위로 전달한다.

사용자 지시에 따라 공중 3종 전용 생성·생산·우클릭·행동 관측이나 새 검사는 수행하지 않았다. 기존 웹 몸체와 cpppj 소스를 정적으로 대조하고 문법·대응표와 기존 전체 회귀만 확인한다. 실제 게임이나 브라우저 창도 열지 않았다. 런타임 동작은 전용 관측으로 검증되지 않았다.

문법·대응표 검사 오류 0, 기존 Node v26 전체 회귀 6,188건 통과다. Node v22는 E722에서 순차 전체 검사했고 현재 v26 주기는 6/8회다.

다음은 원본 순서의 53h 및 후속 Carrier 수신이다. 서버 응답 왕복, Native, 앱 미션 수명도 남았다.
