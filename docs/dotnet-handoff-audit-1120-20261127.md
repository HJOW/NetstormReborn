# dotnetpj 1.120 인계 미체크 항목 점검

2026-11-27 사용자 요청으로 현재 인계 문서의 실제 `- [ ]` 항목 65개를 완료 기준과 기존 근거에 대조했다. 보관본을 설명하는 문장 속 `[ ]`는 작업 항목으로 세지 않았다. 구현 일부가 있거나 다른 프로젝트에서 끝난 것만으로 DN의 화면·수명·실행·배포 완료를 판정하지 않았다. 이번 점검에서 완료 기준이 전부 충족됐으나 체크가 빠진 항목은 확인되지 않았다.
