# 원본 효과음 파일 선택과 감쇠 (WB04-E962)

기준선 `225553df`의 `SoundDevice::FindSoundFile`과 `SoundFileAttenuation`에 따라 미션 음향 적재기가 요청 이름과 실제 파일 이름이 다를 때도 원본 파일을 찾게 했다. 현재 언어별 디렉토리를 기본 디렉토리보다 먼저, 각 디렉토리에서는 `이름-*` 감쇠 파일을 일반 `이름*` 파일보다 먼저 선택한다. 같은 우선순위의 파일은 웹 매니페스트 순서를 사용한다. 경로의 첫 하이픈 뒤 정수는 원본처럼 감쇠 값으로 공개한다.

실제 `sunFenceImpact.wav` 요청이 공개 자산 `sunFenceImpact-500.wav`를 선택하고 감쇠 500을 반환하는 것을 확인했다. 요청 이름과 실제 파일 이름으로 동시에 요청해도 같은 물리 파일은 한 번만 내려받고 해독한다. 인공 매니페스트로 언어별·기본 경로와 감쇠 우선순위 및 원본의 음수·공백·앞선 하이픈 경계를 확인했다. 원본 디스크의 FindFirstFile 순서는 운영체제에 따라 달라 웹에서는 결정된 매니페스트 순서를 사용한다.

Node v26에서 음향 적재와 SoundPlayer 연관 검사 8건이 통과했다. Web Audio 장치와 SoundPlayer의 실제 재생·미션 연결은 남았다. E958 기준 Node v26 전체 회귀 6,529건은 통과했고 같은 고정 상태의 Node v22 회귀가 실행 중이다. E962까지의 다음 Node v26 정기 전체 회귀는 v22 종료 뒤 실행해야 한다.
