# 0.794 경로 패킷 작성·수신·송신 관찰

RawPathData.cpp/.h의 typed writer·Native WriteCurrent·Read·송신 observer를 같은 Runtime 이미지와 전달받은 실제 버퍼에 이식했다. 장기 GameAux.PathPacketHeader는 최초30h/1/BSS DWORD0을 한 번 만들고 일반 World Reset에서 재초기화하지 않는다. 실제 PathProcess와 MakePathFormTransmission·Host30h 수신/상위 Motion 연결은 다음 범위다.

typed writer는 판본별 이미지 크기/count/signed32 절삭과 기존 Source의 거리/반환길이 검사를 유지한다. Native 작성기는 count 진단 정상 복귀 뒤 실제 물리를 계속 읽고, 로그/진단 뒤 현재 이미지·packet+6 부모·nodeCount WORD를 다시 선택한다. signed64 절삭의 낮은DWORD와 비정상0, 거리DWORD 감김, signedWORD payload주소/반환도 보존한다. 음수 payload주소가 nodeCount의 낮은BYTE와 겹칠 때 BYTE 저장 뒤 바뀐 WORD를 증가하는 순서도 검사했다. 초기 선언 길이는 현재 unsignedDWORD 최소4 뒤 낮은WORD이며 실제 반환 길이와 구별한다. 미사용8~10BYTE와 반환 길이 밖 stale buffer는 지우지 않는다.

Read는 기존 count에 append하고 finished/targets/helper/꼬리를 먼저 쓴다. 압축 run은 최초 signed count를 보존하되 현재 payload/로그 장치를 읽으며 직접좌표는 각 조건의 현재 count를 읽는다. append는 point/direction/time→count++→용량진단이다. 의식점 callback 뒤 현재 부모 좌표/stage/count를 다시 조회하고 turning→speed→now→Prepare→clearAnimation 순서를 유지한다. 입력 부족/진단/선택 장치 실패에서 앞선 부분 효과를 되돌리지 않는다. observer는 sending0에서 물리를 읽지 않고 송신 sentinel 진단 복귀 뒤 현재 signedWORD+24의 낮은WORD를 기록한다.

기존 두 보호 PE의 pathdata-x86.tsv768행을 typed 작성기로, 그중 PATCH384행을 Native 작성기로 재생해 반환길이와 전체2048BYTE가 일치했다. Native384는 같은 자료의 부분집합이며 새 독립 관측384개로 계산하지 않는다. 수신/observer·가변 callback/진단 복귀 검사는 CPP Source 계약 증빙이며 별도 독립 PE 수신 관측이라고 주장하지 않는다. C# 출력으로 기대값을 만들지 않았다.
