# dotnetpj 1.076 — R5-4c 카메라 고향·특수 타일 건너뜀·메뉴 덮음 차단

2026-11-26, HJOW-Athlon. R5 HUD·덱·미니맵·인벤토리 묶음의 셋째 조각이다. 미션 입장
카메라 고향(내 사제·월드 가운데), 특수 셰이프 타일의 조용한 건너뜀, 미션 중 시작
화면 다시 그리기 차단을 이었다. 생산 덱·미니맵·인벤토리·메뉴 배경 숨김과 UberRoot
제품 결선은 R5-4c 나머지·R5-4d에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Core/Original/RawCameraHome.cs`: 신규. 원문
  `PATCH4340d0/CD488f6c8`의 초기 카메라 선택·`camera.setCenter` 중심 이동 몸체다.
  모드·소유자·화면·억제 깊이(`CameraHomeState`), 로딩 전역·Carrier preview 바깥 경계
  (`CameraHomeHooks`), 대본 `ViewSpot` 인자 해석, free 건너뜀·마지막 내 사제 선택·
  Challenge 분기·억제 깊이 올림/복원을 이식했다. 1.076에서 추가했다.
- `dotnetpj/src/Netstorm.Client/Host/HostSession.CameraHome.cs`: 신규.
  `ResetMissionCamera`가 같은 세션 풀·타입·카메라 목표로 고향을 옮긴다. 근거: cpppj
  `ClientRendererFrame.cpp`의 ResetCamera 결선이다. DN 제품은 매 프레임 Commit하므로
  목표 쓰기까지만 수행하고, 입장 경로의 Carrier preview에는 닿지 않아 억제 깊이를
  독립 카운터로 둔다. 시작 덤프에는 닿지 않는다. 1.076에서 추가했다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 미션 시작의 `ResetCamera` 순서에
  세션 카메라 고향을 이었고, 시작 화면 다시 그리기를 메뉴에서만 수행한다. 근거:
  미션 진입 뒤에도 시작 화면을 다시 그리면 구름·타이틀이 월드를 덮는다. 팔레트 준비는
  첫 호출에 끝났다. 1.076에서 수정했다.
- `dotnetpj/src/Netstorm.Client/Display/RawTileSprites.cs`: 특수 셰이프 레코드는 그림이
  없으므로 원문처럼 조용히 건너뛴다(기존 `InvalidDataException`은
  `thewarbegins`·`surrounded` 진입 수집에서 FATAL이었다). 1.076에서 수정했다.
- `dotnetpj/tests/Netstorm.Core.Tests/RawCameraHomeTests.cs`: 신규 12건(범위·선택·
  죽음 복귀·대체·타입 오류·억제·preview·감김·Challenge·ViewSpot). 1.076에서 추가됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostMissionCameraTests.cs`: 신규 2건(내 사제
  고향·사제 없음 대체). 1.076에서 추가됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/RawTileSpritesTests.cs`: 특수 프레임 조용한
  건너뜀 1건을 더했다. 1.076에서 수정했다.
