실제 Netstorm.exe/Netstorm.dll과 Client/Core/Assets/Net의6파일을 SHA256으로 고정했다. 일반31경로 양쪽62회와 CPP데모3회는 영어·1024×768·창모드·음소거·빈 사용자루트·Unix1760000000·25ms·120프레임 조건이며90프레임의 전체 session-dump를 수집했다.

- **65회 모두 종료0·수집 오류0**, 양쪽 엔진은 각각 같은 실행 파일을 썼고 DN 실행6파일도 전후 불변이다.

- CPP는 기존 미초기화 SP행 열3(owner0 SP) 외 변동이 없다. 기대값을 새 DN 결과로 갱신하지 않았다.

L2 수집기 자체의 종료1은 전체 동일성 미달 결과이며, 개별 게임 프로세스65개의 종료0과 구별한다. 관문은 오류·실행 종료·완전 덤프·지표·빌드/원본/자료 불변을 별도로 감사했다. 포획·희생·특정 적 공격·승리 재현 입력은 보내지 않았고 사용자 지정 검사 범위를 유지했다.
