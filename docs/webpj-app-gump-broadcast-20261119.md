# WB04-E917: Client Gump 프레임 방송

cpppj `RawButtonControls`의 같은 등록표 기반 `GumpFrame::Broadcast`와 가상 분배를 Client 소유자에 연결했다. 파생 노드별 방송 처리기는 다른 입력·부착·소멸자와 같은 수명으로 등록·반납한다. 기본 노드의 방송은 원본처럼 빈 본문이며, 방송을 요구하는 미연결 파생은 명시 오류다. 실제 구분선은 이 경로에서 `HudDividerInput.broadcast`를 실행한다.

실제 Client 트리에서 마우스 누름 후 공통 `broadcast`가 표시·통지·비dead 필터를 거쳐 구분선 드래그 및 연결된 자식 크기 갱신으로 이어지고 release·삭제하는 것을 확인했다. 별도 검사에서 숨김·통지 해제·dead·반납 뒤 분배를 확인했다. 관련 Node 검사 17건이 통과했다.

이 단계는 Client 내부 방송을 연결한다. 브라우저 포인터 큐와 앱 프레임의 실제 호출, 다른 파생의 idle·방송, 전체 HUD UI는 아직 남았다.

Node v26.13.0 전체 회귀 6,480건이 실패·취소·건너뜀 없이 통과했다.
