# 1.160 객체 정보의 실제 세션 장치

객체 정보 작성기에 같은 현재 세션의 TYPE 표, 실제 자산 정의의 class, 로컬 소유자·편집/미션 모드, 현재 동맹 및 Player 상태, 사제 지면 판정을 결선했다. 외부 메뉴·번역·서식·소유자 이름과 가상 수량은 호출자가 공급하며, 완전 적재 전에는 원본처럼 진입을 거부한다. 제품에 아직 호출자를 설치하지 않았다.

실제 자산과 세션을 사용하는 검사에서 부분 적재 거부를 먼저 확인하고, 검사 전용 적재 표식 아래 동맹 변경을 매 호출 반영함을 확인했다. 원본 객체 정보1,434행과 현재 소유자 이름 검사까지 집중7/7 통과했다. 최초 검사에서는 실제 파일 정의 수가 전체 TYPE 슬롯 수보다 적은데 같다고 가정해 실패했다. 기존 자산 로더처럼 범위 안에 있는 정의만 허용하도록 고친 뒤 재실행해 통과했다. 실제 제품의 완전 적재·가상 수량·우클릭 메뉴는 여전히 미완료다.

게임 실행은 하지 않았고 1.158 실패 수정 후 Client 전체 회귀는 별도 실행 중이다.
