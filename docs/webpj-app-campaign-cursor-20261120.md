# 앱 미션 커서 장치 (WB04-E1005)

로그인 완료 시 실제 Session의 커서를 앱의 Gump 직접·재귀 명령, 현재 Renderer, 언어와 글꼴, 마우스, 선택 및 로컬 전송에 연결한다. 화면점 조회는 원본과 같이 루트 직계만 선택하고 Gump 부모 SID는 UI 부모가 아닌 object 필드를 읽는다. 비용 팝업과 기록 장치 등 미연결 경로는 실제 선택 시 오류로 남긴다.

실제 다리 취득에서 배치 메타데이터의 배열을 프레임 코드 표로 잘못 취급하던 오류가 드러나 동일 월드의 실제 FrameCodeTable을 사용하도록 고쳤다. 실제 Tutorial1의 자동 생산 다리를 같은 앱 커서로 집고 취소하는 Node 통합 검사와 미리보기·커서 검사를 포함한 21건, 기존 Chromium 미션 흐름 1건이 통과했다. 아직 생산 키와 UI, 실제 배치 검증은 연결되지 않았다.
