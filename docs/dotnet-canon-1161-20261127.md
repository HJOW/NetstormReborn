# 1.161 정기 회귀 재검증

1.158 최초 회귀의 Assets 383/383, Core 4,121/4,121 통과를 재사용한다. 이후 두 프로젝트 코드는 바뀌지 않았다. 누락된 원본 대조 목록 등록과 1.159 소유자 이름 조회를 포함한 Release 빌드에서 Client 전체를 다시 실행해 2,963통과·실패0, 음향 하드웨어1건은 TRX상 NotExecuted다. 합계 7,467통과이며 미실행을 통과로 세지 않는다.

최초 목록 누락 실패와 수정은 [1.158](dotnet-canon-1158-20261127.md)에 보존한다. 최초 세 결과는 `extracted/dotnet-1158-regression/`, 수정 후 Client 결과는 `extracted/dotnet-1160-regression/`에 있다. Client 빌드 이후 추가된 1.160 객체 정보 세션 결선과 그 뒤 변경은 이 회귀에 포함되지 않으며 M1 0/34 기준도 변하지 않는다.
