# 1.153 정기 회귀 재검증

1.151 최초 회귀의 Assets 383/383, Core 4,121/4,121 통과 결과를 재사용한다. 이후 이 두 프로젝트 코드는 바뀌지 않았다. 선택 검사 수명 수정과 1.152 제품 효과 경로를 포함한 별도 Release 빌드에서 Client 전체를 다시 실행해 2,956통과·실패0, 음향 하드웨어1건은 TRX상 NotExecuted다. 합계 7,460통과이며 음향 하드웨어를 통과로 세지 않는다.

첫 Client의 실패1건과 검사 수명 교정은 [1.151](dotnet-canon-1151-20261127.md)에 보존한다. 최초 세 결과는 `extracted/dotnet-1151-regression/`, 수정 후 Client 결과는 `extracted/dotnet-1153-regression/`에 있다. 1.152 이후 생산 갱신 등의 새 변경은 이 회귀에 포함되지 않으며 M1 0/34 기준도 변하지 않는다.
