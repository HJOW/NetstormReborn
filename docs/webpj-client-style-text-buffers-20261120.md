# Client 다중 줄 스타일 버퍼

WB04-E1039는 실제 Client 글자 Gump의 조각 저장소와 StyleText·FontSet·Markup 그림 복제를 다중 줄 버퍼에 연결한다. 버퍼 토큰은 Gump 등록 ID와 별개이며, 완료 줄과 그림 복제는 기존 원본 소멸 순서를 따른다. 같은 Markup 객체를 다중 줄 처리기에 빌릴 수 있도록 생성 시 관찰 경계도 제공한다.

Tutorial1 실제 글꼴과 fortGump 그림을 한 줄에 추가하고 줄 배치·폭 측정·조각 반납을 확인했다. 관련 Node 검사 32건이 통과했다. 다중 줄 Gump 생성·출력·입력과 메뉴 연결은 아직 남아 있다. 기존 다중 줄 스타일 파서의 유니코드 입력 연결도 별도 작업이다.
