# dotnetpj 0.918 — RU-3 배틀 제외·제거 메뉴 이식

2026-11-24, HJOW-Athlon. RU-3 열한 번째 묶음이다. 배틀 메뉴 자식 후반(제외·제거)을 같은 controlled 스택 작성에 연결했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `BuildBattleExcludeMenu`는 `cpppj/src/client/NativeBattleInfoMenus.cpp`의 제외 메뉴 전체를 이식했다. 12별칭 단축평가·TYPE 분류(Spells 비트·테마)·기타 그룹 100/나머지 50 용량·여섯 정렬·다섯 하위 메뉴 출력 순서(Spells/Sun/Wind/Rain/Thunder, 기타 미출력)를 원문대로 유지한다. 각 행 설명은 정렬 때 재사용하지 않고 작성 때 다시 읽으며 빈 배열도 같은 정렬 부모에 전달한다.
- `BuildBattleRemoveMenu`는 제거 확인 메뉴를 이식했다. TYPE 조회 뒤 Fancy 생성·현재 번역·설명 서식·Yes(`TYPE`)/No(`0`) 항목을 같은 `5429e4` 명령으로 작성한다. 선택 문자열 정체성은 주입 장치에 맡기고 미연결 장치는 일반 성공으로 꾸미지 않는다.
- 합성 TYPE 표·지식 행 검증이라 신규 fixture는 없다. 네 공장 설치·바깥 UI·NativeRoot/HUD 창 생성·Enter·HUD 작성자·Root reply 저장은 후속 단위에서 잇는다.
