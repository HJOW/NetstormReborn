# WB04-E726: 비행 데이터·명령 수신 정적 이식

cpppj `RawCampaignSession.cpp` 기준 `225553df`의 `ReceiveFlyerPacket`·`CurrentFlyerProcess`·`ReceiveFlyerCommand`(5231~5260)과 Carrier 39h·86h 등록을 정적으로 이식했다. 39h 신규 분기는 임시 필드로 부모 테마를 읽고 새 Process에 다시 해석한 뒤 같은 Host에 명시 Form으로 부착하며, 기존 분기는 현재 PID를 갱신한다. 86h는 선택된 명령만 현재 부모의 첫 종속 Form과 실제 PID에 전달한다. 진단 복귀 후 조회와 임시 필드 정리 순서를 유지한다.

사용자 지시에 따라 이 단위에서 공중 3종 전용 생성·생산·우클릭·행동의 관측이나 새 검사를 하지 않았다. 원본 소스와 기존 웹 몸체를 정적으로 비교하고 문법과 기존 전체 회귀만 확인한다. 실제 게임이나 브라우저 창도 열지 않았다. 런타임 동작은 전용 관측으로 검증되지 않았다.

문법·대응표 검사 오류 0, 기존 Node v26 전체 회귀 6,187건 통과다. Node v22는 E722에서 순차 전체 검사했고 현재 v26 주기는 4/8회다.

다음은 원본 순서의 3bh·3ch 총 애니메이션 수신이다. 나머지 Carrier, 서버 응답 왕복, Native 및 앱 미션 수명은 남았다.
