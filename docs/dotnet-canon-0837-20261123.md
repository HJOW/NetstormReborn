# dotnetpj 0.837 — 같은 실제 생산 동기화·색표 소비자와 중지 인계

2026-11-23, HJOW-Athlon. 현재 단위까지 검증·문서·커밋을 마치고 목표를 일시 중지하라는 사용자 요청을 반영한다. 다음 단위는 시작하지 않았다. 실행 경로는 `dotnetpj/src/Netstorm.Game/bin/Release/net10.0/Netstorm.exe`다.

## 변경

- Source ClientProductionSync의 실제 대여 분기와 장기 Player/Deck/현재 기술·신전 DWORD/Finder/RawCarrierPreDestroy kind WORD 조립을 추가했다. known0 메뉴도 실제 Deck getter와 SID0 조회를 생략하지 않는다. 선택된 큰 효과만 실제 Session을 요구하며 가짜 생성/삭제로 대체하지 않는다.
- Session 생산 장치 생성 위치에서 같은 실제 Deck/기술/내용물/가상 삭제의 RawProductionSync를 구성하고 반납 때 연결을 해제한다. Source의 `!loaded && !editorUiInstalling && !editorPrefixUiInstalling` 거부와 실제 커서 관문을 추가했다.
- **현재 세 설치 값은 초기 false이며 실제 Source Load/Editor 공개 부모는 아직 미연결이다.** 기존 부분 Game 적재나 공개 Runtime을 loaded로 간주하지 않는다. 이번 검증은 설치 전 거부와 worldless 분기를 증명하며, 설치 후/Editor 두 동기 범위의 실제 성공을 증명하지 않는다. 이 미완료 경계를 임의 true 쓰기로 우회하지 않는다.
- 실제 Game이 같은 Storage/Gameplay/PlayerRecords/옵션87/SP/OwnerTables의 생산 문맥을 첫 UI 뒤 한 번 보관하고 같은 Client 동기화 진입점을 제공한다. 실제 생산 패널/전체 Root 공장에 연결하는 작업은 다음 단계다.
- 실제 본문 그림은 최초 COL에서 별도 Shadow 표를 계산하던 경로 대신 같은 현재9표의7번 행을 getter로 빌린다. 고정 RGB/primary와 같은9배열 수명은 유지한다.
