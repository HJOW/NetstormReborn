# dotnetpj 1.070 — R5-3b 타일 스프라이트 출력

2026-11-26, HJOW-Athlon. R5 타입별 Draw·효과 묶음의 둘째 조각이다. 수집한 타일 항목의
일반 그림을 실제 SHP 픽셀로 출력하는 장치를 이식했다. 소유자·그림자·죽음·추상·가상 분기와
프레임 구동 결선은 뒤 조각에서 잇는다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Display/RawTileSprites.cs`: 신규. `DrawTile`을 두었다.
  근거: cpppj `RawCampaignFactoryDisplay.cpp`의 `DrawEntry`가 타일에 쓰는
  `SpriteDraw::Draw` 일반 분기(498220 제외)다. 토큰·SID·타입 범위, 판본별 프레임·extra
  바이트, 블록=타입−70·프레임 범위, 월드/화면 좌표 일치, 타입 핫스폿 기준점, half-open
  clip의 끝 포함 pane 변환을 지키고 VFX SHP를 직접 합성한다. 일반 외(꼬리 4·추상·죽음·
  가상)는 R5-3c 명시 실패로 둔다. 화면 밖은 가장자리 타일의 정상으로 둔다. 1.070에서 추가했다.
- `dotnetpj/tests/Netstorm.Client.Tests/RawTileSpritesTests.cs`: 신규 3건. 실제
  `_shapes.shp`의 불투명 프레임 타일을 골라 배치 일치·클립 제한·일반 외/불량 거부를
  대조한다. 불투명-인덱스-0 픽셀까지 포함한 전체 배치 대조다. 1.070에서 추가됐다.
