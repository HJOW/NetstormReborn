# dotnetpj 0.827 — 현재 owner 색표·생산 문맥·장기 검색 공유

작업일2026-11-22, PC HJOW-Athlon. 전체 생산 부모가 사용할 Source owner 색표 저장소와 문맥을 이식하고 실제 초기 UI/Session이 같은 장기 검색 상태를 빌리도록 연결했다. 실행 경로는`dotnetpj/src/Netstorm.Game/bin/Release/net10.0/Netstorm.exe` 한 곳이다. 전체 생산 부모 설치와 ClientProductionSync의 실제 Session 설치 범위는 계속 남았다.

## 변경

- `OwnerColorTableOperations`는 0043bc40/0043be30의 준비/같은값 관문, enabled→redraw DWORD store·감김, 현재 TYPE/토큰 재조회·free 복귀 뒤0쓰기, 강제ffffffff 설정과 일반12/전용3표의 초기 등록 순서 전체다. 선택한 외부 효과만 요구하고 실패 전 효과를 유지한다.
- `OwnerColorTableState`는 ready0/enabled1로 시작하고 실제 완성된 RawColorSortPrimary를 같은 장기 owner로 보유한다. 기존 일반/전용 색표 계산 본체를 재사용하며 TYPE별9×256BYTE 표와 opaque 토큰을 관리한다. 배너를 전환해도 이전 토큰 뷰와 EnabledBox 주소는 유지되고 현재 값/현재 색표를 읽는다. 초기 등록은 한 번이며 색표가 없는 토큰·잘못된 정렬/색번호를 거부한다. 실제 Client 첫 색표 생성/F7 장치와의 공급은 후속이다.
- `ProductionControlContext`는 실제 장기 Storage/Gameplay/PlayerRecords와 옵션 배열, 선택적인 실제 SP/OwnerColorTableState를 빌린다. 별도 옵션/Player 배열을 만들거나 Runtime 대여를 설치 완료로 해석하지 않는다.
- `ClientGameplayGlobals.ProductionFinder`는 실제 최초 SID0 조회부터 같은 권한/TYPE/checking owner를 읽는다. `HostSession.ProductionFinder`와 기존 AI/생산 조회도 이 객체를 빌린다. Session을 캡처하던 검색 장치 재결선을 제거해 장기 뷰가 이전 Session을 보유하지 않게 했다. 일반 미션 fresh 설치 위치에서만 Source finder 기본값을 같은 주소에 쓰며 prepared 대여/반납은 현재 상태를 보존한다.
