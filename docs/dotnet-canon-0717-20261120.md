# 0.717 실제 Host 후처리의 현재 Runtime 대여

실제 HostSession은 RawSurfaceWorld 객체를 소유하지 않으므로 직접 생성한 기존 후처리 부모에 현재 외곽 대여를 전달했다. 섬/지형 부모, 그래프 교체 부모, 억제 적재 부모, live Player 부모와 최소 AI 부모2곳의 총6생성지점을 같은 약한 장부로 등록한다. 현재 pin의 함수 사본만 넘기며 준비 단계의 게임 조회·초기화·가짜 owner 생성은 하지 않는다.

Runtime 공개 전에 생성한 부모는 공개 때 갱신하고, 공개 후 생성한 부모는 즉시 같은 pin을 받는다. 이전 그래프 부모가 실제 caller에 살아 있는 경우도 다음 공개/반납을 함께 따르며 장부 자체는 이전 부모를 강하게 보유하지 않는다. 이미 실행 중인 호출이 보유한 대여는 변경하지 않는다. Player 고정뷰 최종 정리는 실행 중 배송 관문 뒤 pin을 먼저 분리한 다음 자식 정리를 호출한다. 정리 중에는 현재 Gameplay owner를 다시 요구하지 않고 직접 소유한 같은 세션 장치를 사용한다. 앞선 pin 분리/자식 부분 효과를 정리 실패 때 롤백하지 않으며 Player 고정뷰 대여는 기존 규칙대로 정상 정리 뒤만 반환한다.

Client 집중27건(신규4/기존23)이 모두 통과했다. 실제 자산으로 조립한 Host의 공개전/공개후 부모, 그래프 교체전/현재/live부모의 다음 owner 공개, 효과 내 실제 RuntimeCallActive와 고정뷰 반납 거부, 예외의 앞선 장부 쓰기/깊이 보존·외곽 종료 지연·마지막 복귀 반납, 최종 pin 해제를 확인했다. 기존 제품 진단 API를 추가하지 않고 검사에서만 실제 private 부모를 reflection으로 빌려 기존 선택 재검사 효과를 관찰했다. 근거는 `extracted/dotnet-0717/client-initial.log`와 `host-postpop-initial.trx`다.

실제 DN thewarbegins 시작/종료1회는 종료0이며 덤프 전체 바이트가0.716과같고원본1392파일SHA도불변이다. 시드1760000000·25ms/90프레임·영어1024×768창/음소거를사용했다. 근거는 `extracted/dotnet-0717/smoke.py`·`smoke-summary.json`·`smoke/thewarbegins/dn/run.json`/`f090.tsv`다. 실제 포획/희생·특정 적 공격·승리 재현은 하지 않았다.

cpppj RawSurfaceWorld.cpp의BindRuntimePin과RawCampaignSession.cpp의공개/종료순서를대조했다. PORT_MAP의기존Session2행기준은같으며RawSurfaceWorld2행을새로추가했다. cpp_sync종료0·연결fixture360개불변이다. Factory/ProcessRuntime과건설효과의전체대여전달, 전체Login/State/전송Root는아직남는다. 다음0.718은이실제하위장치들의현재수명결선을이어간다. 정기전체회귀는0.720이며M1/전체목표는미완료다.
