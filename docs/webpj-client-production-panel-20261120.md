# Client 생산 패널 조립

WB04-E1032는 기존 생산 유지 상태를 가진 Session에 원본 생산 패널의 예산·세 배경·두 격자·구분선을 공통 Gump 트리로 조립했다. 80픽셀 도킹 폭과 하단 80픽셀 예약, 실제 기술 GumpForm, 격자 재부착, 선택과 다리 슬롯 명령을 연결한다. 기존 생산 유지 상태 객체를 그대로 빌리며 별도의 다리 공급 상태를 만들지 않는다.

실제 Tutorial1 Session과 공통 Gump 입력에서 아이콘 픽셀을 눌러 실제 내용물 SID가 커서 미리보기에 들어가고 취소됨을 확인했다. 다리 슬롯 명령, 두 기술 Form과 패널 삭제도 검사했다. 관련 Node 26 검사 21건 및 Node 22 앱 검사 4건이 통과했으며 마지막 생성 수명 보강 후 앱 검사를 다시 통과했다.

이 조립은 아직 앱 화면에 설치되지 않았다. 현재 생산 유지의 재부착 콜백, 금액 idle, 실제 색표·옵션·소리·안내 및 화면 크기 변경을 앱과 결합한 뒤 Chromium에서 확인해야 한다. E1030 고정 Node 26 전체 회귀는 실행 중이다.
