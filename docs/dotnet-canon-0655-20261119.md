## 이식 (증거)

- `dotnetpj/src/Netstorm.Core/Original/RawAiCollectors.cs`: `AiCollectorsGlobals`(시각·로컬 owner·무효그래프)·`AiCollectorsHooks`(생산·비용·최대HP·적·배치·생산·로그·소리)·`RawAiCollectors`(`Ensure`·`PlaceInHome`·`DeployWithNotice`·`HasFlying`·`Vulnerable`)를 추가했다. 취약 사제용 비행 수집자 또는 일반 수집자 선택, 자기 경계 y→x 난수 후보 배치(최대 20회), 배치→생각 기한·로그→로컬 소리, 수집자 목록 비행 genus 판정, 현재 HP 선저장·최대HP/2 비교를 원문 순서대로 실행한다. 같은 PATCH 풀·TYPE 계약을 먼저 확인하고 후보 배치에서만 같은 게임 난수를 소비한다. 근거: cpppj `o/RawAiCollectors.h/.cpp` 전체(53·90행)다.
