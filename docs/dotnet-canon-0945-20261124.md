# dotnetpj 0.945 — 메타 전투 master 조회 본체 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 0x7c 메타 게임 로그인과 메타 연결이 공유하는 현재 전투의 첫 master 참가자 조회 본체를 같은 CS에 연결했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientMetaBattleMaster.Find`는 004b2c60 전체를 이식한다. 전투 번호가 0이면 전투 기록을 읽지 않고 -1이며, 8칸을 순서대로 읽어 0 후보를 건너뛰고 flags bit4가 선 첫 후보를 반환한다. 별도 active 조건을 더하지 않으며 범위 밖 전투·참가자는 원문 상한에서 거부한다. 0.945에서 추가됐다.
- 0x7c 수신 본체와 설치는 master 조회·현재 구독자·연결 장치가 마련되는 대로 잇는다.
