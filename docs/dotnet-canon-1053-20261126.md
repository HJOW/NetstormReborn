# dotnetpj 1.053 — SL-2b PlayIntro 분배 이식과 SL-2 마감

2026-11-26, HJOW-Athlon. SL-2의 두 번째 조각이다. PlayIntro 일반 입력 분배를 이식하고
SL-2를 마감한다. 장면음악은 SL-3(나머지 음향)에서, Guide 진입은 R6(튜토리얼 모드 진입·
브리핑 흐름)에서 잇는다. 지도 초기화(카메라·월드 셀)는 제품에 연결되어 있다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/RawIntroMenu.cs`: `DispatchPlayIntroInput`과
  `PlayIntroCommand(0x020000d8)`를 추가했다. 근거: cpppj `IntroMenu.cpp`의
  `DispatchPlayIntroInput`이다. 명령이 아니면 소비하지 않고, 뗌은 소비만 하며, 누름은
  next[0]=39·next[35]=1을 쓴다. 버튼 노출·State39·영상 재생은 R6에서 잇는다. 1.053에서
  추가했다.
- `dotnetpj/tests/Netstorm.Client.Tests/IntroDetectTests.cs`: 3건을 추가했다. 명령 아님·
  Esc의 미소비, 뗌의 소비만, 누름의 다음 블록 쓰기와 짧은 블록 거부를 대조한다. 1.053에서
  추가됐다.
