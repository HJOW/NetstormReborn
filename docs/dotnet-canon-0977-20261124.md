# dotnetpj 0.977 — Build에 참가자 이름 0x88·전투 옵션 0x67 수신기 연결

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 같은 장기 기본 표를 공유하는 `ClientPacketDispatch.Build`/`InstallDefaults`에 원문 앱 전역 0x88 참가자 이름·0x67 전투 옵션 수신기를 연결했다. 0x71·0x21 Build 연결과 제품 기존 경로는 바꾸지 않는다. 세션·메뉴 결합 후크 중 0x20·0x22·0x23·0x24·0x25(NSInfo·생성·좌석·Chat·번역·안내·표시·음향 장치 필요)와 Root Source 공개·제출 갈래, RU-3 나머지·R4-4 정기 두 단위는 후속에서 잇는다.

## 변경과 원문 대응

- 0x88 후크는 실제 장기 장치를 공유한다. CS 조회·이름 복사는 실제 CS에 수행하고 번역·등급·표시·NSInfo만 후속으로 명시 실패한다. 미발견 구독자는 호스트 오류로 표시하고, 비활성은 조용히 돌아가며, 유효 이름은 복사 뒤 번역 앞에서 멈춘다. 새로 만든 본체가 없다. 0.977에서 추가됐다.
- 0x67 후크는 실제 장기 장치와 0x1d와 같은 호출자 진단 장치를 공유한다. 게임·CS·저장소·상태·진단·수준9 로그는 실제 owner이며, 바깥 옵션 복사·범위·비용은 실제 값을 계산하고, 저장·음향·NSInfo·재생성만 후속으로 명시 실패한다. 무효 전투·초과 길이는 로그만 남기고, 자기 master는 조용히 넘기며, 일반 경로는 음향 앞에서 멈춘다. 새로 만든 본체가 없다. 0.977에서 추가됐다.
- 0x88·0x67의 수준9 로그는 원문 대응으로 같은 호출자 진단 장치에 코드 9를 붙인다.
- 수송 팩토리(`ClientCampaignTransport.Make`)는 같은 `InstallDefaults`를 공유하므로 두 항목을 자동으로 공유한다.
