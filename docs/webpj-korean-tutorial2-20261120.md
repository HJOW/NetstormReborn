# 한국어 두 번째 튜토리얼

WB04-E1062는 Tutorial2의 모든 단계 안내·완료 버튼을 한국어로 옮기고 웹 한국어 묶음에 포함한다. 실행 Header, 섹션 순서, 버튼·설정 명령과 원본 그림 태그를 영어 원문과 비교했다. 아직 번역하지 않은 Tutorial3의 영어 대체도 확인했다.

Node 26 관련 22건, 실제 Chromium 미션의 첫 두 페이지와 자산 복사본 검사가 통과했다. 첫 두 화면의 갈무리11과 줄바꿈을 직접 확인했다. 두 번째 페이지에서 그림 태그는 보존됐지만 본문의 원본 그림이 화면에 보이지 않아 Tell 그림 출력은 별도 구현·검증이 필요하다. 뒤쪽 단계의 실제 화면과 나머지 튜토리얼·캠페인 번역도 남았다.
