# 1.175 현재 실행본 34경로 L2 재수집

1.171의 지역 소유권 변경을 포함한 DN Release 사본과 현행 CPP 실행본으로 일반31미션·데모3경로를 각각 별도 사용자 루트에서 진입하고 90프레임 덤프 뒤 종료했다. **68회 모두 종료0**, 오류·누락0이며 `originals` 1,392개 파일은 전후 불변이다. 공격·포획·희생·승리 조작은 하지 않았다. 각 실행 제한은 기존 60초에서 180초로 늘렸고, 그 외 수집 경로와 설정은 기존 도구를 사용했다.

전체 행 L2 일치는 **0/34**다. 일반31경로의 cpp_only997·dn_only21, 공통 SID 101,731개 중 소유자 일치 97,413개·슬롯 전체 일치 76,643개다. 이전 0.998은 같은 집계에서 각각 997·21·101,731·90,434·72,783이다. 이번 CPP 실행본 SHA-256은 `6851dfabaa7f6b8eb98eb4c8b312b9374d3287ae4ee845552d6fd9d78dc0846b`이며 이전 실행본도 달라 위 개선 전체를 특정 변경의 효과로 단정하지 않는다. DN의 실행기뿐 아니라 실제 DLL 해시는 `extracted/dotnet-l2-1173-binary/capture-hashes.json`에 기록했다.

수집 당시 구 비교기의 `summary.json`은 보존하고 1.174 비교기로 실제 덤프를 다시 읽어 `summary-clock.json`과 `analysis.json`을 별도로 만들었다. 34경로 모두 게임 시각 비트가 다르다. CPP/DN 시각 쌍은 9.2/2.25초 21개, 10.6/2.25초 10개, 9.3/2.25초 2개, 11.225/2.25초 1개다. 그러므로 이 결과는 동일한 입력 단계의 현행 관측이며 같은 게임 시각의 동등성을 뜻하지 않는다. 동시각·동일 진행 상태 비교, M1과 실제 플레이는 미완료다.

전체 자료와 각 실행 인자·로그·해시 감사는 `extracted/dotnet-l2-1173/`에 있다. 비교기 자체는 불일치가 있어 종료1을 반환했으며 이는 각 게임 실행의 종료 코드와 구별한다.
