# 1.158 정기 회귀와 원본 대조 목록 교정

1.157까지의 Release 정기 회귀에서 Assets 383/383과 Core 4,121/4,121은 통과했다. Client는 2,961통과·1실패·음향 하드웨어 1미실행이다. 실패는 1.157에서 연결하고 전수 대조한 `object-menu-info-x86.tsv`가 공통 fixture 목록에 등록되지 않은 것이다. 원시 결과는 `extracted/dotnet-1158-regression/`에 있다. 이 최초 실행은 전체 회귀 성공으로 세지 않는다.

`cpp_sync.py --update --add object-menu-info-x86.tsv:Client`로 실제 원본 파일의 SHA-256과 1,434행만 목록에 추가했다. 다른 목록 항목은 변경되지 않았다. 목록의 연결·해시·형식 검사와 객체 정보 전체 대조는 5/5 통과했다. 수정된 Client 전체 재실행이 필요하며 최신 성공 전체 회귀는 1.153이다.
