# WB04-E818 적재된 Session의 Client State 정리

기준선 `225553df`의 State 정리 부모와 E817에서 조립한 장기 소유자에 실제 `TheWarBegins` Fort를 적재한 Session을 연결했다. 정리 부모가 같은 Session의 AI·Player 링크·Kernel 자식 증빙을 소비하고 외곽 Session과 표면 대여를 반납한 뒤 Player를 재구성하는 경로를 검사했다. Gump 정리·교체가 외곽 반납보다 먼저 실행되고 재접속 기한이 벽시각 + 10초로 설정되는 것도 확인했다.

최초 집중 검사에서 적재된 커서가 화면 dirty 장치를 요구함을 확인하고 관찰용 장치를 제공했다. UI·음향·시계는 검사 대역이며, 실제 Client/앱의 UI·음향 수명과 Login/Start 이후 정리, Native 분기는 아직 연결하거나 검증하지 않았다. 이 단위는 게임 창을 실행하지 않는다.

검증: 집중 검사 1건과 Node v26.13.0 전체 6,305건 통과(실패·취소·건너뜀 0). 대응표는 1,160행 오류 0이다. E811의 Node v22 전체 검사 뒤 v26 전체 회귀 7/8회다.
