# WB04-E936: Client 돌 버튼과 배경

cpppj `RawButtonControls`의 돌 버튼 조립 일부를 `ClientStoneControls`로 연결했다. 같은 Client 등록표·트리·수집·입력·방송·idle·수명 위에서 기존 ButtonGump와 StoneButtonGump, 실제 배경 생성기를 사용한다. 버튼 상태·팔레트·자산·시계·소리·기본 입력 장치는 호출자가 공급한다. 생성 전 파생 할당과 생성 실패 뒤 미부착 배경도 등록 여부에 맞게 실제 수명 또는 미등록 반납으로 정리한다.

실제 Client 트리에서 버튼과 배경 생성, 마우스 캡처·방송·idle·뗌, 자식 우선 반납을 확인했다. 비0 배경 타입 장치가 없는 실패와 생성 전 할당도 정리했다. 원본 버튼 관측을 포함한 관련 Node 검사 27건이 통과했다.

실제 Slider·TextEntry 공장, 앱의 현재 자산·소리 장치 및 버튼의 픽셀 출력과 브라우저 입력 분배는 아직 연결하지 않았다.
