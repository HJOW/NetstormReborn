# dotnetpj 0.917 — RU-3 지식 정렬·배틀 메뉴 전반 이식

2026-11-24, HJOW-Athlon. RU-3 열 번째 묶음이다. 지식 행 CRT 정렬과 배틀 메뉴 자식 전반(정렬·전체·개별)을 같은 controlled 스택 작성에 연결했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `KnowledgeSort`는 `cpppj/src/client/KnowledgeSort.cpp`의 지식 행 비교·정렬을 이식했다. 7우선 플래그 분류·C 로캘 ASCII 대소문자 접기 비교와 CRT 작은 구간 선택·중앙 피벗·동률 제거·큰 구간 보관을 원문 순서대로 보존하며 표 밖 TYPE와 스택 넘침은 명시 거부한다. 합성 행 검증이라 신규 fixture는 없다.
- `NativeBattleInfoMenus` 전반 3종은 `cpppj/src/client/NativeBattleInfoMenus.cpp`의 정렬·전체·개별 메뉴 작성을 이식했다. 각 행의 choice→current→명령→choice 재조회 순서와 정체성 비교, 번역되지 않는 정렬 라벨, 활성 설정만의 세로 하위 메뉴, 포함 최댓값 캡처·이름 제목·256BYTE 서식을 원문대로 유지한다. 선택지 주소 정체성은 주입 장치에 맡기고 미연결 장치는 일반 성공으로 꾸미지 않는다.
- `BattleOptionMenuText`의 정체성은 같은 실제 선택/번역 포인터의 논리 값이며 호스트 임시 문자열 주소가 아니다. 제외·제거 메뉴와 네 공장 설치·바깥 UI·NativeRoot/HUD 창 생성·Enter·HUD 작성자·Root reply 저장은 후속 단위에서 잇는다.
