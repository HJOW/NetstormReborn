# dotnetpj 1.035 — WP-2 제품 Root Path/Start/Motion 설치

2026-11-25, HJOW-Athlon. R4-6 월드·경로 묶음의 두 번째 조각이다. 제품 Root 미션 흐름에
실제 Motion 전체 부모를 설치했다. 본체·API·Host·Native 30h는 0.801에서 완료됐고,
이번에는 세션 Root급 효과 묶음(`BuildMotionRootEffects`)과 한 번 설치
(`BuildMotionRootDevices`)를 제품 진입 경로(`ClientHostGame`)에 연결했다.
입력·음향·포획·회피 갈고리와 CD 전용 갈고리는 명시 거부다.

## 변경과 원문 대응

- `dotnetpj/src/Netstorm.Client/Host/HostSession.Motion.cs`:
  `BuildMotionRootEffects(definitions)` 신규. Metadata(실제 정의 속도·회전·기본 프레임)·
  벌프 난수(실제 게임 난수)·의식 목표점(실제 세션 신전 의식)·정리 예약/의식·가상 삭제는
  실제 장치다. Cd*·PlayAt·Robust는 원문 FillMissing처럼 명시 거부한다. 근거: cpppj
  src/client/RawCampaignSession.cpp 3899~3928행의 effects 조립이다. 1.035에서 추가됐다.
- `dotnetpj/src/Netstorm.Client/Host/HostSession.Motion.cs`:
  `BuildMotionRootDevices(definitions)` 신규. 섬·앵커(그래프 준비·펜스·바람 사냥꾼 TYPE은
  원문 상수 1·90·140)·프레임·상태를 세션 공유 상태에서 조립해 `BuildMotionWorldDevices`로
  잇는다. 근거: 같은 파일 3806~3807행의 anchorState와 3929행의 motion 조립이다.
  추가 목록은 세션 Outposts, 내용물 조회는 세션 공유 상태를 쓴다. 1.035에서 추가됐다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 미션 시작 AI 생성 뒤
  `session.BuildMotionRootDevices(worldDefinitions)`를 호출한다. 입력이 없으면 게임
  효과를 내지 않으며 L2 덤프에 닿지 않는다. 1.035에서 추가됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostMotionRootTests.cs`: 신규 3건. 제품 Root와
  같은 묶음·조립으로 시작 본체·부모·지면을 설치하고 실제 예약·파괴·Metadata를 확인하며,
  입력·음향 갈고리의 명시 거부와 중복 설치·미설치 거부를 대조한다. 1.035에서 추가됐다.
