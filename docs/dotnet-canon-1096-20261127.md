# dotnetpj 1.096 — 공유 세션의 GumpForm 삭제 분배

2026-11-27, HJOW-Athlon. 제품처럼 장기 Surface를 공유하는 세션의 전체 삭제 분배기에 같은 저장소의 GumpForm을 등록했다. 저장소와 실제 공통 삭제 본체가 일치하는지 검사하여 다른 풀이나 다른 삭제 깊이를 혼합하지 않는다. 독립 시험 세션의 기존 경로는 유지한다.

- 제품 순서의 공유 Surface/세션/공장으로 실제 GumpForm을 생성하고 세션 자원 삭제 분배로 반납해 동일 삭제 본체와 Pre/Post 깊이 복귀를 확인했다. 관련 검사 4/4 통과, 검사와 게임 Core/Client/Game DLL 해시 일치. 이 검사는 미부착 Form 삭제이며 부모 삭제 중 중첩 통지나 생산 Form 부착은 검증하지 않았다.
- Game Release 빌드 성공, `cpp_sync.py` 종료 0. 대표 세 미션 CPP/DN 각각 종료 0, DN 90프레임 덤프는 0998과 바이트 일치, 원본 1,392파일은 세 감사에서 불변이다. 기존 CPP-DN 상태 차이로 비교 도구 종료 1. 결과 `extracted/dotnet-l2-1096-gump-dispatch/`.

현재 세션 분배기의 가상표 우선 선택은 공통 삭제의 PATCH 진단 연결 여부에 묶여 있어, 현재 TYPE가 기본 3과 다르면서 Gump 가상표를 쓰는 별칭 분배를 별도로 대조해야 한다. 부모 삭제의 실제 UI 통지·중첩 삭제, 생산 Form 생성/부착과 인벤토리 내용물·유지·입력은 미완료다. 전체 UberRoot와 L4a 일치도 남는다.
