# 0.770 ChatWindow 생성·입력·helper·수명 본체

ChatWindow가 기존 HudChatNode/ChatWindowState/기하와 같은 실제 Console/편집 버퍼를 사용한다. 원문 순서의 네 자식 생성/포인터 대입, 공유 로그 교체, 최초 clear/quit 등록, 접두 정규화·대상 substring 추가/제거, 스크롤·Enter·복사/붙여넣기·이름 조회·기본 Help 위임을 복원했다. helper의 색256/배경256/높이8..16 아이콘, 현재 목록의 마지막 제외와21/23 그룹, 두 Config 조회 사이의 번역/사건 캡처도 유지한다.

로그는 자식 문맥을 저장하되 부모에 지정/복원하며 예외에서 복구하지 않는다. 소멸은 다른 창이 current여도 무조건0으로 쓴 뒤 공통 수명에 맡긴다. 생성 실패와 선택 장치 누락을 빈 성공으로 바꾸지 않는다. 실제 전체 UI 공장/자식 가상 분배·Enter Root 호출자와 송수신 설치는 후속이며 이번 본체 이식을 실제 표시/플레이 완료로 계산하지 않는다.

기존 TextEntry 원문 검사 장면의 기본 주소 조회와 관측 기능을 파생 장면에서 재사용하도록 열었다. 같은 실제 Gump/Buffer/물리/trace를 복제하지 않고 부모까지 실행한다. 신규3건 포함 집중20건이 모두 통과했다. ChatWindow180관측의 전체 root/Console/편집/후보/trace/반환이 일치했고 기존 Console2292관측도 그대로 통과했다. 기본166관측은 전체180에서 이름 재번호/후보열만 제외한 정확한 부분집합임을 별도 감사와 검사로 확인했다. 별도 추가관측346건으로 합산하지 않는다. 로그 문맥의 정상/예외 효과와 지연 binding/다른 current 소멸도 확인했다. 새 경고는 없다.
