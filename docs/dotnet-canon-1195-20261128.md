# 1.195 공통 음소거 제어 본체

전체 State 전환의 음향 선행으로 `SoundMusicControl`에 원문 `SetVolume`·`PushMute`·`PopMute`만 이식했다. 효과음과 동일한 `SoundState`를 검증하고 재진입 잠금·두 예약 음량·DWORD 깊이 증가·signed 양수 감소·마지막 예약값 복원을 보존한다. Patch는 효과음 복원 callback의 재진입 뒤 깊이를 다시 읽는 관문을 유지한다. 음량을 임의로 제한하지 않는다.

음악 준비/종료 관문이 닫혔으면 채널을 요구하지 않으며, 열렸으면 실제 채널 음량 장치가 없을 때 해당 위치에서 실패한다. 이 클래스는 음악 채널·곡 선택·파일·스트리밍·worker·실제 Runtime을 구현하거나 빈 성공으로 대신하지 않는다. 현재 제품의 무음 인자 방식 차이와 SceneMusic 제품 조립도 미완료다.

원본 `musiccontrol-x86.tsv` 전체5,292행 중 해당 세 동작이 있는 **396행 부분집합**을 세 판본 각132행으로 대조했다. 재진입36행도 포함한다. 명령열·현재/예약 음량·깊이·실제 효과음 표 Adler를 원본과 비교했으며 기대값은 수정하지 않았다. 제어5건과 기존 SoundPlayer 원본표10건의 집중 **15/15 통과**다. 별도 Release 빌드 종료0·신규 오류/경고0, 기존 제품/검사 경고는 유지했다. 결과는 `extracted/dotnet-music-control-1195-tests/music-control.trx`, 빌드는 `extracted/dotnet-music-control-1195-artifacts/`다.

공통 목록에 원본5,292행/SHA `182d5d85568022e10f31358416e484074bc0a7063d4172dedc577db94e856fa6` 한 항목과 PORT_MAP 부분 이식2행만 등록했다. 동일 검사 출력에 현재 목록 사본을 적용한 자료 목록4건+제어5건의 재빌드 없는 검사도 **9/9 통과**했다(`music-manifest.trx`). `cpp_sync.py` 종료0이다. 실제 게임 창·음향 하드웨어·전체5,292행 실행을 검증한 것으로 세지 않는다.
