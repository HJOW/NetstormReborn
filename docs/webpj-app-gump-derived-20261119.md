# WB04-E910: 앱 Gump 파생 노드 수명

공통 Client Gump 소유자는 기본 노드와 같은 주소의 실제 파생 노드, 가상 입력 처리기와 삭제 소멸자를 등록할 수 있다. 기존 생성기·지연 수명 장치를 같은 노드 저장소로 빌려 주며, 삭제 시 파생 소멸자를 호출한 뒤 그 소멸자가 공통 scalar 해제를 실행한다. 다른 토큰으로 같은 물리 노드를 중복 할당하거나 파생 소멸자를 생략하는 요청은 거부한다. 부착은 루트뿐 아니라 명시한 현재 부모와 mode도 전달한다.

실제 `GumpBackgroundCreate`와 `GumpBackgroundNode`의 type 0 경로를 같은 Client 저장소에서 생성·부착·입력·소멸시켰다. Gump 생성·배경·트리·입력·수명 연관 Node 검사 40건과 Chromium의 같은 파생 노드 수명 1건이 통과했다. HUD·HTML·진행 창의 파생 소유자와 글자 저장소·월드 투영·실제 브라우저 입력은 아직 연결하지 않았다.
