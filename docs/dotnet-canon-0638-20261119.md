# 0.638 AI 직접 명령 세션 결선 (R4-5 AI 초기화)

- 일시: 2026-11-19, HJOW-Athlon
- 범위: 직접 AI 지갑·파라미터의 세션 결선과 세션 소유 brain 메모리. 사제 포획/희생·승리 재현과 실제 미션 시작 흐름 연결은 사용자 확인·후속 범위라 건드리지 않는다.
- 목표: R4-5 입력 중 게임 난수를 소비하지 않는 직접 writer 두 개를 실제 세션에서 잇고 brain 행 대조의 바탕을 둔다.

## 이식 (증거)

- `dotnetpj/src/Netstorm.Client/Host/HostSession.cs`: 세션 소유 `RawAiBrainMemory AiBrainMemory`(첫 토큰 `0x20000000`, 0 채움)를 추가하고 `CrankAiMoney()`·`SetAiParameter(uint)` 세션 메서드를 연결했다. 지갑은 같은 현재 Player 기록과 세션 본체로 고정 30000을 쓰고, 파라미터는 소유자 0을 아무것도 읽지 않고 먼저 반환한다. 근거: cpppj `src/client/RawCampaignSession.cpp` 1001행의 `aiMemory` 조립과 4866·4871행의 `CrankAiMoney`·`SetAiParameter`다. 원문 할당 입력 효과(`services.ai.allocationBytes`)는 DN 세션에 없어 0으로 채우며, 본체는 풀 슬롯이 아니라 L2 세션 덤프에 직접 나가지 않는다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionAiCommandTests.cs`: 신규 4건(첫 토큰 `0x20000000`·부착 brain 지갑 쓰기·선택기별 파라미터 쓰기·소유자 0/brain 없음 무시). 실제 세션 메모리에서 토큰을 확보해 Player 기록에 붙이고 대조했다.

## L1 (증거)

- `HostSessionAiCommandTests` 4/4 통과. `Release` 빌드 오류 0(경고는 기존과 동일).
- 사용자 지시에 따라 전체 회귀는 4단위당 1회만 수행한다. 이번 단위는 집중 검사만 수행했고 다음 전체 회귀는 0.640 시점에 수행한다.

## L2 (증거)

- 이번 단위는 L2 덤프에 닿지 않는다(실제 미션 시작 흐름의 `CreateAiBrains` live 연결 미결선). L2 기준선은 0.636(`extracted/dotnet-l2-0636/`)과 같다.
- 착수 확인: 호스트 `HJOW-Athlon`/192.168.0.94는 AGENTS 실행 확인 예외 PC다. 사제 포획/희생·승리 재현 명령은 보내지 않았다.
