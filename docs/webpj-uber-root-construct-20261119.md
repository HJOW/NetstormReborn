# WB04-E912: Uber 루트 전체 생성·교체

cpppj `UberRootGump`의 10.78 전체 생성, 현재 자식 10개 관계 등록, 제목 메시지 선택, 기존 루트 자식 이관과 재생성을 이식했다. 각 하위 공장·부착·메시지·정리 효과는 도달할 때만 요구하며 콜백 뒤 현재 Uber 필드와 원본 전역을 다시 읽는다. 원본의 signed DWORD와 float32 저장 위치, 실패 전 부분 효과도 유지한다. 공통 등록표와 실제 기본/파생 노드 주소를 사용한다.

`cpppj/tests/fixtures/uber-root-x86.tsv`의 원본 10.78 160행에서 생성·교체 완료 여부와 반환값, 전체 노드의 기록·미기록 바이트, 1000칸 등록표, 현재 전역과 콜백 순서가 모두 일치했다. 재생성의 삭제→정리→전체 생성→공개, 실제 트리에서 기존 자식 이관과 하위 공장 누락의 부분 효과도 검사했다. 기존 HUD·Gump 트리 및 실제 Client 루트와 함께 Node 검사 28건이 통과했다.

하위 미니맵·생산·채팅·메시지 공장과 실제 UI 표시 장치는 이 부모에 아직 연결하지 않았다. 따라서 이 단위의 완료는 앱 HUD 생성이나 미션 플레이 완료를 뜻하지 않는다.
