# dotnetpj 0.955 — 0x88 메타 참가자 이름 본체·설치 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 원문 0x88 메타 참가자 이름의 수신 본체·고정 F 설치와 등급 합계·구독자 조회를 같은 분배기에 연결했다. 0.954의 0x26 메타 geometry와 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientMetaCoreWeight.Weight`는 42b210 전체를 이식한다. Core 마스크와 마지막 +5 BYTE를 TYPE 조회 뒤에도 현재 물리에서 다시 읽으며 32비트 순회·첫 일치 level+1 합계·바이트 합산을 보존한다. 0.955에서 추가됐다.
- `ClientChallengeGlobals.FindParticipantBySubscriber`는 40개 구독자 DWORD 배열 순서 비교를 이식한다. 유효성 비트나 구독자 0을 검색 조건으로 삼지 않으며 처음 일치(0번 포함)를 반환한다. 0.955에서 추가됐다.
- `ClientMetaParticipantName.Write/Rebuild/Refresh/Receive`는 이름표 서식·접두사·전체 갱신·수신 전체를 이식한다. NB09의 긴 길드 태그 줄이기·형식 불명 생략·초과 명시 거부를 보존한다. 비활성 기록은 입력 이름도 읽지 않는다. 0.955에서 추가됐다.
- `ClientMetaParticipantName.Install`은 0x88의 원문 빈 observer·버전·고정 길이와 고정 F를 설치한다. 0.955에서 추가됐다.
- 번역·표시·NSInfo의 실제 메뉴 결선은 세션·R5 메뉴 연결에서 잇는다.
