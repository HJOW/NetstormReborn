# WB04-E718: Session 건설 명령 수신 등록

`RegisterConstructionCommands`의 typed 경로를 외곽 Session에 연결했다. Load 뒤 같은 건설 본체의 3eh/3fh, 건설 상태 37h, 회수 54h, 승천 51h, 배치 거부 2fh, SP 통지 6ch를 원본 순서와 버전·길이로 등록한다. 건설 거부는 같은 Pool·Hash·TYPE·Canon과 실제 삭제를 사용한다. Native 수신 대여는 4D-8에 남는다.

6ch는 같은 분산 SP를 읽고 서버의 잔액 부족 관문, 원본 DWORD 부호 반전과 단정도 가산, 정기 소득 조건, 현재 MessageBoard 안내, 서버 방송을 원본 순서로 수행한다. 필요한 안내나 하위 장치가 없으면 선택된 위치에서 오류를 내며 앞선 효과는 유지한다. 외곽의 `sp`/`setSp`는 같은 저장소의 단정도를 사용한다.

실제 Tutorial 1 Session의 등록과 로컬 및 다른 Player의 SP 가산·차감, 비활성 정기 소득의 조기 반환을 확인했다. 관련 집중 검사 28건과 기존 건설 거부·Session 검사 17건이 통과했다. 이번 검사는 공중 유닛 전용 생성·행동이나 사제 포획·희생·승리를 실행하지 않았고 실제 게임 또는 브라우저 창도 열지 않았다.

로그인 Load 콜백은 원본 순서상 Carrier 전체 등록이 먼저이므로 여전히 명시 미연결에서 중단한다. Carrier 등록 뒤 이 건설 등록과 E717의 연구 등록을 이어야 서버 후반·클라이언트 응답 왕복을 진행할 수 있다. 외부 수신표 대여/반납·Native 분기와 로그인 기준선 뒤 32커밋 판정은 남는다.
