# 0.631 미션 틱 결정론과 덤프 시계 결선 (R4-4 미션 틱)

- 일시: 2026-11-19, HJOW-Athlon
- 범위: 고정 시각 모드의 1프레임 1틱 고정과 덤프 게임 시각의 세션 시계 결선. RNG 25,611 격차의 구간 특정(타임라인 대조). 사제 포획·희생·승리 재현은 사용자 확인 범위라 건드리지 않는다.
- 목표: 0.630에서 남은 앞 3건 프레임 정렬(cpp 11,7,10·DN 10,4,9) 중 난수 상태 격차의 원인을 확정한다.

## 이식 (증거)

- `dotnetpj/src/Netstorm.Client.Host/ClientHostGame.cs`: 고정 시각 모드(`--fixed-frame-ms != 0`)에서는 `IsFixedTimeStep = false`로 두어 그리기당 Update를 한 번만 호출한다. 근거: MonoGame 고정 단계는 벽시계가 느리면 Draw당 Update를 여러 번 호출해 미션 시계·난수 소비가 실행 환경에 종속된다. timeline-0631 관측에서 같은 시드·같은 바이너리의 DN 덤프가 따라잡기(+2틱, 덤프 프레임 92)로 어긋남을 확인했다. 제품 기본값(고정 끔)은 그대로 둔다.
- `dotnetpj/src/Netstorm.Client/Host/HostSessionDump.cs`: world 1 덤프의 게임 시각에 세션의 실제 미션 시각(`ProcessTime`)을 쓴다. 근거: cpppj `SessionStateDump.cpp`의 `client.Time().game`이며 DN 미션 경로에 같은 역할의 시계가 없어 `frame 90 0`만 나가고 있었다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostPlayerWorldLiveTests.cs`: 신규 1건(`DumpWritesMissionTimeFromProcessTime`). 기존 11건 유지.

## L2 (증거, `extracted/dotnet-l2-0631/guardmyback` + `extracted/timeline-0631/`)

- 수집 성공(양쪽 종료 코드 0). 지표는 0.630과 동일(cpp 3792·DN 3502·공통 3502·타입 3334·소유자 3179·프레임 2742·슬롯 2322·그래프 226/255, 정기 23/62).
- DN 덤프 시각이 `frame 90 0`에서 `frame 90 2.25`로 바로잡혔다(90틱×0.025). 덤프 프레임 번호도 92(따라잡기)에서 90(1:1)으로 고정됐다.
- DN 결정성 입증: 같은 조건의 별도 실행(`timeline-0631/dn2`) 덤프와 L2 덤프가 바이트 일치(401,474바이트)했다. 같은 시드·같은 바이너리에서 벽시계와 무관하게 같은 덤프가 나온다.
- RNG 격차 분해(시드 고정·1760000000, LCG `state*0x10003+3` 사슬 공유 확인, DN→cpp 25,611회):
  - 적재 구간 소비는 작다. cpp f010→f030(브리핑 정지) 22회. DN은 틱 전 구간에서 난수를 전혀 소비하지 않는다(4개 덤프 동일 상태).
  - 격차의 본체는 틱 구간이다. cpp는 미션 진행 중 프레임 30→60에 13,095회·60→90에 14,540회를 소비하고 DN은 0회다. DN에 미연결인 틱 난수(주변 바람 매 프레임·AI·장식·사제 재생·연소 등 R4-4·R4-5·R6 범위)가 원인이다.
  - 정기 부착 시점 어긋남을 특정했다. cpp 공장 사건2·사건5는 미션 시작(클라이언트 시각 약 9.2) 시점에 부착돼 즉시 1회 발화한다(사건2 cnt=1·다음 17.2, 사건5 cnt=3·다음 10.7). DN은 적재(미션 시각 0) 시점에 부착돼 첫 틱에 발화한다(사건5 cnt=5·다음 2.575). DN 발화 패턴(틱 1·21·41·62·83)은 double 0.025 누적 재현과 일치함을 확인했다(62·83의 1~2틱 밀림은 0.025 이진 부동소수 누적). 부착 의미(즉시 발화, 원문 00496e80/00496f00)는 양쪽이 같고 시점(R4-6 로그인·시작 흐름)이 다르다.
  - cpp는 프레임 30→90 사이에 객체를 계속 Pop한다(f030→f060 19건·f060→f090 1건, 모두 타입6 내용물 폼). DN은 적재 시점에 전부 Pop한다(전 구간 3502 고정). 미션 시작 Pop 정렬(R6 내용물·생산) 잔여다.
- 착수 확인: 호스트 `HJOW-Athlon`/192.168.0.94는 AGENTS 실행 확인 예외 PC다. 원본 대신 `extracted/dotnet-oracle-data/` 사본을 읽었다. 사제 포획·희생·승리 재현 명령은 보내지 않았다.
