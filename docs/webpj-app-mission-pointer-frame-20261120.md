# 미션 포인터·좌클릭 입력 프레임 (WB04-E994)

준비된 미션 프레임에서 실제 브라우저 포인터를 원본 안팎 경계로 폴링하고, 같은 Tutorial의 폴링 통지와 Client Gump overlay·방송 뒤 현재 World 마우스 좌표와 이동 커서를 갱신한다. 좌클릭 누름·뗌은 브라우저 사건에서 직접 실행하지 않고 같은 입력 큐에 예약한다. 지원한 사건은 Guide → Gump → World 순서로 Kernel 전에 처리한다.

좌클릭과 이동점 통지 및 포인터 재진입으로 만들어진 오른쪽 버튼 뗌만 이 경로가 소비한다. 다른 사건은 앞을 추월하거나 지우지 않는다. 원본 전체 일반 입력·우클릭 메뉴·키보드·HUD는 남았다. 열린 Tell 창은 기존 모달 입력 경로를 유지한다.

실제 Tutorial1의 현재 마우스 좌표 갱신·큐 순서와 원본 포인터 관측 3,878행 등 관련 Node 검사 32건이 통과했다. Chromium에서 여러 안내 페이지를 닫고 사제를 클릭해 실제 좌표가 바뀌는 이동과 큐 소비를 다시 확인했다. E986 고정 Node 26 전체 검사는 별도로 실행 중이다.
