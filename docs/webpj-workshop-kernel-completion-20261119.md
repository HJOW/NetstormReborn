# WB04-E827 전체 Kernel의 워크샾 자연 완공

E774의 캠페인 1-1 실제 Fort·내부 Login/Ready·미션 Start·사제 메뉴·커서·3eh 워크샾 배치를 같은 검사에서 재사용했다. 이전처럼 사제 경로와 건설 프로세스를 따로 호출하지 않고, 같은 Session의 전체 Kernel을 25ms 간격으로 진행해 자연 완공을 확인했다. SP 3,000→2,200, 최대 HP, 건설 비트 해제 및 건설·표시·반복 소리 Form의 후속 반납을 검사했다. 격리 검사와 자연 검사 2건이 통과했다.

처음에는 AI 벽시각·일반 미션 여부·객체 이름 장치, AI 탐색의 8바이트 초기 입력, 반복 소리 장치가 빠져 실제 선택 위치에서 중단됐다. 각 입력을 명시하고 AI 명령은 같은 내부 전송으로 보냈다. 시계·이름·소리는 검사 장치이며 실제 청취를 확인한 것은 아니다. 최종 시각 연결을 바꾸면서 먼저 시작한 전체 회귀는 중단하고 최종 상태로 다시 실행했다.

브라우저 입력·표시, 전체 GameWorld 프레임과 워크샾 완공 이후 생산은 남는다. 게임 창·사제 포획/희생·특정 적 공격·승리·제한된 공중 유닛 전용 행동은 실행하지 않았다.

검증: Node v26.13.0·v22.23.3 전체 각각 6,321건 통과(실패·취소·건너뜀 0), 대응표 1,160행 오류 0. 두 버전은 순차 실행했고 v22 전체 검사 뒤 v26 회귀 0/8회다.
