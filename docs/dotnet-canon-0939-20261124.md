# dotnetpj 0.939 — 제단 정기 분기 이식

2026-11-24, HJOW-Athlon. R4-4 정기 처리 묶음이다. Rune/Dais에 이은 제단(Altar) 정기 분기 본체를 같은 실제 풀/프레임 장치에 연결했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `RawRitualRegular.RunAltarRegular`는 44a5e0 전체 분기를 이식한다. 21번(자동 해방·도망 예약·소리·주기 반환), 20번(전진), 22번(후퇴·복귀), 23번(통과), 24번(완성·파괴·폭발 후속), 그 밖(공통 손상 분배)을 원문 순서대로 가른다. 0.939에서 추가됐다.
- `AltarSacrificeState`(저항 주기 3.0·도망 확률 40)와 `AltarRegularHooks`(다이스/사제 조회·권한·동맹·해방·애니메이션·이탈·파괴·전진·프레임·예약·공유·난수·소리·손상 14종)를 함께 두어 후속 0x307 Host 부착이 같은 후크를 재사용하도록 했다.
- 제단 분기는 `RawRitualRegular`의 304/305/306/307 분기와 분리되어 있어 Rune·Dais 본문을 바꾸지 않는다.
