# WB04-E921: 브라우저 마우스 사건 큐

cpppj `ClientMain.cpp`의 마우스 버튼 사건을 브라우저 Canvas 입력에서 같은 원본 40칸 큐로 옮기는 경계를 추가했다. 좌·중·우 누름/뗌, Shift·Ctrl·Alt와 범위 밖 음수를 포함한 논리 좌표를 보존한다. 지원하지 않는 브라우저 버튼은 큐에 넣지 않는다. 원본 입력 소비자가 설치되기 전에는 적재를 끄며 앱을 다시 시작할 때도 꺼진 상태로 만든다.

세 버튼·보조 키·signed 좌표·미지원 버튼 및 기존 포인터 경계를 포함한 Node 검사 11건이 통과했다. Chromium에서 실제 Canvas 누름·뗌을 활성화된 큐로 받는 검사와 기존 폴링·재진입 검사를 포함해 3건이 통과했다.

현재 실제 미션 입력 소비자는 아직 연결되지 않았으므로 앱에서는 큐 적재를 자동 활성화하지 않는다. 키보드·문자 사건의 원본 큐 변환, 사용자 입력 프레임과 HUD·월드 입력 연결은 남았다.

전체 회귀 첫 실행에서 E919 폴링 모듈과 E921 마우스 모듈의 대응표 경로 누락으로 대응표 검사 2건이 실패했다. ClientMain 대응 파일 열에 두 경로를 추가한 뒤 관련 검사 7건이 통과했고 Node v26.13.0 전체 회귀를 처음부터 다시 실행해 6,485건이 실패·취소·건너뜀 없이 통과했다.
