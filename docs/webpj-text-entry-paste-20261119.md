# WB04-E927: 확장 문자 붙여넣기

cpppj `TextEntryBuffer::Paste`의 확장 문자 경로와 `FilterDisplayText`를 웹 바이트 편집기에 연결했다. 현재 본문 또는 붙여넣기 본문에 확장 문자가 있으면 선택을 완전한 문자 경계로 맞추고, 선택을 제외한 현재 바이트 수와 최대 길이를 계산한다. 제외된 확장 선두는 토큰 전체를 거르고 남은 공간이 부족하면 토큰 중간에서 자르지 않는다. 삽입할 내용이 없으면 선택을 보존하고 원본처럼 dirty만 설정한다. 기존 순수 바이트 붙여넣기는 기준선 경로를 유지한다.

실제 편집 버퍼·클립보드 시험 틀에서 한글 바이트 상한, 확장 문자 제외, 기존 한글 뒤 ASCII 제한, 빈 결과의 선택 보존을 확인했다. 원본 10.78 편집기 2,292행·버퍼 570행을 포함한 관련 Node 검사 30건이 통과했다.

현재 클립보드 호스트와 실제 앱 편집기는 미연결이며 확장 글꼴 측정·출력과 브라우저 IME는 남았다.
