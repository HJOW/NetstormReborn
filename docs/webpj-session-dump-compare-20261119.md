# WB04-E870 Session 덤프 비교 도구

`node webpj/tools/session-dump-compare.mjs <기준> <대상> [--ignore-sp-owner0]`는 판번호 1 덤프의 각 행을 번호와 종류로 구별해 누락·추가·값·순서 차이를 보고한다. 형식 오류는 종료 코드 2, 차이는 1, 일치는 0이다. 인자를 지정한 경우에만 비결정적인 SP 소유자 0을 제외하며 출력에 제외 사실을 표시한다. 다른 소유자와 SP 초기화 상태는 계속 비교한다.

집중 검사는 동일·누락·추가·순서·잘못된 형식과 저장된 실제 cpppj Tutorial1 덤프의 SP 소유자별 차이를 확인했다. fixture 추적 검사를 포함한 연관 검사 7건이 통과했고, 명령줄에서 실제 기준 덤프를 자기 자신과 비교해 차이 0을 확인했다. 사용자 지시의 새 회귀 주기에 따라 이번 단위에서는 전체 회귀를 반복하지 않았다.

이 도구는 전달받은 덤프를 비교할 뿐 웹에서 미션을 시작하거나 같은 프레임의 웹 덤프를 생성하지 않는다. Tutorial1 L2 대조는 실제 Client/앱 수명 연결 이후에 수행한다. 원본 게임 창은 실행하지 않았다.
