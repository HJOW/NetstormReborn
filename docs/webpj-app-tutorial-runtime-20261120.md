# WB04-E974 앱 Tutorial 안내 실행기

로그인 Ready인 같은 World·Guide·Start에 `RawCampaignTutorialOneBindings`를 준비한다. 프레임 시계·현재 모달·지식 잠금·Gump 차단, 미션 대본의 안내 창, 팝업 닫기, 선택 조회와 게임 시계의 중첩 정지/재개를 현재 앱 장치에 연결한다. 데모 종료는 기존 입력 큐에 원본 Reload 사건을 예약하며 실제 소비는 후속이다. 중복 생성과 미션 토큰·수명이 다른 경우는 거부한다.

현재 웹 TellWindow는 원본 Gump HTML 인스턴스와 별도이므로 안내 열림 조회에서 Client HTML 인스턴스와 웹 모달을 함께 확인한다. 다이얼로그를 닫은 뒤 원본 Gump의 지연 파괴까지 남는 간격은 아직 동일하다고 주장하지 않는다.

검증: 실제 Tutorial1 로그인과 Start 뒤 공통 안내 10프레임에서 `A.` 창과 자기 정지, 창을 닫은 뒤 7프레임에서 시계 재개를 확인했다. 앱 Gump·원본 프레임 게이트 및 미션 연결 검사를 포함한 Node 30건 통과. 이 검사는 Tutorial 실행기를 직접 호출했으며 Guide/앱 프레임 자동 연결·세계 입력/표시는 남았다. E970 고정 Node 26 회귀가 실행 중이고 E974 고정 Node 22 정기 회귀는 그 뒤 실행한다.
