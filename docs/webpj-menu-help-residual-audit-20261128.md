# 메뉴·도움말 잔여 판정과 실제 포인터 검사 — WB04-E1467

2026-11-28 HJOW-Athlon. 현재 앱의 영어 F1 도움말에서 본문 끌기와 브라우저 포인터 붙잡기/반납을 **네 브라우저×세 화면비, 12경로 모두 확인**했다. 이와 함께 인계4절의 옛 미연결·미확인 문구를 기존 후속 단위와 현재 자산에 대조했다. 제품·검사·번들·CPP·원본은 변경하지 않았다.

## 실제 브라우저 범위

Chromium·설치 Chrome·설치 Edge·Firefox에서 DPR2, 1024×768·1366×768·1280×800으로 같은 앱을 각각 실행했다. 원래 시작 화면을 거쳐 F1 키로 연 뒤 저장된 긴 `statsHelp` 주제를 요청했다. 주제 선택은 기존 `_openHelp` 호출이며 **본문 끌기·놓기·OK 닫기는 실제 브라우저 마우스**다. 게임·미션을 시작하지 않았다.

각 경로에서 창의 실제 경계는 `x=(화면폭−450)/2`, `y=40`, `450×350`이었다. 링크가 아닌 본문을60논리픽셀 위로 끌면 스크롤이60픽셀(좌표 정수화2픽셀 이내) 움직였다. 창 바깥 `(5,5)`로 계속 끌어 놓아도 원래 주제를 유지했다. **각12경로의 마지막 네 사건은 pointerdown → gotpointercapture → pointerup → lostpointercapture**이며 마지막 붙잡기=false·본문 dragY=null·입력 buttons=0이다. OK가 창을 닫았고 페이지/콘솔 오류0이다.

Canvas 바깥/OS 창 밖이나 실제 터치 장치의 제스처 취소, 물리 커서의 육안 품질까지 입증한 검사는 아니다. 최초 실행 준비는 작업 경로를 중복 붙여 수집기 파일 생성에 실패했다. 올바른 무시 폴더에 작성한 브라우저 실행은 네 경로 모두 첫 실행에 통과했다. 실패 로그와 수집기/결과는 `webpj/extracted/e1467-*`에 보존한다.
