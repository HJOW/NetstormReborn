# WB04-E857 캠페인 커서 Gump 연결

기준선 `225553df`의 `BindCampaignCursorGumps`를 이식했다. 현재 컨트롤의 Gump 위치 조회와 명령 분배, 커서 배치·드롭의 공통 부모 조회, 조각 허용 명령 `0200005f`와 수신 명령 `0200005e`를 연결한다. 팝업 종료 훅이 없을 때만 기존 컨트롤의 지연 종료 요청을 사용한다. 기준선 이후 해당 C++ 파일에 변경은 없다.

집중 검사에서 전달 인자와 반환, 숨김 플래그, 같은 부모 함수와 기존 팝업 훅 보존을 확인했다. 실제 `RawCampaignCursor` 검사에도 이 연결을 적용해 같은 Form의 Gump 부모 재부착과 수신 명령·프로세스 통지를 확인했다. 집중 검사 2건과 Node v26.13.0 전체 회귀 6,371건이 통과했다(실패·취소·건너뜀 0).

실제 브라우저 Gump 트리와 Client 수명, 비용 표시·번역·측정·마우스·기록 장치는 아직 남아 있다. 원본 게임 창은 실행하지 않았다.
