# 0.611 파이프라인 미리보기 해소 (MayPlace 전체 일치)

- 일시: 2026-11-18, HJOW-Athlon
- 범위: R6-3 캐논 배치 파이프라인 L1 3건(`canonmayplace-x86.tsv` 432행) 전수 일치. 0.610에서 격리된 미리보기 배열 불일치의 원인 제거가 중심이다.
- 목표: 농지 MayPlace 실결선·L2 3경로 재수집의 전제인 파이프라인 전체 판정을 닫는다.

## 원인

- `CanonMayPlaceTests` 준비 코드가 패턴 전역 8개를 `state.Geometry.PatternTypes.AsSpan().CopyTo(새 배열)`로 복사했다. `CopyTo`는 호출자 스팬을 인자 배열로 복사하므로 패턴표가 그대로 0으로 남았다.
- 패턴표가 0이면 `DecodeCanonType`이 비패턴 경로를 타서 미리보기 Bounds가 L19·T20(1×1)으로 줄고, 미리보기 차단 배열이 전부 0이 된다. 기대치는 3×3 받침 패턴 경로의 L17·T18 Bounds와 01 패턴 차단 배열이다.
- 허용·차단·지역·원본·해시·고정은 일치했으므로 MayPlace 반환 자체는 맞았고, 표시용 미리보기 배열만 어긋난 상태였다.

## 수정

- `dotnetpj/tests/Netstorm.Core.Tests/CanonMayPlaceTests.cs`: 패턴표 복사를 `Array.Copy(새 배열, state.Geometry.PatternTypes, 8)`로 바로잡았다. 제품 코드는 변경하지 않았다(테스트 준비 코드만 수정).
- 진단용으로 만든 `CanonMayPlaceDiagTests.cs`는 원인 확정 뒤 삭제했다(일회성 파일 미보관 원칙).

## 검증 (증거)

- `dotnet test Netstorm.Core.Tests -c Release --filter "FullyQualifiedName~CanonMayPlace"` 0 실패·3 통과(TRX `mayplace0611`, 패치·CD·1037 각 144행, 약 20분).
- 허용·차단·지역·원본·해시·고정 checksum과 미리보기 차단 배열 144바이트 hex가 세 판본 모두 일치한다.
- Release 빌드 0경고·0오류(경고는 기존 xUnit2020 안내 2건 유지).
- 확대 회귀 영향 없음: 미리보기와 무관한 기존 L1은 손대지 않았고, 변경 파일은 테스트 1행이다.
