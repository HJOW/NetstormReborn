# dotnetpj 1.032 — R4-5c 신전 삭제 결선과 정기 전체 회귀

2026-11-25, HJOW-Athlon. R4-5c 신전 삭제 결선과 4단위 만의 정기 전체 회귀다.
`HostSession`에 `BuildAiTempleDestroy()`를 두어 원문 `createHooks.destroyTemple`과
같은 범위 검사·실제 파괴 결선을 세션 API로 수행하고, 시작한 미션 흐름
(`ClientHostGame`)에서 실제 세션 파괴를 넘긴다. 원문 NoTemple 분기
(첫 지역→섬 신전 조회→신전 제거→brain 없이 0 반환)의 순서·통지는 세션 파괴 분배를
그대로 쓴다. 기존에 고정된 NoTemple 기록 관례(`AiBrains`에 0 기록)는 바꾸지 않고
기존 검사가 그대로 통과함을 확인했다.

## 변경과 원본 대응

- `dotnetpj/src/Netstorm.Client/Host/HostSession.AiBrains.cs`: `BuildAiTempleDestroy()` 신규.
  SID 범위 검사(`temple > 65535 || temple >= Pool.Capacity`, 원문 `out_of_range`와 같은 순서) 뒤
  전략 `setup.destroy`와 같은 실제 세션 파괴(`BuildSessionDestroy`)에 전달한다.
  근거: cpppj `RawCampaignSession.cpp` 2816~2818행의 createHooks 조립이다.
  1.032에서 추가됐다. `CreateMissionAiBrains`의 `destroyTemple` 설명만 갱신했고
  null 기본값(미연결 시 명시 거부)은 유지한다.
- `dotnetpj/src/Netstorm.Game/ClientHostGame.cs`: 미션 시작 AI 생성에
  `destroyTemple: session.BuildAiTempleDestroy()`를 넘긴다. 근거: 같은 파일의 미션 시작
  흐름(0.641 난이도 결선 자리)이다. 1.032에서 추가됐다.
- `dotnetpj/tests/Netstorm.Client.Tests/HostSessionAiLiveCreateTests.cs`: 5건 추가(13→18건).
  NoTemple 소유자의 섬 신전 파괴·0 기록·무 brain 부착, 신전 없음 경로의 파괴 생략,
  범위 밖 SID 거부 2건, 장치 미설치 거부. 신전 슬롯은 팩토리 생성(타입 6)으로 유효한
  가상 표·링크를 갖추고 섬 기록에 둔다. 1.032에서 추가됐다.
