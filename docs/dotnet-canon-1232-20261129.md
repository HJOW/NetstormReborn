# 1.232 실제 메타맵 이탈과 State 정리 연결

2026-11-29, HJOW-Athlon. H-1의 메타 이탈 장치를 원문 순서로 이식하고 실제 Game 정리 입구에 연결했다. **집중46/46·정기 전체7,807통과·실제 정리4경로/기존 진입3경로 정상 종료**다. 저장 장치와 원문 State 부모 호출은 남는다.

## 구현 범위

`NativeMetaDisplayCleanup`은 CPP `NativeMetaDisplay.cpp`의 `ClearMetaDisplayZones`와 `LeaveMetaDisplay`에 대응한다. 먼저 실제51개 구역의 양수 상태/비영 SID 마커를 기존 `RawMetaZoneCleanup.ClearMarker`로 지운다. 이어 참가자0..39의 비영 SID를 삭제하고, 콜백 정상 복귀 뒤 현재 CS를 다시 읽어 SID0·16BYTE 가변 배열 반납을 실행한다. SID0 참가자는 배열도 보존한다. 마지막으로 전투0..9의 비영 SID를 삭제한 뒤 같은 현재 슬롯만0으로 쓴다. 참가자·전투의 유효성 비트로 추가 필터링하거나 CS 전체를 초기화하지 않는다.

`LeaveCurrent`는 같은 Client/Local/표면을 검증하고 선택된 비영 SID에서만 현재 Session을 요구한다. 현재 Pool/Local 정체성과 DWORD SID 범위를 확인한 뒤, 각 가상 삭제 동안만 전체 Runtime을 pin해 기존 `DestroyWorldObject`를 호출한다. 새 World나 풀을 만들지 않으며 일반 Pre/Post 삭제로 대신하지 않는다. `ClientHostGame.CleanupNativeWorld(reason)`의 `LeaveMetamap`이 이 장치를 사용한다. Fort/Battle 저장 분기의 기존 명시 오류는 유지한다.

CPP216행 파일 중 이번 범위는 위 두 정리 함수다. 참가자/전투 표시 갱신·전체 Poll·NSInfo 갱신까지 옮긴 것으로 세지 않는다. 대응표의 새 한 행이 해당 CPP 파일 전체를 집계하는 한계도 그대로다.
