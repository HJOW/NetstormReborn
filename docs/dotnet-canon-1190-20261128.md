# 1.190 Client 전체 회귀와 작업 중단 인계

사용자의 일시 중지 요청에 따라 1.189의 제품 수정 및 대표 미션 검증을 마친 뒤, 이미 진행 중이던 Release Client 전체 검사를 완료했다. **2,979건 통과, 실패 0건**이며 `WindowsSoundHardwareTests.MutedNativeDeviceLoadsDuplicatesAndRestoresAfterReinitialize` 한 건은 TRX 개별 결과가 `NotExecuted`다. TRX 총계는 2,980이다. 결과는 `extracted/dotnet-1190-regression/Client.trx`에 있다.

변경되지 않은 1.184의 Assets 383건과 Core 4,121건에 이번 Client 결과를 합치면 **7,483건 통과**다. Assets와 Core 전체를 이번에 다시 실행한 것은 아니다. 이 검사는 1.188의 UI 정리와 1.189의 NSInfo TYPE·팔레트 변경을 포함하며, 실제 음향 하드웨어·미션 승리·전체 게임 동등성을 검증하지 않는다.

재개하면 `LEFT_JOBS.dotnetpj.md`의 기존 우선순위대로 R5-4c3c의 미니맵 잔여 1픽셀과 미션 전환 수명부터 계속한다. 같은 프레임의 CPP와 DN은 게임 시각이 다르므로 1.173~1.176의 시각 관측을 적용해 비교 조건을 기록한다. 1.180~1.181에서 확인한 SP 쓰기 14회 차이와 1.187에서 확인한 주변 바람 4회·장면 음악 1회의 실제 호출 경로를 원본 순서에 맞게 연결해야 하며, 난수를 임의로 앞당기지 않는다. 1.188의 UI 정리 입구와 1.189의 NSInfo TYPE·색상은 준비됐지만 전체 State 전환과 HUD 재생성은 미완료다. 이후 R5-4c4 → R5-4d → R5-3 → R5-5 → R6 순서를 유지한다.

사용자의 실제 실행 제약도 유지한다. 사제 포획·희생, 특정 적 공격, 시나리오 승리 재현은 캠페인 1-1~1-5 및 스커미시에서 아군 인공지능을 활성화해 진행할 수 있고 다른 스테이지의 해당 재현은 건너뛴다. 단순 진입·대기·유닛 생산·건물 건설 검사는 진행할 수 있다. 진행 단위마다 인수인계를 갱신하고 커밋하며 커밋 실패 시에도 작업을 이어간다.
