# Session 다이스 의식과 희생 요청 (WB04-E647)

기준선 `225553df`의 `RawCampaignRitual.inc` 다이스 상태·Regular·희생
요청 구간을 기존 신전·룬·같은 Pool/Host/경로에 연결했다. 관련 cpppj
소스는 기준선 뒤 변경이 없다. 현재 Player 기록·동맹·권한·사제/다리/
너겟 TYPE과 checking을 다시 읽으며 실제 Core 장부와 분산 SP 정책,
입력 명령 큐·Tell·위치 음향을 사용한다. 희생 내용물은 같은 finder로
종류 WORD를 비교하고 원문 삭제 관문과 DWORD 순번 감김을 유지한다.

지연 음향은 실제 미부착 Sound47 객체를 한 번 확보해 같은 객체를 Host에
부착하고 원문 절대 시작 시각을 쓴다. 로컬 특수 효과와 멀티플레이 상태는
cpppj의 미연결 경계처럼 선택 시 명시 오류다. 제단 수명과 실제 미션
Load/자연 희생은 후속이며 `loaded=false`를 유지한다.

신규 검사 4건은 같은 Player/동맹 장부와 설치 관문, 실제 Sound47 예약과
시각, 실제 Core/SP 보상·큐/Tell, 실제 내용물 제거와 다이스 자격 조회를
확인한다. 최초 집중 검사에서 외부 선택·위치 음향을 제공하지 않아 삭제가
미연결 경계에서 멈췄고, 다음 검사에서는 중립 소유자의 로컬 알림을 잘못
기대했다. 시험 입력과 기대값을 교정한 뒤 신규 검사를 포함한 다이스/
