# dotnetpj 0.934 — 분배 부모 기본 18행 설치 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 공통 패킷 분배 부모에 InstallClientPacketDefaults의 장기 기본 18행을 설치했다. 제품 기존 경로는 바꾸지 않는다.

## 변경과 원문 대응

- `ClientPacketDispatch.Build`는 다른 묶음보다 먼저 `ClientPacketDefaultObservers.Install18(packet, surface.Storage)`을 설치한다. 기본 18행(관찰 전용 11종과 실제 C3 수신 7종)의 버전·길이·관찰기와 4437f0 원문 RET 수신기를 같은 분배기에 둔다. 0.934에서 추가됐다.
- 18행 종류(`0x0c`·`0x42`·`0x4d`·`0x55`·`0x56`·`0x57`·`0x5a`·`0x10`·`0x11`·`0x12`·`0x16`·`0x17`·`0x1c`·`0x1e`·`0x1f`·`0x68`·`0x85`·`0x87`)는 41h·로그인·설정·버전·기술·변수·Native gameplay 묶음과 겹치지 않아 뒤따르는 설치가 기본 행을 밀지 않는다.

- Release 테스트 빌드는 오류 0이다. 신규 경고 0이다(기존 3건만).
- 신규 1건(부모의 기본 18행 C3/버전/길이/관찰기 등록과 기존 묶음 보존)은 통과/실패 0이다. `ClientPacketDispatchParentTests` 6건과 `ClientPacketDefaultObserversTests` 검사를 포함한 27건이 함께 통과한다.
