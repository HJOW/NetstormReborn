# WB04-E737 운반 명령 수신 등록

현재 Session 분배기에 `40h` 이동, `4fh` 줍기, `50h` 투하, `60h` 탈취 수신을 등록했다. 송신자와 원본 고정 패킷 길이를 각각 보존하고, 투하 수신은 기존 Session 준비 함수를 먼저 실행한다. 네 명령은 이미 연결된 같은 월드·Pool의 각 처리기를 사용한다.

근거는 기준선 `225553df`의 `RawCampaignSession.cpp`와 네 `RawCarrier*.cpp`다. 해당 파일의 기준선 이후 변경은 없다. 기존 10.78 fixture는 이동 982행, 줍기 2,657행, 투하 413행, 탈취 1,105행이며 이전 각 단위에서 대조했다. 이번에 새 fixture는 추가하지 않았다.

Tutorial 1 Session의 실제 분배기로 고정 길이 네 패킷을 보내 반환된 슬롯에서 각각 중단되는지 확인했다. 집중 검사 25건이 통과했다. 실제 운반 행동과 미션 왕복은 이번 검사가 아니다.

Node v26.13.0 전체 회귀 6,214건을 통과했다. 대응표 오류는 0건이며 Node v22 전체 재검사 주기는 7/8회다.
