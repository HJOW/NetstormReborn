# dotnetpj 0.965 — PacketDelays 지연 분포·FIFO 이식

2026-11-24, HJOW-Athlon. R4-6 전송·수신 묶음이다. 수송 팩토리의 `hooks.delay` 자리에 들어갈 Client 지연 분포·장치·FIFO를 이식했다. 0.964의 Build 연결과 제품 기존 경로는 바꾸지 않는다. 큐 설치(Prepare) 호출과 wall/난수 묶음, 수송 생성·재결합·Publish는 R11 후속에서 잇는다.

## 변경과 원문 대응

- `PacketDelayGlobals`는 005e4784 선택 분포와 wall·난수 장치를 이식한다. 기본01ff·lag1/2/3 원문 signed BYTE와 `ResetDefault`·`SelectLag`(1/2/3만 교체) 순서를 보존한다. 0.965에서 추가됐다.
- `RawPacketDelayQueue`는 4def40의 100칸 ring과 `Enqueue`·`Pump`·`Grow`를 이식한다. bucket 난수 선소비·고정 지연도 bucket 난수 소비·observer1 뒤 선언 길이 복사·`delay*0.001+wall` 기한·선두 순서 배송·주소/깊이 복구·닫힘 `-1`·실패 선두 보존 순서를 보존한다. 호출자 버퍼 대신 사본에 observer를 실행하는 점만 DN 불변 버퍼 관례에 맞췄다. 0.965에서 추가됐다.
- `RawPacketDelay.Prepare`는 실제 Poll에서만 분포가 있고 큐가 없으면 설치하고 `Delayed`를 세운다. 이미 설치된 큐는 다시 초기화하지 않는다. 0.965에서 추가됐다.
- `ClientConnectionGlobals.PacketDelays()`는 같은 Client의 실제 장기 분포 owner를 공유한다. `PacketDispatchHooks.Delay`는 TCP/UDP Poll만 선택하는 자리다. 0.965에서 추가됐다.
