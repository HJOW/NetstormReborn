# WB04-E803 일반 좌클릭 선택

기준선 `225553df`의 `UserInput::Event`와 `GameWorld::SelectFromPointer`에 따라 이동 모드 밖의 일반 좌클릭을 같은 실제 Session의 후보 검색과 `Select(sid, force, 1)`에 연결했다. Ctrl과 현재 특수 권한이 함께 있으면 강제 선택하고, 선택 뒤 특수 권한을 다시 읽어 사건 좌표의 실제 공간 검색 결과를 차례대로 진단 콜백에 전달한다. 편집·항해 모드는 웹 범위 밖으로 명시 거부한다. 기준선 이후 해당 cpppj 파일 변경은 없다.

TheWarBegins 로컬 Session에서 사제의 실제 화면 픽셀 좌클릭으로 선택하고, Ctrl 특수 선택의 공간 검색이 같은 사제 SID를 진단 콜백에 전달하는 것을 확인했다. 분기 시험은 비특수 Ctrl과 웹 제외 모드를 확인한다. 진단 콜백은 시험 대역이며 실제 Client 로그 장치는 미연결이다. 상위 메뉴·브라우저 이벤트와 실제 다중 유닛 이동 검증, NB20 실제 건설 조각 취득·취소는 남았다.

검증: 집중 검사 2건 통과, 대응표 1,160행 오류 0. Node v26.13.0과 v22.23.3 전체 검사 각각 6,296건 통과(실패·취소·건너뜀 0). 두 버전은 순차 실행했다.
