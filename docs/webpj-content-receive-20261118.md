# WB04-E731 내용물 데이터 수신

`2dh` 수신을 18바이트 패킷으로 등록했다. 수신기는 현재 Session의 내용물 타입과 공장을 사용한다. 공장에서 슬롯을 가져오기 전에 기존 상태를 읽고, 공용 WORD 설정기를 실행한 뒤 받은 필드를 같은 슬롯에 쓴다. 패킷에 첫 Pop 표식이 있거나 기존 슬롯이 비어 있으면 첫 Pop 플래그를 구한다. 부착 시에는 현재 가상 표를 다시 읽고 내용물 정렬 부착, 공용 Form 부착, 자산 부착 중 해당 함수를 호출한다.

근거는 기준선 `225553df`의 `RawSquidMutationReceive.cpp` 및 `RawCampaignSession.cpp`에 있는 `2dh` 등록과 호출이다. 수신기 행의 근거 커밋은 `541624a9`이며 이번 경로는 기준선 이후 변경이 없다. 새 원본 fixture는 추가하지 않았다.

독립 슬롯 검사에서 필드와 호출 순서, Take 이전의 빈 상태, 부착 장치 누락 시 선행 쓰기를 확인했다. Tutorial 1의 Node 통합 검사에서는 `2dh`를 실제 분배기로 보내 부모와 자식의 링크를 확인했다. 초안에서 부모를 클라이언트 SID에 만들어 서버 송신 검사에 걸렸으므로 일반 서버 할당으로 교정했다.

Node v26.13.0 전체 회귀 6,200건을 통과했다. 대응표 오류는 0건이다. Node v22 전체 재검사 주기는 1/8회다.

다음 작업은 `2eh` 일반 삭제와 `65h` 감시 Form 수신이다. 이후 Carrier 등록, 로컬 로그인 응답 왕복, 앱의 미션 진입 연결이 남아 있다.
