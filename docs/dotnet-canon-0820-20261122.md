## 동일 빌드의 65개 시작 경로

일반 31개 경로 양쪽 62회와 CPP 데모 3회를 영어·1024×768·창모드·음소거·빈 사용자 루트·Unix 1760000000·25ms·120프레임 조건으로 실행하고 90프레임 전체 덤프를 수집했다.

- 65개 게임 프로세스 모두 종료 0·수집 오류 0이다. 두 엔진은 각각 고정 EXE SHA를 사용했고 DN 실행 6개 파일도 전후 불변이다.
- DN 31개 전체 덤프 바이트와 34개 경로 지표가 0.816과 같다. 0.819 대표 3개 시작 경로의 전체 덤프도 같다.
- CPP는 기존 sp행의 열 3(owner 0 SP) 외 변동이 없다. 기대값을 현재 DN 결과로 바꾸지 않았다.
- 원본 1,392개 파일의 전체 이름·해시가 전후와 0.816 전체 장부에 대해 불변이다.
- M1은 **0/34**(cpp_only 997·dn_only 21)이며 DN 데모 3개 진입 경로은 미연결이다. 진입 성공을 플레이 완료나 표시/입력 동일성으로 확대하지 않는다.

원시 L2 수집기의 종료 1은 전체 동일성 미달 결과이며 개별 게임 65개의 종료 0과 구별했다. 포획/희생·특정 적 공격·승리 재현 입력은 보내지 않고 사용자 지정 진입 검사 범위를 유지했다.
