Netstorm Minimum Requirements
----------------------------------------------------------------------
100% Microsoft Windows 9x and up compatible computer system  (including compatible 32-bit drivers for   CD-ROM drive, video card, sound card and input devices)
Processor Type: Pentium 90MHz
RAM: 24MB
25MB of uncompressed hard disk space
256 Color (640 x 480) VLB or PCI video card with 1MB RAM
100% Sound Blaster compatible sound card
100% Microsoft-compatible mouse and driver
DirectX 5 or higher

Additional System Requirements for Multiplayer:
100% 14.4Kbps Windows 9x compatible modem
100% Windows 9x compatible network (LAN)
IPX network (LAN)
TCP/IP network (Internet play)
----------------------------------------------------------------------

To play NetStorm online you must run the nsLaunchC.exe every time. To play campaigns or Lan you can just run the Netstorm.exe. 

If you want to have a fort that already has all the levels run the TMaker.exe. If you have any questions about that see TMaker.txt.  

And remember to watch for updates on the server and patches at netstormhq.com!
