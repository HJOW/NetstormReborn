# 썬 디스크 투사체 교정 전 바이트 근거

첫 C++ 대조 전 root가 실제 보고서를 읽은 tool 출력의 SHA를 `recovery-archermissile-correction-evidence.json`에 기록한다. 이 디렉토리의 `archermissile-x86.tsv`는 그 사전 fixture SHA와 동일하다. `RawMissile-before-correction.cpp`는 ctor 두 분기와 CD 충돌 사운드 조건을 역변환해 복원한 바이트이며 그 사전 C++ SHA와 동일함을 감사한다.

이전 전체 보고서의 바이트 snapshot은 보존하지 못했다. 이 디렉토리에 이전 보고서가 있다고 주장하지 않는다. 초기 C++ 실패로그는 `extracted/campaign-runtime7-ArcherMissile_-initial-tests.log`로 보존한다. 같은 1,888개 입력의 재관찰이며 교정으로 추가한 신규 고유 입력은 0개다.
