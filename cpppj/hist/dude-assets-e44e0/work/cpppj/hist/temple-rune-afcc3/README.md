# 단위08 첫 Temple/Rune 전수 대조의 보존 출처

마지막 디컴파일 PC는 **HJOW-Athlon, 2026-10-13**이다. 이 디렉토리는 수정 전 전용 production/test/oracle/fixture/report를 원경로대로 보존하며 현재 구현 파일로 사용하지 않는다. 공통 SquidPostPop와 HP·기존 건설 근거는 별도 b76adf9 lineage를 참조한다.

첫 원본 보고서의 고유 입력 수는 Temple **6720**, Rune **1920**이다. 최초 공유 C++ 대조에서 Temple1330개 check, Rune26개 check가 실패했고 두 실제 소비자 검사는 성공했다. 이 수는 실패한 check 수이며 실패 입력 수로 해석하지 않는다.

Temple의 이전 원본 검사기는 네 해시 배열과 지면 주소가 겹쳤다. 따라서 선언한 spot 입력이 지워진 출력이며 지면 보정 분기의 올바른 근거로 사용하지 않는다. 전용 지면 주소로 수정한 현재 관찰이 같은 입력 식별자6720개를 대체한다. 목표점에서 준비한 사제 좌표도 실제 입력으로 다시 기록한다.

Rune의 이전 fixture1920개는 원본 출력으로 그대로 보존된다. C++가 시간 helper의 this로 Rune을 사용한 한곳을 발견한 Dais로 교정했다. 독립 Rune 시간 조회와 PostPop 내부 Dais 시간 조회를 구분한다.

현재 `tools/analyze_temple_rune_runtime8_lineage.py`가 이 보존 파일의 바이트 SHA, 원본 보고서 출처, 전체 기존 문자/토큰, 현재 동일 입력 식별자를 검사한다. 교정 전6720/1920과 재실행을 새 관찰 수에 더하지 않는다. 추가 고유 입력은 **0**이다. 실제 게임/GUI/캠페인 완주 검사는 아니다.
